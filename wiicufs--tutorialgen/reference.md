## 1. 直接说清，比“所谓的生活化”更像人话

### 反面：万能词没有信息

```markdown
还有一笔旧账没算。
同名端是下一节的整个舞台。
去耦等效是解决互感方程的大杀器。
理想变压器为什么能变阻抗？这是它的魔法。
```

这些句子的问题不是口语，而是指向不稳定：旧账可能是初始值、旧结果或漏洞；舞台可能是变量、问题或应用；大杀器可能是任意方法；魔法没有说明机制。信息熵极其可怜，观感恐怖谷。读者只能回翻上下文猜，且不适。

### 正面：对象、条件、关系、结果

```markdown
还需要解释一个现象：谐振时，电容两端电压为什么会高于电源电压？
本节先确定同名端如何决定互感项的正负号。
去耦等效把含互感项的方程改写为普通电感网络，之后可直接列结点方程。
由 U1/U2=N1/N2、I1/I2=N2/N1，可得 Zin=(N1/N2)^2 ZL。
```

后一组并不冷，也不需要读者解码。它直接告诉读者当前对象、下一步动作和因果关系。

### 类比何时可留

```markdown
# 不够：
不同频率的正弦像不同筛子，各筛各的。

# 可以：
不同频率的正弦在一个周期内的乘积积分为零，称为正交。
因此把函数乘上 sin(nωt) 再积分时，其他频率项全部消失，
可以单独求第 n 次的系数。这个结论只用于周期积分和线性汇总。
就像筛掉了...的筛子
```

这里即使保留“筛子”的直觉，也必须给出映射、结果和边界；通常直接写后一段就够。

## 2. 自然段落不是没有结构

下面是一种自然推进：

```markdown
### 为什么相变时温度不变仍然吸热？

相变期间，温度不变只说明分子平均动能没有继续增加，
不说明内能不变。液体变成蒸气时，分子间距离增加，
需要克服分子间作用力，因此势能增加。

能量关系是：
$$Q=\Delta U+P\Delta V$$

其中大部分热量对应 $\Delta U$，小部分对应膨胀做功。
所以“温度不变”不能推出“没有吸热”。
```

它有结构：问题 → 误解 → 机制 → 公式 → 结论。但它不需要先画阅读路线，也不需要在结尾广播“下一站”。

### 逐讲施工图的形态（五槽；它是第一依据）

**反面（旧写法，一句话 = 没长肉）**：

```markdown
2. 路径无关的四个等价条件（讲到：单连通；连续偏导；反例）
```

**正面（同一讲、同一节，长成施工图）**：

```markdown
2. 路径无关的四个等价条件
   ① 第一性：四个说法；等价链条逐步：1⇔2（拼闭曲线）；2⇒3（构造 $u=\int_A^B$，**真验 $u_x=P,u_y=Q$**）；3⇒4（$u_{xy}=u_{yx}$，需连续）；4⇒1（格林）
   ② 定义/边界：等价只在**单连通**成立；反例 $P=\frac{-y}{x^2+y^2},Q=\frac{x}{x^2+y^2}$，除原点 $P_y=Q_x$，绕原点逐项算得 $2\pi$
   ③ 必须答：认知链【施工图 2】四等价；$P_y=Q_x$ 够不够
   ④ 例题：1 道验证 $u$ 满足 $u_x=P,u_y=Q$
   ⑤ 易错：有洞仍用；只查 $P_y=Q_x$ 不查单连通
```

**判断标准**：预填充和最终版几乎一样 = 没长肉 = 失败；施工图里出现“可以验证/显然/同理” = 槽没填满。

**对照**：正文的节标题与这里的 `1.` `2.` 一一对应；正文改节名/顺序 → **先改这里**。


PLAN 是作者的工作台。读者只应看到当场需要的内容：

## 4. 脉络图、任务、自测：按需，不是仪式

### 值得加脉络图的情形

一讲同时处理三个分支，例如“先求状态 → 选择查表路径 → 做能量方程 → 核查单位”。读者确实会在路径选择处迷失，可放一张简短路线图。

### 不值得加脉络图的情形

一讲只解释一个线性因果链，例如“为什么电容电压连续”。直接从 $i=C\,du/dt$、有限电流、积分关系讲到结论，读者不会因为没有树状图而迷路。

### 值得加自测的情形

多个相近公式容易混淆时，用三五项动作型自测：例如“我能区分饱和液体、气液混合物和过热蒸气”。

### 不值得加自测的情形

小结已经用例题、公式与边界自然收束时，再加十个复选框只会重复。

## 5. 不空降的最小形态

### 反面

```markdown
相变时查饱和表，利用 x 求 h。
```

读者不知道“饱和表、x、h”是什么，也不知道为何要查。

### 正面

```markdown
气液混合物的温度和压力不再足以确定状态，还需要知道其中蒸气占多少。
这个比例叫干度 $x$：单位质量混合物中蒸气的质量占比，范围是 0 到 1。
查饱和表得到饱和液体焓 $h_f$ 和饱和蒸气焓 $h_g$ 后，混合物焓为
$$h=h_f+x(h_g-h_f)。$$
```

定义、为什么需要、符号、范围、公式都在读者第一次遇到处。

## 6. 验证脚本的最小形态

```python
# 规模纪律：方波的前若干傅里叶项，目标 < 2 秒。
import numpy as np

A = 10.0
for n_max in [1, 3, 9, 99]:
    u_rms = np.sqrt(sum((4 * A / (n * np.pi)) ** 2 / 2
                        for n in range(1, n_max + 1, 2)))
    print(f"n={n_max}: partial RMS={u_rms:.4f}; expect -> {A}")
```

它不是为了炫代码：输出明确说明正在测什么、预期是什么、为何这个数据能支撑讲义结论。脚本应归档，讲义中的数值能追溯回来。

## 7. 预写偏差要诚实留下

```markdown
> 一个修正：原先以为“保留更多傅里叶项会消除跳变处过冲”。
> 实测中，过冲高度没有消失，只是集中到更窄的时间区间。
> 这是 Gibbs 现象。增加项数能改善整体逼近，但不能让跳变点局部一致收敛。
```

需要同时有：原预想、实际现象、原因。不要把改过后的结论伪装成一开始就知道。

## 10. 完整形态检查在 PLAN 中怎样工作

“完整覆盖”不是让正文回答一个六问清单，而是防止作者只写“主线刚好够跑”的部分。**六问分两层记录**：归属/深度在地毯清单（关键词级），完整形态在逐讲施工图的每个知识点上（讲内）。

### 第一层：地毯清单的“四选一”

```markdown
- 电容电压连续性 → 05 讲：正文（要会用；推导到“有限电流 ⇒ u 连续”）
- 理想冲激电流 → 05 讲：认识层（知道有此例外，不展开）
- 串并联电容的初值 → 后讲（06 讲，元件串并联）
- 电容的储能公式 → 不写（上册已讲；理由：前置课已覆盖）
```

### 第二层：逐讲施工图每点的完整形态

```markdown
### 05 偏导数与全微分
1. 偏导数的定义（讲到：固定其余变量的一元导数；几何=截面切线；例题一道）
2. 全微分（讲到：定义 Δz=AΔx+BΔy+o(ρ)；可微⇒连续/偏导存在）
3. 电容电压连续性（讲到：$i=C\,du/dt$ → 有限电流 ⇒ $u$ 连续；被控：理想冲激例外；相邻边界：“不是永远开路”）
```

### 读者正文可能只需要这样写

```markdown
换路瞬间，若电容电压突然改变，就意味着 du/dt 无穷大。
由 i=C du/dt 可知这需要无穷大的电流。普通电路没有这种电流，
所以 uC(0+)=uC(0-)。

注意：这不是“电容永远开路”。电容只在直流稳态中不再有电流；
换路后它仍可能充电或放电。
```

后台检查很完整，正文却只写当前读者必须知道的关系、条件和常见误用。

### 可用的 PLAN 写法（1.7.0：论坛求助体）

```markdown
### 05 偏导数与全微分

- 我带着什么来：
  - 一元导数我熟：斜率、切线，$f'(x)$ 就是变化率；
  - 我以为“偏导”就是把另一个变量当常数，照一元求导就行；
  - 全微分这词在教材里见过，但没看懂它和偏导差在哪。
- 第一反应：
  - 偏导应该不难，就是多写一个符号；
  - 全微分大概就是 $dz=f_x dx+f_y dy$？——但为什么能这么写，不知道；
  - 可微是不是就是“偏导存在”？感觉教材在绕。
- 我会依次卡住（顺着施工图）：
  - 【元问题】这讲到底在解决“怎么算”还是“可不可微”？两件事混在一起，我该先抓哪个？
  - 【施工图 1】偏导的几何意义是什么？截面切线……那另一个方向呢？
  - 【施工图 2】全微分的定义里 $o(\rho)$ 是啥？为什么不是 $o(\Delta x)$？
  - 【边界】偏导存在但不可微，真的假的？能不能给个具体函数让我信？
  - 【防错】我是不是会把“偏导连续 ⇒ 可微”记成“可微 ⇒ 偏导连续”？
  - 【不知道该不该问】$\partial$ 这个符号怎么读？考试写“偏 z 偏 x”行不行？
  - 【不知道该不该问】混合偏导 $f_{xy}=f_{yx}$ 是不是永远成立？老师说“一般成立”，那什么时候不成立？
  - 【额其实我们不这么说】我以为要背“可微的充分必要条件”，结果好像只背充分条件？
  - 【意思对但没人这么记】我能不能把全微分理解成“切平面”？——可以，但 07 讲才正式说。
```

## 12. 问答段装新知识的事故

线性代数教程曾把下列内容首讲塞进“想当然三连击”：

- $(AB)^{-1}=B^{-1}A^{-1}$；
- $A^{-k}$ 的含义；
- 矩阵没有普通除法。

这种写法看似有互动，实际是让读者从答疑里捡结论：

```markdown
# 错误
想当然三连击：$(AB)^{-1}$ 是不是 $A^{-1}B^{-1}$？
```

正确次序应是：正文先给定理、条件、推导或数值例子；定理全部，完整给出后，为了便于理解，才可以在后面追加式地写：

```markdown
如果你想当然认为顺序无所谓，试一下 A、B 都可逆但 AB≠BA 的例子。
反序不是记号游戏：要让 (AB)(B^{-1}A^{-1})=I，B 必须先和 B^{-1} 相邻。
```

末尾若还需要问答索引，首句写“本节零新知识，只对答案”，每条对应一个正文小节。

## 13. 任务、脉络图、导航的选择示范

## 14. 一个完整验证脚本的形态

```python
# 规模纪律：小规模演示，目标 < 8 秒。
import time
import numpy as np

T0 = time.perf_counter()
np.random.seed(42)
N = 50
x = np.random.uniform(-3, 3, N)
y = 2.0 * x + 3.0 + np.random.normal(0, 0.5, N)

print("=== EXP1: gradient descent — loss decreases ===")
w, b, lr = 0.0, 0.0, 0.05
losses = []
for epoch in range(100):
    y_pred = w * x + b
    loss = np.mean((y_pred - y) ** 2)
    losses.append(loss)
    w -= lr * 2 / N * np.sum((y_pred - y) * x)
    b -= lr * 2 / N * np.sum(y_pred - y)

print(f"learned w={w:.4f}, b={b:.4f}")
print(f"loss: epoch 0={losses[0]:.4f}, epoch 99={losses[-1]:.4f}")
print("expect: loss decreases and parameters approach the source values")
print(f"runtime={time.perf_counter() - T0:.2f}s")
```

脚本同时给出规模、数据、预期、实测和结论。讲义引用其中数字时，读者可定位脚本复跑。

## 15. 预写偏差怎样诚实写进讲义

### 例：偏差—方差的预想被实测打破

预写：“9 次多项式偏差低、方差高。”

实测：

```text
degree=9: bias^2=6.3720, variance=390.5019
```

可写成：

```markdown
> 一个诚实记录：这次 9 次模型的 bias^2 也高（6.37），
> 不是常见图里的“低偏差”。样本数接近参数数目，拟合数值不稳定，
> 部分采样的预测剧烈偏离，连平均预测也偏了。
> 但最明显的仍是方差 390 的爆炸：它说明模型对训练样本极敏感。
```

三件事必须都在：原预想、实际数据、根因。不要偷偷把结论换掉。

## 18. 例题题头与答案步长

### 反面：让读者翻书的题头

```markdown
**例 2**：同上点，求最速上升方向。
**例 2**：同上 $\mathbf a,\mathbf b$，求叉积。
**候选表示范（以 §四例 2 为例）**：
**2.** 同上，求 $z_{xy}$。
```

读者看到“同上”时手里没有上一题：最速上升是在哪个函数、哪一点？$\mathbf a,\mathbf b$ 是多少？§四例 2 是哪道题？只能回翻。

### 正面：题头就地完整

```markdown
**例 2**：$f=x^2+y^2$ 在 $(1,1)$，求最速上升方向与最大变化率、最速下降方向。

**例 2**：$\mathbf a=(1,2,3)$、$\mathbf b=(2,0,-1)$。求 $\mathbf a\times\mathbf b$……

**候选表的写法（以 $f=x^2+y^2$ 在三角形 $x\ge0,y\ge0,x+y\le2$ 上的最值为例）**：

**2.** $z=f(u,v)$、$u=x-y$、$v=xy$：求 $z_{xy}$。
```

允许额外写“相似例子见第 04 讲例 2，你可以去看”，但当前处必须自足。

### 反面：跳步答案

```markdown
**解**：$f_x=3x^2-3y=0$ ⇒ $y=x^2$；$f_y=3y^2-3x=0$ ⇒ $x=y^2$。
代入：$x=x^4$ ⇒ $x=0$ 或 $x=1$，对应 $(0,0)$ 与 $(1,1)$。
$(0,0)$：$A=0,B=-3,C=0,\Delta=-9<0$ ⇒ 鞍点。
```

问题：$x=x^4$ 怎么解出两个根？$A,B,C$ 从哪来？

### 正面：每步给出依据

```markdown
**解**：$f_x=3x^2-3y=0$ ⇒ $y=x^2$；$f_y=3y^2-3x=0$ ⇒ $x=y^2$。
代入：$x=x^4$ ⇒ $x(x^3-1)=0$ ⇒ $x=0$ 或 $x=1$（实数；另两根为复数）。

先算二阶偏导（对任意点）：$f_{xx}=6x$、$f_{xy}=-3$、$f_{yy}=6y$。

- $(0,0)$：$A=0,B=-3,C=0$，$\Delta=0\cdot0-(-3)^2=-9<0$ ⇒ 鞍点；
- $(1,1)$：$A=6,B=-3,C=6$，$\Delta=36-9=27>0$，$A>0$ ⇒ 极小值 $f(1,1)=-1$。
```

验收：读者遮住答案，能按步骤复现。

## 19. 具体化与可视化审计

### 反面：只有符号公式

```markdown
链式法则：$z_x=f_u u_x+f_v v_x$；多层就是多个因子连乘；
变量同时出现在多层时 $z_x=f_x+f_u u_x$。
```

读者看不出“谁对谁”：$f_x$ 和 $f_u u_x$ 分别在算哪条路？多层到底是几条？

### 正面：一个形态配一个具体函数，逐项算

```markdown
**形态三：$z=x^2u$、$u=x+y$，求 $z_x$（在 $(1,2)$）**
- 直接项：固定 $u$，$f_x=2xu$；
- 间接项：$f_u=x^2$，$u_x=1$，$f_uu_x=x^2$；
- $z_x=2xu+x^2$；在 $(1,2)$：$u=3$，$z_x=2\cdot1\cdot3+1=7$；
- 只算直接项得 6——差 1 就是漏掉的那条路。
```

### 能画没画的反例

```markdown
可微：$\Delta z=A\Delta x+B\Delta y+o(\rho)$，其中 $o(\rho)$ 管所有方向。
```

读者不知道“一个平面贴住曲面”是什么样；配一张曲面 + 逼近平面 + 误差的图，这句话才有几何内容。
