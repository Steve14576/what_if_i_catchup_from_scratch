# Python 程序设计——导览

> 这是一套**面向完全没有写过程序的人**的教程。目标不是"认得语法"，而是：学完你能自己配置环境、写出能读能改的脚本、出错时查到具体一行、用 git 保住自己的代码、看懂 AI 写的东西是不是在骗你，并且能拿下国内大学《Python 程序设计》的期末试卷。

## 这门课是什么

Python 是一门通用编程语言。它的语法接近英文，能跑在 Windows、macOS、Linux 上，标准库自带文件、日期、JSON、CSV、正则这些日常工具，所以它常被用来做三件事：写小工具（批量改文件名、整理表格）、做数据处理（读 CSV、统计、出图）、当作学编程的第一门语言（语法负担小，能把注意力放在"怎么想问题"上）。

这门课的编排分四段：

- **计算机素养（01–03）**：程序在机器里怎么跑、你的机器怎么配成能干活的工位、代码怎么保管和回退。这三讲是**见面熟**：目的是让你知道"有这么几样东西、以后卡住时知道去哪儿找"，不是让你背命令。读的时候不要有压力，任何一条命令记不住都正常；它们会在后面用到的地方被重新提起、就地再讲一遍。**你完全可以现在只翻一遍，直接跳到 04 讲开始写代码，卡住了再回来查。**
- **Python 主干（04–15）**：从第一个 `print` 开始，一路到字符串、列表、字典、控制流、函数、异常、模块、文件、面向对象。这是本课程的主体，每一讲都是"能用起来的完整形态 + 能跑的实测 + 能自检的作业"。
- **验证与交付（16–17）**：怎么用测试和断点确认自己没改坏、怎么写日志、怎么测量性能、怎么让别人（或三个月后的你）在你的机器之外也能把项目跑起来。
- **与后续的接口（18）**：与 AI 协作的工程流程、五个必须能讲清机制的问题、往下走的路标。

这条主线有一条硬约束：**Python 各讲不依赖 01–03**。任何一讲正文里的命令都是整条给出的，你不需要先读过素养卷才能跑通。

## 前置

- 会用电脑打字、会打开文件夹、会装软件。就这些。
- 数学：只需要四则运算与"变量"这个概念的日常理解；本课程会在第 04 讲把"变量"重新讲一遍，旧的直觉不碍事。
- 英语：术语会给中英对照（方便你读官方文档和报错信息），正文不依赖英语阅读能力。
- 不需要任何编程经验；也不需要预先装好 Python——第 02 讲会从头装。

## 学完你能做什么

- [ ] 在一台干净的电脑上装好 Python、建好虚拟环境、装好依赖，并说清每条命令改动了什么。
- [ ] 写出 50–300 行的单文件脚本：读文件、清洗文本、用列表与字典做统计、把结果写回文件或打印成表。
- [ ] 遇到报错时读懂 traceback，定位到具体一行，而不是重跑碰运气。
- [ ] 把逻辑封装成函数与类，并说清"什么时候该用类、什么时候用字典就够"。
- [ ] 用 git 每改一小步就提交，改坏了能退回上一版，并推送到远程仓库。
- [ ] 用 `pytest` 写测试、用 `breakpoint()` 查变量、用 `logging` 留下可查的记录。
- [ ] 用 `time.perf_counter()` 测出瓶颈，并把 $O(n^2)$ 的写法改成 $O(n)$。
- [ ] 让项目在别人的机器上按 README 跑起来（依赖有版本、路径不含本机绝对路径）。
- [ ] 审查 AI 给出的 diff：判断它改了什么、有没有编造、该不该接受。
- [ ] 应付期末试卷：语法、容器、函数、异常、文件、类这些题型能独立做完。

## 每讲怎么用

1. 开头有一段"这一讲解决什么"，先看它，判断这一讲要不要现在读（素养卷可以只翻一遍就跳过）。
2. 正文按问题、机制、例子、边界展开。算得出数的地方一定给数，跑得起来的地方一定给完整命令。
3. 代码块可以直接复制运行；输出单独标出，并注明是哪条命令产生的。凡正文给出的实测数字，都能在 `scripts/` 找到对应脚本复跑。
4. 读到"这里现在只要知道这么多"就真的可以停，后面的讲会回来接。
5. 每讲末尾有作业，答案平铺在题目下方（没有折叠）。先自己写，再对照。
