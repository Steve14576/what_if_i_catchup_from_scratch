# Python 教程 导览

这是一套从零开始的 Python 教程。它假定你**没写过任何一行代码**，从"机器到底在跑什么"讲起，一直讲到你能独立写出一个能交给别人跑通的小项目。

它有两个目标，这两个目标不冲突：

1. **真会用**：装环境、读写文件、处理数据、调试、写测试、用 git 管版本、能判断 AI 给出的代码哪里可疑。
2. **考得过**：覆盖国内大学 Python 课程的主线考点（语法、内置类型、流程控制、函数、文件、OOP 基础、常用标准库），期末卷子上的常规题型都能上手写。

不针对计算机二级，但考纲之外的东西不会假装不存在：凡是本课不细讲的方向，最后一讲都会点名"它是什么、什么时候需要、去哪学"。

## 前置知识

- 会用鼠标和键盘，能新建、保存、找到文件。
- 会打开一个终端窗口。**不会也没关系**，第 02 讲讲的就是这件事。
- 不需要任何编程经验，也不需要高等数学。

## 学完能做什么

- 从一个空文件夹开始，装好解释器与虚拟环境，写出、运行、调试一个几百行的 Python 程序。
- 用数值、字符串、列表、字典、集合把真实数据收进来、转成结构、算出去，并知道自己选错了结构会付出什么代价。
- 读写文本 / CSV / JSON 文件，处理编码与路径，写出"换台电脑也能跑"的脚本。
- 读懂报错栈并定位问题，给关键函数写测试，把一个脚本整理成有目录结构、依赖声明和入口命令的小项目。
- 用 git 命令行完成日常版本管理：提交、看差异、回退、分支，并知道什么不该进仓库。
- 面对一个陌生工具，能用四个问题判断它值不值得现在学、它改的是哪一层、出问题去哪看证据。

## 素养卷怎么读（减压声明）

第 01–08 讲是正式讲次，但它们的作用是**让你提前见个面、知道有这么回事**，不是让你现在就掌握。

- 里面的操作看不懂，可以跳过去，直接翻到第 09 讲开始写 Python。课程主线不依赖这八讲里的任何一个操作。
- 当你后面真的需要它们时（比如第一次装第三方包、第一次把代码改坏想退回去、第一次被 AI 改乱文件），会明确指回这几讲，那时再读会比现在顺。
- 反过来，如果你现在就跟着做完这八讲，后面的路会平很多：你知道文件在哪、命令怎么敲、环境装在哪、改坏了怎么退、工具该往哪找。
- 这八讲里的作业都是"动手看一眼"或"按判据判断"的级别，不要求你背任何命令或产品名。

一句话：**先翻一遍，混个脸熟；用到了再回来。**

## 怎么跑本课程的示例

本课程所有代码都在终端里运行，不靠双击。

```powershell
python hello.py
```

如果 Windows 上 `python` 提示"不是内部或外部命令"，先看第 02 讲（`PATH`）和第 03 讲（安装与勾选项）。在 macOS 或 Linux 上通常是：

```bash
python3 hello.py
```

双击 `.py` 的后果取决于系统关联：常见情况是窗口一闪就关，或者被编辑器打开成文本——两种都看不到运行结果。这不是你写错了，是运行方式不对：真正执行代码的是解释器，双击并不等于"运行"。

## 达标判据

如果你能独立做到下面这些，这套课就算学到位了：

1. 拿到一段报错，能指出出错的文件与行号，并说出错误类型大概意味着什么。
2. 拿到一份 CSV，能读进来、清洗掉脏数据、按某个字段分组统计、把结果写成 JSON。
3. 能说清"列表、元组、字典、集合"各自适合什么场景，并给出反例。
4. 能用 git 提交、看差异、回退到上一个可用版本。
5. 能对 AI 给出的代码说出"这里可能有问题"，并设计一个最小验证。
6. 面对一个新工具，能说出它改的是哪一层、出问题去哪看证据、现在该不该学。
