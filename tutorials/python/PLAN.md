## 一、目标与读者画像

### 课程目标（学完能做什么，行为化）

- 能从一个空目录开始，装好解释器与虚拟环境，写出、运行、调试一个几十到几百行的 Python 程序。
- 能说清每个语法构造"长什么样、执行时到底发生了什么、完整形态能变到什么程度、什么会打断它"，而不是背语法表。
- 能用内置类型（数值、字符串、列表、元组、字典、集合）把真实数据收进来、转成结构、算出去，并知道自己选错了结构会付出什么代价。
- 能读写文本 / CSV / JSON 文件，处理编码与路径，写出别人能跑通的脚本（不依赖"在我电脑上能跑"）。
- 能读懂报错栈并定位问题，能给关键函数写测试，能把一个脚本整理成有目录结构、依赖声明和入口的小工程。
- 能用 git 命令行完成日常版本管理（提交、看差异、回退、分支），能判断哪些东西不该进仓库。
- 面对一个陌生工具，能用四个问题判断它的作用层级、风险与验证方式；能判断 AI 给出的代码哪里可疑、怎么验证、什么时候不该用它。
- 应对国内大学 Python 课程的期末考试：语法、数据类型、流程控制、函数、文件、OOP 基础、常用标准库的常规考法都能上手写；同时知道考纲之外还有哪些东西存在。

### 读者是哪一种（决策记录）

**完全零基础**（2026-11 用户对齐拍板）。含义：

- 没写过任何代码，不知道变量、终端、路径、解释器是什么；也可能从没打开过命令行窗口。
- 有正常的高中数学与英语阅读能力，能接受抽象定义，但不接受"先记住，以后就懂了"。
- 不知道自己不知道什么：没写出来的东西他问不出来。所以"地毯式覆盖优先于组织优雅"是本课程第一纪律。
- 不是"带旧语言经验"的画像；但凡是有其他语言直觉的地方（缩进即语法、变量是标签不是盒子、`for` 是遍历不是三段式、Python 没有值传递/引用传递这种二分），正文要主动破误。

### 主线与素养卷的耦合边界（关键决策）

1. **01–08 是正式讲次，不是附录**：有自己的前置说明、正文、小结、作业，编号进大纲，进 AA。
2. **01–08 每讲开头必须有一句减压声明**：这一讲只要求"见个面熟"，看不懂的段落可以跳过，后面真正用到时会回来重讲。声明之后正文仍然要讲清楚。
3. **Python 主线（09 起）不得依赖素养卷的任何操作**：任何一讲的实验都必须在"已经装好 Python 并会打开一个终端"这一个前提下就能完成；git、虚拟环境、AI 工具只作为可选加速出现，删掉它们不影响主线讲次自洽。

### 环境与工具口径（决策记录）

- **主线工具链**：Windows 优先（本机与多数机房），同时给 PowerShell / cmd / macOS / Linux 的差异；`python -m venv .venv` + `pip install` + `git` 三条是正文主干。
- **uv 作为推荐方案单列小节**，讲清它替掉了哪几步；所有主线实验都有"不用 uv 也能做"的等价路径。
- **编辑器与 AI 工具可以出现具体产品**（2026-11-14 用户明确更新）：VS Code、Cursor、Qoder、Claude Code、Codex 类命令行代理。写"怎么装、怎么配、怎么判断产物"，不写"某产品的隐藏技巧"，不写排行榜。
- **无网络 / 无管理员权限 / 机房还原卡**三种场景，02、03 各给替代路径。
- 课程自身验证脚本按本仓库口径跑：`uv run --with numpy python <脚本>`；这是作者侧执行方式，不写进读者主线。

### 例子与实验风格

- 每个机制至少给一个能手工算出结果的小例子，再给一个贴近真实任务的例子（日志、成绩表、配置、文件）。
- 能打印出的对象身份、类型、长度、耗时、报错信息，就是本课程的主要可视化手段。
- 涉及随机、性能、浮点的结论不许单次成立就写：至少三个规模点 / 多次重复，报告均值与波动。
- 预写结论被实测推翻时，正文保留"原预想 / 实测 / 根因"三件事，不许悄悄改口。

### 排版契约（8 条硬约束，逐讲交付前机械核对）

1. 标题层级最多三级（`#` / `##` / `###`）；`###` 一律带 `X.Y` 编号。
2. 每讲表格不超过 6 张，且只用于对照或决策，不用于承载正文叙述。
3. 所有代码块必须标语言：`python`、`powershell`、`bash`、`text`、`gitignore`、`toml`、`json`。
4. 加粗不独占一行。
5. 结尾顺序固定：`## 小结` → `## 作业`；答案平铺为 `**参考答案：**`，禁用 `<details>`。
6. 任何新工具第一次出现，必须回答三件事：怎么装、怎么验证装好了、装不上或没权限时怎么办。
7. 术语首次出现三件套：中英全称 + 一句话定义 + 现在要理解到哪一步。
8. 每讲开头固定四行 blockquote：前置、预计时间、本讲回答、本讲结束你能做到。

### 作业风格

每讲 4–8 题；每题给可自验证的验收方式；答案只用已教概念；答案不跳步；涉及报错的题要贴真实报错文本。

### 3.3 关键机制"完整形态六问"决定

六问依次为：① 标准形态与自由度 ② 嵌套与组合 ③ 被控与外部打断 ④ 重复与共存 ⑤ 规范 ⑥ 相邻边界。

- **名字绑定与对象（09）**：① `名字 = 对象`，可反复绑定不同类型；② 可绑定任何表达式结果；③ 重新绑定只改名字；④ 两个名字可指向同一对象（别名），改内容要看可变性；⑤ `snake_case`，不用 `l`/`O`/`I`；⑥ 与 C 的"内存盒子"不同。①③④⑥ 进正文，② 在 15 讲回收。
- **切片（11/12）**：① `seq[start:stop:step]`，三者可省，`step` 可负；② 可连续切片；③ 越界不报错；④ 切片生成新对象（numpy 才是视图，23 讲对照）；⑤ 取前 N / 反转 / 去首尾；⑥ 与 `del seq[i:j]`、切片赋值的区别。全进正文。
- **`for` 与迭代协议（14）**：① 没有三段式；② 可嵌套、可与 `else`/`break` 组合；③ 遍历中修改容器会跳过或报错；④ 生成器只能遍历一次（16 讲补）；⑤ 要索引用 `enumerate`；⑥ 与 `while` 的分工。全进正文。
- **函数参数（15）**：① 位置/关键字/默认/`*args`/`**kwargs`/仅关键字；② 参数可解包传入；③ 默认值在定义时求值一次；④ 同名参数后写是语法错误；⑤ 默认值不用可变对象；⑥ 与"值传递/引用传递"二分不对应。全进正文。
- **作用域与闭包（15/16）**：① LEGB；② 内层读外层，写外层需 `nonlocal`；③ 函数内赋值即变局部；④ 闭包捕获变量不是值；⑤ 少用 `global`；⑥ 与类属性、模块级变量的边界。①②④ 进 16，③⑤ 进 15。
- **异常（18）**：① `try` 包住最小范围；② 可嵌套，未捕获向外传播；③ `finally` 一定执行（含 `return` 路径）；④ 捕获顺序从具体到宽泛；⑤ 不裸 `except`、不静默 `pass`；⑥ 与"返回值表示错误"的分工。全进正文。
- **文件与编码（19）**：① `open(路径, mode, encoding)`；② 可嵌套多个 `with`；③ 异常时 `with` 仍会关闭；④ 写入模式会截断；⑤ 永远显式 `encoding="utf-8"`；⑥ `Path` 管路径，`open` 管内容。全进正文。
- **类与实例属性（20/21）**：① `__init__` 里 `self.x` 建实例属性；② 类体赋值建类属性；③ 读属性先实例后类；④ 同名时实例遮蔽类；⑤ 可变类属性是共享陷阱；⑥ 与模块变量、闭包的分工。①③④⑤ 进 20，共享后果实测。
- **git 三区（04）**：① 工作区 → 暂存区 → 历史；② `add` 可多次、可挑文件；③ `commit` 后工作区再改不影响已提交；④ `restore` 与 `revert` 各退到哪；⑤ 一次提交一件事；⑥ 与"复制文件夹备份"的边界。全进正文，④ 实测。
- **虚拟环境（03）**：① `python -m venv .venv` 生成独立解释器入口与 `site-packages`；② 激活只改当前 shell 的 `PATH`；③ 不激活可用绝对路径；④ 每项目各建各的；⑤ `.venv` 不进 git；⑥ 与全局安装的边界。全进正文。
- **上下文与提问（06）**：① 上下文是一段有限长度的输入；② 可分层（目标/现状/约束/验收）；③ 超出预算会丢细节；④ 同一会话里旧内容会互相干扰；⑤ 贴原文不转述；⑥ 与"搜索引擎"的边界（它不查证）。全进正文。
- **权限分档（08）**：① 读 / 写 / 执行三档；② 可按目录限制；③ 危险动作先 dry-run；④ 权限随能力上升而收紧；⑤ 先提交再放权；⑥ 与"聊天式工具"的边界。全进正文。
