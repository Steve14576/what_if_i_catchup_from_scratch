# AA 一览：Python 教程概念与命令字典

这是附录，不是速查口令。每条概念给：中文名、英文/缩写、**说清它是什么**、首次出现讲次、理解层次。理解层次有三种：

- **要会用**：能独立写出来、能改、能排错；
- **要能解释**：能用自己的话说明它是什么、为什么需要它；
- **知道存在**：听过、知道什么时候该去找它，但不要求现在会用。

条文随讲次增长；每条都指向首次出现的那一讲，方便回查当时是怎么讲的。

## 一、概念

| 概念（中文） | 英文 / 缩写 | 定义（说清是什么） | 首次出现 | 理解层次 |
|---|---|---|---|---|
| 源代码 | source code | 用某种编程语言的语法写出、供人或程序阅读的文本；在硬盘上和普通文本文件没有存储层面的区别 | 第 01 讲 | 要能解释 |
| 解释器 | interpreter | 一个可执行程序，读入源代码文本、检查语法、编译成字节码并按顺序执行；Python 程序的执行者 | 第 01 讲 | 要能解释 |
| 字节 | byte | 计算机存储数据的基本单位，八个二进制位一组；文件在硬盘上就是一串字节 | 第 01 讲 | 知道存在 |
| 编码 | encoding | 字节与字符之间的对应规则；同一串字节用不同编码解码会得到不同字符，这就是乱码的来源 | 第 01 讲 | 要能解释（细节在第 08、16 讲） |
| 标准库 | standard library | 随解释器一起安装的一批 Python 模块，不需要联网或额外安装即可 `import` | 第 01 讲 | 知道存在 |
| 包 | package | 别人写好并发布出来的一组 Python 代码，装进环境后可以 `import` 使用 | 第 01 讲 | 要能解释（第 03、14 讲展开） |
| pip | pip | Python 的包管理程序，负责从包索引下载并安装第三方包；它自己也是装在某个环境里的程序 | 第 01 讲（提及）/ 第 03 讲（正式） | 要会用 |
| 交互式解释器 | REPL（Read-Eval-Print Loop） | 敲一行代码、立刻求值、把表达式结果打印出来的运行环境，提示符是 `>>>` | 第 01 讲 | 要会用 |
| 标准输出 | stdout | 程序正常打印内容的输出通道；终端默认显示它，也可以被重定向到文件 | 第 01 讲 | 要能解释 |
| 退出码 | exit code | 程序结束时交给操作系统的一个整数，`0` 表示正常结束，非 `0` 表示出了错误 | 第 01 讲 | 要能解释 |
| 语法错误 | SyntaxError | 源代码不符合 Python 语法时抛出的错误，在编译阶段发现，此时一行都还没执行 | 第 01 讲 | 要能解释 |
| 缩进错误 | IndentationError | 缩进不符合语法要求（例如 `if` 后没有缩进块）时抛出的错误，同属编译阶段 | 第 01 讲 | 要能解释 |
| 运行时错误 | runtime error | 语法合法、执行到某一句时才发生的错误（如名字未定义、文件不存在） | 第 01 讲 | 要能解释 |
| 调用链 | call stack | 程序执行到出错位置时，一层层函数调用留下的记录；traceback 里从下往上是"由内到外" | 第 01 讲 | 要能解释（第 15、21 讲展开） |
| 进程 | process | 正在运行中的程序实例，占用内存与 CPU；关闭启动它的终端会让它终止 | 第 01 讲 | 知道存在 |
| 环境变量 | environment variable | 操作系统保存的一组"名字 = 值"配置，供程序在启动时读取 | 第 01 讲（提及） | 要能解释（第 02 讲正式讲） |
| PATH | PATH | 一个特殊的环境变量，保存一串目录；终端在这些目录里按顺序查找你敲的命令，顺序决定哪个版本先被找到 | 第 01 讲（提及）/ 第 02 讲（正式） | 要能解释 |
| 虚拟环境 | virtual environment | 一个独立目录，里面有这套环境自己的解释器入口、`site-packages` 与配置文件，使不同项目互不污染 | 第 01 讲（提及）/ 第 03 讲（正式） | 要会用 |
| 编译型 / 解释型 | compiled / interpreted | 源码是否需要先整体翻译成机器码再运行；Python 属于解释型，运行必须有解释器在场 | 第 01 讲 | 知道存在 |
| 终端 | terminal | 一个窗口程序，负责显示文字、把键盘输入交给 shell、把结果画出来 | 第 02 讲 | 要能解释 |
| shell | shell | 真正读你输入的命令行、解释并执行它的程序，如 PowerShell、cmd、bash | 第 02 讲 | 要能解释 |
| 命令行 | command line | 你敲的那一整行字，包括命令名与参数 | 第 02 讲 | 要能解释 |
| 提示符 | prompt | shell 打印在输入区前面的字符串，通常包含当前目录，不同类型 shell 长得不一样 | 第 02 讲 | 要能解释 |
| 目录 | directory | 存放文件或其他目录的容器，与"文件夹"同义 | 第 02 讲 | 要会用 |
| 根目录 | root directory | 文件树的最顶层；Windows 每个盘符各有一个根（`C:\`），Unix 只有一个（`/`） | 第 02 讲 | 要能解释 |
| 绝对路径 | absolute path | 从根开始写、不依赖当前目录就能唯一定位一个文件的路径 | 第 02 讲 | 要会用 |
| 相对路径 | relative path | 从当前工作目录开始写的路径，同一个写法在不同目录下指向不同文件 | 第 02 讲 | 要会用 |
| 当前工作目录 | cwd（current working directory） | 进程的一个属性，相对路径的起点；子进程继承启动它的父进程的 cwd | 第 02 讲 | 要能解释 |
| 路径分隔符 | path separator | 路径里用于分层级的字符；Windows 认 `\` 与 `/`，Unix 只认 `/` | 第 02 讲 | 要能解释 |
| 大小写敏感 | case sensitivity | 文件名是否区分大小写；Windows 不区分，Linux 区分 | 第 02 讲 | 知道存在 |
| 通配符 | wildcard | 用 `*` 等符号代表一批文件名的写法，由 shell 展开后再交给命令 | 第 02 讲 | 知道存在 |
| 重定向 | redirection | 用 `>` / `>>` 把程序的标准输出写进文件；由 shell 完成，不是程序自己做的 | 第 02 讲 | 知道存在 |
| 管道 | pipe | 用 `|` 把前一个命令的输出交给后一个命令当输入 | 第 02 讲 | 知道存在 |
| site-packages | site-packages | 一个环境存放第三方包的目录；`pip install` 的终点，也是隔离的实际承载者 | 第 03 讲 | 要能解释 |
| 基础解释器 | base interpreter | 建虚拟环境时用作母本的那个解释器；虚拟环境自己不全量拷标准库，运行时回它那里借 | 第 03 讲 | 要能解释 |
| 环境前缀 | `sys.prefix` / `sys.base_prefix` | 两个变量：前者是当前环境的根目录，后者是基础安装的根；两者不相等就说明你在虚拟环境里 | 第 03 讲 | 要会用 |
| 激活 | activate | 把当前 shell 的 `PATH` 改成"本环境 `Scripts` 排最前"，并设置 `VIRTUAL_ENV` 与提示符前缀；不是开关 | 第 03 讲 | 要会用 |
| 停用 | deactivate | 把 `PATH` 还原成激活前存下的那份 | 第 03 讲 | 要会用 |
| 环境配置文件 | `pyvenv.cfg` | 纯文本，记录母本路径（`home`）、是否借用全局包（`include-system-site-packages`）、版本与创建命令 | 第 03 讲 | 要能解释 |
| 镜像源 | index / mirror | 包索引的替代服务器，国内常用清华为加速下载；不改包的内容，只改下载地址 | 第 03 讲 | 要会用 |
| 依赖清单 | `requirements.txt` | 一行一个"包名==版本"的文本清单，用 `pip freeze` 导出、`pip install -r` 恢复 | 第 03 讲 | 要会用 |
| uv | uv | 用 Rust 写的 Python 包与项目管理器；建环境与装包比 `venv` + `pip` 快一个量级，但默认不往环境里装 pip | 第 03 讲 | 知道存在 |
| 多版本启动器 | `py` launcher | Windows 上的 `py.exe`，可以按版本号选择解释器，不依赖 `PATH` 里那个 `python` 是谁 | 第 03 讲 | 知道存在 |
| 离线 wheel | wheel / `.whl` | 预先下载好的包文件，可用 `--no-index --find-links` 安装；必须与 Python 版本、系统位数匹配 | 第 03 讲 | 知道存在 |
| 仓库 | repository | 带历史的项目目录；历史全部存在它下面的 `.git` 目录里 | 第 04 讲 | 要会用 |
| 提交 | commit | 一次保存动作的产物：当时完整的文件树 + 作者 + 时间 + 一句说明 + 内容哈希 | 第 04 讲 | 要会用 |
| 哈希 | hash | 由提交内容算出的十六进制缩写（如 `88f58f5`），用来唯一标识一个提交 | 第 04 讲 | 要能解释 |
| HEAD | HEAD | 指向"你当前所在提交"的指针；`HEAD:文件` 表示取该提交里的这个文件 | 第 04 讲 | 要能解释 |
| 工作区 | working tree | 硬盘上你正在编辑的那些真文件 | 第 04 讲 | 要能解释 |
| 暂存区 | staging area / index | 一份"下一次提交要包含什么"的清单；`git add` 的终点、`git commit` 的源头 | 第 04 讲 | 要会用 |
| 分支 | branch | 指向某个提交的名字；切换分支只是换 HEAD 指向并更新工作区，不是复制代码 | 第 04 讲 | 要会用 |
| 合并 | merge | 把另一个分支的提交并入当前分支；目标分支未动过时表现为快进 | 第 04 讲 | 要会用 |
| 快进 | fast-forward | 合并时只需把当前分支指针向前挪到目标提交，不产生合并提交 | 第 04 讲 | 要能解释 |
| 冲突 | merge conflict | 两个分支改了同一处，git 不猜，用 `<<<<<<<` / `=======` / `>>>>>>>` 标出两边，需要人定稿 | 第 04 讲 | 要会用 |
| 忽略规则 | `.gitignore` | 列出不纳入版本控制的路径模式；只对未被跟踪的文件生效 | 第 04 讲 | 要会用 |
| 远程仓库 | remote | 网络上的仓库副本，用于备份与协作；`clone` / `push` / `pull` 与它交互 | 第 04 讲 | 知道存在 |
| 工具四问 | four questions | 判断一个陌生工具的四步：解决什么问题、输入输出是什么、改哪一层、出问题去哪看证据 | 第 05 讲 | 要会用 |
| 工科判据 | engineering criterion | 判断"会不会"的标准：能跑、能测、能量、能复现；"看懂了"不算 | 第 05 讲 | 要能解释 |
| 分层信任 | layered trust | 底层（语言语义、文件系统）要真懂，中层（库）看文档加小实验，高层（框架、代理）先用但保留回退 | 第 05 讲 | 要能解释 |
| 三条底线 | repeatable / reversible / verifiable | 工程素养的三条判据：可重复（换机器能跑）、可回退（改坏能回去）、可验证（结论有判据） | 第 05 讲 | 要能解释 |
| 语言模型 | language model | 根据已有文本预测"下一个 token"的模型；它没有运行你的程序 | 第 06 讲 | 要能解释 |
| token | token | 模型处理文本的基本单位（约等于一个词或半个词）；上下文窗口与计费都按它算 | 第 06 讲 | 知道存在 |
| 上下文 | context | 一次性交给模型阅读的全部内容；它不知道你磁盘上的文件，除非你贴进去 | 第 06 讲 | 要能解释 |
| 幻觉 | hallucination | 模型生成出看似合理、实则不存在或不成立的内容（编造的函数名、参数、结论） | 第 06 讲 | 要能解释 |
| 上下文窗口 | context window | 一次请求里模型能读到的 token 上限，包含系统提示、历史对话、你的输入与它的输出 | 第 06 讲 | 要能解释 |
| 上下文工程 | context engineering | 在有限窗口里决定放哪些信息（目标/现状/约束/验收），以得到想要的产出 | 第 06 讲 | 要会用 |
| 温度 | temperature | 控制采样随机程度的参数；低更稳定、高更发散；调到很低也不保证逐字复现 | 第 06 讲 | 知道存在 |
| 截断 | truncation | 输入超过窗口时丢弃部分内容的处理；丢哪一段由实现决定，不能假定"贴了就读到了" | 第 06 讲 | 要能解释 |
| 编辑器 | editor | 负责编辑文本的程序，本身不一定能运行或调试代码 | 第 07 讲 | 要能解释 |
| IDE | Integrated Development Environment | 集成开发环境：编辑器 + 运行 + 调试 + 项目管理打包在一起 | 第 07 讲 | 要能解释 |
| 调试器 | debugger | 能暂停程序、逐行执行、查看变量当前值的工具；比 `print` 多了"暂停与观察" | 第 07 讲 | 要会用 |
| 命令行代理 | CLI agent | 在终端里运行、能读写项目文件并执行命令的 AI 工具（Claude Code、Codex 一类） | 第 07 讲 | 要能解释 |
| 扩展 | extension | 给编辑器加能力的插件包；装在用户扩展目录，同类装两个会互抢 | 第 07 讲 | 要会用 |
| 解释器选择 | Select Interpreter | 编辑器里记录"用哪个 python.exe 来运行、补全、调试"的配置项，本质是一条路径 | 第 07 讲 | 要会用 |
| 断点 | breakpoint | 让程序执行到某一行时暂停的标记；配合查看变量与单步使用 | 第 07 讲 | 要会用 |
| 单步 | step / next | 一次只执行一行（或进入函数内部）的调试动作 | 第 07 讲 | 要会用 |
| 外部判据 | external evidence | 不依赖对方说法的客观证据，如退出码、`diff --stat`、`--help` 输出的参数表 | 第 08 讲 | 要会用 |
| 预演 | dry-run | 只报告"将会做什么"而不真执行的形式（如 `git clean -nd`），用于在不可逆操作前确认范围 | 第 08 讲 | 要会用 |
| 对象 | object | 内存里真实存在的数据单位，带类型与身份；变量名只是贴在上面的标签 | 第 09 讲 | 要能解释 |
| 绑定 | binding | 名字与对象之间的关联；`a = 1` 是把名字 `a` 绑到对象 `1` 上，不是把值装进盒子 | 第 09 讲 | 要能解释 |
| 身份 | identity（`id()`） | 对象在内存中的编号；`is` 比较的就是它，`==` 比较的是内容 | 第 09 讲 | 要会用 |
| 类型 | type | 对象所属的类别（`int` / `str` / `float` …）；名字本身没有类型 | 第 09 讲 | 要会用 |
| 内置函数 | built-in function | 解释器自带、不需 `import` 就能用的函数，如 `print` / `input` / `type` / `int` | 第 09 讲 | 要能解释 |
| 关键字 | keyword | 语法保留字（`for` / `if` / `class` / `None` 等），不能当名字 | 第 09 讲 | 要能解释 |
| 注释 | comment | `#` 到行尾的文本，解释器忽略，不进入 `__doc__` | 第 09 讲 | 要会用 |
| 文档字符串 | docstring | 函数/模块/类体第一句字符串，存进 `__doc__`，供 `help()` 与编辑器使用 | 第 09 讲 | 要会用 |
| 缩进 | indentation | Python 用缩进表示代码块；同块内必须一致，不混 Tab 与空格 | 第 09 讲 | 要会用 |
| 任意精度整数 | arbitrary-precision integer | `int` 的位数按需增长，不受机器字长限制，不会溢出 | 第 10 讲 | 要能解释 |
| 浮点误差 | floating-point error | 十进制小数无法被有限位二进制精确表示而导致的微小偏差 | 第 10 讲 | 要能解释 |
| 双精度 | IEEE 754 double | `float` 的存储格式，约 15–17 位有效数字 | 第 10 讲 | 知道存在 |
| 银行家舍入 | round half to even | 恰好 `.5` 时向最近偶数取整的规则，`round()` 采用 | 第 10 讲 | 要能解释 |
| 容差比较 | tolerance / `math.isclose` | 用绝对或相对容差判断两个浮点"够不够近"，替代 `==` | 第 10 讲 | 要会用 |
| 整数分 | integer cents | 金额用最小货币单位（分）存为整数，避免浮点误差累积 | 第 10 讲 | 要会用 |
| 索引 | index | 用位置取单个字符或元素；从 0 起，支持负索引（-1 是最后一个） | 第 11 讲 | 要会用 |
| 切片 | slice | `seq[起点:终点:步长]`，含起点不含终点，越界自动截断不报错 | 第 11 讲 | 要会用 |
| 不可变对象 | immutable | 创建后内容不能改的对象（`str` / `int` / `tuple`）；所谓"修改"都产生新对象 | 第 11 讲 | 要能解释 |
| 转义 | escape sequence | 反斜杠加字符表示特殊字符（`\n` / `\t` / `\\`）；`r"..."` 里不生效 | 第 11 讲 | 要会用 |
| f-string | formatted string literal | 前缀 `f` 的字符串，`{}` 求值嵌入，`:` 后接格式说明符（对齐、精度、千分位） | 第 11 讲 | 要会用 |
| 字节串 | bytes | `encode()` 之后的字节序列，写作 `b'...'`；`len` 数是字节数不是字符数 | 第 11 讲 | 要能解释 |
| 列表 | list | 有序、可变、可混装类型的序列，方括号写法；方法就地修改 | 第 12 讲 | 要会用 |
| 元组 | tuple | 有序、不可变的序列；元素结构固定，可解包、可当字典键 | 第 12 讲 | 要会用 |
| 就地修改 | in-place | 直接改原对象的方法（如 `append` / `sort`），通常返回 `None` | 第 12 讲 | 要能解释 |
| 浅拷贝 | shallow copy | 新建外层容器、元素引用共享；`a[:]` / `a.copy()` / `list(a)` | 第 12 讲 | 要会用 |
| 深拷贝 | deep copy | 递归复制所有层级，`copy.deepcopy`；比浅拷贝慢 | 第 12 讲 | 要会用 |
| 可哈希 | hashable | 有稳定哈希值、能作字典键或放进集合；可变对象不可哈希 | 第 12 讲 | 要能解释 |
| 解包 | unpacking | 把序列元素一次分给多个名字，如 `x, y = point` | 第 12 讲 | 要会用 |
| 字典 | dict | 键值映射；按键哈希定位（均摊 O(1)）；键必须可哈希且唯一 | 第 13 讲 | 要会用 |
| 集合 | set | 只存唯一元素的无序容器；均摊 O(1) 成员判断，支持并交差 | 第 13 讲 | 要会用 |
| 哈希表 | hash table | 用哈希值定位存储格子的结构，字典与集合的底层实现 | 第 13 讲 | 要能解释 |
| 视图 | view | `keys()` / `values()` / `items()` 返回的动态视图，不复制数据 | 第 13 讲 | 知道存在 |
| 均摊常数时间 | amortized O(1) | 平均每次操作耗时与规模无关；偶尔因扩容变慢 | 第 13 讲 | 要能解释 |
| 真值 | truthiness | 对象在 `if` 中的真假：零、空、`None`、`False` 为假，`"0"` / `[0]` 为真 | 第 14 讲 | 要能解释 |
