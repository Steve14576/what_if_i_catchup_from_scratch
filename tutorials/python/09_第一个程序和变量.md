## 0. 第一个程序

新建 `hello.py`，内容就一行：

```python
print("hello, python")
```

在终端里运行：

```powershell
python hello.py
```

```text
hello, python
```

这一行拆开看：`print` 是一个**函数**（准确说是 Python 内置的函数），括号里是交给它的东西，双引号里是**字符串**——一段文本。`print` 做的事只有一件：把它收到的东西送到屏幕上。

第 01 讲已经讲过为什么在文件里写和在 `>>>` 后敲结果一样：执行的都是同一个解释器。

下一节先看脚本从哪一行开始执行，以及括号和引号各自在做什么。

## 1. 执行顺序：从上到下，一句一句

Python 没有"入口函数"这种要求（不像 C 的 `main`），脚本默认从第一行开始，按书写顺序往下执行。实测一个三行的脚本：

```python
print("第一行")
print("第二行")
print("第三行")
```

```text
第一行
第二行
第三行
退出码 = 0
```

这个顺序看起来理所当然，但它有两个重要推论，后面每讲都会用到：

- 你**不能**在定义之前使用一个名字（第 02 讲那个 `NameError` 就是这么来的）；
- 想让某段代码"先不执行"，就得把它放进函数里（第 15 讲），而不是随手写在中间。

执行顺序定了，下一节把 `print` 的三个参数一次说清。

## 2. `print`：三个参数

大多数人只用过 `print(东西)`。它其实还有三个参数，各自管一件事：

| 参数 | 管什么 | 默认值 | 什么时候用 |
|---|---|---|---|
| `sep` | 多个值之间的分隔符 | 一个空格 | 想用 `-`、`,`、`\t` 分隔时 |
| `end` | 这一行结尾输出什么 | 换行符 | 想让下一条输出接在同一行时 |
| `file` | 输出到哪里 | 标准输出（屏幕） | 想把内容写进文件时（第 19 讲） |

实测四种写法：

```text
print('a', 'b', 'c')            -> a b c
print('a', 'b', sep='-')        -> a-b
print('x', end='')  再 print('y') -> xy
用 file= 写文件后，文件内容是: '写进文件的一行'
```

读法：

- `print('a', 'b', 'c')` 收到三个值，默认用空格分开，最后加一个换行；
- `sep='-'` 把分隔符换掉；
- `end=''` 把结尾的换行换成空字符串，于是下一条 `print` 的输出接在同一行；
- `file=某个文件对象` 让它不往屏幕写，而往文件写。

代码里的 `参数名=值` 这种写法叫**关键字参数**，第 15 讲讲函数时会正式讲；现在只需要知道"`print` 认这三个名字"。

一个常见需求：把几个值拼成一个字符串再输出。可以用逗号让 `print` 自己分开，也可以自己拼：

```python
print("和是", 9)        # 输出：和是 9（中间自动一个空格）
print("和是" + str(9))  # 输出：和是9（自己拼，不留空格）
```

第二种里的 `str(9)` 是把数字转成字符串，`+` 在这里是字符串拼接——这些是第 11 讲的内容，现在看到不慌，知道有这么两条路即可。

`print` 会用了，下一节看 `input`：为什么它拿回来的永远是字符串。

## 3. `input`：拿回来的永远是字符串

### 3.1 实测：为什么一算就错

`input("提示文字")` 会在屏幕上显示提示，等你敲一行、按回车，然后**把这一整行当成字符串**交回来。

写一个脚本试：

```python
a = input("第一个数: ")
b = input("第二个数: ")
print("a 的类型:", type(a).__name__)
print("直接相加:", a + b)
print("转成整数后相加:", int(a) + int(b))
```

输入 `3` 和 `4`，实测输出：

```text
第一个数: 第二个数: a 的类型: str
直接相加: 34
转成整数后相加: 7
```

三件事：

- `a` 的类型是 `str`（字符串），**哪怕你输入的是数字**；
- `a + b` 是字符串拼接，所以 `"3" + "4"` 得到 `"34"`；
- `int(a)` 把字符串按十进制解释成整数，`3 + 4` 才是 `7`。

这就是新手第一个"明明输入的是数字，怎么算错了"的来源。**`input` 只负责读一行文本，理解数字是你的责任。**

`type(x)` 返回这个对象的类型，`type(x).__name__` 取它的类型名（`'str'`、`'int'`、`'float'`）。`type` 是内置函数，第 10 讲讲类型时会反复用它。

### 3.2 转换失败长什么样

如果输入的不是数字，`int()` 会失败。实测 `int("abc")`：

```text
ValueError: invalid literal for int() with base 10: 'abc'
退出码 = 1
```

`ValueError` 的意思是"值不对"：类型对了（字符串），但内容不是合法的整数。这条报错里的 `'abc'` 告诉你具体是哪个值有问题。

现在你只需要知道"它会这样失败"；怎么优雅地处理（提示用户重输而不是崩溃）是第 18 讲异常处理的内容。

类型问题暴露了，下一节回答"变量到底是什么"。

## 4. 变量：标签不是盒子

### 4.1 绑定的实测

这是本讲最核心的一节。先看实测：

```text
a = 1; b = a       -> a=1, b=1, id 相同吗 = True
再执行 a = 2       -> a=2, b=1
```

如果变量是"盒子"，`b = a` 就是把 1 复制进 `b` 这个盒子，`a = 2` 就是往 `a` 盒子里放 2——那 `b` 是 1，这没问题。但"盒子"模型会在别的地方塌掉（下一节就会看到）。

更准确的模型是**标签**：

- `1` 是一个**对象**，存在内存里；
- `a` 是一个**名字**，先贴在 `1` 上；
- `b = a` 不是复制对象，是再拿一张标签 `b` 贴到**同一个** `1` 上；
- `a = 2` 是把标签 `a` 撕下来，贴到新对象 `2` 上。原来那个 `1` 上还贴着 `b`，所以 `b` 仍然是 1。

`id(x)` 返回对象的身份编号（在 CPython 里就是内存地址），可以用来判断"两个名字是不是贴在同一个对象上"。实测 `id(a) == id(b)` 为 `True`，因为那一刻两个名字确实指着同一个 `1`。

一句话记住：**`=` 不是"把值放进变量"，而是"把名字绑到一个对象上"。**

### 4.2 为什么"标签"比"盒子"好用

因为 Python 里有些对象是**可变**的，有些是**不可变**的。数字、字符串不可变（你没法"把 1 改成 2"，只能新建一个 2）；列表、字典可变（可以往里加东西）。

盒子模型遇到可变对象会立刻失效。实测（列表是第 12 讲的内容，这里只借它演示"可变对象"）：

```python
xs = [1, 2]
ys = xs
ys.append(3)
```

```text
-> xs=[1, 2, 3], ys=[1, 2, 3], 是同一个对象吗 = True
```

`ys = xs` 没有复制列表，只是给同一个列表多贴了一张标签；`ys.append(3)` 改的是那个列表本身，所以 `xs` 看到的也变了。

对照：另造一个内容相同的新列表

```text
另造一个内容相同的 zs=[1,2,3]：xs == zs 吗 = True，xs is zs 吗 = False
```

内容相等（`==` 为真），但不是同一个对象（`is` 为假）。

### 4.3 `==` 与 `is`：判等与判同一

| 比较 | 问的问题 | 例子 | 结果 |
|---|---|---|---|
| `x == y` | 两个对象**内容**一样吗 | `[1,2,3] == [1,2,3]` | `True` |
| `x is y` | 是不是**同一个对象** | `[1,2,3] is [1,2,3]` | `False` |

日常写代码，判"值相等"一律用 `==`；`is` 基本只用于一个场景：判断是不是 `None`，写成 `if x is None`。现在只要记住这两者的分工，别把 `is` 当 `==` 用。

### 4.4 动态类型：名字没有类型，对象才有

同一个名字可以先后指向不同类型的对象，实测：

```text
x = 10      -> type = int
x = '十'    -> type = str
x = 3.5     -> type = float
```

不报错。原因还是标签模型：`x` 只是一张标签，撕下来贴到哪个对象上都行；"类型"是这个对象的属性。

这带来两个直接后果：

- **灵活**：一个变量可以先放配置值、后放结果，不必声明类型；
- **危险**：类型错误只会在运行到那一句时暴露，而不是在"声明"时被检查。所以第 10 讲会专门讲类型转换的规则与失败形态。

### 4.5 名字的规则

| 规则 | 说明 | 例子 |
|---|---|---|
| 只能用字母、数字、下划线 | 数字不能开头 | `user_name`、`n2` 可以；`2n` 不行 |
| 区分大小写 | `Name` 与 `name` 是两个名字 | 容易造成"改了一个另一个没改" |
| 不能用关键字 | `for`、`if`、`class`、`None` 等是语法保留字 | 实测 `for = 1` 报 `SyntaxError` |
| 中文合法但不建议 | 技术上能跑（实测 `半径 = 3` 正常输出） | 输入法切换、检索、协作都麻烦 |
| 约定用 `snake_case` | 小写字母 + 下划线 | `total_score`，而不是 `TotalScore` |

命名不是审美问题。名字是给你三个月后自己看的检索线索：`n` 和 `total_score`，后者能让你在不看代码的情况下猜出它是什么。

变量模型立住了，下一节补两个常被忽略的细节：注释与文档字符串。

## 5. 注释与文档字符串

```python
# 这是注释，Python 执行时会忽略它
def area(r):
    """返回圆面积，r 为半径。"""
    return 3.14 * r * r
```

实测输出：

```text
函数的文档字符串 = '返回圆面积，r 为半径。'
调用结果 = 3.14
```

两种东西都"不参与计算"，但用途不同：

- **注释**：`#` 开头的行，从 `#` 到行尾都被忽略。它写给读代码的人看，Python 不保存它。
- **文档字符串**（docstring）：函数/模块/类体里的**第一句字符串**（通常用三引号）。它会被保存到对象的 `__doc__` 属性里，`help(area)` 或编辑器的悬停提示读的就是它。

实测证明了两者的区别：注释那行没有出现在 `area.__doc__` 里，而三引号那句出现了。

`def` 是定义函数的关键字，三引号的完整用法是第 11 讲的内容，函数是第 15 讲——现在只需要知道"这两样东西不参与计算，但一个是给自己看的，一个是给工具看的"。

两者分清了，下一节说缩进：它不是排版，是语法。

## 6. 缩进是语法，不是排版

其他语言用大括号 `{}` 表示"这几行属于同一块"，Python 用**缩进**。实测缺少缩进：

```text
IndentationError: expected an indented block after 'if' statement on line 1
```

加上四个空格后就正常：

```text
加上四个空格: 退出码=0 输出='x'
```

三条硬规则：

- 同一块内缩进必须**一致**（本项目统一用 4 个空格）；
- **不要混用 Tab 和空格**，编辑器看着一样，解释器会报 `TabError`；
- 缩进层级决定"谁属于谁"，所以复制粘贴别人的代码后第一件事是检查缩进。

这里的 `if` 是条件判断（第 14 讲），现在只需要借它看"块"这个概念：`if True:` 后面缩进的那几行，属于这个 `if` 的块。

缩进规则明确了，下一节把前面所有零件拼成一个能跑的小脚本。

## 7. 把脚本补完整

把前面几节拼起来，就是本讲的成品：读两个数，输出和差积商。

```python
a_text = input("a = ")
b_text = input("b = ")
a = float(a_text)
b = float(b_text)
print("和 =", a + b)
print("差 =", a - b)
print("积 =", a * b)
print("商 =", a / b)
```

输入 `7` 和 `2`，实测输出：

```text
a = b = 和 = 9.0
差 = 5.0
积 = 14.0
商 = 3.5
退出码 = 0
```

四件事值得注意：

1. 第一行看起来像 `a = b = 和 = 9.0`，这是本讲用管道喂输入造成的：没有回显，两句提示语就直接连在一起了。你自己在终端里敲时，每敲一行按回车会换行，看到的是分开的几行。
2. 这里用 `float` 而不是 `int`，因为除法会产生小数。
3. 四个结果全是小数（`9.0` 而不是 `9`）：`float` 参与运算，结果就是 `float`。第 10 讲会讲清 `int` 与 `float` 的区别、以及为什么 `0.1 + 0.2` 不等于 `0.3`。
4. 这份脚本**没有处理"用户输入了非数字"**的情况，会直接崩。这不是遗漏，是第 18 讲要解决的问题——现在先让主流程跑通。

顺便说清脚本的两个命名细节：`a_text` / `b_text` 是"用户输入的原始文本"，`a` / `b` 是"转换后的数字"。名字里带上这一步的差别，三个月后你才看得懂为什么要有两次赋值。

脚本拼完了，下一节把本讲结论收起来。

## 8. 这一讲留下的东西

- 脚本从上到下逐句执行，没有 `main` 入口；名字必须先绑定后使用。
- `print` 有 `sep` / `end` / `file` 三个参数，分别管分隔、结尾、去向。
- `input` 永远返回字符串；要算数必须自己转 `int()` / `float()`，转换失败会抛 `ValueError`。
- 变量是标签：`=` 把名字绑到对象上；重新绑定不影响别的名字；可变对象被多个名字共享时，改内容会互相可见。
- `==` 判内容相等，`is` 判同一对象；日常判等用 `==`，`is` 只用于 `None`。
- 名字没有类型，对象才有；同一个名字可以先后指向不同类型。
- 注释给读者，文档字符串给工具；缩进是语法，四空格一致，不混 Tab。

下一讲进入数字本身：`int` 与 `float` 到底差在哪、整数除法为什么有两种、`0.1 + 0.2` 为什么会出问题。

## 本讲小结

- 脚本按书写顺序执行，实测三条 `print` 输出顺序就是书写顺序。
- `print` 的 `sep`、`end`、`file` 三个参数分别控制分隔符、行尾、输出去向。
- `input` 返回 `str`：实测输入 3 和 4，`a + b` 得到 `"34"`，`int(a) + int(b)` 才是 7；`int("abc")` 抛 `ValueError`。
- 变量是标签：实测 `a = 1; b = a; a = 2` 之后 `b` 仍为 1，因为标签 `a` 被撕走，对象 `1` 没变。
- 可变对象被两个名字共享时，改内容两边都变（实测 `xs`/`ys`），而内容相同的新对象 `is` 为假。
- `==` 比内容，`is` 比身份；名字区分大小写，关键字不能当名字，中文合法但不建议。
- 注释不进 `__doc__`，函数体第一句三引号字符串会进（实测）。
- 缩进决定代码块：`if` 后不缩进报 `IndentationError`，加四个空格正常。

## 作业

**Q1.** 下面这段脚本运行后输出什么？为什么？

```python
x = "5"
y = 2
print(x * y)
```

**参考答案：** 输出 `55`。

`x` 是字符串 `"5"`，`y` 是整数 `2`。字符串与整数相乘在 Python 里表示"重复"，所以 `"5" * 2` 得到 `"55"`。这是本讲"类型属于对象"的直接后果：同样的 `*`，作用在数字上是乘法，作用在"字符串与整数"上是重复。

如果想让结果是 10，必须显式转换：`int(x) * y`。

**Q2.** 你写了：

```python
a = input("请输入一个数: ")
b = input("请输入一个数: ")
print(a + b)
```

输入 `2` 和 `3`，输出是 `23` 而不是 `5`。解释原因，并改成正确写法。

**参考答案：** `input` 返回的永远是字符串，`a + b` 做的是字符串拼接，`"2" + "3"` 得到 `"23"`。

正确写法二选一：

```python
a = int(input("请输入一个数: "))
b = int(input("请输入一个数: "))
print(a + b)
```

或者保留原始文本、单独转换：

```python
a_text = input("请输入一个数: ")
b_text = input("请输入一个数: ")
print(int(a_text) + int(b_text))
```

第二种多一行，但名字上区分了"文本"与"数字"，后面要处理非法输入时更好改。

**Q3.** 预测并解释下面三行之后的 `a` 与 `b`：

```python
a = [1, 2]
b = a
b = [9, 9]
```

**参考答案：** `a` 是 `[1, 2]`，`b` 是 `[9, 9]`。

关键在于第三行是**重新绑定**而不是修改对象：`b = [9, 9]` 新建了一个列表，然后把标签 `b` 从原来的列表上撕下来贴到新列表上。原来那个 `[1, 2]` 还贴着 `a`，不受影响。

对比本讲实测的那个例子：`ys.append(3)` 是**改内容**，所以 `xs` 跟着变；`b = [9, 9]` 是**换标签**，所以 `a` 不变。这两个动作长得像，效果完全相反。

**Q4.** 用 `print` 的 `end` 参数，在同一行输出 `1 2 3`，每个数字之间用一个空格分隔、末尾换行。

**参考答案：** 两种写法都行：

```python
for i in range(1, 4):
    print(i, end=" ")
print()
```

或者不用循环，直接利用 `sep`：

```python
print(1, 2, 3)
```

第二种更简单——`print` 默认就用空格分隔、自动换行。想练 `end` 的话，第一种的末尾 `print()` 是必要的：它输出一个空行，把行尾补上。

（`for` 与 `range` 是第 14 讲的内容，这里只作为示例；用第二种完全不涉及没学的语法。）

**Q5.** 下面这段代码报什么错？属于第 01 讲说的哪一类（执行前发现还是执行中发现）？

```python
print("开始")
print(未定义的变量)
print("结束")
```

**参考答案：** 报 `NameError: name '未定义的变量' is not defined`，属于运行时错误——执行到第二行才发现。

屏幕会先输出 `开始`，然后中止，`结束` 不会输出，退出码为 `1`。判断依据是第 01 讲：语法/缩进错误在执行前就被发现，一行都不跑；运行时错误发生在执行到那一句时，前面的语句已经生效。

**Q6.** 把下面的代码改成"用标签模型解释得通"的注释（即：用注释说清每一行在做什么，而不是写"给 a 赋值"）：

```python
total = 0
count = 0
total = total + 5
count = count + 1
```

**参考答案：** 一种写法：

```python
total = 0            # 累加器初始化为 0，指向整数对象 0
count = 0            # 计数器初始化为 0
total = total + 5    # 先取出 total 当前指向的 0，算出新对象 5，再把 total 改贴到 5 上
count = count + 1    # 同理：取出 0，算出 1，把 count 改贴到 1 上
```

要点是：`total = total + 5` 不是"在原对象上加 5"（整数不可变），而是"算出新对象、把名字改贴过去"。这个区别在你以后遇到可变对象（列表）时会变得关键。
