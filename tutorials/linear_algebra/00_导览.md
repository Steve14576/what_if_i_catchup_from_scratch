# 线性代数——从零重学 · 导览

> 这是一套**面向完全没系统学过线性代数的人**的教程。目标不是"看懂几个定义"，而是：学完你能单纯凭借它，通过一份正经的期末/考研水准线代考核，并且真的理解每个方法在空间里干了什么、边界在哪。

## 这门课是什么

线性代数是"研究线性关系"的数学，也是几乎所有定量领域（机器学习、物理、工程、经济、统计）的公共语言。它的主线其实只有一句话：**把"一堆东西按比例相加"这件事，系统地搞清楚。**

- 向量 = 能加、能缩放的东西；
- 矩阵 = 记录"一个线性变换"的数表；
- 解方程组 = 问"能不能用几个向量拼出目标"；
- 特征值 / SVD = 找一个变换"最本质的拉伸方向"。

这套课从零开始，每一步都配三样东西：**几何直觉**（它在空间里干什么）、**能笔算的小例子**（贴近答卷）、**能跑的 numpy 数值实验**（把结论坐实成具体数字）。你不需要任何线性代数基础，只需要高中代数（会解二元一次方程、知道坐标平面）和一点点微积分（第 21 讲才用到）。

## 前置

- 高中代数：会解一次方程组、会算多项式。
- 初步微积分：仅**应用提升的第 21 讲（矩阵微积分）**需要导数/梯度的概念；主干 01–18 讲完全不用。
- Python：不需要预先会。需要跑数值实验时，讲义会当场给出可直接运行的代码；环境用 `uv`（不熟也没关系，只跑不改的话，照着复制即可）。

## 学完你能做什么

- [ ] 手算并解释：矩阵乘法、行列式、逆矩阵、高斯消元解方程组。
- [ ] 判断线性方程组解的情况（无解/唯一/无穷），写出解的结构，说清秩在数什么。
- [ ] 判断一组向量是否线性无关，给子空间找出基、说出维数。
- [ ] 说清一个矩阵对应的四个基本子空间，用秩-零化度定理对账。
- [ ] 求特征值与特征向量，判断能否对角化，用对角化快速算 $A^{100}$、解递推。
- [ ] 做 Gram-Schmidt 正交化、把 $\boldsymbol b$ 投影到子空间、用正规方程做最小二乘拟合。
- [ ] 用顺序主子式判二次型正定，说清正定的几何与特征值判据。
- [ ] 写出任意矩阵的 SVD，解释"旋转-缩放-旋转"，做低秩逼近。
- [ ] （应用提升）解释计算机上为什么条件数大的矩阵危险，跑 LU/Cholesky/迭代法；推出最小二乘与 PCA 的矩阵梯度。

## 讲次大纲

主干打下的地基越牢，后面每一讲越轻松——请**按顺序**学，不要跳。

## 每讲怎么用（固定循环）

1. 开头看**本讲目标**和**脉络图**，知道这讲要带你做出什么、途经哪几站。
2. 跟着**任务成品**走——先看到"我能做出什么"，再回头拆零件。
3. 每个概念注意标注的**理解角度与深度**：是"要会推导/手算"、"要知道有这回事+去哪找它"、还是"建立直觉即可"。别把该建直觉的东西当公式背，也别把该手算的偷懒跳过。
4. 数值实验的每个实测数字，都能在 `scripts/` 里找到对应脚本复跑。
5. 结尾**掌握度自测**全打勾 → 做**作业**（基础/提高/综合三档）→ 达标。

## 达标判据

- **一讲达标** = 该讲"掌握度自测"全部能打勾，且作业能独立做出来（答案只在 `<details>` 里用于对照，不是抄）。
- **一门达标** = "学完你能做什么"清单全部打勾。
- **应试达标** = 拿一份真实期末/考研线代卷，能在限时内做下来且说清每步理由。
