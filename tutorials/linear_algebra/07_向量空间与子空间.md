## 一、任务开场：凭什么多项式"也是向量"？

看这个集合：**所有次数不超过 3 的多项式**（如 $1-2t+4t^3$、$3t+t^2$）。它长得和 $\mathbb{R}^n$ 完全不像——没有一列数字，也没有箭头。可我记得第 01 讲说过"向量就是能加能缩放的东西"。那问一句：**多项式能加、能缩放吗？**

$$\underbrace{(1-2t+4t^3)}_{f} + \underbrace{(3t+t^2)}_{g} = 1+t+t^2+4t^3\quad(\text{还是次数} \le 3 \text{的多项式} ✓)$$

$$7\cdot(1-2t+4t^3)=7-14t+28t^3\quad(\text{还是次数} \le 3 \text{的多项式} ✓)$$

**加完、缩放完，还是"自己人"**——它在行为上和 $\mathbb{R}^n$ 里的向量一模一样。那为什么不能把它当向量？**可以当。** 这个"能不能当向量"的判断标准，就是本讲要建立的"资格表"：一个集合想要自称"向量空间"，必须让加法和数乘在这个集合里**封闭**（结果不跑出去），外加几条不太会出事的记账规则。凡是通过资格表，就是向量空间，管你是多项式、函数还是矩阵。

> 下一站：把资格表写全——八条公理。

## 二、向量空间：八条公理＝一张打勾清单

**正式定义**：集合 $V$（元素叫"向量"，记号沿用 $\vec v,\vec w,\dots$）配上一套**加法**和**数乘**（对实数标量），若下面八条**全部**成立，则称 $V$ 为（实）**向量空间（vector space）**：

**（A）加法四条**
1. 交换律：$\vec u+\vec v=\vec v+\vec u$；
2. 结合律：$(\vec u+\vec v)+\vec w=\vec u+(\vec v+\vec w)$；
3. **有零向量（zero vector）**：存在 $\vec0\in V$ 使 $\vec v+\vec0=\vec v$ 对一切 $\vec v$ 成立；
4. 有负向量：每个 $\vec v$ 有 $-\vec v$ 使 $\vec v+(-\vec v)=\vec0$。

**（B）数乘四条**
5. $1\,\vec v=\vec v$；　6. $(ab)\vec v=a(b\vec v)$；
7. $a(\vec u+\vec v)=a\vec u+a\vec v$；　8. $(a+b)\vec v=a\vec v+b\vec v$。

**怎么对待这八条（态度，先于背）**：**不背，当打勾清单用**。第 01 讲说过这个心智模型，这里正式盖章：它们没有任何反直觉的东西——全是你在数字上早已习惯的规则（数加数满足这八条，$\mathbb{R}^n$ 也满足）。列出来的唯一意义是：**以后遇到一个新集合，宣称它是向量空间之前，逐条打勾**。绝大多数集合挂掉的不是这几条记账规则（它们自动成立），而是下一条没说出来的**封闭性**——而这正是子空间三条件的重点。真正要盯着的就一句话：**加法、数乘的结果还在不在集合里**。

**为什么"封闭性"在八条里不显眼**：加法、数乘的定义域本来就是"集合内的两元素/元素与标量"到"某个结果"的映射；八条只约束结果的性质，**没保证结果还在 $V$ 里**。"还在不在里面"要单独检查——这就是子空间三条件的前两条。

**例子公园（认脸用，不用每个都深挖）**：

| 集合 | 是不是向量空间（加法=对应系数相加等） | 一句话 |
|---|---|---|
| $\mathbb{R}^n$ | ✓ | 第 01 讲老乡 |
| $\{\vec0\}$ | ✓ | 最平凡的空间，仅含零向量 |
| 过原点的直线 $\{(t,2t)\}$ | ✓ | 第 01 讲 span 的实例 |
| 次数 $\le n$ 的多项式 $P_n$ | ✓ | 本讲开场例子，系数数组视角就是 $\mathbb{R}^{n+1}$ |
| $m\times n$ 矩阵全体 $M_{m\times n}$ | ✓ | 加法=逐元素，数乘=逐元素（第 02 讲第三节） |
| 全体连续函数 / 全部可微函数 | ✓ | **线性组合保持连续性和可微性**（微积分事实），所以函数空间成立 |
| 不过原点的直线 $\{(1,0)+(t,2t)\}$ | ✗ | 缺零向量、加法不封闭（第三节判例） |
| 第一象限 $\{(x,y):x,y\ge0\}$ | ✗ | 数乘 $-1$ 就跑出去（第三节判例） |

> **就地破误（naive）**："函数也能是向量？太抽象了吧。"——抽象恰恰是目的：微分方程的解集、信号空间、统计里的函数空间都是向量空间，**一套"向量"的直觉和定理免费复用**（本讲第七节落点，第 21 讲矩阵微积分还会用它）。你现在只需要接受"**能加能缩放并且留在里面**"就是全部资格。

> 下一站：空间里面的"合格小子集"——子空间。

## 三、子空间：三条件打勾 + 为什么必须过原点

**定义**：$V$ 是向量空间，$W\subseteq V$ 是非空子集。若满足三条，则 $W$ 是 $V$ 的**子空间（subspace）**：

1. **$\vec0\in W$**（过原点）；
2. **加封闭**：$\vec u,\vec v\in W\Rightarrow\vec u+\vec v\in W$；
3. **数乘封闭**：$\vec v\in W,c\in\mathbb R\Rightarrow c\vec v\in W$。

**为什么三条就够**：八条公理里除"有零向量"和"有负向量"外，其余六条是"运算规则"，在子集里照样成立（规则不挑对象）；而"有负向量"由第 3 条推出（$-\vec v=(-1)\vec v$）——所以真正要额外向"子集"索要的，就是**零向量在不在、加法和数乘出不出得去**。三条件是最小检查单。

**为什么必须过原点（第 3 问，把"差一点"算出来）**：看不过原点的直线 $M=\{(1,0)+(t,2t)\}$。它能加能缩放吗？

- **① 零向量不在**：$(0,0)=(1,0)+(t,2t)$ 需要 $t=-1$ 且 $t=0$，矛盾——$M$ 里根本没有 $\vec0$。
- **② 加法不封闭**：取 $u=(2,2)$、$v=(0,-2)$，都在 $M$（$t=1$ 和 $t=-1$）；但 $u+v=(2,0)$，它不在 $M$ 上（$t=0.5$ 才得到 $(1.5,1)$）。$M$ 自己都能看出"两解之和跳出 M"（EXP2 实测同款）。

两条全破——**尽管 $M$ 每个元素长得像向量，它不构成子空间**。直觉：子空间必须"含 $\vec0$、加出 $\vec0$ 的管理半径内"，非齐次解集那种"平移掉原点的集合"（第 04 讲叫**仿射集**）都过不了这条。

**判例三则（把清单用熟）**：

1. 过原点直线 $L=\{(t,2t)\}$：$\vec0=(0,0)\in L$ ✓；$(t_1,2t_1)+(t_2,2t_2)=(t_1+t_2,\,2(t_1+t_2))\in L$ ✓；$c(t,2t)=(ct,2(ct))\in L$ ✓ → **是子空间**（EXP1 随机点全过）。
2. 第一象限 $Q=\{(x,y):x,y\ge0\}$：① $\vec0\in Q$ ✓；② $(1,0)+(0,1)=(1,1)\in Q$ ✓——**但不代表过关**：③ 取 $c=-1,\ \vec v=(1,0)$，$(-1)(1,0)=(-1,0)\notin Q$ ✗ → **不是子空间**。教训：**三条件全查才算数，①②过了③照样能挂**。
3. 零空间 $\{\vec0\}$：三条件平凡成立 → 是最小的子空间。

## 四、三种标准来源：span、$N(A)$、$\mathrm{col}(A)$（把第 01、04 讲的东西正式领进门）

**来源一：span = 最小子空间**。第 01 讲说"所有线性组合的集合"叫 span；现在补上身份——**span 自动是子空间**（含 $\vec0$：系数全 0；加封闭：两个组合相加是系数相加的新组合；数乘封闭：缩放系数）。而且它是**包含这些向量的最小子空间**（任何含它们的子空间必含它们的全部线性组合）。所以"张成子空间 / span"是同一个东西的两个名字——**回答第 4 问的"张成空间是不是子空间"：是，它俩是同一个对象的两个叫法**。

**来源二：零空间 $N(A)$（核 kernel）**。第 04 讲说"$A\vec x=\vec0$ 的解集"；现在补证它是子空间，三条件一行搞定（借 $A$ 的线性）：

$$A\vec0=\vec0\ \checkmark;\qquad A(\vec x_1+\vec x_2)=A\vec x_1+A\vec x_2=\vec0+\vec0=\vec0\ \checkmark;\qquad A(c\vec x)=cA\vec x=c\vec0=\vec0\ \checkmark$$

（EXP3 实测：$A\vec x_1=A\vec x_2=\vec0 \Rightarrow A(\vec x_1+\vec x_2)=\vec0$、$A(7\vec x_1)=\vec0$，与手算一致。）

**来源三：列空间 $\mathrm{col}(A)$（值域 range）**。$A$ 的全部列向量的 span。由来源一自动是子空间；它是"$A\vec x$ 能得到的全部结果"（第 02 讲的列组合视角：$A\vec x$ 就是列的线性组合），所以**"$\vec b\in\mathrm{col}(A)$" ⇔ "$A\vec x=\vec b$ 有解"**——第 03 讲秩判据的另一面。

**非齐次解集不是子空间（第 4 问后半，系统化）**：$A\vec x=\vec b$（$\vec b\neq\vec0$）的解集是"$\mathrm{col}(A)$ 之外平移的一份"，即第 04 讲的通解结构 $\vec p+N(A)$：它**不过原点**（$A\vec0=\vec0\neq\vec b$），加法也不封闭（两个特解之和一般不是解）。它是仿射集，不是子空间——**差的就是那一次平移**。这就是为什么第三、四讲总把齐次和非齐次分开谈。

## 五、子空间的交与并：一个可以，一个不行（想当然就地破）

**定理（交）**：两个子空间 $W_1,W_2$ 的**交集 $W_1\cap W_2$ 仍是子空间**。三条件：$\vec0$ 在两个里，故在交里 ✓；加封闭：$u,v\in W_1\cap W_2$ 则 $u+v$ 同时在两个里（各自封闭），故在交里 ✓；数乘同理 ✓。（EXP6 数字：$x$ 轴与 $y=2x$ 直线之交 = 原点 $\{\vec0\}$，是最小的子空间 ✓。）

**反例（并）**：两个子空间的**并集一般不是子空间**——这正是最容易被"想当然"糊过去的一条。拿两条坐标轴（各自都是子空间）：

$$W_1=\{\text{x 轴}\},\quad W_2=\{\text{y 轴}\},\quad u=(3,0)\in W_1,\quad v=(0,4)\in W_2$$

$u,v$ 都在并集里，但 $u+v=(3,4)$ 既不在 $x$ 轴也不在 $y$ 轴上（两个分量都非零）——**加封闭被打破**（EXP4 实测同款）。所以**"并不是子空间"**。

**为什么我们只玩"交"和"span"而不玩"并"**（直觉）：子空间要能"任取两个元素相加还在"，而并集只保证"元素在某一个里"，无法保证"和"还落回这两个中的一个；span 和交都能把"需要闭合成"的东西**重新生成**进去，并集不能。**这是线性代数里少数几个"结构天然爱交不爱并"的例子**，第 13 讲的正交补、第 09 讲四子空间对账都会再见到这个脾气。

## 六、numpy 实测

脚本 `scripts/lec07-01_verify_subspaces.py` 实测（节选）：

```
=== EXP1 过原点直线 L={(t,2t)} 三条件 ===
  ① 0 in L? True
     u=[-0.89 -1.78] v=[1.13 2.27]: u+v in L? True; 5u in L? True   （随机 3 组全过）
  -> 封闭性成立，L 是子空间

=== EXP2 不过原点直线 M={p+(t,2t)} ===
  ① 0 in M? False
  ② u=[2. 2.], v=[ 0. -2.] 都在 M；u+v=[2. 0.]，仍在 M? False
  -> 不封闭，M 不是子空间（仿射集）

=== EXP3 N(A) 与 col(A) ===
  A@(x1+x2)=[0. 0. 0.]；A@(7x1)=[0. 0. 0.]            ← 加、数乘都在 N(A) 里
  col(A): 3c1-2c2=[-3. -6. -3.]                        ← 列的线性组合，由定义恒在

=== EXP4 两坐标轴之并的反例 ===
  (3,0)+(0,4)=(3,4)——不在任何一条轴上 -> 并集不封闭，不是子空间

=== EXP5 多项式空间 P3 ===
  f+g=[1. 1. 1. 4.]；7f=[7. -14. 0. 28.]               ← 系数数组，加/数乘后仍是 4 维
```

## 七、落点：抽象空间不是浪费（第 08 讲要干什么）

你可能会问第 6 问："考试又不考函数空间，学这些干嘛？" 三句话回答：

1. **省事**：微分方程里"$f''=-f$ 的所有解"恰好是向量空间（$f_1,f_2$ 都是解 ⇒ $c_1f_1+c_2f_2$ 还是解——这就是"线性齐次方程的解集是向量空间"；作业 C3 让你亲手打勾）。懂向量空间，就懂"为什么线性方程的解能线性叠加"。
2. **换底**：第 08 讲要给任意向量空间定义**基与维数**——没有本讲的准入资格表，连"$P_3$ 的维数是几"都没法问。第 09 讲则靠本讲的 $N(A)$、$\mathrm{col}(A)$ 数出四个基本子空间的维数。
3. **平移**：第 08、13 讲的所有定理（无关、基、正交）都"不知道"你是 $\mathbb{R}^n$ 还是函数空间——写一遍，处处用。

> 收尾：你现在有了"资格表"（八条=打勾清单）和"日常检查单"（子空间三条件），并正式领进了三个最重要的子空间实例：span、$N(A)$、$\mathrm{col}(A)$。下一讲第 08 讲回答那个悬了很久的问题：**一个子空间最少要几个向量才能张成它**——线性无关、基与维数。

## 本讲小结

- **向量空间**：能加、能缩放、结果还在里面的集合；八条公理是**打勾清单**（不背，遇到新集合逐条查；真正会挂的是封闭性）。
- **例子公园**：$\mathbb{R}^n$、$\{\vec0\}$、过原点直线/平面、多项式 $P_n$、矩阵 $M_{m\times n}$、连续/可微函数全体都是向量空间；不过原点的直线、第一象限不是。
- **子空间三条件**：① 含 $\vec0$；② 加封闭；③ 数乘封闭。三条全查才算数（第一象限①②过了③挂）。必须过原点：仿射集（非齐次解集）全被拦下。
- **三个标准来源**：span=最小子空间；$N(A)$=齐次解集（三条件用 $A$ 的线性一行证毕）；$\mathrm{col}(A)$="$A\vec x$ 的全部结果"，$\vec b\in\mathrm{col}(A)\iff A\vec x=\vec b$ 有解。
- **交与并**：交是子空间（三条件继承）；**并不是**（$(3,0)+(0,4)=(3,4)$ 反例）——结构爱交不爱并。
- **落点**：抽象空间让"线性方程的解能叠加"和"基、维数、正交"到处通用；第 08 讲正式数维数。

**A1.** 依次判断下列集合是否为 $\mathbb{R}^2$ 的子空间，逐条打勾（①含0 ②加封 ③数封）：(a) $\{(x,y):y=0\}$（x 轴）；(b) $\{(x,y):x+y=1\}$；(c) $\{(x,y):x,y\ge0\}$（第一象限）；(d) $\{(0,0)\}$。

**参考答案**：

(a) ① $(0,0)$ 满足 $y=0$ ✓；② $(x_1,0)+(x_2,0)=(x_1+x_2,0)$ ✓；③ $c(x,0)=(cx,0)$ ✓ → **是**。
(b) ① $(0,0)$ 不满足 $x+y=1$ ✗ → **不是**（仿射集）。
(c) ① ✓；② ✓（正加正仍非负）；③ 取 $c=-1,\ (1,0)$：$(-1,0)$ 不满足非负 ✗ → **不是**（三条件齐全才算数）。
(d) ①②③ 平凡成立 → **是**（最小子空间 $\{\vec0\}$）。


**A2.** 对下面三个"自报家门是子空间"的集合，各写一行理由证明：$W_1=\mathrm{span}\{(1,1),(1,-1)\}$；$W_2=N\begin{pmatrix}1&2\\2&4\end{pmatrix}$；$W_3=\mathrm{col}\begin{pmatrix}1&0\\0&1\end{pmatrix}$。

**参考答案**：

$W_1$：span 自动是子空间（线性组合的线性组合还是线性组合，系数全 0 得 $\vec0$）。
$W_2$：$A\vec x=A\vec y=\vec0\Rightarrow A(\vec x+\vec y)=\vec0$、$A(c\vec x)=c\vec0=\vec0$，且 $A\vec0=\vec0$——三条件由 $A$ 线性一行证完。数值：$A$ 秩 1，$N(A)=\{(-2t,t)\}$，是过原点的直线 ✓。
$W_3$：$\mathrm{col}(I_2)=\mathbb R^2$（$I$ 的两列就是 $\vec e_1,\vec e_2$），$\mathbb R^2$ 是子空间（平凡）。


**A3.** 判断对错并给一句话理由：(a) 两个子空间的并一定是子空间；(b) 若 $\vec b\neq\vec0$，则 $A\vec x=\vec b$ 的解集可能是 $\mathbb R^n$ 的子空间；(c) 多项式集合 $\{P(t):P(1)=0\}$ 是向量空间 $P_n$ 的子空间；(d) $\{\vec0\}$ 是任何向量空间的子空间。

**参考答案**：

(a) **错**：第五节反例 $(3,0)+(0,4)=(3,4)$ 跳出两轴之并。
(b) **错**：解集不过原点（$A\vec0=\vec0\neq\vec b$），子空间必须含 $\vec0$。
(c) **对**：满足 $P(1)=0$ 的 $P_1,P_2$，其和与数乘在 $t=1$ 处仍为 0（$(cP)(1)=cP(1)=0$）；且零多项式 $P\equiv0$ 在集合里——三条件成立（第四章"由约束确定的子空间"族，跨越 $P(1)=0$ 之类的线性条件正是子空间的常见样式）。
(d) **对**：三条件对单点集 $\{0\}$ 平凡成立。


**B. 提高**

**B1.**（完整证明）设 $W_1,W_2$ 是 $V$ 的子空间，证明 $W_1+W_2=\{\vec w_1+\vec w_2:\vec w_1\in W_1,\vec w_2\in W_2\}$（子空间**和**）是子空间。逐条写三条件。

**参考答案**：

① $\vec0=\vec0+\vec0$，$\vec0$ 同时在两空间，故 $\vec0\in W_1+W_2$ ✓。
② 设 $u=u_1+u_2$、$v=v_1+v_2$（$u_i,v_i\in W_i$），则 $u+v=(u_1+v_1)+(u_2+v_2)$，括号内各自在 $W_i$（其封闭性），故 $u+v\in W_1+W_2$ ✓。
③ $c u=(cu_1)+(cu_2)\in W_1+W_2$ ✓。
结论：**和**也是子空间（对比第五节"并"不是——和把元素"重新组合"回去，并不行）。


**B2.** 设 $S=\{(x,y,z):x+2y=0\}$。(a) 证明 $S$ 是 $\mathbb R^3$ 的子空间；(b) 把 $S$ 写成 $\mathrm{span}$ 的形式；(c) 平移版 $\{(x,y,z):x+2y=1\}$ 为什么不是？

**参考答案**：

(a) ① $(0,0,0)$ 满足 $0+0=0$ ✓；② 若 $x_i+2y_i=0$（$i=1,2$），则 $(x_1+x_2)+2(y_1+y_2)=(x_1+2y_1)+(x_2+2y_2)=0$ ✓；③ $cx+2(cy)=c(x+2y)=0$ ✓ → 是子空间（过原点平面）。
(b) 用 $z$ 参数：$x=-2y$，$S=\mathrm{span}\{(-2,1,0),(0,0,1)\}$——两个方向的平面。
(c) $(0,0,0)$ 不满足 $0+0=1$，①直接破；且两个满足者的和 $(x_1+x_2)+2(y_1+y_2)=2\neq1$，②也破。


**B3.** $A=\begin{pmatrix}1&2\\2&4\\3&6\end{pmatrix}$。(a) $\mathrm{col}(A)$ 是维几的"什么"？(b) 判断 $\vec b=(5,10,15)$ 与 $\vec b'=(1,0,0)$ 哪个在 $\mathrm{col}(A)$ 里，用列组合写出来。

**参考答案**：

$A$ 两列成比例：$c_2=2c_1$，$\mathrm{col}(A)=\mathrm{span}\{(1,2,3)\}$，是一条过原点的直线（一维子空间）。
(a) 一维直线。
(b) $\vec b=(5,10,15)=5(1,2,3)=5c_1$ → 在 $\mathrm{col}(A)$ ✓（$A(5,0)^{\top}=(5,10,15)$ 也行）。$\vec b'=(1,0,0)$：需要 $(x_1+2x_2,2x_1+4x_2,3x_1+6x_2)=(1,0,0)$，即 $x_1+2x_2=1$ 且 $2(x_1+2x_2)=0$，矛盾 → 不在。


**B4.** 在 $P_3$（次数≤3 的多项式）中，判断 $\{p(t):p(0)=p(1)\}$ 是否子空间，逐条打勾。

**参考答案**：

① 零多项式 $p\equiv0$：$p(0)=p(1)=0$ ✓。
② $p,q$ 各满足 $p(0)=p(1),q(0)=q(1)$：$(p+q)(0)=p(0)+q(0)=p(1)+q(1)=(p+q)(1)$ ✓。
③ $(cp)(0)=cp(0)=cp(1)=(cp)(1)$ ✓。
→ 是子空间（"两端相等的函数"类，线性条件只约束取值不约束次数）。同族：$P(1)=0$（A3(c)）。


**C. 综合**

**C1.** ★ 用 numpy 复现两个想当然：构造 $u=(1,0),v=(0,1)$（两轴代表），打印 $u,v,u+v$，确认 $u+v$ 不在任何一轴；再取三条过原点直线的样本点各 9 个，打印"两两相加仍在直线上"的 `allclose` 结果是否为全 True（直线 1：$y=2x$）。

**参考答案**：

代码：
```python
import numpy as np
u=np.array([1.,0.]); v=np.array([0.,1.])
w=u+v
print("u+v=",w,"在x轴?",w[1]==0,"在y轴?",w[0]==0)   # (1,1) 两轴都不在
ts=np.linspace(-1,1,9)
pts=np.column_stack([ts,2*ts])
for i in range(3):
    for j in range(3):
        s=pts[i]+pts[j]
        assert abs(s[1]-2*s[0])<1e-12               # y=2x 恒成立
print("任意两样本点之和仍在直线1上：全部断言通过")
```
结论：样本验证与理论一致——并集不封闭、单条过原点直线封闭。


**C2.**（证明）若 $W$ 是 $V$ 的子空间，证明 $W$ 的**全体加法的"组合闭包"本身**就是 $W$：即对任意有限多个 $\vec w_1,\dots,\vec w_k\in W$ 与任意标量 $c_1,\dots,c_k$，有 $c_1\vec w_1+\cdots+c_k\vec w_k\in W$。这为什么等价于说"子空间=对线性组合封闭"？

**参考答案**：

归纳：k=1 由数乘封闭；设对 $k$ 项成立，则 $c_1w_1+\cdots+c_{k+1}w_{k+1}=(c_1w_1+\cdots+c_kw_k)+c_{k+1}w_{k+1}$，括号内 $\in W$（归纳假设）、$c_{k+1}w_{k+1}\in W$（数乘），和 $\in W$（加封闭）。证毕。
等价性：把三条件中的"加封闭、数乘封闭"合起来正是"对任意有限线性组合封闭"；而含 $\vec0$ 保证非空且有零元。所以一句话版子空间定义成立：**子空间=非空且对线性组合封闭的子集**——这也是第四节 span 是"最小子空间"的原因（span 就是"线性组合闭包"）。


**C3.**（应用视角）证明"$f''=-f$ 的所有可微函数"构成一个向量空间（函数空间）。提示：只需检查线性组合仍是解（$f_1,f_2$ 满足方程时 $c_1f_1+c_2f_2$ 呢？）；零函数在不在？（微积分可用：$(c_1f_1+c_2f_2)''=c_1f_1''+c_2f_2''$。）

**参考答案**：

设 $f_1,f_2$ 满足 $f_i''=-f_i$。对 $g=c_1f_1+c_2f_2$：$g''=c_1f_1''+c_2f_2''=c_1(-f_1)+c_2(-f_2)=-(c_1f_1+c_2f_2)=-g$ ✓。零函数 $f\equiv0$ 满足 $0''=0=-0$ ✓，含零元。故解集是（函数意义下的）向量空间——这就是"线性方程的解能叠加"的出处，也是第 12 讲特征值在微分方程应用的种子：$f=\sin t,\cos t$ 都是解，通解是它们的线性组合。
