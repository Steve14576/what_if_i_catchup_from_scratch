## 二、布局约定：梯度摆成什么形状

### 2.1 新问题的形状清单

微积分一路学过来，求导的对象其实一直是这几种：

| 函数 | 导数结果 | 状态 |
|---|---|---|
| $f:\mathbb R\to\mathbb R$ | $f'$（标量） | 微积分 I，闭眼算 |
| $f:\mathbb R^n\to\mathbb R$ | $\nabla f$（$n$ 维向量） | 微积分 II/III 的梯度 |
| $f:\mathbb R^n\to\mathbb R^m$ | $\dfrac{\partial\vec y}{\partial\vec x}$（$m\times n$ 矩阵，Jacobian） | 见过名字，没怎么手算过 |
| $f:\mathbb R^{m\times n}\to\mathbb R$ | $\dfrac{\partial f}{\partial X}$（？） | **本讲的新东西** |

最后一行就是"标量对矩阵求导"——ML 里天天发生：损失是标量，参数是矩阵 $W$，想更新 $W$ 就要知道"损失对 $W$ 的每个元素有多敏感"。第一反应"矩阵还能进导数？"（PLAN 里登记的卡点）——先拆掉这个心理障碍：**把矩阵 $X$ 按某种顺序"拉直"成一个长向量，一切立刻回归多元微积分**。布局约定要解决的唯一问题就是：拉直算完之后，结果**怎么摆回矩阵**。

### 2.2 布局约定：梯度与自变量同形

本课程统一一条规矩，一句话：

> **梯度的形状 $=$ 自变量的形状。**（谁变，就对谁逐项摆。）

具体到三种情形：

- 自变量 $\vec x$（$n$ 维向量）$\Rightarrow$ $\nabla f$ 是 $n$ 维向量，$\nabla f_i=\dfrac{\partial f}{\partial x_i}$；
- 自变量 $X$（$m\times n$ 矩阵）$\Rightarrow$ $\nabla f$ 是 $m\times n$ 矩阵，$(\nabla f)_{ij}=\dfrac{\partial f}{\partial X_{ij}}$（$i$ 行 $j$ 列对上就直接放 $i$ 行 $j$ 列）；
- 自变量 $\vec x$、但对 $\vec x$ 的**每个分量**都算一个导数（Jacobian）$\Rightarrow$ $\dfrac{\partial\vec y}{\partial\vec x}$ 是 $m\times n$：第 $i$ 行是 $y_i$ 的梯度（第五节用）。

为什么是这一条（三个理由，一条比一条硬）：

1. **数学上它是唯一自洽的摆法**。全微分是 $df=\sum_i\dfrac{\partial f}{\partial x_i}dx_i=\langle\nabla f,d\vec x\rangle$——左边是标量、右边是内积；只有 $\nabla f$ 与 $d\vec x$ **同形**，才能逐项配对求和（第 13 讲内积的定义）；
2. **物理上梯度必须活在自变量空间里**。梯度指向最陡上升方向，你要"从 $\vec x$ 出发沿负梯度走一步"（第八节的梯度下降）——没法从一个向量出发沿一个"行向量"走；
3. **编程上它是库的默认**。PyTorch/JAX 的 `grad` 与参数同形；本讲的数值梯度 `np.zeros_like(x)` 也是同形（2.5）。

**约定不是真理，是纪律。** 文献里另有"分子布局、分母布局"等流派（结果摆成行向量还是列向量各选各的），讨论"哪种对"没有意义；有意义的是**一段推导内不许换规矩**。转置错位的 bug 九成来自约定混用——本节之后，全文所有梯度默认"同形"。形状自检从此成为习惯动作：**每次求完导，看一眼形状对不对**（$A^T(A\vec x-\vec b)$ 与 $\vec x$ 同维吗？$2(W\vec x-\vec y)\vec x^T$ 与 $W$ 同形吗？）。

### 2.3 两台推导发动机

推矩阵梯度，需要两台"发动机"。

**发动机一：逐分量法。** 对 $f(\vec x)$：算 $\dfrac{\partial f}{\partial x_i}$（把 $\vec x$ 的其它分量当常数），然后摆回同形。对矩阵变量：算 $\dfrac{\partial f}{\partial X_{ij}}$，摆回 $m\times n$。这台发动机"看得见机制"——每一步都是标量偏导，适合第一次见、教学演示、元素级函数（迹、逐元素运算）。

**发动机二：全微分法（识别法）。** 原理一句话：既然 $\nabla f$ 的定义就是"让 $df=\langle\nabla f,d\vec x\rangle$ 成立的那个东西"，那就**把 $df$ 算出来、凑成内积的形式，凑出来的"另一个因子"就是 $\nabla f$**。操作手册三步：

1. **微分**：对 $f$ 做全微分，利用 $d$ 的线性性、乘法法则、复合（$d$ 作用时只有变量在动，常数一律穿行）；
2. **凑内积**：把结果整理成 $\langle G,dX\rangle$ 的形状；
3. **识别**：$G$ 就是 $\nabla f$；最后做形状自检。

矩阵版的"内积"是 Frobenius 内积：$\langle G,dX\rangle=\operatorname{tr}(G^TdX)$——把两个矩阵拉直成向量后的点积，第 13 讲内积公理在矩阵空间的原样化身。三条常用的微分速查（此后随时用）：

$$d(AXB)=A\,(dX)\,B,\qquad d(X^T)=(dX)^T,\qquad d(\operatorname{tr}X)=\operatorname{tr}(dX).$$

为什么两台都要留：**逐分量法**给机制（第一次见 $x^TAx$ 的导数时不看分量会心虚），**全微分法**给速度与稳定性（复合结构越长越省事）。实战工作流：微分法主推、分量法抽查一两项、最后数值对账（2.5）——三路互证，这就是 20 讲"双路线对账"精神在微积分上的第一次落地。

### 2.4 热身三连

三块积木，后面每个大公式都是它们的组合。

**(i) $\nabla(a^T\vec x)=a$。** 逐分量：$f=\sum_i a_ix_i$，$\dfrac{\partial f}{\partial x_i}=a_i$，摆回向量就是 $a$。微分法：$df=a^Td\vec x$，直接读到 $G=a$。两版都一行。形状自检：$a$ 与 $\vec x$ 同维 ✓。

**(ii) $\nabla(\vec x^T\vec x)=2\vec x$。** 微分法：$d(\vec x^T\vec x)=(d\vec x)^T\vec x+\vec x^Td\vec x=2\vec x^Td\vec x$，所以 $\nabla=2\vec x$。这就是微积分 II 里熟悉的老朋友（$f=\lVert\vec x\rVert^2$ 的梯度）——平移过来毫无违和。

**(iii) $\nabla(\vec x^TA\vec x)=(A+A^T)\vec x$；$A$ 对称时简化为 $2A\vec x$。** 微分法：

$$d(\vec x^TA\vec x)=(d\vec x)^TA\vec x+\vec x^TA\,d\vec x=\vec x^TA^Td\vec x+\vec x^TA\,d\vec x=\vec x^T(A^T+A)\,d\vec x\ \Longrightarrow\ \nabla=(A^T+A)\vec x.$$

（第二步用了 $d\vec x^T$ 与"标量的转置等于自己"把两项都归到 $d\vec x$ 一侧。）EXP2 对账：非对称 $A$ 与 $(A+A^T)\vec x$ 偏差 $7.14\times10^{-10}$；对称 $A$ 与 $2A\vec x$ 偏差 $1.87\times10^{-9}$。

**一个值得停一秒的洞察**：把 $A$ 拆成对称部分与反对称部分 $A=\underbrace{\tfrac{A+A^T}2}_{A_s}+\underbrace{\tfrac{A-A^T}2}_{A_k}$，则 $\vec x^TA_k\vec x\equiv0$（$1\times1$ 的标量等于自己的转置，而 $\vec x^TA_k\vec x=(\vec x^TA_k\vec x)^T=\vec x^TA_k^T\vec x=-\vec x^TA_k\vec x$）。所以二次型**只感受 $A$ 的对称部分**：$\vec x^TA\vec x=\vec x^TA_s\vec x$，导数 $\nabla=2A_s\vec x=(A+A^T)\vec x$——第 16 讲"二次型与对称矩阵一一配对"（"二次型 $=$ 对称矩阵的标量外衣"）在这里获得了微分身份的证明：反对称部分对函数值、对梯度都是透明的。

| 积木 | 结果 | 形状自检 |
|---|---|---|
| $a^T\vec x$ | $a$ | 与 $\vec x$ 同维 |
| $\vec x^T\vec x$ | $2\vec x$ | 同维 |
| $\vec x^TA\vec x$ | $(A+A^T)\vec x$（对称 $2A\vec x$） | 同维 |

### 2.5 数值验尸台：中心差分

推出来的公式对不对？除了"再推一遍"（同一条思路可能同一个错误犯两次），还有一条**独立**路线：数值差分。对每个分量做中心差分：

$$\left(\nabla f\right)_i\approx\frac{f(\vec x+h\vec e_i)-f(\vec x-h\vec e_i)}{2h},$$

$\vec e_i$ 是第 $i$ 个坐标方向。一台十行的验尸台（脚本里的 `numgrad`）：把 $\vec x$ 逐分量各扰动 $\pm h$，差分出"数值梯度"，与解析公式**逐分量对抗**。

误差预算（为什么中心差分好、$h$ 取多少）：差分是"两点割线逼近斜率"，泰勒展开让**截断误差** $\sim h^2$（中心差分把一阶项对消掉了，比前向差分的 $\sim h$ 高一阶）；同时 $f$ 的求值自带浮点舍入 $\sim\mathrm{eps}$，被除以 $2h$ 放大成**舍入误差** $\sim\mathrm{eps}/h$。两本账一升一降，最优 $h\sim\mathrm{eps}^{1/3}\approx6\times10^{-6}$（当场选取，量级理由如上）——本讲脚本取 $h=10^{-6}$，实测精度见下。EXP1 对两把"标准尺"自检：$\nabla(a^T\vec x)$ 偏差 $1.43\times10^{-10}$、$\nabla(\vec x^T\vec x)$ 偏差 $2.63\times10^{-10}$——**验尸台本身的精度在 $10^{-10}$ 级**。

使用规范（本讲全讲执行）：

1. 报两个数：**最大绝对偏差**与**相对偏差**（不报一个含糊的"差不多"）；
2. 量级红线：偏差超过 $10^{-8}$ 量级就"非可忽略"，必有一方错了——数值差分与解析公式是两条独立路线，**对上了才可信**；
3. 它只报告"死因"，不负责"抢救"：差分说"不对"，定位靠形状自检与五秒钟小例（代入 $1\times1$ 的 $A$ 手验）。

这台台子和 20 讲的"验收三步（估/查/验）"是同一件事的微积分版本：**解析推一条路，数值走一条路，对账**。此后每个大公式——$\nabla\lVert A\vec x-\vec b\rVert^2$（第三节）、Hessian $=2A^TA$（第四节）、反向传播 26 参数（第五节）——都过这台台子，读数随文给出。

## 三、最小二乘的梯度：第三副面孔出全

### 3.1 主推导：$\nabla\lVert A\vec x-\vec b\rVert^2=2A^T(A\vec x-\vec b)$

PLAN 里登记的核心卡点，也是 20 讲钩子点名"怎么推"的公式。两个版本都推一遍。

**版本一（展开 $+$ 热身三连）**。先展开平方：

$$f(\vec x)=\lVert A\vec x-\vec b\rVert^2=(A\vec x-\vec b)^T(A\vec x-\vec b)=\vec x^TA^TA\vec x-2\vec b^TA\vec x+\vec b^T\vec b.$$

（中间一步：$(A\vec x)^T(A\vec x)-2(A\vec x)^T\vec b+\vec b^T\vec b$，再把 $A^T$ 翻到 $A\vec x$ 的左边。）三项分别求梯度：第一项是二次型 $\vec x^T(A^TA)\vec x$，$A^TA$ 对称，用 2.4(iii) 得 $2A^TA\vec x$；第二项是线性的 $-2\vec b^TA\vec x=(-2A^T\vec b)^T\vec x$，用 2.4(i) 得 $-2A^T\vec b$；第三项常数，梯度为零。合起来：

$$\nabla f=2A^TA\vec x-2A^T\vec b=2A^T(A\vec x-\vec b).$$

**版本二（全微分，三行）**。微分法最舒服的一点：只有变量在动，$A、\vec b$ 是常数直接穿行。

$$df=d\left[(A\vec x-\vec b)^T(A\vec x-\vec b)\right]=2(A\vec x-\vec b)^T\,d(A\vec x-\vec b)=2(A\vec x-\vec b)^TA\,d\vec x=\left[2A^T(A\vec x-\vec b)\right]^Td\vec x.$$

（第一步：$(d u^T)u+u^Tdu=2u^Tdu$，$u=A\vec x-\vec b$；第二步：$d(A\vec x-\vec b)=Ad\vec x$；第三步把 $2(A\vec x-\vec b)^TA$ 整体转置成"向量 $^T\cdot d\vec x$"的形状。）读出 $\nabla f=2A^T(A\vec x-\vec b)$。∎

**讲评**：版本一全程只用 2.4 的三块积木——适合把"新公式还原为已知积木"；版本二机械三步、对复合结构更稳——适合当主力。两版对照本身也是一次"双路线对账"。EXP3 对账：随机 $5\times3$ 的 $A$ 上，解析与数值梯度最大偏差 $1.05\times10^{-9}$。形状自检：$A$ 是 $m\times n$，$A^T(A\vec x-\vec b)$ 是 $n$ 维，与 $\vec x$ 同形 ✓。

### 3.2 置零：正规方程，第三副面孔出全

令 $\nabla f=\vec0$：

$$2A^T(A\vec x-\vec b)=\vec0\quad\Longleftrightarrow\quad A^TA\vec x=A^T\vec b.$$

右边就是 15 讲的**正规方程**。至此，最小二乘解的三副面孔全部配齐（15 讲登记了两副，本讲补上第三副）：

| 面孔 | 语言 | 一句话 |
|---|---|---|
| 几何（13/15 讲） | 投影 | 残差垂直列空间：$A^T(\vec b-A\hat{\vec x})=\vec0$（垂线脚） |
| 代数（15 讲） | 方程 | 最优系数满足 $A^TA\hat{\vec x}=A^T\vec b$ |
| **微积分（本讲）** | 梯度 | 碗底 $=$ 梯度零点：$\nabla\lVert A\vec x-\vec b\rVert^2=\vec0$ |

三副面孔说的是同一件事——15 讲 L117 预告的"不用求导的 bonus：$-2A^T(\vec b-A\vec x)=\vec0$，同一方程的第三副面孔"，在本节正式展开完毕。EXP3 的两个闭环读数：梯度置零解与 `lstsq` 的解最大偏差 $7.77\times10^{-16}$（机器精度级一致）；置零解处的 $\lVert\nabla f\rVert=1.62\times10^{-15}$（数值上确认它就是驻点）。

顺带收一笔账：15 讲的公式 $\hat{\vec x}=(A^TA)^{-1}A^T\vec b$——它不是"被推出的拟合公式"，它是**梯度方程在 $A^TA$ 可逆时的显式解**。有了本节，"为什么偏偏是这个公式"不再需要单独记忆：它是碗底条件的一步移项。

### 3.3 15 讲主例重逢：碗底就是梯度零点

拉出 15 讲的主例（第六节，拟合 $y=1.1+1.1t$ 的四个点）：

$$A=\begin{pmatrix}1&0\\1&1\\1&2\\1&3\end{pmatrix},\qquad \vec b=(1,2,4,4)^T,\qquad A^TA=\begin{pmatrix}4&6\\6&14\end{pmatrix},\qquad A^T\vec b=(11,22)^T.$$

15 讲手算的结论是 $\hat{\vec x}=(1.1,1.1)$、SSE$=0.7$。现在用本讲的公式复核——只要一行：

$$A^TA\hat{\vec x}=\begin{pmatrix}4\times1.1+6\times1.1\\6\times1.1+14\times1.1\end{pmatrix}=\begin{pmatrix}11\\22\end{pmatrix}=A^T\vec b\ \Longrightarrow\ \nabla\mathrm{SSE}(\hat{\vec x})=\vec0.$$

**当年手算的"碗底"，正是梯度零点。** EXP4 的三个确认：$\mathrm{SSE}(1.1,1.1)=0.7000$（与 15 讲手算的 $0.7$ 吻合）；$\nabla\mathrm{SSE}(1.1,1.1)=[0.,0.]$（机器零）；**对抗测试**——从 $(1.1,1.1)$ 出发、沿 200 个随机方向各走 $0.001$，SSE **全部上升**（`True`）。"全部上升"是"局部极小"的数值证据（必要非充分——一阶必要条件由梯度公式保证），200 个方向一个不破，这就是对"碗底"最有说服力的现场演示。

### 3.4 标量对矩阵：$\nabla_W\lVert W\vec x-\vec y\rVert^2=2(W\vec x-\vec y)\vec x^T$

把变量从向量升级成矩阵——ML 的第一现场：一层线性网络用 $W$（$m\times n$）预测 $\vec y\approx W\vec x$，损失 $f=\lVert W\vec x-\vec y\rVert^2$ 是标量、变量是矩阵。"标量对矩阵"不再是别人的问题，是我们自己的问题。

**推导（全微分法）**。记残差 $\vec r=W\vec x-\vec y$（$m$ 维），微分：

$$df=2\vec r^T\,d(W\vec x)=2\vec r^T(dW)\vec x.$$

现在要凑 $\langle G,dW\rangle=\operatorname{tr}(G^TdW)$ 的形状。$2\vec r^T(dW)\vec x$ 是标量，而**标量可以塞进迹里**（$\operatorname{tr}(1\times1)=\text{它自己}$），于是：

$$df=\operatorname{tr}\left(2\vec r^T(dW)\vec x\right)\overset{\text{轮换}}{=}\operatorname{tr}\left(2\vec x\,\vec r^T(dW)\right)=\operatorname{tr}\left(\left[2\vec r\vec x^T\right]^TdW\right).$$

（轮换：$\operatorname{tr}(PQ)=\operatorname{tr}(QP)$，把 $dW$ 转到最右、把 $2\vec x\vec r^T$ 留在内积左侧；$\vec x\vec r^T$ 是 $n\times m$，转置后 $m\times n$ 正好对上 $dW$ 的方向。）识别：

$$\boxed{\ \nabla_W f=2\vec r\vec x^T=2(W\vec x-\vec y)\vec x^T.\ }$$

**形状自检**：$(W\vec x-\vec y)\vec x^T$ 是 $m\times n$ 的**外积**（第 02 讲的老朋友），与 $W$ 同形 ✓。EXP2 对账：数值梯度形状 $(3,2)$ 与 $W$ 同形，与解析 $2(W\vec x-\vec y)\vec x^T$ 偏差 $2.86\times10^{-10}$。

这个结果的"结构长相"值得记牢：**残差 $\otimes$ 输入**。它是后面第五节反向传播里"每层一个外积"的最小版本——单层网络是 $\vec r\vec x^T$，深网络就是一层一层的外积接力。下一节先把二阶情报（Hessian）补齐，第五节看外积流水线怎么跑起来。

## 四、Hessian 与碗：二阶情报

### 4.1 Hessian：二阶导数的矩阵版

一元微积分里 $f''$ 告诉你"斜率在怎么变"；多元里，梯度的变化率是一个矩阵。定义干脆：**Hessian $=$ 梯度的 Jacobian**——对 $f(\vec x)$，先把梯度 $\nabla f$（这本身是一个向量值函数）摆好，再按 2.2 的规定对它求一次 Jacobian：

$$H=\nabla^2f,\qquad H_{ij}=\frac{\partial^2 f}{\partial x_j\,\partial x_i}=\frac{\partial}{\partial x_j}\left(\frac{\partial f}{\partial x_i}\right).$$

（第 $i$ 行接第 $i$ 个梯度分量的"变化率"。行、列的先后各书各写，但马上要说的对称性让这场笔墨官司失去意义。）

两个事实先收下：

1. **Hessian 天然对称**：只要二阶偏导连续（本课一切函数都够光滑），混合偏导与先后次序无关（$\partial_i\partial_jf=\partial_j\partial_if$，微积分课一句带过），所以 $H=H^T$——Hessian 直接住进第 16 讲的领地（对称矩阵：谱定理、正定、二次型全套装备就位）；
2. **用途**：梯度说"往哪走"（方位），Hessian 说"脚下弯成什么样"（曲率）——判极值（本节）、量收敛速度（第八节）都靠它。

### 4.2 $\nabla^2\lVert A\vec x-\vec b\rVert^2=2A^TA$

拿主菜函数开刀。3.1 已得梯度：

$$\nabla f(\vec x)=2A^T(A\vec x-\vec b)=2A^TA\vec x-2A^T\vec b.$$

看结构：这是 $\vec x$ 的**线性**向量值函数（$M\vec x+\vec c$ 的样子，$M=2A^TA$、$\vec c=-2A^T\vec b$）。线性函数的 Jacobian 就是 $M$ 自己（逐分量：$\partial(M\vec x)_i/\partial x_j=M_{ij}$），所以

$$\boxed{\ \nabla^2\lVert A\vec x-\vec b\rVert^2=2A^TA.\ }$$

**注意一个事实**：这个 Hessian **不随 $\vec x$ 变**（$2A^TA$ 是常数矩阵）——因为原函数是二次的。二次函数的 Hessian 恒定，Hessian 恒定的函数就是二次函数；"碗"之所以是碗，正因为曲率处处一样（不会半路变尖变平）——第八节牛顿法"一步到位"的根源就在这一行。

为什么这个 Hessian 有当"碗"的资格：第 16 讲的账直接调用——$A^TA$ 恒半正定（$\vec x^T(A^TA)\vec x=\lVert A\vec x\rVert^2\ge0$），列满秩时 $\lVert A\vec x\rVert^2=0\Rightarrow\vec x=\vec0\Rightarrow$ 正定。于是 SSE 的 Hessian 处处正定（列满秩时）$\Longrightarrow$ 唯一碗底。15 讲"碗底唯一"的微积分版证明，两行。

EXP5 对账：随机 $5\times3$ 的 $A$ 上，数值 Hessian 与解析 $2A^TA$ 最大偏差 $5.30\times10^{-10}$；$2A^TA$ 的特征值 $[1.5819,\ 4.6396,\ 8.7722]$ 全正（碗形确认）。

### 4.3 AC$-$B$^2$ 判据 $=$ Sylvester 的 $2\times2$ 特例

微积分课背过的"二元函数极值判定"——课上一般把它写作 $A=f_{xx}$、$B=f_{xy}$、$C=f_{yy}$ 三个字母（这里换一套下标，免得和矩阵 $A$ 撞车）：

| 判据 | 结论 |
|---|---|
| $\det H=h_{11}h_{22}-h_{12}^2>0$ 且 $h_{11}>0$ | 极小 |
| $\det H>0$ 且 $h_{11}<0$ | 极大 |
| $\det H<0$ | 鞍点 |

现在一眼看出：这就是 **Sylvester 判据（16 讲）的 $n=2$ 特例**——"$\det H>0$ 且 $h_{11}>0$"就是顺序主子式 $D_1>0$、$D_2>0$，就是 $H$ 正定，就是极小。16 讲 L294 的承诺（"微积分课背的'AC$-$B$^2>0$ 且 A$>0$ 是极小'就是 $2\times2$ 的 Sylvester，21 讲把梯度与 Hessian 正式接上"）正式兑现。

为什么微积分课只教 $2\times2$：三维以上 Sylvester 要算一串从 $1\times1$ 到 $n\times n$ 的顺序主子式，手算太贵——课堂只练 $2\times2$；而"高维判据"的完整机器（主子式 / 谱判据）第 16 讲已经备齐。所以这里从来没有缝：**微积分课的判据是 Sylvester 判据的 $2\times2$ 截屏**。

EXP5 现场两例：$H=\begin{pmatrix}2&1\\1&3\end{pmatrix}$——$h_{11}=2>0$、$\det H=5>0$，极小；$H=\begin{pmatrix}1&2\\2&1\end{pmatrix}$——$\det H=-3<0$，鞍点。后者正是 16 讲第五节的不定例（微积分判据与 Sylvester 给出同一个"鞍"）。

**判据的边界**（一句）：$\det H=0$ 时二阶判据"不分胜负"（可能是槽、可能要更高阶情报），本课出场的 Hessian 全是正定碗，不踩这个区间。

### 4.4 地形图：碗、鞍、脊

把 16 讲的谱与本节的地形对上，得到这张小地图（$n$ 维照用，看谱）：

| Hessian 的谱 | 地形 | 优化含义 |
|---|---|---|
| 全正（正定） | 碗 | 唯一底，最舒适的目标 |
| 全负（负定） | 倒扣碗 | 唯一顶（最小化视角：翻成 $-f$ 就是碗） |
| 有正有负（不定） | 鞍 | 沿一个方向是谷、另一个方向是脊 |
| 有零有正（半正定） | 槽（谷底平坦） | 有"不动方向"（零空间方向），二阶判据失效 |

本讲后半程的三位主角——SSE 的碗（第三、四节）、似然的碗（第六节）、PCA 的"方差二次型"（第七节）——都落在这张图的"碗"格上。**优化的地形学就是 Hessian 的谱几何**；第八节的"下山"整场都发生在这张地图上。

## 五、链式法则与反向传播

### 5.1 从标量链式到矩阵链式

标量链式法则：$\dfrac{df}{dx}=\dfrac{df}{dg}\cdot\dfrac{dg}{dx}$——"外导数乘内导数"。矩阵版怎么接？答案是**全微分法的两行纸**：

设 $\vec y=g(\vec x)$（向量值函数，Jacobian $J=\dfrac{\partial\vec y}{\partial\vec x}$ 是 $m\times n$），$f(\vec y)$ 是标量。做微分：

$$df=\langle\nabla_{\vec y}f,\ d\vec y\rangle=\langle\nabla_{\vec y}f,\ J\,d\vec x\rangle=\langle J^T\nabla_{\vec y}f,\ d\vec x\rangle\ \Longrightarrow\ \boxed{\ \nabla_{\vec x}f=J^T\nabla_{\vec y}f.\ }$$

（第二步：$d\vec y=J\,d\vec x$——"好函数的局部变化是线性的"，微积分的事；第三步：把 $J$ 翻到内积左侧。）形状自检：$\nabla_{\vec y}f$ 是 $m$ 维、$J^T$ 是 $n\times m$，乘出来 $n$ 维，与 $\vec x$ 同形 ✓。

**这一行就是反向传播的全部**：内层梯度 $=$ 局部 Jacobian 转置 $\times$ 外层梯度。"传话"方向永远从最终的标量损失往回走——名字里的"反向"到此解释完毕。

### 5.2 两层网络的完整手推

上脚本的现场（EXP10）：一个两层 tanh 网络，输入 3 维、隐层 4 维、输出 2 维。参数：$W_1(4\times3)$、$\vec b_1(4)$、$W_2(2\times4)$、$\vec b_2(2)$——**一共 $12+4+8+2=26$ 个**。损失 $L=\tfrac12\lVert\vec z-\vec y\rVert^2$。

**前向**（四步装配）：

$$\text{pre}_1=W_1\vec x+\vec b_1,\qquad \vec h=\tanh(\text{pre}_1),\qquad \vec z=W_2\vec h+\vec b_2,\qquad L=\tfrac12\lVert\vec z-\vec y\rVert^2.$$

（tanh 逐元素作用；$\text{pre}_1$ 是"激活前的线性输出"，留它是为了反传时对号入座。）

**反向**（从 $L$ 出发，按 5.1 的链式一步步往里传）：

1. **输出误差**：$\dfrac{\partial L}{\partial\vec z}=\vec z-\vec y$（2 维）——$\tfrac12\lVert\vec z-\vec y\rVert^2$ 的梯度（2.4(ii) 的 $\tfrac12$ 版）；
2. **输出层参数**：$\dfrac{\partial L}{\partial W_2}=(\vec z-\vec y)\vec h^T$（$2\times4$ 外积）、$\dfrac{\partial L}{\partial\vec b_2}=\vec z-\vec y$。这正是 3.4 的单层公式（输入换成 $\vec h$、残差换成 $\vec z-\vec y$）：**"残差 $\otimes$ 输入"第二次出场**；
3. **传回隐层**：$\dfrac{\partial L}{\partial\vec h}=W_2^T(\vec z-\vec y)$（4 维）——5.1 的 $J^T$ 版（$\vec z=W_2\vec h+\vec b_2$ 对 $\vec h$ 的 Jacobian 就是 $W_2$）；
4. **过 tanh（逐元素）**：$\dfrac{\partial L}{\partial\text{pre}_1}=\dfrac{\partial L}{\partial\vec h}\circ(1-\vec h^2)$（4 维，$\circ$ 为逐元素积）。来源：$\text{pre}_{1,i}$ 只影响 $h_i$，局部斜率 $\tanh'=1-\tanh^2=1-h_i^2$——逐元素链式；
5. **输入层参数**：$\dfrac{\partial L}{\partial W_1}=\dfrac{\partial L}{\partial\text{pre}_1}\vec x^T$（$4\times3$ 外积）、$\dfrac{\partial L}{\partial\vec b_1}=\dfrac{\partial L}{\partial\text{pre}_1}$——**"残差 $\otimes$ 输入"第三次出场**。

**形状自检一路顺**：每个参数梯度都与该参数同形（$W_2$ 梯度 $2\times4$ ✓、$W_1$ 梯度 $4\times3$ ✓）——26 个参数谁都不错位。

### 5.3 反向传播：外积装配的流水线

把 5.2 提炼成模式（对本课语境，两层模板已经足够）：

- **参数梯度 $=$ 误差信号 $\otimes$ 本层输入**：$\dfrac{\partial L}{\partial W}=\delta_{\text{out}}\,\text{input}^T$、$\dfrac{\partial L}{\partial\vec b}=\delta_{\text{out}}$；
- **往内层传话**：$\delta_{\text{in}}=J_{\text{layer}}^T\delta_{\text{out}}$——线性层乘 $W^T$，逐元素激活逐元素乘局部斜率（如 $1-\vec h^2$）。

前向与反向是**同一张图的正反两遍**：每个算子在前向干一件事、在反向贡献一个"局部导数乘法"。这套装配与"把全体参数拉直、对损失整体求梯度"完全一致（本讲用 EXD10 的数值对账坐实，不搭计算图的理论架子）。EXP10 现场：26 个参数的解析反传 vs 中心差分数值梯度，最大偏差 $3.39\times10^{-11}$、相对偏差 $1.04\times10^{-10}$。

手推一遍之后，"框架黑箱"感应当消失：autograd 干的事只是"自动化"——每个算子在计算图上注册一个反向函数，反向时把本节这套"局部导数 $\times$ 上游梯度"流水线跑一遍。数学内核就是 5.1 的那一行 $J^T\nabla$。

一句工程话：**自己的反传不确定对错，先拉 `numgrad` 对账**——十行代码，$10^{-10}$ 级的安心。

## 六、噪声下的真相：最大似然与参数不确定度

### 6.1 高斯模型与 $-{\log L}$ 的梯度

把最小二乘放回它的出生地（15 讲第八节的预告）。统计模型：

$$\vec b=A\vec w+\vec\varepsilon,\qquad \vec\varepsilon\sim\mathcal N(\vec0,\ \sigma^2I),$$

即每个观测 $b_i$ 围绕"真值" $\vec a_i^T\vec w$ 做高斯抖动、彼此独立、同方差 $\sigma^2$。这组参数"生出"这批数据的**似然**（概率密度之积）：

$$L(\vec w,\sigma)=\prod_{i=1}^{n}\frac{1}{\sqrt{2\pi\sigma^2}}\exp\!\left(-\frac{(b_i-\vec a_i^T\vec w)^2}{2\sigma^2}\right).$$

取对数（乘积变求和）、再取负号（把"最大化"翻成"最小化"）：

$$-\log L(\vec w,\sigma)=\frac{\lVert A\vec w-\vec b\rVert^2}{2\sigma^2}+\frac n2\log(2\pi\sigma^2).$$

第二项与 $\vec w$ 无关（常数）；第一项就是 SSE 除以 $2\sigma^2$。对 $\vec w$ 求梯度——3.1 结果的直接应用：

$$\nabla_{\vec w}(-\log L)=\frac{2A^T(A\vec w-\vec b)}{2\sigma^2}=\frac{A^TA\vec w-A^T\vec b}{\sigma^2}.$$

### 6.2 最小二乘 $=$ 最大似然

把上式置零：

$$\frac{A^TA\vec w-A^T\vec b}{\sigma^2}=\vec0\quad\Longleftrightarrow\quad A^TA\vec w=A^T\vec b\quad\Longleftrightarrow\quad\text{正规方程}.$$

关键观察：$\sigma^2$ 是一个**正数因子**——不管噪声多大（$0.1$ 还是 $10$），置零条件一模一样。所以**最大似然解 $=$ 最小二乘解**，与噪声强度无关。EXP6 现场：$\sigma=0.1$ 时 $\lVert\nabla(-\log L)(\hat{\vec w})\rVert=7.94\times10^{-9}$、$\sigma=10$ 时 $=0.00\times10^{0}$——两个极端噪声下，OLS 解都站在驻点上。

15 讲两处承诺的兑现：L83"在高斯噪声模型下，平方和最小恰好就是最大似然（21 讲正式）"；L215"完整统计解释在第 21 讲正式展开"（后半段在 6.4 兑现）。**"平方"这个选择至此户口办全**：几何（与范数同序）、代数（二次好解）、统计（高斯下 $=$ MLE）三重身份齐备。

边界一句：等价的前提是"高斯噪声"假设。数据里若有离群值（重尾分布），平方项会把它们放大、把估计拽着走——工程上换 Huber/绝对值和等稳健损失，就不再是"最小二乘"。这里只点账，不展开。

### 6.3 $\sigma$ 也一起优化：自由度的账

前面把 $\sigma$ 当了已知数；其实它是参数之一。对 6.1 的 $-{\log L}$ 关于 $\sigma$ 求导置零（一元的，直接算），得 $\hat\sigma^2=\dfrac{\mathrm{SSE}}{n}$——除以 $n$ 的 MLE 解。

但这里藏着账：$\mathrm{SSE}$ 是**拟合后残差**的平方和，不是原始噪声——残差住在 $n-p$ 维空间里（$p$ 个参数"校准"掉了 $p$ 个自由度），所以 $\mathbb E[\mathrm{SSE}/n]=\dfrac{n-p}{n}\sigma^2$，**系统性偏小**；无偏版本要除以 $n-p$。

EXP6 用 500 轮重复把账对清（设定 $n=8$、$p=3$、$\sigma=0.5$，即 $\sigma^2=0.25$、$(n-p)/n=5/8$）：

- 平均 $\mathrm{SSE}/n=0.1531$（理论 $\tfrac58\times0.25=0.1562$——向下偏差确认）；
- 平均 $\mathrm{SSE}/(n-p)=0.2450$（理论 $0.2500$——无偏确认）。

单次抽样时这两个数都会飘（少样本时飘得不好引用，所以脚本取 500 轮平均）；"自由度从哪来"的完整推导属统计课，本讲把数字对齐。

### 6.4 参数不确定度与置信区间

最后一问：$\hat{\vec w}$ 有多准？核心公式（15 讲承诺的"协方差、置信区间"）：

$$\boxed{\ \mathrm{Cov}(\hat{\vec w})=\sigma^2(A^TA)^{-1}.\ }$$

两行推导，全部是已学的工具：$\hat{\vec w}=M\vec b$，$M=(A^TA)^{-1}A^T$ 是 $\vec b$ 的线性函数；$\vec b$ 的波动是 $\mathrm{Cov}(\vec b)=\sigma^2I$；线性变换的协方差传播是 $\mathrm{Cov}(M\vec b)=M\,\mathrm{Cov}(\vec b)\,M^T$（"$\vec b$ 的波动经 $M$ 传输"）。相乘，中间项 $(A^TA)^{-1}A^TA=I$ 相消：

$$\mathrm{Cov}(\hat{\vec w})=M(\sigma^2I)M^T=\sigma^2\,(A^TA)^{-1}A^T\,A\,(A^TA)^{-1}=\sigma^2(A^TA)^{-1}.$$

读出：第 $j$ 个系数的**标准误** $\mathrm{se}_j=\sigma\sqrt{[(A^TA)^{-1}]_{jj}}$；95% 置信区间 $\hat w_j\pm1.96\,\mathrm{se}_j$。语义好读：$A^TA$ 越大（信息越多）$\to$ 逆越小 $\to$ 参数越确定；$\sigma$ 越大（噪声越凶）$\to$ 区间越宽。量纲自查：$\sigma$ 是数据单位，$\mathrm{se}$ 与它同量纲 ✓。

EXP7 现场（蒙特卡洛 2 万次）：设计矩阵用 15 讲同款（$t=0,1,2,3$ 的 $[1,t]$）、真参数 $\vec w=(1.5,-0.4)$、$\sigma=0.3$——

- 样本协方差与理论 $\sigma^2(A^TA)^{-1}$ 的对角比值：$[1.006,\ 0.998]$（公式在 2 万次实验下精确复现）；
- 理论标准误 $\mathrm{se}=[0.2510,\ 0.1342]$；
- **联合覆盖率** $=0.921$：两个系数的 95% 区间同时吞住真值的经验频率，联立理论值 $0.95^2=0.902$——吻合。

"置信区间"背后的全部线性代数就在这：**$(A^TA)^{-1}$ 是参数不确定度的形状，$\sigma$ 是它的尺度**。方法论上再记一笔：公式预测 vs 蒙特卡洛实验——"双路线对账"的又一种形态。

## 七、PCA：协方差矩阵的谱分解

### 7.1 数据的"碗"：从中心化到协方差

场景：$n$ 个样本、$d$ 个特征的数据矩阵 $X$（$n\times d$，一行一个样本）。目标：找"变化最大"的方向——方差大的方向就是信息量大的方向（无监督视角）。

**第一步：中心化** $Z=X-\mathbf 1\vec\mu^T$（每个特征减去自己的均值）。必须做——否则"变化最大的方向"可能只是"数据云团相对原点的方位"，那是假信息；中心化后"方向"才表示"围绕中心的变化"。（EXP8 的现场就一行：`Z8 = X8 - X8.mean(axis=0)`。）

**第二步：协方差矩阵** $C=\dfrac{Z^TZ}{n-1}$（$d\times d$、对称、半正定——$\vec v^TC\vec v=\lVert Z\vec v\rVert^2/(n-1)\ge0$）。对角元 $=$ 各特征自身方差，非对角元 $=$ 成对协方差。16 讲 L296 的账在此启用："数据协方差矩阵对称半正定；它的特征向量 $=$ 主成分方向、特征值 $=$ 方差。"

### 7.2 主方向 $=$ 特征向量（拉格朗日推导）

找单位向量 $\vec v$（$\lVert\vec v\rVert=1$）使投影 $Z\vec v$ 的方差最大。方差就是 Rayleigh 商：

$$\mathrm{Var}(Z\vec v)=\frac{\lVert Z\vec v\rVert^2}{n-1}=\frac{\vec v^TZ^TZ\vec v}{n-1}=\vec v^TC\vec v.$$

约束优化，用本讲的求导工具（拉格朗日乘子）：

$$\mathcal L(\vec v,\lambda)=\vec v^TC\vec v-\lambda(\vec v^T\vec v-1),\qquad \nabla_{\vec v}\mathcal L=2C\vec v-2\lambda\vec v=\vec0\ \Longrightarrow\ \boxed{\ C\vec v=\lambda\vec v.\ }$$

（梯度的两步全是一分钟内推过的积木：$\nabla(\vec v^TC\vec v)=2C\vec v$——2.4(iii) 对称版；$\nabla(\lambda\vec v^T\vec v)=2\lambda\vec v$——2.4(ii) 的 $\lambda$ 倍。）结论：**主方向就是协方差矩阵的特征向量**，$\lambda$ 越大该方向方差越大；谱定理（16 讲）保证特征向量正交、可对角化——主方向互相垂直，一组干净的坐标系。

特征值从大到小排 $\lambda_1\ge\lambda_2\ge\cdots$，第 $i$ 个主方向的方差占比 $=\lambda_i/\sum_j\lambda_j$。16 讲 L146"正定 $=$ 合格尺子"在此兑现：$\vec v^TC\vec v$ 之所以能被当"方差"来量，正因为 $C$ 半正定。

### 7.3 双视角：eigh($C$) vs SVD($Z$)

同一条数据，两条路线：

- **路线一（协方差谱分解）**：对 $C$ 求 `eigh` $\to$ 特征值 $\lambda$、主方向 $V$；
- **路线二（数据直接 SVD）**：对 $Z$ 做 SVD $Z=U\Sigma V^T$（17 讲），则

$$C=\frac{Z^TZ}{n-1}=\frac{V\Sigma^2V^T}{n-1}=V\,\mathrm{diag}\!\left(\frac{\sigma_i^2}{n-1}\right)V^T\ \Longrightarrow\ \text{右奇异向量 $=$ 主方向},\quad \frac{\sigma_i^2}{n-1}=\lambda_i.$$

EXP8 现场（200 样本、两个相关特征 $[z,\ 2z+0.5\eta]$）：协方差特征值 $[4.3037,\ 0.0431]$、占比 $[0.9901,\ 0.0099]$（$99\%$ 的方差在第一个方向）；第一主方向——eigh 得 $[0.4351,\ 0.9004]$、SVD 得 $[0.4351,\ 0.9004]$、$|\text{点积}|=1.0000$（同一方向）；$\sigma_i^2/(n-1)$ 与特征值逐个对账（零差）；投影方差 $\mathrm{Var}(Z\vec v_1)=4.3037=\lambda_1$（定义式的现场确认）。17 讲 L369"右奇异向量 $=$ 主方向、$\sigma^2=$ 方差"正式兑现——16 讲"谱定理的舞台"与 17 讲"SVD 右奇异向量"，在这里合流成同一件事。

**工程选择**：实践优先 SVD($Z$)——不显式造 $C$（$Z^TZ$ 会平方条件数，20 讲的 $\kappa^2$ 教训迁移；$d\gg n$ 时 $d\times d$ 的 $C$ 更是白烧内存）。EXP8 已证明两条路线数学等价，数值上 SVD 更稳。

### 7.4 降维的使用与边界

**用法**：要压到 $k$ 维，投影 $Z_k=ZV_k$（$n\times k$——每个样本的"主成分坐标"）；想近似还原 $X\approx\mathbf 1\vec\mu^T+Z_kV_k^T$。EXP8 里 $k=1$ 已保住 $99\%$ 的方差。

**边界四条**（工程坑清单）：

1. **尺度敏感**：特征单位不一致时先标准化（否则"米 vs 毫米"决定主方向）——头号坑；
2. **正负号无意义**：$\pm\vec v$ 都是主方向，投影差个符号——不要对"方向朝哪"做语义解释；
3. **线性视野**："变化最大"是线性假设，弯曲、环状的数据结构它抓不到（非线性降维是另一条线，第 22 讲的地图上有位置）；
4. **方差大 $\ne$ 有用**：PCA 无监督，"信息"由方差定义——存在"方差小但在乎判别"的任务，关键方向可能被它丢掉。

## 八、下山：梯度下降与条件数

### 8.1 沿负梯度走

优化问题 $\min f(\vec x)$ 的最朴素办法：站在点上，看坡度（梯度），往最陡下坡方向挪一小步——

$$\vec x_{k+1}=\vec x_k-\alpha\nabla f(\vec x_k).$$

$\alpha$ 叫步长（学习率）。方向有了（负梯度），两个问题留着：步子多大？几步到底？本课的场景（碗）里有精确答案。

先把"碗"标准化：中心平移到碗底、常数舍去（不影响梯度），任何二次函数的碗都可写成 $f(\vec x)=\tfrac12\vec x^TH\vec x$（$H$ 对称正定）。主菜 SSE 也一样：$f=\lVert A\vec x-\vec b\rVert^2$ 的 Hessian 是 $2A^TA$（4.2），平移一下就是标准碗。

### 8.2 二次碗的剂量学：收敛因子 $1-1/\kappa$

标准碗的梯度 $\nabla f=H\vec x$（2.4(iii) 对称版），代入迭代：

$$\vec x_{k+1}=\vec x_k-\alpha H\vec x_k=(I-\alpha H)\vec x_k.$$

**逐轴分析**（把 $\vec x$ 拆到 $H$ 的特征方向上——谱定理，16 讲）：$H$ 的第 $i$ 个特征方向上，分量每步乘以 $1-\alpha\lambda_i$。所以整个迭代的进度由**最慢的方向**决定：收敛因子 $=\max_i\lvert1-\alpha\lambda_i\rvert$。取步长 $\alpha=1/L$（$L=\lambda_{\max}$，最陡方向的曲率；再大步最陡方向就震荡），则最大的是最小特征值处的 $1-\mu/L$（$\mu=\lambda_{\min}$）：

$$\text{收敛因子}=1-\frac{\mu}{L}=1-\frac1\kappa,\qquad \kappa=\frac{\lambda_{\max}}{\lambda_{\min}}.$$

每步最慢缩水一个 $(1-1/\kappa)$，$(1-1/\kappa)^{\kappa}\approx e^{-1}$——**$\kappa$ 步才缩水一个 $e$ 折**；要把误差压到 $\varepsilon$，步数 $\approx\kappa\ln(1/\varepsilon)$。

白话说"病态碗为什么下山慢"：扁平方向（小特征值）坡缓，"往前走 1 米的收获"很小；可步长被陡方向（大特征值）卡着不敢放大——于是缓方向一步挪一点点，凑 $\kappa$ 步才过一个 $e$ 折。**20 讲重逢**：解方程的迭代收敛看谱半径、CG 吃 $\sqrt{\kappa}$；最小化的迭代收敛看 Hessian 的谱、GD 吃 $\kappa$——同一个 $\kappa$，两种赛道。

### 8.3 实测：$\kappa=10$ vs $\kappa=1000$（EXP9）

脚本现场：$H=\mathrm{diag}(1,10)$（$\kappa=10$）对 $H=\mathrm{diag}(0.01,10)$（$\kappa=1000$）；步长 $\alpha=1/L=0.1$（两例 $L$ 都是 10）；起点 $(1,1)$；跑到相对误差 $10^{-6}$ 记步数——

- $\kappa=10$：**128 步**（理论 $\kappa\ln(1/\varepsilon)=10\times13.8\approx138$，同量级）；
- $\kappa=1000$：**13463 步**（理论 $1000\times13.8\approx13816$，同量级）；
- 比值 105 倍，与 $\kappa$ 之比 100 同量级——$\kappa$ 放大 100 倍，步数同步放大 100 倍。

（"理论"是最坏方向估计；实际步数还取决于起点的谱分解——量级吻合就确认了机制，不必强求小数点位。）

### 8.4 牛顿法：二阶情报的降维打击与代价

GD 只用一阶情报。牛顿法把 Hessian 也用上：**"当地地形近似为一个碗，直接跳到这个碗的底"**——解方程 $H\vec d=-\nabla f$，更新 $\vec x\leftarrow\vec x+\vec d$。对二次碗，局部 $=$ 全局，于是第一步就：

$$\vec x_1=\vec x_0-H^{-1}(H\vec x_0)=\vec0.$$

EXP9 现场：同一个 $\kappa=1000$ 的碗，牛顿法 **1 步**到 $\lVert\vec x\rVert=0.0\times10^{0}$——与 GD 的 13463 步形成对峙。机制在 4.2 已经埋好：二次函数的 Hessian 恒定，第一步的二次近似就是函数本身，所以"一步到位"不是巧合、是必然。

**代价**（为什么大模型不用牛顿法）：

1. **每步要解一个线性方程组** $H\vec d=-\vec g$：一次分解 $O(n^3)$——20 讲"分解复用"的主场（$H$ 不变时分解一次、新右端只前代/回代，这正是 20 讲 L218 许诺的"第 21 讲牛顿类方法的每一步"）；
2. **Hessian 要算得出、存得下**：$n$ 个参数是 $n\times n$ 矩阵——百万参数存储 $10^{12}$ 个数，做梦；
3. $H$ 不定/病态时，牛顿方向还要修正（工程细节，接口级）。

所以真实世界的优化器谱系是"一阶 $+$ 一阶的改良"（动量、Adam……第 22 讲接口处指路）；但"看得懂 Hessian 与 $\kappa$"永远是读懂收敛曲线的底层素养。

| 方法 | 每步代价 | 二次碗步数 | 适用 |
|---|---|---|---|
| 梯度下降 | $O(n^2)$（一次矩阵-向量） | $\sim\kappa\ln(1/\varepsilon)$ | 参数多、追求单步便宜 |
| 牛顿法 | $O(n^3)$（解方程）＋存 Hessian | $1$（二次函数） | 参数少、Hessian 可得 |

### 10.2 坑清单（背下来，上机前默念）

1. **布局混用**：一段推导里"同形/行向量"换来换去 $\to$ 转置错位。对策：同形纪律，每步形状自检；
2. **梯度形状摆错**：$\nabla_W$（$m\times n$）写成 $n\times m$——"形状自检"当场拆穿；
3. **链式顺序搞反**：传回该用 $W^T$ 却用了 $W$。试金石：线性层 $W\vec x+\vec b$ 的传回必须乘 $W^T$（5.1 的 $J^T$）；
4. **参数个数对不上**：反传实现后先数参数（26 个的例子），再和 `numgrad` 全对账——两个检查缺一不可；
5. **过拟合接口**（15 讲欠账的落点）：SSE 只降不升是定律（15 讲嵌套定律）——所以 SSE 本身**不设**过拟合警报；判别"贴 vs 抓"要在独立数据上做（训练/验证/正则化，统计课主场）。本讲能贡献的接口：系数不确定度 $\mathrm{se}$ 爆炸（6.4）是"模型在抓噪声"的统计指纹之一——拟合到病态时，方差账和病态账同源；
6. **不管 $\kappa$ 直接冲 GD**：病态碗先看条件数——128 步 vs 13463 步的教训（8.3）；要么预处理、要么换方法。

## 小结（一页）

- **布局约定**：梯度与自变量同形（谁变对谁逐项摆）；三块积木 $\nabla(a^T\vec x)=a$、$\nabla(\vec x^T\vec x)=2\vec x$、$\nabla(\vec x^TA\vec x)=(A+A^T)\vec x$。
- **主公式**：$\nabla\lVert A\vec x-\vec b\rVert^2=2A^T(A\vec x-\vec b)$；置零 $=$ 正规方程 $=$ "第三副面孔"；标量对矩阵版 $=2(W\vec x-\vec y)\vec x^T$（残差 $\otimes$ 输入）。
- **二阶情报**：$\nabla^2\lVert A\vec x-\vec b\rVert^2=2A^TA$（恒定、正定）；AC$-$B$^2$ 判据 $=$ Sylvester $2\times2$；地形图 $=$ Hessian 的谱。
- **链式与反传**：$\nabla_x=J^T\nabla_y$；每层"误差 $\otimes$ 输入"装配参数梯度；26 参数对账 $3.4\times10^{-11}$。
- **统计**：$-{\log L}$ 梯度 $=(A^TA\vec w-A^T\vec b)/\sigma^2$，置零与 $\sigma$ 无关 $\Rightarrow$ MLE$=$OLS；$\mathrm{Cov}(\hat{\vec w})=\sigma^2(A^TA)^{-1}$、$\pm1.96\,\mathrm{se}$；$\hat\sigma^2$ 的自由度账。
- **PCA**：中心化 $\to$ 协方差 $C\to$ 主方向 $C\vec v=\lambda\vec v$；eigh 与 SVD 双视角等价；工程选 SVD。
- **下山**：GD 收敛因子 $1-1/\kappa$、步数 $\sim\kappa\ln(1/\varepsilon)$（实测 128 vs 13463）；牛顿法一步（二次函数）但每步 $O(n^3)$。
- **对账文化**：解析 vs 数值、eigh vs SVD、公式 vs 蒙特卡洛——三路互证。

**A1.** 形状三连：(a) $f(\vec x)=\vec c^T\vec x+\tfrac12\vec x^TB\vec x$（$B$ 对称）：求 $\nabla f$ 与 $\nabla^2f$，各是什么形状？(b) $f(X)=\vec a^TX\vec b$（$X$ 为 $m\times n$）：用全微分法推 $\nabla_Xf$（提示：$df=\vec a^T(dX)\vec b$，塞进迹里轮换）；(c) $f(W)=\lVert W\vec x-\vec y\rVert^2+\lambda\lVert W\rVert_F^2$（岭回归形式）：求 $\nabla_Wf$。

**参考答案**：(a) $\nabla f=\vec c+B\vec x$（$n$ 维，与 $\vec x$ 同形）；$\nabla^2f=B$（$n\times n$）。逐项：$\nabla(\vec c^T\vec x)=\vec c$；$\nabla(\tfrac12\vec x^TB\vec x)=\tfrac12\cdot2B\vec x=B\vec x$。(b) $df=\vec a^T(dX)\vec b=\operatorname{tr}(\vec a^T(dX)\vec b)\overset{\text{轮换}}{=}\operatorname{tr}(\vec b\,\vec a^T(dX))=\langle\vec a\vec b^T,dX\rangle$，故 $\nabla_Xf=\vec a\vec b^T$（$m\times n$ 外积，与 $X$ 同形）。(c) 第一项即 3.4 结果 $2(W\vec x-\vec y)\vec x^T$；第二项 $\nabla_W\lambda\sum_{ij}W_{ij}^2=2\lambda W$。合起来 $\nabla_Wf=2(W\vec x-\vec y)\vec x^T+2\lambda W$（$m\times n$ ✓）。数值验证（`lec21-02`，随机 3×2 现场）：(a) 偏差 $2.28\times10^{-10}$（Hessian vs $B$ 偏差 $3.09\times10^{-10}$）；(b) 偏差 $1.68\times10^{-11}$；(c) 偏差 $4.24\times10^{-10}$。

**B. 提高**

**B1.** 证明 $\nabla(\vec x^TA\vec x)=(A+A^T)\vec x$，并解释为什么二次型只"感受"$A$ 的对称部分。

**参考答案**：$d(\vec x^TA\vec x)=(d\vec x)^TA\vec x+\vec x^TA\,d\vec x=\vec x^TA^Td\vec x+\vec x^TA\,d\vec x=\vec x^T(A^T+A)d\vec x$，识别得 $(A+A^T)\vec x$。反对称部分透明：$\vec x^TA_k\vec x=(\vec x^TA_k\vec x)^T=\vec x^TA_k^T\vec x=-\vec x^TA_k\vec x\Rightarrow\vec x^TA_k\vec x\equiv0$；故 $\vec x^TA\vec x=\vec x^TA_s\vec x$、$\nabla=2A_s\vec x=(A+A^T)\vec x$——与 16 讲"二次型与对称矩阵一一配对"同源。

**B2.** 证明：$A^TA$ 恒半正定；$A$ 列满秩时正定。（这正是 4.2 中"SE 的碗"的资格证。）

**参考答案**：$\vec x^T(A^TA)\vec x=(A\vec x)^T(A\vec x)=\lVert A\vec x\rVert^2\ge0$。若 $\lVert A\vec x\rVert^2=0$ 则 $A\vec x=\vec0$；列满秩时只有 $\vec x=\vec0$，故等号仅在零向量处——正定。∎

**B3.** 推导 $\mathrm{Cov}(\hat{\vec w})=\sigma^2(A^TA)^{-1}$，并解释 $\mathrm{se}$ 的量纲与大小语义。

**参考答案**：$\hat{\vec w}=M\vec b$、$M=(A^TA)^{-1}A^T$；$\mathrm{Cov}(M\vec b)=M\,\mathrm{Cov}(\vec b)\,M^T=M(\sigma^2I)M^T=\sigma^2(A^TA)^{-1}A^TA(A^TA)^{-1}=\sigma^2(A^TA)^{-1}$。量纲：$\sigma$ 是数据单位，$\mathrm{se}_j$ 与它同量纲；$A^TA$ 越大（信息越多）$\mathrm{se}$ 越小、$\sigma$ 越大 $\mathrm{se}$ 越大。

**B4.** 完整推导 PCA 主方向方程：写出拉格朗日函数、梯度、驻点方程，并说明"为什么取最大特征值方向"。

**参考答案**：单位球上最大化 $\vec v^TC\vec v$（$\lVert\vec v\rVert=1$）；拉格朗日 $\mathcal L=\vec v^TC\vec v-\lambda(\vec v^T\vec v-1)$；$\nabla_{\vec v}\mathcal L=2C\vec v-2\lambda\vec v=\vec0\Rightarrow C\vec v=\lambda\vec v$。单位球是紧致集、最大点存在；任何最大点必是驻点（约束必要条件），且 $\vec v^TC\vec v=\lambda\vec v^T\vec v=\lambda$，故最大值 $=\lambda_{\max}$、取在最大特征向量处。

**C1.** ★ 反传对账：两层小网络（输入 2 维、隐层 3 维、tanh、输出 1 维；参数 $2\times3+3+3\times1+1=13$ 个），手写反向传播，并用中心差分数值梯度对账（答案借助脚本 `lec21-02` 的 C1 现场，读数引用同一设计）。

**参考答案**：核心反传五步（形状自检照 5.2）：

```python
import numpy as np

def numgrad(f, x, h=1e-6):
    x = np.asarray(x, dtype=float); xf = x.ravel(); g = np.zeros(x.size)
    for i in range(x.size):
        e = np.zeros(x.size); e[i] = h
        g[i] = (f((xf + e).reshape(x.shape)) - f((xf - e).reshape(x.shape))) / (2 * h)
    return g.reshape(x.shape)

rng = np.random.default_rng(7)
x = rng.normal(size=2)
W1 = rng.normal(size=(3, 2)); b1 = rng.normal(size=3)
W2 = rng.normal(size=(1, 3)); b2 = rng.normal(size=1)
y = np.array([1.0])

def L(params):
    W1 = params[:6].reshape(3, 2); b1 = params[6:9]
    W2 = params[9:12].reshape(1, 3); b2 = params[12:]
    h = np.tanh(W1 @ x + b1); z = (W2 @ h + b2)[0]
    return 0.5 * (z - y[0]) ** 2

def grads():                       # 手写反传
    pre = W1 @ x + b1; h = np.tanh(pre); z = (W2 @ h + b2)[0]
    dz = np.array([z - y[0]])
    dW2 = np.outer(dz, h); db2 = dz
    dh = W2.T @ dz
    dpre = dh * (1 - h * h)
    dW1 = np.outer(dpre, x); db1 = dpre
    return np.concatenate([dW1.ravel(), db1, dW2.ravel(), db2])

p0 = np.concatenate([W1.ravel(), b1, W2.ravel(), b2])
print(np.abs(grads() - numgrad(L, p0)).max())     # 3.30e-10
```

读数：13 个参数全对账，最大偏差 $3.30\times10^{-10}$。
