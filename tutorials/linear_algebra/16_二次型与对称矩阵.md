$$f(x,y)=2x^2+4xy+5y^2$$

第 11 讲所有主角都是"矩阵"；这次是一个**能吃的表达式**（喂给它一对 $(x,y)$，吐回一个数）。第 15 讲末尾预告的问题："它恒正吗？"本讲结束时你不只会回答，还能用**三台互相独立的机器**回答，外加几何图像：

## 二、二次型 = 对称矩阵：反对称部分被 $\vec x$ 杀死

**二次型（quadratic form）**：每项**总次数恰好为 $2$** 的多项式。二元的一般形：

$$f(x,y)=ax^2+bxy+cy^2$$

$n$ 元就是 $\sum_{i\le j}$ 一切 $x_ix_j$ 类项的带系数和。它总可以写成矩阵夹心饼干：

$$f=\vec x^TA\vec x\qquad(\vec x=(x,y)^T)$$

**读音规则（记法）**：把 $A$ 拆开看 $\vec x^TA\vec x=\sum_{i,j}a_{ij}x_ix_j$，关键在交叉项 $xy$ 的**来路**：它在 $(1,2)$ 位贡献 $a_{12}xy$、在 $(2,1)$ 位贡献 $a_{21}xy$——**两个位置合流**。所以记账时把 $bxy$ 的系数 $b$ **对半分**：$b/2$ 站 $(1,2)$、$b/2$ 站 $(2,1)$；平方项站对角线。口诀：**平方项站对角，交叉项对半分**。主例 $4xy$：$4/2=2$ 站两处，得 $A=\begin{pmatrix}2&2\\2&5\end{pmatrix}$。

**为什么 $A$ 总取对称的（不对称行不行）**：行——但**看不出任何区别**。设 $A$ 的反对称部分 $S=\frac{A-A^T}{2}$（$S^T=-S$）。考察 $\vec x^TS\vec x$：它是一个**数**，数的转置等于自己：

$$\vec x^TS\vec x=(\vec x^TS\vec x)^T=\vec x^TS^T\vec x=-\vec x^TS\vec x$$

一个数等于自己的相反数，只能是 $0$——**反对称部分整块对二次型的贡献为零**（实测 EXP1：非对称 $\begin{pmatrix}2&4\\0&5\end{pmatrix}$ 与它的对称部分给出同一个 $1.790000$）。所以：同一二次型完全由对称部分决定；于是**约定俗成：二次型的矩阵永远写对称的那个**，二次型与对称矩阵**一一对应**。

**唯一性的两个探针（为什么说"一一对应"）**：对称矩阵 $A$ 的对角元 $a_{ii}=f(\vec e_i)$（只让第 $i$ 个变量取 1）、交叉元由 $f(\vec e_i+\vec e_j)-f(\vec e_i)-f(\vec e_j)=2a_{ij}$ 反推——二次型的"体检数据"唯一确定每个元素（作业 B3 让你走完这条）。**反面**：两个不同矩阵可以给同一个二次型（比如上面那对非对称/对称），但**两个不同的对称矩阵绝不会**。

**回收第 02/09 讲**：这一步"转置不改变标量、于是对称部分才是本质"的戏法，用的就是第 02 讲的转置律和第 09 讲的对称矩阵概念——它俩今天正式有了后代。

> 下一站：拿到矩阵后，怎么"一眼"看出恒正——高中手艺升级。

## 三、配方法：化平方和（合同正式登场）

高中你干过这件事：证明 $x^2+6x+10$ 恒正——配成 $(x+3)^2+1$，两个非负项顶着，恒正。二次型版一模一样，只是多一个变量：

**主例配方全程（每一步都可查）**：

$$
2x^2+4xy+5y^2=2(x^2+2xy)+5y^2
=2\big[(x+y)^2-y^2\big]+5y^2
=2(x+y)^2-2y^2+5y^2
=\boxed{2(x+y)^2+3y^2}
$$

（说明每一跳：把含 $x$ 的项提系数 $2$ 出来 —— 里面 $x^2+2xy$ 是 $(x+y)^2$ 挖掉 $y^2$ —— 减出来的 $-2y^2$ 与 $5y^2$ 合并。）**结论一眼可见**：两个平方项的系数 $2,3$ 全正 ⇒ 对一切 $(x,y)\neq(0,0)$，$f>0$——**正定**（第四节正式定义）。为什么"平方和"这么好用：平方项各自非负、且**只有全为零才同时取零**，系数全正则和恒正——配方法把"一个复杂的交叉表达式"翻译成"若干个互相独立的非负账本"。

**翻译成矩阵语言（这一步是本讲的枢纽）**：配方过程就是换变量。令 $u=x+y,\ v=y$（可逆替换），则 $f=2u^2+3v^2$。解回 $x=u-v,\ y=v$，写成矩阵：

$$\vec x=\begin{pmatrix}1&-1\\0&1\end{pmatrix}\begin{pmatrix}u\\v\end{pmatrix}=P\vec y\qquad\Longrightarrow\qquad
\vec x^TA\vec x=(P\vec y)^TA(P\vec y)=\vec y^T(P^TAP)\vec y$$

括号里的 $B=P^TAP$ 就是新变量下二次型的矩阵——实测 $P^TAP=\mathrm{diag}(2,3)$ 零差。**这就是第 10 讲预告的"合同（congruent）"**：

> **合同**：$B=P^TAP$（$P$ 可逆）。二次型换变量时矩阵的变化关系。注意对称性自动保持（$(P^TAP)^T=P^TA^TP=P^TAP$），且二次型的值**逐点不变**（同一个 $\vec x$、同一个数，只是换了描述它的坐标）。

**配方流程（多变量通用版，考试直接照走）**：
1. 有 $x_1^2$：把含 $x_1$ 的全部项收成 $a_{11}\big(x_1+\text{（其他变量的线性式）}\big)^2$，减去"多吃进去的"，剩下的式子不再含 $x_1$——转下一变量重复；
2. 没有 $x_1^2$（比如只剩 $x_1x_2$ 型交叉项）：先做一次**临时换元**把它变成平方差（如 $x_1=y_1+y_2,\ x_2=y_1-y_2$ 化出 $x_1x_2=y_1^2-y_2^2$），回到第 1 条。
3. 全程只做可逆替换——配方产出的 $P$ 是**上三角**（每次把旧变量用新变量表达，一步步倒），主例的 $P=\begin{pmatrix}1&-1\\0&1\end{pmatrix}$ 正是此形。

**标准形与惯性定理**：配方到没有交叉项为止的结果叫**标准形**（只含平方项；系数再缩成 $\pm1$ 就是**规范形**，$p$ 个 $+1$、$q$ 个 $-1$）。两个重要事实：
- **标准形不唯一**：配方给 $\mathrm{diag}(2,3)$，第六节的正交法给 $\mathrm{diag}(1,6)$——系数完全不同（别人的换元法不同罢了）。
- **但"正号个数 $p$、负号个数 $q$"雷打不动**（**惯性定理**；$p+q=\mathrm{rank}(A)$，配方顺手读出秩）。主例两版都是"两个正、零个负"。这是二次型的指纹：**名称、系数可以变，配比（惯性）不能变**。惯性定理的完整证明超出本课主干（把它当"实测+直觉背书的常识"用，本课只押结论）；考试的直接用途：判类型只需知道 $p,q$。

## 四、正定与几何：碗与鞍、椭圆与双曲线

> **定义（正定）**：对称矩阵 $A$ 称**正定（positive definite）**，若对一切 $\vec x\neq\vec0$ 有 $\vec x^TA\vec x>0$。（注意"对称"是前提的一部分；非对称矩阵不谈正定。）

家族全像：**正定**（$>0$）、**负定**（$-A$ 正定，即 $\vec x^TA\vec x<0$）、**半正定**（$\ge0$ 允许存在非零 $\vec x$ 取等）、**不定**（既有正也有负取值）。

**几何：$f$ 的"等高线"**。把 $f(\vec x)=c$ 看成地形图：
- **正定 = 处处开口向上的碗**：一元时 $y=ax^2$（$a>0$）是向上抛物线；二元时**每个方向的截面**都是向上抛物线。等高线 $f=c$ 是一圈圈**同心椭圆**，$f$ 越大圈越大、$f=0$ 缩成一个点（碗底），且当 $\|\vec x\|\to\infty$ 时 $f\to\infty$（"没有逃逸路线"）。
- **不定 = 马鞍（鞍面）**：有的方向往上翘、有的方向往下兜。等高线是**双曲线**（两支），$f=0$ 是两条交叉直线（两个正负方向之间的分界线）。
- **半正定 = 压扁的碗**：某条方向碗是平的，$f=c$（$c>0$）退化成**两条平行线**、$f=0$ 是一条直线（那条平掉的方向）。
- **负定 = 倒扣的碗**：形状同正定，开口向下。

**主例的椭圆长什么样（用第六节的谱来读）**：$f=1$ 的椭圆——别急着画，先记住两个数字来源：第六节算出 $\lambda=1,6$，则**半轴长 $=1/\sqrt{\lambda}$、方向 $=$ 特征向量**：沿 $(2,-1)$ 方向半轴 $1$、沿 $(1,2)$ 方向半轴 $1/\sqrt6\approx0.41$——一个斜着放的瘦椭圆。实测（EXP6）：用参数化 $\vec x=\frac{\cos t}{\sqrt{\lambda_1}}\vec q_1+\frac{\sin t}{\sqrt{\lambda_2}}\vec q_2$ 扫一圈，$f\equiv1$ 精确成立（$10^{-10}$ 级零差）；不定的对照例（第五节那个 $\begin{pmatrix}1&2\\2&1\end{pmatrix}$）用 $\sinh/\cosh$ 参数化扫出两条分支，也都严格落在 $f=1$ 上。**"半轴=1/√λ"这句话**到第七节谱定理后你会知道为什么。

**元问题：正定为什么值得专门学？**（第 13 讲内积公理③的答案）第 13 讲立内积三公理时，第三条就叫"**正定**"：$\langle\vec v,\vec v\rangle\ge0$ 且等号只在零向量。当时只用在点积/积分款上；现在答案揭晓：**用对称矩阵 $A$ 定义双线性型 $\langle\vec x,\vec y\rangle=\vec x^TA\vec y$，它满足三条公理 ⟺ $A$ 正定**（对称⟺对称公理、矩阵乘的法律⟺线性、正定定义⟺正定公理）。也就是说——**正定矩阵就是"有资格当内积的矩阵"，是一把合格的尺子**。第 13 讲的加权内积 $\sum w_ix_iy_i$ 正是被正定对角矩阵造出来的；主例 $A$ 也在 $\mathbb R^2$ 上造出一把斜的尺子。这个视角在 21 讲 PCA 会大放异彩。

**顺带一个回收**：正定 ⇒ $\det>0$ ⇒ 可逆（第 05/06 讲的"可逆判定器"被正定一键触发——为什么 $\det>0$ 的证明放第五节，正好接 Sylvester）。

## 五、判据一：Sylvester 顺序主子式（高中判别式的遗产）

**先从高中直通车**。高中判"$ax^2+bxy+cy^2$ 恒正"：固定 $y$ 把 $f$ 看成 $x$ 的一元二次（首项 $a$），恒正 ⟺

$$a>0\quad\text{且}\quad\text{判别式}=(by)^2-4a\cdot cy^2=(b^2-4ac)y^2<0\ \ (\forall y\neq0)\iff a>0,\ b^2<4ac$$

把结论翻译成矩阵：$A=\begin{pmatrix}a&b/2\\b/2&c\end{pmatrix}$，则 $D_1=a$、$D_2=ac-\frac{b^2}{4}=\frac{4ac-b^2}{4}$，于是 $b^2<4ac\iff D_2>0$。**高中"首项正+判别式负"就是 2×2 的 Sylvester 判据**——现在把它升级到 $n$ 维。

> **定义（顺序主子式）**：$D_k$ = 左上角 $k\times k$ 子阵的行列式（$D_1=a_{11}$，$D_2=\det\begin{pmatrix}a_{11}&a_{12}\\a_{21}&a_{22}\end{pmatrix}$……直到 $D_n=\det A$）。**"顺序"二字是要害**：从左上角**依次**圈大，不能跳、不能换别的子阵。
>
> **Sylvester 定理**：对称 $A$ 正定 $\iff$ 一切顺序主子式 $D_1,\dots,D_n$ 全为正。

**先手算对账（三堂会审的第三、四堂对上了）**：主例 $D_1=2>0$、$D_2=\det\begin{pmatrix}2&2\\2&5\end{pmatrix}=6>0$ ⇒ 正定；特征值 $\lambda=1,6$ 全正 ⇒ 正定——两条独立逻辑同判（EXP4 还补了一张五类型全表：正定 $(+2,+6)$ 谱 $\{1,6\}$、不定 $(+1,-3)$ 谱 $\{-1,3\}$、负定 $(-2,+3)$ 谱 $\{-3,-1\}$、半正定 $(+1,0)$ 谱 $\{0,2\}$、以及第五节的坑例，全部对账）。3×3 再补一盘（EXP5）：$A=\begin{pmatrix}2&-1&0\\-1&2&-1\\0&-1&2\end{pmatrix}$，$D=(2,3,4)$ 全正、谱 $(2-\sqrt2,\ 2,\ 2+\sqrt2)\approx(0.586,2,3.414)$ 全正——再同判。

**为什么"顺序主子式全正"能等价于正定（这题的来龙去脉）**：

*必要性（正定 ⇒ 全正），两步走*：
1. **正定在低维也正定**：若 $A$ 正定，只看"前 $k$ 个分量"的子空间（$\vec x=(x_k;\ 0,\dots,0)^T$），$\vec x^TA\vec x=\vec x_k^TA_k\vec x_k$——所以 $A_k$（左上 $k\times k$ 子阵）自己也是正定矩阵。
2. **正定 ⇒ 行列式为正**（引理）：设 $A$ 正定。对每个 $t\in[0,1]$ 构造 $A_t=(1-t)A+tI$——对任何 $\vec x\neq\vec0$，$\vec x^TA_t\vec x=(1-t)\vec x^TA\vec x+t\|\vec x\|^2>0$（两项非负、不同时为零），所以**整条路径上全是正定阵**，从而**全可逆**（若某个 $A_t$ 奇异，则存在 $\vec z\neq\vec0$ 被它杀成零，$\vec z^TA_t\vec z=0$，与正定矛盾——第 06 讲"可逆 ⟺ 零空间只有零"）。行列式是元素的连续函数，一路非零 ⇒ 不变号；终点 $\det A_1=\det I=1>0$ ⇒ 起点 $\det A>0$。■
把 1、2 接起来：$A_k$ 正定 ⇒ $D_k=\det A_k>0$，对每个 $k$ 成立。

*充分性（全正 ⇒ 正定），块消元 + 归纳*（骨架三步，理解"为什么会真"即可）：
1. **消掉交叉项**：把 $A$ 分块 $A=\begin{pmatrix}a&\vec v^T\\\vec v&B\end{pmatrix}$（$a=D_1>0$）。取上三角 $T=\begin{pmatrix}1&-\vec v^T/a\\0&I\end{pmatrix}$（$\det T=1$，可逆），直接乘开：

$$T^TAT=\begin{pmatrix}a&\vec0^T\\\vec0&B'\end{pmatrix},\qquad B'=B-\frac{\vec v\vec v^T}{a}\quad(\text{剩下那块从此与第一变量无关})$$

2. **商行列式全正**：$T$ 是上三角，它的左上 $k\times k$ 块 $T_k$ 满足"子块一致"（前 $k$ 个坐标里的变换就是 $T_k$），于是 $A$ 的 $k+1$ 阶顺序主子阵 $A_{k+1}=T_{k+1}^T\,\mathrm{diag}(a,B'_k)\,T_{k+1}$ 形式取行列式：$D_{k+1}=1\cdot a\cdot\det B'_k$，即 $\det B'_k=D_{k+1}/D_1>0$——**$B'$ 的顺序主子式全正**。
3. **归纳**：$B'$（$n-1$ 阶、对称）顺序主子式全正 ⇒ 由归纳假设 $B'$ 正定 ⇒ 分块对角的 $\mathrm{diag}(a,B')$ 正定（两段各自恒正）⇒ $A$ 合同于正定阵。合同保持正定性（$\vec x^T(P^TAP)\vec x=(P\vec x)^TA(P\vec x)$，$P$ 可逆使 $\vec x\neq\vec0\Leftrightarrow P\vec x\neq\vec0$）⇒ **$A$ 正定**。■（归纳基：$1\times1$ 显然。）

**负定与不定怎么判（直接配套）**：
- **负定 ⟺ $D_k$ 符号交替**：$D_1<0,\ D_2>0,\ D_3<0,\dots$（即 $(-1)^kD_k>0$）。道理一行：$-A$ 正定，而 $-A$ 的顺序主子式 $(-1)^kD_k$。
- **不定**：其余情形（出现符号混合，或某 $D_k=0$ 卡断链条）。
- **考试用法**：先算 $D_1$ 定个基调，从小的 $D_k$ 起判——很多不定型在 $D_2$ 就现形了（EXP4 的不定例 $D_2=-3$ 一秒破产）。

**为什么必须"顺序"、为什么 $\det>0$ 不够（坑，现在点名，第九节有清单）**：$\det A=2>0$ 的 $A=\begin{pmatrix}-1&0\\0&-2\end{pmatrix}$——顺序主子式 $(-1,+2)$，判出**负定**（谱 $\{-2,-1\}$；EXP4 最后一行的"坑例"）。**只看 $\det>0$ 会把一个开口向下的碗当正定**；Sylvester 要求从 $D_1$ 开始**整条链**全正。两个数字各自重要：$D_k$ 是"前 $k$ 个变量的小碗长什么样"的体检报告，链子断在哪，问题就出在哪。

## 六、判据二：正交法与谱判据（特征值全正）

**正交法化标准形（主例全程，含手算）**：

**第 1 步：求 $\lambda$——不用解特征方程**。第 11 讲的账单 $\mathrm{tr}=\sum\lambda$、$\det=\prod\lambda$ 直接上场：$\mathrm{tr}=7$、$\det=6$ ⇒ 找"和为 7、积为 6"的一对数：$1$ 和 $6$ ✓。

**第 2 步：求特征向量（解 $N(A-\lambda I)$，第 11 讲老流程）**：
- $\lambda=1$：$A-I=\begin{pmatrix}1&2\\2&4\end{pmatrix}$，方程 $x+2y=0$ ⇒ 单位向量 $\vec q_1=(2,-1)/\sqrt5$；
- $\lambda=6$：$A-6I=\begin{pmatrix}-4&2\\2&-1\end{pmatrix}$，方程 $-2x+y=0$ ⇒ 单位向量 $\vec q_2=(1,2)/\sqrt5$。
- 顺手验正交：$(2,-1)\cdot(1,2)=2-2=0$ ✓——**对称矩阵的特征向量自动正交**（第七节证明；这就是第 11 讲路标说的事）。

**第 3 步：拼 $Q$、换变量**：$Q=[\vec q_1\ \vec q_2]$（列依次配 $\lambda_1=1,\lambda_2=6$），$Q^TQ=I$（第 13 讲正交矩阵），$\vec x=Q\vec y$ 代入：

$$f=\vec x^TA\vec x=\vec y^TQ^TAQ\,\vec y=\vec y^T\begin{pmatrix}1&0\\0&6\end{pmatrix}\vec y=1\cdot y_1^2+6\cdot y_2^2$$

实测 $Q^TAQ=\mathrm{diag}(1,6)$ 零差（$Q^TQ-I$ 偏离 $1.1\times10^{-16}$；脚本里 $Q$ 第一列可能整体反号——特征向量符号可以任意，不影响对角化）。

**为什么这就给出"特征值全正 ⟺ 正定"（谱判据）**：$\vec x=Q\vec y$ 是**可逆变量的替换**（$Q$ 正交所以 $\vec y=Q^T\vec x$ 一步回去），$\vec x\neq\vec0\Leftrightarrow\vec y\neq\vec0$。于是：

- **⇒**：若 $A$ 正定而某个 $\lambda_i\le0$，取 $\vec y=\vec e_i$（对应非零的 $\vec x=Q\vec e_i$）得 $f=\lambda_i\le0$，矛盾；
- **⇐**：若 $\lambda$ 全正，$f=\sum\lambda_iy_i^2\ge\lambda_{\min}\|\vec y\|^2>0$ 对一切 $\vec y\neq\vec0$ 成立。

> **谱判据**：对称 $A$ 正定 $\iff$ 特征值全为正。（负定 ⟺ 全负；半正定 ⟺ 全 $\ge0$；不定 ⟺ 有正有负。）

**两法对照表（同一目标的两种工程）**：

| | 配方法（Sylvester 家族） | 正交法（谱家族） |
|---|---|---|
| 变量替换 | $\vec x=P\vec y$，$P$ 可逆（通常上三角） | $\vec x=Q\vec y$，$Q$ 正交（旋转/反射） |
| 对角产物 | 一般数字，如 $\mathrm{diag}(2,3)$ | **必是特征值** $\mathrm{diag}(1,6)$ |
| 保什么 | 惯性（$p,q$）、秩；**不保**长度、角度、迹、特征值 | 惯性 $+$ **长度、角度、形状**（刚体运动）$+$ 谱 |
| 用途 | 手算判类型最快 | 几何主轴、数值计算、理论（谱定理、SVD、PCA） |

**几何一句话**：第 13 讲说"正交矩阵=刚体运动（旋转与反射）"。正交法就是**把镜头转到特征向量方向**看这个椭圆：转镜头不改变椭圆本身的形状，只让它的轴对齐坐标轴——于是在新坐标系里，$f=1$ 变成教科书椭圆 $y_1^2/1+y_2^2/\frac16=1$，半轴 $1/\sqrt{\lambda_i}$ 直接读出（第四节的预告在此兑现）。

**数值一句**：实际计算中没人手算 $n$ 阶特征多项式——`np.linalg.eigh`（对称专用）一行把 $\lambda,Q$ 都给你，判正定就是 `(eigvalsh(A) > 0).all()`。

## 七、谱定理：第 11/13 讲承诺兑现之夜

第 11 讲"三条边界"之 ② 原话是"对称矩阵特征值全是实数，特征向量还能挑成两两正交的（第 13 讲'正交'出场后兑现，第 16 讲正式立为谱定理）"；第 13 讲正交语言立好后再次预告"第 16 讲谱定理正式兑现"。现在兑现。

> **谱定理（实对称矩阵的谱分解）**：设 $A$ 实对称（$A^T=A$）。则：
> ① $A$ 的特征值**全是实数**；
> ② **不同**特征值对应的特征向量**自动正交**；
> ③ $A$ 有 **$n$ 个两两正交的单位特征向量**（重特征值也能凑满配额：在特征空间内用第 14 讲的 Gram-Schmidt 加工即得）；
> ④ 把它们排成 $Q=[\vec q_1\ \cdots\ \vec q_n]$（$\vec q_i$ 配 $\lambda_i$），则 $Q$ 正交、$Q^TAQ=\Lambda=\mathrm{diag}(\lambda_1,\dots,\lambda_n)$，即

$$A=Q\Lambda Q^T\qquad(\text{谱分解；列 = 特征向量，是 }A\text{ 的"展开式"})$$

**证明三段接力（"实、正交、齐"）**：

**(a) 特征值全实（两行）**。设 $A\vec x=\lambda\vec x$（$\vec x\neq\vec0$，暂允许复数）。考察数 $s=\vec x^HA\vec x$（$\vec x^H=\bar{\vec x}^T$，$\bar{}$ 是共轭——"共轭转置"记号）。因为 $s$ 是数，$s=s^H$；又 $A$ 实对称使 $A^H=A$：

$$s^H=(\vec x^HA\vec x)^H=\vec x^HA^H\vec x=\vec x^HA\vec x=s$$

所以 $s$ **是实数**。另一方面 $\vec x^HA\vec x=\vec x^H(\lambda\vec x)=\lambda\,\vec x^H\vec x=\lambda\|\vec x\|^2$，其中 $\|\vec x\|^2=\sum|x_i|^2>0$。于是 $\lambda=s/\|\vec x\|^2$ 是实数。■（第 11 讲的悬案 "$R_{90}$ 给 $\pm i$"至此划清界限：**非对称矩阵才出复数**，对称的永远没有。）

**(b) 不同特征值的特征向量自动正交（三行）**。设 $A\vec v=\lambda\vec v$、$A\vec w=\mu\vec w$、$\lambda\neq\mu$（现在都是实的）。**转移技巧**：把 $A$ 从内积的一边搬到另一边：

$$\lambda\langle\vec v,\vec w\rangle=\langle A\vec v,\vec w\rangle=(A\vec v)^T\vec w=\vec v^TA^T\vec w=\vec v^T(A\vec w)=\langle\vec v,A\vec w\rangle=\mu\langle\vec v,\vec w\rangle$$

（第二跳用 $A^T=A$——**对称性就用在这一点上**。）于是 $(\lambda-\mu)\langle\vec v,\vec w\rangle=0$，而 $\lambda\neq\mu$ ⇒ $\langle\vec v,\vec w\rangle=0$。■

**(c) 凑齐 $n$ 个正交特征向量（"必有一个特征值"的几何论证 + 降维归纳）**。关键是一个漂亮的观察：**单位球面上的最值点就是特征向量**。

1. **取最值**：$g(\vec x)=\vec x^TA\vec x$ 在单位球 $\|\vec x\|=1$（闭合有界）上连续，必取到最大值，设其最大值点为 $\vec v$、最大值为 $\lambda$（显然 $\vec v\neq\vec0$，且 $g(\vec v)=\lambda$）。
2. **垂直条件**：球面在 $\vec v$ 处的"切方向"恰是与 $\vec v$ 垂直的一切 $\vec z$（$\vec z\perp\vec v$）。沿切方向走，$G(t)=\frac{(\vec v+t\vec z)^TA(\vec v+t\vec z)}{\|\vec v+t\vec z\|^2}$ 在 $t=0$ 处取最大 ⇒ $G'(0)=0$。商式求导、利用 $\|\vec v\|=1$、$\vec z\perp\vec v$、$\vec v^TA\vec v=\lambda$，只剩两个一次项：$G'(0)=2\vec z^T(A\vec v-\lambda\vec v)=0$，对**一切** $\vec z\perp\vec v$ 成立。
3. **逼出特征方程**：$\vec z^T(A\vec v-\lambda\vec v)=0$ 对一切 $\vec z\perp\vec v$ ⇒ 向量 $A\vec v-\lambda\vec v$ 与 $\vec v^\perp$ 中每个向量垂直 ⇒ 它只能落在 $\vec v^\perp$ 的正交补里，即 $A\vec v-\lambda\vec v=\alpha\vec v$（第 13 讲第七节：正交补的正交补回到原空间）。两边与 $\vec v$ 内积：$\lambda-\lambda=\alpha$ ⇒ $\alpha=0$ ⇒ $A\vec v=\lambda\vec v$。**最值点就是特征向量**。
4. **降维归纳**：$A$ 把 $\vec v^\perp$ 保持在自己内部（若 $\vec z\perp\vec v$，则 $(A\vec z)^T\vec v=\vec z^TA^T\vec v=\vec z^T(A\vec v)=\lambda\,\vec z^T\vec v=0$——对称性再次出手）。$\vec v^\perp$ 是 $n-1$ 维空间，$A$ 在上面仍是实对称机器——回到第 1 步同款论证，又得一个正交的新特征向量。如此下去拿到 $n$ 个两两正交的单位特征向量（"同 $\lambda$ 内部"的加工：特征空间内任意正交基化，14 讲 GS 现成）。■

**归纳短版**：**实**（共轭转置两行）→ **正交**（转移技巧三行）→ **齐**（球面最值+降维归纳）。考试一般直接使用谱定理；证明的价值在于"这不是运气"——EXP7 里随机抽的 5×5 对称矩阵，重构误差 $1.1\times10^{-15}$、列正交偏离 $1.0\times10^{-15}$，双双零差级；而同规模**非对称**对照组特征值成对变复数（$(1.602\pm0.704j)$ 等）、特征向量矩阵不正交度 $0.750$——**"对称"这个条件不是装饰**。

**顺手结账两个旧账**：
- **Rayleigh 商**（第 11 讲幂法）：球面论证的中间产品就是 $\lambda_{\min}\le\vec x^TA\vec x\le\lambda_{\max}$（$\|\vec x\|=1$；因为 $f=\sum\lambda_iy_i^2$ 是 $\lambda$ 的加权平均）——幂法从任意初值往上爬的那座"山"，山顶高度恰是 $\lambda_{\max}$、山脚 $\lambda_{\min}$。实测 EXP8：$S=\begin{pmatrix}2&1\\1&2\end{pmatrix}$ 的单位圆上撒 2 万点，$f$ 的最大/最小贴到 $3.000000/1.000000$=谱的上下端。第 11 讲"Rayleigh 商贴 $\lambda_{\max}$"的机制全在这里。
- **对称与正交的撞名清理**（第 13 讲坑 4 预警）：那里的结论是"正交矩阵 ≠ 对称矩阵、互不蕴含"。本讲说的是**另一件事**：**对称矩阵可以被正交矩阵对角化**——$\vec q$ 们负责"正交"（$\vec q_i$ 是正交矩阵的列），$A$ 负责"对称"。两个概念在谱定理里各司其职、不互含。
- **推论（两个，后讲见）**：① $\sqrt{A}=Q\sqrt{\Lambda}Q^T$（把 $\lambda_i$ 开根号）是"正定矩阵的平方根"——第 17 讲 SVD 的构造零件；② 谱分解 $A=Q\Lambda Q^T$ 里 **$Q$ 同时是相似与合同的桥**（$Q^{-1}=Q^T$，一个矩阵干两份工，第八节展开）。

## 八、合同 vs 相似：两个关系握手 + 四个应用接口

第 10 讲"四种矩阵关系一次分清"那节里，合同一行是**预告**（"$B=P^TAP$：二次型换变量，保正负惯性，第 16 讲正式登场"）。今天登场，并在对称矩阵身上完成与相似的合流对照：

| | 相似 $B=P^{-1}AP$ | 合同 $B=P^TAP$ |
|---|---|---|
| 场景 | 换基：同一台变换换一套语言 | 换变量：同一个二次型换一组坐标 |
| 保持 | 特征值、迹、$\det$、秩 | 对称性、秩、**正负惯性 $(p,q)$** |
| **不保** | ——（谱核心信息全保） | **特征值、迹**（一般情形；主例：配方把迹 $7$ 变 $5$、谱 $\{1,6\}$ 变 $\{2,3\}$） |
| 何时同一 | **$P$ 正交时两个关系合一**：$Q^{-1}=Q^T$，一个 $Q$ 干两份工 | |

**主例现场（同一二次型的两次换衣服）**：配方（合同路径）给 $\mathrm{diag}(2,3)$——秩 2 ✓、正号 2 个 ✓，但迹从 7 悄悄变 5、谱消失（$2,3$ 不是特征值）；正交路径给 $\mathrm{diag}(1,6)$——迹 7 ✓、谱 $\{1,6\}$ ✓，**既是合同又是相似**。一句话记：**配方是"斜着搭脚手架"（只保内外轮廓=惯性），正交是"旋转镜头"（连坐标系的正交结构都原样带着，于是谱也保住）**。这就是谱定理的独特地位：它是对称矩阵里"合同与相似的握手点"。

**四个应用接口（本讲是它们的公共祖先）**：
1. **$A^TA$ 正定**（第 15 讲"碗底唯一"的真身）：任何矩阵：$\vec x^T(A^TA)\vec x=(A\vec x)^T(A\vec x)=\|A\vec x\|^2\ge0$——**恒半正定**；列无关时 $\|A\vec x\|^2=0\Rightarrow A\vec x=0\Rightarrow\vec x=0$——**正定**。所以最小二乘的 $\mathrm{SSE}(\vec x)=\|\vec b-A\vec x\|^2$ 的二次部分是个**正定的碗**，唯一最低点=正规方程的解。实测 EXP9 用第 15 讲那个拟合矩阵：$A^TA=\begin{pmatrix}4&6\\6&14\end{pmatrix}$，$D=(4,20)$ 正定、恒等式零差、特征值全正。
2. **Hessian 与极值判定**（第 21 讲预告 + 微积分回收）：二元函数在驻点处看二阶偏导排成的对称矩阵 $H=\begin{pmatrix}f_{xx}&f_{xy}\\f_{xy}&f_{yy}\end{pmatrix}$（Hessian）：$H$ 正定 ⇒ 极小（碗底）、负定 ⇒ 极大、不定 ⇒ 鞍点。微积分课背的 "$\mathrm{AC-B^2}>0$ 且 $A>0$ 是极小"——**就是 2×2 的 Sylvester**。21 讲把梯度与 Hessian 正式接上。
3. **Cholesky 分解**（第 20 讲预告）：正定矩阵能拆成 $A=LL^T$（$L$ 下三角）——"正定版的平方根"，解方程最快最稳的一档；顺序主子式全正正是这台分解存在且数值健康的保证。
4. **PCA**（第 21 讲预告）：数据协方差矩阵对称半正定；它的特征向量=主成分方向、特征值=方差。今天谱定理的舞台就是 PCA 的舞台。

## 九、心智模型与坑

**三副铭牌（背这三句，考试实践都够用）**：
1. **二次型 = 对称矩阵的标量外衣**：写它、认它、换它全走矩阵语言；反对称部分纯属噪音（被 $\vec x$ 杀死）。
2. **正定 = 处处开口向上的碗**：所有方向截面向上；$f=c$ 是同心椭圆族；$f=0$ 只剩碗底。正定矩阵 = 合格的尺子（内积度量衡）。
3. **谱定理 = 对称矩阵的身份证**：实、正、齐（特征值全实、正交可挑齐）；$Q,\Lambda$ 一出，二次型的坐标（正交法）、几何（主轴半轴）、正负（谱判据）全透明。

**坑清单（六个，全有实测撑腰）**：
1. **交叉项对半分**：$4xy$ 写两个 $2$ 站 $(1,2)/(2,1)$，别把 $4$ 整个塞进去（写错矩阵后面全错——三堂会审从第一节就崩）。
2. **"顺序"二字不能丢**：Sylvester 要求 $D_1$ 到 $D_n$ **从左上角依次全正**；$\det>0\neq$ 正定（反例 $\begin{pmatrix}-1&0\\0&-2\end{pmatrix}$：$\det=2$ 却负定）。也别忘了正定的前提是**对称**。
3. **半正定别硬套 Sylvester**：顺序主子式全 $\ge0$ **不充分**（反例 $\begin{pmatrix}0&0\\0&-1\end{pmatrix}$：$D=(0,0)$ 都非负，但 $f=-\vec y^2$ 取负值）；半正定要用**全体**主子式——本课知道有这回事即可，不展开。
4. **合同 ≠ 相似**：配方产物 $\mathrm{diag}(2,3)$ **不是**谱——要谱就用正交法；两关系只在 $P$ 正交处握手。
5. **$Q$ 的列与 $\lambda$ 配对**：列的次序决定对角元的次序（`eigh` 升序返回、符号随机——自己拼 $Q$ 时列 $i$ 配 $\lambda_i$，别错位）。
6. **"正定"一词三个失散兄弟**：内积公理③的"正定"（函数性质）／矩阵/二次型正定（本讲）／"正数的定积分"（无关）——前两者同源：**正定矩阵就是能让 $\langle\vec x,\vec y\rangle=\vec x^TA\vec y$ 过公理清单的那些矩阵**。看到"正定"先问：说的是哪种对象。

## 小结（一页）

- **二次型**：每项总次数 2 的齐次多项式；$\vec x^TA\vec x$ 表示，$A$ 取**对称**（反对称部分被杀死）且唯一；交叉项系数**对半分**行军。
- **配方法**：高中配方的 $n$ 元版；产出标准形（只含平方项，系数缩成 $\pm1$ 为规范形）；对应**合同** $B=P^TAP$（第 10 讲预告落地）；**惯性定理**：$p,q$ 不变、$p+q=\mathrm{rank}$（标准形本身不唯一）。
- **正定家族**：正/负/半正/不定；几何=碗与鞍、$f=c$ 的椭圆/双曲线/平行线；正定=合格内积（第 13 讲公理③答案）。
- **两个判据**：Sylvester（$D_1..D_n$ 从左上依次全正；负定符号交替；证明=低维限制+形变引理 / 块消元+归纳）；谱判据（$\lambda$ 全正；正交法一步）。
- **谱定理**：实、正交、齐（三段证明）；$A=Q\Lambda Q^T$；对称矩阵上**合同与相似握手**（$Q^{-1}=Q^T$）；Rayleigh 区间 $\lambda_{\min}\le\vec x^TA\vec x\le\lambda_{\max}$（第 11 讲幂法归宿）。
- **接口**：$A^TA$ 正定（15 讲碗底）、Hessian 判极值（21 讲）、Cholesky（20 讲）、PCA（21 讲）。
- **心智模型**：二次型=对称矩阵的标量外衣；正定=向上的碗；谱定理=对称矩阵的身份证。

**A. 基础**

**A1.** 写出下列二次型的对称矩阵：(a) $f=3x^2-4xy+y^2$；(b) $f=x_1^2+2x_1x_2-x_2x_3+5x_3^2$（三元）。

**参考答案**：

(a) 平方项站对角 $(3,1)$，交叉项 $-4xy$ 对半 ⇒ $\begin{pmatrix}3&-2\\-2&1\end{pmatrix}$。
(b) 逐个上账：$x_1^2\to a_{11}=1$；$x_3^2\to a_{33}=5$；$2x_1x_2\to a_{12}=a_{21}=1$（$2/2=1$）；$-x_2x_3\to a_{23}=a_{32}=-\frac12$；无 $x_2^2\to a_{22}=0$，无 $x_1x_3\to a_{13}=0$：

$$\begin{pmatrix}1&1&0\\1&0&-\frac12\\0&-\frac12&5\end{pmatrix}$$

**A2.** 配方法化标准形并判类型：(a) $f=2x^2+6xy+5y^2$；(b) $f=x^2+4xy+y^2$；(c) $f=x^2-4xy+4y^2$。

**参考答案**：

(a) $2(x^2+3xy)+5y^2=2\big[(x+\frac32y)^2-\frac94y^2\big]+5y^2=2(x+\frac32y)^2+\frac12y^2$——系数 $2,\frac12$ 全正 ⇒ **正定**。（对照：$\lambda=\frac{7\pm3\sqrt5}{2}>0$，谱判据同判。）
(b) $(x+2y)^2-4y^2+y^2=(x+2y)^2-3y^2$——一正一负 ⇒ **不定**（谱 $\{3,-1\}$）。
(c) $(x-2y)^2$——一个平方项、另一个系数 0 ⇒ **半正定**（谱 $\{0,2\}$；$f=0$ 不止原点：整条直线 $x=2y$）。

**A3.** Sylvester 判下列矩阵：(a) $\begin{pmatrix}3&1\\1&3\end{pmatrix}$；(b) $\begin{pmatrix}-2&1\\1&-2\end{pmatrix}$；(c) $\begin{pmatrix}0&1\\1&0\end{pmatrix}$；(d) $\begin{pmatrix}2&4\\4&2\end{pmatrix}$。

**参考答案**：

(a) $D_1=3>0,D_2=8>0$ ⇒ **正定**（谱 $\{2,4\}$）。
(b) $D_1=-2<0,D_2=3>0$ ⇒ 符号 $-,+$ 交替 ⇒ **负定**（谱 $\{-3,-1\}$）。
(c) $D_1=0$ ⇒ 链条一开始就断（正定要求严格 $>0$）⇒ **不是正定**；实际谱 $\{1,-1\}$ **不定**——$D_1=0$ 的启发：有零特征值或不定，但绝不是正定。
(d) $D_1=2>0,D_2=4-16=-12<0$ ⇒ **不定**（谱 $\{6,-2\}$）。

**A4.** $A=\begin{pmatrix}3&1\\1&3\end{pmatrix}$：判正定；求 $f=4$ 的椭圆的主轴方向与半轴长。

**参考答案**：

$\mathrm{tr}=6,\det=8$ ⇒ $\lambda=4,2$（和为 6 积为 8），全正 ⇒ 正定。特征向量：$\lambda=4$ 给 $(1,1)/\sqrt2$、$\lambda=2$ 给 $(1,-1)/\sqrt2$。半轴 $=1/\sqrt\lambda$ 乘 $\sqrt{c}$（$f=c=4$）：沿 $(1,1)/\sqrt2$ 半轴 $2/\sqrt4=1$；沿 $(1,-1)/\sqrt2$ 半轴 $2/\sqrt2=\sqrt2$。即椭圆 $y_1^2/1+y_2^2/2=1$（坐标轴即主轴）。

**B. 提高**

**B1.**（证明：Sylvester 必要性）设 $A$ 正定。证明每个顺序主子式 $D_k>0$。（提示：先证左上 $k\times k$ 子阵自己正定，再用"正定 ⇒ $\det>0$"；后者可用 $\det=\prod\lambda$ 或形变路径 $A_t=(1-t)A+tI$。）

**参考答案**：

第一步：对任意 $\vec x_k\neq\vec0$，把 $\vec x=(x_1,\dots,x_k,0,\dots,0)^T$ 代入：$\vec x^TA\vec x=\vec x_k^TA_k\vec x_k>0$——所以 $A_k$ 正定（同样的定义）。
第二步：正定 ⇒ $\det>0$。谱路线（本讲第六节已立）：$A_k$ 对称 ⇒ 特征值全实（谱定理⑦），正定给 $\lambda_i>0$（若 $\lambda_i\le0$，其单位特征向量 $\vec v$ 满足 $\vec v^TA_k\vec v=\lambda_i\le0$，矛盾），于是 $D_k=\det A_k=\prod\lambda_i>0$（第 11 讲账单）。■（若在第五节时点上作答，还可用形变引理代替谱路线——两条路都通向 $D_k>0$。）

**B2.**（证明：谱定理 ②）设 $A$ 对称，$A\vec v=\lambda\vec v$、$A\vec w=\mu\vec w$，$\lambda\neq\mu$。证明 $\vec v\perp\vec w$。

**参考答案**：

转移技巧。$\lambda\langle\vec v,\vec w\rangle=\langle A\vec v,\vec w\rangle=\vec v^TA^T\vec w=\vec v^T(A\vec w)=\langle\vec v,A\vec w\rangle=\mu\langle\vec v,\vec w\rangle$。所以 $(\lambda-\mu)\langle\vec v,\vec w\rangle=0$；$\lambda\neq\mu$ ⇒ $\langle\vec v,\vec w\rangle=0$。■（关键是 $A^T=A$ 允许 $A$ 在内积两边自由移动——非对称矩阵没有这个自由。）

**B3.**（证明：对称化与唯一性）(a) 对任意矩阵 $A$ 与反对称 $S$，证明 $\vec x^TS\vec x=0$ 恒成立；(b) 证明：若对称矩阵 $A,B$ 满足 $\vec x^TA\vec x=\vec x^TB\vec x$（一切 $\vec x$），则 $A=B$。

**参考答案**：

(a) $\vec x^TS\vec x$ 是数 ⇒ 等于自己的转置 $=\vec x^TS^T\vec x=-\vec x^TS\vec x$ ⇒ $2\vec x^TS\vec x=0$ ⇒ 恒为零。
(b) 取 $\vec x=\vec e_i$：$a_{ii}=b_{ii}$（对角全同）；取 $\vec x=\vec e_i+\vec e_j$：左边 $=a_{ii}+a_{jj}+2a_{ij}$、右边 $=b_{ii}+b_{jj}+2b_{ij}$，对角已同 ⇒ $a_{ij}=b_{ij}$。所以每个元素相同，$A=B$。■（合起来：二次型与对称矩阵一一对应——(a) 说明对称部分决定一切，(b) 说明对称部分不会撞车。）

**B4.**（证明 + 解释）(a) 证明：对任意矩阵 $A$，$A^TA$ 恒半正定；若 $A$ 的列线性无关，则 $A^TA$ 正定。(b) 用一句话解释这与第 15 讲"正规方程的解是碗底"的关系。

**参考答案**：

(a) $\vec x^T(A^TA)\vec x=(A\vec x)^T(A\vec x)=\|A\vec x\|^2\ge0$（半正定）；等号成立 ⟺ $A\vec x=\vec0$ ⟺（列无关时）$\vec x=\vec0$（第 08/09 讲：列无关 ⟺ 零空间只有零）。所以列无关时正定。■
(b) $\mathrm{SSE}(\vec x)=\|\vec b-A\vec x\|^2=\vec x^T(A^TA)\vec x-2(A^T\vec b)^T\vec x+\vec b^T\vec b$：二次部分正定 ⇒ 开口向上的碗，唯一最低点就是 $A^TA\hat{\vec x}=A^T\vec b$ 的解——15 讲的"唯一性"从"$A^TA$ 可逆"升级为"碗的形状"。

**C. 综合**

**C1.** ★ numpy 三堂会审：对 $f=2x^2+4xy+5y^2$ 复跑三条判据：(a) 配方恒等式在三个非整数点上对账；(b) 顺序主子式与 `eigvalsh` 全打印；(c) 再随机取一个 3×3 对称矩阵（固定种子），三路（配方思路太难就只用 Sylvester 与谱）对账判类型。

**参考答案**：

```python
import numpy as np
rng = np.random.default_rng(16)
A = np.array([[2., 2.], [2., 5.]])
pts = [(0.3, -0.7), (1.1, 2.3), (-0.4, 0.9)]
for x, y in pts:
    l = 2*x*x + 4*x*y + 5*y*y
    r = 2*(x+y)**2 + 3*y*y
    print(l, r)                    # 两组数逐点零差
print(np.linalg.det(A[:1,:1]), np.linalg.det(A))   # 2.0, 6.0 (>0: 正定)
print(np.linalg.eigvalsh(A))       # [1. 6.] 全正, 同判
B = rng.normal(size=(3, 3)); B = (B + B.T)/2
d = [np.linalg.det(B[:k,:k]) for k in (1, 2, 3)]
print(d, np.linalg.eigvalsh(B))    # 对照: D 全正 <=> 谱全正
```
读数：主例恒等式零差、$D=(2,6)$ 与谱 $(1,6)$ 同判；随机 3×3 的坐标对账里，**$D$ 全正与谱全正是同一张判决书**（异号同现、全正同现）。

**C2.** ★ numpy 谱定理实测：随机 5×5 对称阵验证 $A=Q\Lambda Q^T$ 与 $Q^TQ=I$；再取同规模非对称阵，打印其特征值（观察复数对）与特征向量矩阵不正交度，并写一句话结论。

**参考答案**：

```python
import numpy as np
rng = np.random.default_rng(16)
S = rng.normal(size=(5, 5)); S = (S + S.T)/2
w, Q = np.linalg.eigh(S)
print(np.abs(Q @ np.diag(w) @ Q.T - S).max())   # 1.1e-15
print(np.abs(Q.T @ Q - np.eye(5)).max())        # 1.0e-15
N = rng.normal(size=(5, 5))
wn, V = np.linalg.eig(N)
print(np.round(wn, 3))                          # 含复数对 (1.602+0.704j) 等
print(np.abs(V.conj().T @ V - np.eye(5)).max()) # 0.750
```
读数：对称的谱分解是恒等式（零差级）；非对称的对照里特征值逃出实轴、特征向量互相斜着——**"实、正交、齐"三件事没有一件是白给的**。

**C3.** ★ numpy 椭圆半轴：取 $A=\begin{pmatrix}1&2\\2&1\end{pmatrix}$（不定）与 $C=\begin{pmatrix}3&1\\1&3\end{pmatrix}$（正定），对各自 $f=4$：(a) 打印谱；(b) 验证"沿第 $i$ 特征方向、距原点 $2/\sqrt{\lambda_i}$ 的点恰在 $f=4$ 上"；(c) 对 $C$ 再用参数化 $\vec x=\frac{2\cos t}{\sqrt{\lambda_1}}\vec q_1+\frac{2\sin t}{\sqrt{\lambda_2}}\vec q_2$ 扫三个 $t$ 验证 $f\equiv4$。

**参考答案**：

```python
import numpy as np
for M in [np.array([[1.,2.],[2.,1.]]), np.array([[3.,1.],[1.,3.]])]:
    w, Q = np.linalg.eigh(M)
    print(w)                                    # 不定: [-1. 3.]; 正定: [2. 4.]
    for i in range(2):
        p = 2/np.sqrt(abs(w[i])) * Q[:, i]      # 沿第 i 特征方向, 距离 2/sqrt|lambda_i|
        print(p @ M @ p)                        # 4.0 (f=4 上的顶点)
C = np.array([[3.,1.],[1.,3.]]); w, Q = np.linalg.eigh(C)
for t in (0.4, 1.3, 2.2):
    p = 2*np.cos(t)/np.sqrt(w[0])*Q[:,0] + 2*np.sin(t)/np.sqrt(w[1])*Q[:,1]
    print(p @ C @ p)                            # 4.000000 全同
```
读数：不定例的"顶点"在谱为负的方向上——那是双曲线的顶点（$f=4$ 的曲线沿 $|w|$ 大的方向张口）；正定例参数化整圈 $f\equiv4$。**半轴 $=2/\sqrt{\lambda_i}$ 的规矩在两组例子里都实测落账**。
