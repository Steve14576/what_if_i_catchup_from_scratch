## 一、任务开场：把"无穷多解"写成"全体"

看矩阵（它就是"很多方程其实只有一条有用"的典型）

$$A = \begin{pmatrix}1&2&3\\2&4&6\\1&2&3\end{pmatrix},\qquad A\vec x=\vec 0$$

第 03 讲你会说：消元后剩 $\left[\begin{array}{ccc}1&2&3\\0&0&0\\0&0&0\end{array}\right]$，"有无穷多解，$x_2,x_3$ 自由"。没错，但"无穷多"三个字什么都没描述。**我们想要一个能装下所有解、还能看清它形状的对象。**

把方程 $x_1+2x_2+3x_3=0$ 解出 $x_1=-2x_2-3x_3$，令 $x_2=s,\ x_3=t$：

$$\vec x = s\begin{pmatrix}-2\\1\\0\end{pmatrix} + t\begin{pmatrix}-3\\0\\1\end{pmatrix}$$

**全体解 = 这两个向量的所有线性组合**（第 01 讲的 span！）。它是一张过原点的**平面**。这一讲就是把这套描述系统化：那张平面叫 **零空间**，"两个方向"里的"2"和"消元后剩下 1 条有用方程"里的"1"，都由一个叫**秩**的数牵起来。

> 下一站：先把秩立起来——它到底是什么、怎么数。

## 二、秩 rank：数"独立信息"的个数

**定义（可操作版）**：矩阵 $A$ 的**秩（rank）**，记 $\mathrm{rank}(A)$，是它化行成阶梯形（REF）后的**主元个数**，也就是上一节里"$1$"那个数——真正独立、不冗余的方程/信息的条数。

上面 $A$ 化简后只有 1 个主元，所以 $\mathrm{rank}(A)=1$（numpy 实测亦给 `rank(A)=1`）。

**秩的几种等价说法（同一件事的不同眼光，随讲次逐步兑现）**：

| 说法 | 现在可以这样理解 | 何时严格化 |
|---|---|---|
| 主元个数 | 消元后不为 0 的阶梯行数 | 本讲（定义） |
| 行秩 = 独立的行数 | 有多少行"互相拼不出对方" | 第 08 讲（线性无关） |
| 列秩 = 独立的列数 | 有多少列是真正新的方向 | 第 08、09 讲 |
| 列空间的维数 | $A$ 的列能张出多大的空间 | 第 09 讲 |
| 非零特征值个数（可对角化时） | 变换"没压扁掉"的维度数 | 第 11、12 讲 |

**⚠ 惊艳点（回答第 4 个疑问）：行秩 = 列秩。** 你可能犯嘀咕："行数和列数常常不一样（比如 $2\times5$），凭什么'独立的行数'恰好等于'独立的列数'？" 这不是显然的，是线性代数的一条**定理**：对任意矩阵，独立的行数 = 独立的列数。正因如此，"秩"这个数才**不需区分行还是列、定义良好**。你现在只需接受"秩既是行方向的个数也是列方向的个数，两者相等"，证明用到第 09 讲。**反例直觉都造不出，恰恰说明它不平凡。**

**怎么算秩（手算流程）**：消成 REF，数主元。秩满足：
- $\mathrm{rank}(A)\le\min(m,n)$（独立方向不会超过行数、也不会超过列数）。
- 方阵：$\mathrm{rank}=n$ 叫**满秩**（第 06 讲会证：满秩 ⇔ 可逆 ⇔ 行列式≠0）。

**破天真问题（回答第 7 问）：秩 = 1 不等于"只有一个非零元素"。** 上例 $A$ 有 9 个元素全非零，但秩只是 1——因为其余 8 个"信息"都能由第一行 $[1,2,3]$ 生成。秩数的是**独立方向**，不是**非零格子的个数**。

## 三、零空间与秩-零化度定理

**齐次系统 $A\vec x=\vec 0$ 的解集**，叫 $A$ 的**零空间（null space / kernel）**，记 $N(A)$：

$$N(A) = \left\{\ \vec x \;:\; A\vec x = \vec 0\ \right\}$$

**为什么它是个"空间"（子空间直觉）**：若 $\vec u,\vec v$ 都满足 $A\vec{\ }=\vec 0$，则 $A(\vec u+\vec v)=A\vec u+A\vec v=\vec 0+\vec 0=\vec 0$，$A(c\vec u)=cA\vec u=\vec 0$——**解加还是解、解缩放还是解**，还一定含 $\vec 0$。所以 $N(A)$ 是过原点的、"能加能缩放"的集合（严格的"子空间"定义在第 07 讲）。几何上它就是一条过原点的线 / 一个过原点的平面 / 整个空间。

**怎么求 $N(A)$ 的一组"生成方向"（基）**：消成 REF → 标出自由变量 → **每次只让一个自由变量 =1、其余自由变量 =0**，回代出主元变量，得到一个解向量；有几个自由变量就得几个方向。上一节 $s,t$ 两个方向就是这么来的。

**秩-零化度定理（rank-nullity theorem）**——本讲的定海神针：

$$\underbrace{r}_{\text{主元数}=\mathrm{rank}(A)} \;+\; \underbrace{(n-r)}_{\text{自由变量数}=\dim N(A)} \;=\; n$$

说人话：**未知数的总个数 $n$，一半被主元"占用"（等于秩 $r$），剩下的全成了可以自由取值的"方向"（零空间的维数）。** 实测里 $r=1$、$\dim N(A)=2$、$1+2=3=n$ 精确对上（脚本 CASE1）。

> 这里"$\dim$（维数）"你先当"需要几个方向才能张成它"，严格定义第 08 讲给。

> 下一站：右端不是 $\vec 0$ 时，解集结构怎样？——特解 + 零空间。

## 四、非齐次解的结构：通解 = 特解 + 零空间

现在看 $A\vec x=\vec b$，$\vec b\ne\vec 0$，且**假设有解**。核心结论：

$$\boxed{\ \{\text{全部解}\} = \{\text{一个特解 } \vec p\} + N(A)\ } \quad\text{即}\quad \vec x = \vec p + \vec x_h,\ \ \vec x_h\in N(A)$$

**为什么（一段能复述的证明）**：设 $\vec p$ 是 $A\vec x=\vec b$ 的某个解，$\vec x$ 是**任意**一个解。则
$$A(\vec x-\vec p) = A\vec x - A\vec p = \vec b - \vec b = \vec 0 \ \Rightarrow\ \vec x - \vec p \in N(A)$$
记 $\vec x-\vec p=\vec x_h$，就得 $\vec x=\vec p+\vec x_h$。反过来，任何 $\vec p+\vec x_h$（$\vec x_h\in N(A)$）都满足 $A(\vec p+\vec x_h)=\vec b+\vec 0=\vec b$。两边互相包含，证毕。**这条"两解之差落在零空间"的推理，你要能自己说出来**——它是整个解结构定理的命门。

**具体例子（相容）**：仍用上例 $A$，取 $\vec b=(1,2,1)$（注意它满足"第2分量=2×第1、第3=第1"，正好落在 $A$ 的列张成的空间里，故相容）。令自由变量先取 0，得主元变量 $x_1=1$，得一个**特解** $\vec p=(1,0,0)$。通解就是
$$\vec x = \vec p + s\,(-2,1,0) + t\,(-3,0,1),\qquad s,t\in\mathbb R$$
脚本实测：取 $s=2,t=-1$，通解 $\vec x=(0,2,-1)$，回代 $A\vec x=(1,2,1)=\vec b$，✓。

**几何图像**：零空间是过原点的平面；加上特解 $\vec p$ 后，解集是**把这个平面平移**、不再过原点的另一张平面。"两个不同特解之差"正好是平移方向之一，落回 $N(A)$。

## 五、解的三种命运：秩判据总表

把第 03 讲"看阶梯形"的判断，升级成纯秩的语言（$r=\mathrm{rank}(A)$，$r^*=\mathrm{rank}([A\mid\vec b])$）：

| 情形 | 判据 | 解的个数 / 结构 |
|---|---|---|
| 无解（不相容） | $r < r^*$ | $\vec b$ 不在列空间里 |
| 唯一解 | $r = r^* = n$ | 零空间只剩 $\vec 0$，故特解唯一 |
| 无穷多解 | $r = r^* < n$ | 通解 = 特解 + 零空间，自由参数 $n-r$ 个 |

记忆：**先看 $r$ 和 $r^*$ 是否相等（判有没有解），再看 $r$ 是否等于 $n$（判唯一还是无穷）**。

- 齐次 $A\vec x=\vec 0$ 永远有 $\vec x=\vec 0$ 这个解，所以它只会"唯一（$r=n$，零空间只有 $\vec 0$）"或"无穷（$r<n$）"，绝不会无解。
- $r=r^*=n$ 时 $N(A)=\{\vec 0\}$，这就是"唯一解"为何=特解唯一。

## 六、numpy 实测

脚本 `scripts/lec04-01_verify_rank_solution.py`（命令 `uv run --with numpy python scripts/lec04-01_verify_rank_solution.py`），对 $A=\begin{pmatrix}1&2&3\\2&4&6\\1&2&3\end{pmatrix}$ 实测：

```
rank(A)=1, n=3, 零空间维数应为 n-r=2

=== CASE1 齐次 Ax=0 零空间基 ===
  A@n1 = [0. 0. 0.]   A@n2 = [0. 0. 0.]       (n1=(-2,1,0), n2=(-3,0,1))
  n1,n2 线性无关? rank=2
  秩-零化度对账: 1 + 2 = 3 (= n)

=== CASE2 非齐次 Ax=b（相容, b=(1,2,1)）===
  rank(A)=1, rank([A|b])=1 -> 相容
  A@p = [1. 2. 1.]  (特解 p=(1,0,0))
  通解示例 p+2n1-n2 = [ 0.  2. -1.]   A@(该通解) = [1. 2. 1.] (=b)

=== CASE3 b 不在列空间 -> 无解 (b_bad=(1,0,0)) ===
  rank(A)=1, rank([A|b_bad])=2 -> 无解
```

**逐条对账**：CASE1 证实秩-零化度 $r+(n-r)=n$ 与零空间基正确；CASE2 证实"特解+齐次解"仍是解（结构定理的数值面）；CASE3 证实 $\vec b$ 跑出列空间时 $r<r^*$、判无解。**注意 $r^*$ 比 $r$ 大，正是因为多出 $\vec b$ 这一列带来了一个新方向**（它不在 $A$ 的列张成的空间里）。

## 七、边界与常见的坑（防错）

- **非齐次解集**$N(A)+\vec p$**一般不是子空间**（$A\vec x=\vec b$，$\vec b\ne\vec 0$ 时解集不过原点：$\vec 0$ 代入得 $A\vec 0=\vec 0\ne\vec b$）。它是"平移的子空间"（数学上叫**仿射集**，知道即可，不必记术语）。只有齐次解集才一定是子空间。
- **两个特解之差一定在零空间**（第四节的命门推理）。做题时若你找到两个不同解，别以为"解不唯一=有 bug"，它恰恰印证结构定理。
- **秩=1 不代表只有一个非零元素**（第二节已破）。秩看独立方向，不看格子计数。
- **$r=r^*$ 是"有解"的充要条件**，不是"唯一解"。唯一解要再加 $r=n$。别只比 $r,r^*$ 就宣布唯一。
- **$\mathrm{rank}(AB)\le\min(\mathrm{rank}A,\mathrm{rank}B)$**：复合只会让秩变小或不变（更多信息被压掉），这条以后判"乘完秩掉没掉"会用到，先记直觉。

> 收尾：齐次解集=零空间、非齐次=特解+零空间、秩-零化度把 $r,n$、自由变量数锁死。但"向量空间/子空间"的确切定义还没给（第 07 讲），"基、维数"也还没正式立（第 08 讲）。而眼下最该补的是方阵专属的"体积标尺"——**行列式**，它会在第 05、06 讲把"可逆"这件事彻底讲透。

## 本讲小结

- **秩 $\mathrm{rank}(A)$ = 主元个数 = 独立信息数**；满足行秩=列秩（不平凡的定理，本讲接受、第 09 讲证）；$\mathrm{rank}\le\min(m,n)$；方阵满秩 $\mathrm{rank}=n$。
- **零空间 $N(A)$** = 齐次 $A\vec x=\vec 0$ 的全体解，是过原点的子空间；用"自由变量轮流 =1"求出基。
- **秩-零化度定理**：$r+(n-r)=n$，即 秩 + 零空间维数 = 未知数个数。
- **非齐次解结构**：通解 = 特解 + 零空间；命门是"两解之差落在零空间"。几何上是零空间平移。
- **解的命运的秩判据**：$r<r^*$ 无解；$r=r^*=n$ 唯一；$r=r^*<n$ 无穷（自由参数 $n-r$）。
- **坑**：非齐次解集不是子空间；秩 1≠一个非零元；$r=r^*$ 只保证有解不保证唯一。

**B2.** 设 $A$ 是 $m\times n$，$A\vec x=\vec b$ 有**唯一**解。证明必有 $r=n$（提示：用"两解之差 ∈ 零空间"）。

<details><summary>参考答案</summary>

</details>

**C2.**（结构直觉）某网络流问题给你 $A\vec x=\vec b$，你发现一个可行方案 $\vec p=(5,3,2)$，又发现"绕环流"方向 $\vec h=(1,-1,0)$ 满足 $A\vec h=\vec 0$。（a）(4,4,2) 是不是也解？（b）这个方程组的解唯一吗？说理由。

<details><summary>参考答案</summary>
(a) $(4,4,2)=(5,3,2)+(-1)(1,-1,0)=\vec p-\vec h$，是通解形式，**是解**。（b）**不唯一**：只要存在非零 $\vec h$ 使 $A\vec h=\vec 0$，就有 $\vec p+c\vec h$ 无穷多个解（等价于 $r<n$、零空间非平凡）。工程直觉：能叠加"守恒的环流"就意味着方案可连续调整，必不唯一。
</details>
