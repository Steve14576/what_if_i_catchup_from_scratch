## 一、任务成品：主例的完整体检

本讲主人公——一个不起眼的 $2\times2$ 矩阵：

$$A=\begin{pmatrix}2&2\\-1&1\end{pmatrix}$$

它不对称（$A^T=\begin{pmatrix}2&-1\\2&1\end{pmatrix}\neq A$）、有负元素，第 16 讲的谱定理管不到它；但下面的体检表走完，你会拿到它的一切：

| 步骤 | 本例的数 | 用的机器 |
|---|---|---|
| 1. 算 $A^TA$ | $\begin{pmatrix}5&3\\3&5\end{pmatrix}$（两列长度平方 $5,5$、内积 $3$） | 第 13/15 讲 |
| 2. 谱（心算） | $\mathrm{tr}=10$、$\det=16$ ⟹ $\lambda=(2,8)$ | 第 11 讲两笔账 |
| 3. 奇异值 | $\sigma_1=\sqrt8=2.828427$、$\sigma_2=\sqrt2=1.414214$ | 本讲第三节 |
| 4. 右奇异向量 | $\vec v_1=\frac{1}{\sqrt2}(1,1)^T$、$\vec v_2=\frac{1}{\sqrt2}(-1,1)^T$ | $A^TA$ 的特征向量 |
| 5. 左奇异向量 | $\vec u_1=(1,0)^T$、$\vec u_2=(0,1)^T$（$\vec u_i=A\vec v_i/\sigma_i$） | 本讲第三节 |
| 6. 组装 | $A=U\Sigma V^T$，$U=I$、$\Sigma=\mathrm{diag}(2.828427,\,1.414214)$、$V$ 如上 | 本讲第三节 |
| 7. **三路自检** | $U^TU-I$：$2.2\times10^{-16}$；重构 $\|U\Sigma V^T-A\|$：$4.4\times10^{-16}$；$\sigma$ 降序 | 本讲纪律 |
| 8. 副产品 | $\det A=4=\sigma_1\sigma_2$；伪逆 $A^+=A^{-1}=\begin{pmatrix}0.25&-0.5\\0.25&0.5\end{pmatrix}$ | 第 05/06 讲回收、第七节 |
| 9. 几何 | 单位圆 ⟶ 半轴 $2.828427$、$1.414214$ 的椭圆（轴沿 $(1,0)$、$(0,1)$） | 第四节 |

（实测全中：重构零差、正交零差、$\sigma_1\sigma_2=\det A=4.000000$。）

和 16 讲一样，先看成品再补内功。但这一讲有一个必须你现在就消化的概念冲击：**$\vec u_i$、$\vec v_i$ 不是特征向量**——$A\vec v_i=\sigma_i\vec u_i$ 而不是 $A\vec v_i=\sigma_i\vec v_i$。SVD 的主角是两个不同的方向族：一个住在输入空间（$\vec v$），一个住在输出空间（$\vec u$），中间夹一个纯数 $\sigma_i$。为什么必须是两个族、能不能合成一个族——就是下一节的主题。

## 二、动机：非方阵没有特征值，"最大拉伸方向"还在吗

**特征值的三条局限**（回收第 11 讲的全部家底）：

1. **只对方阵出生**。$m\times n$（$m\neq n$）连 $A-\lambda I$ 都写不出来（$I$ 得是方的），特征值根本无从谈起。但 $2\times3$ 的矩阵照样是一台变换机器（02 讲面孔 4）——它也需要一份"工作报告"。
2. **非正规方阵会"骗人"**。看剪切矩阵 $S=\begin{pmatrix}1&3\\0&1\end{pmatrix}$：上三角，特征值 $=(1,1)$——"全部伸缩倍数都是 $1$"？可这个剪切明明把斜向量拉得很长。实测你以为的"没拉伸"是假象：$\sigma=(3.302776,\,0.302776)$，最狠的方向被拉了 $3.3$ 倍（EXP4）。
3. **非对称矩阵的特征向量不正交**。16 讲实测过：随机 $5\times5$ 非对称矩阵，特征向量矩阵的不正交度 $0.750$——特征基是一堆歪斜的方向，没法当坐标系用。

所以特征值只是方阵世界的一份"局部报告"。而几何的真相对**一切**矩阵成立：

> **任何矩阵都把单位球映成椭球**（降秩时退化成"扁的"，最扁的极端是线段或点）。

具体到 $\mathbb{R}^2\to\mathbb{R}^2$：单位圆 $\|\vec x\|=1$ 被 $A$ 打过去，得到一个**椭圆**；椭圆有几根轴、每根多长，这就是变换的完整档案。怎么找？问一个朴素问题：

**哪个方向的 $\vec x$ 被拉得最长？** 即最大化 $\|A\vec x\|$（$\|\vec x\|=1$）。平方展开：

$$\max_{\|\vec x\|=1}\|A\vec x\|^2=\max_{\|\vec x\|=1}\vec x^T(A^TA)\vec x$$

右边这个 $\vec x^TM\vec x$ 的形式，第 16 讲见过：**二次型**；最大化它的方向，正是 $M$ 的最大特征方向（16 讲第七节的球面论证：单位球上 $G'(0)=0$ 逼出 $A\vec v=\lambda\vec v$——注意那个论证已经在 $A^TA$ 身上用过一次了）。而这里的 $M=A^TA$ **恒对称半正定**（16 讲作业 B4 已证：$\vec x^TA^TA\vec x=\|A\vec x\|^2\ge0$）——谱定理保证它有完整的正交特征基（16 讲第七节）。

于是答案浮出水面：

$$\text{最大拉伸方向}=\ A^TA\ \text{的最大特征向量}\vec v_1,\qquad \text{拉长倍数}=\sqrt{\lambda_1}$$

第二个、第三个……拉伸方向同理是其余的特征向量。$\sqrt{\lambda_i}$ 就是**奇异值** $\sigma_i$ 的来历——"非方阵的特征值替身"，从 $A^TA$ 的谱里开根号长出来。这正是第 16 讲末尾钩子的兑现：**$A^TA$ 永远对称半正定，它的谱开根号就是奇异值。**

**回收第 11 讲**：还记得幂法吗？它迭代逼近的最大特征方向、以及第 16 讲"球面上 $2$ 万点采样贴住上下界"的实测——幂法和那些采样在追踪的，正是今天这个"最大拉伸方向"。当时它属于对称矩阵的故事；今天它拿到了通用的名字：$\sigma_1$ 与 $\vec v_1$。

> 下一站：光有方向和倍数还不够——把这两个族组装成完整的矩阵分解。

## 三、构造：从 $A^TA$ 到 $A=U\Sigma V^T$（谱定理的第二次出场）

**记号先立齐**（SVD 的四件套）：
- $A$：任意 $m\times n$ 矩阵，$\mathrm{rank}=r$。
- $\vec v_1,\dots,\vec v_n$：$A^TA$ 的单位正交特征向量，按特征值 $\lambda_1\ge\lambda_2\ge\cdots\ge\lambda_n\ge0$ 排列（$\ge0$ 是半正定逼的）。叫**右奇异向量**（它们住在输入空间 $\mathbb{R}^n$）。
- $\sigma_i=\sqrt{\lambda_i}$：**奇异值**，降序 $\sigma_1\ge\cdots\ge\sigma_n\ge0$；其中前 $r$ 个为正（$\lambda_i>0\iff$ 第 $i$ 个方向没被压扁），后 $n-r$ 个为零。
- $\vec u_i=\dfrac{A\vec v_i}{\sigma_i}$（$i\le r$）：**左奇异向量**（住在输出空间 $\mathbb{R}^m$），对零奇异值不定义，稍后补全。

**定理（SVD，奇异值分解）**：任何 $m\times n$ 实矩阵都能写成

$$A=U\Sigma V^T$$

其中 $U$（$m\times m$）与 $V$（$n\times n$）都是正交矩阵，$\Sigma$（$m\times n$）是"对角阵"（左上角 $\mathrm{diag}(\sigma_1,\dots,\sigma_r)$、其余全零）。

**证明（三段式，全部重活交给第 16 讲）**：

**① 拿到 $V$ 和 $\sigma$**：$A^TA$ 对称半正定 ⟹（16 讲谱定理）存在正交矩阵 $V$ 与对角 $\Lambda=\mathrm{diag}(\lambda_i)$ 使 $A^TA=V\Lambda V^T$，且 $\lambda_i\ge0$。开根号定义 $\sigma_i=\sqrt{\lambda_i}$。

**② 拿到前 $r$ 个 $\vec u$ 并验证它们正交**：对 $\sigma_i>0$ 定义 $\vec u_i=A\vec v_i/\sigma_i$。关键计算——先看内积：

$$\langle A\vec v_i,\ A\vec v_j\rangle=\vec v_i^TA^TA\vec v_j=\vec v_i^T(\lambda_j\vec v_j)=\lambda_j\langle\vec v_i,\vec v_j\rangle=\lambda_j\,\delta_{ij}$$

（$\vec v$ 们是标准正交的：同则内积 $1$、异则 $0$）。两边除以 $\sigma_i\sigma_j$（$i,j\le r$ 时为正）：

$$\langle\vec u_i,\vec u_j\rangle=\frac{\lambda_j}{\sigma_i\sigma_j}\delta_{ij}=\delta_{ij}$$

——前 $r$ 个 $\vec u$ 自动是一组**单位正交向量**。**注意这个计算的本质**：$A$ 一般把正交方向搞歪（非正交矩阵的特征向量就不正交），但 $A$ 作用在 $\vec v_i$ 这组特殊方向上时，保持了两两垂直——因为 $\vec v_i$ 是 $A^TA$ 的特征向量，歪斜量被 $A^TA$ 提前吸收掉了。

**③ 补全 $U$**：前 $r$ 个 $\vec u$ 是 $\mathbb{R}^m$ 里的单位正交组，还不够组成正交矩阵（除非 $r=m$）。补：在 $\mathbb{R}^m$ 里取与它们全正交的一组单位向量把基凑满（Gram-Schmidt 的精神，第 14 讲；凑法不唯一——这就是 $U$ 不唯一的第一来源）。补满后 $U=(\vec u_1,\dots,\vec u_m)$ 正交。

**④ 对账 $A=U\Sigma V^T$**：验证两个矩阵相等，最省的办法是让它们作用在基 $\vec v_1,\dots,\vec v_n$ 上逐列对上（右边 $=U\Sigma V^T\vec v_j=U\Sigma\vec e_j=\sigma_j\vec u_j$）：
- $j\le r$：按定义 $A\vec v_j=\sigma_j\vec u_j$ ✓；
- $j>r$：$\|A\vec v_j\|^2=\vec v_j^TA^TA\vec v_j=\lambda_j=0$，所以 $A\vec v_j=\vec 0=0\cdot\vec u_j$ ✓。

两边在整组基上一致 ⟹ 处处一致。$\blacksquare$

**把定理读一遍**：证明里的每一件重活——正交特征基的存在性（谱定理）、特征值非负（半正定）、补基（Gram-Schmidt）——全部来自前十六讲。SVD 自己没有新的"魔法"，它是**谱定理的第二形态**：第一个形态是 $A$ 对称时 $A=Q\Lambda Q^T$（16 讲第七节），第二个形态是 $A$ 任意时让 $A^TA$ 在幕后做对称工作，台前就有了两套基 $U,V$。

**full 版与 economy 版**（工程上要分清，实测 EXP3）：
- **完整版**：$U$ 是 $m\times m$、$V$ 是 $n\times n$、$\Sigma$ 是 $m\times n$（对角带零尾巴）。
- **经济版**（`full_matrices=False`）：只保留有用的 $k=\min(m,n)$ 列——$U$ 是 $m\times k$、$\Sigma$ 是 $k\times k$、$V$ 是 $n\times k$。低秩逼近场景里经济版是主角（多出来的列全乘零，没用还占地方）。
- 实测（EXP3，$3\times2$ 的 $B$）：完整版 $U$ 是 $3\times3$、经济版 $U$ 是 $3\times2$；两种版本重构误差都是 $5.6\times10^{-16}$。多出来的第三列 $\vec u_3\approx(-0.57735,\,0.57735,\,0.57735)$ 是步骤 ③ 补出来的——满足 $B^T\vec u_3=0$（实测零差）：它是**左零空间**的基（第 09 讲的名词，第八节回收）。

**实测（EXP1+EXP8）**：主例构造全程零差（重构 $4.4\times10^{-16}$、$U,V$ 正交性 $2.2\times10^{-16}$）；随机 $4\times6$ 矩阵同样成立（重构 $3.9\times10^{-15}$，$A^TA$ 的 $6$ 个谱开根号前 $4$ 个恰是 $\sigma$、后 $2$ 个为零）。

## 四、几何：旋转-缩放-旋转

把 $A=U\Sigma V^T$ 按"输入吃什么、输出吐什么"的顺序重写：

$$\vec y=A\vec x=U\underbrace{(\Sigma\underbrace{(V^T\vec x)}_{\text{第一步}})}_{\text{第二步}}$$

**三步动作，一步一句**：

1. **$V^T\vec x$——旋转**。$V$ 正交，正交矩阵 = 刚体运动（第 13 讲语言：保长度保角度）。$V^T$ 把输入坐标系的轴线掰到 $\vec v_1,\dots,\vec v_n$ 方向上——用 $\vec v$ 族当新坐标轴描述同一个 $\vec x$。几何上：旋转（或反射）。
2. **$\Sigma(\cdot)$——缩放**。对角矩阵各轴独立放缩（02 讲对角阵面孔）：第 $i$ 个新坐标乘 $\sigma_i$。拉伸最狠的轴乘 $\sigma_1$、最弱乘 $\sigma_n$；零奇异值把对应轴**压成零**。
3. **$U(\cdot)$——再旋转**。把缩放好的结果从坐标轴方向转到输出空间里 $\vec u_1,\dots,\vec u_m$ 的方向。同样保长度。

**一句话**：任何矩阵 = 旋转 $\to$ 沿坐标轴缩放 $\to$ 再旋转。缩放倍数就是奇异值，两个旋转的"铰链"就是 $U$ 和 $V$。

**主例实况**（EXP2 数字，椭圆怎么来的）：
- 输入方向 $\vec v_1=\frac{1}{\sqrt2}(1,1)^T$：$V^T$ 把它转到 $\vec e_1$；$\Sigma$ 乘以 $\sigma_1$：长度 $1\to2.828427$；$U$ 保持长度。所以 $\vec v_1$ 方向的像长 $=\sigma_1$。
- 输入方向 $\vec v_2=\frac{1}{\sqrt2}(-1,1)^T$：同理像长 $=\sigma_2=1.414214$。
- **单位圆 $2$ 万点全采样**：$\|A\vec x\|$ 的最小值 $1.414214$、最大值 $2.828427$——正好贴住 $[\sigma_2,\sigma_1]$（实测零差级）。椭圆的最长半轴 $=\sigma_1$（沿 $\vec u_1$ 方向）、最短半轴 $=\sigma_2$（沿 $\vec u_2$ 方向）。

**表格总览：形状决定几何**（$A$ 把输入空间的单位球打到输出空间）：

| $A$ 的形状 | 单位球（$\mathbb{R}^n$）$\longrightarrow$ | 读法 |
|---|---|---|
| $2\times2$ 满秩 | 圆 ⟶ 椭圆（半轴 $\sigma_1,\sigma_2>0$） | 最标准的情形 |
| $2\times2$ 降秩（$\sigma_2=0$） | 圆 ⟶ 线段（长 $2\sigma_1$） | 压扁方向：第 05/06 讲 $\det=0$ 的几何 |
| $3\times2$（高瘦，EXP3） | 圆 ⟶ 三维空间里**平面上的椭圆** | 升维不产生新方向：像仍住在二维平面（$\vec u_1,\vec u_2$ 张成的）里 |
| $2\times3$（矮胖） | 三维球面 ⟶ 平面椭圆（被压） | 降维必然压掉方向（至少 $n-m$ 个零奇异值） |

**回收第 02 讲**：矩阵的"变换机器"面孔（面孔 4）当时只能笼统说"扭、转、拉、压"；现在工作报告写清楚了：**全部动作 = 旋转 + 各轴拉伸 + 旋转**，拉伸账本 $=\sigma_i$ 序列。第 11 讲问"变换里方向不变只伸缩的向量是谁"——那是方阵的特权问题（$\vec v\to\lambda\vec v$ 同空间）；对任意矩阵，正确的问题是"**哪个输入方向被拉到最长的哪个输出方向**"（$\vec v_i\to\sigma_i\vec u_i$，两个空间各住一半）。

## 五、手算全程：考场版完整流程

### 5.1 主例六步（$2\times2$ 标准动作）

**第 1 步：算 $A^TA$**。$A=\begin{pmatrix}2&2\\-1&1\end{pmatrix}$，$A^TA=\begin{pmatrix}2\cdot2+(-1)(-1)&2\cdot2+(-1)\cdot1\\2\cdot2+1\cdot(-1)&2\cdot2+1\cdot1\end{pmatrix}=\begin{pmatrix}5&3\\3&5\end{pmatrix}$。（顺手的检查：$A^TA$ 必须对称——不对称就是算错了。）

**第 2 步：解特征多项式**。$\det(A^TA-\lambda I)=(5-\lambda)^2-9=\lambda^2-10\lambda+16$。心算口诀（第 11 讲两笔账）：和 $10$、积 $16$，拆出 $\lambda=2,\,8$。（验算：$2+8=10=\mathrm{tr}$ ✓，$2\cdot8=16=\det$ ✓。）

**第 3 步：开根号得奇异值**。$\sigma_1=\sqrt8=2\sqrt2\approx2.828427$、$\sigma_2=\sqrt2\approx1.414214$——**降序**排。

**第 4 步：求单位特征向量当 $\vec v$**。$\lambda=8$：$(5-8)x+3y=0\Rightarrow x=y\Rightarrow\vec v_1=\frac{1}{\sqrt2}(1,1)^T$。$\lambda=2$：$(5-2)x+3y=0\Rightarrow y=-x\Rightarrow$ 单位化取 $\vec v_2=\frac{1}{\sqrt2}(-1,1)^T$（取哪个符号都行，见 5.3）。

**第 5 步：$u_i=Av_i/\sigma_i$ 直接算**。
- $A\vec v_1=\frac{1}{\sqrt2}(2+2,\,-1+1)^T=\frac{1}{\sqrt2}(4,0)^T=(2\sqrt2,\,0)^T$；除以 $\sigma_1=2\sqrt2$ 得 $\vec u_1=(1,0)^T$。
- $A\vec v_2=\frac{1}{\sqrt2}(-2+2,\,1+1)^T=\frac{1}{\sqrt2}(0,2)^T=(0,\sqrt2)^T$；除以 $\sigma_2=\sqrt2$ 得 $\vec u_2=(0,1)^T$。
（顺带验算：$\|A\vec v_i\|$ 应恰为 $\sigma_i$——这里 $2\sqrt2$ 与 $\sqrt2$ ✓。）

**第 6 步：组装 + 验算**。

$$A=U\Sigma V^T=I\cdot\begin{pmatrix}2\sqrt2&0\\0&\sqrt2\end{pmatrix}\cdot\frac{1}{\sqrt2}\begin{pmatrix}1&-1\\1&1\end{pmatrix}=\begin{pmatrix}2&2\\-1&1\end{pmatrix}$$

还原成功。**验算三件套**（做完必查）：① $U,V$ 各自正交（$U^TU=I$、$V^TV=I$）；② 乘法还原回 $A$（实测 $4.4\times10^{-16}$）；③ $\sigma$ 降序非负。顺手一笔账：$\det A=4=\sigma_1\sigma_2$——方阵特有的对账（05 讲"行列式=体积缩放"的 SVD 版：所有轴的缩放倍数乘起来就是体积倍数）。

### 5.2 非方阵示范（$3\times2$，补 $\vec u_3$ 的技巧）

$B=\begin{pmatrix}1&1\\0&1\\1&0\end{pmatrix}$（实测 EXP3）。$B^TB=\begin{pmatrix}2&1\\1&2\end{pmatrix}$，特征值 $(1,3)$（和 $4$、积 $3$），$\sigma_1=\sqrt3\approx1.732051$、$\sigma_2=1$。特征向量同款：$\vec v_1=\frac{1}{\sqrt2}(1,1)^T$（$\lambda=3$）、$\vec v_2=\frac{1}{\sqrt2}(1,-1)^T$。
- $B\vec v_1=\frac{1}{\sqrt2}(2,1,1)^T$，$\vec u_1=\frac{B\vec v_1}{\sqrt3}=\left(\sqrt{\tfrac23},\,\tfrac{1}{\sqrt6},\,\tfrac{1}{\sqrt6}\right)^T\approx(0.816497,\,0.408248,\,0.408248)^T$；
- $B\vec v_2=\frac{1}{\sqrt2}(0,-1,1)^T$，$\vec u_2=(0,\,-\frac{1}{\sqrt2},\,\frac{1}{\sqrt2})^T$。

**$U$ 还缺一列（$m=3>r=2$）——补法二选一**：
- **正交补法**：解 $\vec u_1^T\vec x=0$、$\vec u_2^T\vec x=0$（即求 $[\vec u_1\ \vec u_2]^T$ 的零空间，第 04/09 讲机器），再单位化；
- **叉积法**（仅 $3$ 维可用）：$\vec u_3=\vec u_1\times\vec u_2$。手算一遍：$\vec u_1\times\vec u_2=\left(\frac{1}{\sqrt3},\,-\frac{1}{\sqrt3},\,-\frac{1}{\sqrt3}\right)^T$（用"单位正交 + 右手方向"验符号）。实测该列 $\approx(-0.57735,\,0.57735,\,0.57735)$——与手算差整体符号，**都合法**（见 5.3）。检查 $\|B^T\vec u_3\|=0$ 零差：补出来的方向与列空间正交，是左零空间基。

### 5.3 符号与顺序的约定（先打预防针）

SVD **不唯一**，考试按你算出的一致配对着写即可：
- **配对翻转**：$(\vec u_i,\vec v_i)$ 同时取反，$\sigma_i\vec u_i\vec v_i^T$ 不变——分解还是对的。主例的 $\vec v_2$ 取 $(1,-1)/\sqrt2$ 时 $\vec u_2$ 就是 $(0,-1)$；本讲取的是实测那组：$\vec v_2=(-1,1)/\sqrt2$、$\vec u_2=(0,1)$。**规矩**：一个符号翻转必须成对发生（翻转取决于你选的 $\vec v$，$\vec u$ 跟着变，不能各翻各的）。
- **重复奇异值**：$\sigma_i=\sigma_j$ 时对应二维平面里还可以任意旋转（比如主例换成 $A=I$：任何正交 $U$、$V=U$ 都是它的 SVD）。**奇异值序列本身是唯一的**（这是定理的结论），不唯一的是基的挑选。
- **顺序**：约定降序。考试若题目没给约定，把 $\sigma$ 降序写、$\vec u,\vec v$ 跟着排就行。

## 六、低秩逼近与 Eckart-Young：数据瘦身的最优解

### 6.1 把 $A$ 拆成一堆"秩一积木"

$A=U\Sigma V^T$ 还有一种更好用的展开方式——按**外积**摊开：

$$A=\sum_{i=1}^{r}\sigma_i\,\vec u_i\vec v_i^T$$

**怎么读出来的**（一行推导）：$U\Sigma$ 是把 $U$ 的各列乘上 $\sigma_i$（$n$ 列之后全为零）得到的矩阵，再乘 $V^T$ 就是"一行行摊开"：$\Sigma V^T$ 的第 $i$ 行是 $\sigma_i\vec v_i^T$，配上 $U$ 的第 $i$ 列 $\vec u_i$，得到 $r$ 块**秩一矩阵** $\vec u_i\vec v_i^T$ 的叠加（$\vec u\vec v^T$ 是第 02 讲的外积：任何 $\vec x$ 被它映到 $\vec u$ 方向的"一个标量倍"，像只占一条线）。

**读法**：矩阵 $=r$ 块积木按**重要性**堆叠——积木 $i$ 的大小是 $\sigma_i$、输入方向 $\vec v_i$、输出方向 $\vec u_i$。$\sigma$ 降序排列，就是按重要性排序。这是 SVD 全部威力的来源：**账本不只记数，还排好了序**。

### 6.2 截断与谱断崖

**截断 SVD**：只留前 $k$ 块积木，得 $A_k=\sum_{i\le k}\sigma_i\vec u_i\vec v_i^T$（秩 $\le k$，且实际秩 $=k$ 若 $\sigma_k>0$）。这就是**低秩逼近**：拿一个秩 $k$ 的矩阵假装 $A$。

**谱断崖**（实测 EXP6 的合成图，$64\times64$）：前 $6$ 个奇异值 $=(22.8376,\ 13.0408,\ 2.3301,\ 2.22,\ 2.1333,\ 2.0695)$——两个大、然后陡降一个数量级。看构造就明白：图里藏了两个正弦条纹（各自是精确的秩一外积），加了一点点噪声；两个条纹对应前两个 $\sigma$，噪声把尾部铺成一条"平底"（满秩，能量摊薄到几千个小 $\sigma$ 上）。**大 $\sigma$ 集中=信号，小 $\sigma$ 延绵=噪声**——断崖的高度差就是信噪比的眼睛。

**截到哪？** 断崖的位置通常就是答案：rank-$2$ 截断把两个条纹恢复得干干净净（误差 $9.3539$，恰好等于噪声本身的 Frobenius 范数量级），再往后加积木只能收噪声。这就是去噪的标准动作：**截断 = 只保留大 $\sigma$ 的积木**。

### 6.3 Eckart-Young 定理：截断是最优的

"只保留前 $k$ 块"凭什么是最优？这是 SVD 最著名的定理之一：

> **Eckart-Young**：对任何 $k$，在所有秩 $\le k$ 的矩阵 $B$ 中，$A_k$ 离 $A$ 最近：
> $$\min_{\mathrm{rank}(B)\le k}\|A-B\|_2=\sigma_{k+1}\quad(\text{由 }A_k\text{ 达到}),\qquad \min_{\mathrm{rank}(B)\le k}\|A-B\|_F=\sqrt{\sum_{i>k}\sigma_i^2}\quad(\text{同样由 }A_k\text{ 达到}).$$

两种距离记号先说明白（本讲新出现，一次立清）：
- **谱范数** $\|M\|_2=\max_{\|\vec x\|=1}\|M\vec x\|$——"最大拉伸倍数"，第四节几何立刻告诉你它 $=\sigma_1(M)$。
- **Frobenius 范数** $\|M\|_F=\sqrt{\sum_{ij}m_{ij}^2}$——把所有元素平方求和开根号，"逐元素版本的长度"。顺带一条恒等式：$\|M\|_F^2=\mathrm{tr}(M^TM)=\sum_i\lambda_i(M^TM)=\sum_i\sigma_i^2$（第二个等号是第 11 讲 $\mathrm{tr}=\sum\lambda$，第三个是 $\sigma$ 定义）。

**谱范数版完整证明**（很短，而且用到的全是学过的家伙）：
- **下界**：设 $B$ 任意，$\mathrm{rank}(B)\le k$。取 $W=\mathrm{span}\{\vec v_1,\dots,\vec v_{k+1}\}$（维数 $k+1$）。把 $B$ 限制在 $W$ 上看：像维 $\le\mathrm{rank}(B)\le k$，输入维 $k+1>$ 输出维 $\le k$，所以核非平凡（第 10 讲核像维数）——存在单位向量 $\vec x\in W$ 使 $B\vec x=\vec 0$。于是

$$\|A-B\|_2\ \ge\ \|(A-B)\vec x\|=\|A\vec x\|\ \ge\ \sigma_{k+1}$$

第一个不等号用谱范数是"取最大拉伸"（任何单位向量的像长都是下界）；最后一个不等号的推导：$\vec x\in W$ 时按 $\vec v$ 基展开 $\|A\vec x\|^2=\sum_{i\le k+1}\sigma_i^2(\vec v_i^T\vec x)^2\ge\sigma_{k+1}^2\sum_{i\le k+1}(\vec v_i^T\vec x)^2=\sigma_{k+1}^2\cdot1$（$\vec v$ 是标准正交基，括号求和 $=\|\vec x\|^2$）。
- **达到**：$\|A-A_k\|_2=\|\sum_{i>k}\sigma_i\vec u_i\vec v_i^T\|_2=\sigma_{k+1}$（尾部积木里最大的就是它）。

所有秩 $\le k$ 的 $B$ 都不小于 $\sigma_{k+1}$、而截断恰好等于 $\sigma_{k+1}$——谱范数版证毕。$\blacksquare$ **留意证明的性格**：它没有把 $B$ 掰开细看，只用了一个维数计数（像维不够 $\Rightarrow$ 核里有向量）就把所有竞争者一网打尽——这是"SVD 靠谱定理做主"之外的第二种 SVD 味道：**维数和极值论证**。

**Frobenius 版**：证明思路同类（对尾部能量做同样操作、配一层格外的精细估计），本课不展开，直接押结论；你有三件实测背书：① $\|A-A_k\|_F=\sqrt{\sum_{i>k}\sigma_i^2}$ 逐项零差（EXP6：rank-1 $16.0486$、rank-2 $9.3539$、rank-4 $8.7828$、rank-8 $7.7816$——两边打印完全同值）；② **采样检验**：$200$ 个随机生成的秩 $2$ 矩阵里离 $A$ 最近的一个误差 $74.7619$，远大于截断误差 $9.3539$（定理说"没有比截断更近的"，采样版全部落败）；③ 谱范数版已完整证明，且截断在两版里是同一个矩阵——同一个冠军拿了两个奖。

**存储账**（为什么工程界爱它）：$64\times64$ 的图全存 $4096$ 个数；rank-2 只需存两个 $\vec u$、两个 $\vec v$、两个 $\sigma$：$2\times(64+64+1)=258$ 个数——**$6.3\%$ 的存储，误差落在噪声水平**。图像越大优势越悬殊（大图里 $\sigma$ 衰减通常极快），这就是 SVD 图像压缩的全部原理。

**回收第 08 讲（支票兑现）**：第 08 讲作业里那组数据 $f_2=2f_1$、$f_3=f_1$——**精确冗余**：删掉相关列，列空间不降、信息零损失。但现实数据大多是**近似冗余**：第 3、4 个奇异值很小但非零——"差不多重复"的方向。删还是不删？Eckart-Young 给出标准答案：**删掉小 $\sigma$ 的积木，代价恰是 $\sqrt{\sum_{\text{被删}}\sigma_i^2}$，且在一切同秩矩阵里它是最小的**。"列空间=真正承载数据的方向"由此升级：**大 $\sigma$ 的方向承载数据、小 $\sigma$ 的方向承载噪声或冗余——瘦身从"删严格零"进化为"截谱"**。

## 七、伪逆 $A^+$：第 15 讲的牌位揭幕

### 7.1 从"逆不够用"到伪逆

三笔旧账翻出来：
- **第 06 讲**：只有方阵谈得上双边逆；长方阵最多有左逆或右逆，"没有一般意义的伪逆之外的救法"——当时的原话是"伪逆在第 17 讲正式造"。
- **第 15 讲**：$A^TA$ 奇异（$A$ 列相关）时，最小二乘解**不唯一**（解集是一条直线），但"想拿一个代表性的解"需要武器——当时留的牌位写着：伪逆 $A^+$ 挑**长度最短**的那个解。
- **第 13 讲**：列相关时投影矩阵公式 $A(A^TA)^{-1}A^T$ 失效（$A^TA$ 不可逆），"或走伪逆路"。

今天造这个武器。**定义**：

$$A^+=V\Sigma^+U^T$$

其中 $\Sigma^+$ 是 $\Sigma$ 转置形状、把**非零**奇异值取倒数、零保持零：$\Sigma^+=\mathrm{diag}\left(\frac1{\sigma_1},\dots,\frac1{\sigma_r},0,\dots,0\right)$（$n\times m$）。

**为什么是"转置 + 取倒数 + 零保零"**：满秩方阵时 $A^{-1}=V\Sigma^{-1}U^T$——逆的含义是"反着做三步"：$U$ 反旋转、$\Sigma$ 反缩放（$1/\sigma_i$）、$V$ 反旋转。长方阵或降秩时，"反缩放"里出现 $1/0$——那个方向的信号已经在压扁时丢掉了，**任何数都反拉不回来**；伪逆的立场：**不编造，给零**（声明"这个方向我无法恢复"），其余方向照常反缩放。所以伪逆 = "能做主的尽量做主、做不了主的老实说做不了主"的广义逆。

### 7.2 四条 Moore-Penrose 性质

$A^+$ 由四条性质**唯一**刻画（Moore-Penrose 条件）：

$$AA^+A=A,\qquad A^+AA^+=A^+,\qquad (AA^+)^T=AA^+,\qquad (A^+A)^T=A^+A$$

- 第 1 条：$A^+$ 是"合格的反向工作者"——用它去乘，至少不破坏原变换；
- 第 2 条：$A^+$ 自己不被浪费——对 $A^+$ 而言 $A$ 也是它的"伪逆"（对称身份）；
- 第 3、4 条：$AA^+$ 与 $A^+A$ 都是**对称**矩阵——投影该有的样子（第 13 讲：正交投影矩阵对称）。

实测（EXP7，随机 $4\times3$）：四条性质偏差 $7.8\times10^{-16}$、$4.4\times10^{-16}$、$7.8\times10^{-16}$、$4.0\times10^{-16}$——全在机器精度。**与逆的关系**（第 06 讲支票）：满秩方阵时 $A^+=A^{-1}$——实测主例 $A^+=\begin{pmatrix}0.25&-0.5\\0.25&0.5\end{pmatrix}$ 与 `inv(A)` 偏差 $2.2\times10^{-16}$。**长方阵的左/右逆也归位了**：列满秩时 $A^+=(A^TA)^{-1}A^T$（左逆）、行满秩时 $A^+=A^T(AA^T)^{-1}$（右逆）——把它们代进四条性质逐条验证即可（作业 B3 做第一式）。

### 7.3 与最小二乘的握手：最短那个解

- **超定方程** $A\vec x=\vec b$（无解）：第 15 讲的答案是"在列空间找最近点"。"最近点"的坐标不唯一时、以及唯一时，统一公式都是

$$\hat{\vec x}=A^+\vec b$$

实测（EXP7，$4\times2$ 超定例）：$A^+\vec b=(0.9,\,0.9)$，与正规方程解**完全一致**；代回自检 $A^T\vec e=$（零差）——最小二乘的全部纪律它一键满足。
- **15 讲坑例闭环**（$A=\begin{pmatrix}1&1\\1&1\end{pmatrix}$、$\vec b=(2,0)$，解集 $c+d=1$）：$A^+\vec b=(0.5,\,0.5)$——正是当初"挑最短解"的许诺。三个代表解实测对照：$(0.5,0.5)$ 长度 $0.707107$、$(1,0)$ 与 $(0,1)$ 长度都是 $1$，而残差**三家全同**（$1.414214$）。**伪逆 = 最小二乘解里"最短的那个"的选取器**：残差它不管（那是所有最小二乘解共同的最优），它管的是"解里不掺零空间的多余成分"。
- **几何真身**：$AA^+=U\Sigma\Sigma^+U^T$，而 $\Sigma\Sigma^+$ 是"前 $r$ 个对角为 $1$、其余为 $0$"的对角阵（$m\times m$），所以

$$AA^+=U_rU_r^T\qquad(U_r=U\ \text{的前}\ r\ \text{列})$$

——**到列空间的正交投影**（第 13/15 讲那个 $P=A(A^TA)^{-1}A^T$ 的 SVD 真身；列相关时旧公式失效，这个版本照常工作）。投影 + 伪逆 = 同一枚硬币：把 $\vec b$ 投影进列空间（$AA^+\vec b$ 是最佳预测），最短解是把这份投影翻译回坐标（$A^+\vec b$）。

## 八、SVD 与世界的接口

### 8.1 第 09 讲回收：四个基本子空间的正交基，一次配齐

第 09 讲算出四子空间的基要靠消元 + 技巧（转置、找正交补）；SVD 说：不用，两把正交基 $U,V$ 天然摊好了全部答案：

| 子空间 | 维数 | 正交基（SVD 白给） |
|---|---|---|
| 列空间 $\mathrm{col}(A)$ | $r$ | $U$ 的前 $r$ 列 $\vec u_1,\dots,\vec u_r$ |
| 左零空间 $N(A^T)$ | $m-r$ | $U$ 的后 $m-r$ 列 |
| 行空间 $\mathrm{col}(A^T)$ | $r$ | $V$ 的前 $r$ 列 $\vec v_1,\dots,\vec v_r$ |
| 零空间 $N(A)$ | $n-r$ | $V$ 的后 $n-r$ 列 |

**为什么**（两行验证）：$A=U\Sigma V^T$，看 $\vec v_j$（$j>r$）：$A\vec v_j=\sigma_j\vec u_j=\vec 0$——$V$ 的尾巴张成零空间 ✓；看 $\vec u_i$（$i>r$）：对一切 $\vec x$ 有 $\vec u_i^TA\vec x=\vec u_i^TU\Sigma V^T\vec x=(\Sigma V^T\vec x)_i=0$（$\Sigma$ 第 $i$ 行全零）——所以 $\vec u_i\perp\mathrm{col}(A)$，$U$ 的尾巴张成左零空间 ✓。

而且这四组基**同时正交**——第 09 讲的四子空间此前只有"维数对账"（$r$、$n-r$、$m-r$），正交基还要另配（13 讲正交补补一块、14 讲 GS 补一块）；SVD 一个分解全给齐，还顺手给出正交性。实测（EXP5，$3\times4$ 秩 2 的 $C$）：$\|C\vec v_3\|=2.0\times10^{-16}$、$\|C\vec v_4\|=8.6\times10^{-17}$（零空间两个基）、$\|C^T\vec u_3\|=5.6\times10^{-16}$（左零空间）、rank-nullity 对账 $2+2=4$——全中。

**一句话**：SVD 是四个基本子空间的"统一底片"——第 09 讲那张"线性代数基本定理"的图，正交版本就是 $U,V$ 两列队伍的分段图。

### 8.2 第 16 讲回收：对称矩阵的 SVD = 谱分解

- 对称矩阵：$A=Q\Lambda Q^T$（16 讲谱定理）。对照 SVD 取 $U=V=Q$、$\sigma_i=|\lambda_i|$——**完全兼容**（实测：对称 $\begin{pmatrix}2&1\\1&2\end{pmatrix}$ 的 $\sigma=(3,1)=|\lambda|$ 降序）。负特征值只贡献"符号"，被吸进 $U$ 的列里。
- 正定矩阵：$\lambda_i>0$，于是 $\sigma_i=\lambda_i$——SVD 与谱分解数值上重合；"正定平方根" $V\sqrt{\Lambda}V^T$ 恰好是 $\sqrt{A^TA}$ 的构造零件（16 讲原话），如今看懂它为什么是零件：$\sqrt{A^TA}=V\Sigma V^T$，把它塞进 $A=(A)(\cdots)$……更直白地说，$\Sigma$ 就是从 $\sqrt{A^TA}$ 的谱里直接"读出来"的。
- **非对称/非正规矩阵**：$\sigma$ 与 $\lambda$ 分道扬镳（剪切例 $\lambda=(1,1)$ vs $\sigma=(3.302776,0.302776)$，$\kappa=10.908327$）——SVD 是**任何**矩阵的形变真相，特征值只是可对角化部分的故事。

### 8.3 三大分解对照（一张表理顺）

| | 对角化 / 谱分解 | **SVD** | QR（第 14 讲） |
|---|---|---|---|
| 适用 | 可对角化方阵（对称最顺） | **任何矩阵** | 任何矩阵 |
| 形式 | $A=P\Lambda P^{-1}$；对称 $A=Q\Lambda Q^T$ | $A=U\Sigma V^T$ | $A=QR$ |
| 基 | 一组（非对称时不正交） | **两组正交** | 一正交 + 一三角 |
| 对角/标准形 | 相似意义下的对角 | 两组正交基下的对角 | 上三角 |
| 数值稳定性 | 一般（病态时糟） | **最稳** | 稳 |
| 典型用途 | 幂、动力学、振型 | 秩、低秩、子空间、伪逆、投影 | 正交化、最小二乘 |

## 九、心智模型与坑

### 9.1 三块铭牌

1. **任何矩阵 = 旋转-缩放-旋转**。两套正交基（输入 $\vec v$ 族、输出 $\vec u$ 族）夹一个对角账本（$\sigma$ 序列）。这是 SVD 的几何全部。
2. **奇异值 = 真实形变账本**。任何矩阵都有；非负；按大小排序恰好是"从最重要到最不重要"的信息顺序。特征值是方阵世界里会骗人的局部报告（剪切例）。
3. **排序截断 = 万能钥匙**。低秩逼近、去噪、压缩、伪逆全部是同一个动作：**对谱排序，决定留哪个、弃哪个**。$\sigma$ 大 = 留下来做主；$\sigma$ 小 = 舍掉（或"不反拉"）。

### 9.2 六个坑

1. **符号与配对**（5.3）：$(\vec u_i,\vec v_i)$ 翻转要成对；重复 $\sigma$ 时基更自由。奇异值序列唯一、基不唯一。
2. **$U$、$V$ 别搅混**：$V$ 的列住**输入**空间 $\mathbb{R}^n$（右奇异向量——名字来自它在公式**右边**），$U$ 的列住**输出**空间 $\mathbb{R}^m$。尺寸也对不上（$n$ 列 vs $m$ 列），一搅混处处错位。
3. **$\sigma$ 恒非负**：$\sigma=\sqrt{\lambda(A^TA)}\ge0$，符号不会出现在 $\sigma$ 里；特征值则可以负。所以"对称矩阵 $\sigma=|\lambda|$"里的绝对值不是装饰。
4. **非方阵的 $\Sigma$ 是"带形状的对角阵"**：$m\times n$，对角带跑到 $\min(m,n)$ 就停，右侧或下方是零块——写的时候数清行列。
5. **计算机上别用 `eigh(A^TA)` 当 SVD 用**：$A^TA$ 会把条件数**平方**（$\sigma_{\max}^2/\sigma_{\min}^2$），病态矩阵在平方这一步就把小奇异值的信息烧掉了；专业算法直接对 $A$ 做双对角化。numpy 一句话 `np.linalg.svd(A)` 就是正路（第 20 讲细说为什么）。
6. **排序截断的"最优"有范围**：Eckart-Young 保证的是**谱范数 / Frobenius 范数**意义下最优——换成别的度量（比如逐元素最大误差），截断不自动最优。别把定理说满。

**全讲串讲（一条线）**：非方阵没有特征值（动机）⟶ 但"单位球→椭球"照样成立（几何）⟶ 最大拉伸方向 = $A^TA$ 的最大特征方向（16 讲行李）⟶ 全套方向族 + 开根号得 $\sigma$ + $u=Av/\sigma$ 补全 = **$A=U\Sigma V^T$**（构造）⟶ 读成"旋转-缩放-旋转"（几何）⟶ 账本排好序 ⟶ 截断最优 = **低秩逼近**（Eckart-Young）⟶ 倒数替换 + 零保零 = **伪逆**（最小二乘最短解、列空间投影）⟶ 四子空间、对称谱、三大分解、应用地图一表打尽（接口）。**SVD = 谱定理穿上了"两套基"的西装，去任何矩阵的公司上班。**

1. **"非方阵没有特征值，'最大拉伸方向'还存在吗？"** → 第二节：存在——把"特征方向"问题升级为"$\|A\vec x\|$ 最大化"，答案住在 $A^TA$ 的谱里（16 讲行李落地）。

4. **"'旋转-缩放-旋转'几何上啥意思？"** → 第四节：$V^T$ 转进 $\vec v$ 坐标系、$\Sigma$ 各轴拉伸、$U$ 转出去；单位圆→椭圆，半轴 $=\sigma_i$。
5. **"低秩逼近为什么取前几个奇异值就最优？"** → 第六节：外积积木 + Eckart-Young（谱范数版给了完整证明，维数计数一招制敌）。
6. **"伪逆 $A^+$ 是啥？跟第 06 讲的逆、第 15 讲最小二乘啥关系？"** → 第七节：倒数替换+零保零的广义逆；满秩方阵时退化为逆，一般时给"最短最小二乘解"，其投影 $AA^+$ 独占列空间投影一职。
7. **"手算到底要会哪些？"** → 第五节：$2\times2$ 六步、3×2 补 $\vec u_3$、符号约定、验算三件套。
8. **"SVD 和特征分解、QR 怎么选？"** → 8.3 对照表 + 8.4 应用地图。
9. **"numpy 一句话怎么用？"** → `np.linalg.svd(A, full_matrices=False)`（经济版）；低秩截断 = 切 `s` 的尾巴；伪逆 `np.linalg.pinv`。

## 小结（一页）

- **定义链**：奇异值 $\sigma_i=\sqrt{\lambda_i(A^TA)}$（降序、非负）；右奇异向量 $\vec v_i$（$A^TA$ 特征向量，住输入空间）；左奇异向量 $\vec u_i=A\vec v_i/\sigma_i$（住输出空间）；$A=U\Sigma V^T=\sum\sigma_i\vec u_i\vec v_i^T$，任何矩阵（任何尺寸、任何秩）都有。
- **构造**：$A^TA$ 对称半正定 →（谱定理）$V,\Lambda$ → $\Sigma=\sqrt{\Lambda}$ → $\vec u=Av/\sigma$ 自动正交 → 补全 $U$（不唯一）→ 逐列对账成立。
- **几何**：$A$ = 旋转（$V^T$）- 缩放（$\Sigma$）- 旋转（$U$）；单位球→椭球；$\sigma$ = 半轴；$\sigma_{\min}=0$ = 压扁（降秩）。
- **三大用途**：① 四子空间正交基一次配齐（$U,V$ 分段）；② 排序截断 = 最优低秩逼近（Eckart-Young：误差 $=\sqrt{\sum_{i>k}\sigma_i^2}$、谱范数界 $\sigma_{k+1}$）；③ 伪逆 $A^+=V\Sigma^+U^T$：最小二乘最短解 + 列空间投影（$AA^+=U_rU_r^T$）一键双用。
- **对账**：对称时 $\sigma=|\lambda|$；方阵 $|\det|=\prod\sigma_i$；$\|A\|_F^2=\sum\sigma_i^2$；$\kappa=\sigma_1/\sigma_{\min}$；四子空间维数 $r,r,n-r,m-r$ 全由 $\sigma$ 的零/非零分段读出。

## 作业

**A. 基础**

**A1.** 对 $A=\begin{pmatrix}1&2\\2&1\end{pmatrix}$ 完整手算 SVD（六步法），并用验算三件套自检、用 $\det$ 对账。

**参考答案**：$A^TA=\begin{pmatrix}5&4\\4&5\end{pmatrix}$，$\det(A^TA-\lambda I)=\lambda^2-10\lambda+9\Rightarrow\lambda=(1,9)$（和 $10$、积 $9$ ✓）。$\sigma_1=3$、$\sigma_2=1$（降序）。$\lambda=9$：$-4x+4y=0\Rightarrow x=y\Rightarrow\vec v_1=\frac{1}{\sqrt2}(1,1)^T$；$\lambda=1$：$4x+4y=0\Rightarrow y=-x\Rightarrow\vec v_2=\frac{1}{\sqrt2}(1,-1)^T$。$A\vec v_1=\frac{1}{\sqrt2}(3,3)^T\Rightarrow\vec u_1=\frac{1}{\sqrt2}(1,1)^T$；$A\vec v_2=\frac{1}{\sqrt2}(-1,1)^T\Rightarrow\vec u_2=\frac{1}{\sqrt2}(-1,1)^T$（$\sigma_2=1$ 直接除）。验算：$U\Sigma V^T=\cdots=\begin{pmatrix}1&2\\2&1\end{pmatrix}$ ✓；$\det=1-4=-3$，$|\det|=3=\sigma_1\sigma_2$ ✓；$U,V$ 对称正交（$U=V$，两者相等也合法——对称矩阵的 SVD 与谱分解重合）。

**A2.** 对照"奇异值 vs 特征值"：对下列矩阵分别算出二者并说明差异：(a) $\begin{pmatrix}0&3\\0&0\end{pmatrix}$；(b) $\begin{pmatrix}2&0\\0&-3\end{pmatrix}$；(c) $\begin{pmatrix}1&1\\1&1\end{pmatrix}$。

**参考答案**：(a) 上三角 ⇒ $eig=(0,0)$；$A^TA=\begin{pmatrix}0&0\\0&9\end{pmatrix}\Rightarrow\sigma=(3,0)$——"特征值说没拉伸，$\sigma$ 说把一个方向拉成 3 倍"（nilpotent 的真相：把圆拍成线段）。(b) 对角矩阵：$eig=(2,-3)$、$\sigma=(3,2)$（$|{-3}|=3>2$，降序）——$\sigma=|\lambda|$ 且排序可不同。(c) $eig=(2,0)$；$A^TA=\begin{pmatrix}2&2\\2&2\end{pmatrix}$，谱 $(4,0)\Rightarrow\sigma=(2,0)$——两族一致（对称矩阵）。

**A3.** 已知某 $2\times2$ 矩阵的 SVD 为 $U=\begin{pmatrix}0&1\\1&0\end{pmatrix}$、$\Sigma=\mathrm{diag}(4,1)$、$V=\begin{pmatrix}1&0\\0&1\end{pmatrix}$。(a) 求 $A$；(b) 求 $\sigma_1,\sigma_2$、$\mathrm{rank}(A)$、$|\det A|$；(c) 单位圆被 $A$ 映成什么？

**参考答案**：(a) $A=U\Sigma V^T=\begin{pmatrix}0&1\\1&0\end{pmatrix}\begin{pmatrix}4&0\\0&1\end{pmatrix}=\begin{pmatrix}0&1\\4&0\end{pmatrix}$。(b) $\sigma=(4,1)$；$\mathrm{rank}=2$；$|\det|=4=4\cdot1$ ✓。(c) 椭圆，半轴 $4$（沿 $\vec u_1=(0,1)$）与 $1$（沿 $\vec u_2=(1,0)$）。

**A4.** 判断对错并说理由：(a) SVD 只对方阵存在；(b) 奇异值可能为负；(c) $U$ 和 $V$ 是唯一的；(d) 方阵满足 $|\det A|=\prod\sigma_i$；(e) $A^TA$ 的特征值开根号（降序）就是 $\sigma$；(f) 非零奇异值的个数等于 $\mathrm{rank}(A)$。

**参考答案**：(a) 错——任何矩阵都有（本讲定理），这正是它比特征值强的地方。(b) 错——$\sigma=\sqrt{\lambda(A^TA)}\ge0$，符号全在 $U,V$ 里。(c) 错——符号配对翻转、重复 $\sigma$ 时基更自由（5.3）；唯一的是 $\sigma$ 序列。(d) 对——05 讲体积账的 SVD 版。(e) 对——定义原话（注意含零尾巴，取 $\min(m,n)$ 个分量看）。(f) 对——$\sigma_i>0\iff$ 对应方向没被压扁 $\iff$ 维度没丢，个数 $=r$。

**B. 提高**

**B1.** 证明 $\|A\|_F^2=\sum_i\sigma_i^2$（提示：$\|A\|_F^2=\mathrm{tr}(A^TA)$，再用 $\mathrm{tr}=\sum\lambda$）。

**参考答案**：$\|A\|_F^2=\sum_{ij}a_{ij}^2=\sum_i(A^TA)_{ii}=\mathrm{tr}(A^TA)$（第 02 讲转置+乘法的逐元素读法）。$A^TA$ 对称，其谱 $=\lambda_i=\sigma_i^2$（16 讲谱定理保证特征值全实；第 11 讲 $\mathrm{tr}=\sum\lambda$）⟹ $\mathrm{tr}(A^TA)=\sum\sigma_i^2$。■

**B2.** 证明 $P=AA^+$ 是到列空间的正交投影：(a) $P^2=P$；(b) $P^T=P$；(c) $P$ 的像恰为 $\mathrm{col}(A)$。

**参考答案**：(a) 一步 MP1 即可：$AA^+AA^+=(AA^+A)A^+\overset{\text{MP1}}{=}AA^+$。或走 SVD 直读（两条路都值得会，$D$ 后面还要用）：$AA^+=U\Sigma\Sigma^+U^T$，记 $D=\Sigma\Sigma^+=\mathrm{diag}(1,\dots,1,0,\dots)$（前 $r$ 个 $1$），则 $P=UDU^T$，$P^2=UDU^TUDU^T=UD^2U^T=UDU^T=P$ ✓。(b) $P^T=UD^TU^T=UDU^T=P$ ✓。(c) $P$ 的像 $=U$ 前 $r$ 列张成的空间 $=\mathrm{col}(A)$（8.1 表）✓。三个条件齐了（第 13 讲投影三件套）⟹ 正交投影。

**B3.** 设 $A$ 列满秩。证明 $A^+=(A^TA)^{-1}A^T$。（提示：把 $A=U\Sigma V^T$ 代进去算右边。）

**参考答案**：列满秩时 $V$ 满正交、$\Sigma$ 的前 $n$ 个对角 $=\sigma_1..\sigma_n$ 全正（$n$ 列都独立）。$A^TA=V\Sigma^TU^TU\Sigma V^T=V\Sigma^2V^T$（$\Sigma^T\Sigma=\mathrm{diag}(\sigma_i^2)$ 全正），求逆：$(A^TA)^{-1}=V\Sigma^{-2}V^T$（正交矩阵逆=转置，第 13/14 讲）。于是 $(A^TA)^{-1}A^T=V\Sigma^{-2}V^T\cdot V\Sigma U^T=V\Sigma^{-1}U^T=A^+$（列满秩时 $\Sigma^+=\Sigma^{-1}$ 在非零段）。■（这就是 06 讲的"左逆"。）

**C. 综合**

**C1.** ★ numpy 主例全流程复跑：从 $A=\begin{pmatrix}2&2\\-1&1\end{pmatrix}$ 出发，(a) `eigh(A.T@A)` 取谱、开根号、按降序排；(b) 手工构造 $U=AV/\sigma$；(c) 验证 $U\Sigma V^T$ 还原与 $U,V$ 正交；(d) `pinv` 与手工四条 MP 性质对账。

**参考答案**：

```python
import numpy as np
A = np.array([[2., 2.], [-1., 1.]])
lam, V = np.linalg.eigh(A.T @ A)          # 升序 [2, 8]
sig = np.sqrt(lam[::-1]); V = V[:, ::-1]  # 降序
U = A @ V / sig
print(sig)                                 # [2.828427, 1.414214]
print(np.abs(U @ np.diag(sig) @ V.T - A).max())   # 4.4e-16
print(np.abs(U.T @ U - np.eye(2)).max(), np.abs(V.T @ V - np.eye(2)).max())  # 2.2e-16
Ap = np.linalg.pinv(A)
print(np.abs(A @ Ap @ A - A).max())        # 7.8e-16 级
print(Ap)                                  # [[0.25,-0.5],[0.25,0.5]]
```

**C2.** ★ 低秩逼近实验：自造 $50\times50$ 矩阵 = 两个正弦条纹（外积）+ $0.2$ 级噪声（固定种子）。(a) 打印前 8 个 $\sigma$，指出断崖位置；(b) 对 $k=1,2,4$ 计算截断误差并与 $\sqrt{\sum_{i>k}\sigma_i^2}$ 对账；(c) 随机造 100 个秩 2 矩阵验证"都不如截断近"；(d) 报存储账。

**参考答案**：

```python
import numpy as np
rng = np.random.default_rng(17)
x = np.arange(50.)
img = np.outer(np.sin(np.pi*x/8), np.cos(np.pi*x/10)) \
      + 0.6*np.outer(np.sin(np.pi*x/20), np.sin(np.pi*x/7)) \
      + 0.2*rng.normal(size=(50, 50))
U, s, Vt = np.linalg.svd(img)
print(np.round(s[:8], 3))                  # 断崖在前 2 个之后
for k in (1, 2, 4):
    ek = np.linalg.norm(img - U[:, :k] @ np.diag(s[:k]) @ Vt[:k, :])
    print(k, ek, np.sqrt((s[k:]**2).sum()))  # 逐项零差
best = min(np.linalg.norm(img - rng.normal(size=(50,2)) @ rng.normal(size=(2,50)))
           for _ in range(100))
print(best)                                # 远大于 rank-2 截断误差
print(50*50, 2*(50+50+1))                  # 2500 vs 202
```
