## 一、任务开场：老消元我其实会，这讲到底新在哪

解这个三元一次方程组：

$$\begin{cases} x + y + z = 6\\ 2x + 3y + z = 11\\ x - 2y + 3z = 6 \end{cases}$$

你高中就会：用第一个方程把 $x$ 表示出来、代进后面，或者两两相减消元。这讲**不发明新方法**，而是做三件事，让你从"会解这一道"升级到"会解任意一道、且知道有没有解"：

1. 把"消元"从**在方程之间写来写去**，压缩成**在一张数字表上机械操作**（不用每步都抄 $x,y,z$）。
2. 明确"每一步动表**为什么**合法"——这保证流程走到底一定不丢解、不增解。
3. 定义一个**标准终点**（行阶梯形），让"解的个数"变成看形状就能数出来的东西。

第 02 讲说过，这个方程组其实就是"$\vec b=(6,11,6)$ 能不能被 $A$ 的三列拼出来"。消元就是回答这个问题、并把拼法（$\vec x$）找出来的算法。

> 下一站：先把方程组翻译成一张能操作的表。

## 二、增广矩阵：把未知数暂时遮起来

三个方程里，真正在变的是**系数**和**右端常数**；$x,y,z$ 只是占位符号。于是把系数摆成矩阵 $A$、右端摆成列 $\vec b$，中间画一条竖线钉在一起——这就是**增广矩阵（augmented matrix）**，记作 $[\,A \mid \vec b\,]$：

$$\left[\begin{array}{ccc|c} 1&1&1&6\\ 2&3&1&11\\ 1&-2&3&6 \end{array}\right] \quad\begin{smallmatrix}\leftarrow x+y+z=6\\ \leftarrow 2x+3y+z=11\\ \leftarrow x-2y+3z=6\end{smallmatrix}$$

**怎么读**：每一**行**就是一个方程；前三列从左到右是 $x,y,z$ 的系数，竖线**右边**那一列是等号右边的常数。竖线就是"等号"的替身——所以**它不能省**，省了你就分不清哪个数是右端常数、哪个是某未知数的系数（尤其列数不等时）。

**为什么这么干（态度）**：解方程的全部信息都在这张表里，$x,y,z$ 这些字母是死信息。把字母扔掉、只操作数字，手算就快且不易错；这就是消元的"工作台"。你之前学的 $A\vec x=\vec b$ 里，$A\vec x$ 是"列的组合"——**而消元是从"行"的角度动手**，两条眼光会在第 04、09 讲汇合，现在你只需知道：行=方程，消元=对方程做等价变形。

> 下一站：对这张表能做哪些"不会把解改掉"的操作。

## 三、三种保解的行变换（外加一条"乘 0 为什么不行"）

只能对增广矩阵做下面**三种**初等**行变换（elementary row operations）**，它们各自对应方程的一条合法操作，所以**解集完全不变**（叫"同解变换"）：

| 行变换 | 对应方程操作 | 为什么保解 |
|---|---|---|
| ① 交换两行 $R_i\leftrightarrow R_j$ | 把两个方程换个顺序写 | 方程谁先谁后不影响解 |
| ② 某行乘**非零**常数 $R_i\to c\,R_i,\ c\neq0$ | 方程两边同乘一个非零数 | 两边同乘非零数不改变使等式成立的 $(x,y,z)$ |
| ③ 把某行加上另一行的倍数 $R_i\to R_i+k\,R_j$ | 把一个方程的 $k$ 倍加到另一个方程 | 等式 $=$ 等式仍是等式；新方程是旧方程的推论，且可逆回去 |

**记住"只有这三种"**——它们是等价变形的全部。三种都可**逆**（换回来、再乘回 $1/c$、减去 $k$ 倍），这就是"不丢解、不增解"的根本原因。

**回答那个天真问题：把某方程两边乘 0，行不行？** 不行！它**不属于**变换②（②明确要求 $c\neq0$）。乘 0 会把那一行变成 $0=0$，**方程的约束消失了、且不可逆**（你没法从 $0=0$ 恢复原方程）——解集会因此**被凭空放大**（丢信息）。变换③里"另一行的倍数"是加在**不同**的行上，被加的那行仍保留自己，所以不丢信息；这和"整行乘 0"是两码事。这条边界是消元合法性的命门，别糊过去。

> ⚠️ 一个易混点（防错）：变换③是"$R_i$ 加上 $R_j$ 的倍数"，$R_j$ **保持不变**。新手常写成"两行互换着减"最后把两行都改了——记住"被减的那行动、用来减的那行不动"。

> 下一站：用这三种操作把表消成"阶梯形"。

## 四、高斯消元：往行阶梯形(REF)走，手算一遍

**目标形状——行阶梯形（Row Echelon Form, REF）**：像下楼梯，每一行的**第一个非零数**（叫**主元 pivot**）都比上一行的主元靠右，主元下方的数全是 0。

对第二节的表走一遍（只用三种变换，挑整数最省的组合）：

$$\left[\begin{array}{ccc|c} 1&1&1&6\\ 2&3&1&11\\ 1&-2&3&6 \end{array}\right]$$

- 用第 1 行的主元 1 消掉它下面的：$R_2\to R_2-2R_1$，$R_3\to R_3-R_1$

$$\left[\begin{array}{ccc|c} 1&1&1&6\\ 0&1&-1&-1\\ 0&-3&2&0 \end{array}\right]$$

- 用第 2 行的主元 1 消掉它下面的：$R_3\to R_3+3R_2$

$$\left[\begin{array}{ccc|c} 1&1&1&6\\ 0&1&-1&-1\\ 0&0&-1&-3 \end{array}\right]\quad(\text{REF：主元 }1,1,-1\text{ 呈阶梯})$$

- **回代（back substitution）**（从最底行往上解）：
  - 第 3 行：$-z=-3 \Rightarrow z=3$
  - 第 2 行：$y - z = -1 \Rightarrow y = -1+3 = 2$
  - 第 1 行：$x + y + z = 6 \Rightarrow x = 6-2-3 = 1$

得 $\vec x=(1,2,3)$。第六节脚本末尾的 `[check] A1 @ (1,2,3) == [6,11,6]` 会在 numpy 里把解回代核对，一致。

**怎么算不出错的章法（好习惯）**：
- **选主元尽量挑 1 或 $-1$**（或先交换行把它换到主元位），能避免一堆分数。上例对角本就友好。
- 每次动一行，**在表旁边写下用的乘数**（如"$R_2-2R_1$"），万一算错能回溯。
- 只消**当前主元正下方**的数，别乱消；消完一行就"封口"不再动它。
- 每步做完，抽查"这一行的主元下方是不是 0 了"，再进下一列。

> 下一站：REF 的形状直接告诉你——解是唯一、没有、还是无穷多。

## 五、消元终点：解的三种命运，一眼判

把表消成 REF（或更彻底的 RREF，见第七节）后，看两点就定档：**有没有矛盾行**、**主元个数与未知数个数的关系**。

**(1) 无解（不相容 inconsistent）**：出现"$0 = \text{非零}$"的行，即系数全 0 但右端不为 0，形如 $\left[\begin{array}{ccc|c}0&0&0&5\end{array}\right]$。含义：几条方程互相打架，没有公共解。

$$\text{例：}\left[\begin{array}{ccc|c}1&1&1&3\\ 0&1&1&2\\ 0&0&0&-1\end{array}\right]\Rightarrow \text{末行 }0=-1,\ \text{无解}$$

**(2) 唯一解**：没有矛盾行，且**主元个数 = 未知数个数**（每个未知数都对应一个主元）。就是第四节那种。

**(3) 无穷多解**：没有矛盾行，但**主元个数 < 未知数个数**——有些列没有主元，对应的未知数叫**自由变量（free variable）**，可以任意取，每取一组值就得到一个解，所以无穷。

$$\text{例（本讲第二节那条含冗余的系统）REF 后：}\left[\begin{array}{ccc|c}1&2&3&6\\ 0&-1&-2&-3\\ 0&0&0&0\end{array}\right]$$

- 末行全 0（$0=0$，**相容**，不是矛盾）——它只是说"第三个方程没带来新约束"。
- $z$ 那列没有主元 → $z$ 是**自由变量**，记 $z=t$（任意实数）。
- 从第 2 行：$-y-2z=-3\Rightarrow y=3-2t$；从第 1 行：$x+2y+3z=6\Rightarrow x+2(3-2t)+3t=6\Rightarrow x=t$。
- 解集：$(x,y,z)=(t,\ 3-2t,\ t)$。取 $t=1$ 得 $(1,1,1)$，代回原三式都成立。

**自由变量为什么"能随便取"（直觉）**：没有主元=没有任何方程在"卡"这个未知数，它就是可自由设定的量；其余未知数（主元对应的，叫**基本变量**）再被方程反过来用自由变量表示。自由变量个数 = 未知数个数 $n$ − 主元个数 $r$。这个 $r$ 就是第 04 讲的主角：**秩**。

## 六、numpy 实测：三种命运 + 秩判据

脚本 `scripts/lec03-01_verify_gauss_elim.py` 对三个例子各自化到简化行阶梯形（RREF），并算 $\mathrm{rank}(A)$ 与 $\mathrm{rank}([A\mid\vec b\,])$。实测输出（节选）：

```
=== CASE1 唯一解 ===
--- 唯一: rank(A)=3 rank([A|b])=3 主元列=[0, 1, 2]
  RREF([A|b]) =
   [[1. 0. 0. 1.]
    [0. 1. 0. 2.]
    [0. 0. 1. 3.]]
  -> 唯一解 x=[1. 2. 3.]

=== CASE2 无穷解 ===
--- 无穷: rank(A)=2 rank([A|b])=2 主元列=[0, 1]     (第 2 列 z 无主元 -> 自由)
  -> 无穷多解，自由变量个数 = n - r = 1

=== CASE3 无解 ===
--- 无解: rank(A)=2 rank([A|b])=3 主元列=[0, 1, 3]   (主元出现在右端列 = 矛盾)
  -> 无解（不相容，rA < rA|b）

  [check] A1 @ (1,2,3) == [ 6. 11.  6.]   ✓
```

**读数与一条硬判据（Frobenius 相容性定理，第 04 讲会正式讲）**：

| 命运 | 阶梯形特征 | 秩判据 |
|---|---|---|
| 唯一解 | 主元个数 = $n$，无矛盾行 | $\mathrm{rank}(A)=\mathrm{rank}([A|\vec b])=n$ |
| 无穷解 | 主元个数 $r<n$，无矛盾行 | $\mathrm{rank}(A)=\mathrm{rank}([A|\vec b])=r<n$；自由变量 $=n-r$ |
| 无解 | 出现 $0=$非零 行 | $\mathrm{rank}(A)<\mathrm{rank}([A|\vec b])$（右端列多出一个主元，如 CASE3 主元列含 3） |

**注意 CASE2 的秩判据**：$\mathrm{rank}(A)=\mathrm{rank}([A|\vec b])=2<3$，和"无矛盾 + 自由变量 1 个"完全对上；CASE3 因为 $\mathrm{rank}$ 被右端那列顶到 3，才判无解。**"看阶梯形"和"比秩"是同一件事的两种读法**，秩那版更机械、更适合交给计算机——这正是为什么第 04 讲要专门把"秩"立起来。

## 七、高斯消元 vs 高斯-若尔当消元：两种终点

- **高斯消元（Gaussian elimination）**：消到 **REF**（主元下方为 0 即可），然后**回代**。手算更省（不必把主元上方也清零）。
- **高斯-若尔当消元（Gauss-Jordan elimination）**：继续消到 **简化行阶梯形 RREF**——每个主元都是 1，且主元**上下**都为 0。此时解**直接写在右端列**上，不用回代（第六节脚本用的就是 RREF：CASE1 直接读出 $[1,2,3]$）。

两者的**解一致**，只是终点不同。RREF 更"机器友好"（结果一眼读、且形状唯一），REF+回代更"手算友好"（步骤少）。

**RREF 的严格形状（记）**：① 非零行在零行之上；② 每行首个非零元（主元）为 1；③ 主元所在列的其他元素全为 0；④ 主元逐行右移。满足这四条的 RREF 对给定矩阵是**唯一**的——所以第 04 讲能用它来严格定义"秩 = 非零行(主元)个数"，不依赖你怎么消的顺序。

**边界预告（不在本讲展开）**：
- 未知数比方程多（欠定）或方程比未知数多（超定）怎么办——本讲的判据照样用（数主元、比秩），但"超定几乎必无精确解"会引出**第 15 讲最小二乘**。
- 大规模消元的数值稳定性（选主元、误差累积）——**第 20 讲数值线性代数**。

> 收尾：你现在能对任意 $A\vec x=\vec b$ 走完"增广→三种行变换→REF→回代/判命运"。但"解的结构"（为什么解=特解+齐次解）、"秩到底在数什么、为何 $n-r$ 是解空间维数"值得单独钉牢——第 04 讲。

## 本讲小结

- **增广矩阵 $[A|\vec b]$**：每行一个方程，竖线=等号、不能省。
- **三种保解行变换**：换行 / 某行乘**非零**数 / 某行加另一行倍数；都可逆所以同解。**乘 0 不在其列**（丢约束、放大解集）。
- **高斯消元**：用三种变换消到 **REF**（主元成阶梯、下方为 0），**回代**得解；选 $\pm1$ 主元、记乘数、逐列封口是防错章法。
- **三种命运一眼判**：有 $0=$非零行→无解；无矛盾且主元数=$n$→唯一；无矛盾且主元数$r<n$→无穷，**自由变量数 $=n-r$**。
- **秩判据**：$\mathrm{rank}(A)=\mathrm{rank}([A|\vec b])$ 相容（否则无解）；等于 $n$ 唯一、$<n$ 无穷。与"看阶梯形"等价，机械版留给计算机。
- **高斯(REF+回代) vs 高斯-若尔当(RREF 直读)**：解相同，终点不同；RREF 唯一，是第 04 讲定义秩的地基。

**A. 基础**

**A1.** 判断下列增广矩阵各自代表"唯一/无解/无穷"哪种，并说依据（不必解出）：
(a) $\left[\begin{array}{cc|c}1&2&3\\0&1&4\end{array}\right]$；(b) $\left[\begin{array}{cc|c}1&2&3\\0&0&5\end{array}\right]$；(c) $\left[\begin{array}{cc|c}1&2&3\\0&0&0\end{array}\right]$。

**参考答案**：

(a) **唯一**：两个主元（第1、2列）、无矛盾行，主元数=未知数数=2。
(b) **无解**：第2行是 $0=5$ 的矛盾行（$\mathrm{rank}(A)=1<\mathrm{rank}([A|b])=2$）。
(c) **无穷**：只有 1 个主元、$n=2$，无矛盾；自由变量数 $=2-1=1$（第2列无主元，$x_2$ 自由）。


**A2.** 用行变换把 $\left[\begin{array}{ccc|c}1&1&1&4\\2&3&1&12\\1&-1&2&-3\end{array}\right]$ 化为 REF，并回代求解。

**参考答案**：

$R_2\to R_2-2R_1$ 得 $[0,1,-1\,|\,4]$；$R_3\to R_3-R_1$ 得 $[0,-2,1\,|\,-7]$；再 $R_3\to R_3+2R_2$ 得 $[0,0,-1\,|\,1]$。
REF：$\left[\begin{array}{ccc|c}1&1&1&4\\0&1&-1&4\\0&0&-1&1\end{array}\right]$。
回代：第3行 $-z=1\Rightarrow z=-1$；第2行 $y-z=4\Rightarrow y=4+(-1)=3$；第1行 $x+y+z=4\Rightarrow x=4-3-(-1)=2$。
得 $\vec x=(2,3,-1)$。回代原三式核对：$2+3-1=4$✓、$2\cdot2+3\cdot3+(-1)=12$✓、$2-3+2(-1)=-3$✓。


**B. 提高**

**B1.** 含参数讨论：方程组
$$\begin{cases}x + y + z = 1\\ x + 2y + 2z = 2\\ x + 2y + a\,z = b\end{cases}$$
对 $a,b$ 取何值时：唯一解 / 无解 / 无穷多解？

**参考答案**：

增广消元：$R_2-R_1\to[0,1,1|1]$，$R_3-R_1\to[0,1,a-1\,|\,b-1]$，再 $R_3-R_2\to[0,0,a-2\,|\,b-2]$。
- $a\neq2$：第3行主元 $a-2\neq0$，三主元 → **唯一解**。
- $a=2$ 且 $b\neq2$：第3行变 $[0,0,0\,|\,b-2]$，$b-2\neq0$ → 矛盾 → **无解**。
- $a=2$ 且 $b=2$：第3行全 0 → 只有 2 个主元、$n=3$ → **无穷多解**（自由变量 $z=t$，$y=1-t$，$x=t$，可验 $x+y+z=1$）。


**B2.** 把第三节"无穷解"例子 $(x,y,z)=(t,3-2t,t)$ 写成"特解 + 参数×方向向量"的形式，并指出哪部分是齐次解。

**参考答案**：

$(x,y,z)=(0,3,0)+t(1,-2,1)$。$(0,3,0)$ 是原非齐次系统的一个**特解**；$(1,-2,1)$ 方向对应“把右端换成 0”的**齐次系统** $A\vec x=\vec 0$ 的解（三行都满足：$(1,2,3)\cdot d=1-4+3=0$、$(2,4,6)\cdot d=0$、$(1,1,1)\cdot d=1-2+1=0$）。齐次解构成一条过原点的直线，加上特解就是解集这整条平移后的直线——这正是第 04 讲“解=特解+零空间”的先声。


**C. 综合**

**C1.** ★ 用 numpy 验证 B1 三种情形：各取 $(a,b)$ 为 $(3,1)$、$(2,1)$、$(2,2)$，构造 $A,b$，打印 `matrix_rank(A)`、`matrix_rank(np.column_stack([A,b]))`，确认分别落在唯一/无解/无穷。

**参考答案**：

代码：
```python
import numpy as np
def ranks(a,b):
    A=np.array([[1,1,1],[1,2,2],[1,2,a]],float); bb=np.array([1,2,b],float)
    rA=np.linalg.matrix_rank(A); rAb=np.linalg.matrix_rank(np.column_stack([A,bb]))
    n=3
    if rA!=rAb: verdict="无解"
    elif rA==n: verdict="唯一"
    else: verdict="无穷"
    return rA,rAb,verdict
for ab in [(3,1),(2,1),(2,2)]:
    print(ab, ranks(*ab))
# 期望：(3,1)->(3,3,'唯一'); (2,1)->(2,3,'无解'); (2,2)->(2,2,'无穷')
```
秩与手工讨论一致，验证了"比秩"判据对含参系统同样管用。


**C2.**（应用）配平化学方程式 $\_\_\mathrm{C_3H_8}+\_\_\mathrm{O_2}\to\_\_\mathrm{CO_2}+\_\_\mathrm{H_2O}$：设系数 $a,b,c,d$，对 C、H、O 三种原子各列一条守恒方程，得到齐次线性方程组，消元后取最小正整数解。

**参考答案**：

原子守恒（右端移到左边=0）：
C: $3a-c=0$；H: $8a-2d=0$；O: $2b-2c-d=0$。
由前两条 $c=3a,\ d=4a$；代入 O 式：$2b=2(3a)+4a=10a\Rightarrow b=5a$。
取最小正整数 $a=1$：$(a,b,c,d)=(1,5,3,4)$。配平：$\mathrm{C_3H_8}+5\mathrm{O_2}\to3\mathrm{CO_2}+4\mathrm{H_2O}$。
核对：C 左3右3✓；H 左8右8✓；O 左10右$6+4=10$✓。
体会：配平=解**齐次**方程组（右端全 0），解空间非零（有自由变量 $a$），我们只是从中挑一组正整数代表。第 04 讲会把"齐次解集是子空间"讲透。
