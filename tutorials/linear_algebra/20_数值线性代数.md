## 二、浮点：计算机算术的真面目

### 2.1 0.1+0.2 不等于 0.3

先看现场（EXP1）：

```
0.1 + 0.2 = 0.30000000000000004   (用 ==0.3 判断: False)
```

这不是 bug，是**有限位数的必然**。计算机用二进制存数，双精度（64 位）能存 53 位二进制的"有效数字"。0.1 在二进制里是无限循环小数（$0.1=0.0001100110011\ldots{}_2$），存进去时被**截断**到第 53 位——你存下的已经不是精确的 0.1，而是"离 0.1 最近的、能表示的那个数"。0.2 同理。两个"近似 0.1"和"近似 0.2"相加，得到"近似 0.3 但差了一点"的数——差的这一点就是 $5.551\times10^{-17}$（EXP1 第二行读数：`0.1 + 0.2 - 0.3 = 5.551e-17`）。

白话版：想象十进制里只能写 8 位有效数字的袖珍计算器。1/3 = 0.33333333（截断了），三倍的 1/3 会得到 0.99999999 而不是 1。**浮点的本质就是"每个数都带着表示误差"，误差的相对大小在 $10^{-16}$ 附近（双精度）。**

### 2.2 eps 与浮点的结构

双精度 64 位的分配：1 位符号 + 11 位指数 + 52 位尾数。两个最重要的常数：

- **eps $=2^{-52}\approx2.22\times10^{-16}$**：1.0 和"比 1.0 大的最小可表示数"之间的距离。它也叫**机器精度**或**舍入单位 u**；
- 浮点数在 1 附近"网格间距"就是 eps；数值越大网格越粗（指数把间距放大），但**相对间距**各数量级都在 eps 级——记这一条就够。

EXP1 的两个小实验把这张网格摸清楚：

```
1 + eps/2 == 1 ?  True    (半个 eps 被舍掉)
1 + eps   == 1 ?  False   (一个整 eps 恰好进到网格下一个点)
```

准确地说：任何一次浮点运算（+ − × ÷）的结果，都是"精确结果四舍五入到最近的可表示数"。这个模型写成公式，是后续一切误差账的地基：

$$
\mathrm{fl}(a\ \mathrm{op}\ b)=(a\ \mathrm{op}\ b)(1+\delta),\qquad|\delta|\le \mathrm{eps}
$$

读法："**每次基本运算，结果相对精确值最多偏 eps**"。一句话记住：**双精度 = 十六位十进制有效数字的本钱**，任何放大都从这本钱里扣。

> **可以但没必要**：背 $2^{-52}$ 的十进制全位数、深究非规格化数/NaN/inf 的编码规则——遇到再查即可；这一节真正要建的是"$\mathrm{eps}$ 级相对误差"的量级感。

### 2.3 灾难性抵消：有效位数被当场吃掉

既然每次运算只偏 eps 级，怎么会出大问题？因为**减法会消掉相同的高位**。看 EXP1：

```
sqrt(1e16+1) - 1e8: 直算 = 0.000e+00,  等价变形 1/(sqrt+1e8) = 5.000e-09
```

真值是 $1/(\sqrt{10^{16}+1}+10^8)\approx5\times10^{-9}$。但直算时：$\sqrt{10^{16}+1}$ 的真值 $\approx10^8+5\times10^{-9}$——它和 $10^8$ 的**前十六位完全相同**，双精度存不下后面那点差值（$10^8$ 附近的网格间距是 $10^8\times\mathrm{eps}\approx2.2\times10^{-8}$，而 $5\times10^{-9}$ 比网格还细，直接被吞）。于是两个"看着都一样"的数相减，得到的结果是**纯噪声**——这里恰好是 0，一位有效数字都不剩。

机制一句话：**大数相减 → 高位相消 → 结果只剩低位噪声**。这不叫"误差变大"，而是"结果本身失去了意义"。

- **常见场景**：方差公式 $\frac{1}{n}\sum x_i^2-\bar x^2$（均值大、方差小时崩）、求根公式 $(-b\pm\sqrt{b^2-4ac})/(2a)$（$b^2\gg4ac$ 时两支一大一小，小的那支靠相减）、有限差分求导；
- **对策**：**换等价变形，让运算避开大数相减**（本例把减法翻成分母上的加法）；或提高中间精度；或重组公式（方差改"先减均值再平方"的两步算法）。
- **常见误用**：把"灾难性抵消"当成"减法精度低"。单次减法的舍入仍是 eps 级；问题出在**相对误差**——结果比操作数小一千倍时，绝对误差没变、相对误差就放大一千倍。**看相对，不看绝对。**

### 2.4 教材公式 ≠ 工程实现（第 09、14 讲的两笔账）

浮点误差模型 $+$ 抵消效应，足够解释一个从第 09 讲就在积累的悬案：**为什么手算天经地义的公式，搬上计算机要换算法？**

- **第 09 讲的账（RREF 的"脏"）**：手算时判断"主元是不是 0"是眼睛说了算——是 0 就是 0。浮点里没有"恰好是 0"这回事：消元后的元素是 $10^{-18}$ 还是 $-3\times10^{-20}$，取决于一串舍入误差。**"用浮点结果判 rank、判主元为零"在这种意义上不可靠**——"小到多小算零"是一个需要容差和判据的工程决策（第七节给统一说法）。
- **第 14 讲的账（GS 三档表）**：同一个 Gram-Schmidt 的数学定义，三种实现在病态矩阵上误差差出 8 个数量级（第 14 讲 EXP7 实测）：

| 矩阵 | 经典 GS | 修正 GS | LAPACK（`np.linalg.qr`） |
|---|---|---|---|
| 希尔伯特 4×4 | $4.4\times10^{-11}$ | $2.9\times10^{-13}$ | $5.6\times10^{-16}$ |
| 希尔伯特 6×6 | $2.0\times10^{-4}$ | $1.8\times10^{-10}$ | $3.3\times10^{-16}$ |

现在解释为什么：

- **经典 GS 用"原始 $\vec a_j$"算全部投影系数**：一旦前面的 $\vec q$ 带了微小误差，后面每一步都在跟"带误差的账本"对照——**误差逐步累积**；
- **修正 GS 每步用"更新中的残差"算系数**：每一步先把已产生的误差抵消掉再往下传——**误差不累积**；
- **LAPACK 的 Householder 干脆换个数学等价的表达**：用**正交变换（反射）**代替"减投影"流程，正交变换保长度（第 13 讲的 $Q$ 性质），一路不放大误差。结果 6×6 上稳在 $3.3\times10^{-16}$。

**这就是"教材公式 ≠ 工程实现"的完整含义**：数学（恒等式、分解、正交性）没有错，但它在浮点世界里的"生存能力"取决于**误差有没有被累积和放大**。工程实现的选择标准只有一个：**让误差不放大**。第 14 讲预告的 Householder，本讲 5.4 正式上岗。

**另一条同源经验**：第 14 讲坑 1 说"想要数值稳定的 $Q$，把长而壮的向量排前面"——为什么？因为 QR 的算法里有除以 $\|\vec e_j\|$（新方向长度）的步骤。**除以小的数 = 乘上大的倍数 = 误差放大器**——这正是下一节的主角。

## 三、主元选取：消元顺序决定命运

### 3.1 乘数：被忽视的误差放大器

第 03 讲的标准消元：用主元 $a_{kk}$ 把下方元素清零，行的更新是

$$
\text{row}_i\leftarrow \text{row}_i-\mu\,\text{row}_k,\qquad \mu=\frac{a_{ik}}{a_{kk}}
$$

$\mu$ 叫**乘数**。数学上这一步天衣无缝（行变换保解，第 03 讲）；数值上它却是个**放大器**：被更新的元素带着 eps 级相对误差，乘以 $\mu$ 后误差跟着被放大 $|\mu|$ 倍。**$|\mu|$ 大 $=$ 放大倍数大。**

看 EXP2 的戏剧性对照——同一道 2×2 方程组，只是消元顺序不同：

$$
A=\begin{pmatrix}10^{-20}&1\\1&1\end{pmatrix},\qquad \vec b=\begin{pmatrix}1+10^{-20}\\2\end{pmatrix},\qquad \text{真解}=(1,1)
$$

（验证：第一行 $10^{-20}\times1+1\times1=1+10^{-20}$；第二行 $1+1=2$。真解确实是 $(1,1)$。）

- **顺序一（不换行）**：主元是 $10^{-20}$，乘数 $\mu=1/10^{-20}=10^{20}$。浮点求解给出 **$\vec x=(0,1)$，误差 1**（真解 $(1,1)$）——不是"$10^{-16}$ 级放大"，是**全军覆没**。事故链：浮点里 $b_1=1+10^{-20}$ 存进去就已经等于 1（$10^{-20}$ 被网格吞掉，2.3 的机制）；大乘数又把第二行改造得不可辨认；最后回代 $x_1=(1-1\times1)/10^{-20}=0$，本该是 1。
- **顺序二（先换行）**：把第二行（主元 1）换上来，乘数 $\mu=10^{-20}$——小到无害。浮点求解给出 **$\vec x=(1,1)$，误差 0**。

（注意：**手算**两种顺序都是对的——精确世界里 $10^{-20}$ 不会被吞。这场事故只属于浮点，所以"选主元"是上机才需要的纪律。）

**结论：消元的成败，一半取决于"谁当主元"。**

### 3.2 部分主元法：一条规则按下所有雷

**部分主元法**（partial pivoting，也叫列主元法）规则一句话：

> 消每一列之前，先在**当前列、从对角线往下的范围**里找绝对值最大的元素，把它所在的行换到主元位置上来。

为什么稳：换完之后主元是列内（对角线及以下）的最大者，$|a_{kk}|\ge|a_{ik}|$，于是**一切乘数 $|\mu|\le1$**——误差顶多原样传递，绝不会被放大。EXP4 的对照（对同一对矩阵）：

```
朴素 LU 的 L 第二行 = [1e+20, 1.0]   (乘数 1e20 写进 L, 埋雷)
scipy PLU: ||P A - L U||max = 0.0e+00,  置换 P = [[0, 1], [1, 0]]
```

**代价几乎为零**：每次挑主元多花一列比较，总代价 $O(n^2)$，相比消元本体的 $O(n^3)$ 可以忽略。**花万分之一的成本买全部保险**——这是数值线性代数里最划算的买卖。

**为什么"换行"是合法动作**：它是第 03 讲三种初等行变换之一（交换两行，不改变解集）；把所有交换记录下来，就是 3.4 的置换矩阵。

> **坑（不加保险的下场）**：零主元当然必须换行（否则除零）；但危险不止零主元——**小主元**（不恰好是零）照样炸。所以工程实现一律**无脑**执行部分主元，不先检查"需不需要"。

### 3.3 第 03 讲的欠账回收

PLAN 里给第 03 讲登记过一条："不做部分主元导致数值爆炸（20 讲回收）"。现在正式回收：

- 第 03 讲手算消元时，"主元选谁"只要不为零就行——**手算世界**里所有运算精确，选谁都对；
- **机器世界**里，"主元的绝对值多小"直接决定乘数多大、误差放大多少（3.1）。部分主元法不是锦上添花，是"消元能在计算机上跑"的**前提**；
- 顺带把第 03 讲的半句话说完：**避免除以小数**——这和 2.4 里"先处理长而壮的向量"是同一件事的两面。

### 3.4 置换矩阵与 $PA=LU$

把部分主元消元写成矩阵等式。先认识**置换矩阵 $P$**：每行每列恰好一个 1、其余全 0 的方阵。左乘 $P$ 的作用就是**重排行**——"换行"这个动作的矩阵外衣（当场定义，不空降：它只是第 03 讲"交换两行"的记账形式）。

于是部分主元消元的完整形态是一个分解：

$$
PA=LU
$$

- $P$：记录全部行交换；$L$：下三角、对角全 1，装着全部乘数（此刻 $|\mu|\le1$ 是安全的）；$U$：上三角，消元的终点；
- 求解 $A\vec x=\vec b$ 三步走：方程两边左乘 $P$ 得 $LU\vec x=P\vec b$；令 $\vec y=U\vec x$，先解 $L\vec y=P\vec b$（**前代**：下三角从第一行往下逐行代入），再解 $U\vec x=\vec y$（**回代**：第 03 讲的老动作，从上往下倒着来）。

EXP4 的第二次对照验证了装配：$\|PA-LU\|_{\max}=0$（该例数据都是可精确表示的数，严格零差）、$P=\begin{pmatrix}0&1\\1&0\end{pmatrix}$（就是 3.1 那次救命的换行）。

**"分解"的第一层好处：复用**——同一组实验里顺带实测：

```
一次分解多次回代: x = [1.0, 1.0];  换右端 b = [3.0, 4.0]: 残差 0.0e+00
```

分解一次（$O(n^3)$），之后每个新右端只要前代 $+$ 回代（$O(n^2)$）——**矩阵不动、右端换一百个**的场景（电路分析、多载荷结构、后面第 21 讲牛顿类方法的每一步）全靠这个。第五节的完整工具箱从这里展开。

## 四、条件数：问题本身的"体质指数"

### 4.1 $\kappa$ 的定义与几何图像

前两节治的是"算法的病"（运算变形、消元顺序）。但有些问题**本身**就脆——再好的算法也救不了。度量它体质的指标是**条件数**（第 17 讲已经露过面：$\kappa(A)=\sigma_1/\sigma_{\min}$）。正式定义（2-范数版，本讲默认）：

$$
\kappa(A)=\|A\|_2\|A^{-1}\|_2=\frac{\sigma_1}{\sigma_{\min}}
$$

（$\sigma_1\ge\cdots\ge\sigma_{\min}$ 是奇异值，第 17 讲；$\|A\|_2=\sigma_1$、$\|A^{-1}\|_2=1/\sigma_{\min}$ 的推导见作业 B2。用 1-范数/$\infty$-范数也有一套同形式的定义，数值不同、精神一致。）

**几何图像**（第 16/17 讲的老朋友换件新衣）：$A$ 把单位球映射成椭球（SVD 说轴长恰是各 $\sigma_i$）。**$\kappa$ = 最长轴 / 最短轴**——$\kappa=1$：球不变（正交矩阵的倍数，最健康的体质）；$\kappa$ 大：椭球被拉得又瘦又长，某些方向几乎被压扁。

**"压扁"就是危险的来源**：最小奇异值方向上的信息在输出里几乎消失（被乘了 $\sigma_{\min}\approx0$），求解时要反过来除以它——**放大 $1/\sigma_{\min}$ 倍**。$\kappa$ 的一句话读法：**"求解时最坏方向的误差放大倍数"**。

基本性质（能报出来）：

- $\kappa(A)\ge1$，等号 $\iff$ $A$ 是正交矩阵的倍数（各方向等拉伸）；
- $\kappa(A^{-1})=\kappa(A)$；$\kappa(cA)=\kappa(A)$（整体缩放不改变体质）；
- $\kappa$ 对**行/列的尺度**敏感：给各行乘上差很多的数量级会人为吹大 $\kappa$——所以"先做尺度归一（预处理）再算"是常见工程动作（只点名，不展开）。

**与第 17 讲伪逆的接口**（一句话结账）：小奇异值方向"反拉 $1/\sigma$"是危险动作，第 17 讲的**截断伪逆**（太小的 $\sigma$ 直接归零、不反拉）就是这条危险的正式绕行方案——数值上"放弃那一维"好过"反拉一个噪声"。

### 4.2 扰动放大：实测说话

条件数的核心宣告：**输入的小扰动，会被放大最多 $\kappa$ 倍进入输出**。解方程情形写出来（不要求推导，要求会读）：

$$
\frac{\|\delta\vec x\|}{\|\vec x\|}\ \lesssim\ \kappa(A)\cdot\frac{\|\delta\vec b\|}{\|\vec b\|}
$$

EXP3 现场（$H_4$ = 4×4 希尔伯特矩阵 $H_{ij}=1/(i+j-1)$，第 14 讲的"病态试验田"，$\kappa(H_4)=1.551\times10^4$；真解取 $(1,1,1,1)$，给 $\vec b$ 加 $10^{-10}$ 级相对扰动）：

```
随机方向(3 次取最大)放大 4.59e+03 倍
最坏方向(u_min)放大 1.41e+04 倍   (与 kappa = 1.55e+04 同量级)
```

两行读数各有信息量：

- **最坏方向**（扰动沿最小奇异值方向 $u_{\min}$）放大 $1.41\times10^4$——**收割了 $\kappa=1.55\times10^4$ 的大部分**。理论上最坏方向恰好打满 $\kappa$：$\kappa$ 是**上确界**；
- **随机方向**放大 $4.59\times10^3$——日常方向拿不到满额。所以：**$\kappa$ 是"最坏情况标尺"，不代表每次误差都那么大**；但做精度预算时必须按最坏打算。

（第 16 讲的谱定理在这里默默出力：$u_{\min}$ 是最小特征值方向——**可以算出来**。所以"最坏情况"不是玄学，是一条具体方向。）

### 4.3 小残差 ≠ 小误差：最阴的陷阱

普通人验收解的方式：把求出的 $\hat{\vec x}$ 代回方程，看 $\|\vec b-A\hat{\vec x}\|$ 小不小。看 EXP3 的陷阱现场（$H_8$，$\kappa=1.526\times10^{10}$）：

```
人为解沿 v_min 偏 1e-4 -> 相对残差 2.67e-15, 相对误差 3.54e-05
```

读法：把真解沿最小奇异值方向挪 $10^{-4}$ 的**错误解**，代回方程后**残差像完美解一样小**（$2.67\times10^{-15}$），但解的误差是 $3.54\times10^{-5}$——**残差比误差小 10 个数量级**。

机制：$H_8$ 几乎压扁了 $v_{\min}$ 方向。沿这个方向挪 $10^{-4}$，$H\hat{\vec x}$ 里的变化只有 $\sigma_{\min}\times10^{-4}$——被压到看不见。**"残差小"证明的是"$A\hat{\vec x}$ 离 $\vec b$ 近"，不是"$\hat{\vec x}$ 离真解近"**；两者差一个 $\kappa$ 的因子（实测：误差/残差 $\approx1.5\times10^{10}\approx\kappa(H_8)$）。

行动准则：

- 残差是**必要条件**，永远该查，但**不能当解正确的证明**（$\kappa$ 大时尤其不能）；
- 更可靠的验收：① 估出 $\kappa$ 后，检查"误差/残差比"是否符合 $\kappa$ 的量级预期；② **换个算法再解一遍**，两条路线对不上的差值往往就是误差量级；③ 迭代精化（高级动作，点名即可）。完整"验收三步"在 8.2。

### 4.4 误差界 $\kappa\cdot\mathrm{eps}$：第 14 讲那笔账的量化

把 2.2 的舍入模型和 4.2 的放大宣告组装起来，得到解方程的总账本：

$$
\text{浮点解方程的相对误差}\ \approx\ \kappa(A)\cdot\mathrm{eps}\quad(\text{量级界})
$$

含义：**eps 是出厂本钱（16 位有效数字），$\kappa$ 是问题要收的"税"**——$\kappa=10^4$ 时剩约 12 位；$\kappa=10^{10}$ 时剩 6 位；$\kappa=10^{15}$ 时只剩一位，等于白算。

第 14 讲的悬案当场对账（EXP8）：

```
H4: QR 解误差量级 ~ kappa*eps = 3.4e-12   [14 讲实测 6.2e-13, 吻合]
    正规方程 ~ kappa^2*eps = 5.3e-08   [14 讲实测 1.9e-9, 界内(界是上界)]
```

- 第 14 讲实测：QR 路线误差 $6.2\times10^{-13}$、正规方程路线 $1.9\times10^{-9}$（差 3.5 个数量级，当时只有"$Q$ 挡枪"的定性解释）。现在数字全归位：
  - **QR 的账本是 $\kappa\cdot\mathrm{eps}=3.4\times10^{-12}$**——实测 $6.2\times10^{-13}$ 在界内。注意界的用法：**保证不超**，不是精确预测（实跑通常比界好，这正是"最坏情况界"的性格）；
  - **正规方程的账本是 $\kappa^2\cdot\mathrm{eps}=5.3\times10^{-8}$**——实测 $1.9\times10^{-9}$ 同样界内。
- 为什么正规方程按 $\kappa^2$ 记账？因为形成 $A^TA$ 时"问题的病自乘了一次"（4.1 的压扁被做了两遍）——**这正是第 17 讲"别用 eigh($A^TA$)"禁令的同源机制**，5.5 节把那条禁令正式结清。
- 本讲误差账的通用模板：**误差量级 $\approx$（该路线的放大指数）$\times$ eps**。下文的 $\kappa^2$、$\sqrt{\kappa}$、$1/\sqrt{\epsilon}$ 都是同一模板里换一个"放大指数"。

### 4.5 物理极限：$\kappa>1/\mathrm{eps}$ 时，谁来都没用

把账推到极限：$\kappa$ 大到 $1/\mathrm{eps}\approx4.5\times10^{15}$ 时，$\kappa\cdot\mathrm{eps}\ge1$——**误差界超过 100%**：误差可以比解本身还大，解出一条"完全失真"的答案在理论上都属正常。第 15 讲"cond > $10^{16}$ 时 QR 也救不了——双精度的物理极限"的机制就在这：**不是算法不行，是 $\kappa>1/\mathrm{eps}$ 的问题在双精度的数字网格里根本存不下可解的信息**（最小奇异值方向上的差别小于 eps，早已被表示误差淹没）。

EXP8 的对账（第 15 讲那个 12×10 范德蒙德拟合矩阵 $V$）：

```
15 讲 V(12x10): kappa = 1.3e+11;  kappa^2 = 1.8e+22 (远超 1/eps = 4.5e+15)
```

读法（把第 15 讲"3 个数量级差距"的账单彻底展开）：

- $V$ 自己 $\kappa=1.3\times10^{11}$ → QR 路线的账 $\kappa\cdot\mathrm{eps}\approx2.9\times10^{-5}$：恢复系数只能到"小数点后四五位"（第 15 讲实测误差 $2.3\times10^{-2}$，界内）——**QR 能用，但也就这个精度**；
- $\kappa^2=1.8\times10^{22}$ → 正规方程的账 $\kappa^2\cdot\mathrm{eps}\approx4\times10^6$：**误差比真系数大成千上万倍**（第 15 讲实测 $2.7\times10^{1}$，真系数都是 0.5 量级）——"本钱全亏光"的精确含义；
- 顺带把第 15 讲的另一半话说完：$\kappa^2=1.8\times10^{22}\gg1/\mathrm{eps}$ 意味着连"用稳定路线解 $A^TA$ 方程"都已在极限外；而只要 $V$ 的 $\kappa$ 再涨到 $10^{16}$ 以上，连 QR 申请出战都过不了物理极限这一关——**这是矩阵的问题，不是算法的错**。

**第四节总结成一张危险刻度**：

| $\kappa$ 量级 | 状态 | 行动 |
|---|---|---|
| $10^0$–$10^8$ | 健康 | 放心算，常规算法 |
| $10^8$–$10^{16}$ | 亚健康到重病 | 精度按 $\kappa\cdot\mathrm{eps}$ 记账；选稳路线（QR/SVD）；警惕小残差陷阱 |
| $>10^{16}$ | 双精度物理极限外 | 换问题、换精度（长双精度/多精度）、或改建模（正则化）——算法层面无解 |

## 五、分解：把消元组织成工具箱

### 5.1 为什么要"分解"，而不是"每次都消元"

3.4 已经看到第一层好处：**复用**——分解一次 $O(n^3)$，之后每个新右端只要 $O(n^2)$。更深一层的好处是**结构性**：

- **分解 $=$ 把矩阵"编译"成三角因子**：矩阵的信息被整理成"容易求解的形状"（三角=逐行代入即可）；之后求解只是"执行"；
- 不同的矩阵体质，配不同形状的因子（LU 双三角、Cholesky 单三角、QR 正交×三角）——**"认识你的矩阵"能换来计算量和稳定性**；
- 工程上几乎所有矩阵软件（LAPACK、numpy/scipy、MATLAB）内部就是这么组织的：`solve` 一瞬间完成 LU+前代+回代，`cho_solve` 走专用半价通道。

下面把四大家族摆齐，顺手把第 16、17 讲的两笔账结清。

### 5.2 LU 家族：通用方阵的双三角分解

正式形态（3.4 已有）：**$PA=LU$**。补一条"什么时候不用换行也安全"（与第 16 讲 Sylvester 判定的同一条批量）：如果 $A$ 的**顺序主子式**全部非零，则不需要行交换就存在唯一的 $A=LU$（$L$ 单位下三角、$U$ 上三角）——因为无主元消元的第 $k$ 个主元 $=$ $D_k/D_{k-1}$（第 16 讲顺序主子式符号判定的同一本账），只要 $D_k$ 都不为零，一路消下去不会遇到零主元。

但"非零"不等于"安全"：$D_k/D_{k-1}$ 可能**非常小**（3.1 的大乘数就来自这种小主元）。所以现实中的工程口径是**无脑部分主元**——不判断、不检查，直接 $PA=LU$（多花的那点比较成本忽略不计）。LU 求解三步（3.4）：置换 $\to$ 前代 $\to$ 回代；计算量约 $2n^3/3$ 次乘法。

### 5.3 Cholesky：正定矩阵的半价通道（第 16 讲兑现）

第 16 讲的原话兑现时刻："**正定矩阵能拆成 $A=LL^T$（$L$ 下三角）——正定版的平方根，解方程最快最稳的一档；顺序主子式全正正是这台分解存在且数值健康的保证。**"现在逐项兑现：

$$
A=LL^T\qquad(L\ \text{下三角，对角元为正})
$$

计算方式一句话：**逐列算**——第一列直接从 $A$ 的第一列开方出来；后面每一列先"减掉已算列贡献"再开方（模板照 16 讲"配方法/正交法"的精神，具体公式不展开，numpy `cholesky` 一行）。EXP5 主例（$A_5=\begin{pmatrix}4&12&-16\\12&37&-43\\-16&-43&98\end{pmatrix}$）：

```
||L L^T - A||max = 0.0e+00;  解方程残差 = 2.7e-14
```

三个白拿的红利：

- **半价**：计算量约 $n^3/3$，是 LU 的一半（LU 要消出两个三角，Cholesky 只造一个）；
- **不用选主元**：正定性保证"每次开方前的量"恒为正——消元永远遇不到小主元。这里就是"**顺序主子式全正 $=$ 数值健康的保证**"的精确含义：$D_k>0$ 使每一步的主元 $D_k/D_{k-1}$ 不仅非零、还有正的下界；
- **自带正定性体检**：想让非正定矩阵过关？开方开到负数时它**直接报错**，不假装成功——

```
非正定矩阵 (1,2;2,1): Cholesky 直接报 LinAlgError (开到负数平方根就停, 不假装成功)
```

**速度实测（EXP5 下半场）**：同一个 $n=500$ 的对称正定方程组，两条路线（各跑 3 次取最快）：

```
n=500 SPD 求解计时: solve 447 ms vs cholesky+cho_solve 6 ms
```

**约 75 倍**。这不是代码优化的功劳，是**算法选择的红利**——把"矩阵是 SPD"这个身份告诉程序（`scipy.linalg.cho_solve`），它就能砍掉一半计算、跳过全部主元开销。教训一句话：**矩阵的结构是白拿的礼物，别让通用算法把它埋没**。SPD 矩阵无处不在（最小二乘的 $A^TA$、第 16 讲的二次型、PCA 的协方差、物理里的刚度矩阵），所以这条半价通道的出镜率极高。

### 5.4 家族全景：LU / Cholesky / QR / SVD 各自的席位

**Householder 正式上岗**（第 14 讲"20 讲出场"的兑现）。QR 的工业实现不是"显式减投影"的 GS，而是用一串**反射**：每个反射 $H=I-2\vec w\vec w^T/(\vec w^T\vec w)$ 是正交矩阵（第 13 讲正交家族的"反射"原型——镜面），它能把一个向量**镜像**到指定方向；拿它逐列把 $A$ 的对角线以下"拍平"，拍完就是上三角。要点两条：

- **数学产物与 GS 一致**（都是 $A=QR$，$Q$ 正交、$R$ 上三角），但流程不同：GS 在"列向量减法"里累积误差，反射在"正交变换"里不放大误差（2.4 的机制）；
- **照应第 14 讲三档表**：LAPACK 那栏 $3.3\times10^{-16}$ 的满分成绩，就是反射的功劳。（反射的公式认个脸熟即可，不需要会推。）

**四家族对照表**（代价按乘法量级的经典教科书账，常数依实现而变，用于选型比较）：

| 分解 | 适用 | 代价 | 稳定性 | 典型用途 |
|---|---|---|---|---|
| LU（$PA=LU$） | 任意方阵 | $\approx2n^3/3$ | 部分主元下可靠 | 通用求解；一次分解多次右端 |
| Cholesky（$A=LL^T$） | 对称正定 | $\approx n^3/3$ | 无需主元，最稳一档 | SPD 求解（半价通道） |
| QR（$A=QR$） | 任意矩阵（列满秩最顺） | $\approx4n^3/3$（Householder） | 正交变换，最稳 | 最小二乘；病态方程的救场 |
| SVD（$A=U\Sigma V^T$） | 任意矩阵 | 常数倍于 QR（最贵） | 最稳、信息最全 | 伪逆、低秩、条件数、rank 判定 |

**兑现第 17 讲"SVD 最贵（20 讲细算）"**：SVD 的演算是"双对角化（$O(n^3)$）$+$ 迭代求解"两段，常数在 QR 的数倍级——**四种里最贵，没有之一**。但它的回报也是独家的：对**任何**矩阵给出全部奇异值/子空间（第 17 讲"信息与最优性"）。所以第 17 讲的行动准则在成本账上同样成立：**能 QR 解决的不用 SVD；要"信息与最优性"的，只有 SVD。**

**顺手回收"别求逆"的半个理由**（完整版在 8.3）：解 $A\vec x=\vec b$ 不要先算 $A^{-1}$——求逆的代价本身就是一次 LV/PLU 级别的分解、外加 $n$ 个右端的回代；精度上还更差（每列都独立地累积一遍误差）；而 `np.linalg.solve` 内部就是 LU 三件套，直接用它。**逆适合当"记号与理论"，不适合当"计算步骤"。**

### 5.5 eigh($A^TA$) 禁令结清（第 17 讲兑现）

第 17 讲留过一句："**计算机上别用 `eigh(A^TA)` 当 SVD 用**：$A^TA$ 会把条件数**平方**……第 20 讲细说为什么。"现场结账（EXP6）：

```
H4: kappa = 1.551e+04;   kappa(H4^T H4) = 2.407e+08;   kappa^2 = 2.407e+08
H6 最小奇异值: svd 直算 = 1.083e-07;  sqrt(eigh(H^T H)) = 1.083e-07;  相对偏差 = 4.2e-04
H8: eigh 最小特征值 = -2.22e-18 (真实 sigma_min^2 = 1.24e-20) -> 平方后连正负都不保
```

三段读数，三段惨案：

1. **$\kappa(A^TA)=\kappa(A)^2$ 严格成立**（$2.407\times10^8$ 两侧完全一致）：4.1 说"$A^TA$ 把病自乘"，这就是精确的量化——$\kappa$ 从 $1.55\times10^4$ 涨到 $2.4\times10^8$；
2. **信息在"平方"这一步被烧掉**：$H_6$ 的最小奇异值 $10^{-7}$ 量级，平方后是 $10^{-14}$——有效数字从 16 位掉到 2 位左右；开方"回来"时缺的信息补不回来（相对偏差 $4.2\times10^{-4}$，比 eps 大了十多个数量级）；
3. **极端情形连数学事实都保不住**：$H_8$ 上 `eigh` 给出的"最小特征值"是 $-2.22\times10^{-18}$——**负的**。而 $\sigma_{\min}^2$ 真正是 $1.24\times10^{-20}$：噪声（$\sim10^{-18}$）比信号（$10^{-20}$）大了两个数量级，把答案淹没了。

**正路**：`np.linalg.svd(A)` 直接对 $A$ 工作（双对角化），从不形成 $A^TA$——没有平方、没有信息烧毁。这是全讲最清晰的"**数学上恒等，数值上不等价**"标本：$\sigma^2=\lambda(A^TA)$ 数学上无懈可击，计算上是灾难路线。2.4 的"教材公式 ≠ 工程实现"，在这里有了量化最狠的一例。

## 六、迭代法：大矩阵的另一条赛道

### 6.1 动机：大矩阵为什么"不分解"

到 4.5 为止，一切方案（消元、分解）都是**直接法**：有限步、一次性算出精确的（浮点意义下）解。它对中小规模是标准答案，但有两块硬天花板：

- **大三**：$O(n^3)$ 时间、$O(n^2)$ 内存。$n=10^6$（一维问题一万格点也不小了，二维网格轻松上百万）时 $n^3=10^{18}$——不可行；
- **填洞（fill-in）比大三更致命**：稀疏矩阵消元时，零的位置会被"撑出"非零——原始零元的模式被破坏，分解后因子往往远比原矩阵稠密。**内存和时间都被填洞摧毁。**

迭代法换一条哲学：**不"解出"方程，而是"逼向"解**。从任意初值 $\vec x^{(0)}$ 出发，每轮只做**矩阵乘向量**——代价 $O(\mathrm{nnz})$（nnz $=$ 非零元个数；稀疏时 $\approx O(n)$），内存只要原矩阵。代价是换来的：**有限步变无限步**，"什么时候算停"成了核心问题——所以 6.2–6.3 讲的全是"收敛"。

> 边界先钉死：**小/中规模稠密问题，直接法是标准答案**（迭代法在里面没有优势，甚至更慢）。迭代法的主场：**大而稀疏**。（现代工业常两者混合：预处理迭代，本课点到为止。）

### 6.2 Jacobi 与高斯-赛德尔：定常迭代两兄弟

从一个方程看起。第 $i$ 个方程是 $a_{ii}x_i+\sum_{j\neq i}a_{ij}x_j=b_i$——换个读法："**把第 $i$ 个方程当作'关于 $x_i$ 的方程'**"：

$$
x_i=\frac{b_i-\sum_{j\neq i}a_{ij}x_j}{a_{ii}}
$$

- **Jacobi 迭代**：右边一律用上一轮的**旧值**：
$$
x_i^{(k+1)}=\frac{1}{a_{ii}}\Big(b_i-\sum_{j\neq i}a_{ij}x_j^{(k)}\Big)
$$
- **高斯-赛德尔（GS）迭代**：右边用"**已经更新过的值**"——排在前面的分量已换成新值，排在后面的还用旧值：$x_i^{(k+1)}$ 的求和里，$j<i$ 用 $x_j^{(k+1)}$、$j>i$ 用 $x_j^{(k)}$。白话："一边算一边改"——同一轮里新信息立即上岗。

矩阵写法（把 $A$ 拆成对角、严格下三角、严格上三角三块：$A=D+L+U$；$D$ 可逆时）：

$$
\vec x^{(k+1)}=B\vec x^{(k)}+\vec c\qquad
\begin{cases}
B_J=-D^{-1}(L+U), & \vec c_J=D^{-1}\vec b\quad\text{(Jacobi)}\\[2pt]
B_{GS}=-(D+L)^{-1}U, & \vec c_{GS}=(D+L)^{-1}\vec b\quad\text{(GS)}
\end{cases}
$$

**收敛分析（本讲最重要的一次"特征值出场"）**：真解 $\vec x^\*$ 满足 $\vec x^\*=B\vec x^\*+\vec c$（不动点）；两式相减，误差 $\vec e^{(k)}=\vec x^{(k)}-\vec x^\*$ 满足

$$
\vec e^{(k+1)}=B\vec e^{(k)}\ \Longrightarrow\ \vec e^{(k)}=B^k\vec e^{(0)}
$$

——**收敛 $\iff$ $\rho(B)<1$**（$\rho=$ **谱半径** $=$ 全体特征值模的最大者，第 11–12 讲的老工具）。$\rho$ 越接近 1，误差退场越慢（误差按 $\rho^k$ 收缩）。一个**充分条件**（够用就背）：**严格对角占优**（每行对角元的绝对值大于同行其余绝对值之和）$\Rightarrow$ Jacobi 与 GS 都收敛——因为此时 $\|B_J\|_\infty<1$，而谱半径不超过任何诱导范数（作业 B3 两步证完）。注意它是**充分不必要**：看 EXP7 现场（$T=2I-\text{(上下邻居)}$，$n=20$）：

```
到相对残差 1e-8: Jacobi 1633 步;  GS 818 步;  CG 10 步
Jacobi 谱半径 rho = 0.9888 (理论 cos(pi/21) = 0.9888 < 1 -> 收敛)
```

- $T$ 的每行对角是 2、邻居绝对值之和恰好也是 2——**卡在严格对角占优的门槛外**，但 $\rho=0.9888<1$ 依然收敛：充分条件不必要，现场为证；
- GS 步数（818）恰好约 Jacobi（1633）的**一半**——"边算边改"早半步用上新信息，通常能换到约两倍的速度（不是定理保证的普遍结论，是常见现象）；
- 但"$\rho$ 靠近 1 就慢得离谱"：0.9888 已经"看起来离 1 很近"，却要上千步。

**反例与爆炸现场**（把对角降到 1、邻居仍是 $-1$，$\rho=1.978>1$）：

```
反例(对角 1, off -1): Jacobi 谱半径 rho = 1.978 > 1 -> 残差序列 8.6e+00 -> 1.7e+01 -> 3.3e+01 -> 6.5e+01 -> 1.3e+02
```

五步翻 15 倍——**不满足收敛判据时，迭代不是"慢"，是"发散"**。

> **坑**：把"对残差设了阈值"当成"有保证"。阈值只负责"什么时候停"，不负责"能不能到"——ρ≥1 时它永远到不了（残差一路涨），循环写不对就是个死循环/爆表。**先判收敛性，再谈阈值。**

### 6.3 共轭梯度：换一台"全局导航"的迭代机

Jacobi/GS 的慢有个共同根源：**每步只用"邻居的旧值"**——信息传播像传话游戏，从一端传到另一端要很多轮（这正是 $\rho$ 靠近 1 的来源，也是 1633 步的来源）。**共轭梯度法（CG，conjugate gradient）**换了个层级：每步沿一个"由残差历史**全局构造**"的方向走。

适用前提：**$A$ 对称正定**。迭代式（初值 $\vec x^{(0)}=\vec 0$，$\vec r^{(0)}=\vec b$，$\vec p^{(0)}=\vec r^{(0)}$；每轮）：

$$
\alpha_k=\frac{\vec r^{(k)T}\vec r^{(k)}}{\vec p^{(k)T}A\vec p^{(k)}},\quad
\vec x^{(k+1)}=\vec x^{(k)}+\alpha_k\vec p^{(k)},\quad
\vec r^{(k+1)}=\vec r^{(k)}-\alpha_kA\vec p^{(k)}
$$
$$
\beta_k=\frac{\vec r^{(k+1)T}\vec r^{(k+1)}}{\vec r^{(k)T}\vec r^{(k)}},\qquad
\vec p^{(k+1)}=\vec r^{(k+1)}+\beta_k\vec p^{(k)}
$$

白话读法：$\vec r$ 是残差（"还差多远"），$\vec p$ 是搜索方向；$\vec p$ 由"新残差 $+$ 借上一步一点方向"拼成，系数 $\beta$ 专门保证**走过的方向互不"重走"**（术语：$A$-共轭）——**每一步都扫掉一块新地盘，不反复擦同一块**。几何图像接第 16 讲：解 SPD 方程 $=$ 找二次函数碗的碗底；Jacobi/GS 像"沿轴来回挪"，CG 像"顺着碗的主轴量身定制的滑梯，一维只滑一次"。

为什么它快：收敛速度与 **$\sqrt{\kappa}$** 挂钩（"难度指数的平方根"），而不是 $\rho$ 那种"随 $\kappa$ 整体恶化"的关系——**病态问题的难度被从"$\kappa$ 级"降到"$\sqrt{\kappa}$ 级"**。三条定量事实：

- **精确算术下 $n$ 步终止**（有限终止性）：理论上最多走 $n$ 步就到精确解（每步扫掉一维）；
- **渐进收敛率**形如 $\big(\frac{\sqrt{\kappa}-1}{\sqrt{\kappa}+1}\big)^k$（保守界，只给形状）；对**大 $n$、谱弥散**的问题，经验抓手是"**步数 $\sim\sqrt{\kappa}$ 量级**"；
- EXP7 现场：$n=20$ 的 $T$ 上 **CG 10 步**到相对残差 $10^{-8}$（vs Jacobi 1633、GS 818）。本例 $\kappa(T)=178.1$、$\sqrt{\kappa}=13.3$——10 步与"十几步"同量级（小 $n$ 时还有 $n=20$ 的终止上限在兜底，两个效应叠着）。

> 一般（非对称）矩阵的 Krylov 方法另有家族（GMRES、BiCGSTAB 等）——**点名即可，本课不展开**。另外"把 $\kappa$ 降下来再跑 CG"（**预条件**）是工业标配的第一步，同样只点名。

### 6.4 选型：什么时候用哪个

| 场景 | 推荐 | 理由 |
|---|---|---|
| $n$ 小/中、稠密 | 直接法（LU / Cholesky / QR） | 稳定、有界（$\kappa\cdot\mathrm{eps}$ 封顶）、有限步完成 |
| $n$ 大、稀疏、SPD | CG（常配预条件） | 每步 $O(\mathrm{nnz})$；步数 $\sim\sqrt{\kappa}$ |
| $n$ 大、稀疏、一般 | GMRES 族（点名） | 非对称的 Krylov 方法 |
| 结构特殊（三对角、带状） | 专用直接法往往仍最好 | 分解本就便宜，没必要迭代 |

两条定性差别，别记反：**直接法"贵但有保证"**（内存/时间换稳定性与封顶）；**迭代法"每步便宜但速度吃 $\kappa$、可能根本不收敛"**。"迭代法比直接法快"**没有普适性**——小稠密问题上迭代经常输。

### 8.2 结果的验收三步

数值计算没有"证明"，只有"证据链"。三步走：

1. **估**——先算精度上限：$\kappa\cdot\mathrm{eps}$ 量级估计"这个矩阵最多能给我几位有效数字"（$\kappa$ 可用 `cond` 估；LAPACK 另有便宜的估算器，工业代码常用）；
2. **查**——残差（必要条件，永远要查）$+$ 残差与误差的量级比是否合理（4.3：比 $\approx1/\kappa$ 才正常）；
3. **验**——换一条路线/另一个库再解一遍（对不上的差值往往就是误差量级），或扰动输入看输出是否病态抖动。

（第 14/15 讲其实一直在做"双路线对账"——QR vs 正规方程、解析 vs 数值——本讲把这种职业习惯正式命名。）

### 8.3 习惯清单（背下来，上机前默念）

1. **用库，不自己写消元**：LAPACK 里每一步都是几十年论文的沉淀（主元、缩放、分块、并行）——手写版本十有八九漏掉一个不显然的细节；
2. **容差写相对形式**："$\lvert a-b\rvert<\mathrm{tol}$"里的 tol 要跟数据尺度挂钩；绝对容差 $10^{-16}$ 只在数值本身是 1 量级时才对；
3. **别用 `==` 比较浮点**：用 $\lvert a-b\rvert<\mathrm{tol}\cdot\mathrm{scale}$（2.1 的教训）；
4. **默认双精度**；确实不够（$\kappa$ 顶破 $1/\mathrm{eps}$）时换更高精度（longdouble、多精度库）或改模型——算法层面无解的事，别在算法层面死磕；
5. **把结构告诉算法**：对称/正定/稀疏/带状——白拿的礼物（5.3 的 75 倍）；
6. **别求逆解方程**（5.4）：`solve` 是正路；逆留给理论记号；
7. **大问题的性能先看算法复杂度再看代码微调**：$n=500$ 的 75 倍来自"选对分解"，不是循环写得好；
8. **报误差用 2–3 位有效数字 $+$ 量级**：浮点世界里"精确到小数点后 N 位"的断言本身就该被怀疑。

## 九、心智模型与总结

### 9.1 三件心智模型（本讲的"手感"）

1. **误差放大链**：出厂本钱是 eps（16 位有效数字）；每一次运算/每一个算法选择都是一道"税率"——乘数 $\mu$、$\kappa$、$\kappa^2$、$1/\sqrt{\epsilon}$、$\sqrt{\kappa}$。**任何算法的精度都能用"放大指数 $\times$ eps"估价**，这就是本讲统一账本。
2. **分解 $=$ 编译**：矩阵被"编译"成容易执行的因子（三角/正交）；四种体质（一般/SPD/任意/要全信息）配四种工具（LU/Cholesky/QR/SVD）。**选工具 $=$ 报体质**，白拿速度与稳定。
3. **迭代 $=$ 不动点 $+$ 谱半径**：$\vec x\to B\vec x+\vec c$，解是不动点，收敛由 $\rho(B)<1$ 裁决；CG 用 Krylov 子空间把"传话游戏"升级成"全局导航"（难度从 $\kappa$ 级降到 $\sqrt{\kappa}$ 级）。第 11–12 讲的特征值学问，原来是工程迭代机的发动机。

### 9.2 数值线的全景（本讲在课程中的位置）

## 小结（一页）

- **浮点**：每个数带 eps 级相对表示误差；每步运算带 eps 级舍入；减法消高位 $\Rightarrow$ 灾难性抵消（换变形救回）。双精度 $=$ 十六位有效数字本钱。
- **主元**：乘数 $\mu$ 是误差放大器；部分主元保证 $\lvert\mu\rvert\le1$；产物是 $PA=LU$；换行是初等变换（不改解）。
- **条件数**：$\kappa=\sigma_1/\sigma_{\min}$（椭球最长/最短轴）；扰动放大 $\lesssim\kappa$ 倍；误差量级 $\approx\kappa\cdot\mathrm{eps}$；$\kappa>1/\mathrm{eps}$ 双精度物理极限。小残差 $\ne$ 小误差（差 $\kappa$ 倍）。
- **分解**：LU（$2n^3/3$，部分主元）、Cholesky（$n^3/3$，SPD 专属：免主元 $+$ 半价 $+$ 体检）、QR（Householder 反射，最稳）、SVD（最贵、信息最全）；一次分解多次求解；别求逆解方程。
- **迭代**：$\vec x^{(k+1)}=B\vec x^{(k)}+\vec c$，收敛 $\iff\rho(B)<1$；对角占优是充分条件；CG（SPD）步数 $\sim\sqrt{\kappa}$、$n$ 步终止；大稀疏的主场，小稠密别用。
- **敏感性地图**：解方程 $\kappa$、正规方程 $\kappa^2$、对称特征值 $1$、缺陷特征值 $1/\sqrt{\epsilon}$、离散判定无稳定答案。**误差账一律"放大指数 $\times$ eps"模板。**

**B. 提高**

**B1.** 证明：部分主元消元中所有乘数满足 $\lvert\mu\rvert\le1$；并说明这如何限制误差增长。

**参考答案**：第 $k$ 步消元时，主元取自"当前列对角线及以下"的最大绝对值：$\lvert a_{kk}\rvert\ge\lvert a_{ik}\rvert$（一切 $i>k$），故 $\lvert\mu\rvert=\lvert a_{ik}\rvert/\lvert a_{kk}\rvert\le1$。误差含义：行更新 $\text{row}_i-\mu\,\text{row}_k$ 中，$\text{row}_k$ 携带的绝对误差至多被放大 $\lvert\mu\rvert\le1$ 倍、再加上本步的舍入 eps——每一步的"误差规模"不超过"来源误差 $+$ eps"，不存在放大链（对比 3.1 的 $10^{20}$ 倍）。术语：消元的"增长因子"受控。

**B2.** 用 SVD 推导 $\lVert A\rVert_2=\sigma_1$、$\lVert A^{-1}\rVert_2=1/\sigma_{\min}$，从而 $\kappa(A)=\sigma_1/\sigma_{\min}$。

**参考答案**：设 $A=U\Sigma V^T$（第 17 讲）。对任意 $\vec x$：$\lVert A\vec x\rVert=\lVert U\Sigma V^T\vec x\rVert=\lVert\Sigma(V^T\vec x)\rVert$（$U$ 正交保长度，第 13 讲）；$V^T\vec x$ 取遍全部单位向量（$V$ 正交），于是 $\lVert A\rVert_2=\max_{\lVert\vec y\rVert=1}\lVert\Sigma\vec y\rVert=\sigma_1$（把全部质量放在最大奇异值方向）。$A^{-1}=V\Sigma^{-1}U^T$ 的奇异值是 $1/\sigma_i$（降序重排后），故 $\lVert A^{-1}\rVert_2=1/\sigma_{\min}$。相乘即 $\kappa=\sigma_1/\sigma_{\min}$。

**B3.** 证明：$A$ 严格对角占优 $\Rightarrow$ Jacobi 迭代收敛。（两步提示：① 对任意矩阵 $B$，谱半径 $\rho(B)\le\lVert B\rVert_\infty$；② 计算 $\lVert B_J\rVert_\infty$。）

**C3.** ★ 迭代三连：在 $n=20$ 的三对角 $T=2I-(\text{上下邻居})$、$\vec b=\vec 1$、容差 $10^{-8}$ 上，复跑 Jacobi 与 CG 的步数；有余力再加 GS 一栏。

**参考答案**：

```python
import numpy as np
n = 20
T = 2*np.eye(n) - np.eye(n, k=1) - np.eye(n, k=-1)
b = np.ones(n); tol = 1e-8
# Jacobi
x = np.zeros(n); it = 0
while True:
    x = (b - (T - np.diag(np.diag(T))) @ x) / np.diag(T); it += 1
    if np.linalg.norm(b - T @ x) / np.linalg.norm(b) < tol: break
print("Jacobi", it)                          # 1633
# CG
x = np.zeros(n); r = b.copy(); p = r.copy(); rs = r @ r; it = 0
while True:
    Ap = T @ p; a = rs / (p @ Ap); x = x + a*p; r = r - a*Ap; rn = r @ r; it += 1
    if np.sqrt(rn) / np.linalg.norm(b) < tol: break
    p = r + (rn / rs) * p; rs = rn
print("CG", it)                              # 10
```

读数：Jacobi 1633 步、CG 10 步（GS 一栏预期 818 步）——同一条方程，迭代机的代差。附：$\rho(T$ 的 Jacobi$)=\cos(\pi/21)=0.9888$ 可另行验证（`np.abs(np.linalg.eigvals(np.linalg.solve(np.diag(np.diag(T)), T - np.diag(np.diag(T))))).max()`）。
