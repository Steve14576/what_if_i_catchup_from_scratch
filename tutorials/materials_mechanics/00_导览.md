# 材料力学——导览

> 这是一套**面向完全没系统学过材料力学的人**的教程。目标不是"认得几个应力公式"，而是：学完你能单纯凭借它，把国内工科《材料力学》课程水准的考核做下来，并且真的理解每个量在研究什么、它解决哪一类构件问题、前提和边界在哪、什么时候该调用它。

## 这门课是什么

材料力学研究的是：**一根受力的杆件（或由杆件组成的构件）会不会坏、坏在哪里、坏得有多严重**。它把真实的构件抽象成可计算的模型，然后用一套系统的方法算出各处的应力、应变和变形，最后回答三个问题——构件够不够**强度**（会不会断）、够不够**刚度**（变形是否超限）、够不够**稳定性**（受压时会不会突然失稳）。

它的主线只有一条——**一根杆件被拉、被剪、被扭、被弯、被压，各自的应力、应变、变形怎么算**：

- **建模与基础**（01）：先把真实构件换成变形体模型，立好全课程第一套规矩——基本假设、外力与内力、截面法、应力与应变，并认识杆件的四种基本变形。
- **基本变形逐个攻克**（02–11）：轴向拉压（内力、应力、变形、材料性能、强度）、剪切与挤压、圆轴扭转（应力、变形、强度与刚度）、截面的几何性质、平面弯曲（内力图、正应力、切应力、变形）。这是全课的主干，也是考试的重点。
- **复杂应力状态与判据**（12–17）：简单超静定入门、一点的应力状态（应力圆）、广义胡克定律、强度理论、组合变形、压杆稳定。研究"多种应力同时存在时，怎么判定安全"。
- **通用方法与动态问题**（18–21）：能量法求位移、力法解超静定、动载荷、交变应力与疲劳。从"逐根杆手算"升级到"对复杂结构也省力的通用手段"，并处理载荷随时间变化的情形。
- **收束**（22）：一张地图——材料力学往下通向结构力学、弹性力学、有限元去哪里深入。

这套课从零开始，每一步都配四样东西：**固化的标准做法**（每个方法都给出可照抄的模板：标准形式、符号规矩、操作步骤、填数示范——画内力图与代公式不靠"感觉"）、**直觉**（它在解决哪一类构件问题）、**能笔算的例题**（考试风格：概念辨析、计算、脚本题）、**能跑的 Python 数值实验**（把结论坐实成具体数字，全部可在 `scripts/` 复跑；每个内力结论都回代静力平衡独立复核）。关键图形都会配图（`figures/`）：受力图、内力图、应力分布图与变形曲线，且每张图旁都有文字描述兜底。

## 前置

- 高中物理与理论力学常识：会画受力图、列力的平衡方程（$\sum F=0$、$\sum M=0$）即可（本课程会把它们重新严谨化）。
- 微积分：导数、积分和简单微分方程"见过"即可；用到的地方会就地给最小说明，或标注"现在只需知道这么多"。
- 三角函数与几何：会基本的三角恒等式（如 $\sin 2\alpha=2\sin\alpha\cos\alpha$）更省力。
- Python：不需要预先会。需要跑实验时讲义当场给出可直接运行的代码，环境用 `uv`（不熟也没关系，照着复制即可；跑不动也可以只看脚本里的输出表格）。
- 英语：术语会配中英对照（方便你读英文材料或对照考试），但正文不依赖英语。

## 学完你能做什么

- [ ] 对受拉压的杆件：用截面法求轴力并作轴力图，算横截面与斜截面上的应力，用强度条件做校核、设计截面、求许用载荷。
- [ ] 对连接件：正确辨认剪切面与挤压面，做剪切、挤压的实用计算。
- [ ] 对圆轴：作扭矩图，算扭转切应力与扭转角，做强度与刚度两类校核。
- [ ] 对截面的几何性质：算组合截面的形心、惯性矩、抗弯与抗扭截面系数。
- [ ] 对梁：作剪力图与弯矩图，算弯曲正应力与切应力，求挠度与转角，做强度与刚度校核。
- [ ] 解简单超静定问题（拉压超静定、温度应力与装配应力、超静定梁），并说清"静力平衡 + 变形协调"的分工。
- [ ] 对一点的应力状态：用解析法或应力圆求主应力与最大切应力，写广义胡克定律。
- [ ] 对复杂应力状态：选用合适的强度理论算相当应力；处理拉弯、弯扭、偏心拉压等组合变形；用强度理论校核薄壁圆筒（内压容器）。
- [ ] 对压杆：算柔度、判别失稳类型，用欧拉公式或经验公式做稳定校核。
- [ ] 用能量法（单位载荷法、图形互乘）求结构位移；用力法解超静定结构。
- [ ] 处理动载荷（等加速、冲击）与交变应力（疲劳）问题。
- [ ] 用 Python 复跑全课程的数值实验，并说清每个方法的完整形态与边界。

## 每讲怎么用

1. 从本讲开头的"这一讲解决什么"进入正文；正文按问题、关系、例子和边界自然展开。
2. 需要画图或运行例时，先看具体构件、受力或计算目标；概念在解决它所需的位置解释。
3. 注意正文中对关键量的学习要求：哪些要会推导、手算，哪些只需识别适用条件或建立直觉。
4. 数值实验的实测数字可在 `scripts/` 找到脚本复跑（文件名形如 `lecNN-01_verify_xxx.py`）；关键图形在 `figures/`，每张图旁有文字描述。
5. 读完小结后完成作业；某些讲附有掌握度自测或分层练习时，将它作为额外的自检工具。
