# 高等数学 II（下）——多元与级数 · 从三升维到考场 · 导览

> 本课程接《高等数学 I（上）》31 讲。上册把一元微积分的完整链条（极限 → 导数 → 中值定理/泰勒 → 积分 → 应用）建完，并在最后一讲标出了下册的坐标：**下册不是另一门课，是上册的三种升维**——加自变量（一元函数 → 多元函数）、加项数（有限和 → 无穷级数）、加结构（微分方程与向量场语言化）。
>
> 本课程把这三种升维**逐项兑现**：一整套能算、能判、能说清依据的多元微积分与级数技术，配数值实验和图，目标是一份正经的高数（下）期末试卷——每步写得出依据；对没把握的步骤，知道去哪查、查什么。

## 这门课为谁写

- 学完了上册（或等价的一元微积分），**会算不少东西，但对"多元"只有零散印象**；
- 知道偏导、重积分、级数这些名字，但**说不清它们各自在干什么、边界在哪**；
- 容易在旧直觉上栽跟头（"偏导存在就能可微""级数收敛等价于通项趋于零"这类），**希望有人当场把反例摆出来**；
- 目标是期末：时间不大急，但要**有把握、不狼狈地系统性速通**，并且真正学到东西。

## 前置

- 上册全部（尤其：极限的 ε-N/ε-δ、导数与全微分的一元版、定积分与元素法、泰勒公式、常微分方程）。
- 高中数学（向量初步会在第 01 讲重建，不要求熟练）。
- Python 不要求：数值实验给可复制代码，用 `uv run --with numpy python` 跑。

## 学完你能做什么

- [ ] 判断多元函数的极限是否存在（路径法说清"不存在"），区分重极限与累次极限；说清**连续、偏导存在、可微**三者的强弱关系并给反例。
- [ ] 完成复合函数与隐函数求导；写出曲面切平面/法线与空间曲线切线/法平面；用**方向导数与梯度**处理"哪个方向变化最快"。
- [ ] 用海森判据求无条件极值、用拉格朗日乘数法处理条件极值。
- [ ] 熟练计算二重/三重积分（直角、极坐标、柱面、球面、换元雅可比），会用对称性与换序。
- [ ] 计算两类曲线积分与两类曲面积分；正确使用**格林、高斯、斯托克斯**公式（含方向与条件检查）；判断路径无关的四个等价条件。
- [ ] 判别数项级数敛散、处理交错与绝对收敛、求幂级数收敛域与和函数、把函数展开成幂级数/傅里叶级数。
- [ ] 每个数值结论，能跑 `scripts/` 里的脚本复现；每张图能在 `figures/` 找到来源。

## 每讲怎么用

1. 开头看"这一讲解决什么问题"与该讲目标（不是每讲都配路线图——只有多分支、会在选择处迷路的讲才需要）。
2. 概念按"定义 → 条件与边界 → 例题 → 数值实验/图"的顺序走；遇到新符号、新名词，第一次出现处就给定义或"现在只需知道多少"的标注。
3. 数值实验都能在 `scripts/` 找到脚本复跑；图在 `figures/`，每张图都有生成脚本。
4. 结尾有作业；答案平铺在每题下方（先做，再对照）。不是每讲都按"基础/提高/综合"凑档——按内容需要出题。
5. 部分讲配"掌握度自测"——只在多公式易混、考试要求分层明显时出现；小结已足够时不硬加。

## 三档深度与卡壳协议

每个概念都会标明该理解到哪一步：

- **要能推导 / 手算**：核心武器（可微判据、雅可比、格林/高斯/斯托克斯的条件与计算、级数判别）。要亲手写，写到不看书。
- **要知道有这回事 + 什么时候找它**：边界知识（隐函数存在定理、傅里叶收敛性证明、多元泰勒高阶理论）。看到名字知道是什么、去哪查——足够。
- **要建立直觉**：辅助理解（几何图像、物理意义）。它们是路标不是证明。

**卡壳协议**：一个定义读三遍读不懂时——① 先做具体例题或跑数值实验；② 还卡就标记后跳小节，很多卡点在后面的应用里会自己解开；③ 还卡就把问题记下来去问（或写进 `QnAnExperience.md`）。**禁止对一句话空想 30 分钟以上**——数学是读+算+写的循环，不是冥想。

## 达标判据

- **一讲达标** = 能独立做对该讲作业的基础题与提高题（综合题允许卡，卡了看参考思路，隔天重做一遍）。
