## 一、开场：三道正面题

**题 1（速算）**：一个半径 $r$ 的圆盘、圆心到某轴的距离为 $R$（$R>r$，轴在圆盘外），绕轴旋转成的"环面"（甜甜圈），体积是多少？——**不积分**，能不能直接写？

**题 2（平衡点）**：半径 $R$ 的上半圆弧（只是一条线！）——它的"平衡点"在哪？（你们会看到曲线也有形心，且它的 y 坐标是 $\frac{2R}\pi$。）

**题 3（另一种"矩"）**：转动惯量 $I=\int y^2\,dA$——它是**二阶矩**（$dA$ 是"面元"——2.1 马上立语言）。一阶、二阶、零阶——"矩"是一个家族，先把家族认全。

**答案预告**：

1. $V=2\pi^2Rr^2$——因为"体积 $=$ 面积 $×$ 形心路程"：$\pi r^2\times2\pi R$（**巴普斯–古尔丁第二定理**；第五节证明）。
2. 形心在对称轴（y 轴）上，纵坐标 $\bar y_c=\frac{2R}\pi\approx0.637R$——**曲线形心用"弧长加权"算**（第三节）。
3. "矩"家族按被积的**坐标幂次**分级：零阶（面积）、一阶（静矩——决定形心）、二阶（转动惯量——决定抗转）——第二节一张表认全。

> 下一站：把"矩"家族立成账。

## 二、矩的系统：零阶、一阶、二阶

### 2.1 面元 $dA$、区域积分与三张账

**先立语言（本节起处处要用）**：本讲的积分都写成 $\int_\Omega(\cdots)dA$（区域）或 $\int_\gamma(\cdots)ds$（曲线）——先把这两个记号说清楚：

- **$dA$ = 面元**：把区域 $\Omega$ 切成无穷多块"无穷小面积块"，$dA$ 就是其中一块的面积（**面积微元**——与一元的 $dx$ 同辈：$dx$ 是线元、$dA$ 是面元）。
- **$\int_\Omega(\cdots)dA$ = 区域积分**：读作"把每块的（$\cdots$）$\times$ 块面积**累加起来**"的极限。（一般二重积分的正式记号与理论属高数下——31 讲接口会提；**本讲只需要它的一元化算法**，马上给。）
- **一元化算法（本课程唯一需要的算法）**：把 $\Omega$ 竖切成条（位置 $x$、宽 $dx$、高 $h(x)$），**先算条内、再沿条间累加**两步：

$$\int_\Omega(\cdots)\,dA=\int_a^b\Big(\underbrace{\int_{\text{条内}}(\cdots)\,dy}_{\text{一条自己的账}}\Big)dx.$$

——**四条样板**（本节表格与后文全部要用；$f,g$ 为上下边界、条高 $h=f-g$）：

| 累加量 | 条内积分（$y$ 从 $g$ 到 $f$） | 化成一元 |
|---|---|---|
| $1$ | $\int_g^f dy=h$ | $\int_\Omega dA=\int_a^b h\,dx=A$（零阶） |
| $x$ | $x\,h$（**$x$ 在条上是常数**） | $\int_\Omega x\,dA=\int_a^b xh\,dx$ |
| $y$ | $\int_g^fy\,dy=\frac{f^2-g^2}2$ | $\int_\Omega y\,dA=\int_a^b\frac{f^2-g^2}2dx$ |
| $y^2$ | $\int_g^fy^2dy=\frac{f^3-g^3}3$ | $\int_\Omega y^2dA=\int_a^b\frac{f^3-g^3}3dx$ |

（**"先条内后条间"就是 26 讲元素法微元的升级版**：微元里"自己的账"是一元积分——条内积 $y\,dy$、$y^2dy$ 都是旧手艺。）

**曲线的情况（同款立语言）**：$ds$ = **弧微元**（18 讲已有：$ds=\sqrt{1+y'^2}\,dx$）；$\int_\gamma(\cdots)ds$ = "沿曲线累加"，一元化：

$$\int_\gamma(\cdots)ds=\int_a^b(\cdots)\sqrt{1+y'^2}\,dx\quad(\text{或参数化直接代入 }ds).$$

**一句话**：$\int_\Omega\ldots dA$ 与 $\int_\gamma\ldots ds$ 都是"**累加**"的符号——**算法全是一元积分**。

下面进入正题——平面区域 $\Omega$（密度均匀，只谈**几何矩**）、以 $x$ 轴、$y$ 轴为参考轴：

| 阶 | 定义 | 名称 | 回答什么问题 |
|---|---|---|---|
| **零阶** | $\int_\Omega dA=A$ | **面积**（质量的语言） | "有多少量" |
| **一阶** | $M_y=\int_\Omega x\,dA$，$M_x=\int_\Omega y\,dA$ | **静矩**（对 $y$ 轴、$x$ 轴） | "量偏向哪边"（平衡：形心） |
| **二阶** | $I_y=\int_\Omega x^2\,dA$，$I_x=\int_\Omega y^2\,dA$ | **转动惯量**（对轴） | "量离轴多散"（转动的惯性） |

**读表**：**阶数 = 被积函数的坐标幂次**；每升一阶，回答的问题从"多少（零阶：面积）"到"偏哪（一阶：平衡点）"到"多散（二阶：抗转动）"。（"矩"这个词来自物理的"力矩"——它衡量"力 × 力臂"的效果；几何矩是它的"以面积代力"版本——**简介档**。）

### 2.2 一阶矩与形心（核心）

> **定义（形心）**：设区域面积为 $A>0$，
> $$\bar x=\frac{M_y}{A}=\frac1A\int_\Omega x\,dA,\qquad \bar y=\frac{M_x}{A}=\frac1A\int_\Omega y\,dA.$$
> ——**形心 = 一阶矩 ÷ 零阶矩**。

**"÷ 零阶矩"这一步等于"加权平均"**：分子是"位置 × 面积"的累加、分母把总面积归一——形心就是**按面积加权的平均位置**（第七节的数值实验会把它算出来）。

**关键视角（后文处处要用）**：**形心 = "把参考轴搬到它身上，一阶矩归零"的那个位置**。一句话证明：轴过形心时，$\int(x-\bar x)\,dA=\int x\,dA-\bar x A=0$ ✓。这个视角立刻给出两件礼物：

- **对称性白拿**：区域有一条对称轴 ⇒ 关于该轴的一阶矩为 0（两半配对抵消）⇒ **形心在对称轴上**（两条对称轴 ⇒ 形心在交点：圆盘=圆心、矩形=中心）。
- **平行轴定理（二阶矩的平移规律，一节后兑现）**。

**曲线版（弧长加权）**：曲线 $\gamma$（弧长 $L$）的形心：$\bar x=\frac1L\int_\gamma x\,ds$、$\bar y=\frac1L\int_\gamma y\,ds$——**"量"从面积换成弧长**："一阶矩 ÷ 零阶矩"的骨架不变，权重随对象调整。

### 2.3 二阶矩：转动惯量与平行轴定理

**转动惯量**（对 $x$ 轴）：$I_x=\int_\Omega y^2\,dA$——物理上一根绕 $x$ 轴转的均匀薄板的"转动惯性"（**简介档：主要用途是力学，本讲只练几何计算 + 一条平移规律**）。

> **平行轴定理**：$I=I_c+Ad^2$——$I$ 是对任一条轴的转动惯量、$I_c$ 是对**过形心的平行轴**的转动惯量、$d$ 是两轴距离。

**证明（两行——"形心归零一阶矩"的回报）**：把原点搬到形心，写 $x=x̄+u$（$u$ 是相对形心的坐标，$\int u\,dA=0$）：

$$I=\int x^2dA=\int(\bar x+u)^2dA=\bar x^2A+2\bar x\underbrace{\int u\,dA}_{=0}+\int u^2dA=\bar x^2A+I_c\ ✓$$

**读证明**：展开式的"交叉项"之所以整块消失，**正是因为形心把一阶矩清零**——这就是"形心"在二阶矩理论里的全部作用（把 2.2 的"关键视角"用了一次实打实的回报）。

### 2.4 矩的算法接口（一句话）

四条样板已在 2.1 立好——本节只需收拢成一句操作口号：**先条内、后条间**。下一节（形心）是它的第一次正式使用，第七节是数值核对。

## 三、形心的求法（两套）

### 3.1 区域：竖条微元 + "条自身的形心在中间"

区域 $g(x)\le y\le f(x)$（$f,g$ 连续）：竖条微元（宽 $dx$、高 $f-g$）——**条自身也有形心，就在它的中心** $y=\frac{f+g}2$——所以：

$$y\,dA=\frac{f+g}2\,(f-g)\,dx=\frac12\big(f^2-g^2\big)dx\ \Longrightarrow\ \bar y=\frac1A\int_a^b\frac{f^2-g^2}2\,dx,\qquad \bar x=\frac1A\int_a^bx\,(f-g)\,dx.$$

（这就是 2.1 立好的"先条内、后条间"：$\int_\Omega y\,dA$ 的样板直接落地。）

**经典全程（半圆盘的形心）**：$\Omega=\{x^2+y^2\le R^2,\ y\ge0\}$：$A=\frac{\pi R^2}2$；上方 $f=\sqrt{R^2-x^2}$、下方 $g=0$；$\bar x=0$（对称性白拿）：

$$\bar y=\frac{1}{A}\int_{-R}^{R}\frac{R^2-x^2}2\,dx=\frac{2}{\pi R^2}\cdot\frac12\cdot\frac{4R^3}3=\frac{4R}{3\pi}\approx0.4244R\ \checkmark$$

### 3.2 曲线：参数化 + $ds$

**例（上半圆弧的形心——开场题 2 的全程）**：参数化 $x=R\cos\theta$、$y=R\sin\theta$（$\theta\in[0,\pi]$）、$ds=R\,d\theta$、$L=\pi R$：

$$\bar y_c=\frac1{L}\int_0^\pi R\sin\theta\cdot R\,d\theta=\frac{R^2\cdot2}{\pi R}=\frac{2R}\pi\approx0.6366R\ \checkmark$$

（**对照**：半圆弧的形心 $\frac{2R}\pi\approx0.637R$ 比半圆盘的 $\frac{4R}{3\pi}\approx0.424R$ **更靠上**——因为弧的"量"集中在顶端附近，面积的"量"摊在中间——**权重不同、结果不同**。）

### 3.3 两套对照（谁用哪套）

| 对象 | 权重 | 形心公式 | 本讲实例 |
|---|---|---|---|
| 区域（面积） | $dA$ | $\bar y=\frac{1}{A}\int\frac{f^2-g^2}2dx$ | 半圆盘 $\frac{4R}{3\pi}$ |
| 曲线（弧长） | $ds$ | $\bar y_c=\frac1L\int y\,ds$ | 半圆弧 $\frac{2R}\pi$ |

## 四、巴普斯–古尔丁第一定理（侧面积）

> **定理（第一定理）**：平面曲线 $\gamma$（弧长 $L$）绕与它**不相交**的直线 $l$ 旋转一周，所得曲面面积
> $$S=2\pi\bar\rho_c\,L,$$
> 其中 $\bar\rho_c$ 是**曲线的形心**到 $l$ 的距离。等价说法："弧长 $×$ 形心路程"。（命名简介：帕普斯（约 3 世纪）发现、古尔丁（16 世纪）重新发现——故称巴普斯–古尔丁；不同教材对"第一/第二"的编号偶有颠倒，**按公式内容认，别按编号背**。）

### 4.1 证明（一行账 + 合法性账）

取 $l$ 为 $y$ 轴方向、$\gamma$ 在 $x>0$ 一侧。**弧微元 $ds$ 扫出细环带**：$\Delta S\approx2\pi x\,ds$——**误差 $o(ds)$**（26 讲元素法判据：环带的"锥形修正"是高阶账）⇒

$$S=2\pi\int_\gamma x\,ds=2\pi\cdot\underbrace{\frac1L\int_\gamma x\,ds}_{=\bar x_c}\cdot L=2\pi\bar\rho_c\,L\ ✓$$

（中间那步"什么计算都没做"——只是**认出"$\frac1L\int x\,ds$"就是曲线形心的定义**。）

### 4.2 卷面版（考场原样抄写版）

> **卷面版**（默写目标）：
> 设曲线弧长 $L$、形心到轴距离 $\bar\rho_c$。
> **①** 弧微元 $ds$ 绕轴扫出细环带，面积 $\Delta S\approx2\pi\rho\,ds$（元素法：局部误差 $o(ds)$）；
> **②** 求和取极限：$S=2\pi\int\rho\,ds$；
> **③** 由曲线形心定义 $\bar\rho_c=\frac1L\int\rho\,ds$，得 $S=2\pi\bar\rho_c L$。$\blacksquare$

### 4.3 应用（球面积——本定理的招牌）

半圆弧（半径 $R$，上半）绕 $x$ 轴扫出**球面**：$L=\pi R$、弧形心 $\bar y_c=\frac{2R}\pi$（3.2 算过）：

$$S=\pi R\cdot2\pi\cdot\frac{2R}\pi=4\pi R^2\ \checkmark$$

——**球面积公式的巴普斯证明**（实验 3 另有"球面直接积分"双路机核）。

> 下一站：第二条定理（体积）——面积形心派用场。

## 五、巴普斯–古尔丁第二定理（体积）

> **定理（第二定理）**：平面区域 $\Omega$（面积 $A$）绕与它**内部不相交**的直线 $l$ 旋转一周，所得旋转体体积
> $$V=2\pi\bar\rho\,A,$$
> 其中 $\bar\rho$ 是**区域形心**到 $l$ 的距离。（"面积 $×$ 形心路程"。）

### 5.1 证明（三行账：壳层公式 + 一阶矩桥）

取 $l$ 为 $y$ 轴方向、$\Omega$ 在 $x>0$ 一侧（"内部不相交"保证 $\rho=x>0$ 恒成立）：

**第 1 行（壳层公式——26 讲简介层升主角）**：竖条微元（宽 $dx$、高 $h(x)$）绕轴扫出**薄壁圆管**（周长 $2\pi x$、高 $h$、厚 $dx$）：$\Delta V\approx2\pi x\,h(x)\,dx$——**误差 $o(dx)$**（薄管的"壁厚弯曲"是二阶账）⇒

$$V=2\pi\int_a^bx\,h(x)\,dx.$$

**第 2 行（一阶矩桥）**：$\int_a^bx\,h(x)\,dx=\int_\Omega x\,dA=\bar x\,A$（**形心定义**——同样"什么都没算，只是认出来"）。

**第 3 行（合并）**：$V=2\pi\bar x\,A=2\pi\bar\rho\,A$ ✓ $\blacksquare$

### 5.2 卷面版（考场原样抄写版）

> **卷面版**（默写目标）：
> 设区域面积 $A$、形心到轴距离 $\bar\rho$。
> **①** 竖条微元绕轴扫出薄壁圆管：$\Delta V\approx2\pi\rho\,h\,d\rho$ 型（这里 $\rho=x$、高 $h$；元素法：局部误差 $o(dx)$）；
> **②** $V=2\pi\int x\,h(x)\,dx=2\pi\int_\Omega x\,dA$；
> **③** 由形心定义 $\int_\Omega x\,dA=\bar x A$（一阶矩），得 $V=2\pi\bar x A=2\pi\bar\rho A$。$\blacksquare$

### 5.3 应用（环面——开场题 1 的本账）

半径 $r$ 的圆盘、圆心离轴 $R$（$R>r$）：形心在圆心 ⇒ $\bar\rho=R$（对称性白拿）：

$$V=2\pi R\cdot\pi r^2=2\pi^2Rr^2\ \checkmark$$

（实验 1 还有"壳层积分直算"的第二路机核——**两路一致**。）

### 5.4 反求形心（题型）

**识别动作**：题目里出现"**现成的旋转体体积**"（球、环面……）而形心未知 ⇒ **拿第二定理反解**：

$$\bar\rho=\frac{V}{2\pi A}.$$

**标准款**：由球体积 $\frac43\pi R^3=2\pi\bar x\cdot\frac{\pi R^2}2$ ⇒ 半圆盘形心 $\bar x=\frac{4R}{3\pi}$（与 3.1 直接积分**同数**——实验 2 双路机核）；由球面积 $4\pi R^2=2\pi\bar y_c\cdot\pi R$ ⇒ 半圆弧形心 $\bar y_c=\frac{2R}\pi$（**第一定理反用**）。

## 六、适用条件与失效界

### 6.1 适用条件的精确说法

两定理都要求：**轴与对象（区域内部 / 曲线本身）不相交**。精确到"边界"：

- **轴在对象之外**：标准情形 ✓；
- **轴沿边界（相切/重合），不穿内部**：**仍可用** ✓——例：半圆盘（$x\ge0$）绕 $y$ 轴（轴沿它的直边）：$V=2\pi\cdot\frac{4R}{3\pi}\cdot\frac{\pi R^2}2=\frac{4\pi R^3}3$ ✓（**正好是球体积**——左半盘扫出的图形就是球）；
- **轴穿过内部**：**失效**——见 6.2 的完整账。

### 6.2 失效界的账（重数）

**失效现场**：圆盘 $x^2+y^2\le R^2$ 绕它的**直径**（$y$ 轴）——形心在轴上 ⇒ 第二定理给 $V=2\pi\cdot0\cdot A=0$。**而实际扫出的图形是球**（$V=\frac{4\pi R^3}3$）。

**"错"在什么机制**：把圆盘切成竖条看——**轴左侧的条与右侧的条扫出"同一块空间"**：每份面积被"扫"了**两遍**（重数 2）。"面积 $×$ 路程"的记账前提是"**每份面积恰扫一遍**"（重数 1）——前提被破坏时：

| 记法 | 数值（$R=1$） | 是不是"体积" |
|---|---|---|
| 第二定理（距离正负抵消） | $0$ | ✗ |
| 把重数 2 全记上 | $\frac{8\pi}3\approx8.38$ | ✗（重了） |
| 真正的球（点集，数一遍） | $\frac{4\pi}3\approx4.19$ | ✓（但这是"重新定义问题"） |

（实验 4 打印三数。）**结论**：失效不是"公式算得不准"，而是"**问题越出了公式的管辖范围**"——轴穿内部时，"面积×路程"的记账模型不再描述这个旋转（重数≠1）。**考场语**：先检查条件（轴与内部不相交），再动公式。

### 6.3 条件对照表

| 轴的位置 | 重数 | 两定理 |
|---|---|---|
| 与对象不相交 | 1 | ✓ 可用 |
| 沿边界（不穿内部） | 1 | ✓ 可用（半圆盘例） |
| 穿过内部 | ≥2（左右对扫） | ✗ 失效（圆盘例） |

## 八、问法索引（零新知识，只对答案）

> 本节不引入任何新概念，只把高频疑问对到正文出处。

1. **"三种矩一张表怎么背？"**
   （→ 2.1）**幂次表**：零阶 $A$（有多少）、一阶 $\int x\,dA$（偏哪——形心）、二阶 $\int x^2dA$（多散——转动惯量）。只看被积幂次，不看名字。
2. **"形心题的动手顺序？"**
   （→ 3.1/3.2）**先白拿**（对称性⇒建系让 $\bar x=0$）→ **再算一维积分**：区域用 $\frac{f^2-g^2}2$、曲线用 $y\,ds$ → 除以 $A$ 或 $L$。
3. **"两定理在卷面上怎么区分？"**
   （→ 4.2/5.2）**对象**：曲线→第一定理（$S=2\pi\bar\rho_c L$）；区域→第二定理（$V=2\pi\bar\rho A$）。**先查条件**（轴与内部不相交）再写。
4. **"什么时候想起来用反求形心？"**
   （→ 5.4）题目给了**现成体积/面积**（球、环面、球面）而形心未知 ⇒ 用 $\bar\rho=\frac{V}{2\pi A}$（或第一定理版）反解。
5. **"轴穿过区域真的完全不能用？"**
   （→ 6.2）**完全不能用**（不是近似变差——是模型失效：重数≠1）；但"轴沿边界"可以（半圆盘例）。考场先做条件检查。

## 本讲小结

- **矩家族**：零阶（面积——"多少"）、一阶（静矩——"偏哪"：**形心=一阶矩÷面积=一阶矩的零点**）、二阶（转动惯量——"多散"）；**平行轴定理** $I=I_c+Ad^2$（两行证明；交叉项被"形心清零一阶矩"消灭）。
- **形心两套**：区域（竖条微元+条中心：$\bar y=\frac1A\int\frac{f^2-g^2}2dx$）与曲线（弧长加权：$\bar y_c=\frac1L\int y\,ds$）；半圆盘 $\frac{4R}{3\pi}$、半圆弧 $\frac{2R}\pi$。
- **第一定理（侧面积）**：$S=2\pi\bar\rho_c L$——一行账（细环带微元）+ 卷面版；招牌应用球面积 $4\pi R^2$。
- **第二定理（体积）**：$V=2\pi\bar\rho A$——三行账（壳层公式 + 一阶矩桥）+ 卷面版；环面 $2\pi^2Rr^2$；反求形心 $\bar\rho=\frac V{2\pi A}$。
- **条件与失效**：轴与内部不相交（**沿边界可以**）；穿内部 ⇒ 重数≠1、记账模型失效（圆盘三数 0/4.19/8.38）。
- **数值**：七实验机核（环面 $4.6\times10^{-9}$、半圆双路浮点级、球面积差恰 0、失效三数、三矩与平行轴、曲线形心）。

### A. 基础（三矩与判据）

**A1** 矩形 $[0,a]\times[0,b]$：求 $A$、$M_y$、$M_x$、形心、$I_y$（对 $y$ 轴）。

**参考答案**：
$A=ab$；$M_y=\int_0^ax\cdot b\,dx=\frac{a^2b}2$；$M_x=\frac{ab^2}2$；形心 $\left(\frac a2,\frac b2\right)$（与 $M/A$ 一致 ✓）；$I_y=\int_0^ax^2b\,dx=\frac{ba^3}3$。

**A2** 对称性论证：上半圆盘的 $M_y=0$（写出配对抵消的一句证明）。

**参考答案**：
$M_y=\int_{-R}^Rx\sqrt{R^2-x^2}\,dx$；被积函数是**奇函数**（区间对称）⇒ 积分 $=0$ ⇒ $\bar x=0$（形心在 $y$ 轴上）✓。

**A3** 半圆盘对底边（$x$ 轴）的转动惯量 $I_x=\frac{\pi R^4}8$（用竖条公式复写）。

**参考答案**：
竖条上 $\int_0^fy^2dy=\frac{f^3}3$（$f=\sqrt{R^2-x^2}$）⇒ $I_x=\frac13\int_{-R}^R(R^2-x^2)^{3/2}dx$；代 $x=R\sin\theta$：$=\frac{R^4}3\int_{-\pi/2}^{\pi/2}\cos^4\theta\,d\theta$；对称区间 $=2\int_0^{\pi/2}$，用 24 讲华里士 $W_4=\frac{3\pi}{16}$：$I_x=\frac{R^4}3\cdot2\cdot\frac{3\pi}{16}=\frac{\pi R^4}8$ ✓。

**A4** 判断：(1) 三种矩的"阶"按什么分？(2) 形心与一阶矩的关系一句话？(3) 第一定理用谁、第二定理用谁（对象）？(4) 轴沿对象边界（不穿内部）能不能用两定理？

**参考答案**：
(1) **被积函数的坐标幂次**。
(2) **形心 = 一阶矩 ÷ 面积**（也 = "一阶矩的零点"）。
(3) 第一 = **曲线**（弧长）；第二 = **区域**（面积）。
(4) **能**（重数仍为 1；半圆盘绕其直边 ⇒ 球体积）。

### B. 提高（证明与计算）

**B1** 默写第二定理（体积）的卷面版（三行）并标注每行依据。

**参考答案**：
① 竖条微元扫出薄壁圆管：$\Delta V\approx2\pi x\,h\,dx$（元素法：局部误差 $o(dx)$）；
② $V=2\pi\int_a^bxh\,dx=2\pi\int_\Omega x\,dA$（把条上积分与累加合并——积分即"一阶矩"）；
③ $\int_\Omega x\,dA=\bar xA$（**形心定义**）⇒ $V=2\pi\bar xA=2\pi\bar\rho A$。$\blacksquare$

**B2** 半圆弧形心：用参数化直接积分算 $\bar y_c=\frac{2R}\pi$（复写全程）。

**参考答案**：
$x=R\cos\theta$、$y=R\sin\theta$、$ds=R\,d\theta$（$\theta\in[0,\pi]$）、$L=\pi R$：
$\bar y_c=\frac1{\pi R}\int_0^\pi R\sin\theta\cdot R\,d\theta=\frac{R^2\cdot2}{\pi R}=\frac{2R}\pi$ ✓。

**B3** 证明平行轴定理（两行），并写一句"它和形心的关系"。

**参考答案**：
$I=\int x^2dA=\int(\bar x+u)^2dA=\bar x^2A+2\bar x\int u\,dA+\int u^2dA$；$\int u\,dA=0$（形心处一阶矩为零）⇒ $I=\bar x^2A+I_c$ ✓。
关系：交叉项的消失**全靠"形心清零一阶矩"**——形心在此的作用就是把展开式变干净。

### C. 综合（双路与反求）

**C1** 三角形双路对账：区域 $\{0\le y\le x-1,\ 1\le x\le3\}$（顶点 $(1,0),(3,0),(3,2)$）：用第二定理（重心 $\bar x=\frac73$、面积 $2$）与直接壳层积分分别求绕 $y$ 轴体积。

**参考答案**：
第二定理：$V=2\pi\cdot\frac73\cdot2=\frac{28\pi}3$。
壳层：$h(x)=x-1$：$V=2\pi\int_1^3x(x-1)dx=2\pi\Big[\frac{x^3}3-\frac{x^2}2\Big]_1^3=\frac{28\pi}3$ ✓ 两路一致。$\blacksquare$

**C2** 反求形心两款：(1) 用球体积反求半圆盘形心；(2) 用球面积反求半圆弧形心——各写"已知-未知-解"三步。

**参考答案**：
(1) 已知 $V=\frac43\pi R^3$、$A=\frac{\pi R^2}2$ ⇒ $\bar\rho=\frac{V}{2\pi A}=\frac{\frac43\pi R^3}{2\pi\cdot\frac{\pi R^2}2}=\frac{4R}{3\pi}$ ✓。
(2) 已知 $S=4\pi R^2$、$L=\pi R$ ⇒ $\bar\rho_c=\frac{S}{2\pi L}=\frac{4\pi R^2}{2\pi\cdot\pi R}=\frac{2R}\pi$ ✓。$\blacksquare$

### D. 代码（可跑验证）

**D1** 复刻实验 5：半圆盘三矩（$R=1$）——数值算 $A$、$M_y$、$M_x$ 与解析对账（断言 $A\approx\pi/2$、$|M_y|<10^{-10}$、$M_x\approx2/3$，相对容差 $10^{-8}$）。

**参考答案**：

```python
import numpy as np

def simpson(f, a, b, n=None):
    if n is None:
        n = max(2000, int(100 * (b - a)))
        if n % 2 == 1:
            n += 1
    x = np.linspace(a, b, n + 1)
    y = f(x)
    h = (b - a) / n
    return h / 3 * (y[0] + y[-1] + 4 * np.sum(y[1:-1:2]) + 2 * np.sum(y[2:-1:2]))

print("semicircle disk moments (R=1)")
A = simpson(lambda x: np.sqrt(1 - x ** 2), -1, 1, n=200000)   # 端点奇性: 加密
My = simpson(lambda x: x * np.sqrt(1 - x ** 2), -1, 1, n=200000)
Mx = simpson(lambda x: (1 - x ** 2) / 2, -1, 1)
print(f"  A = {A:.10f} (pi/2 = {np.pi/2:.10f})")
print(f"  My = {My:.2e} (对称 -> 0)")
print(f"  Mx = {Mx:.10f} (2/3)")
print(f"  ybar = {Mx/A:.10f} (4/(3pi) = {4/(3*np.pi):.10f})")
assert abs(A - np.pi / 2) / (np.pi / 2) < 1e-8
assert abs(My) < 1e-10
assert abs(Mx - 2 / 3) < 1e-8
print("[OK] 半圆盘三矩全部核实")
```
