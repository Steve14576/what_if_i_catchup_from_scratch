## 一、开场：三道"没有公式可套"的场面

**题 1**：圆 $x^2+y^2=25$。点 $(3,4)$ 处的切线斜率是多少？——**$y$ 没有解出来**（解出来也带根号、分正负支），但切线是圆的客观属性，斜率必存在。怎么求？

**题 2**：参数方程 $x=\cos t,\ y=\sin t$（单位圆）。$\dfrac{dy}{dx}$ 与 $\dfrac{d^2y}{dx^2}$ 是多少？——$y$ 与 $x$ 的关系藏在参数 $t$ 后面，二阶导更是直接求容易想岔。

**题 3**：$y=x^x$ 的导数？——把它当 $x^a$（幂函数）：$x\cdot x^{x-1}$？错（指数也是变量）；当 $a^x$（指数函数）：$x^x\ln x$？也错（底数也是变量）。**"双 $x$"把两条现成公式全部锁死**。

**答案预告**：

1. **$-\dfrac34$**。"两边对 $x$ 求导、把 $y$ 当作 $x$ 的函数"——隐函数求导（第三节），合法性有正经来历。
2. $\dfrac{dy}{dx}=-\cot t$；$\dfrac{d^2y}{dx^2}=-\csc^3t$——**但二阶的算法有个坑**：它不是 $\dfrac{d^2y/dt^2}{d^2x/dt^2}$（这个错误算法会给 $1.732$，正确值是 $-1.5396$，第七节实验 3 数值对照）。第五节把"为什么必须再除一次 $\dfrac{dx}{dt}$"讲透。
3. $y'=x^x(\ln x+1)$——**对数求导**（第四节）把它从"两头不靠"变成两行；它的本质也说清楚：**对数把"乘除幂"结构降维成"加减"结构**。

三题的共同点：**场面变了，工具还是老工具**（链式、隐式恒等、对数律）——本讲不发明新弹药，只开发新地形。

## 二、高阶导数与 $n$ 阶章法

### 2.1 定义与记号

$f$ 的导函数 $f'$ 再求导得**二阶导数** $f''$（物理上是"速度的变化率"=加速度），再求导得**三阶** $f'''$，依此类推得 **$n$ 阶导数** $f^{(n)}$。记号家族：

$$f''(x),\quad y'',\quad \frac{d^2y}{dx^2}\qquad(\text{读"d 平方 y d x 平方"}),\qquad f^{(n)}(x),\qquad \frac{d^ny}{dx^n}.$$

**理解层次提示**：二阶及以上导数**计算为主**（考试形态：求 $y''$、求 $f^{(n)}(0)$）；$\dfrac{d^2y}{dx^2}$ 这个"像分数"的记号的合法来历，和 $\dfrac{dy}{dx}$ 一起在第 12 讲（微分）结清——**现在当记号用**。

### 2.2 常用 $n$ 阶表（附"找规律三步"）

| $f(x)$ | $f^{(n)}(x)$ |
|---|---|
| $e^x$ | $e^x$ |
| $\sin x$ | $\sin\left(x+\dfrac{n\pi}2\right)$ |
| $\cos x$ | $\cos\left(x+\dfrac{n\pi}2\right)$ |
| $x^m$（$m$ 正整数） | $m(m-1)\cdots(m-n+1)x^{m-n}$（$n\le m$）；$n>m$ 时为 $0$ |
| $\ln x$ | $(-1)^{n-1}\dfrac{(n-1)!}{x^n}$ |
| $\dfrac1x$ | $(-1)^n\dfrac{n!}{x^{n+1}}$ |

**"找规律三步"**（考试手算的章法，以 $\sin$ 为例）：

```
第 1 步：算前三阶：(sin)'=cos、(sin)''=−sin、(sin)'''=−cos。
第 2 步：发现周期现象：四阶回 sin——每求导一次相位前进 π/2。
第 3 步：写成一般式 sin(x+nπ/2)，并用"再求一阶导验证公式自洽"收口
        （sin(x+nπ/2) 再求导 = sin(x+(n+1)π/2) ✓ 归纳成立）。
```

$\ln x$ 与 $\frac1x$ 的规律看"每阶多一个负号、分母幂次加一、冒出阶乘链"——同样先算前三阶再归纳。（这两格是 15 讲泰勒公式的前置素材。）

### 2.3 莱布尼茨公式（何时值得用）

> **定理（莱布尼茨公式）**：$(uv)^{(n)}=\displaystyle\sum_{k=0}^{n}\mathrm C_n^{\,k}\,u^{(k)}\,v^{(n-k)}$。
> **来源**：与二项式展开同构（组合系数相同）——对 $n$ 归纳即可：用积法则从 $n$ 推到 $n+1$，配组合恒等式 $\mathrm C_n^k+\mathrm C_n^{k-1}=\mathrm C_{n+1}^k$。骨架一句：**每求一次导，像二项式展开一样"分配打点"**。

**"什么时候值得用"的答案**：当**一个因子是多项式**时——它的高阶导在有限阶后**归零**，求和被截断成几项。经典例：

$$(x^2e^x)^{(20)}=\mathrm C_{20}^0x^2e^x+\mathrm C_{20}^1\cdot2x\,e^x+\mathrm C_{20}^2\cdot2\,e^x=x^2e^x+40xe^x+380e^x$$

（因为 $(x^2)^{(k)}=0$ 对 $k\ge3$——**20 阶的求导，只用三项**。多项式因子把无穷长的公式截成短列。）

## 三、隐函数求导：原理、流程、二阶

### 3.1 原理（疑问 1 的答案）

**局面**：方程 $F(x,y)=0$ 给出 $x$ 与 $y$ 的"捆绑关系"，但没有解出 $y=f(x)$（或解起来很丑）。

**"凭什么能求导"**：先接住一个被声明的问题——**存在性**："$F(x,y)=0$ 在某点附近确实确定了唯一的函数 $y=y(x)$（且可导）"，这件事的叫**隐函数存在定理**，它的严格证明属《数学分析》（需要多元微分——**归地基声明体系的邻居，第 30 讲接口再点名**）。本课程的口径：**接受"局部能确定"（题目给的点都默认满足），专注流程**。

**"把 $y$ 当 $x$ 的函数"合法吗**：合法——这正是存在性结论的内容。于是**方程两边对 $x$ 求导**时：

- 只含 $x$ 的项：正常求导；
- **含 $y$ 的项**：$y$ 是 $x$ 的函数，用**链式法则**——对 $y$ 的表达式求导时要"乘一个 $y'$"：例如 $(y^3)'=3y^2y'$、$(\sin y)'=\cos y\cdot y'$、$(xy)'=y+xy'$（乘积法则+链式联袂）。

### 3.2 流程与例

**三步流程**：① 两边对 $x$ 求导（含 $y$ 项乘 $y'$）→ ② 代数整理解出 $y'$ 的表达式 → ③ 代入具体点（**先代点再解更快**）。

**例 1（开场题 1）**：$x^2+y^2=25$，求在 $(3,4)$ 处的切线斜率。

两边对 $x$ 求导：$2x+2y\,y'=0$。解出：$y'=-\dfrac xy$。代点：$y'(3,4)=-\dfrac34$。

切线：$y-4=-\dfrac34(x-3)$，即 $y=-\dfrac34x+\dfrac{25}4$（顺手看：切线方程恰是 $3x+4y=25$ 的形式——圆的切线的漂亮身份，作业 C1 把它一般化）。

**例 2**：$e^y+xy=e$，求 $y'(0)$（点 $(0,1)$ 在曲线上：$e^1+0=e$ ✓）。

两边求导：$e^y\cdot y'+y+x\,y'=0$（$e^y$ 项用链式；$xy$ 用乘积法则）。整理：$y'(e^y+x)=-y$。**先代点** $(0,1)$：$y'(e+0)=-1$，即 $y'(0)=-\dfrac1e$。（若先解出 $y'=-\dfrac y{e^y+x}$ 再代点，同款——两种顺序都对，先代通常算得快。）

### 3.3 二阶隐导（再求一次导）

对 $x^2+y^2=25$ 求 $y''$：把 $y'=-\dfrac xy$ **再对 $x$ 求导**（商的求导+记住 $y$ 还是 $x$ 的函数）：

$$y''=-\frac{y-x y'}{y^2}\ \overset{\text{代入 }y'}{\underset{}{=}}\ -\frac{y-x\left(-\frac xy\right)}{y^2}=-\frac{y+\frac{x^2}y}{y^2}=-\frac{x^2+y^2}{y^3}=-\frac{25}{y^3}.$$

**关键纪律**：求 $y''$ 时**永远先把 $y'$ 的已知表达式代进去再求导**（或求导后把所有 $y'$ 换成表达式）——凡 $y'$ 僵在分母/分子里没消掉，最后表达式就带"幽灵导数"。圆的 $y''=-\dfrac{25}{y^3}$ 干净收尾（顺带用它兑了一个几何事实：圆的曲率相关量只依赖 $y$ 方向——第 18 讲曲率再见）。

## 四、对数求导：本质与欠条兑现

### 4.1 本质（疑问 3 的答案）

**手法**：对 $y=f(x)$（$f>0$）两边取对数：$\ln y=\ln f(x)$，两边对 $x$ 求导（左边链式：$\dfrac{y'}y$）：

$$\frac{y'}y=\big[\ln f(x)\big]'\quad\Longrightarrow\quad y'=y\cdot\big[\ln f(x)\big]'.$$

**为什么能救**（本质一句话）：**对数把"乘除幂"结构降维成"加减常数倍"结构**——

$$\ln\frac{uv}{w}=\ln u+\ln v-\ln w,\qquad \ln u^v=v\ln u.$$

右边只能做"加减数乘"，求导毫无压力；算完再乘回 $y$。**它对付的正是"乘除幂连成串"的求导**。

**合法性清点**：$\ln$ 是初等函数（07 讲连续与可导区）+ 链式（10 讲）+ $f>0$（对数定义域）——三件全部是已证资产。

### 4.2 应用一：幂指函数 $x^x$（开场题 3 兑现）

$$\ln y=x\ln x\ \Longrightarrow\ \frac{y'}y=\ln x+x\cdot\frac1x=\ln x+1\ \Longrightarrow\ y'=x^x(\ln x+1).$$

**"当 $x^a$ 还是 $a^x$"的回答**：都不当——**取对数把"底上的 $x$"和"指数上的 $x$"拆到了两处**（$\ln x^x=x\ln x$ 的右侧，两个 $x$ 一个在乘积因子、一个在对数里），双 $x$ 的锁就开了。一般幂指函数 $u(x)^{v(x)}=e^{v\ln u}$（恒等式）也有同款通道——**18 讲后续与 12 讲微分记号会把这条通道再翻新一次**。

### 4.3 应用二：连乘商结构（与一个示范）

$$y=\frac{x^2\sqrt{x+1}}{(x-1)^3}\ (x>1)：\quad \ln y=2\ln x+\frac12\ln(x+1)-3\ln(x-1),$$
$$\frac{y'}y=\frac2x+\frac1{2(x+1)}-\frac3{x-1}\ \Longrightarrow\ y'=y\left(\frac2x+\frac1{2(x+1)}-\frac3{x-1}\right).$$

对照：直接对这坨用商法则+积法则+链式，中间式子会很长且容易错——**对数求导把"三层结构的求导"压成"三项加法"**。

### 4.4 欠条兑现：$(x^\alpha)'=\alpha x^{\alpha-1}$（$\alpha$ 任意实数）

10 讲表里登记的那一格，现在补证：设 $x>0$、$y=x^\alpha$，

$$\ln y=\alpha\ln x\ \Longrightarrow\ \frac{y'}y=\frac\alpha x\ \Longrightarrow\ y'=y\cdot\frac\alpha x=\alpha x^{\alpha-1}.$$

$\blacksquare$——**任意实数幂的导数公式正式升级为"已证"**：$x^{\pi}$、$x^{\sqrt2}$、$x^{-2.7}$ 从此放心求导（定义域 $x>0$；整数/分数幂在原来成立的区间上继续有效）。**10 讲的登记区清空一格**。

## 五、参数方程求导：一二阶（含经典坑）

### 5.1 局面与一阶

**局面**：$x=x(t),\ y=y(t)$（如单位圆 $x=\cos t,\ y=\sin t$）——$x$ 与 $y$ 都是参数 $t$ 的函数，$y$ 与 $x$ 的关系"绕了一道"。

**一阶**（顺水推舟）：在 $x=x(t)$ 可逆、$\dfrac{dx}{dt}\ne0$ 的范围内，局部有 $y$ 作为 $x$ 的函数（反函数+复合——10 讲两件工具的联袂）：

$$y=y(t),\ t=t(x)\ \Longrightarrow\ \frac{dy}{dx}=\frac{dy}{dt}\cdot\frac{dt}{dx}=\frac{dy/dt}{dx/dt}.$$

**例**（单位圆）：$\dfrac{dy}{dx}=\dfrac{\cos t}{-\sin t}=-\cot t$。检查一个点：$t=\dfrac\pi3$ 处曲线点在 $\left(\frac12,\frac{\sqrt3}2\right)$，圆在该点切线斜率 $=-\frac{x_0}{y_0}=-\frac{1/2}{\sqrt3/2}=-\frac1{\sqrt3}$，而 $-\cot\frac\pi3=-\frac1{\sqrt3}$ ✓ 与隐函数求导交叉验证通过。

### 5.2 二阶（疑问 2 的坑，完整讲透）

**错误直觉**：$\dfrac{d^2y}{dx^2}\overset{?}{=}\dfrac{d^2y/dt^2}{d^2x/dt^2}$——"既然一阶是两个一阶导的商，二阶就该是两个二阶导的商"。**错**。

**错在哪**：$\dfrac{dy}{dx}$ 这个量（记作 $g(t)$）是 **$t$ 的函数**；而 $\dfrac{d^2y}{dx^2}$ 的定义是 $\dfrac{d}{dx}\left[\dfrac{dy}{dx}\right]$——**对 $x$ 再求导**。现在 $g$ 挂在 $t$ 上，要对 $x$ 求导就必须"换轨道"：先对 $t$ 求导、再乘 $\dfrac{dt}{dx}$（链式法则的标准动作）：

$$\frac{d^2y}{dx^2}=\frac{d}{dx}[g(t)]=\frac{d}{dt}[g(t)]\cdot\frac{dt}{dx}=\frac{\dfrac{d}{dt}\left[\dfrac{dy}{dx}\right]}{\dfrac{dx}{dt}}.$$

**口诀**：**"对 $\dfrac{dy}{dx}$ 再求一遍 $t$ 的导，然后除以 $\dfrac{dx}{dt}$"**——第二个除法是全场核心（第一个商在造 $\frac{dy}{dx}$ 时用过一次，第二次是"换轨道"的代价）。为什么不能直接除两个二阶导？看定义：$d^2y/dt^2$ 里没有"对 $x$ 求导两次"的信息分配——**除法不满足"再求导"的结构**。

**例**（单位圆完整版）：$g(t)=-\cot t$。

$$\frac{d}{dt}[-\cot t]=\csc^2t,\qquad \frac{d^2y}{dx^2}=\frac{\csc^2t}{-\sin t}=-\csc^3t.$$

在 $t=\frac\pi3$：$-\csc^3\frac\pi3=-\left(\frac{2}{\sqrt3}\right)^3=-\frac8{3\sqrt3}\approx-1.5396$。错误公式会给出 $\dfrac{-\sin t}{-\cos t}=\tan t=\sqrt3\approx1.732$——**数值对照在第七节实验 3**（连正负号都反了）。

## 六、相关变化率：方法 + 两例

### 6.1 方法（疑问 5 的答案）

**局面**：两个（或多个）变量都随时间 $t$ 变，已知一个的变化率，求另一个的。**变量间的关系方程从哪来**：几何公式（勾股/相似三角形/面积体积公式）、物理定律——**题目场景里现成**。

**三步流程**：① 写出变量间的关系方程 → ② 两边对 $t$ 求导（**隐函数求导的时间版**：所有变量都是 $t$ 的函数，各乘自己的"变化率"）→ ③ 代入瞬时值解出目标变化率。

### 6.2 例 1：充气气球

球形气球充气，体积增长率 $\dfrac{dV}{dt}=100$ cm³/s。求半径 $r=5$ cm 时半径的增长率。

① $V=\dfrac43\pi r^3$。② 对 $t$ 求导：$\dfrac{dV}{dt}=4\pi r^2\dfrac{dr}{dt}$。③ 代入：$100=4\pi\cdot25\cdot\dfrac{dr}{dt}$ ⇒ $\dfrac{dr}{dt}=\dfrac1\pi\approx0.318$ cm/s。

（顺手读一句：半径越大，同样体积流量撑出的半径增速越小——$1/r^2$ 的衰减，物理直觉在公式里。）

### 6.3 例 2：梯子下滑（经典）

长 10 m 的梯子斜靠墙面，底端以 1 m/s 离墙。当底端距墙 6 m 时，顶端下滑多快？

① 关系：$x^2+y^2=100$（$x$ 底距、$y$ 顶高）。② 对 $t$ 求导：$2x\dfrac{dx}{dt}+2y\dfrac{dy}{dt}=0$。③ 代入 $x=6$（则 $y=8$）、$\dfrac{dx}{dt}=1$：$12+16\dfrac{dy}{dt}=0$ ⇒ $\dfrac{dy}{dt}=-\dfrac34$ m/s（负号：下滑——**求导自带的符号，不用人工补**）。

## 八、问法索引（零新知识，只对答案）

> 本节不引入任何新概念，只把高频疑问对到正文出处。

1. **"隐函数求导最后那一堆 $y'$ 混在式子里，怎么确保没算错？"**
   两条检查（→ 3.2–3.3）：① 解 $y'$ 前把**所有** $y'$ 项聚到一边（系数可能是含 $y$ 的式子——照解不误）；② 求二阶时**先把 $y'$ 的显式表达式代进去**再求导，"幽灵导数"不允许留在最终式里。
2. **"参数二阶我第一次算对了，第二次又错了——有没有一句话防错？"**
   防错句（→ 5.2）：**"二阶 = 对 $\frac{dy}{dx}$ 求 $t$ 导、再除 $\frac{dx}{dt}$"**——写成动作顺序再动手；算完检查"除以 $\frac{dx}{dt}$ 了吗"（漏除是最常见死法，除错成二阶导之比是第二常见）。
3. **"对数求导是不是只能对正函数用？带负号的幂指函数怎么办？"**
   取对数要求 $f>0$（→ 4.1）。带符号的可以对 $|f|$ 取对数或把符号拉出去单独跟踪（$y=|u|^{v}$ 类题先讨论符号区间）；考试最常考的 $x^x$ 在 $x>0$ 上作业。**理解层次：手法在 $f>0$ 上标准，符号处理属边角**。
4. **"$f^{(n)}(0)$ 这种量到底哪里用？"**（疑问 6）
   **泰勒公式**（第 15 讲）：$f(x)=\sum\frac{f^{(n)}(0)}{n!}x^n+\cdots$——高阶导在 $0$ 的取值就是展开系数的原材料。现在先把计算练熟，15 讲把它们装配成武器（→ 钩子在那边）。
5. **"相关变化率题里，求导对象到底是 $t$ 还是 $x$？我总反应慢半拍。"**
   全题变量都是 $t$ 的函数（→ 6.1）——**"一切对 $t$ 求导"**，每个变量掉出一个自己的 $\frac{d\square}{dt}$；这与隐函数求导（一切对 $x$）是同构动作，只是"求导变量"换了。

## 本讲小结

- **高阶导数**：连着求导；记号 $f''$、$f^{(n)}$、$\frac{d^ny}{dx^n}$（分数相 12 讲结清）。常用 $n$ 阶表：$e^x$ 自保、$\sin/\cos$ 相位前进、$x^m$ 有限截断、$\ln/\frac1x$ 的阶乘链。**找规律三步**：算前三阶→看周期/递推→写一般式并自洽验证。
- **莱布尼茨公式**：$(uv)^{(n)}=\sum\mathrm C_n^ku^{(k)}v^{(n-k)}$（与二项式同构，归纳证）。**值得用的场合**：一因子是多项式——高阶导截断求和（$(x^2e^x)^{(20)}$ 只用三项）。
- **隐函数求导**：原理=隐函数存在定理（数学分析辖区，本课程接受其结论）+ 把 $y$ 当 $x$ 的函数的链式。三步：两边对 $x$ 求导→解 $y'$→代点。二阶：**先代 $y'$ 再求导**，消掉"幽灵导数"。
- **对数求导**：本质=**对数把乘除幂降维成加减**；应用：幂指函数（$x^x(\ln x+1)$）与连乘商结构。**欠条兑现**：$(x^\alpha)'=\alpha x^{\alpha-1}$（任意实数 $\alpha$，$x>0$）——10 讲登记区清空一格。
- **参数方程**：一阶 $=\frac{dy/dt}{dx/dt}$（链式+反函数联袂）；**二阶 = 对 $\frac{dy}{dx}$ 求 $t$ 导再除 $\frac{dx}{dt}$**——绝不是两个二阶导之比（数值对照：$-1.5396$ vs $+1.732$）。
- **相关变化率**：关系方程（几何公式）+ 一切对 $t$ 求导 + 代瞬时值；符号自带（梯子的负号）。

### A. 基础（流程复走）

**A1** 求 $y=xe^x$ 的 $y''$；求 $y=\sin^2x$ 的 $y''$。

**参考答案**：
$y=xe^x$：$y'=e^x+xe^x=e^x(x+1)$；$y''=e^x(x+1)+e^x=e^x(x+2)$。
$y=\sin^2x$：先恒等变形 $\sin^2x=\dfrac{1-\cos2x}2$（**变形先行**），$y'=\sin2x$，$y''=2\cos2x$。

**A2** 隐函数：$x^2+xy+y^2=3$ 在点 $(1,1)$ 处求 $y'$ 并写切线方程。

**参考答案**：
两边对 $x$ 求导：$2x+y+xy'+2y\,y'=0$（$xy$ 项用乘积法则）。**先代点** $(1,1)$：$2+1+y'+2y'=0$ ⇒ $3y'=-3$ ⇒ $y'=-1$。
切线：$y-1=-(x-1)$，即 $y=-x+2$。

**A3** 参数方程 $x=t^2,\ y=t^3$（$t>0$）：求 $\dfrac{dy}{dx}$ 与 $\dfrac{d^2y}{dx^2}$。

**参考答案**：
一阶：$\dfrac{dy/dt}{dx/dt}=\dfrac{3t^2}{2t}=\dfrac{3t}2$。
二阶（**防错句走一遍**）：对 $\frac{3t}2$ 求 $t$ 导得 $\frac32$；再除 $\dfrac{dx}{dt}=2t$：$\dfrac{d^2y}{dx^2}=\dfrac{3/2}{2t}=\dfrac3{4t}$。
（自查：漏除会得 $\frac32$——错；两个二阶导之比 $\frac{6t}{2}=3t$——也错。）

**A4** 相关变化率：正方形面积 $A=x^2$，边长以 2 cm/s 增长。当边长 5 cm 时面积增长率？

**参考答案**：
$\dfrac{dA}{dt}=2x\dfrac{dx}{dt}$；代入 $x=5,\ \dfrac{dx}{dt}=2$：$\dfrac{dA}{dt}=20$ cm²/s。

### B. 提高（综合流程与公式）

**B1** 椭圆 $\dfrac{x^2}{16}+\dfrac{y^2}9=1$：求隐式 $y'$；在点 $\left(2,\dfrac{3\sqrt3}2\right)$ 处求 $y''$。

**参考答案**：
对 $x$ 求导：$\dfrac{2x}{16}+\dfrac{2y}{9}y'=0$ ⇒ $y'=-\dfrac{9x}{16y}$。
二阶（先把 $y'$ 代入再求导）：$y''=-\dfrac9{16}\cdot\dfrac{y-xy'}{y^2}=-\dfrac9{16}\cdot\dfrac{y+\dfrac{9x^2}{16y}}{y^2}=-\dfrac9{16}\cdot\dfrac{16y^2+9x^2}{16y^3}$。
用椭圆方程 $9x^2+16y^2=144$（两边乘 144）：$y''=-\dfrac9{16}\cdot\dfrac{144}{16y^3}=-\dfrac{81}{16y^3}$。
代点：$y^3=\left(\dfrac{3\sqrt3}2\right)^3=\dfrac{81\sqrt3}8$ ⇒ $y''=-\dfrac{81}{16}\cdot\dfrac8{81\sqrt3}=-\dfrac1{2\sqrt3}=-\dfrac{\sqrt3}6$。

**B2** 对数求导：$y=\sqrt{\dfrac{x(x+1)}{x-1}}$（$x>1$）：求 $y'$。

**参考答案**：
取对数：$\ln y=\dfrac12\left[\ln x+\ln(x+1)-\ln(x-1)\right]$。
求导：$\dfrac{y'}y=\dfrac12\left(\dfrac1x+\dfrac1{x+1}-\dfrac1{x-1}\right)$。
故 $y'=y\cdot\dfrac12\left(\dfrac1x+\dfrac1{x+1}-\dfrac1{x-1}\right)=\dfrac12\sqrt{\dfrac{x(x+1)}{x-1}}\left(\dfrac1x+\dfrac1{x+1}-\dfrac1{x-1}\right)$。$\blacksquare$
（可选整理：括号内通分也可，但不必——对数求导的答案保持"乘积形式"完全可接受，考试同样给分。）

**B3** 莱布尼茨：求 $(x^2\sin x)^{(10)}$。

**参考答案**：
$x^2$ 的三阶以上导为零 ⇒ 求和只剩 $k=0,1,2$ 三项：
$$(x^2\sin x)^{(10)}=\mathrm C_{10}^0x^2\sin^{(10)}x+\mathrm C_{10}^1\cdot2x\sin^{(9)}x+\mathrm C_{10}^2\cdot2\sin^{(8)}x.$$
用 $\sin^{(n)}x=\sin\left(x+\frac{n\pi}2\right)$：$\sin^{(10)}=\sin(x+5\pi)=-\sin x$；$\sin^{(9)}=\sin\left(x+\frac{9\pi}2\right)=\cos x$；$\sin^{(8)}=\sin(x+4\pi)=\sin x$。
结果：$-x^2\sin x+20x\cos x+45\cdot2\sin x=-x^2\sin x+20x\cos x+90\sin x$。$\blacksquare$
（核对：$\mathrm C_{10}^2=45$，乘回系数 $2$ 得 $90$——组合数别漏乘 $u^{(2)}=(x^2)''=2$。）

### C. 综合（难题档，允许卡）

**C1** 证明：圆 $x^2+y^2=R^2$ 上任一点 $(x_0,y_0)$ 处的切线方程为 $x_0x+y_0y=R^2$（要求处理 $y_0=0$ 的边界情形）。

**参考答案**：
**主情形 $y_0\ne0$**：隐式求导 $2x+2yy'=0$ ⇒ $y'=-\dfrac xy$，在点处斜率 $m=-\dfrac{x_0}{y_0}$。切线：$y-y_0=-\dfrac{x_0}{y_0}(x-x_0)$。两边乘 $y_0$：$y_0y-y_0^2=-x_0x+x_0^2$ ⇒ $x_0x+y_0y=x_0^2+y_0^2=R^2$。$\blacksquare$
**边界情形 $y_0=0$**：此时 $x_0=\pm R$，切线是**竖直直线** $x=\pm R$——公式 $x_0x+y_0y=R^2$ 给出 $\pm Rx=R^2$ 即 $x=\pm R$ ✓ **同一个方程自动覆盖**（证明中"除以 $y_0$"的步骤在这里绕开：$y'$ 无穷大、用竖直切线口径写——两情形合起来公式统一成立）。
（这道题的两层价值：① 把"点斜式+变形"走完整；② **除以变量类操作必须查边界**——$y_0=0$ 时 $-\frac{x_0}{y_0}$ 无意义，边界单独处理后又发现公式统一——"先分情形、再合并"是证明题的常见节奏。）

**C2** 摆线 $x=t-\sin t,\ y=1-\cos t$（$0<t<2\pi$）：求 $\dfrac{dy}{dx}$ 与 $\dfrac{d^2y}{dx^2}$。

**参考答案**：
一阶：$\dfrac{dy/dt}{dx/dt}=\dfrac{\sin t}{1-\cos t}\left(=\cot\dfrac t2\ \text{（半角公式）}\right)$。
二阶（防错句）：对 $\dfrac{\sin t}{1-\cos t}$ 求 $t$ 导（商法则）：
$$\frac{d}{dt}\left[\frac{\sin t}{1-\cos t}\right]=\frac{\cos t(1-\cos t)-\sin t\cdot\sin t}{(1-\cos t)^2}=\frac{\cos t-(\cos^2t+\sin^2t)}{(1-\cos t)^2}=\frac{\cos t-1}{(1-\cos t)^2}=-\frac1{1-\cos t}.$$
再除 $\dfrac{dx}{dt}=1-\cos t$：$\dfrac{d^2y}{dx^2}=-\dfrac1{(1-\cos t)^2}$。$\blacksquare$
（摆线是"最速降线""等时曲线"的历史名角——17 世纪最强智力竞赛的题目；此处先把二阶算对，它的弧长与面积是 26–27 讲的应用素材。）

### D. 代码（可跑验证）

**D1** 复刻并扩展实验 3：对单位圆参数方程，用参数差分核对一阶（$t_0=\pi/3$ 处趋 $-\cot t_0=-0.5774$）；打印二阶的**正确公式值** $-\csc^3t_0\approx-1.5396$ 与**错误公式值** $\tan t_0\approx1.732$ 的对照（断言两者异号且量级不同，说明"除错一次"的后果）。

**参考答案**：

```python
import numpy as np

t0 = np.pi / 3
x = lambda t: np.cos(t)
y = lambda t: np.sin(t)

print("一阶核对 (参数差分, t0 = pi/3):")
for h in [1e-3, 1e-5, 1e-7]:
    dydt = (y(t0 + h) - y(t0)) / h
    dxdt = (x(t0 + h) - x(t0)) / h
    print(f"  h = {h:.0e}: (dy/dt)/(dx/dt) = {dydt / dxdt:.8f}, 公式值 -cot(t0) = {-np.cos(t0) / np.sin(t0):.8f}")

correct = -1 / np.sin(t0) ** 3           # -csc^3 t0 正确
wrong = np.tan(t0)                        # 错误公式 (d2y/dt2)/(d2x/dt2) 会给出 tan t0
print(f"二阶对照: 正确值 -csc^3 = {correct:.6f}, 错误公式值 tan = {wrong:.6f}")
assert correct < 0 < wrong                # 异号
print("[OK] 参数二阶: 正确公式与错误公式异号, 除错一次的后果一目了然")
```

预期输出（实测，确定性计算可复跑）：

```

  h = 1e-03: (dy/dt)/(dx/dt) = -0.57668379, 公式值 -cot(t0) = -0.57735027
  h = 1e-05: (dy/dt)/(dx/dt) = -0.57734360, 公式值 -cot(t0) = -0.57735027
  h = 1e-07: (dy/dt)/(dx/dt) = -0.57735020, 公式值 -cot(t0) = -0.57735027
二阶对照: 正确值 -csc^3 = -1.539601, 错误公式值 tan = 1.732051
[OK] 参数二阶: 正确公式与错误公式异号, 除错一次的后果一目了然
```

（核对点：一阶差商随 $h$ 缩稳定趋 $-0.57735$；二阶两值 $-1.539600$ 与 $+1.732051$ **异号**——错误公式连符号都反了，断言 `correct < 0 < wrong` 通过。）
