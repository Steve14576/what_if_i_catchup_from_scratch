## 一、开场：三道"会不会想歪"题

**题 1**：$\displaystyle\int_0^2x\sqrt{x^2+1}\,dx$——不定积分的凑微分你信手拈来；**定积分"换元要不要换限"**？（不换的话，错出多少？）

**题 2**：$\displaystyle\int_{-1}^1x^3dx$ 与 $\displaystyle\int_{-1}^1x^2dx$——**不硬算**，一眼出？

**题 3**：$\displaystyle\int_0^{\pi/2}\sin^4x\,dx$——"华里士公式"三个字听说过吗？它管哪一段区间？

**答案预告**：

1. **必须换限**——把 $x$ 的刻度 $0\to2$ 换成 $u$ 的刻度 $1\to5$（22 讲：换元=换刻度）；**不换限的错误值**是 $\frac{4\sqrt2}3\approx1.886$，正确值 $\frac{5\sqrt5-1}3\approx3.393$——**错了一倍多**（实验 1 的对照表）。
2. $\int_{-1}^1x^3dx=0$（奇函数——正负抵消）；$\int_{-1}^1x^2dx=\frac23$（偶函数——右边算一半乘二）——**对称性两公式**（第三节）。
3. $=\frac{3\pi}{16}$——**华里士公式**的疆域是 $[0,\frac\pi2]$ 上**纯** $\sin^n$ 或 $\cos^n$（换区间直接套会错——实验 3 给倍数对照）。

> 下一站：第一件武器——换元与换限。

## 二、换元法：上下限跟着换刻度

### 2.1 定理与两行证明

> **定理（定积分换元）**：设 $f$ 连续、$\varphi$ 有连续导数，则
> $$\int_a^bf(\varphi(x))\,\varphi'(x)\,dx=\int_{\varphi(a)}^{\varphi(b)}f(u)\,du.$$

**证明（N-L 两行）**：设 $F$ 是 $f$ 的原函数。左边被积函数的原函数是 $F(\varphi(x))$（**链式复核**：$(F(\varphi(x)))'=f(\varphi(x))\varphi'(x)$ ✓）⇒ 由 N-L：

$$\text{左}=F(\varphi(x))\Big|_a^b=F(\varphi(b))-F(\varphi(a));$$

$$\text{右}=F(u)\Big|_{\varphi(a)}^{\varphi(b)}=F(\varphi(b))-F(\varphi(a)).$$

两边相等 ✓。$\blacksquare$（**读证明**：换元定理不过是"链式法则 + N-L"的组合技——**没有新定理**。）

### 2.2 "为什么必换限"（疑问 1）与不回代路线

**换限=换刻度**（22 讲的 $dx$ 现在说话）：$u=\varphi(x)$ 是一次**刻度变换**——"从 $x$ 的 $a$ 到 $b$"在 $u$ 的世界里对应的刻度就是"从 $\varphi(a)$ 到 $\varphi(b)$"。**不换限等于拿着 $x$ 的刻度去读 $u$ 的表**——读数无意义。

**两条路线对照**（不定积分 vs 定积分换元）：

| | 不定积分换元 | 定积分换元 |
|---|---|---|
| 换元后 | 对 $u$ 积分 | 对 $u$ 积分 |
| 收尾 | **回代**成 $x$（再 $+C$） | **换限**（算完即答案，**免回代**） |
| 原因 | 答案要写成 $x$ 的函数 | 答案是个**数**——限一换，"谁的世界"已经对上 |

**演示（开场题 1）**：$\int_0^2x\sqrt{x^2+1}\,dx$：$u=x^2+1$、$du=2x\,dx$ ⇒ $x\,dx=\frac12du$；**限**：$x=0\Rightarrow u=1$，$x=2\Rightarrow u=5$：

$$=\frac12\int_1^5\sqrt u\,du=\frac12\cdot\frac23u^{3/2}\Big|_1^5=\frac{(5\sqrt5-1)}3\approx3.393.$$

**"忘换限"的样子**（反面教材）：若照旧写 $\frac12\int_0^2\sqrt u\,du=\frac{(2\sqrt2)\cdot2}3\approx1.886$——**同样的被积函数、错的刻度**——数值差 $1.5$ 以上（实验 1）。

### 2.3 反向换元（$x=\varphi(t)$ 型）与边界说明

也可以用**第二换元方向**（19/20 讲的手艺原样搬）：$x=a\sin t$ 等——**限就按 $x$ 的端点反解 $t$**：

$$\int_0^1\sqrt{1-x^2}\,dx\ \xrightarrow{x=\sin t}\ \int_0^{\pi/2}\cos^2t\,dt=\frac\pi4$$

（**双路线对照**：这是四分之一单位圆面积——**几何一眼也是 $\frac\pi4$**——手法与几何互证；$\int_0^{\pi/2}\cos^2t\,dt=\frac12\cdot\frac\pi2=\frac\pi4$ 用了降幂（20 讲）。）

**边界诚实**（简介）：换元 $\varphi$ **不必单调**——定理照样成立；但**不单调时"路径可能折返"**（同一段被来回扫），结果仍然正确、容易亲手算错——**考试题默认单调换元**，遇到怪换元回头查限的走向。（**理解层次：知道有这回事**。）

## 三、对称性：偶倍奇零

### 3.1 两公式与证明（疑问 2）

> **定理（对称性公式）**：设 $f$ 在 $[-a,a]$ 上连续：
> $$f\ \text{偶}:\ \int_{-a}^af=2\int_0^af;\qquad f\ \text{奇}:\ \int_{-a}^af=0.$$

**证明（拆区间 + 换元）**：$\int_{-a}^af=\int_{-a}^0f+\int_0^af$——对第一段换元 $x=-t$（$dx=-dt$，限 $-a\to0$ 变 $a\to0$）：

$$\int_{-a}^0f(x)dx=\int_a^0f(-t)(-dt)=\int_0^af(-t)dt=\begin{cases}+\int_0^af(t)dt,&f\ \text{偶}\\-\int_0^af(t)dt,&f\ \text{奇}\end{cases}$$

⇒ 偶：两段相加 $=2\int_0^af$；奇：相消 $=0$ ✓。$\blacksquare$

**"前提谁在查"（疑问 2 后半）**：**动手前的第一扫就是它**——"区间对称吗？"（$[-a,a]$、"$[-2,2]$"——**不对称的区间一切免谈**）；然后是"函数的奇偶性对得上吗"。**两个都过才启动**。

**两例**：$\int_{-1}^1x^3dx=0$（奇）；$\int_{-1}^1x^2dx=2\cdot\frac13=\frac23$（偶）。**混合函数的用法**：$\int_{-2}^2(x^3+3x^2)dx=0+3\cdot2\int_0^2x^2dx=3\cdot2\cdot\frac83=16$（**逐项拆开**：奇项归零、偶项翻倍）。

### 3.2 对称性的推广视角——引出下一节

偶倍奇零的本质是"**关于中点 $0$ 的配对**"：$x$ 与 $-x$ 处的值按奇偶性交换。**把配对中心从 $0$ 挪到任意中点 $\frac{a+b}2$**，就是下一节的**区间再现**（它是"对称性的区间版"，不要求奇偶、不要求中心在原点）。

> 下一站：区间再现——对称性的一般形态。

## 四、区间再现（疑问 3）

### 4.1 公式与一行证明

> **公式（区间再现）**：设 $f$ 连续：
> $$\int_a^bf(x)\,dx=\int_a^bf(a+b-x)\,dx.$$

**证明（换元 $x=a+b-t$）**：$dx=-dt$；$x:a\to b$ ⇒ $t:b\to a$：

$$\int_a^bf(x)dx=\int_b^af(a+b-t)(-dt)=\int_a^bf(a+b-t)\,dt\ \checkmark\quad\blacksquare$$

**读法**："把图像关于区间中点 $\frac{a+b}2$ 翻个面，**积分值不变**"——为什么：翻面把左侧与右侧配对，**每一对的底边等长、高度互换**，面积账不变。

### 4.2 杀手锏演示（疑问 3 的答案）

**类型 A（"$x$ 与 $f$ 错位"型）**：$\displaystyle I=\int_0^\pi x\sin x\,dx$——直接分部可以做，但要两步；**再现一步杀**：

$$I=\int_0^\pi(\pi-x)\sin(\pi-x)dx=\int_0^\pi(\pi-x)\sin x\,dx\quad(\text{用 }\sin(\pi-x)=\sin x).$$

**两式相加**（$I$ 与它的再现版把 $x$ 消掉）：

$$2I=\int_0^\pi\pi\sin x\,dx=\pi\cdot2\ \Longrightarrow\ I=\pi.$$

**一般版**（同名考点）：$\int_0^\pi xf(\sin x)dx=\frac\pi2\int_0^\pi f(\sin x)dx$——**推导同款**（再现 + 相加）：两者的平均是"把 $x$ 换成对称位置的 $\pi-x$"⇒ 片内常数化。**使用条件**：被积式里 $f(\sin x)$ 部分在 $x\to\pi-x$ 下**不变**（$\sin(\pi-x)=\sin x$ ✓；**若是 $\cos$，注意 $\cos(\pi-x)=-\cos x$ 不符**——换别的对称或不可用）。

**类型 B（"再现解方程"型）**：$\displaystyle I=\int_0^1x(1-x)^{99}dx$：再现（$a+b=1$）：

$$I=\int_0^1(1-x)\cdot x^{99}\,dx=\int_0^1x^{99}dx-I\ \Longrightarrow\ 2I=\frac1{100}\ \Longrightarrow\ I=\frac1{200}.$$

（**"再现回自己"→ 列方程解出**——与 20 讲循环型分部同一种解方程思路。）

## 五、华里士公式（疑问 4）

### 5.1 递推推导（分部法完整链）

记 $W_n=\displaystyle\int_0^{\pi/2}\sin^nx\,dx$（$n\ge0$ 整数；对 $\cos^n$ 完全同款——换元 $x\to\frac\pi2-x$ 一句话，见 5.3）。对 $n\ge2$ 分部（$u=\sin^{n-1}x$、$dv=\sin x\,dx$、$v=-\cos x$）：

$$W_n=\big[-\sin^{n-1}x\cos x\big]_0^{\pi/2}+(n-1)\int_0^{\pi/2}\sin^{n-2}x\cos^2x\,dx.$$

**边界项 $=0$**（$x=0$：$\sin=0$；$x=\frac\pi2$：$\cos=0$）；余项用 $\cos^2=1-\sin^2$：

$$W_n=(n-1)\int_0^{\pi/2}\sin^{n-2}dx-(n-1)W_n=(n-1)W_{n-2}-(n-1)W_n\ \Longrightarrow\ \boxed{\ nW_n=(n-1)W_{n-2}\ }$$

**底座**：$W_0=\frac\pi2$（常数积）、$W_1=1$（$\int_0^{\pi/2}\sin x\,dx=1$）——**递推从底座逐层降** ✓。

### 5.2 公式与双阶乘记号

**双阶乘记号**（声明确认）：$n!!=$ 从 $n$ 起**隔一个乘一个**直到 1 或 2——如 $5!!=5\cdot3\cdot1$、$6!!=6\cdot4\cdot2$。于是：

$$W_n=\int_0^{\pi/2}\sin^nx\,dx=\begin{cases}\dfrac{(n-1)!!}{n!!}\cdot\dfrac\pi2,&n\ \text{偶},\\[6pt]\dfrac{(n-1)!!}{n!!},&n\ \text{奇}.\end{cases}$$

**例**：$W_4=\frac{3!!}{4!!}\cdot\frac\pi2$——逐件算清：$4!!=8$、$3!!=3$，故 $W_4=\frac38\cdot\frac\pi2=\frac{3\pi}{16}\approx0.589$；$W_5=\frac{4!!}{5!!}=\frac8{15}\approx0.533$。

### 5.3 适用边界与误用对照（疑问 4 后半——"错了多少"）

**公式的适用条件**（三件）：①区间**恰为** $[0,\frac\pi2]$；②幂次是**纯** $\sin^n$ 或**纯** $\cos^n$（$\cos$ 版：换元 $x\to\frac\pi2-x$ 把 $\cos$ 变 $\sin$、区间不变——**一句换元就转让**）；③$n$ 整数幂（实数幂另有 Beta 函数语言——挂名不展开）。

**误用对照（数字说话）**：$\int_0^\pi\sin^4x\,dx$ 直接套 $W_4$ 得 $\frac{3\pi}{16}\approx0.589$——**错**，真值 $\frac{3\pi}8\approx1.178$（**差两倍**）。原因：$\sin^4$ 关于 $x=\frac\pi2$ 对称——$\int_0^\pi=2\int_0^{\pi/2}=2W_4$——**半周期对称要手动补倍数**（"区间不对"的正确补救：先化归到 $[0,\frac\pi2]$ 再套）。**混合幂**（$\sin^m\cos^n$）的公式存在（双阶乘分式版）——**知道有、遇到查**，本课程主练纯幂。

## 六、周期性平移与识别章法

### 6.1 周期性（疑问 5）

> **公式**：$f$ 以 $T$ 为周期 ⇒ $\displaystyle\int_a^{a+T}f(x)dx=\int_0^Tf(x)dx$（**对一切 $a$**）。

**证明（一句话——变限求导版）**：记 $G(a)=\int_a^{a+T}f$：$G'(a)=f(a+T)-f(a)=0$（变限求导——23 讲！，周期给出 $f(a+T)=f(a)$）⇒ $G$ 是常数 ⇒ $G(a)=G(0)=\int_0^Tf$ ✓ $\blacksquare$（**“为什么”的图形读法**：整周期段跟着窗口滑动，进出口保持平衡——平移不变。）

**用途**：$\int_a^{a+T}$ 型把限"平移回家"，再上华里士/对称：$\int_{10}^{10+2\pi}\sin^2x\,dx=\int_0^{2\pi}\sin^2x\,dx=4W_2$——算清：$W_2=\frac{1!!}{2!!}\cdot\frac\pi2=\frac\pi4$，故 $=4\cdot\frac\pi4=\pi$ ✓。

### 6.2 识别章法：动手前 30 秒扫描表（疑问 6——元问题）

```
① 区间对称（[-a,a]）吗？—— 是 → 拆奇偶（偶倍奇零）
② 被积式含 "x 与 f(a+b−x) 结构"（如 x·sin x）？—— 是 → 区间再现
③ 区间是 [0,π/2] 且纯 sin^n/cos^n？—— 是 → 华里士
④ 周期函数 + 怪异上下限（差为周期）？—— 是 → 平移回标准区间
⑤ 都不是 —— 老实走：换元（换限！）→ 分部 → N-L
```

**扫描表的价值**：把"灵光一闪"变成**固定动作**——考场上先扫 30 秒，常常省下 10 分钟硬算（且硬算易错）。**五件武器的优先级**：能"不动手"（对称/再现/华里士/周期）就不动手；动手就按 ⑤ 的顺序。

## 七、数值实验：四连验证

**方法**：数值积分用 Simpson 法（$n=2000$，误差 $\sim10^{-13}$ 级——误差账先算后设阈值：以下断言全部用解析值对照，阈值与量级匹配）。

完整脚本在 `scripts/lec24-01_verify_integral_tech.py`（运行：`uv run --with numpy python scripts/lec24-01_verify_integral_tech.py`）。

### 实验 1：换限对账与"忘换限"的代价

数值 Simpson 算 $\int_0^2x\sqrt{x^2+1}dx$：与解析 $\frac{5\sqrt5-1}3$ 对照；同时打印"忘换限"错误值 $\frac{4\sqrt2}3$。

（实测，全脚本 0.00 秒跑完，可复跑）：

```
  数值 = 3.3934466292, 解析 (5sqrt5-1)/3 = 3.3934466292, 相对差 = 4.84e-15
  忘换限值 4sqrt2/3 = 1.8856180832, 与真值差 = 1.5078
```

**结论（实测坐实）**：数值与解析吻合到 $10^{-15}$ 级；忘换限的错误值与真值相差 $\approx1.51$——**"必换限"的量化证据**。

### 实验 2：对称性实弹

$\int_{-1}^1x^3dx$（应 0）与 $\int_{-1}^1x^2dx$（应 $\frac23$）：Simpson 数值。

（实测）：

```
  x^3: 数值 = 8.527e-17 (理论 0); x^2: 数值 = 0.6666666667 (理论 0.6666666667)
```

**结论（实测坐实）**：$8.5\times10^{-17}$（浮点零点级）与 $0.6667$——奇消偶倍的两行实弹。

### 实验 3：华里士与"区间误用"对照

$W_4=\frac{3\pi}{16}$、$W_5=\frac{8}{15}$（Simpson 核对）；$\int_0^\pi\sin^4x\,dx$ 的数值与"直接套 $W_4$""正确 $2W_4$"三者并列。

（实测）：

```
  W4: 数值 = 0.5890486225, 解析 = 0.5890486225; W5: 数值 = 0.5333333333, 解析 = 0.5333333333
  int_0^pi sin^4: 数值 = 1.1780972451, 直接套W4 = 0.5890486225, 2W4 = 1.1780972451
```

**结论（实测坐实）**：$W_4,W_5$ 数值与解析 10 位全同；$\int_0^\pi\sin^4=1.1781$ 恰为 $2W_4$ 而"直接套"只有 $0.5890$——**差两倍**的活体。

### 实验 4：区间再现实弹

$\int_0^\pi x\sin x\,dx$：Simpson 数值 vs 解析 $\pi$；并验证再现恒等式（$\int_0^\pi(x)\sin x$ 与 $\int_0^\pi(\pi-x)\sin x$ 的数值相等）。

（实测）：

```
  数值 = 3.1415926536, pi = 3.1415926536, 差 = +1.07e-13
  再现版数值 = 3.1415926536, 与直接版差 = +0.00e+00
```

**结论（实测坐实）**：与 $\pi$ 吻合到 $10^{-13}$；再现两版数值**恰为 0 差**（被积函数逐点不同、积分值逐位相同）——"翻面不变账"的实弹。

## 本讲小结

- **换元**：定理=链式+N-L 两行；**换限=换刻度**（22 讲 $dx$ 的落地）；**换限后免回代**；反向换元（$x=\varphi(t)$）限按端点反解；$\varphi$ 不必单调（简介）。

### B. 提高（推导与再现）

**B1** 证明换元定理与对称性公式（各自按正文路线写全）。

**参考答案**：
**换元**：$F$ 为 $f$ 原函数；左 $=F(\varphi(x))\big|_a^b$（链式复核）；右 $=F(u)\big|_{\varphi(a)}^{\varphi(b)}$——同值。$\blacksquare$

**B2** 完整推导华里士递推（分部法三行），并算出 $W_6$。

**参考答案**：

### D. 代码（可跑验证）

**D1** 复刻并扩展实验 1、3：(a) Simpson 算 $\int_0^2x\sqrt{x^2+1}dx$ 对照解析 $\frac{5\sqrt5-1}3$（断言 $<10^{-8}$ 相对），并打印"忘换限值" $\frac{4\sqrt2}3$ 与真值之差（断言 $>1$）；(b) 算 $\int_0^\pi\sin^4x\,dx$ 与 $W_4=\frac{3\pi}{16}$、$2W_4$ 三者对照（断言数值 $\approx2W_4$ 且与 $W_4$ 相差 $>0.5$）。

**参考答案**：

```python
import numpy as np

def simpson(f, a, b, n=2000):
    x = np.linspace(a, b, n + 1)
    y = f(x)
    h = (b - a) / n
    return h / 3 * (y[0] + y[-1] + 4 * np.sum(y[1:-1:2]) + 2 * np.sum(y[2:-1:2]))

print("(a) int_0^2 x sqrt(x^2+1) dx")
num = simpson(lambda x: x * np.sqrt(x ** 2 + 1), 0, 2)
exact = (5 * np.sqrt(5) - 1) / 3
wrong = 4 * np.sqrt(2) / 3
print(f"  数值 = {num:.10f}, 解析 = {exact:.10f}, 相对差 = {abs(num - exact) / exact:.2e}")
print(f"  忘换限值 = {wrong:.10f}, 与真值差 = {abs(wrong - exact):.4f}")
assert abs(num - exact) / exact < 1e-8
assert abs(wrong - exact) > 1.0

print("(b) int_0^pi sin^4 x dx vs W4 与 2W4")
num2 = simpson(lambda x: np.sin(x) ** 4, 0, np.pi)
W4 = 3 * np.pi / 16
print(f"  数值 = {num2:.10f}, W4 = {W4:.10f}, 2*W4 = {2 * W4:.10f}")
assert abs(num2 - 2 * W4) / (2 * W4) < 1e-8
assert abs(num2 - W4) > 0.5
print("[OK] 换限与华里士区间的双重对照通过")
```
