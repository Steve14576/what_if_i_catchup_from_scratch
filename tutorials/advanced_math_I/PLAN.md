## 一、目标与读者画像

### 课程目标（学完能做什么，行为化）

- 能**读懂并写出** ε-N / ε-δ 证明：给一个具体数列或函数极限，能独立写出严格证明（找 N / 找 δ），能说出量词顺序为什么不能换。
- 能**完整陈述并证明**费马引理、罗尔、拉格朗日、柯西四大中值定理，说清每个条件缺一个会怎样（有反例）；能对中值等式证明题**系统地构造辅助函数**（原函数法 / 常数 k 法 / 因子法），不再是"看答案抄魔法"。
- 能用单调性、凹凸性、**泰勒公式**完整地解决极值、不等式、**极值点偏移**类难题，每一步说得出依据；知道对称化构造的合法来源（凸性）。
- 能说清 **N-L 公式为什么成立**（连续 ⇒ 变限积分可导 ⇒ 原函数存在 ⇒ 牛顿-莱布尼茨），不再只有"反向求导"口诀；会不定积分全套（凑微分 / 三角代换 / 分部 / 有理函数 / 三角有理式）、定积分全套（换元必换限 / 对称性 / 区间再现 / 华里士）。
- 能用**黎曼和**从定义把 ∫₀¹x²dx 算出来；会用**元素法**处理面积 / 体积 / 弧长 / 旋转体；能**严格证明并正确使用巴普斯定理**（含适用条件与失效反例）。
- 会反常积分的敛散判别与计算。
- （模块 D）会解可分离变量、齐次、一阶线性微分方程与二阶常系数线性微分方程（通解全流程）。
- 讲义中每个数值结论，都能用 `scripts/` 里的归档脚本复跑验证。
- **总验收**：拿一份正经的期末 / 考研水准高数（上）试卷，能在限时内做下来，且每步写得出严格依据。

### 读者是哪一种（决策记录）

**带旧心智模型来重学的大一新生**——skill 原则 11 四分类中最接近"带旧语言经验来的"：不是零基础，而是**提前学过、学得半斤八两、带着一批错误直觉和混乱记忆**，必须逐条破误，同时有真实可用的资产不能全推倒。用户 2026-09 画像原话要点：

- 大一新生，容易**过度思考**（会反复纠结定义的边角、把简单问题想复杂、卡住时往哲学方向发散）。
- 高中提前看过微积分，学得**半斤八两且混乱**。
- **ε-δ 与级数等基础概念完全没有甚至开倒车**（级数属高数下，本课程在接口讲给地图；"开倒车"指把 0.999…=1 当悖论、无穷小当"很小的数"参与运算这类症状）。
- 只知道"**反向求导约等于求积分**"。
- 高中"了解"过**极值点偏移**、**三个中值定理**，仅限了解甚至**记乱了**。
- 课余不严谨地"证明"过中值定理和二维三维**旋转巴普斯定理**，自我陶醉；**没有把公式定理武器化，考试会慌乱**。
- 很想学。

**含义（写作策略由此定）**：

1. 每条旧直觉误会（下方清单）在对应讲有**就地破误段**（原则 13：新知识先进正文系统节，破误段只做对答案与校准）。
2. 读者的资产（导数计算熟练、数列与不等式工具、图象直觉）**正面肯定并保留**，但图象直觉降级为"启发手段，不能充当证明"。
3. 防过度思考的专项设计：每个严格定义给"理解到什么程度就够了"的三档标注（原则 7）；给"卡住协议"（卡住时先做数值实验 / 先做具体例子，不空转）；导览页写明"第一次读不懂 ε 定义是正常的，数学家自己花了两百年才写对"。
4. 期末绝望模式（skill 适用场景）：**绝对不能想当然、绝对不能漏或跳知识点、要系统地组织**。

### 可保留资产清单（不全推倒，写作时正面接住）

- 高中导数计算熟练：多项式、sin/cos、eˣ、ln x、四则与复合的基本操作（09–11 讲直接升级为严格版，不从头当新知识灌输）。
- 数列与不等式工具：等差等比、基本不等式、放缩直觉（05 讲单调有界、06 讲比较，直接调用）。
- 图象直觉：保留为启发手段与"预判答案"工具，明确定位为**不能充当证明**（每个定理仍给完整代数证明）。
- 中值定理"听说过"的印象：转正为"结构记忆"——罗尔是拉格朗日 g(x)=x 的特例、柯西是拉格朗日的参数化推广（13/14 讲从零证明，但承认读者见过名字）。

### 三大纲领（课程总策略，各讲自查）

- **A 严谨地基**：ε 语言与"定义 → 定理 → 证明 → 反例"完整循环，全程使用；每讲至少一个完整证明或完整严格定义，让读者"知道严谨长什么样"而不只是"被要求严谨"。
- **B 洗习惯**：旧直觉误会清单逐条破；立规矩"图像启发 ≠ 证明"；每次用定理先报条件。
- **C 武器化**：把定理变成解题系统——辅助函数构造系综（原函数法 / 常数 k 法 / 因子法）、等价替换的合法边界表、泰勒打题模板（展开到第几阶）、极值点偏移的凸性本质与对称化来源、巴普斯的适用条件与验证。

### 例子风格（决策记录）

数学课的"能跑的成品"=**可检验的严格解题行为**（不强行编故事入戏，skill 原则 14 新表述）。每个抽象概念配三样：

1. 严格定义 + 直觉图像（图像只做启发，讲义里明说）；
2. 手算例题（贴近考卷，含完整过程）；
3. numpy 数值实验（把结论坐实成具体数字：ε-N 找具体 N、黎曼和收敛表、巴普斯与直接积分对照一致等，进 `scripts/`，可复跑）。

另配**反例库**：每个定理配"条件缺一个就崩"的反例（连续不可导、开区间无最值、区域与轴相交时巴普斯失效等）——这是防"图像当证明"的核心疫苗。

### 作业风格（决策记录）

每讲作业按**基础 / 提高 / 综合（难题）**三档，题量饱和。全部可自验证：数值题附答案与验算方法；证明题附参考证明（完整写出，含每步依据）；代码题附可跑验证。答案**只能用已教概念**（对照下方"已教清单"逐句查）。答案块一律平铺"**参考答案：**"，禁 `<details>`。

### 口径声明（两处，讲义中显式标注）

- **凹凸口径**：本课程采用同济口径——$f\big(\tfrac{x_1+x_2}{2}\big)<\tfrac{f(x_1)+f(x_2)}{2}$ 称**凹**（图像开口向上，如 x²），反之称**凸**。国际文献（英文 convex）与竞赛语境的"凸"与本课程"凹"同义。第 17 讲首次出现处声明，AA_一览同步登记——这是"两种口径有差别就声明选了哪个"。
- **"级数"归属**：级数属高数下。本课程只在 22 讲（黎曼和取极限）与 30 讲（接口地图）以"现在可以跳过"的合法预告形式提及，不展开、不空降。

### 3.2 关键机制"完整形态六问"决定登记（数学课的"机制"=定义/定理/操作，只登记易漏且已拍板的）

- **ε-N 定义（02）**：① 标准形态+各部分自由度：N 依赖 ε（可依赖不唯一）、n>N 与 n≥N 无本质差、前有限项无关；② 组合：与子列（子列收敛⇎原列收敛，方向）、与四则（04 的前提）；③ 被控：N 是"存在"不是"给出公式"，证明只需取一个够大的；④ 重复：先取大 N 仍合法；⑤ 规范：证明模板四步（任给 ε→找 N→验证 n>N⇒|aₙ−A|<ε→结论），坏习惯=把 |aₙ−A|<ε 写成 ≤ 且不说明；⑥ 边界：与"越来越接近"的区别、与 ε-δ 的分工（离散脚标 vs 连续自变量）。①③⑤⑥进正文，②④以提醒形式进正文。
- **极限四则（04）**：① 成立前提：各极限存在；② 组合：与等价替换（06）的关系、与洛必达（14）的关系——"三条路"地图；③ 被控：分母极限非零；④ 重复：拆项次数任意但每步都需前提；⑤ 规范：∞−∞ 不能直接减、有界×无穷小=无穷小的用法；⑥ 边界：存在+不存在≠不存在（反例 x·sin(1/x)）。全进正文。
- **等价替换（06）**：① 替换对象是"因子"不是"任意子式"；② 组合：与泰勒（15 讲展开即替换的一般化）；③ 被控：加减时替换需差的主项不被消（sin x−tan x 的经典错误）；④ 重复：多个因子可同时换；⑤ 规范：x→0 时表的适用条件（x 换成 φ(x) 且 φ(x)→0）；⑥ 边界：非幂指对象（ln(1+x)~x 但 ln(1+2x)~2x 不是 x）。①③⑤⑥进正文，②做预告钩子。
- **中值定理（13/14）**：① 条件清单（闭区间连续+开区间可导+端点值（罗尔）），每个条件的失效反例；② 组合：罗尔⊂拉格朗日⊂柯西（单射化嵌套）；③ 被控：ξ 的存在性（不知在哪，只知存在）——"中值"的本义；④ 重复：多次用中值定理（两次拉格朗日的题型）；⑤ 规范：证明书写模板；⑥ 边界：与介值定理（08）的区别（中值定理管导数零点，介值管函数值）。全进正文。
- **洛必达（14）**：① 前提：0/0 或 ∞/∞ 且右端极限存在（或∞）；② 组合：与等价替换混用顺序（先化简再洛必达）；③ 被控：失效三案例（循环、右端不存在、数列直接用）；④ 重复：多次使用需每次重新验证前提；⑤ 规范：先化简（等价/恒等变形）再洛必达；⑥ 边界：非未定式不能用（极限直接代入的情形）。全进正文。
- **泰勒公式（15）**：① 标准形态两余项+展开点自由度（麦克劳林是特例）；② 组合：与等价替换（一阶替换=泰勒最低阶特例）、与中值定理（拉格朗日余项=一次中值定理）；③ 被控：阶数由题目精度要求定；④ 重复：唯一性保证不同方法展开结果一致；⑤ 规范：带余项写全（防"用泰勒不带余项"坏习惯）；⑥ 边界：局部性（余项只在 x₀ 附近小）。全进正文。
- **变限积分求导（23）**：① 标准型（f 连续、上下限可导）；② 组合：复合上限链式、分部时变限出现；③ 被控：被积函数含 x 时必须先换元/提项；④ 重复：多次求导得高阶导；⑤ 规范：先识别型再套公式；⑥ 边界：f 不连续时 Φ 仍连续但未必可导。全进正文。
- **分部积分（20）**：① 标准型+u/dv 划分；② 组合：与换元先后、循环型自身迭代；③ 被控：u 选择由"导数简化/积分不恶化"决定（口诀的原理）；④ 重复：循环型两次分部回代；⑤ 规范：分部后 dv 必须可积；⑥ 边界：∫ln x dx 型（无乘积结构也可分部：取 u=ln x, dv=dx）。全进正文。
- **元素法（26）**：① 标准四步（定区间/取微段/近似 ΔA≈f(x)dx/求和取极限）；② 组合：适用于面积/体积/弧长/功的同构；③ 被控：近似的合法性=误差 o(Δx)（末节给严格说明链回黎曼和）；④ 重复：分割方式自由（竖条/横条/环形壳——结果一致）；⑤ 规范：微段选取的直觉（垂直于旋转轴切）；⑥ 边界：为什么不能直接 ΔA=f(x)Δx 而不加验证（反例：弧长的近似 l≈√(1+f'²)dx 若用 Δl≈Δx 就错——历史上确实错过，椭圆周长黑历史一句话）。全进正文。

## 四、每讲认知思维链条（学习者第一人称 · 五段骨架，写法见 wiicufs/reference.md 1.9）

> 每条五段：① 我带着什么来（旧直觉式写法）/ ② 第一反应（常含会错的直觉，正文须有破误段）/ ③ 我会依次卡住的 4–8 个疑问（[→] 标计划中的答题小节，交付该讲时校正为真实小节；四类必含：元问题迷失/旧直觉冲突/边界/防错；强制至少 1 条"不知道自己不知道"、至少 1 条"想当然归纳"）/ ④ 学完后 / ⑤ 钩子。
> 读者画像定制：链条里的旧直觉直接取自第一节"旧直觉误会清单"——本课程的链条不只是"零基础会问什么"，更是"半瓶水会在哪里翻车"。

### 模块 A（01–08）

- **01 函数**
  - 我带着什么来：高中天天画函数图象、求定义域，"函数"对我来说就是一个解析式加一张图；导数我会求，所以我觉得函数这块我闭着眼能过。
  - 第一反应：第一章讲函数？这不是高中东西吗，大概就是复习——我会带着"这讲可以加速"的心态进来。
  - 我会依次卡住：
    - "f(x)=x 和 g(x)=x²/x 凭什么不是同一个函数？化简后不是一样吗？" [→01 §2.2]
    - "狄利克雷函数这种'没有公式的函数'也算函数？那函数的边界到底在哪？" [→01 §三 3.1–3.4]
    - "'映射'是什么？跟函数什么关系，为什么课本要换词？" [→01 §2.1 映射视角段]
    - "有界、单调我高中就知道，你们说的'严格定义'跟高中的描述差在哪？" [→01 §四 4.1–4.4]
    - "奇偶性为什么要先检查'定义域关于原点对称'？不对称时讨论奇偶还有意义吗？" [→01 §4.3]
    - "反函数到底什么时候存在？'单调才有反函数'是充要还是充分？" [→01 §5.1–5.2]
    - "复合还要检查'内层值域接到外层定义域'？高中我直接套，会不会一直瞎套出错？" [→01 §6.1 与 6.3]
    - "这些重讲的东西和极限导数有啥关系？我在为谁打地基？" [→01 开场与小结]
  - 学完后：函数是"定义域+对应法则"的整体，不是一条公式；判断性质、复合、反函数，先查定义域再谈式子。
  - 钩子：函数钉死了，下一个问题来了：数列的项"无限逼近"某个数——"逼近"到底怎么才算被说死？

- **02 数列的极限**
  - 我带着什么来：会等差等比求和；听过"n 越大 1/n 越接近 0"；参与过 0.999…=1 的争论，谁也没说服谁。
  - 第一反应：极限不就是越来越接近嘛，这个我懂——多半会跳读定义直接看例题，然后在量词上翻车。
  - 我会依次卡住：
    - "'要多接近有多接近'和'越来越接近'差在哪？1, 0, 1/2, 0, 1/3, 0… 一摆一停，难道不算收敛？" [→摆动收敛反例]
    - "ε 和 N 到底谁先谁后？'任意'和'存在'读起来像绕口令，我总把顺序读反。" [→量词顺序]
    - "N 找出来不唯一怎么办？我找的 N 比书上的大，是我错了吗？" [→N 不唯一]
    - "为什么 n>N 就够、前有限项乱跳不管？前 100 项乱跳不会毁掉极限吗？" [→有限项无关]
    - "证明里 ε 是我选的还是对手选的？这个'对抗游戏'到底怎么玩？" [→ε-N 博弈图像]
    - "收敛数列一定有界，那有界数列一定收敛？(-1)ⁿ 是干嘛的？" [→有界⇎收敛/反例]
    - "ε-δ 这么费劲，工科考试真的要考吗？还是套运算法则就行？" [→为什么学严格定义/元问题]
  - 学完后：极限是"对抗游戏"：对手出 ε 我出 N，出得起就收敛；收敛⇒有界但反过来不行。
  - 钩子：数列只有 n→∞ 一种逼近方向；函数的自变量能逼近一个点、还能奔向无穷、还能左右分着来——ε-δ 登场。

- **03 函数的极限**
  - 我带着什么来：刚学会 ε-N；高中说过无数次"看图，x 越来越靠近 2，f(x) 越来越靠近 4"。
  - 第一反应：ε-δ 大概就是 ε-N 把 N 换成 δ？我觉得可以平移过来用——多半漏掉"去心"和"左右"两个关键细节。
  - 我会依次卡住：
    - "x→x₀ 时 x 能等于 x₀ 吗？f 在 x₀ 没定义，极限还能存在？" [→去心邻域]
    - "六种极限过程我记不住，有统一的理解方式吗？" [→邻域语言统一/元问题]
    - "左极限右极限凭什么分开定义？什么时候必须分开算？" [→左右极限/分段函数]
    - "sin(1/x) 在 0 附近到底烂成什么样？图都画不出来还怎么研究？" [→不存在反例/数值实验]
    - "δ 依赖 ε 我懂了；那 δ 能依赖 x 吗？'每点一个 δ'和'整段一个 δ'是不是两回事？" [→一致性预告/不知道自己不知道]
    - "证 x→2 时 x²→4，为什么不能直接代 x=2？代进去不就完了？" [→代值是特权/连续预告]
  - 学完后：极限过程=自变量逼近方式；点极限用去心 δ 邻域；代值是连续函数的特权不是极限的默认操作。
  - 钩子：极限定义立住了，两个最常用的对象登场：无穷小与无穷大——它们不是数，是状态。

- **04 无穷小、无穷大与四则运算**
  - 我带着什么来：刚会写 ε-δ 的简单证明；高中经常说"这东西趋于零，忽略不计"。
  - 第一反应：无穷小就是很小的数吧；四则运算高中早会了——多半轻敌，栽在"前提"上。
  - 我会依次卡住：
    - "无穷小到底是'数'还是'过程'？0 算无穷小吗？" [→无穷小定义]
    - "无穷大和'很大'什么区别？无穷大就是无界吗？" [→无穷大vs无界]
    - "lim(f+g)=lim f+lim g 我一直用，原来还有前提？什么时候崩？" [→四则条件]
    - "∞−∞ 为什么不能直接减？我高中好像这么干过。" [→坏习惯破误]
    - "lim x·sin(1/x) 为什么不能拆成 lim x · lim sin(1/x)？后者不存在啊。" [→拆分失败反例/防错]
    - "有界×无穷小=无穷小这招什么时候是唯一的路？" [→组合拳识别]
  - 学完后：无穷小是趋于 0 的变量（0 是唯一算无穷小的数）；四则法则是带前提的定理，用前报条件。
  - 钩子：很多极限"算不动"——存在性本身要证，两条判据登场：夹逼与单调有界。

- **05 存在判据与两个重要极限**
  - 我带着什么来：会算简单极限；"有界"这个词高中就熟；递推数列见过但没证过收敛。
  - 第一反应：证极限存在？极限算出来不就存在了——多半没意识到"存在"本身是件事。
  - 我会依次卡住：
    - "什么样的极限算不动？算不动时我该往哪想？" [→算不动的三类/元问题]
    - "夹逼的上界下界怎么找？随便猜吗？" [→夹逼章法]
    - "单调有界里'单调''有界'缺一个会怎样？" [→反例/边界]
    - "sin x/x=1 的夹逼证明用几何面积图，图算证明吗？不是说图像不能当证明？" [→图像启发vs证明的定位/旧直觉冲突]
    - "(1+1/n)ⁿ 单调有界的放缩是怎么想到的？" [→放缩来源]
    - "0.999…=1 到底怎么回事？今天能说死了吗？" [→位值表示与极限/不知道自己不知道]
  - 学完后：存在性可证；夹逼用于"算不动但围得住"，单调有界用于递推数列；0.999…=1 不再是悖论而是记号问题。
  - 钩子：这些极限常涉及无穷小之间的"快慢"——比较无穷小的阶，是替换技术的地基。

- **06 无穷小的比较与等价替换**
  - 我带着什么来：听学长说过"sin x 换 x"，自己用过也翻过车，不知道翻在哪。
  - 第一反应：等价替换就是背表换嘛——多半栽在加减和变量条件上。
  - 我会依次卡住：
    - "'等价'（~）到底是什么意思？和'相等'差在哪？" [→等价定义]
    - "为什么乘除能换、加减危险？加减有没有能换的场合，判据是什么？" [→合法边界]
    - "sin x−x 怎么办？表里没东西可换——是不是要展开到更高阶？" [→高阶差/泰勒预告]
    - "表是 x→0 的，遇到 x→π/2、ln(1+2x) 这种还能用吗？" [→变量替换条件/防错]
    - "我会不会把 1−cos x 换成 x 之类然后答案差系数？" [→阶数敏感性/防错]
    - "我自己归纳过'等价就是长得像'，这么说行吗？" [→想当然归纳校准]
  - 学完后：等价=比值趋于 1；替换本质是"因子的极限"；加减看差的主项，表外先换变量。
  - 钩子：sin x−x ~ −x³/6 这个三次项是哪来的？——"展开"这门武器必须正式学了，但它前面还有微分学的关卡。

- **07 连续性与间断点**
  - 我带着什么来："连续"对我来说就是笔不离纸；间断点的名字背过一点（可去、跳跃）。
  - 第一反应：这么直观的东西还要定义？——多半低估，分类判别全是新活。
  - 我会依次卡住：
    - "三条件（有定义/极限存在/二者相等）哪个最容易在题里漏？" [→定义/防错]
    - "'可去'凭什么可去？改一下函数值就连续，这合法吗？" [→可去修补]
    - "振荡间断什么样？sin(1/x) 图画不出来，怎么研究它？" [→振荡型/数值实验]
    - "1/x 在 0 处是什么型？和 tan x 在 π/2 一样吗？" [→无穷型判别]
    - "'初等函数在其定义区间内连续'——为什么不能说'在定义域上连续'？" [→边界细节/想当然]
    - "分段函数接缝处怎么检查？要单独算左右极限？" [→接缝检查/防错]
  - 学完后：连续是点态的极限等式；间断分类=左右极限存在性的组合判定流程。
  - 钩子：单点连续是零散的；"闭区间上整体连续"会送三件大礼——最值、介值、零点。

- **08 闭区间上连续函数的性质**
  - 我带着什么来：图像直觉"连续的线肯定有最高最低"；零点定理的名字见过。
  - 第一反应：这不显然吗，画图就看到了——多半把定理当废话，直到看到条件反例的杀伤力。
  - 我会依次卡住：
    - "'闭'为什么不能换'开'？y=x 在 (0,1) 没最值我服，但换 y=x² 呢，是不是又行了？反例到底怎么举才稳？" [→闭字反例/边界]
    - "不连续就一定没有最值吗？" [→反例构造]
    - "介值和零点谁是谁的推论？我记乱过。" [→关系梳理/画像定制]
    - "二分法是定理应用还是数值方法？为什么二分一定能收敛到根？" [→二分+收敛链]
    - "一致连续是什么？跟连续差在哪？我要学多深？" [→简介层/理解深度标注]
    - "考试上这些定理怎么'用'？构造 f 的套路是什么？" [→应用模板/元问题]
  - 学完后：闭+连续=最值存在+取遍中间值；定理使用=构造函数+报条件，一步不缺。
  - 钩子：连续函数的"增量比"在一点的极限——导数。你以为你高中就会了，现在重新会一遍。

### 模块 B（09–18）

- **09 导数：定义即极限**
  - 我带着什么来：求导熟练（多项式/三角/指对都会）；"导数=切线斜率=瞬时变化率"背得极顺。
  - 第一反应：导数我高中就会，这讲是复习公式——多半把"会算"当"懂了"，这是画像里的核心病灶。
  - 我会依次卡住：
    - "f'(x₀)=lim Δy/Δx 和'斜率公式'差在哪？瞬时变化率不是 Δt=0 吗，0/0 怎么办？" [→0/0 悖论/定义的必要性]
    - "左右导数为什么分开定义？|x| 在 0 不可导的完整说法是什么？" [→左右导数/防错]
    - "可导⇒连续我好像知道，连续⇒可导为什么崩？比 |x| 更狠的反例存在吗？" [→反例/魏尔斯特拉斯简介]
    - "f 在 a 点可导 vs f' 在 a 点连续，是一回事吗？" [→可导vs导函数连续/不知道自己不知道]
    - "lim_{x→a} f'(x) 和 f'(a) 什么时候相等？接缝点求导我只会用定义，有没有偷懒判据？" [→导数极限定理预告]
    - "有公式不用、非用定义求导，考试考吗？" [→为什么用定义/定位]
  - 学完后：导数是极限不是公式；"会算"是公式层，"会定义"才扛得住构造题和证明。
  - 钩子：定义只能算少量导数，成套法则把求导变成流水线——但每条法则先证再用。

- **10 求导法则**
  - 我带着什么来：高中用过乘法法则和链式，不知道证明；链式当"约掉 dy"。
  - 第一反应：法则套就完了，证明多余——多半把 dy/dx 当真分数。
  - 我会依次卡住：
    - "(uv)'=u'v+uv'——我用乘积增量展开能自己推吗？(u'v)' 为什么不是 u'v'？" [→乘法法则证明/旧直觉冲突]
    - "链式证明里 Δu=0 时的漏洞，正规教材怎么补的？'约掉 dy'到底哪里不合法？" [→链式严格证明/不知道自己不知道]
    - "反函数求导 =1/f'(y)，这个'倒数'怎么来的？反三角函数导数就靠它？" [→反函数求导推导]
    - "sin'x=cos x 怎么证？用哪个重要极限？" [→三角导数/05 讲回收]
    - "a^x 求导为什么冒 ln a？e 到底特殊在哪？" [→指对导数]
    - "复合大函数我老漏层，剥洋葱的章法？" [→防漏章法/防错]
  - 学完后：法则全证明过一遍；链式从"约掉"错觉升级为"复合极限定理"；求导流水线可靠。
  - 钩子：还有"没有显式 y"的场面（隐函数、参数方程），以及 dy/dx 是不是分数的正式答案——微分。

- **11 求导进阶**
  - 我带着什么来：显式求导熟练；见过"两边取对数再求导"的骚操作。
  - 第一反应：对数求导像技巧堆砌——多半不知道它为什么合法、何时是刚需。
  - 我会依次卡住：
    - "隐函数求导：y 没解出来凭什么能求 dy/dx？我把 y 当 x 的函数，合法吗？" [→隐函数原理]
    - "参数方程二阶导 d²y/dx² 为什么不是 (d²y/dt²)/(d²x/dt²)？我直接除一次的直觉哪错了？" [→参数二阶的坑/防错]
    - "x^x 到底当 x^a 还是 a^x？取对数为什么能救？" [→幂指函数/对数求导本质]
    - "n 阶导数怎么找规律？莱布尼茨公式什么时候才值得用？" [→n 阶章法]
    - "相关变化率怎么列方程？变量间关系从哪来？" [→相关变化率方法]
    - "f^{(n)}(0) 这种量后面还有大用？" [→泰勒预告]
  - 学完后：隐/参数/幂指三场面全有正规流程；对数求导本质=乘积幂结构降维。
  - 钩子：求导机器完备。把 Δy 拆成"线性主部+高阶小量"——微分，误差估计的武器。

- **12 微分**
  - 我带着什么来：dy/dx 写了无数次当分数用；听过"以直代曲"。
  - 第一反应：微分就是导数换个写法？——多半分不清 dy 和 Δy。
  - 我会依次卡住：
    - "dy 和 Δy 到底差在哪？凭什么 Δy=dy+o(Δx)？" [→微分定义]
    - "可微⇔可导，那要两个词干嘛？" [→两词分工]
    - "误差传播 Δy≈f'(x₀)Δx 怎么用？相对误差公式怎么推？" [→误差传播]
    - "dx 也是微分吗？dx=Δx 吗？谁规定的？" [→dx 的地位/不知道自己不知道]
    - "∫ 里的 dx 和这里的微分是一回事吗？先记着这个疑问行吗？" [→记号统一预告/合法预告]
    - "'以直代曲'在别处还有名字吗？" [→线性近似广泛性/直觉]
  - 学完后：微分=线性主部；"把非线性换成线性"被合法化；dy/dx 是"微分之比"而不是分数魔法。
  - 钩子：导数管局部变化率，但真正连接两端点的是全局定理——中值定理，微分学的火力核心。

- **13 中值定理 I：费马、罗尔、拉格朗日**
  - 我带着什么来：高中"了解"过拉格朗日，叙述大概记得；自己也画图平移切线"证"过它。
  - 第一反应：中值定理我知道啊——多半条件忘光，辅助函数当魔法抄，这是画像重灾区。
  - 我会依次卡住：
    - "罗尔凭什么单独是定理？不就是拉格朗日的特例？" [→结构关系]
    - "证明里 F(x)=f(x)−f(a)−k(x−a) 这个函数怎么想到的？k 是干嘛的？" [→辅助函数来历/常数 k 法]
    - "闭区间连续+开区间可导，为什么一个'闭'一个'开'？" [→条件细节/边界]
