**题 1**：$\int_0^1x^2dx=\frac13$——你会用"$\frac{x^3}3\big|_0^1$"**秒算**。**执照**在哪？（"找原函数代进去"凭什么是对的？）

1. 执照 = **N-L 公式**，它的证明链本讲第三节展开：变上限积分 $\Phi$ 是"用和式极限造出来的原函数"，任意原函数与 $\Phi$ 差常数，端点差的记账把常数抹掉——**口诀的每一步都有出处**。

## 二、变上限积分：$\Phi'=f$ 与 19 讲挂账

### 2.1 变上限积分是什么

固定 $a$、让上限 $x$ 动起来：

$$\Phi(x)=\int_a^xf(t)\,dt\qquad(x\in[a,b]).$$

**三个读法**：①"面积的累积器"（从 $a$ 一路积到 $x$）；②**积分变量换成 $t$** 的礼仪（处处用 $t$ 是惯例——**"积到哪儿"的 $x$ 与"被积到哪儿"的 $t$ 是两种角色**，这个区分是本讲第四节防错的核心）；③它是个**函数**（$x$ 进、数出）。

### 2.2 定理 1（微积分基本定理·第一部分）与证明

> **定理 1**：设 $f$ 在 $[a,b]$ 上**连续**，则 $\Phi(x)=\int_a^xf(t)dt$ 在 $[a,b]$ 上可导，且
> $$\Phi'(x)=f(x)\qquad(x\in[a,b]).$$

**证明**（三步，工具全是旧资产）：

**① 增量与区间可加**（22 讲性质）：对 $\Delta x\ne0$（$x+\Delta x\in[a,b]$）：

$$\frac{\Phi(x+\Delta x)-\Phi(x)}{\Delta x}=\frac{1}{\Delta x}\int_x^{x+\Delta x}f(t)\,dt.$$

**② 积分中值定理**（新——先证再造）：

> **积分中值定理（连续版）**：$f$ 在 $[x,x+\Delta x]$ 连续 ⇒ 存在 $\xi$ 介于 $x$ 与 $x+\Delta x$ 之间，使
> $$\int_x^{x+\Delta x}f(t)\,dt=f(\xi)\,\Delta x.$$

**证明**（三行）：设 $m,M$ 为 $f$ 在该区间上的最小、最大值（**最值定理**——08 讲）：$m\Delta x\le\int\le M\Delta x$（**22 讲的上下界性质**——逐项夹）⇒ 两边除以 $\Delta x$：平均值 $\frac1{\Delta x}\int\in[m,M]$ ⇒ 由**介值定理**（08 讲）：存在 $\xi$ 取到该值 ⇒ $\int=f(\xi)\Delta x$。$\blacksquare$（**读法**：$\frac1{\Delta x}\int$ 是"$f$ 在区间上的算术平均"，中值定理说"连续函数必在某点取到自己的平均值"。）

**③ 商的计算与取极限**：由②，商 $=f(\xi)$（$\xi$ 介于 $x$ 与 $x+\Delta x$ 之间）。$\Delta x\to0$ 时**$\xi\to x$**（夹在中间），而**$f$ 连续**：

$$\lim_{\Delta x\to0}\frac{\Phi(x+\Delta x)-\Phi(x)}{\Delta x}=\lim f(\xi)=f(x).\qquad\blacksquare$$

**"连续用在哪"的精确答案**（疑问 1 的后半）：**只用在一处**——最后 $\xi\to x$ 时把 $f(\xi)$ 换成 $f(x)$（连续性正是"自变量接近 ⇒ 函数值接近"的许可证）。前半段（可加性、中值定理）只需 $f$ **可积+有最值**。

**挂账兑现（19 讲）**：定理 1 的推论直接就是——

> **推论（原函数存在定理）**：闭区间上连续的函数**必有原函数**（$\Phi$ 就是一个）。

——**"连续 ⇒ 有"的那一格从此不是声明而是定理**（19 讲存在性地图的最后一块拼图到位）。开场的 $e^{-t^2}$ 例就是活样板：**原函数存在（=$\Phi$），但它不是初等函数**（21 讲的边界与此**同时成立、互不矛盾**——"存在"说的事"有没有"，"初等"说的是"能不能用有限初等拼"）。

## 三、N-L 公式：证明链与口诀地基

### 3.1 定理 2 与四步证明链（疑问 2 的答案）

> **定理 2（微积分基本定理·第二部分 / N-L 公式）**：设 $f$ 在 $[a,b]$ 连续，$F$ 是 $f$ 的**任意**一个原函数，则
> $$\int_a^bf(x)\,dx=F(b)-F(a).$$

**证明链（四步，每步注明出处）**：

1. **造**：由定理 1，$\Phi$ 是 $f$ 的一个原函数；
2. **连**：$F-\Phi$ 也是"原函数差"⇒ 由 **13 讲推论**（区间上导数恒零⇒常数）：$F-\Phi\equiv C$；
3. **定**：取 $x=a$：$\Phi(a)=\int_a^af=0$（22 讲约定）⇒ $C=F(a)$；
4. **取**：取 $x=b$：$\int_a^bf=\Phi(b)=F(b)-C=F(b)-F(a)$ ✓。$\blacksquare$

**"为什么先证 $\Phi$ 是原函数"的答案**：N-L 的本质是"**用任意原函数来算 $\Phi(b)-\Phi(a)$**"——不先确认 $\Phi$ 是原函数、且与 $F$ 只差常数（第二步），"$F(b)-F(a)$ 等于 $\Phi(b)-\Phi(a)$"就没有依据。**链条的第 2 步（差常数）是全场枢纽**——它保证"**任意**原函数都合格"（不用去找特殊的那个）。

### 3.2 口诀的地基（"反向求导"的执照全文）

| 口诀步骤 | 执照 |
|---|---|
| "找原函数 $F$" | 19 讲概念 + 本讲定理 1（保证找得到）；**任意一个都行** |
| "代端点" | 22 讲定义（积分的值）+ 定理 2（$=\Phi(b)-\Phi(a)$） |
| "相减 $F(b)-F(a)$" | 13 讲推论（原函数差常数）——**常数在相减中蒸发** |

**使用规范**：记号 $F(x)\big|_a^b=F(b)-F(a)$；**当场对照**：$\int_0^1x^2dx=\frac{x^3}3\big|_0^1=\frac13$（**定义级 20 行 vs 公式级 1 行**——22 讲埋的伏笔在此收利息）。

**列威两例**：$\int_1^2\frac{dx}x=\ln2$（19 讲基础表 + N-L）；$\int_0^{\pi/2}\cos x\,dx=\sin\frac\pi2-\sin0=1$。

## 四、三张地图与变限积分的四运算

### 4.1 三张地图（疑问 3——本讲最值钱的辨析）

初学会把"**可积** / **有原函数** / **能用 N-L**"混成一张地图——**它们是三张**：

| 性质 | 条件 | 例子 |
|---|---|---|
| **黎曼可积**（定积分存在） | 有界 + 坏点少（连续/有限间断都行——22 讲） | $f=\mathrm{sgn}\,x$ 在 $[-1,1]$（跳跃）：**可积**（22 讲把跳跃处误差压掉） |
| **有原函数**（$F'=f$ 有解） | **不许有第一类间断**（19 讲）——连续⇒有（本讲定理 1） | $\mathrm{sgn}$：**没有**原函数（19 讲跳跃排除） |
| **N-L 可用** | 有原函数（$F$ 存在）**且** $f$ 在区间上"$F'=f$ 逐点成立" | $\mathrm{sgn}$：**不能用**（无 $F$） |

**"可积但 N-L 不接单"的完整例**：$\int_{-1}^1\mathrm{sgn}\,x\,dx$：**可积**（几何：两块相消）$=0$——但**找不出原函数**（19 讲），N-L 无从下笔 ⇒ **这种积分要回 22 讲的手段**（几何/分段/定义）。**结论警句**：**"能积"（存在）与"能用导数机器积分"（N-L）是两回事**——N-L 的政治局限定在"连续"（或更宽的"有原函数"）地带。

（**范围补充**：$f$ 连续 ⇒ 三者全齐；$f$ 有有限多个第一类间断 ⇒ 可积仍成立（22 讲）、原函数没有（19 讲）、N-L 不直接适用——**但**"分段拼原函数"可以得到类似结果（每段用 N-L 相加——**分段 N-L**）——实战技巧：**在连续段上各用各的**。）

### 4.2 变限积分四运算（疑问 4、5、6）

**① 基本型**：$\dfrac{d}{dx}\int_a^xf(t)dt=f(x)$（定理 1 原文）。

**② 复合上限（链式）**：$G(x)=\int_a^{g(x)}f(t)dt=\Phi(g(x))$ ⇒ **链式（10 讲）**：

$$G'(x)=\Phi'(g(x))\cdot g'(x)=f\big(g(x)\big)\,g'(x).$$

**③ 两端都变（区间可加）**：$\int_{u(x)}^{v(x)}f=\int_a^{v(x)}f-\int_a^{u(x)}f$ ⇒

$$\frac{d}{dx}\int_{u(x)}^{v(x)}f(t)dt=v'(x)f(v(x))-u'(x)f(u(x)).$$

**④ 被积函数含 $x$（疑问 5——防错重镇）**：$\int_0^xxf(t)dt$ 怎么求导？**关键认知**：对 $t$ 积分时，**$x$ 是外来参数（与 $t$ 无关），可以提出去**：

$$\int_0^x xf(t)\,dt=x\int_0^xf(t)\,dt\ \Longrightarrow\ \frac{d}{dx}=\int_0^xf(t)dt+x\,f(x)\quad(\text{乘积法则}).$$

**防错口诀**："**先看 $x$ 站哪边**"——$x$ 在**上限**里 ⇒ 定理 1/链式；$x$ 在**被积式**里 ⇒ **先提/先化简**（能提就提），提不出来（如 $f(x-t)$ 型）⇒ **换元**（26 讲细办，今天知道有这条路）。**永远不要**对着含 $x$ 的被积式直接"把上限换进去"。

**⑤ 秒杀题（疑问 6）**：识别特征——**"积分除以 $h$（或乘除后像增量比）"**：

$$\lim_{x\to a}\frac{1}{x-a}\int_a^xf(t)dt=f(a)\quad(\text{定理 1 的增量比原文}),$$

$$\lim_{x\to0}\frac{\int_0^x\sin t\,dt}{x^2}\ \xrightarrow{\text{洛必达/求导}}\ \frac{\sin x}{2x}\Big|_{x\to0}=\frac12\quad(\text{变限求导 + 洛必达联手}).$$

## 五、数值实验：四连验证

**方法与误差账（先算再跑——阈值纪律的正面示范）**：EXP1/3 需要**双层数值**（内层数值积分 $\Phi$ + 外层差商）——误差账：内层用 **Simpson 法**（误差 $\sim h^4$，$n=1000$ 时 $\sim10^{-13}$ 级）⇒ 被差商（分母 $2\times10^{-4}$）放大到 $\sim10^{-9}$；外层差商自身误差 $O(h^2)\sim10^{-8}$。总误差 $\sim10^{-8}$ 级——**故阈值取相对 $10^{-6}$**（留两个数量级裕量）。

完整脚本在 `scripts/lec23-01_verify_ftc.py`（运行：`uv run --with numpy python scripts/lec23-01_verify_ftc.py`）。

### 实验 1：非初等原函数的 $\Phi'=f$（$e^{-t^2}$）

用 Simpson 数值积分造 $\Phi(x)=\int_0^xe^{-t^2}dt$，对 $x=0.3,0.7,1.2$ 做中心差商核对 $e^{-x^2}$。

（实测，全脚本 0.02 秒跑完，可复跑）：

```
  x = 0.3: 差商 = 0.913931183, e^(-x^2) = 0.913931185, 相对差 = 2.73e-09
  x = 0.7: 差商 = 0.612626394, e^(-x^2) = 0.612626394, 相对差 = 6.66e-11
  x = 1.2: 差商 = 0.236927760, e^(-x^2) = 0.236927759, 相对差 = 6.27e-09
```

**结论（实测坐实）**：三点全过（相对差 $10^{-9}$ 级，**低于预设阈值三个量级**——误差账稳健）——**"写不出的原函数"照样满足 $\Phi'=f$**——定理 1 的震撼活体。

### 实验 2：N-L 的数值对账（$\int_1^2\frac{dx}x=\ln2$）

黎曼和中点法（$n=10^4$）算积分 vs $\ln2$。

（实测）：

```
  中点法和 = 0.6931471802, ln2 = 0.6931471806, 差 = -3.12e-10
```

**结论（实测坐实）**：两者吻合到 $10^{-10}$ 级（中点法 $O(1/n^2)$ 超预期很稳）——"公式级 1 行"的值与"定义级"的极限确实同数。

### 实验 3：复合上限（$G(x)=\int_0^{x^2}e^{-t^2}dt$，$G'=2xe^{-x^4}$）

差商核对 $G'(x)$（$x=0.5,1.0$）。

（实测）：

```
  x = 0.5: 差商 = 0.939413055, 2x e^(-x^4) = 0.939413063, 相对差 = 7.92e-09
  x = 1.0: 差商 = 0.735758877, 2x e^(-x^4) = 0.735758882, 相对差 = 6.67e-09
```

**结论（实测坐实）**：两点全过——链式与变限求导的联合作业。

### 实验 4：秒杀题的数值表（$\frac{\int_0^x\sin t\,dt}{x^2}\to\frac12$）

$x=10^{-1},10^{-2},10^{-3}$：（$1-\cos x$）/x² 的表。

（实测）：

```
  x = 1e-1: 值 = 0.4995834722, 与 1/2 的差 = -4.17e-04
  x = 1e-2: 值 = 0.4999958333, 与 1/2 的差 = -4.17e-06
  x = 1e-3: 值 = 0.4999999583, 与 1/2 的差 = -4.17e-08
```

**结论（实测坐实）**：三行趋 $0.5$，偏差按 $x^2$ 缩（$-\frac{x^2}{12}$ 结构）——"积分除幂"题型的数值回执。

## 本讲小结

- **变上限积分** $\Phi(x)=\int_a^xf(t)dt$：**定理 1（微基·上）**：$f$ 连续 ⇒ $\Phi'=f$——证明三步（可加性→积分中值→连续性）；**"连续用在哪"=最后一步**。**推论（19 讲挂账兑现）**：连续 ⇒ 有原函数（$\Phi$ 就是）——**"原函数存在"≠"原函数初等"**（$e^{-t^2}$ 的正反面同时成立）。
- **N-L（微基·下）**：$\int_a^bf=F(b)-F(a)$，$F$ **任意**原函数——四步证明链（造 $\Phi$→差常数（13 讲）→定常数（$\Phi(a)=0$）→取 $b$）；**口诀的地基表**（找原函数/代端点/相减——执照齐全）；记号 $F\big|_a^b$。
- **三张地图**：可积（坏点少）/ 有原函数（无第一类间断）/ N-L（原函数在手）——**跳跃函数**：可积但 N-L 不接单（分段 N-L 是实战折中）。
- **变限四运算**：基本（$\Phi'=f$）/ 复合上限（链式：$f(g)g'$）/ 两端（$v'f(v)-u'f(u)$）/ **被积函数含 $x$**（先提成常数——乘积法则；提不出走换元）——防错口诀"**先看 $x$ 站哪边**"。
- **秒杀题**：$\frac1{x-a}\int_a^xf\to f(a)$ 的识别；变限求导 + 洛必达的联手。

### D. 代码（可跑验证）

**D1** 复刻并扩展实验 1、3：(a) 用 Simpson 法（$n=1000$）造 $\Phi(x)=\int_0^xe^{-t^2}dt$，对 $x=0.5,1.0$ 做中心差商（$h=10^{-4}$）核对 $e^{-x^2}$（断言相对差 $<10^{-6}$，**注明误差账**）；(b) 对 $G(x)=\int_0^{x^2}e^{-t^2}dt$ 同法核对 $G'=2xe^{-x^4}$（$x=0.5,1.0$）。

**参考答案**：

```python
import numpy as np

def simpson(f, a, b, n=1000):
    # n 为偶数; 复合 Simpson 法 (误差 ~ h^4)
    x = np.linspace(a, b, n + 1)
    y = f(x)
    h = (b - a) / n
    return h / 3 * (y[0] + y[-1] + 4 * np.sum(y[1:-1:2]) + 2 * np.sum(y[2:-1:2]))

g = lambda t: np.exp(-t ** 2)

print("(a) Phi(x) = int_0^x e^{-t^2} dt, Phi' 应 = e^{-x^2}")
h = 1e-4
for x in [0.5, 1.0]:
    Phi = lambda xx: simpson(g, 0, xx)
    dq = (Phi(x + h) - Phi(x - h)) / (2 * h)
    rel = abs(dq - g(x)) / g(x)
    print(f"  x = {x}: 差商 = {dq:.9f}, e^(-x^2) = {g(x):.9f}, 相对差 = {rel:.2e}")
    assert rel < 1e-6   # 误差账: Simpson ~1e-13; 差商放大 ~1e-9; 差商自身 O(h^2)~1e-8

print("(b) G(x) = int_0^{x^2} e^{-t^2} dt, G' 应 = 2x e^{-x^4}")
for x in [0.5, 1.0]:
    G = lambda xx: simpson(g, 0, xx ** 2)
    dq = (G(x + h) - G(x - h)) / (2 * h)
    target = 2 * x * np.exp(-(x ** 4))
    rel = abs(dq - target) / target
    print(f"  x = {x}: 差商 = {dq:.9f}, 2x e^(-x^4) = {target:.9f}, 相对差 = {rel:.2e}")
    assert rel < 1e-6
print("[OK] 非初等原函数的 Phi'=f 与复合上限 G' 双双核实")
```
