## 一、开场：三道"显然吗"的审判题

用你的图像直觉判三题（各 30 秒），**重点不是答案，是你判的时候的依据**：

**题 1**："连续的曲线必有最高点最低点"——$f(x)=x$ 在开区间 $(0,1)$ 上呢？那换成"弯的" $f(x)=x^2$ 在 $(0,1)$ 呢？是不是又有了？

**题 2**："连续曲线从 $0$ 爬到 $3$，必然踩过中途的每个数"——$f(x)=\begin{cases}x, & 0\le x<1\\ x+1, & 1\le x\le2\end{cases}$ 在 $[0,2]$ 上：它从 $f(0)=0$ 到 $f(2)=3$，"中途"的 $1.5$ 它踩过吗？

**题 3**：零点定理说"连续且两端异号 $\Rightarrow$ 有零点"——那"连续且**有零点**"能不能反过来说"两端异号"？$f(x)=x^2$ 在 $[-1,1]$ 上现成的一个反例就够。

**答案预告**：

1. $f=x$ 在 $(0,1)$：**没有最值**（上确界 $1$ 藏在取不到的端点 $1$ 处）。换成 $f=x^2$：**一样没有**——弯了不代表把最值挪近了；它的最大"候选值" $1$ 仍然只在 $x=1$ 处达到，而 $1$ 被开区间挖掉了。**"开区间一定没最值"也不对**（$f(x)=x(1-x)$ 在 $(0,1)$ 就有最大值 $1/4$）——条件的意义是"保票"而不是"划分"（第二节把反例造法讲透）。
2. **没踩过**。它在 $x=1$ 处从 $0.999\ldots$ 直接跳到 $2$——值域是 $[0,1)\cup[2,3]$，**中间整整一段 $(1,2)$ 是空的**。"连续"这个条件一去掉，"取遍中间值"立刻破产（第三节）。
3. **不能反过来**。零点在 $x=0$，而两端 $f(-1)=f(1)=1>0$ **同号**——"异号"只是**充分条件**（一个稳的判据），不是有根的必要条件（第三节把这个逻辑方向钉死）。

扣除"显然"的三道题，本讲要干的活：**把每个'显然'精确化、把每个条件的责任落实、把反例造得针尖对麦芒**。

## 二、最值定理：证明骨架与反例全集

### 2.1 陈述

> **定理（最值定理）**：若 $f$ 在闭区间 $[a,b]$ 上连续，则 $f$ 在 $[a,b]$ 上**有最大值和最小值**——即存在 $\xi,\eta\in[a,b]$，使对一切 $x\in[a,b]$ 有 $f(\eta)\le f(x)\le f(\xi)$。

（对照 03 讲的"局部有界"：局部有界是"每点附近各自有界"，最值定理是"整段统一的有界**且界被取到**"。从局部到全局的这次升级，条件代价就是**闭 + 连续**。）

### 2.2 证明骨架（二分反证——用本课程工具能走到的最近处）

只证"最大值部分"（最小值取 $-f$ 同理）。反证：设 $f$ 在 $[a,b]$ 上连续但**没有上界**。

**第 1 步（二分构造）**：取中点 $c=\dfrac{a+b}2$。区间 $[a,c]$ 与 $[c,b]$ 中**至少有一个无上界**（若两个都有上界，则 $[a,b]$ 上有界——有限个上界取大者，02/04 讲"有限个取 $\max$"的老动作）。把那个无上界的半区间保留，记 $[a_1,b_1]$；对 $[a_1,b_1]$ 重复同样的操作，得 $[a_2,b_2]\supset\cdots$——一列**嵌套闭区间**，长度 $b_n-a_n=\dfrac{b-a}{2^n}\to0$。

**第 2 步（取公共点）**：嵌套闭区间列长度趋于零，存在**唯一公共点** $\xi$（这是**闭区间套定理**——它的严格证明依赖实数完备性，归**地基声明一**（02 讲）管辖；图景：区间一路缩，缩到一个点，缩不没也跑不掉）。

**第 3 步（连续性收口）**：$f$ 在 $\xi$ 连续 $\Rightarrow$ **局部有界**（03 讲 7.1）：存在 $\delta>0$，使 $|x-\xi|<\delta$ 时 $|f|\le M$。而第 1 步的区间列长度趋于 $0$、且都含 $\xi$，故 $n$ 充分大时 $[a_n,b_n]$ 整个落进这个邻域——于是 $[a_n,b_n]$ 上 $f$ 有上界 $M$，与"保留的是无上界区间"矛盾。$\blacksquare$

**读这个骨架读什么**：
- 每一步都在用本课程的现成工具：二分的"两半至少坏一半"（有限取 $\max$ 的对偶）、局部有界（03 讲）、极限的收口；
- **恰好有一处走不过去**：第 2 步"公共点存在"——这是实数完备性借给闭区间的一张支票（地基声明一）。开区间版本在这一步直接失败：$(0,1)$ 的嵌套开区间列可以"缩向" $0$ 而 $0$ 不在里面——最值定理的"闭"字，命门就在这一行。
- 本课程对这条定理的最终口径：**证明骨架理解 + 公共点那一步记在地基声明一名下**（数学分析补全体细节）。

### 2.3 反例全集：每个条件各配一个"精准打击"（疑问 1、2 的答案）

**反例造法的原则先说清**（"反例怎么举才稳"）：要让结论失效，就得**把结论依赖的东西精确拆掉**——要么把"最值点"藏到区间外面/挖掉的端点（针对"闭"），要么让函数在"该出手的地方"破坏连续性（针对"连续"）。漫无目的地"找个怪函数"不叫构造，叫碰运气。

**打击一：开区间（把最值藏到端点外）**

| 反例 | 表现 | 藏值手法 |
|---|---|---|
| $f(x)=x$ 在 $(0,1)$ | 无最大值（上确界 $1$，$f(x)<1$ 恒成立） | 最大值只在 $x=1$ 处达到，$1$ 被挖 |
| $f(x)=x^2$ 在 $(0,1)$ | 无最大值 | 同上（"弯"不救场） |
| $f(x)=x$ 在 $[0,1)$（半开） | 无最大值 | **单侧开挖也致命**——"闭"是两端都要闭 |

（疑问 1 的完整答案：$x^2$ 不行、半开也不行——**只要有一端"开"，就能把值藏进那一端**。注意"开区间也可能有最值"（$x(1-x)$）不构成反驳——反例只需证明"条件不可去"，不需要"开区间必坏"。）

**打击二：不连续（在最值该出手处破坏连续）**

| 反例 | 表现 | 破坏手法 |
|---|---|---|
| $f(x)=\begin{cases}x, & 0<x<1\\ \dfrac12, & x=0\ \text{或}\ 1\end{cases}$ 在 $[0,1]$ | 无最大值（值域 $(0,1)\cup\{\frac12\}$，上确界 $1$ 无处可达） | 在**两端点**把函数值拉走——端点的连续性被破坏，上确界失去了"落点" |
| $f(x)=\begin{cases}\dfrac1x, & 0<x\le1\\ 0, & x=0\end{cases}$ 在 $[0,1]$ | **无界**（更谈不上最值） | 在端点处"爆表"——连续破坏得最剧烈，连有界都保不住 |

**打击三（疑问 2 的正面回答）：不连续一定没有最值吗？——不。**

$f(x)=\begin{cases}x, & 0\le x<1\\ 2, & x=1\end{cases}$ 在 $[0,1]$：在 $x=1$ 不连续，但**有最大值 $2$**（还有最小值 $0$）。**连续性之于最值定理是"保票"，不是"指纹"**：有了它包你必然有最值；没有它只是"可能没有"（上述两个打击），也可能碰巧有（本例）。——这与 04 讲"四则法则前提崩≠结论亡"是同一种逻辑结构：**充分条件的失守从不自动推出结论的死亡**。这条精神在本课程反复出现，此处第三次立标。

### 2.4 使用口径

看到"求 $[a,b]$ 上最值"的题（第 16 讲会配上导数工具全套武装），本讲先立**存在性**：只要是闭区间上连续函数，**先宣布"最值存在"再去找**——"存在"替"找"作保，这是后续全部最值应用题的合法性起点。

## 三、介值定理与零点定理：辈分关系与二分证明

### 3.1 三定理的辈分（疑问 3 的梳理）

$$ \underbrace{\text{最值定理}}_{\text{最深（依赖完备性）}}\ \Longrightarrow\ \underbrace{\text{介值定理}}_{\text{推论}}\ \Longrightarrow\ \underbrace{\text{零点定理}}_{\mu=0\ \text{的特例}} $$

**读法**：最值定理（整段有最大值最小值）$\Rightarrow$ 介值定理（任意介于两函数值之间的数都被取到）：拿到最值 $m$、$M$，中间值 $\mu$ 所在的位置由最值"框住"，再用连续性把水平线 $\mu$ 与曲线的交点逼出来（这是教科书的标准路线之一）。零点定理则是介值定理在 $\mu=0$ 的直接特例——**"零点定理是介值定理的特例"这层辈分，记牢**（有人记乱过：反过来的方向是不成立的）。

**但本讲的实际证明路线**换一条腿走（更硬、更适合考试复现）：**直接给零点定理的二分法完整证明**（下一小节），然后介值定理由平移归约到零点（$\mu$ 任意：令 $F(x)=f(x)-\mu$，则 $f(\xi)=\mu\iff F(\xi)=0$——**零点定理是介值定理的"标准型"**，这就是为什么考试永远考零点定理）。

### 3.2 零点定理与二分法证明（现场完整）

> **定理（零点定理）**：设 $f$ 在 $[a,b]$ 上连续，且 $f(a)$ 与 $f(b)$ **异号**（$f(a)\,f(b)<0$）。则存在 $\xi\in(a,b)$，使 $f(\xi)=0$。

**证明**（二分法——把"根的区间"每次砍一半，砍到钉死）：

不妨设 $f(a)<0<f(b)$（否则用 $-f$ 代替 $f$，根不变）。记 $[a_0,b_0]=[a,b]$。

**迭代规则**：对区间 $[a_n,b_n]$（满足 $f(a_n)<0<f(b_n)$），取中点 $c_n=\dfrac{a_n+b_n}2$：

- 若 $f(c_n)=0$——**命中**，证毕；
- 若 $f(c_n)<0$：取 $[a_{n+1},b_{n+1}]=[c_n,b_n]$（保留"左负右正"的性质）；
- 若 $f(c_n)>0$：取 $[a_{n+1},b_{n+1}]=[a_n,c_n]$。

于是得到嵌套闭区间列 $[a_0,b_0]\supset[a_1,b_1]\supset\cdots$，长度 $=\dfrac{b-a}{2^n}\to0$，且**恒满足** $f(a_n)<0<f(b_n)$。

**收口**：长度的区间列存在公共点 $\xi$（闭区间套定理，地基声明一——与第二节同一张支票），且 $a_n\to\xi$、$b_n\to\xi$。由 $f$ 在 $\xi$ 连续：

- 若 $f(\xi)>0$：连续性给出 $\delta>0$，使 $|x-\xi|<\delta$ 时 $f(x)>\dfrac{f(\xi)}2>0$（**保号的连续版**，07 讲 4.4 副产品的近亲——本质是局部保号）。但 $a_n\to\xi$ 意味着 $n$ 充分大时 $a_n$ 落进这个邻域，而 $f(a_n)<0$ **恒成立**——矛盾；
- 若 $f(\xi)<0$：对称地，$n$ 充分大时 $b_n$ 落进"$f<0$ 的邻域"，而 $f(b_n)>0$——矛盾。

两种情形都不可能，只剩 $f(\xi)=0$。$\blacksquare$

**这个证明的两个灵魂动作**：
1. **连续性的终审作用**："极限点的函数值"与"逼近它的符号恒定的函数值"不能打架——$f(\xi)\ne0$ 时局部保号会造出一个邻域，把无穷多"反符号"的端点关在门外；连续性确保这个邻域存在。
2. **嵌套区间的收缩**：$\xi$ 被两侧夹死——这就是**二分法算法**的数学本体（第四节把它算法化）。

### 3.3 应用模板（疑问 6 的答案）：证"方程有根"的三件套

**模板**（考试标准动作）：**构造函数 → 找异号端点 → 报条件收口**。

> **例**：证明方程 $x=e^{-x}$ 在 $(0,1)$ 内有根。
> **构造** $F(x)=x-e^{-x}$（移项化零：方程的根 $\iff$ $F$ 的零点）。**连续性**：$F$ 是初等函数，在 $[0,1]$ 上连续（**代值特权/连续性验收，07 讲**）。**异号**：$F(0)=0-1=-1<0$；$F(1)=1-e^{-1}>0$。**收口**：零点定理 $\Rightarrow$ $\exists\xi\in(0,1)$，$F(\xi)=0$，即 $x=e^{-x}$ 有根。$\blacksquare$

**模板的防错**：
- 构造函数就是**移项**（把所有东西挪到一边），别创造新的等式变形；
- 报条件时"闭区间 + 连续"要说全（这是给分点，也是你自检的清单）；
- 结论只说"**有根**"——根在哪、有几个，定理不负责（定位交给二分法，个数问题第 16 讲用导数解决）。

（顺带钉死开场题 3 的逻辑方向："异号"是**充分**条件：$f(a)f(b)<0\Rightarrow$ 有根；反之不然（$x^2$ 在 $[-1,1]$：有根而两端同号——**偶重根**不换号）。考"判断根的存在"时找异号；考"有根推异号"的命题一律抓好这个反例。）

## 四、二分法：定理的工程形态（疑问 4）

### 4.1 算法

**输入**：$f$ 在 $[a,b]$ 上连续、$f(a)f(b)<0$、精度目标 $\varepsilon$。**循环**：

```
while (b − a) > ε:
    c = (a + b) / 2
    if f(c) == 0: 输出 c, 停
    elif f(a)·f(c) < 0:  b = c     # 根在左半边
    else:                a = c     # 根在右半边
输出 (a+b)/2
```

### 4.2 收敛链（"为什么一定收敛到根"）

**误差界**：第 $n$ 次二分后区间长 $\dfrac{b-a}{2^n}$——**每步严格减半**，故达到精度 $\varepsilon$ 所需步数

$$n\ge\log_2\frac{b-a}{\varepsilon}\qquad(\text{向上取整}).$$

**收敛的理由**（把第三节的证明按算法重读一遍）：区间列嵌套收缩，公共点存在（地基声明一）$\xi$；每步保留的区间都含一个"符号变化"，连续性迫使 $f(\xi)=0$——**算法一定锁定根**。$f$ 连续是"锁定绳"，闭区间是"收缩空间"，二者缺一，第三节的两个反例对应这里的两类失效。

### 4.3 两个身份，都拿住

**它是定理应用还是数值方法？——都是**：合法性由零点定理提供（所以它必须要求"连续+异号"）；工程形态是算法（所以它考"步数估计"与"误差界"，也真的被用于开机自检、查表定位等实际场合）。**考试的两种题型**：①手算两步二分、报区间与误差界；②给精度问步数（直接套 $2^{-n}$ 的账）。

## 五、一致连续（简介层：知道定义、差距与结论）

### 5.1 定义（$\delta$ 从"依赖点"到"统一"）

07 讲的连续是**逐点**的：每个 $x_0$ 配各自的 $\delta$（可以随 $x_0$ 变化）。把量词改写一下，让 $\delta$ **在整段上统一**：

> **定义（一致连续）**：设 $f$ 在区间 $I$ 上有定义。若对任意 $\varepsilon>0$，存在**只依赖 $\varepsilon$** 的 $\delta>0$，使得对 $I$ 中**任意两点** $x_1,x_2$：$|x_1-x_2|<\delta\Rightarrow|f(x_1)-f(x_2)|<\varepsilon$，则称 $f$ 在 $I$ 上**一致连续**（uniformly continuous）。

**差别的一句话**：连续是"$\forall\varepsilon\,\forall x_0\,\exists\delta$"；一致连续是"$\forall\varepsilon\,\exists\delta\,\forall x_1,x_2$"——**$\delta$ 能不能先于点被选定**。一致连续 $\Rightarrow$ 连续；反之不然。

**反例（为什么"闭"在这里又出现）**：$f(x)=\dfrac1x$ 在 $(0,1]$ 上连续，但**不一致连续**——$x$ 越靠近 $0$ 曲线越陡，任何"统一的 $\delta$"都会被靠近 $0$ 的区域击穿（第六节实验 4 的数值指纹：等比例小的区间，越靠近 $0$ 函数差越大）。

### 5.2 Cantor 定理（结论陈述）

> **定理（Cantor）**：闭区间 $[a,b]$ 上的连续函数必一致连续。

**图景**：闭区间上没有"跑到头"的出口，连续性无处"失控"（证明依赖完备性，属数学分析）。**"闭 + 连续"第三次发威**：最值、零点、一致连续——模块 A 三大礼包，条件配方一模一样。

### 5.3 理解深度标注（疑问 5 的答案：学多深）

按 00 导览的"三档深度"，一致连续这一层的要求是：**知道定义（$\delta$ 统一 vs 逐点）、知道与连续的关系（单向）、知道 Cantor 结论与"闭"字的角色、会本讲 C2 这种"用放缩亲手证一个"**——**到此为止**。一般理论（一致连续的判别法、开区间情形的细致分级）属《数学分析》；本课程后续只在第 22 讲（可积性简介）露一次脸。**别陷进去**：它不是期末主战场，考到也就是"叙述定义/判断谁推谁"的层次。

## 七、问法索引（零新知识，只对答案）

> 本节不引入任何新概念，只把高频疑问对到正文出处。

1. **"'闭'换成'开'就一定没有最值吗？"**
   不一定（$x(1-x)$ 在 $(0,1)$ 有最值）——但**存在没有的反例**（$x$、$x^2$ 在 $(0,1)$），所以"闭"不可去（→ 2.3 打击一；"保票"逻辑见打击三）。反例造法：把最值点到藏进被挖的端点。
2. **"不连续就一定没最值吗？"**
   不一定（→ 2.3 打击三的例：不连续但有最大值 $2$）——但存在没有的反例（端点拉走 / 端点爆表），所以"连续"不可去。
3. **"零点定理和介值定理谁推谁？"**
   介值 $\Rightarrow$ 零点（$\mu=0$ 特例）；介值本身是最值定理的推论（→ 3.1 的辈分链）。考试重头是零点定理（因为它可归约一切"$f(x)=\mu$"问题：平移构造函数 $F=f-\mu$）。
4. **"根的唯一性/个数怎么办？"**
   本讲定理只管**存在**（→ 3.3 防错）——定位用二分（第四节），个数用单调性/导数（第 16 讲）。

## 作业（模块 A 收官卷）

**说明**：基础/提高/综合/代码四档。参考答案平铺在每题下方（先独立做再对照）。所有题只用到本讲与之前教过的概念。

### A. 基础（定理应用）

**A1** 证明方程 $x^3-x-1=0$ 在 $(1,2)$ 内有根。

**参考答案**：
构造 $F(x)=x^3-x-1$（**移项化零**）。**连续**：多项式，$[1,2]$ 上连续（代值特权）。**异号**：$F(1)=1-1-1=-1<0$；$F(2)=8-2-1=5>0$。由**零点定理**，$\exists\xi\in(1,2)$，$F(\xi)=0$，即原方程有根。$\blacksquare$

**A2** 判断最值是否存在（给依据）：(1) $f(x)=x^2$ 在 $[1,2]$；(2) $f(x)=x$ 在 $(0,1)$；(3) $f(x)=\begin{cases}x, & 0\le x<1\\ 2, & x=1\end{cases}$ 在 $[0,1]$。

**参考答案**：
(1) **存在**（闭区间 $[1,2]$ + 多项式连续，最值定理；最大 $f(2)=4$、最小 $f(1)=1$）。
(2) **不存在**：上确界 $1$ 只在 $x=1$ 达到，而 $1$ 被开区间挖掉（反例原理：藏值进开挖端）。
(3) **存在**：最大值 $2$（在 $x=1$）、最小值 $0$（在 $x=0$）——**不连续但有最值**：连续是保票不是指纹（反问：定理的条件还能去掉吗？看 (2) 与本题的另一个兄弟——它不能作为"去掉连续"的依据，因为存在无最值的不连续例）。

**A3** 设 $f$ 在 $[0,1]$ 上连续，$f(0)=f(1)$。证明：存在 $c\in\left[0,\dfrac12\right]$，使 $f(c)=f\left(c+\dfrac12\right)$。

**参考答案**：
构造 $F(x)=f(x)-f\left(x+\dfrac12\right)$（在 $\left[0,\frac12\right]$ 上连续——连续函数的复合与差，07 讲定理 1、2 传送）。两头计算与求和：

$$F(0)=f(0)-f\left(\tfrac12\right),\qquad F\left(\tfrac12\right)=f\left(\tfrac12\right)-f(1)=f\left(\tfrac12\right)-f(0)\ \ \big[\,\text{用}\ f(1)=f(0)\,\big].$$

两式**相加为零**：$F(0)+F(\frac12)=0$——即 $F(0)$ 与 $F(\frac12)$ **异号或同为零**。
- 若某个为零：直接就是 $c$；
- 若异号：由**零点定理**（闭区间 $\left[0,\frac12\right]$ + 连续 + 异号），$\exists c$，$F(c)=0$，即 $f(c)=f\left(c+\frac12\right)$。$\blacksquare$
（这是"零点定理构造题"的样板：**目标式移项成 $F$，再找两个端点让 $F$ 异号**——找异号的手段这次是"两头相加为零"的代数事实。）

**A4** 判断对错：(1) $f$ 在 $[a,b]$ 连续且 $f(a)f(b)<0$ $\Rightarrow$ 有根；(2) $f$ 连续且"有根" $\Rightarrow$ $f(a)f(b)<0$；(3) 有根 $\Rightarrow$ 端点异号（不假设连续）。

**参考答案**：
(1) **对**（零点定理本体）。
(2) **错**：$f(x)=x^2$ 在 $[-1,1]$ 有根（$x=0$），两端 $f(\pm1)=1$ 同号——偶重根不换号（→ 3.3）。"异号"是充分条件。
(3) **错**：同一个反例即可：$f(x)=x^2$ 在 $[-1,1]$（连续版的反例，已够说明 (2)）。若想看一个不连续的强化版：$f(x)=\begin{cases}x^2, & x\le0\\ 1, & x>0\end{cases}$ 在 $[-1,1]$：有根（$f(0)=0$）、两端 $f(-1)=f(1)=1$ 同号、且在 $0$ 处跳跃不连续。

### B. 提高（反例构造与证明）

**B1** 造两个反例：(1) 在 $[0,1]$ 上不连续且**无最大值**的函数；(2) 在 $(0,1)$ 上连续且**有最大值**的函数。

**参考答案**：
(1) $f(x)=\begin{cases}x, & 0<x<1\\ \dfrac12, & x=0\ \text{或}\ x=1\end{cases}$：值域 $(0,1)\cup\{\frac12\}$，上确界 $1$ 处处达不到——**无最大值**（注意最小值 $1/2$ 倒是有）。
（验证"无最大"：任取 $x\in(0,1)$，$f(x)=x<1$ 且可找到更大的 $f(x')$；端点值 $1/2<1$——确无最大。）
(2) $f(x)=x(1-x)=x-x^2$：连续（多项式），$f(x)=\frac14-(x-\frac12)^2\le\frac14$，且在 $x=\frac12$ 处取等——**最大值 $\frac14$ 存在**。
（两例合并的经验：条件与结论之间是保票关系——反例要证明"条件不可去"，只需各造一个"针尖"例；"开区间有最值"与"不连续有最值"都不反驳定理本身。）

**B2** 对 $x^3-x-1=0$ 在 $[1,2]$ 上做两步二分（手算）：给出根所在的区间与误差界。

**参考答案**：
$F(1)=-1<0$，$F(2)=5>0$。
- 第一步：$c=\frac32$，$F(1.5)=1.5^3-1.5-1=0.875>0$ ⇒ 根在 $[1,\,1.5]$；
- 第二步：$c=\frac{1+1.5}2=1.25$，$F(1.25)=1.25^3-1.25-1\approx-0.297<0$ ⇒ 根在 $[1.25,\,1.5]$。
**误差界**：$|根-区间中点|\le\frac{1.5-1.25}2=0.125$；或"根∈[1.25,1.5]"直接作答（长度 $0.25=\frac{1}{2^2}$——每步减半的账）。
（真根 $\approx1.32471796\ldots$（第六节实验与 D1 会数值对照）——二分两步已经把位置圈到 $0.25$ 宽。）

**B3** 证明（不动点定理的入门版）：若 $f$ 在 $[a,b]$ 上连续，且 $f([a,b])\subseteq[a,b]$（值域落在区间内），则存在 $\xi\in[a,b]$，使 $f(\xi)=\xi$。

**参考答案**：
构造 $F(x)=f(x)-x$（连续：差，07 讲定理 1）。条件 $f([a,b])\subseteq[a,b]$ 给出两个不等式：$f(a)\ge a$（因为 $f(a)\in[a,b]$）与 $f(b)\le b$。于是

$$F(a)=f(a)-a\ \ge 0,\qquad F(b)=f(b)-b\ \le 0.$$

即 $F(a)$ 与 $F(b)$ 异号或出现零：
- 若有零：得证；
- 否则 $F(a)>0>F(b)$：**零点定理** $\Rightarrow\exists\xi$：$F(\xi)=0$，即 $f(\xi)=\xi$。$\blacksquare$
（同 A3/A1 一个模板：**移项造 $F$，用题设条件在两端读出符号**——"值域在区间内"这个条件就是为端点符号服务的。）

### C. 综合（难题档，允许卡）

**C1** 设 $f$ 在 $[0,1]$ 上连续，$f(0)=f(1)$。证明：对任意正整数 $n$，存在 $\xi$，使 $f(\xi)=f\left(\xi+\dfrac1n\right)$。（A3 的 $n$ 版推广）

**参考答案**：
构造 $F(x)=f(x)-f\left(x+\frac1n\right)$，在 $\left[0,\ 1-\frac1n\right]$ 上连续。考察 $n$ 个点 $\dfrac kn$（$k=0,1,\ldots,n-1$）处的值并**求和**（望远镜消去）：

$$\sum_{k=0}^{n-1}F\left(\frac kn\right)=\sum_{k=0}^{n-1}\left[f\left(\frac kn\right)-f\left(\frac{k+1}n\right)\right]=f(0)-f(1)=0.$$

$n$ 个数之和为零 $\Rightarrow$ **其中既有 $\ge0$ 的、又有 $\le0$ 的**（若全部同号严格则和不为零）。取 $j,k$ 使 $F\left(\frac jn\right)\le0\le F\left(\frac kn\right)$；在这两点构成的闭区间上用**零点定理**（$F$ 连续），得 $\xi$：$F(\xi)=0$——即 $f(\xi)=f\left(\xi+\frac1n\right)$。$\blacksquare$
（A3 是 $n=2$ 的特例：两头相加为零。**求和为零 ⇒ 符号不齐 ⇒ 中间插零**——这条"望远镜求和 + 零点定理"的组合拳是竞赛/考研构造题的常客。）

**C2** 证明 $f(x)=x^2$ 在 $[0,1]$ 上一致连续；并说明它在 $\mathbb R$ 上**不**一致连续。

**参考答案**：
**$[0,1]$ 上一致连续**（放缩找统一 $\delta$）：任给 $\varepsilon>0$，对任意 $x_1,x_2\in[0,1]$：

$$|x_1^2-x_2^2|=|x_1+x_2|\cdot|x_1-x_2|\le 2|x_1-x_2|$$

（$x_1+x_2\le2$——**这就是"闭区间"给的红利：斜率的统一上界**）。取 $\delta=\dfrac\varepsilon2$（**只依赖 $\varepsilon$、与点无关**）：$|x_1-x_2|<\delta\Rightarrow|x_1^2-x_2^2|<\varepsilon$。故一致连续。$\blacksquare$

**$\mathbb R$ 上不一致连续**（定义否定式）：取 $\varepsilon_0=1$。任给 $\delta>0$，取 $t>\dfrac1{2\delta}$ 与 $x_1=t$、$x_2=t+\dfrac1{2t}$（一个标准的"右邻点"构造）：$|x_1-x_2|=\dfrac1{2t}<\delta$，但

$$|x_1^2-x_2^2|=2t\cdot\frac1{2t}+\frac1{4t^2}=1+\frac1{4t^2}>1=\varepsilon_0.$$

——$\exists\varepsilon_0=1$，$\forall\delta$ 都找得到"距离 $<\delta$ 但函数值差 $\ge1$"的点对：不一致连续。$\blacksquare$
（两个方向合起来展示了"一致连续 = 斜率受整段统一管制"：$x^2$ 在 $[0,1]$ 斜率 $\le2$（管得住）、在 $\mathbb R$ 斜率无界（管不住）。**不要**提炼成"斜率有界 $\iff$ 一致连续"——那需要中值定理（13 讲）才说得准，现在只吸收"斜率统一受控"这层图景。）

### D. 代码（可跑验证）

**D1** 二分法完整实弹：对 $F(x)=x^3-x-1$ 在 $[1,2]$ 上二分 20 步，打印每 5 步的区间、区间长与中点值；断言"第 $n$ 步后区间长 $=(b-a)/2^n$"（用 $n=5,10,15,20$ 的打印值核对），并输出与"参照值" $1.3247179572\ldots$ 的偏差（该参照值来自更高精度二分，见脚本注释）。

**参考答案**：

```python
import numpy as np

F = lambda x: x ** 3 - x - 1
a, b = 1.0, 2.0
ref = 1.3247179572          # 高精度参照值（x^3-x-1 的根，10 位截断）

print("二分 20 步 (x^3 - x - 1 = 0, [1, 2]):")
for n in range(1, 61):
    c = (a + b) / 2
    if F(c) == 0:
        break
    if F(a) * F(c) < 0:
        b = c
    else:
        a = c
    if n in (5, 10, 15, 20):
        length = b - a
        expected = 1.0 / 2 ** n
        print(f"  n = {n:2d}: 区间 [ {a:.9f}, {b:.9f} ], 长 = {length:.3e} (= 1/2^{n}? {abs(length - expected) < 1e-15})")
print(f"  60 步后根 ≈ {(a + b) / 2:.10f}, 与参照值偏差 = {abs((a + b) / 2 - ref):.2e}")

# 用 60 步结果刷新参照：报告它
print(f"  (60 步二分本身即参照: {(a + b) / 2:.10f})")
```
