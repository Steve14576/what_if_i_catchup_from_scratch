## 一、开场：三道"公式从哪来"题

**题 1**：圆盘法 $V=\int\pi y^2dx$——你高中"见过"公式。**它从哪来**？"$\Delta V\approx\pi y^2\Delta x$"这行字凭什么**是合法的**？

**题 2**：弧长——每小段近似写 $\sqrt{\Delta x^2+\Delta y^2}$，为什么**不能**图省事用 $\Delta x$？（两者差在哪一级？）

**题 3**：旋转体的两条"捷径"——"体积 $=$ 面积 $×$ 形心路程"与它的侧面积版——**为什么成立**？"路程"里的"平均"是哪一种平均？（正式处理在 27 讲，今天先埋问题。）

**答案预告**：

1. 从**元素法**来：薄圆盘微元（半径 $y$、厚 $\Delta x$）的体积 $\approx\pi y^2\Delta x$——**"以直代曲"的误差是 $o(\Delta x)$ 级（局部）**，而**求和之后仍然消失**——第二节把这条"合法性链"的完整账写出来。
2. 差在**阶数**：用 $\Delta x$ 近似的误差是 $O(\Delta x)$ 级（**一阶**——求和后**不消失**，会累积成一个正的错值）；用弦长近似的误差是**高阶**（求和后消失）——**这一"阶"之差就是元素法的生死线**（第五节完整论证）。
3. 关键在"**平均路程**"的合法性："面积 $×$ 平均路程"里的"平均"必须是**按面积加权**——而加权平均位置**正是形心**；再加上微元级"以直代曲"的合法性账（元素法判据），两条捷径就都有了严格证明——这是 27 讲的主线（今天先记住疑点）。

## 二、元素法：模板与合法性链

### 2.1 模板（三步）

> **①选积分变量**（$x$ 或 $y$ 或 $\theta$）、**定范围**（$[a,b]$）；**②微元**：在 $[x,x+dx]$ 上"以直代曲"，写出 $\Delta Q\approx q(x)dx$（即 $dQ=q(x)dx$）；**③积分**：$Q=\int_a^bq(x)dx$。

**"微元三问"**（每题必答）：**（a）近似误差为什么求和后消失？**（b）$q$ 该写成什么？**（c）范围**（交点在算前先求清楚）。

### 2.2 合法性链（疑问 1——"误差哪去了"的完整账）

以面积为例：把 $[a,b]$ 分成 $n$ 段，第 $i$ 段真实面积 $\Delta A_i$、近似值 $f(\xi_i)\Delta x_i$。**两个事实**：

**① 局部误差是 $o(\Delta x_i)$**：$\Delta A_i=f(\xi_i)\Delta x_i+\delta_i$，其中 $\delta_i/\Delta x_i\to0$（当 $\Delta x_i\to0$）——这是 12 讲"**以直代曲**"的原文（$f$ 连续时，小段上的面积差被 $o(\Delta x)$ 兜住）；统一写法：$|\delta_i|\le\varepsilon(\lambda)\cdot\Delta x_i$，其中 $\lambda=\max\Delta x_i$、$\varepsilon(\lambda)\to0$（一致性的账——**误差界"每段按比例"给**）。

**② 求和：误差的总账**：

$$\big|\text{近似总面积}-\text{真实面积}\big|=\Big|\sum\delta_i\Big|\le\varepsilon(\lambda)\sum\Delta x_i=\varepsilon(\lambda)\,(b-a).$$

**关键**：$\varepsilon(\lambda)\to0$ 而 $\sum\Delta x_i=(b-a)$ **是一个有界的数**——⇒ **总误差 $\to0$** ✓。$\blacksquare$

**这就是"误差哪去了"的答案**：**局部的高阶小量（每人错 $o(\Delta x)$）经求和后总账仍是小量（乘上有界的长度 $(b-a)$）**。**一整句话**：$o(\Delta x)$ 乘有界次数 $=$ 小量——**元素法的一切合法性就压在这**。

**反面模式（下文的弧长教训）**：若把局部误差写成**一阶**（$\delta_i\approx c\cdot\Delta x_i$、$c\ne0$）——求和后 $\approx c(b-a)$ **不消失**——**"每段错一点点"变成"整体错一大截"**。判据：

> **元素法合法 ⇔ 局部误差 $o(\Delta x)$（不是 $O(\Delta x)$）。**

## 三、平面图形面积：变量选择是道选择题

### 3.1 基本形态与微元训练

**上下曲线围成**：$A=\int_a^b\big[f_{\text{上}}(x)-f_{\text{下}}(x)\big]dx$（微元：$\big[f_{\text{上}}-f_{\text{下}}\big]dx$——"竖条"高一乘宽）。

**右左曲线围成**（对 $y$ 积分）：$A=\int_c^d\big[x_{\text{右}}(y)-x_{\text{左}}(y)\big]dy$——**同一个区域，两种切法**：**哪种"一条就够"就用哪种**。

### 3.2 变量选择实战（经典对照）

**区域**：抛物线 $x=y^2$ 与直线 $y=x-2$ 围成。**先求交点**：$x=y^2$ 代入 $y=x-2$：$y=y^2-2\Rightarrow y^2-y-2=0\Rightarrow y=2,-1$——交点 $(4,2)$ 与 $(1,-1)$。

**横切（对 $y$ 积分——右减左）**：右边界 $x=y+2$、左边界 $x=y^2$：

$$A=\int_{-1}^{2}\big[(y+2)-y^2\big]dy=\Big[\frac{y^2}2+2y-\frac{y^3}3\Big]_{-1}^{2}.$$

**把数算干净**：上界 $y=2$：$\frac42+4-\frac83=\frac{10}{3}$；下界 $y=-1$：$\frac12-2+\frac13=-\frac76$ ⇒ $A=\frac{10}3+\frac76=\frac{27}6=\frac92$ ✓。

**对照：竖切（对 $x$ 积分）要拆两段**（$x\in[0,1]$ 上边界是 $\pm\sqrt x$ 的"上下支"、$x\in[1,4]$ 上边界是 $\sqrt x$ 与 $x-2$——交换了）——**两段的账更繁**。**结论**：**"横切一句完"——变量选择省下的是整整一段积分的账**（实验 1 数值对账 $=4.5$）。

## 四、体积：盘/环/截面

### 4.1 圆盘法与圆环法（疑问 2——"轴的位置"全表）

**微元来源**：绕 $x$ 轴旋转——**垂直于轴的切**（竖切）产生**薄圆盘**：半径 $y$、厚 $dx$：$\Delta V\approx\pi y^2dx$。

> **圆盘法**：$V=\pi\int_a^by^2dx$（区域上边界为 $y$ 曲线）。
> **圆环法**（washer）：区域夹在两曲线间：$V=\pi\int_a^b\big[y_{\text{外}}^2-y_{\text{内}}^2\big]dx$——**外减内**（大圆盘挖小圆盘）。

**"盘 vs 环"与"轴的位置"——判读四格表**：

| 旋转轴 | 切法（垂直于轴） | 微元半径 | 公式骨架 |
|---|---|---|---|
| $x$ 轴 | 竖切 $dx$ | $y$（或｜$y_{\text{外}}$−$y_{\text{内}}$｜配对） | $\pi\int y^2dx$（环：外²−内²） |
| $y$ 轴 | 横切 $dy$ | $x$ | $\pi\int x^2dy$（环：外²−内²） |
| 直线 $y=k$ | 竖切 $dx$ | $\|y-k\|$（**半径是到轴的距离**） | $\pi\int[(y_{\text{外}}-k)^2-(y_{\text{内}}-k)^2]dx$ |
| 直线 $x=k$ | 横切 $dy$ | $\|x-k\|$ | 同款对偶 |

**判读顺序（防错）**：①轴是谁？②**切哪边**（垂直于轴）？③半径**到轴的距离**（高到其他轴的距离就错工）——**"盘还是环"最后看**：切面有没有被挖空（区域是否夹在两曲线之间）。

（绕 $y$ 轴的"竖切"路线是**壳层法**——简介层：另一个公式 $\int2\pi x y\,dx$——**知道有、考试主流用四格表**。）

### 4.2 截面法（疑问 3——"更一般"在哪）

> **截面法**：若立体垂直于 $x$ 轴、位置 $x$ 处的截面面积 $A(x)$ 已知：$V=\int_a^bA(x)\,dx$（微元：薄片 $\approx A(x)\Delta x$）。

**"更一般"的答案**：旋转体只是"**截面是圆（或环）**"的特例；截面法**不管截面长什么样**——只要面积能写成 $x$ 的函数。**经典全程（椭球体）**：$\frac{x^2}{a^2}+\frac{y^2}{b^2}+\frac{z^2}{c^2}=1$：在 $x$ 处截面是椭圆 $\frac{y^2}{b^2}+\frac{z^2}{c^2}=1-\frac{x^2}{a^2}$，半轴 $b\sqrt{1-\frac{x^2}{a^2}}$ 与 $c\sqrt{1-\frac{x^2}{a^2}}$ ⇒ 面积 $A(x)=\pi bc\left(1-\frac{x^2}{a^2}\right)$ ⇒

$$V=\int_{-a}^{a}\pi bc\left(1-\frac{x^2}{a^2}\right)dx=\pi bc\left(2a-\frac{2a}3\right)=\frac43\pi abc\ \checkmark$$

（$a=b=c=R$ 时回收到球体积 $\frac43\pi R^3$——**旧公式是新引擎的一个特例** ✓。）

## 五、弧长：推导与历史教训（疑问 4）

### 5.1 为什么不能用 $\Delta x$ 近似（历史教训的完整论证）

**两种近似的对照**（每小段 $[x_{i-1},x_i]$，段长 $\Delta x_i$、弧长 $\Delta s_i$）：

- **错误写法**（$\Delta s_i\approx\Delta x_i$）：误差 $\Delta s_i-\Delta x_i$——由弧微分的几何（$ds=\sqrt{1+y'^2}dx$——18 讲的账）：$\Delta s_i\approx\sqrt{1+y'(\xi_i)^2}\,\Delta x_i$——**误差**

$$\Delta s_i-\Delta x_i\approx\big(\sqrt{1+y'^2}-1\big)\Delta x_i=O(\Delta x_i)\quad(\text{一阶}；y'\ne0\ \text{时}).$$

**求和**：总误差 $\approx\sum\big(\sqrt{1+y'^2}-1\big)\Delta x_i\to\int_a^b\big(\sqrt{1+y'^2}-1\big)dx>0$——**一个正数，不消失**！——"每段少算一点点"累积成"整段少算一大截"（数值铁证：实验 3 的 $0.785$ vs $0.881$——"$\Delta x$ 和"永远是 $\frac\pi4$、弧长是 $0.881$——**永不收敛到真值**）。

- **正确写法**（弦长）：$\Delta s_i\approx\sqrt{\Delta x_i^2+\Delta y_i^2}$——弧与弦的差是**高阶**（弧的"弯"贡献的是二阶账——与元素法合法性链同一级别的账）——**求和后消失** ✓。

**一句话**：$\Delta x$ 近似弧长的误差是**一阶**（**违反元素法判据**）；弦长近似的误差是**高阶**（合格）。

### 5.2 公式推导（LMVT 链）

由 LMVT（13 讲）：$\Delta y_i=y'(\xi_i)\Delta x_i$（$\xi_i\in(x_{i-1},x_i)$）：

$$\Delta s_i\approx\sqrt{\Delta x_i^2+\Delta y_i^2}=\sqrt{1+y'(\xi_i)^2}\,\Delta x_i\ \Longrightarrow\ s=\int_a^b\sqrt{1+y'^2}\,dx.$$

（**推导的账**：弦长→弧长的差是高阶（5.1 的对照）；$\sqrt{1+y'(\xi_i)^2}$ 是连续函数（$y'$ 连续时）⇒ 黎曼和 → 积分 ✓。）

### 5.3 案例（优雅一例）

$y=\ln\cos x$（$x\in[0,\frac\pi4]$）：$y'=-\tan x$ ⇒ $\sqrt{1+y'^2}=\sec x$ ⇒

$$s=\int_0^{\pi/4}\sec x\,dx=\ln|\sec x+\tan x|\Big|_0^{\pi/4}=\ln(1+\sqrt2)\approx0.8814\ \checkmark$$

（**两处旧账回收**：$\int\sec$ 的"乘 $(\sec+\tan)$"技巧（20 讲备查）与 $1+\tan^2=\sec^2$（20 讲）。**对照实验 3**：数值"弦长和"收敛到 $0.8814$、"$\Delta x$ 和"恒 $\frac\pi4$。）

## 六、极坐标面积与功的同构（疑问 5、6）

### 6.1 极坐标面积：扇形微元

**微元来源**：把极角细分——$[\theta,\theta+\Delta\theta]$ 上曲边扇形**近似为**半径 $r(\theta)$ 的**标准扇形**——标准扇形面积（高中资产）：$\frac12r^2\Delta\theta$（圆心角 $\Delta\theta$、半径 $r$：占整圆的 $\frac{\Delta\theta}{2\pi}$，面积 $\frac{\Delta\theta}{2\pi}\cdot\pi r^2=\frac12r^2\Delta\theta$ ✓）——"以直代曲"：小段上 $r(\theta)$ 近似常值。

$$A=\frac12\int_{\alpha}^{\beta}r(\theta)^2\,d\theta.$$

**经典全程（心形线 $r=1+\cos\theta$ 的全面积）**：

$$A=\frac12\int_0^{2\pi}(1+\cos\theta)^2d\theta=\frac12\int_0^{2\pi}\big(1+2\cos\theta+\cos^2\theta\big)d\theta=\frac12\big(2\pi+0+\pi\big)=\frac{3\pi}2\ \checkmark$$

（**用了 24 讲的三件**：$\int_0^{2\pi}\cos=0$（周期整消）、$\int_0^{2\pi}\cos^2=\pi$（对称+华里士）——**旧武器在新场景的回收**。理解层次：极坐标绘图与"描点定范围"属练习量——**考试题型以"给方程、给范围"为主**。）

### 6.2 功的同构（疑问 6——同一台引擎）

**变力做功**：微元 $\Delta W\approx F(x)\Delta x$（小段上力近似常值）⇒ $W=\int_a^bF(x)\,dx$。**例（弹簧）**：$F=kx$（胡克定律——物理资产，此处直接引用）：从平衡位拉到 $L$：

$$W=\int_0^Lkx\,dx=\frac12kL^2\ \checkmark（数值对账见实验 4）。$$

**"同构性"的正式回答**：**元素法是骨架，量名是插件**——面积（$q=$ 高）、体积（$q=$ 截面积）、弧长（$q=\sqrt{1+y'^2}$）、极坐标面积（$q=\frac12r^2$）、功（$q=$ 力）、液体压力（$q=$ 压强×深度条——简介）——**写微元、定范围、积分**三步不变。**理解层次：功与压力会"列微元"即可**（物理应用细节属后续课程）。

**结论（实测坐实）**：两者与解析吻合（浮点级）——盘/环公式双验证。

### 实验 3：弧长两对照（历史教训的数值判决）

$y=\ln\cos x$（$0\to\frac\pi4$）：(i) **弦长和**（$n=10^3,10^4$）→ $0.8814=\ln(1+\sqrt2)$；(ii) **$\Delta x$ 和**（恒 $\frac\pi4\approx0.7854$——**永不收敛到弧长**）。

（实测）：

```
  n = 1000: 弦长和 = 0.88137356 (弧长 0.88137359, 差 -2.27e-08); delta-x 和 = 0.78539816 (恒 pi/4)
  n = 10000: 弦长和 = 0.88137359 (弧长 0.88137359, 差 -2.27e-10); delta-x 和 = 0.78539816 (恒 pi/4)
```

**结论（实测坐实）**：弦长和逐位趋 $0.88137359=0.8814$（误差按 $1/n$ 降）；$\Delta x$ 和恒 $0.78539816=\frac\pi4$（**误差 $0.0960$ 不消失**）——"一阶误差求和后不消失"的活体判决。

1. **"元素法判据一句话？"**
   （→ 2.2）**局部误差必须 $o(\Delta x)$**（不是 $O(\Delta x)$）——合法则有"$\varepsilon(\lambda)(b-a)\to0$"的求和账；违规则有"$c(b-a)$ 不消失"的翻车账（弧长教训）。
2. **"旋转体公式，考场如何 30 秒定式？"**
   （→ 4.1）四步：**轴是谁 → 垂直切 → 半径=到轴距离 → 盘还是环**（切面是否挖空）；非坐标轴（$y=k$）用 $|y-k|$。

   （→ 4.2）题目**给出"截面是什么形状"**（或显然能用 $x$ 表达面积）时——旋转体反而是特例；椭球体是标准演练。
4. **"弧长积分难算怎么办？"**
   （→ 5.3）$\sqrt{1+y'^2}$ 的化简靠恒等式：常见的三种"化简友好"型：$1+\tan^2=\sec^2$（对 $\ln\cos$ 型）、$1+\sinh^2=\cosh^2$（挂名）、配方后三角代换（20 讲三型）；**算不动先查化简**。
5. **"物理量题要不要背公式？"**
   （→ 6.2）**不要**——只练"写微元"：力×位移、压强×面积（深度）、……；**同一台引擎、换插件**。

## 本讲小结

- **元素法模板**：选变量/定范围 → 微元（以直代曲 $\Delta Q\approx q\,d$）→ 积分；**微元三问**（误差账/写法/范围）。
- **合法性链**：局部误差 $o(\Delta x)$ + 求和（$\le\varepsilon(\lambda)(b-a)\to0$）⇒ 合法；**判据：局部误差必须 $o(\Delta x)$**；反面模式=一阶误差求和不消失。
- **面积**：上下/右左两写法——**变量选择是选择题**（$x=y^2$ 与 $y=x-2$：横切一积分 $=\frac92$、竖切拆两段）。
- **体积**：盘/环——**四格表**（轴×切法；半径=到轴距离；盘环看挖空）；**截面法更一般**（椭球体全程 $V=\frac43\pi abc$）。
- **弧长**：$s=\int\sqrt{1+y'^2}dx$——**历史教训论证**：$\Delta x$ 近似是一阶误差（求和不消失，数值恒 $\frac\pi4\ne0.881$）；弦长/弧之差是高阶（合格）；LMVT 链导出公式；$\ln\cos$ 例 $=\ln(1+\sqrt2)$。
- **极坐标面积**：$\frac12\int r^2d\theta$（扇形微元；心形线 $\frac{3\pi}2$——旧武器大回收）。
- **功的同构**：$W=\int F\,dx$（弹簧 $\frac12kL^2$）——**一台引擎、排插式插件**。

## 作业

### A. 基础（直接演练）

**A1** 面积：$y=x^2$ 与 $y=x$ 围成的区域。

**参考答案**：
交点：$x^2=x\Rightarrow x=0,1$。上减下：$A=\int_0^1(x-x^2)dx=\frac12-\frac13=\frac16$。

**A2** 体积：(1) $y=\sqrt x$ 在 $[0,4]$ 绕 $x$ 轴（圆盘法）；(2) $y=x$ 与 $y=x^2$ 之间绕 $x$ 轴（圆环法）。

**参考答案**：
(1) $V=\pi\int_0^4x\,dx=\pi\cdot8=8\pi$。
(2) 外 $x$、内 $x^2$：$V=\pi\int_0^1(x^2-x^4)dx=\pi\left(\frac13-\frac15\right)=\frac{2\pi}{15}$。

**A3** 弧长：$y=\frac23x^{3/2}$ 在 $[0,3]$。

**参考答案**：
$y'=\sqrt x$ ⇒ $\sqrt{1+y'^2}=\sqrt{1+x}$ ⇒ $s=\int_0^3\sqrt{1+x}\,dx=\frac23(1+x)^{3/2}\Big|_0^3=\frac23(8-1)=\frac{14}3$。

**A4** 判断：(1) 元素法的局部误差必须是什么级？(2) "用 $\Delta x$ 近似弧长"错在哪一级？(3) 圆盘法的"盘"垂直于什么？(4) 极坐标面积微元是什么？

**参考答案**：
(1) $o(\Delta x)$（高阶）。
(2) **一阶**（$O(\Delta x)$——求和后不消失）。
(3) **旋转轴**（垂直于轴切）。
(4) $\frac12r^2d\theta$。

### B. 提高（推导与全程）

**B1** 复写元素法合法性链（含两个事实与求和式）。

**参考答案**：
事实①：局部 $\Delta A_i=f(\xi_i)\Delta x_i+\delta_i$、$|\delta_i|\le\varepsilon(\lambda)\Delta x_i$（$\varepsilon\to0$——以直代曲的账）；事实②：$|\sum\delta_i|\le\varepsilon(\lambda)\sum\Delta x_i=\varepsilon(\lambda)(b-a)\to0$ ⇒ 近似和 → 真实值。$\blacksquare$

**B2** 弧长公式推导（LMVT 链）+ "$\Delta x$ 近似"误差为一阶的论证。

**参考答案**：
LMVT：$\Delta y_i=y'(\xi_i)\Delta x_i$ ⇒ 弦长 $=\sqrt{1+y'(\xi_i)^2}\Delta x_i$（高阶差 + 黎曼和 ⇒ $s=\int\sqrt{1+y'^2}dx$）。
$\Delta x$ 近似：$\Delta s-\Delta x\approx(\sqrt{1+y'^2}-1)\Delta x=O(\Delta x)$（$y'\ne0$）——求和 → $\int(\sqrt{1+y'^2}-1)dx>0$ **不消失**。$\blacksquare$

**B3** 椭球体：完整截面法（截面面积 → 积分 → $\frac43\pi abc$）。

**参考答案**：
$x$ 处截面：$\frac{y^2}{b^2}+\frac{z^2}{c^2}=1-\frac{x^2}{a^2}$ ⇒ 半轴 $b\sqrt{\cdot}$、$c\sqrt{\cdot}$ ⇒ $A(x)=\pi bc(1-\frac{x^2}{a^2})$；$V=\pi bc\int_{-a}^{a}(1-\frac{x^2}{a^2})dx=\pi bc\cdot\frac{4a}3=\frac43\pi abc$。$\blacksquare$（**$a=b=c=R$ 回收球体**。）

### C. 综合（难题档，允许卡）

**C1** 非坐标轴旋转：$y=\sin x$（$[0,\pi]$）与 $x$ 轴之间的区域**绕直线 $y=-1$** 旋转——求体积。

**参考答案**：
半径 = 到轴距离：外半径 $\sin x+1$；内半径 $1$（区域下界 $y=0$ 到轴距离 1）：

$$V=\pi\int_0^\pi\big[(\sin x+1)^2-1^2\big]dx=\pi\int_0^\pi(2\sin x+\sin^2x)dx=\pi\Big(4+\frac\pi2\Big).$$

（$\int_0^\pi\sin=2$（24 讲）；$\int_0^\pi\sin^2=\frac\pi2$（对称+华里士）——**旧账全回收**。）$\blacksquare$

**C2** 双纽线：$r^2=2\cos2\theta$ 的全面积（**先想清楚"一叶"的范围**）。

**参考答案**：
一叶：$\theta\in[-\frac\pi4,\frac\pi4]$（$\cos2\theta\ge0$ 的区间）；全图两叶：

$$A=2\cdot\frac12\int_{-\pi/4}^{\pi/4}2\cos2\theta\,d\theta=\int_{-\pi/4}^{\pi/4}2\cos2\theta\,d\theta=\sin2\theta\Big|_{-\pi/4}^{\pi/4}=2.$$

（核对：$r^2=a^2\cos2\theta$ 的面积 $=a^2$，$a^2=2$ ✓。）$\blacksquare$

### D. 代码（可跑验证）

**D1** 复刻并扩展实验 2—3：(a) 球体 $\pi\int_{-1}^1(1-x^2)dx$ 数值 vs $\frac{4\pi}3$（断言 $<10^{-8}$ 相对）；(b) **弧长双对照**：$y=\ln\cos x$ 的弦长和（$n=10^4$）vs $\ln(1+\sqrt2)$（断言 $<10^{-5}$ 相对）**且**"$\Delta x$ 和"恒 $\frac\pi4$（断言与弧长之差 $>0.09$）。

**参考答案**：

```python
import numpy as np

def simpson(f, a, b, n=None):
    if n is None:
        n = max(2000, int(100 * (b - a)))
        if n % 2 == 1:
            n += 1
    x = np.linspace(a, b, n + 1)
    y = f(x)
    h = (b - a) / n
    return h / 3 * (y[0] + y[-1] + 4 * np.sum(y[1:-1:2]) + 2 * np.sum(y[2:-1:2]))

print("(a) sphere volume")
V = np.pi * simpson(lambda x: 1 - x ** 2, -1, 1)
exact = 4 * np.pi / 3
print(f"  数值 = {V:.10f}, 解析 = {exact:.10f}, 相对差 = {abs(V - exact) / exact:.2e}")
assert abs(V - exact) / exact < 1e-8

print("(b) arc length: chord sum vs delta-x sum")
n = 10000
x = np.linspace(0, np.pi / 4, n + 1)
y = np.log(np.cos(x))
chord = np.sum(np.sqrt(np.diff(x) ** 2 + np.diff(y) ** 2))
dxsum = np.sum(np.diff(x))
exact_arc = np.log(1 + np.sqrt(2))
print(f"  弦长和 = {chord:.8f}, 弧长解析 = {exact_arc:.8f}, 相对差 = {abs(chord - exact_arc) / exact_arc:.2e}")
print(f"  delta-x 和 = {dxsum:.8f}, 与弧长之差 = {abs(dxsum - exact_arc):.4f}")
assert abs(chord - exact_arc) / exact_arc < 1e-5
assert abs(dxsum - exact_arc) > 0.09
print("[OK] 球体积与弧长双对照全部核实")
```

```

  数值 = 4.1887902048, 解析 = 4.1887902048, 相对差 = 2.12e-16
(b) arc length: chord sum vs delta-x sum

  delta-x 和 = 0.78539816, 与弧长之差 = 0.0960

```

（核对点：(a) 球体积吻合 $2.1\times10^{-16}$（浮点级）；(b) 弦长和吻合 $2.6\times10^{-10}$ 而 $\Delta x$ 和差 $0.0960>0.09$ 且恒为 $\frac\pi4$——"高阶合格 vs 一阶翻车"的数值终审。**附带说明**：EXP4 初版又踩了“标量 `math.cos` 套数组”的同族坑（连续三讲第三例）——**被积函数一律只用 `np.*`** 已升格为脚本模板纪律。）
