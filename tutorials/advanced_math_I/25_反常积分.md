# 第 25 讲：反常积分

> **前置**：第 23 讲（N-L 与变限求导）+ 24 讲（定积分计算技术）+ 05/07 讲（极限与初等函数）。
> **预计时间**：3.5–4 小时（含作业）。积分学"计算篇"的最后一站：**把两条限制各放开一条**——区间从有限变**无穷**、函数从有界变**无界**——"积分"还能不能算、怎么算、什么情况下这件事根本无意义。
>
> **一句话定位**：反常积分 = **变限积分取极限**（"收敛/发散"的所有定义都从这一句长出来）。两大主题：**两张 $p$ 积分表**（$\int_1^\infty x^{-p}$ 与 $\int_0^1x^{-p}$——比较判别法的"标尺"，分界线 $p=1$ 的原委）+ **内部瑕点必拆**（"奇函数对称抵消"在这里制造了最著名的陷阱）。外加：发散的两型（$\infty$ / 振荡）、比较判别法的用法与"对数尺子"的补充。
>
> **本讲回答什么**：
> 1. $\int_1^\infty\frac{dx}{x^2}=1$ 而 $\int_1^\infty\frac{dx}x=+\infty$——$p$ 的**分界为什么恰在 1**？
> 2. 瑕积分 $\int_0^1\frac{dx}{x^p}$ 的分界也在 1？两张表**镜像**是什么意思？
> 3. 内部有瑕点**必须拆区间**——不拆、直接代值会错出什么？
> 4. "发散"就是 $+\infty$ 吗？有没有**振荡型**发散？
> 5. 比较判别法的尺子（$p$ 积分）怎么选？尺子够不着怎么办？
> 6. 收敛的反常积分能当普通积分用吗（四则、N-L）？
>
> **本讲目标（学完你能）**：
> 1. 用"变限取极限"写出两类反常积分的定义，并**完整推导两张 $p$ 积分表**（说清分界线 $p=1$ 的机制）；
> 2. 用换元 $x=\frac1t$ 证明两表的镜像关系；正确处理"内部瑕点必拆"并识别"对称抵消"陷阱；
> 3. 用比较判别法（$p$ 尺 + 对数尺）判定收敛性；区分发散的两型。
>
> **目标达成 = 末尾"掌握度自测"全部打勾。**
>
> **怎么学这一讲**：所有"反常"的定义只有一句"**先算普通积分、再取极限**"——任何题的第一步都是把限写成 $b$ 或 $\varepsilon$ 的极限（养成这个动作，目录级的混淆自动消失）；两张表要**推**不要背（都是幂函数积分 + 一个极限）；"拆区间"是本讲的核心纪律。

## 一、开场：三道"分界与陷阱"题

**题 1**：$\displaystyle\int_1^\infty\frac{dx}{x^2}=1$ 收敛，而 $\displaystyle\int_1^\infty\frac{dx}x=+\infty$ 发散——两个函数"长得几乎一样"，**分界线为什么恰在 $p=1$**？

**题 2**：$\displaystyle\int_0^1\frac{dx}x$——"在 $0$ 处爆炸"的积分——它是病，还是"病得和 $\int_1^\infty\frac{dx}x$ 一样"？（**镜像**在哪？）

**题 3（陷阱预警）**：$\displaystyle\int_{-1}^1\frac{dx}x$——"奇函数、区间对称——对称抵消得 0？"——**这一步对不对？**

**答案预告**：

1. 分界线来自一个**极限**：$\int_1^b x^{-p}dx$ 的尾部是 $\frac{b^{1-p}-1}{1-p}$ 型——**指数 $1-p$ 必须为负（$b^{1-p}\to0$）才收敛**——$1-p<0\Leftrightarrow p>1$。妙处还有**几何直觉**：$\frac1x$ 的尾巴"每翻倍贡献一个常数 $\ln2$"（剪不断）；$\frac1{x^2}$ 的尾巴"每翻倍贡献减半"（等比收）——第三节/实验 1 细说。
2. **一样的病**（都是"在端点上爆炸/拖尾"）：把 $x=\frac1t$ 换元，$[1,\infty)$ 上的尾巴**逐字翻译**成 $(0,1]$ 上的爆炸——**两张 $p$ 积分表互为镜像**（分界线 $p=1$ 不变，方向翻转：$\int_1^\infty$ 要 $p>1$、$\int_0^1$ 要 $p<1$）。
3. **错**！——**这里必须拆区间**：拆开后**两个半边各自发散**（各自是 $+\infty$ 与 $-\infty$ 的"未定式"）——"抵消"只对**各自收敛**的情形合法。正确结论：**$\int_{-1}^1\frac{dx}x$ 发散**（第三节的完整"陷阱解剖"）。

> 下一站：先把"无穷区间"的病定义清楚——一切从"变限取极限"开始。

## 二、无穷区间上的反常积分与 $p$ 表（无穷端）

### 2.1 定义（一句话："先普通、再极限"）

> **定义**：设 $f$ 在 $[a,+\infty)$ 上连续：
> $$\int_a^{+\infty}f(x)\,dx:=\lim_{b\to+\infty}\int_a^bf(x)\,dx.$$
> 极限**存在（有限）**称反常积分**收敛**，该极限值就是积分值；极限不存在称**发散**。

$\int_{-\infty}^bf$ 对称定义；$\int_{-\infty}^{+\infty}f$：**必须拆成两段**（任选分点 $c$）：

$$\int_{-\infty}^{+\infty}f=\int_{-\infty}^{c}f+\int_c^{+\infty}f\quad(\text{两段都收敛才算收敛}).$$

**"变限取极限"是全部**：计算照旧用 N-L（先算 $\int_a^bf$），**最后加一步取极限**——"收敛/发散"的判定就是"这个极限存不存在"。

### 2.2 两例与 $p$ 表（无穷端）

**例 1**：$\int_1^{+\infty}\frac{dx}{x^2}=\lim_{b\to\infty}\left(1-\frac1b\right)=1$（收敛）。
**例 2**：$\int_1^{+\infty}\frac{dx}x=\lim_{b\to\infty}\ln b=+\infty$（发散）。

> **$p$ 积分表（无穷端）**：$\displaystyle\int_1^{+\infty}\frac{dx}{x^p}$：**$p>1$ 时收敛**（$=\frac1{p-1}$）、**$p\le1$ 时发散**。

**推导（完整——"分界在 1"的原委）**：$p\ne1$ 时：

$$\int_1^b\frac{dx}{x^p}=\frac{x^{1-p}}{1-p}\Big|_1^b=\frac{b^{1-p}-1}{1-p}.$$

**关键只剩一项**：$b^{1-p}$（$b\to\infty$）——**指数为负才归零**：$1-p<0\Leftrightarrow p>1$ ⇒ 收敛 $\frac{0-1}{1-p}=\frac1{p-1}$；$p<1$ 时 $b^{1-p}\to\infty$ ⇒ 发散。$p=1$ 单列：$\ln b\to\infty$ 发散 ✓。

**"分界在 1"的几何直觉**（值得记住）：

- $\frac1x$：每一段 $[c,2c]$ 的贡献 $=\ln2$——**区间翻倍就贡献一个常数**——尾巴是"无限个 $\ln2$"⇒ **剪不断**（发散）；
- $\frac1{x^2}$：每段 $[c,2c]$ 的贡献 $=\frac1{2c}$——**翻倍就减半**——等比级数收敛 ⇒ **剪得断**。

（这正是"调和级数 vs 平方倒数和"的连续版——级数语言属高数下，此处只作呼应。）

## 三、瑕积分与"必拆"纪律

### 3.1 定义与 $p$ 表（零点端）

**瑕点**：$f$ 在点 $c$ 的附近无界（如 $\frac1x$ 在 $0$ 附近"爆炸"）。

> **定义（瑕积分）**：$c$ 为瑕点且 $c$ 在端点（取下限为例）：
> $$\int_a^cf(x)dx:=\lim_{\varepsilon\to0^+}\int_{a+\varepsilon}^cf(x)\,dx.$$
> **$c$ 在内部**：$\int_a^bf=\int_a^cf+\int_c^bf$——**必须拆成两个瑕积分，各自收敛才算收敛**。（同一个区间里多个瑕点：**逐个拆到每段只剩一个"端点瑕"**。）

> **$p$ 积分表（零点端）**：$\displaystyle\int_0^1\frac{dx}{x^p}$：**$p<1$ 时收敛**（$=\frac1{1-p}$）、**$p\ge1$ 时发散**。

**推导**：$p\ne1$：$\int_\varepsilon^1x^{-p}dx=\frac{1-\varepsilon^{1-p}}{1-p}$——只剩 $\varepsilon^{1-p}$（$\varepsilon\to0^+$）：**指数为正才归零**：$1-p>0\Leftrightarrow p<1$ ⇒ 收敛 $\frac1{1-p}$；$p=1$：$\ln\frac1\varepsilon\to\infty$ 发散 ✓。

### 3.2 镜像关系（疑问 2 的答案——换元一句话）

**断言**：$\int_1^{+\infty}\frac{dx}{x^p}$ 与 $\int_0^1\frac{dx}{x^p}$ 是**同一个积分被换元 $x=\frac1t$ 互译**：

$$x=\frac1t,\quad dx=-\frac{dt}{t^2};\qquad \int_1^\infty\frac{dx}{x^p}=\int_1^0t^p\cdot\left(-\frac{dt}{t^2}\right)=\int_0^1t^{p-2}\,dt=\int_0^1\frac{dt}{t^{2-p}}.$$

**读结果**：无穷端的 $p$ ↔ 零点端的 $2-p$：**收敛条件"$p>1$"被翻译成"$2-p<1$"（同一个）**——**两表镜像、分界线同一条** ✓。用途：**任何一张表忘了一半，用换元当场推另一半**。

### 3.3 "必拆"纪律与对称抵消陷阱（疑问 3——本讲重头）

**陷阱解剖（开场题 3 的完整版）**：$\int_{-1}^1\frac{dx}x$。

- **错误路线**（"奇函数对称抵消"）：$\ln|x|\big|_{-1}^1=0-0=0$——**错**！
- **正确路线**（拆区间）：$\int_{-1}^1\frac{dx}x=\int_{-1}^0\frac{dx}x+\int_0^1\frac{dx}x$——左半 $=\lim_{\varepsilon\to0^+}\ln\varepsilon=-\infty$（**发散**）；右半 $=+\infty$（**发散**）——**一个发散就够宣判**：整体**发散**。

**为什么"抵消"不合法**：$-\infty$ 与 $+\infty$ 的"和"是**未定式**（22 讲"有向面积"的账要在**两半各自算清**之后才谈抵消——先欠着 $-\infty$、再欠 $+\infty$，没有"两笔债对消"这回事）。

**对照记牢**（一表分清）：

| 情形 | 结论 |
|---|---|
| 奇函数 + **两半各自收敛** | $=0$（真正的抵消——如 $\int_{-1}^1x\,dx$） |
| 奇函数 + 某半发散（含瑕点） | **发散**（$\int_{-1}^1\frac{dx}x$：**不是 0**） |
| 偶函数 + 两半收敛 | $=2\int_0^a$（如 $\int_{-1}^1\frac{dx}{\sqrt{\|x\|}}=2\cdot2=4$） |
| 偶函数 + 半发散 | **发散**（$\int_{-1}^1\frac{dx}{x^2}$：**不是 $2\times$ 发散值**——那个值 $\frac1x$ 的"∞"） |

（**一句话总纪律**：**对称性的一切用法，前提都是"各自收敛"**——24 讲的"偶倍奇零"在反常积分这里的**门禁更严**。另：$\int_{-\infty}^{+\infty}$ 的"对称主值"（$\lim_{R\to\infty}\int_{-R}^R$）是另一套约定——**挂名**，本课程不用。）

## 四、发散两型与比较判别法

### 4.1 发散的两副面孔（疑问 4）

"发散"= **极限不存在**——两种子型：

- **$\infty$ 型**：$\int_1^\infty x\,dx=\lim\frac{b^2-1}2=+\infty$（"面积真到无穷"）；
- **振荡型**：$\int_1^{+\infty}\sin x\,dx=\lim_{b\to\infty}(\cos1-\cos b)$——**振荡无极限**（值在 $[\cos1-1,\cos1+1]$ 里摆——**既不趋于数、也不奔向 $\infty$**）。

**对照**（实验 3）：$\int_1^{+\infty}\frac{\sin x}x\,dx$ **收敛**（摆幅被 $\frac1x$ 压小——"条件收敛"——挂名，其值 $=\frac\pi2-\mathrm{Si}(1)\approx0.625$）——**"乘了个 $1/x$ 就从振荡发散变收敛"**（高数下的狄利克雷判别法正题；本讲只作对照）。

### 4.2 比较判别法（疑问 5）

> **定理（比较判别法，无穷端——非负情形）**：设 $x$ 足够大时 $0\le f(x)\le g(x)$：
> $$\int_a^{+\infty}g\ \text{收敛}\ \Longrightarrow\ \int_a^{+\infty}f\ \text{收敛};\qquad \int_a^{+\infty}f\ \text{发散}\ \Longrightarrow\ \int_a^{+\infty}g\ \text{发散}.$$

**证明思路**（单调有界——05 讲资产）：$\Phi_f(b)=\int_a^bf$ **单调不减**（非负）且 $\Phi_f(b)\le\Phi_g(b)\le\int_a^\infty g<+\infty$ ⇒ **单调有界必收敛** ✓。$\blacksquare$（瑕积分版同款——把 $b$ 换成 $\varepsilon\to0^+$。）

**尺子怎么选（疑问 5 的答案）——两条**：

1. **$p$ 尺**：看尾巴/爆炸点的**幂次主项**——$f\sim\frac{c}{x^p}$：无穷端要 $p>1$、零点端要 $p<1$；
2. **对数尺**（$p$ 尺够不着时）：$\displaystyle\int_2^\infty\frac{dx}{x(\ln x)^q}$：**$q>1$ 收敛、$q\le1$ 发散**（换元 $u=\ln x$ 直接翻成 $p$ 尺——推导见下）。

**演示三连**：

- $\int_1^\infty\frac{dx}{x^2+1}$：$\frac1{x^2+1}\le\frac1{x^2}$ ⇒ 收敛（其值 $=\frac\pi4$——实验 4）；
- $\int_1^\infty\frac{dx}{x+\sqrt x}$：主项 $\sim\frac1x$ ⇒ 发散——**比较方向的校验**：大 $x$ 时 $x+\sqrt x\le2x$ ⇒ $\frac1{x+\sqrt x}\ge\frac1{2x}$，故由 $\frac1{2x}$ 发散推出它发散 ✓；
- $\int_2^\infty\frac{dx}{x(\ln x)^2}$：$u=\ln x$ ⇒ $\int_{\ln2}^\infty\frac{du}{u^2}$——$p=2>1$ 收敛（$=\frac1{\ln2}$）✓；而 $\int_2^\infty\frac{dx}{x\ln x}$ ⇒ $\int_{\ln2}^\infty\frac{du}u$ 发散——**对数尺的分界也在"1 次方"** ✓。

### 4.3 收敛之后的"常规性"（疑问 6——边界清单）

收敛的反常积分是**一个数**——能四则运算、能参与 N-L、能换元（**每一步作用的对象都是"已经收敛的积分"**）。**但三条边界**：

1. **拆区间各自收敛**是一切"相加/抵消"的前提（本节反复强调）；
2. **换元/分部在反常积分里照用，但极限的账要重记**：换元后"新限的极限"是新的关卡（**理解层次：能做、但每步确认收敛**）；
3. **收敛 ≠ 被积函数趋于 0 的逆命题**：$f\to0$ 不保证收敛（$\frac1x$ 就是 $f\to0$ 而发散）——**"趋于 0"是必要条件形状的直觉，不是判据**。

## 五、数值实验：四连验证

**方法说明**：收敛性实验一律"**截断观察法**"——用有限截断 $b$（或 $\varepsilon$）的多档值观察"趋于定值 / 无界增长 / 振荡"三种行为（数值不能"证明"收敛，只能**呈现行为肖像**——诚实口径）。**另加一条采样账**：截断 $b$ 很大时，等段数 Simpson（$n$ 固定 2000）的段长 $h$ 会变大、误差 $\sim h^4$ 爆炸（$b=10^4$ 时把 $\frac1{x^2+1}$ 的积分算成 $1.118$，真值 $0.785$）——脚本改为按"**每单位长度固定密度**"分段（$n\approx100(b-a)$）；这是 24 讲"误差账先算"纪律在数值积分里的又一次实例。

完整脚本在 `scripts/lec25-01_verify_improper.py`（运行：`uv run --with numpy python scripts/lec25-01_verify_improper.py`）。

### 实验 1：$p$ 剖面（$\int_1^{b}x^{-p}dx$，$b=10,100,1000,10^4$）

$p=1.5$（应趋 $2$）、$p=1$（对数增长）、$p=0.5$（幂增长）三列对照。

（实测，全脚本 0.13 秒跑完，可复跑）：

```
  p = 1.5: 1.3675, 1.8000, 1.9368, 1.9800
  p = 1.0: 2.3026, 4.6052, 6.9078, 9.2103
  p = 0.5: 4.3246, 18.0000, 61.2456, 198.0000
```

**结论（实测坐实）**：$p=1.5$ 列稳定趋 $2$（$b=10^4$ 时 $1.98=2-\frac{2}{100}$ 精确符合尾部公式）；$p=1$ 列每十倍恰 $+2.3026=\ln10$（完美对数）；$p=0.5$ 列快速无界（$198=2(100-1)$）——三种命运的行为肖像。

### 实验 2：拆区间纪律（$\int_{-1}^1$ 两例）

(i) $\int_{-1}^{-\varepsilon}+\int_\varepsilon^1$ 对 $\frac1x$：两半各自向 $\pm\infty$ 走（**发散实锤**）；(ii) 对 $\frac1{\sqrt{|x|}}$：两半各自收敛、总趋 $4$。

（实测）：

```
  eps = 1e-01: 1/x 左半(显示为 -值) = -2.3026, 右半 = 2.3026; 1/sqrt 右半 = 1.3675
  eps = 1e-03: 1/x 左半(显示为 -值) = -6.9092, 右半 = 6.9092; 1/sqrt 右半 = 1.9368
  eps = 1e-05: 1/x 左半(显示为 -值) = -25.0379, 右半 = 25.0379; 1/sqrt 右半 = 2.0239
  1/sqrt 两半之和 (eps=1e-5) = 4.047845 (趋 4)
```

**结论（实测坐实）**：$\frac1x$ 的两个半边（$\varepsilon$ 每缩两个量级就翻 $+2.303$）分别向 $-\infty$ 与 $+\infty$ 走——"**不是 0**"的数值判决；$\frac1{\sqrt{|x|}}$ 稳定趋 $4$。

### 实验 3：振荡两型（$\int_1^b$，$b=10,50,100,200,500$）

$b=10,50,100,200,500$：$\int_1^b\sin x\,dx$（振荡——随 $b$ 摆动）vs $\int_1^b\frac{\sin x}x\,dx$（收敛——趋 $\approx0.625$）。

（实测）：

```
  sin:   +1.3794, -0.4247, -0.3220, +0.0531, +1.4242
  sin/x: 0.7123, 0.6055, 0.6161, 0.6223, 0.6265
```

**预期结论**：$\sin$ 列摆动无收敛（$+1.38\to-0.42\to\cdots\to+1.42$ 来回摆）；$\frac{\sin x}x$ 列稳定趋 $0.63$ 级（逐个收缩）——"振荡发散 vs 条件收敛"的对照肖像。

### 实验 4：判别法对账（$\int_1^{10^4}$ 两例）

(i) $\int_1^{10^4}\frac{dx}{x^2+1}\to\frac\pi4\approx0.7854$；(ii) $\int_1^{10^4}\frac{dx}{x+1}=\ln(10001)-\ln2\approx8.52$（还在涨——发散）。

（实测）：

```
  1/(x^2+1): 0.785298 (pi/4 = 0.785398); 1/(x+1): 8.517293 (= ln(10001/2) = 8.517293, 还在涨)
```

**结论（实测坐实）**：$\frac1{x^2+1}$ 贴住 $\frac\pi4$（差 $10^{-4}$ 级——截断尾部的账）；$\frac1{x+1}$ 与解析值**逐位相同**且随 $b$ 继续增长——比较法预言的"一个收敛一个发散"在数值上分道扬镳。

## 本讲小结

- **两类反常积分**（定义=**变限取极限**）：无穷区间（$\int_a^\infty$：$b\to\infty$）；瑕积分（端点瑕 $\varepsilon\to0^+$；**内部瑕必拆**）。
- **两张 $p$ 表（镜像）**：$\int_1^\infty x^{-p}$：$p>1$ 收敛（$\frac1{p-1}$）；$\int_0^1x^{-p}$：$p<1$ 收敛（$\frac1{1-p}$）；镜像=换元 $x=1/t$（$p\leftrightarrow2-p$）；**分界在 1 的机制**：$b^{1-p}$（或 $\varepsilon^{1-p}$）需要"负指数把它压到 0"；几何直觉：$1/x$ 尾巴每翻倍贡献 $\ln2$（剪不断）vs $1/x^2$ 每翻倍减半（剪得断）。
- **拆区间纪律与抵消陷阱**：奇函数"对称抵消"**前提是两半各自收敛**——$\int_{-1}^1\frac{dx}x$ **发散**（$\infty-\infty$ 未定式不是 0）；四行情景对照表。
- **发散两型**：$\infty$ / **振荡**（$\int_1^\infty\sin x$）——对照：$\frac{\sin x}x$ 条件收敛（挂名）。
- **比较判别法**：非负 + 逐点大小 ⇒ 大收敛推小收敛、小发散推大发散（证明=单调有界）；尺子：**$p$ 尺**（幂主项）+ **对数尺**（$x(\ln x)^q$：$q>1$ 收敛）。
- **收敛后常规性**：是数、能运算；三条边界（拆在先、极限账、$f\to0$ 不是判据）。

### A. 基础（定义直算与判别）

**A1** 计算或判定：(1) $\int_1^\infty\frac{dx}{x^3}$；(2) $\int_1^\infty e^{-x}dx$；(3) $\int_1^\infty\frac{dx}{\sqrt x}$。

**参考答案**：
(1) $p=3>1$：$=\frac1{3-1}=\frac12$。
(2) $\lim_{b\to\infty}(e^{-1}-e^{-b})=\frac1e$（收敛）。
(3) $p=\frac12\le1$：**发散**（$\lim2(\sqrt b-1)=\infty$）。

**A2** 瑕积分：(1) $\int_0^1\frac{dx}{\sqrt x}$；(2) $\int_0^1\frac{dx}{x^2}$；(3) $\int_0^1\frac{dx}{\sqrt[3]x}$。

**参考答案**：
(1) $p=\frac12<1$：$=\frac1{1-\frac12}=2$。
(2) $p=2\ge1$：**发散**（$\lim(\frac1\varepsilon-1)=\infty$）。
(3) $p=\frac13<1$：$=\frac1{1-\frac13}=\frac32$。

**A3** 拆区间：(1) $\int_{-1}^1\frac{dx}{x^2}$（**注意**：偶函数也别急着翻倍）；(2) $\int_{-1}^1\frac{dx}{\sqrt{|x|}}$。

**参考答案**：
(1) **拆**：左半 $\int_{-1}^0\frac{dx}{x^2}$ 发散（$p=2$）⇒ **整体发散**（偶函数"...=2∫₀¹"的前提没满足——不是某个有限值的两倍）。
(2) **拆**：左半 $=\int_0^1\frac{dt}{\sqrt t}$（换元 $x=-t$）$=2$；右半 $=2$ ⇒ 总 $=4$ ✓（两半各自收敛后再相加——**拆在先**）。

**A4** 判断：(1) "发散"就一定是 $+\infty$ 吗？(2) 内部瑕点可以不拆直接代值吗？(3) $\int_{-1}^1x^{-3}dx=0$ 吗？(4) 收敛的反常积分可以参与四则运算吗？

**参考答案**：
(1) **不是**（还有振荡型：$\int_1^\infty\sin x$）。
(2) **不行**（必拆；不拆的"代值"会给出像 0 这种假答案）。
(3) **不是**（$\int_{-1}^1x^{-3}$ 内部瑕点 0 ⇒ 拆后发散——"奇抵消"不成立）。
(4) **可以**（是数；但先确认收敛）。

### B. 提高（推导与判别实战）

**B1** 完整推导 $\int_1^\infty\frac{dx}{x^p}$ 的收敛条件（$p\ne1$ 与 $p=1$ 分列）。

**参考答案**：
$p\ne1$：$\int_1^b=x^{1-p}/(1-p)\big|_1^b=\frac{b^{1-p}-1}{1-p}$——仅剩 $b^{1-p}$：$p>1$ 时 $\to0$（收敛 $=\frac1{p-1}$）；$p<1$ 时 $\to\infty$（发散）。
$p=1$：$\ln b\to\infty$（发散）。$\blacksquare$

**B2** 用换元 $x=\frac1t$ 证明两表镜像（写出 $p\leftrightarrow2-p$ 的完整链条）。

**参考答案**：
$x=\frac1t$：$dx=-\frac{dt}{t^2}$；限 $1\to\infty$ 变 $1\to0$：

$$\int_1^\infty\frac{dx}{x^p}=\int_1^0t^p\left(-\frac{dt}{t^2}\right)=\int_0^1\frac{dt}{t^{2-p}}.$$

⇒ 左表在指数 $p$ 的收敛条件（$p>1$）⇔ 右表在指数 $2-p$ 的收敛条件（$2-p<1$）——**同一条件** ✓。$\blacksquare$

**B3** 比较判别法：(1) $\int_1^\infty\frac{dx}{x\sqrt{x+1}}$；(2) $\int_2^\infty\frac{dx}{\ln x}$；(3) $\int_0^1\ln x\,dx$（先判收敛、再算出值）。

**参考答案**：
(1) $\frac1{x\sqrt{x+1}}\le\frac1{x^{3/2}}$（$x\ge1$ 时 $\sqrt{x+1}\ge\sqrt x$）⇒ 比 $p=\frac32>1$ 小 ⇒ **收敛**。
(2) $x>e$ 时 $\ln x<x$ ⇒ $\frac1{\ln x}>\frac1x$——**小的（$1/x$）散 ⇒ 大的也散** ⇒ **发散**。
(3) 瑕点 $x=0$（$\ln x\to-\infty$）：$\int_\varepsilon^1\ln x\,dx=(x\ln x-x)\big|_\varepsilon^1=-1-\varepsilon\ln\varepsilon+\varepsilon\to-1$（$\varepsilon\ln\varepsilon\to0$——05 讲的极限）⇒ **收敛，值 $=-1$**。

### C. 综合（难题档，允许卡）

**C1** 双反常叠加：$\displaystyle\int_1^\infty\frac{dx}{x\ln^2x}$ 与 $\displaystyle\int_2^\infty\frac{dx}{x\ln^2x}$——**判两个**，并解释为什么第一个还有额外的问题。

**参考答案**：
换元 $u=\ln x$（$du=\frac{dx}x$）：
$\int_2^\infty=\int_{\ln2}^\infty\frac{du}{u^2}$（$p=2>1$，收敛 $=\frac1{\ln2}$）；
$\int_1^\infty=\int_0^\infty\frac{du}{u^2}$——**下端点 $u=0$ 是新瑕点**（$1/u^2$ 在 0 爆炸、$p=2\ge1$ 发散）⇒ **整体发散**（回看原式：$x=1$ 处 $\ln x=0$、被积函数爆炸——**区间起点恰好站在爆点上**）。$\blacksquare$
（**教训**：换元后"新的限"要重新过一遍瑕点检查——4.3 边界 ② 的实例。）

**C2** 判别+数值增长：(1) 判定 $\int_0^1\frac{dx}{1-x^2}$ 的收敛性（提主项）；(2) 若无发散隐患，算出 $\int_0^{1/2}$ 部分的值（$=\frac12\ln3$——复核：$\int\frac{dx}{1-x^2}=\frac12\ln\left|\frac{1+x}{1-x}\right|$，代 $\frac12$：$\frac12\ln3$ ✓）并说明"整体发散在 $x\to1^-$ 处"。

**参考答案**：
(1) $x\to1^-$：$1-x^2=(1-x)(1+x)\sim2(1-x)$ ⇒ 被积 $\sim\frac1{2(1-x)}$——**$p=1$ 型**（发散）。
(2) $\int_0^{1/2}=\frac12\ln3\approx0.549$（有限）；但 $\int_{1-\varepsilon}^1$ 段 $\sim\frac12\ln\frac1\varepsilon\to\infty$ ⇒ **整体发散**。$\blacksquare$

### D. 代码（可跑验证）

**D1** 复刻并扩展实验 1、3：(a) $p$ 剖面表（$p=1.5,1,0.5$；$b=10,100,1000$；断言 $p=1.5$ 列随 $b$ 增趋 2（$|S-2|<0.05$ 对 $b\ge1000$）而 $p=0.5$ 列递增无界（$b$ 越大值越大且 $>10$ 对 $b=1000$））；(b) 振荡对照（$b=50,100,200$：$\sin$ 列摆动（相邻差 $>0.5$ 至少一处）vs $\sin x/x$ 列趋 $\approx0.625$（$|S-0.625|<0.05$））。

**参考答案**：

```python
import numpy as np

def simpson(f, a, b, n=None):
    if n is None:
        n = max(2000, int(100 * (b - a)))   # 采样密度账: 大区间按密度分段
        if n % 2 == 1:
            n += 1
    x = np.linspace(a, b, n + 1)
    y = f(x)
    h = (b - a) / n
    return h / 3 * (y[0] + y[-1] + 4 * np.sum(y[1:-1:2]) + 2 * np.sum(y[2:-1:2]))

print("(a) p-profile of int_1^b x^{-p} dx")
for p in [1.5, 1.0, 0.5]:
    row = []
    for b in [10, 100, 1000]:
        row.append(simpson(lambda x: x ** (-p), 1, b))
    print(f"  p = {p}: " + ", ".join(f"b={b}: {v:.4f}" for b, v in zip([10, 100, 1000], row)))
S15 = simpson(lambda x: x ** (-1.5), 1, 1000)
S05 = simpson(lambda x: x ** (-0.5), 1, 1000)
assert abs(S15 - 2) < 0.1 and S05 > 10   # b=1000 时尾部 2/sqrt(1000)≈0.063, 阈值按此取 0.1

print("(b) oscillation: sin x vs sin x / x")
vals_sin, vals_sinc = [], []
for b in [50, 100, 200, 500]:
    vals_sin.append(simpson(np.sin, 1, b))
    vals_sinc.append(simpson(lambda x: np.sin(x) / x, 1, b))
print(f"  sin: {[f'{v:.4f}' for v in vals_sin]}")
print(f"  sin/x: {[f'{v:.4f}' for v in vals_sinc]}")
assert max(abs(vals_sin[i + 1] - vals_sin[i]) for i in range(len(vals_sin) - 1)) > 0.5
assert abs(vals_sinc[-1] - 0.625) < 0.05
print("[OK] p 剖面与振荡对照全部核实")
```
