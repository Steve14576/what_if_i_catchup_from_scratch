# 高等数学 I（上）——一元微积分 · 从地基到武器 · 导览

> 这是一套面向**大一新生**的高等数学（上）教程。但它不是"从零开始"的那种——它专门为你这种读者写的：**提前看过一点微积分、会算不少东西、但地基是晃的**。目标只有一个：学完你能单纯凭借这套讲义，扛住一份正经的期末 / 考研水准高数（上）试卷，并且**每一步都写得出严格依据**。

## 这门课是什么

高等数学（上）= 一元微积分：极限、连续、导数、微分、中值定理、泰勒、积分，以及它们的应用。它的全部内容，可以压成一句话：

> **先把"无限逼近"说死（极限），再用它定义"瞬时变化"（导数），再把局部信息拼成全局定理（中值定理与泰勒），最后把求导整个反过来（积分），收尾于"用积分量世界"（应用）。**

这套讲义的做法，和你在别处见过的"速成"或"公式手册"都不一样：

- **不掠过你已经会的东西，但也不放过你没学扎实的**。你说得出"反向求导约等于求积分"，那本课程会带着你把这句话背后的整条逻辑链（连续 ⇒ 变限积分可导 ⇒ 原函数存在 ⇒ 牛顿-莱布尼茨公式）亲手证明一遍——口诀变成定理，才算武器。
- **每个定理给完整证明 + 条件反例**。你在高中"了解"过三大中值定理、课余也自己"证明"过中值定理和巴普斯定理——很好，那你知道证明里最容易被自己糊弄过去的是哪一步吗？本课程会把每一步摊开，把"画图看出"和"证明"之间的那条线划清楚：**图像用来启发，定义和定理用来证明**。这条线，就是"考试会慌乱"和"写题有底气"的区别。
- **每个抽象概念配三样**：严格定义 + 直觉图像（明说它只是启发）+ 能跑的数值实验（numpy，具体数字，可复跑）。
- **作业按基础 / 提高 / 综合三档配足**，全部带参考答案与验算方法——包括你听过但没打穿的难题类型（极值点偏移、构造辅助函数、巴普斯反求形心）。

## 这门课为谁写（对号入座）

假想读者长这样（对上几条算几条，全中也正常）：

- 高中提前看过微积分，会求导、会算简单面积，学得**半斤八两**；
- ε-δ、ε-N 这些**严格定义基本没有甚至倒退**，看到"任意给定 ε>0 存在 N"就头晕；
- 知道的"积分"约等于"反向求导"；
- 听说过**极值点偏移**、**三大中值定理**，但记乱了，只会叙述、不会证明、更不会用；
- 课余自己"证明"过中值定理、**旋转巴普斯定理**，自我陶醉过，但知道不太严谨；
- 很想学好，但**容易过度思考**：定义读三遍、越读越玄，一个问题能想出十个岔路。

这套讲义按这个画像逐讲设防：每条上面这些旧直觉，在对应讲次都有"就地拆弹"的段落，正面告诉你哪里对、哪里错、错在哪一步。

## 每讲怎么用（固定循环）

1. 开头看**本讲目标**和**脉络图**，知道这讲带你做出什么、途经哪几站。
2. 先做**开场任务**（通常是几道"你以为你会"的判断或计算题）——允许翻车，翻车是这讲存在的理由。
3. 概念按**严格定义 → 直觉图像 → 手算例题 → 数值实验**的顺序走。注意每个概念标注的**理解深度**（见下方三档），别把该建直觉的东西死磕成背诵，也别把该会证明的东西糊弄成"显然"。
4. 数值实验每个数字都能在 `scripts/` 找到脚本复跑。
5. 结尾**掌握度自测**全打勾 → 做**作业**（基础/提高/综合三档）→ 参考答案在每题下方平铺（先独立做再对照，不是抄）。

## 特别给"容易过度思考的你"：三档深度与卡住协议

你最大的敌人不是难，是**在错的地方死磕**。这门课每个概念都标了三档，请照着分配精力：

- **要能推导 / 手算**：核心武器（ε-δ 证明、中值定理、泰勒、积分技术）。这些题要亲手写，写到不看书。
- **要知道有这回事 + 什么时候找它**：边界知识（魏尔斯特拉斯函数、可积性完整理论、一致连续深论）。看到名字知道是什么、去哪讲查——足够，别陷进去。
- **要建立直觉**：辅助理解（图像、物理意义、几何解释）。它们是路标不是证明，理解到"能预判答案"即可。

**卡住协议**（重要）：一个定义读三遍读不懂时——

1. 先去做这一节的**具体例题**或**数值实验**（数字比符号友好）；
2. 还卡，就**标记后跳小节**，很多"卡点"在下一节的应用里会突然自己解开；
3. 还卡，把问题记下来去问（或沉淀到 `QnAnExperience.md`，那是你自己的追问卡片，不是讲义的一部分）。
4. 禁止做的事：对着一句话空想 30 分钟以上。数学是读+算+写的循环，不是冥想。第一次读不懂 ε 语言是**正常的**——严格极限语言数学家自己打磨了两百年才写对，你给自己两小时，不亏。

另：**你的旧直觉不会被否定，会被收编**。会求导是资产，图象直觉是资产，"听说过中值定理"也是资产——本课程做的是给它们补地基、划边界，不是推倒重来。
