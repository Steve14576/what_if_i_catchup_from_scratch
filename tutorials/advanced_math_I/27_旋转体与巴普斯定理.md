## 一、开场：三道"旧账"题

**题 1**：你高中"自己证过"的巴普斯——**把当年的推理复述一遍**（提示：大概是"把区域分成小片，每片扫出的体积 ≈ 片面积 × 片绕轴的路程；把所有片平均一下，就是面积 × 平均路程"）。**哪一步经不起追问**？

**题 2**：定理里的 $\bar\rho$ 是"**平均距离**"还是"**形心的距离**"？——这两个"平均"是一回事吗？

**题 3**：实心圆盘绕着**自己的一条直径**旋转（轴穿过区域！）：巴普斯公式给出 $V=2\pi\bar\rho A$，而圆盘的形心就在轴上（$\bar\rho=0$）——**公式给 0**。它"错出"多少？

**答案预告**：

1. "切开、扫出、平均"的**方向全对**——缺的一步是：**"平均路程"里的"平均"必须说清是哪种平均**——一旦说清（**按面积加权**），会发现它**正是形心的定义**——于是合法；而且"每片扫出 ≈ 片面积 × 片路程"这个近似还需要元素法的合法性账（局部误差 $o$——26 讲判据）。第三节把两件事都补齐。
2. **一回事——但只有把"平均"定义成"面积加权平均"之后**。算术平均（$\frac{\rho_1+\rho_2}2$ 式）会给出**错的** $\bar\rho$；面积加权平均 = 一阶矩/面积 = 形心距离（第二节把定义立正）。
3. **从 0 错到 $\frac{4\pi}3$**（$R=1$）：圆盘绕直径"扫出"的图形是球（体积 $\frac43\pi R^3$），而公式给 0——**并且注意**：这次连"差多少"都说不清——因为轴的左右两半**扫的是同一块空间**（重数 2）：**"面积 × 路程"的记账前提（每片面积被数一次）被破坏了**（第四节详解）。

## 二、形心：定义与两类求法

### 2.1 定义（一阶矩 / 面积）

**物理直觉先行**：均匀薄片的"平衡点"——但数学定义直接立账：

> **定义（平面区域 $\Omega$ 的形心）**：设 $\Omega$ 面积为 $A>0$，
> $$\bar x=\frac{1}{A}\iint_\Omega x\,dA,\qquad \bar y=\frac{1}{A}\iint_\Omega y\,dA,$$
> 即**一阶矩除以面积**。曲线弧 $\gamma$（弧长 $L$）的形心同款：$\bar x=\frac1L\int_\gamma x\,ds$、$\bar y=\frac1L\int_\gamma y\,ds$（一阶矩定义为"**弧长加权**"）。

**读法**："形心 = **按面积（或弧长）加权的平均位置**"——这就是开场题 2 的答案：**"平均"这个词必须配一个权重**，权重的选择（面积/弧长）由对象决定；"算术平均"是错的平均。

**对称性的白拿结论**：$\\Omega$ 有对称轴 ⇒ **形心在对称轴上**（积分里正负配对抵消——24 讲对称思想）；**两条对称轴 ⇒ 形心在交点**（例：圆盘形心=圆心、正方形=中心——**白拿**）。

### 2.2 求法一：直接积分（元素法再出场）

区域为 $g(x)\le y\le f(x)$（$f,g$ 连续）：**竖条微元**（宽 $dx$、高 $f-g$）——**微元自己也有形心**（条的中心 $y=\frac{f+g}2$）：

$$dA=(f-g)dx,\qquad y\,dA=\frac{f+g}2(f-g)dx=\frac12\big(f^2-g^2\big)dx$$

⇒（对 $x$ 积分、除以 $A$）：

$$\bar y=\frac{1}{A}\int_a^b\frac{f^2-g^2}2\,dx;\qquad \bar x=\frac1A\int_a^b x\,(f-g)\,dx.$$

**经典全程（上半圆盘的形心）**：$\Omega=\{x^2+y^2\le R^2,\ y\ge0\}$：$A=\frac{\pi R^2}2$；$f=\sqrt{R^2-x^2}$、$g=0$：

$$\bar y=\frac{1}{A}\int_{-R}^{R}\frac{R^2-x^2}2dx=\frac{2}{\pi R^2}\cdot\frac12\cdot\frac{4R^3}3=\frac{4R}{3\pi}\approx0.4244R\ \checkmark$$

（**$\bar x=0$ 白拿**（对称）；用到的 $\int_{-R}^R(R^2-x^2)dx=\frac{4R^3}3$ 与 $A$——旧账。）

### 2.3 求法二：巴普斯**反求**（预告）

**思路**：某些旋转体的体积是"现成的"（球、环面……）⇒ 巴普斯式 $V=2\pi\bar\rho A$ **反解** $\bar\rho$——详细题型第四节；先给一个预览：由球体积 $\frac43\pi R^3=2\pi\bar x\cdot\frac{\pi R^2}2$ ⇒ $\bar x=\frac{4R}{3\pi}$ ✓（**与直接积分同数**——两条路互证）。

## 三、巴普斯定理：三行证明与旧证明开庭

### 3.1 证明（壳层法 + 一阶矩桥）

> **定理（巴普斯，体积版）**：平面区域 $\Omega$（面积 $A$）绕**与 $\Omega$ 内部不相交**的直线 $l$ 旋转一周，所得旋转体体积
> $$V=2\pi\bar\rho\,A,$$
> 其中 $\bar\rho$ 是 $\Omega$ 的形心到 $l$ 的距离。

**证明（三行）**：取 $l$ 为 $y$ 轴方向、$\Omega$ 在 $x>0$ 一侧（坐标可平移旋转到此形态，**"内部不相交"保证了 $\rho=x>0$ 恒成立**）：

**第 1 行（壳层公式——26 讲简介层升主角）**：竖条微元（宽 $dx$、高 $h(x)$）绕轴扫出**薄壁圆管**（周长 $2\pi x$、高 $h$、厚 $dx$）：$\Delta V\approx 2\pi x\,h(x)\,dx$——**局部误差 $o(dx)$（26 讲判据——薄管的"壁厚方向弯曲"是二阶账）** ⇒

$$V=2\pi\int_a^bx\,h(x)\,dx.$$

**第 2 行（一阶矩桥）**：$\int_a^bx\,h(x)dx=\int x\,dA=\bar x\,A$（**形心定义**——第二行什么计算都没做，只是"认出"它是形心）。

**第 3 行（合并）**：$V=2\pi\bar x\,A=2\pi\bar\rho\,A$ ✓ $\blacksquare$。

**读证明**：**巴普斯的全部内容 = "壳层公式里那个 $x$ 的积分，恰好是形心的分子"**——定理**不是新知识**，是"壳层法 + 形心定义"的**恒等改写**。

### 3.2 旧证明开庭（疑问 1——当年的推理，开庭）

**你当年的版本**（三个动作）：①"切开"——把区域分成小片 ✓；②"扫出"——每片扫出的体积 ≈ 片面积 × 片路程 ——**这一步其实对了**（微元级：正是"薄管"的账）；③"平均"——全部加起来 ≈ 总面积 × **平均路程**——**这一步是本讲的主角**（"平均"二字的合法性）。

**逐点验尸**：

| 步骤 | 判断 | 缺什么 |
|---|---|---|
| ①切开 | **对** | —— |
| ②每片 ≈ 片面积 × **片自身形心的**路程 | **对**（微元级巴普斯——这正是"薄管体积 $=2\pi x\,h\,dx$"）| 严格化：元素法合法性（$o(dx)$） |
| ③"平均"换成"**按面积加权平均**" | **关键一步** | 你没说"按面积加权"——而**加权平均位置 = 形心**（第二节定义）|

**追加开庭（为什么"按面积加权"必须点明）**：把"平均路程"换成**算术平均** $\frac{\rho_{\min}+\rho_{\max}}2$——反例立得：区域 $\Omega=\{(x,y):1\le x\le2,\ 0\le y\le x\}$（三角形：面积 $A=\frac32$；竖条微元高 $h=x$）：

- **面积加权**（形心）：$\bar x=\frac1A\int_1^2x\cdot x\,dx=\frac23\cdot\frac73=\frac{14}9\approx1.556$；
- **算术平均**（$\rho$ 取值范围 $[1,2]$）：$=1.5$——**不同**！

两个"平均"给出两个体积：加权式 $2\pi\cdot\frac{14}9\cdot\frac32=\frac{14\pi}3$、算术式 $2\pi\cdot\frac32\cdot\frac32=\frac92\pi$——**差** $\frac{14\pi}3-\frac92\pi=\frac{\pi}6\approx0.524$。

**结论**："平均"必须是**面积加权**；不点明权重，"平均"就是错的口袋。

## 四、失效条件、侧面积版与反求形心

### 4.1 失效条件（疑问 3——"为什么"与"差多少"）

**条件回顾**：轴与**区域内部**不相交（**沿边界、在区域外——都行**；穿过内部——不行）。

**"差多少"的完整判决（圆盘例）**：圆盘 $x^2+y^2\le R^2$ 绕其**直径**（$y$ 轴）：形心在轴上 ⇒ $\bar\rho=0$ ⇒ **巴普斯给 $V=0$**。

- **"实际图形"**：圆盘绕 $y$ 轴扫出的点集**是球**（水平截面的"直径段"旋转成"圆盘截面"——实验 4 的账）：$V_{\text{球}}=\frac{4\pi R^3}3$——**与公式的 0 差 $\frac{4\pi R^3}3$**。
- **失效的机理**（比"差多少"更重要）：轴上方的账**被重复数了**——圆盘上 $x$ 与 $-x$ 两处扫出**同一块空间**：**重数处处为 2**（轴割的除外）——"面积×路程"的记账前提（**每份面积恰扫过一遍**）被破坏。所以：**这不是"公式算得不准"的问题，而是"这个问题不在公式的管辖范围内"**——两句话分开：**公式由于"距离的正负抵消"给了 0；而"扫出体积"的账本身也重了**（若按重数 2 记账得 $\frac{8\pi R^3}3$——**也不是球**）。
- **边界情形对照（白拿验证）**：半圆盘（$x\ge0$）绕 $y$ 轴：轴沿边界、不穿内部 ⇒ **可用**：$V=2\pi\cdot\bar x\cdot A=2\pi\cdot\frac{4R}{3\pi}\cdot\frac{\pi R^2}2=\frac{4\pi R^3}3$ ✓——**球体积**（左半盘扫出的图形；没有重数问题——每份面积恰扫一遍）。**"边界可以、内部不行"由此坐实。**

### 4.2 侧面积版（疑问 4——两条定理、两只形心）

> **定理（巴普斯，侧面积版）**：平面曲线弧 $\gamma$（弧长 $L$）绕与它不相交的直线旋转一周，扫出的曲面面积
> $$S=2\pi\bar\rho_c\,L,$$
> 其中 $\bar\rho_c$ 是**曲线弧的形心**（弧长加权）到轴的距离。

**证明（一行——与体积版同一台引擎）**：弧微元 $ds$ 扫出细环带：$\Delta S\approx2\pi\rho\,ds$（误差 $o(ds)$）⇒ $S=2\pi\int\rho\,ds=2\pi\bar\rho_c\,L$ ✓ $\blacksquare$。

**两版分工表**：

| | 旋转的对象 | 形心是"谁的" | 微元 |
|---|---|---|---|
| 体积版 | **区域**（面积 $A$） | 区域形心（面积加权） | 薄管（$2\pi x h\,dx$） |
| 侧面积版 | **曲线**（弧长 $L$） | 曲线形心（弧长加权） | 细环带（$2\pi\rho\,ds$） |

**球表面积全程（侧面积版的王牌演示）**：半径 $R$ 的**上半圆弧**绕 $x$ 轴扫出球面：$L=\pi R$；弧形心 $\bar y_c$（下半节的直接积分：$\bar y_c=\frac1L\int y\,ds=\frac1{\pi R}\int_0^\pi R\sin\theta\cdot R\,d\theta=\frac{R^2\cdot2}{\pi R}=\frac{2R}\pi$）⇒

$$S=\pi R\cdot2\pi\cdot\frac{2R}\pi=4\pi R^2\ \checkmark$$

（**球面积公式的巴普斯证明**——与"球面直接积分"另一路对照见实验 3。）

### 4.3 反求形心（疑问 5——题型）

**题型识别**：旋转体的体积**已知**（球的、环面的、或用盘/环法已算出）＋区域面积易求 ⇒ **反解 $\bar\rho=V/(2\pi A)$**。

**标准例（环面）**：半径 $r$ 的圆盘、圆心离轴 $R$（$R>r$、不交）绕轴 ⇒ 旋转体叫**环面**（"甜甜圈"）：

$$V=2\pi R\cdot\pi r^2=2\pi^2Rr^2\ \checkmark（形心距离=R——白拿，圆盘形心在圆心）$$

——**这题的"正用"是算环面体积**；**"反用"的示范**：已知环面体积 $2\pi^2Rr^2$、区域（圆盘）面积 $\pi r^2$ ⇒ $\bar\rho=\frac{2\pi^2Rr^2}{2\pi\cdot\pi r^2}=R$ ✓——**固然白拿，但流程正确**；**真正要动手的反用例**：由**球体积**反求**半圆盘形心**（第二节 2.3）、由**球面积**反求**半圆弧形心**（$\bar y_c=\frac{4\pi R^2}{2\pi\cdot\pi R}=\frac{2R}\pi$ ✓）——**反用题型 = "用已知旋转体公式 + 面积/弧长，反解未知形心"**。

## 五、数值实验：四连验证

**方法**：数值积分（Simpson，含采样密度账 $n\approx100(b-a)$）；"双路对照"（巴普斯 vs 直接积分）。

完整脚本在 `scripts/lec27-01_verify_pappus.py`（运行：`uv run --with numpy python scripts/lec27-01_verify_pappus.py`）。

### 实验 1：环面双路（$R=3$、$r=1$）

(i) 巴普斯：$V=2\pi^2Rr^2$；(ii) 直接壳层积分：$2\pi\int_2^4x\cdot2\sqrt{1-(x-3)^2}\,dx$（**区间=圆心 $3\pm$ 半径 $1$**；壳层法直接算）——对照两者。

（实测，全脚本 0.01 秒跑完，可复跑）：

```
  巴普斯 = 59.2176264065, 壳层 = 59.2176261328, 相对差 = 4.62e-09
```

**结论（实测坐实）**：两路一致到 $4.6\times10^{-9}$（**注**：被积函数在半圆端点有垂直切线（导数无界），Simpson 收敛变慢：常规 $n$ 下残差 $4.6\times10^{-6}$，加密到 $n=2\times10^5$ 后降到 $4.6\times10^{-9}$——"端点奇性"的采样账）——环面的双路互证。

### 实验 2：半圆盘形心双路（$R=1$）

(i) 直接积分 $\bar y=\frac{4R}{3\pi}$；(ii) 巴普斯反求（由球体积 $\frac{4\pi}3=2\pi\bar y\cdot\frac\pi2$）——**两条路**。

（实测）：

```
  直接积分 = 0.4244131816, 巴普斯反求 = 0.4244131816, 差 = -5.55e-17
```

**结论（实测坐实）**：两路同得 $0.42441318\ldots$（差浮点级）——互证。

### 实验 3：球面积双路（$R=1$）

(i) 侧面积版巴普斯：$\pi\cdot2\pi\cdot\frac2\pi=4\pi$；(ii) 球面直接积分：$2\pi\int_{-1}^{1}\sqrt{1-x^2}\cdot\frac{1}{\sqrt{1-x^2}}dx=2\pi\int_{-1}^1 1\,dx=4\pi$（**解析；先在纸上化简为常值 1**）——数值对账。

（实测）：

```
  侧面积版 = 12.5663706144, 直接积分 = 12.5663706144, 相对差 = 0.00e+00
```

**结论（实测坐实）**：$4\pi\approx12.5664$ 两路差恰 $0$——侧面积版的王牌（**对账要点：被积函数在数值计算前必须先化简为常值 $1$**——直接代入未化简式在端点 $0/0$ 会出 NaN）。

### 实验 4：失效三数（圆盘绕直径，$R=1$）

打印：巴普斯值（$\bar\rho=0$ ⇒ $0$）、旋转点集的"单层体积"（球 $=\frac{4\pi}3$）、"重数 2 的账"（$\frac{8\pi}3$）。

（实测）：


- **形心**（一阶矩/面积；曲线版=弧长加权）——**"平均"必须配权重**；对称性白拿。
- **求法**：直接积分（竖条微元+条自身形心）与**巴普斯反求**（由现成体积反解）。
- **巴普斯体积版三行证明**：**壳层公式**（$V=2\pi\int xh\,dx$——26 讲简介升主角）**+ 一阶矩桥**（$\int x\,dA=\bar xA$）$=2\pi\bar\rho A$——**定理是恒等改写，不是新知识**。
- **旧证明开庭**：切/扫方向全对；缺"**按面积加权**"四个字（不加说清，"平均"就是错的口袋——三角形反例：加权 $1.556$ vs 算术 $1.5$）。

- **反求形心**：环面 $2\pi^2Rr^2$ 正反两用；判别动作=找"现成体积"。

### B. 提高（证明与构造）

**B1** 复写巴普斯体积版的三行证明，并给"旧证明体检表"（三步各自的判断与缺口）。

### C. 综合（难题档，允许卡）

### D. 代码（可跑验证）

**D1** 复刻并扩展实验 1、3：(a) 环面双路（$R=3,r=1$：巴普斯 $6\pi^2$ vs 壳层数值积分，断言 $<10^{-8}$ 相对）；(b) 球面积双路（侧面积版 $4\pi$ vs 球面直接积分数值 $2\pi\int_{-1}^{1}\frac{\sqrt{1-x^2}}{\sqrt{1-x^2}}dx$——**注意被积函数化简为常值 1 的对账要点**，断言 $<10^{-8}$）。

**参考答案**：

```python
import numpy as np

def simpson(f, a, b, n=None):
    if n is None:
        n = max(2000, int(100 * (b - a)))
        if n % 2 == 1:
            n += 1
    x = np.linspace(a, b, n + 1)
    y = f(x)
    h = (b - a) / n
    return h / 3 * (y[0] + y[-1] + 4 * np.sum(y[1:-1:2]) + 2 * np.sum(y[2:-1:2]))

print("(a) torus: Pappus vs shell integral (R=3, r=1)")
pappus = 2 * np.pi ** 2 * 3 * 1
shell = 2 * np.pi * simpson(lambda x: x * 2 * np.sqrt(1 - (x - 3) ** 2), 2, 4, n=200000)   # 端点奇性: 加密
print(f"  巴普斯 = {pappus:.10f}, 壳层 = {shell:.10f}, 相对差 = {abs(shell - pappus) / pappus:.2e}")
assert abs(shell - pappus) / pappus < 1e-8

print("(b) sphere area: Pappus(侧面积版) vs direct integral (R=1)")
pappus_s = np.pi * 1 * 2 * np.pi * (2 / np.pi)
direct = 2 * np.pi * simpson(lambda x: 1.0 + 0.0 * x, -1, 1)   # 先化简成常值 1
print(f"  巴普斯 = {pappus_s:.10f}, 直接积分 = {direct:.10f}, 相对差 = {abs(direct - pappus_s) / pappus_s:.2e}")
assert abs(direct - pappus_s) / pappus_s < 1e-8
print("[OK] 环面与球面积的双路对照全部核实")
```
