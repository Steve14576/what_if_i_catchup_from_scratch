## 一、开场：三场吵不出结果的争论

别跳过。这三场架，每一场都埋着本讲要拆的雷——而且按你的画像，你**亲自吵过其中至少一场**。

**争论 1**：$\dfrac1n,\dfrac1{2},\dfrac1{3},\ldots$ "越来越接近 $0$"——这话没毛病。可是它不也"越来越接近 $-1$"吗？你看：它与 $-1$ 的距离是 $1+\dfrac1n$，确实**一直在变小**。那么它到底收敛到 $0$ 还是 $-1$？还是都收敛？"越来越接近"这句话，是不是本身就没说清东西？

**争论 2**：数列
$$1,\ 0,\ \tfrac12,\ 0,\ \tfrac13,\ 0,\ \tfrac14,\ 0,\ \ldots$$
（奇数项是 $1,\tfrac12,\tfrac13,\ldots$，偶数项全是 $0$）——它"一摆一停"，前段还在 $0$ 和 $1$ 之间晃来晃去。直觉上，"收敛"应该意味着**安稳下来、不再晃**吧？这玩意儿晃个不停，收敛吗？

**争论 3**：$0.999\ldots = 1$ 吗？正方说"你看 $1/3 = 0.333\ldots$，两边乘 $3$"；反方说"不对，永远差着 $0.000\ldots1$"。你在高中参与过这场争论，谁也没说服谁——因为它吵的根本不是计算，是"无限小数到底是什么意思"这个**定义问题**。

先把结论预告了（细节全部在后面各节展开）：

1. **"越来越接近 $X$"不是收敛**。收敛要求的是**距离 $|a_n-X|$ 本身趋于 $0$**——$\tfrac1n$ 到 $0$ 的距离趋于 $0$，到 $-1$ 的距离趋于 $1$，所以极限是 $0$ 不是 $-1$。直觉话的病根：没有把"接近"定量化，谁都能来碰瓷（→ 第三节）。
2. **收敛**。摆动不碍事——定义只管"$n$ 充分大之后，距离小于任意给定的 $\varepsilon$"，**不管你是怎么晃过来的**。"收敛 = 安稳地靠近"里的"安稳"，是你脑补的（→ 第四节、第五节例 3）。
3. **等于 $1$**。反方的"$0.000\ldots1$"根本不是一个数——小数点后"无限个 $0$ 之后再有一个 $1$"，"无限个之后"没有那个位置。$0.999\ldots$ 的真实含义是"部分和数列 $0.9,0.99,0.999,\ldots$ 的极限"，而这个极限恰好是 $1$——第六节用你今天要学的 $\varepsilon$-$N$ 当场证给你看。

> 下一站：三场架的病根是同一个——都拿**过程直觉**当**数学定义**用。拆之前，先把"数列"这个对象本身说清楚。

## 二、数列：先把对象说清

> **定义（数列）**：一个**数列**就是定义在正整数集 $\{1,2,3,\ldots\}$ 上的函数 $a_n=f(n)$，按 $n=1,2,3,\ldots$ 的次序把函数值排成一列，记作 $\{a_n\}$，第 $n$ 项 $a_n$ 叫**通项**。

用第 01 讲的机器模型一句话收编：**数列 = 一台只在整数刻度上开工的机器**——输入 $1,2,3,\ldots$，输出 $a_1,a_2,a_3,\ldots$。定义域固定是正整数集（这整讲不用操心定义域问题了），所以一个数列由**通项公式**（或描述规则）唯一确定。$a_n=\tfrac1n$ 是机器说明书，"$1,0,\tfrac12,0,\tfrac13,\ldots$"（奇数项 $1/k$、偶数项 $0$）也是机器说明书——第 01 讲说过的"说明书不一定是公式"，在这里照样成立。

三个马上要用的旧词，从 01 讲原样搬过来：

- **有界**：存在 $M>0$ 使 $|a_n|\le M$ 对一切 $n$ 成立。$(-1)^n$ 有界（$M=1$），$a_n=n$ 无界。
- **单调**：$a_{n+1}>a_n$ 恒成立叫严格增；严格减同理（口径同 01 讲：说"单调增"默认严格增）。
- **记号**：$|a_n-A|$ 读作"第 $n$ 项到数 $A$ 的距离"——本讲从头到尾都在跟它打交道。

（一个小口径：有的书从 $n=0$ 开始编号。$\varepsilon$-$N$ 语言对此完全不敏感——反正"前有限项无关"——本课程统一从 $n=1$ 开始。）

> 下一站：对象清楚了。现在开刀：把"越来越接近"这句直觉话放上解剖台。

## 三、诊断："越来越接近"的三宗罪

为什么要费劲立一个 $\varepsilon$-$N$ 定义？因为直觉版"无限接近"有**三宗罪**，每一宗都对应开场的一場争论。

**罪一：没定量（对应争论 1）。**"接近"没说**差多少**。$\tfrac1n$ 到 $-1$ 的距离 $1+\tfrac1n$ 确实一直在变小——按"越来越接近"的字面意思，$\tfrac1n$"越来越接近" $-1$，一点毛病没有，但它显然不该收敛到 $-1$。病根：**"距离在变小"和"距离趋于零"是两回事**。前者允许距离降到 $1$ 就停（甚至降到任何正数就停），后者要求距离最终小于**任何**正数。直觉话没做这个区分，所以选出两个"极限"——荒谬。修法：把"接近"换成距离 $|a_n-A|$，把"无限"换成"要多小有多小"。

**罪二：过程成见（对应争论 2）。**直觉想象收敛的过程是"安稳地、一步一步靠近"——所以摆动数列直觉上"不像收敛"。但请看事实：那个摆动数列的奇数项 $1,\tfrac12,\tfrac13,\ldots$ 自己趋于 $0$，偶数项恒为 $0$ 也"趋于" $0$——两条腿都在走向 $0$，只是走路姿势难看（一跳一停）。**收敛关心的是"最终待在哪"，不关心"走路姿势"**。给"姿势"翻个四格表：

|  | 单调 | 不单调（摆动） |
|---|---|---|
| **收敛** | $\tfrac1n$（安稳走向 $0$） | $1,0,\tfrac12,0,\tfrac13,\ldots$（跳着走向 $0$） |
| **发散** | $a_n=n$（安稳走向无穷） | $(-1)^n$（原地永久跳） |

**收敛 $\Leftrightarrow$ 单调，四个格子各有住户，谁也不是谁的门票**（第七节会给你完整反例装备）。修法：把"过程"从定义里彻底删掉，只保留"**尾部**"——$n$ 大到某个 $N$ 之后的事。

**罪三：终点幻觉（对应争论 3）。**直觉想象"无限接近"是"无限地写下去，最后一项最接近极限"——但数列**没有最后一项**。$0.999\ldots$ 的"差 $0.000\ldots1$"预设了小数有"最后一位"，而"无限个 $0$ 之后"没有那个位置——这个数根本不存在。极限不是一个"到达了的终点站"，它是**全程走势的一个性质**（第六节展开）。修法：别找终点，看**走势的判据**。

三宗罪修完，需要的语言其实就三块原料：

1. **距离**：$|a_n-A|$（定量，治罪一）；
2. **尾部**：存在 $N$，只管 $n>N$（删过程，治罪二）；
3. **任意精度**：对**一切**正数 $\varepsilon$ 都要成立（不许停在某个精度就收工，治罪三）。

> 下一站：把这三块原料组装起来，就是那个传说中吓人的 $\varepsilon$-$N$。它不是天书，是修好的直觉。

## 四、$\varepsilon$-$N$：正式定义逐句拆（本讲心脏）

### 4.1 定义

> **定义（数列的极限）**：设 $\{a_n\}$ 是一个数列，$A$ 是一个实数。若对**任意给定**的 $\varepsilon>0$，**存在**正整数 $N$，使得当 $n>N$ 时，$|a_n-A|<\varepsilon$ 恒成立，则称数列 $\{a_n\}$ **收敛**于 $A$，记作
> $$\lim_{n\to\infty}a_n=A\quad\text{或}\quad a_n\to A\ (n\to\infty).$$
> 不收敛于任何实数的数列叫**发散**。

$\varepsilon$ 读 "epsilon"（艾普西隆），就是"$\varepsilon$-N"里那位。它不是什么新数学对象，就是一个**正数**——它的全部戏份是"当精度标尺用"。

### 4.2 逐句拆：四个部件

把定义拆成四个部件，每个部件对着第三节的一块原料：

| 部件 | 原文 | 作用 | 治的病 |
|---|---|---|---|
| 靶心 | $A$ | 被逼近的数 | —— |
| 精度 | $\forall\varepsilon>0$ | 距离要多小算合格，**对手**说了算 | 罪一（定量） |
| 尾部 | $\exists N$，$n>N$ | 前面怎么乱写都行，只看**之后全体** | 罪二（删过程） |
| 判据 | $\|a_n-A\|<\varepsilon$ | 尾部每一项到靶心的**距离**都小于精度 | 罪三（走势判据，不是终点） |

**几何直观（启发用，不作证明）**：在数轴上以 $A$ 为中心画一条宽 $2\varepsilon$ 的带子 $(A-\varepsilon,\ A+\varepsilon)$。收敛的意思是：**不管带子多窄，从某一项开始，后面所有项全部躺进带子里**。带子缩，尾巴照样全进——这就是"要多近有多近"。

### 4.3 对抗游戏：这定义该怎么"玩"

**心智模型（本讲第一件要焊进直觉的东西）**：$\varepsilon$-$N$ 是一场**挑战-接招**游戏——

- **对手出题**（$\forall\varepsilon>0$）：对手随便挑一个正数 $\varepsilon$，越小越刁钻，**不许还价**（"任意"的全部含义就是剥夺你的定价权）；
- **你接招**（$\exists N$）：你报一个分界线 $N$，承诺"$N$ 之后每一项到 $A$ 的距离都小于 $\varepsilon$"；
- **判定**：$N$ 之后只要**有一项**漏出带子，你就输了这一轮；接住了，这一轮过。
- **收敛** $=$ **每一轮都接得住**（对手可以无限轮地刁难下去，你轮轮都得有解）；
- **发散** $=$ **存在一轮你永远接不住**——形式化写出来（发散的否定式，第八节实验 2 直接用它）：
  $$\exists\,\varepsilon_0>0,\ \forall N,\ \exists\,n>N:\ |a_n-A|\ge\varepsilon_0.$$
  读作："有一个死缠烂打的 $\varepsilon_0$，你换任何 $N$，它都能在你承诺的尾部里找到一根漏网之鱼。"（发散到任何数都接不住，就是数列不收敛于任何 $A$。）

注意一个方向：**你不是要算出"$N$ 的公式"**——你只需要**存在**一个够大的 $N$（见 4.5）。这场游戏你手里有两件不对称武器：对手的 $\varepsilon$ 你不能挑，但你的 $N$ 可以**往大了随便放**。

### 4.4 量词顺序：为什么 $\forall\varepsilon\ \exists N$ 不能换成 $\exists N\ \forall\varepsilon$

把顺序换成"**存在** $N$，对**一切** $\varepsilon>0$，$n>N$ 时 $|a_n-A|<\varepsilon$"——发生了什么？

这句新话要求：同一条分界线 $N$，服侍**所有**精度。也就是 $n>N$ 时，距离 $|a_n-A|$ 要小于**一切正数**——而一个固定的非负数要小于一切正数，只有一种可能：**它等于 $0$**。于是新话的真实含义是：**$n>N$ 时 $a_n\equiv A$，尾部是常数列**。

这就是量词顺序的分量：

- $\forall\varepsilon\ \exists N$（原版）：**先挑战、后接招**——$N$ 可以看着 $\varepsilon$ 出，$\varepsilon$ 越小我 $N$ 越往后退，**退着退着就把精度守住了**。这是"逼近"。
- $\exists N\ \forall\varepsilon$（交换版）：**一条万能线服侍一切精度**——只有"尾部干脆不动了"（常数列）才做得到。这是"到达"。

**所以"$\forall$ 在前 $\exists$ 在后"不是绕口令的排列习惯，它编码的正是"逼近而非到达"**。考试考量词顺序（判断题/叙述题），不是考背诵，是考你知不知道这两个词**换位置就换了宇宙**。

（顺带：数列里"逼近"和"到达"真的可以同时发生——常数列 $a_n\equiv c$ 收敛于 $c$，两种量词顺序都满足。但"极限等于 $A$"**从不要求** $a_n$ 等于过 $A$：$\tfrac1n\to0$，而 $\tfrac1n$ 永远不等于 $0$。第八节实验 3 的浮点彩蛋会给你看计算机上"提前到达"的假象。）

### 4.5 $N$ 的自由度：四个"不拘小节"

游戏规则里，$N$ 的地位有四条弹性，每条都被初学者当成"我做错了"——不，是定义本来就不管：

1. **$N$ 依赖 $\varepsilon$，但不必给出依赖公式**。$\varepsilon$ 越小，$N$ 通常越大（$1/n$ 那个例子：$\varepsilon$ 缩小十倍，$N$ 大十倍）。但证明里你**只需要**"取一个够大的 $N$"，$N$ 怎么找来的是草稿纸上的事，正式书写里它只要出现、只要够大。
2. **$N$ 不唯一**。你找的 $N=100$ 能接住，那 $N=101$、$N=200$、$N=10^6$ 全都能（尾部条件只会更容易满足）。**你的 $N$ 比书上答案的大，不是错，是赢得更宽裕**。书上的 $N$ 也只是"之一"。
3. **$n>N$ 与 $n\ge N$ 无本质差**。差的那一项（$n=N$ 自己）是有限项，用 $N'=N-1$ 就能来回换算。两种写法都对，本课程统一写 $n>N$。
4. **前有限项与收敛性无关**。把数列前一万项改成乱码，收敛性和极限**纹丝不动**——定义只看"某个 $N$ 之后"的全体，而 $N$ 想多大有多大。这也是为什么"数列有没有前几项乱跳"从来不是讨论收敛时的正经顾虑（争论 2 的第二钉棺材钉）。

### 4.6 证明模板：四步走，一步不跳

用定义证明 $\lim a_n=A$，**永远**是这四步（第五节四道例题全走它）：

```
第 1 步  任给 ε > 0。（对手出题，你不还价）
第 2 步  要使 |a_n − A| < ε，即 ……，解出/放缩出 n > 某个关于 ε 的量。
         （草稿纸上反解；正式书写里这就是"找 N"）
第 3 步  取 N = ⌈该量⌉（向上取整，保证够大；多加 1 更保险）。
第 4 步  则当 n > N 时 |a_n − A| < ε 成立，由定义，lim a_n = A。
```

（收尾符号 $\blacksquare$ 读作"证毕"——本课程所有证明的结束标记，从下一节起正式上岗。）

**坏习惯清单**（判卷老师一眼盯住的四种，全是"游戏规则没吃透"的症状）：

- **自己挑 $\varepsilon$**：写"令 $\varepsilon=0.001$"——$\varepsilon$ 是**对手**出的，你挑一个宽的精度证明不了任何事（那只是一轮游戏，收敛要轮轮都赢）。验证某个具体 $\varepsilon$ 只配叫**抽查**，配当草稿，不配写进正式证明。
- **只验 $n=N$ 一项**：接招的承诺是"$n>N$ **全体**"——验证一根漏不进带子的项不算接招。
- **不等号方向/等号含糊**：$|a_n-A|<\varepsilon$ 写成 $\le\varepsilon$ 不加说明（改严格为不严格时要么说明放缩、要么两边留余量）；$N$ 不是整数（$N$ 是项数，必须是正整数，取整别忘了）。
- **第 2 步跳步**：直接宣布"$N$ 存在"而不给 $|a_n-A|<\varepsilon$ 到"$n>$ 什么"的推导链——阅卷人只认链条，不认你的自信。

> 下一站：定义立完了。进车间——四道例题，同一套模板，手熟为止。

## 五、例题车间：四道题，一套模板

**车间纪律**：每道题先"猜"再"证"。**猜**靠数值代入或直觉（合法！猜错不扣分，不猜才是问题）；**证**只能靠 4.6 的模板。猜完不证，就还是高中模式。

### 例 1（热身）：证明 $\lim_{n\to\infty}\dfrac1n=0$

**猜**：$n=10,100,1000$ 时 $\tfrac1n=0.1,0.01,0.001$——走势明显奔 $0$ 去。

**证**（四步）：
1. 任给 $\varepsilon>0$。
2. 要使 $\left|\dfrac1n-0\right|=\dfrac1n<\varepsilon$，只需 $n>\dfrac1\varepsilon$。
3. 取 $N=\left\lceil\dfrac1\varepsilon\right\rceil$（向上取整，保证 $N\ge\dfrac1\varepsilon$）。
4. 当 $n>N$ 时，$n>\dfrac1\varepsilon$，故 $\left|\dfrac1n\right|<\varepsilon$。由定义，$\lim\tfrac1n=0$。$\blacksquare$

**复盘**：距离恰好就是 $\tfrac1n$ 本身（正项数列逼近 $0$ 的常见便宜）；反解一步就出。$N$ 若取 $\left\lceil\tfrac1\varepsilon\right\rceil+1$ 也完全合法（4.5 第 2 条）。

### 例 2：证明 $\lim\limits_{n\to\infty}\dfrac{2n+1}{n}=2$

**猜**：$n=100$ 时 $\tfrac{201}{100}=2.01$；$n=10000$ 时 $2.0001$——奔 $2$ 去。（猜的原理：分子分母同除 $n$，得 $2+\tfrac1n$，主部是 $2$。）

**证**：$\left|\dfrac{2n+1}{n}-2\right|=\left|\dfrac1n\right|=\dfrac1n$——**问题瞬间归约为例 1**。以下三步照抄例 1 的 2–4 步（$N=\lceil 1/\varepsilon\rceil$）。$\blacksquare$

**复盘**：这是 $\varepsilon$-$N$ 证明的**主流形态**——复杂分式先做恒等变形，把 $|a_n-A|$ 化简成一个"明显趋于 $0$ 的简单量"，再对简单量找 $N$。**化简（猜 $A$ 之后的第一件事）比找 $N$ 更要紧**。

### 例 3（争论 2 的正式归档）：证明 $a_n=1,0,\tfrac12,0,\tfrac13,0,\ldots$ 收敛于 $0$

先写清通项（01 讲的功课：对象先定义清楚）：
$$a_n=\begin{cases}\dfrac{2}{n+1}, & n\text{ 为奇数}\\[2pt] 0, & n\text{ 为偶数}\end{cases}$$
（检查：$n=1$ 给 $\tfrac22=1$ ✓，$n=3$ 给 $\tfrac24=\tfrac12$ ✓，$n=5$ 给 $\tfrac26=\tfrac13$ ✓。）

**证**：对两种 $n$ 统一放缩——
$$|a_n-0|\le\begin{cases}\dfrac2n,\\ 0,\end{cases}\quad\text{恒有 } |a_n|\le\dfrac{2}{n}.$$
（奇数项 $\tfrac2{n+1}<\tfrac2n$；偶数项 $0\le\tfrac2n$。放缩把两个分支焊成一根线。）

1. 任给 $\varepsilon>0$。
2. 要使 $|a_n|\le\dfrac2n<\varepsilon$，只需 $n>\dfrac2\varepsilon$。
3. 取 $N=\left\lceil\dfrac2\varepsilon\right\rceil$。
4. $n>N$ 时 $|a_n|<\varepsilon$，由定义 $a_n\to0$。$\blacksquare$

**复盘**：**摆动数列的证明武器是"统一放缩"**——两条腿姿势不同，但都迈不过同一条上界 $\tfrac2n$。这道题正式宣告：**"走路难看"与"收敛"无关**，判据只有一条：尾部全体进带。

### 例 4（一分钟例）：$a_n\equiv c$（常数列）收敛于 $c$

$|a_n-c|=0<\varepsilon$ 对**一切** $\varepsilon>0$、一切 $n$ 成立——任取 $N=1$ 即接住所有轮次。这是 4.4 里"唯一同时满足两种量词顺序"的居民。

## 六、$0.999\ldots=1$：当场了结

### 6.1 先问"它是什么"（争论的真正死因）

这场架吵不出结果，是因为双方都在**默认 $0.999\ldots$ 是一个"写出来的东西"**，然后争论它和 $1$ 差多少。错位在这：**无限小数不是一个"写出来的东西"，是一个"走势的名字"**。

数学上，无限小数的定义是**位值缩写**：
$$0.999\ldots\ :=\ \lim_{n\to\infty}\underbrace{0.99\ldots9}_{n\text{ 个 }9}\ =\ \lim_{n\to\infty} s_n,\qquad s_n=\underbrace{0.99\ldots9}_{n\text{ 个 }9}.$$
（有限小数 $0.99\ldots9$ 是合法的、写得出来的；无限小数是这些有限小数排成的数列的**极限**——第三宗罪的"终点幻觉"在这已经拔掉了：没有"最后一位"，只有走势。）

### 6.2 用今天的手艺证它

**第 0 步（化简通项）**：高中等比数列求和给
$$s_n=\underbrace{0.99\ldots9}_{n\text{ 个 }9}=\frac9{10}+\frac9{10^2}+\cdots+\frac9{10^n}=1-\frac1{10^n}=1-10^{-n}.$$
（首项 $\tfrac9{10}$、公比 $\tfrac1{10}$ 的等比和：$s_n=\tfrac{9/10\,(1-10^{-n})}{1-1/10}=1-10^{-n}$，高中公式，直接用。）

**第 1–4 步（$\varepsilon$-$N$ 模板，证 $s_n\to1$）**：距离 $|s_n-1|=10^{-n}$。

1. 任给 $\varepsilon>0$。
2. 要使 $10^{-n}<\varepsilon$，即 $n>\log_{10}\dfrac1\varepsilon$（对数解不等式，高中手艺）。
3. 取 $N=\left\lceil\log_{10}\dfrac1\varepsilon\right\rceil$。
4. $n>N$ 时 $|s_n-1|=10^{-n}<\varepsilon$。由定义，
$$0.999\ldots=\lim_{n\to\infty}s_n=1.\qquad\blacksquare$$

**实感核对**：$\varepsilon=10^{-6}$（百万分之一）时 $N=6$——写到第 6 个 9，距离就只剩 $10^{-6}$；写到 $n$ 个 9，距离 $10^{-n}$。**每一轮游戏都接得住，且 $N$ 的公式干净得像作弊。** 第八节实验 3 数值坐实。

### 6.3 反方两句话的合法处置

- **"永远差 $0.000\ldots1$"**：$0.000\ldots1$ 不是一个数。小数点后无限个 $0$ **之后**的"那个位置"不存在（"无限个之后"自相矛盾）；真实存在的是距离数列 $10^{-n}$，它趋于 $0$——**差的确永远存在（每一步都有差），但差的大小趋于零**，极限定义捕捉的正是后者。
- **"$1/3=0.333\ldots$ 三边乘 $3$"**：正方的这条论证其实**好**——但只有像 6.1 那样先把"无限小数=极限"定义立住，它才是证明；否则它只是把一场定义之争换了个马甲（"为什么 $0.333\ldots\times3=0.999\ldots$？"又得吵一轮）。

### 6.4 两个诚实的边界声明（防过度自信）

1. **本论证的前提是定义**：我们证的是"按位值缩写的定义，$0.999\ldots$ 恰好等于 $1$"。**为什么这样定义无限小数**？（一句话：它是唯一能与有限小数的算术保持连贯、又允许"无限位"的推广；展开版属级数理论，**高数下**的事。）
2. **更深一层的地基**：本讲说"数列收敛于 $A$"，全程用实数 $A$。**实数轴本身"没有洞"（例如单调有界的数列必有极限）是一条被假设的地基**，$\varepsilon$-$N$ 语言只负责**描述**收敛，不负责**保证**实数配得上这些描述——实数系的严格构造（戴德金分割等）是《数学分析》的内容，本课程站在地基上盖楼，不挖地基。知道这层楼下面有东西、知道去哪门课挖，就够了。

## 七、收敛数列的四条性质：谁推谁

本节格式统一：**定理 → 证明（两个新工具箱首次亮相）→ 反例/边界**。先放总表（**箭头都是单向的**，反向全部不成立，各有反例在下面）：

$$\text{收敛}\ \Longrightarrow\ \begin{cases}\text{极限唯一}\\ \text{有界}\\ \text{任何子列收敛到同一极限}\\ \text{尾部保号}\end{cases}$$

| 性质 | 内容 | 方向 | 反例（反向不成立） |
|---|---|---|---|
| 唯一性 | 收敛 ⇒ 极限唯一 | 不可逆（无意义） | —— |
| 有界性 | 收敛 ⇒ 有界 | ✗ 反向 | $(-1)^n$：有界不收敛 |
| 子列 | 收敛 ⇒ 一切子列同限 | ✗ 反向 | $1,0,1,0,\ldots$：子列（全取偶数项）收敛，原列发散 |
| 保号性 | $A>0$ ⇒ 尾部 $>A/2>0$ | ✗ 反向 | $a_n=1/n>0$，极限 $=0$（保号保到极限只剩 $\ge$） |

### 7.1 唯一性（新工具"三明治"首秀）

> **定理**：若 $\{a_n\}$ 收敛，则极限唯一。

**证明**（反证）：设 $a_n\to A$ 又 $a_n\to B$，且 $A\ne B$。取 $\varepsilon_0=\dfrac{|A-B|}{2}>0$。

按定义，$\exists N_1$：$n>N_1$ 时 $|a_n-A|<\varepsilon_0$；$\exists N_2$：$n>N_2$ 时 $|a_n-B|<\varepsilon_0$。取 $n>\max(N_1,N_2)$，则
$$\underbrace{|A-B|}_{\text{面包}}\ \le\ \underbrace{|A-a_n|+|a_n-B|}_{\text{馅}}\ <\ 2\varepsilon_0=|A-B|,$$
即 $|A-B|<|A-B|$，矛盾。$\blacksquare$

**新工具：三明治（三角不等式）**。$|A-B|\le|A-a_n|+|a_n-B|$ 就是高中的绝对值不等式 $|x+y|\le|x|+|y|$（$x=A-a_n,\ y=a_n-B$）。它第一次露出杀伤力：**把两个"小于 $\varepsilon/2$"的东西夹出"$A=B$"或矛盾**。以后凡证明里出现"除以 2"（$\varepsilon_0=|A-B|/2$、未来的 $\varepsilon/2$ 技巧），都是这个三明治的变奏。**认脸即可，本讲不考名字。**

### 7.2 有界性（新工具"有限项取 max"首秀）

> **定理**：收敛 ⇒ 有界。

**证明**：设 $a_n\to A$。取一个具体的精度 $\varepsilon=1$（这里**可以**自己挑！因为带子宽窄只影响这轮的 $N$，不影响"收敛"这个已经到手的事实——见 4.6 坏习惯清单的对照：已经证完收敛，回头取 $\varepsilon=1$ 是使用定理，不是证明收敛）。$\exists N$：$n>N$ 时 $|a_n-A|<1$，于是
$$|a_n|\le|a_n-A|+|A|<1+|A|,\qquad n>N.$$
**尾部**有了统一的界 $1+|A|$；**前面** $N$ 项是有限个，取
$$M=\max\{|a_1|,|a_2|,\ldots,|a_N|,\ 1+|A|\},$$
则 $|a_n|\le M$ 对一切 $n$ 成立——有界。$\blacksquare$

**新工具：有限项取 $\max$**。"尾部一个界 + 前有限项各自一个界，有限个界里挑最大"——有限性保证 $\max$ 存在。这个朴素的动作以后反复出场（闭区间最值、一致连续……都是它的亲戚）。

**反向不成立的反例**：$(-1)^n$ 有界（$M=1$）但发散——**发散证明见 7.3，先把"有界 $\ne$ 收敛"这个直觉焊死**。同时注意它的逆否命题倒是真的：**无界 ⇒ 发散**（本讲作业 A4 用它）。所以"有界"是收敛的**入场券性质**：收敛的必有，有的未必收敛——查有界性可以**一票否决**收敛（发现无界直接判发散），不能**一票通过**。

### 7.3 反例解剖：$(-1)^n$ 为什么发散（两种武器）

**武器一（用定义的否定式，4.3 的游戏判负）**：对**任何**候选靶心 $A$，取 $\varepsilon_0=1$。任给 $N$，取 $n>N$，则 $a_n=\pm1$ 中至少一个与 $A$ 的距离 $\ge1$：因为 $|1-A|+|-1-A|\ge|(1-A)+(A+1)|=2$，两者**之和至少为 2，故至少一个 $\ge1$**；而 $N$ 之后奇偶两项都存在，挑出距 $A\ge1=\varepsilon_0$ 的那一项，它就是漏网之鱼。即
$$\exists\,\varepsilon_0=1,\ \forall N,\ \exists\,n>N:\ |a_n-A|\ge\varepsilon_0,$$
对一切 $A$ 成立——$(-1)^n$ 不收敛于任何数，发散。$\blacksquare$

（这个证明的价值：**证明"不收敛于任何数"必须对所有候选 $A$ 都判负**——这是"发散"比"不收敛于某个数"难写的地方，也是初学者最常漏的量词。）

**武器二（子列定理的系统化打法）**：先立定理——

> **定理（子列）**：若 $a_n\to A$，则 $\{a_n\}$ 的**任何**子列（按下标严格增挑出的无穷子列，如 $a_{n_1},a_{n_2},\ldots$，$n_1<n_2<\cdots$）都收敛于 $A$。
> **证明**：$\forall\varepsilon>0$，$\exists N$：$n>N\Rightarrow|a_n-A|<\varepsilon$。子列下标 $n_k\ge k$（第 $k$ 个被挑出的项，原下标至少是 $k$——因为挑出项的下标严格增、每个至少是 $1,2,\ldots,k$ 里没用过的）。故取 $K=N$：$k>K$ 时 $n_k\ge k>N$，于是 $|a_{n_k}-A|<\varepsilon$。$\blacksquare$

套用：$(-1)^n$ 的奇子列 $-1,-1,\ldots$ 极限是 $-1$，偶子列 $1,1,\ldots$ 极限是 $1$，两子列极限**不同**——若原列收敛，两子列都应收于同一个极限（定理），矛盾。发散。$\blacksquare$

**方向警告（重要）**：子列收敛 **⇏** 原列收敛。$1,0,1,0,\ldots$ 的"全取偶数项"子列恒为 $0$ 收敛，原列照样发散（奇子列恒为 $1$，两子列不同限——跟 $(-1)^n$ 同款死因）。**子列定理的正确用法只有单向的：证"两子列极限不同（或某子列发散）⇒ 原列发散"**；想证原列收敛，别指望子列。

### 7.4 保号性

> **定理（保号）**：若 $\lim a_n=A>0$，则 $\exists N$：$n>N$ 时 $a_n>\dfrac{A}{2}>0$（$A<0$ 时对称：$a_n<\dfrac{A}{2}<0$）。

**证明**：取 $\varepsilon=\dfrac A2>0$（同 7.2：**使用**定理挑精度，合法）。$\exists N$：$n>N$ 时 $|a_n-A|<\dfrac A2$，即 $-\dfrac A2<a_n-A<\dfrac A2$，右边不等式给出 $a_n>A-\dfrac A2=\dfrac A2>0$。$\blacksquare$

**怎么记**：极限的**严格**正号，保证的是**尾部**的严格正号（还打了对折保险 $A/2$——不打折会被"距离 $<\varepsilon$"的边界蹭掉）。

**方向与边界（防错）**：反向只剩非严格版本：若 $a_n>0$ 对一切 $n$ 且 $a_n\to A$，则 $A\ge0$（**可以等于 0**：$\tfrac1n$ 全为正、极限恰为 $0$）。"$>0$" 走到极限处自动降级为"$\ge0$"——这个降级在极限运算里**永远存在**，第 16 讲判极值时它会回来咬每一个不设防的人。

**保号性拿去干嘛**：它的下游是"用极限的符号控制尾部项的符号"——第 09 讲导数定义推单调性、第 16 讲极值充分条件，全是它的变奏。现在先把定理本身焊住。

## 八、数值实验：对抗游戏的机器版

完整脚本在 `scripts/lec02-01_verify_sequence_limit.py`（运行：`uv run --with numpy python scripts/lec02-01_verify_sequence_limit.py`）。四个实验对机器完全不神秘：$\varepsilon$ 就是程序里的一个数，$N$ 就是一个循环起点，"验证"就是一段 for 循环。

### 实验 1：对抗游戏实况（$a_n=1/n\to0$）

程序让对手依次出 $\varepsilon=0.1,\ 0.01,\ 10^{-3},\ 10^{-6},\ 10^{-9}$，对每个 $\varepsilon$ 用例 1 的公式取 $N=\lceil1/\varepsilon\rceil$，然后扫描 $n\in(N,\ N+1000]$ 全体项，核对 $|a_n|<\varepsilon$ 是否**一项不漏**；同时用"更宽裕的 $N'=2\lceil1/\varepsilon\rceil$"再验一遍（坐实 4.5 第 2 条：$N$ 不唯一）。

（实测，全脚本 $0.01$ 秒跑完，可复跑）：

```
eps = 0.1: N = 10, 尾部1000项 max|a_n| = 9.091e-02 (< eps? True) ; 宽裕版 N' = 20: max = 4.762e-02 (< eps? True)
eps = 0.01: N = 100, 尾部1000项 max|a_n| = 9.901e-03 (< eps? True) ; 宽裕版 N' = 200: max = 4.975e-03 (< eps? True)
eps = 0.001: N = 1000, 尾部1000项 max|a_n| = 9.990e-04 (< eps? True) ; 宽裕版 N' = 2000: max = 4.998e-04 (< eps? True)
eps = 1e-06: N = 1000000, 尾部1000项 max|a_n| = 1.000e-06 (< eps? True) ; 宽裕版 N' = 2000000: max = 5.000e-07 (< eps? True)
eps = 1e-09: N = 1000000000, 尾部1000项 max|a_n| = 1.000e-09 (< eps? True) ; 宽裕版 N' = 2000000000: max = 5.000e-10 (< eps? True)
  -> 每轮都接得住; eps 缩小 10 倍 N 长大 10 倍 (N 依赖 eps); 取更大的 N 同样合法 (N 不唯一)
```

**结论（实测坐实）**：每个 $\varepsilon$ 都接住（扫描最大值 $<\varepsilon$）；$\varepsilon$ 缩小 $10$ 倍，$N$ 长大 $10$ 倍——"$N$ 依赖 $\varepsilon$"看得见摸得着；宽裕版 $N'=2N$ 同样合法（$N$ 不唯一）。

（一句较真提示：后两行 `max` 打印成 `1.000e-06`/`1.000e-09`，看着"等于 $\varepsilon$ 却判 True"——那是**三位有效数字的显示四舍五入**，实际值是首项 $\dfrac1{N+1}=9.99999999\times10^{-7}$（最大项在 $n=N+1$，其后递减），严格小于 $\varepsilon$。较真是好习惯，但先分清较真的是**显示**还是**数值**——这本身就是本讲"精确语言"主题的浮点版。）

### 实验 2：摆动数列收敛、$(-1)^n$ 发散（机器版判负）

对第五节例 3 的摆动数列：给定 $\varepsilon=10^{-2}$，用例 3 的 $N=\lceil2/\varepsilon\rceil$，扫描尾部全体核对。
对 $(-1)^n$：反向演一场**判负**——取 $\varepsilon_0=0.9$，让程序对 $N=1,10,100,1000,10^6$ 逐一"接招"，每次都在尾部找出漏网之鱼（对候选 $A=1$ 用奇数项、对 $A=-1$ 用偶数项，距靶 $\ge1>0.9$）——4.3 否定式
$$\exists\,\varepsilon_0,\ \forall N,\ \exists\,n>N:\ |a_n-A|\ge\varepsilon_0$$
在机器上的**逐字复刻**：不是"算出发散"，是"演示永远接不住"。

（实测）：

```
摆动数列: eps = 0.01, N = ceil(2/eps) = 200, 扫描 5000 项, max|a_n| = 0.009901 (< eps? True)
  -> 一跳一停地走路, 尾部照样全体进带: 收敛 (第五节例 3 的机器版)
  (-1)^n: N =       1: 漏网项 n =       3 距 A=1 为 2 (>= 0.9); n =       2 距 A=-1 为 2 (>= 0.9)
  (-1)^n: N =      10: 漏网项 n =      11 距 A=1 为 2 (>= 0.9); n =      12 距 A=-1 为 2 (>= 0.9)
  (-1)^n: N =     100: 漏网项 n =     101 距 A=1 为 2 (>= 0.9); n =     102 距 A=-1 为 2 (>= 0.9)
  (-1)^n: N =    1000: 漏网项 n =    1001 距 A=1 为 2 (>= 0.9); n =    1002 距 A=-1 为 2 (>= 0.9)
  (-1)^n: N = 1000000: 漏网项 n = 1000001 距 A=1 为 2 (>= 0.9); n = 1000002 距 A=-1 为 2 (>= 0.9)
  -> 对任何 N 都接不住 eps0 = 0.9 (两个候选靶心都判负): 发散 = 定义否定式的机器版
```

**结论（实测坐实）**：摆动数列尾部 5000 项最大偏离 $0.009901<0.01$（轮轮接得住，走路难看不妨碍进带）；$(-1)^n$ 对任何 $N$（哪怕 $N=10^6$）都被漏网之鱼判负——收敛与发散在机器上是**同一台验证器的两种判决**。

### 实验 3：$0.999\ldots$ 的实弹射击（含浮点彩蛋）

$s_n=1-10^{-n}$。对手出 $\varepsilon=10^{-3},10^{-6},10^{-9}$：程序按 6.2 的公式取 $N=\lceil\log_{10}(1/\varepsilon)\rceil$，扫描核对尾部；再打印**浮点彩蛋**：$n$ 多大时，机器里 $1-10^{-n}$ **干脆就等于 $1.0$**？（预告：float64 到 $1$ 的最后一段台阶只有约 $10^{-16}$ 宽——$10^{-n}$ 比它还小时，$1-10^{-n}$ 被**舍入**成 $1.0$。数学上 $s_n$ **永远不等于** $1$，机器上它"提前到达"——第 01 讲"采样 ≠ 全体"的续集：**机器的舍入不是数学的到达**。）

（实测）：

```
eps = 0.001: N = ceil(log10(1/eps)) = 3, 尾部扫描 max|s_n - 1| = 1.000e-04 (< eps? True)
eps = 1e-06: N = ceil(log10(1/eps)) = 6, 尾部扫描 max|s_n - 1| = 1.000e-07 (< eps? True)
eps = 1e-09: N = ceil(log10(1/eps)) = 9, 尾部扫描 max|s_n - 1| = 1.000e-10 (< eps? True)
浮点彩蛋: 机器上 1 - 10^-n == 1.0 从 n = 17 开始 (float64 到 1 的最后一级台阶约 1.1e-16 宽)
  -> 数学上 s_n 永不等于 1 (差恒为 10^-n > 0); 机器上 n >= 17 就被舍入成 1.0: 舍入不是到达
```

**结论（实测坐实）**：$N$ 公式逐个命中（$\varepsilon=10^{-k}\Rightarrow N=k$，尾部最大距离恰为首项的 $10^{-(N+1)}$）；彩蛋实测位置 $n=17$——比预告里猜的"$n\approx16$"晚了一步。这一步不是白差的，按规矩交代：

> **一个诚实的修正**（作者预判彩蛋位置的翻车，三要素）：
> ① **偏差描述**：预告里我推理"$1$ 旁的台阶宽 $2^{-53}\approx1.11\times10^{-16}$，而 $10^{-16}$ 比它小，所以 $n=16$ 起 $1-10^{-n}$ 就该被舍入成 $1.0$"——预想彩蛋在 $n\approx16$。
> ② **实测**：$1-10^{-16}=0.9999999999999999\ne1.0$；从 $n=17$ 起，$1-10^{-n}$ 才等于 $1.0$。
> ③ **根因**：舍入的判据不是"$x$ 比台阶窄"，而是"**离哪格近住哪格**"。$1$ 的下一格是 $1-2^{-53}$，两格的中界在 $1-2^{-54}\approx1-5.55\times10^{-17}$：$10^{-16}$ 离 $1-2^{-53}$ 那格更近（住进去），$10^{-17}$ 才跨过中界住进 $1$。我把"半级台阶"（$2^{-54}$）错当成了"整级台阶"（$2^{-53}$）。
> 教训与第 01 讲那场同款：**量级对 $\ne$ 数值对**——"约 $10^{-16}$"这个量级估计本身没错，错在把它当了舍入边界的精确值。浮点数轴不是连续斜坡，是离散客房：舍入 = 就近入住。

### 实验 4：量词顺序的机器版（常数列 vs $1/n$）

常数列 $a_n\equiv5$：程序对一连串缩小的 $\varepsilon$ 逐个"接招"，打印**同一个** $N=1$ 是否回回接住（$\exists N\ \forall\varepsilon$ 的形态——4.4 说的"万能线"，常数列的特权）。
对照组 $1/n$：$N$ 必须跟着 $\varepsilon$ 一路增大（$\forall\varepsilon\ \exists N$ 的形态）。

（实测）：

```
常数列 a_n = 5: 同一个 N = 1 接住一切 eps (尾部恒为 5, 距离恒为 0):
    eps = 0.5: N = 1, |5 - 5| = 0 < eps? True
    eps = 0.1: N = 1, |5 - 5| = 0 < eps? True
    eps = 0.01: N = 1, |5 - 5| = 0 < eps? True
    eps = 0.0001: N = 1, |5 - 5| = 0 < eps? True
    eps = 1e-08: N = 1, |5 - 5| = 0 < eps? True
  对照 1/n -> 0: N 必须看着 eps 出 (N 随 eps 缩小而增大):
    eps = 0.5: N = ceil(1/eps) = 2
    eps = 0.1: N = ceil(1/eps) = 10
    eps = 0.01: N = ceil(1/eps) = 100
    eps = 0.0001: N = ceil(1/eps) = 10000
    eps = 1e-08: N = ceil(1/eps) = 100000000
  -> 常数列是'万能 N'的唯一居民 (量词可交换的那类); 1/n 的 N 依赖 eps: 逼近不是到达
```

**结论（实测坐实）**：两张表并排——一张 $N$ 恒为 $1$，一张 $N$ 随 $\varepsilon$ 缩小而指数式增长（$\varepsilon=10^{-8}$ 时 $N$ 已是 $10^8$）。**"逼近"与"到达"的差别，打印在纸上。**

## 九、问法索引（零新知识，只对答案）

> 本节不引入任何新概念，只把高频疑问对到正文出处。

1. **"$\varepsilon$-$N$ 这么费劲，工科考试真的要考吗？我直接背极限运算法则不行吗？"**
   考，但考的形态是"用定义证具体数列 + 叙述量词"，不是让你背定义原文（→ 第四、五节）。更硬的理由：**后面每一条"拿来就用的法则"都带前提**——第 04 讲四则运算法则的前提是"各极限存在"，洛必达的前提更长。不懂定义，你就**不知道那些前提在保护什么**，也就不知道什么时候会踩空（第 04 讲会给你看"发散+发散=收敛"这种前提失效的现场）。$\varepsilon$-$N$ 是那本法则手册的**保修条款**。
2. **"写证明时我能先取 $\varepsilon=0.001$ 找找感觉吗？"**
   能，且推荐——在草稿纸上（→ 4.6 坏习惯清单）。用具体 $\varepsilon$ 走一遍流程是找 $N$ 的最好方法；正式书写时必须换回"任给 $\varepsilon>0$"。另：**已经证完收敛后**回头取具体 $\varepsilon$（如 7.2 取 $\varepsilon=1$）是合法使用，性质不同。
3. **"$N$ 必须是整数吗？$\lceil x\rceil$ 是什么？"**
   $N$ 是"项数"，必须是正整数；$\lceil x\rceil$ 是向上取整（01 讲 3.2 取整函数的"反方向兄弟"：不小于 $x$ 的最小整数）。取整后 $N$ 只会更大不会更小，尾部条件更宽裕——这就是 4.5 第 2 条"往大放"的应用。
4. **"$\lim$ 这个记号什么时候有资格写？"**
   只有**收敛性已证（或已知）**时。"$\lim a_n=A$" 是一张**证书**，不是一句愿望——先写 $\lim$ 后算值的日常操作，其实每一步都默认了存在性。这个默认什么时候安全（第 04 讲：各极限存在时四则安全）、什么时候出事（发散对象混入），正是后面几讲的主题之一。

## 本讲小结

- **数列 = 只在整数刻度上开工的机器**（01 讲机器模型的特例）；收敛性由通项走势决定，与前有限项、走路姿势无关。
- **"越来越接近"三宗罪**：没定量（$\tfrac1n$ 也"越来越接近"$-1$）、过程成见（摆动照样收敛）、终点幻觉（数列没有最后一项）。修好的语言 = **距离 $|a_n-A|$ + 尾部 $n>N$ + 任意精度 $\forall\varepsilon$**。
- **$\varepsilon$-$N$ = 对抗游戏**：对手出 $\varepsilon$ 不许还价，我出 $N$ 只需存在、可以往大放；**轮轮接得住 = 收敛**；**存在一轮永远接不住 = 发散**（否定式：$\exists\varepsilon_0\ \forall N\ \exists n>N$，距离 $\ge\varepsilon_0$）。
- **量词顺序 $\forall\varepsilon\ \exists N$ 是"逼近"的编码**；换成 $\exists N\ \forall\varepsilon$ 就变成"尾部常数"——"到达"。$1/n\to0$ 而 $1/n$ 永不等于 $0$。
- **证明模板四步**：任给 $\varepsilon$ → 反解/放缩出 $n>$ 某量 → 取整定 $N$ → 验证收笔。主流形态：先把 $|a_n-A|$ **化简**成简单量再找 $N$；摆动数列用**统一放缩**焊两分支。
- **收敛的四条单向性质**：唯一（三明治 $\varepsilon_0=|A-B|/2$）、有界（尾部界 $1+|A|$ + 前有限项取 $\max$）、子列同限（只可用于**证发散**）、保号（严格正极限 ⇒ 尾部 $>A/2$；反向降级为 $\ge$）。**有界是入场券不是通行证**；无界直接判发散（逆否）。
- **$0.999\ldots=1$**：无限小数 = 部分和数列的极限（位值缩写定义）；$|s_n-1|=10^{-n}$，$N=\lceil\log_{10}(1/\varepsilon)\rceil$，证毕。"$0.000\ldots1$" 不是数。
- **两个诚实边界**：实数"无洞"是被假设的地基（数学分析去挖）；机器上 $s_n$ 会被舍入"提前到达"（浮点 ≠ 数学）。
- **心智模型清单**：对抗游戏（定义）、$\varepsilon$-带（几何直观，启发用）、三明治与有限取 $\max$（两个证明小工具，认脸）。

## 作业

**说明**：基础/提高/综合/代码四档。参考答案平铺在每题下方（先独立做再对照）。所有题只用到本讲与之前教过的概念。

### A. 基础（模板与判断）

**A1** 用定义证明 $\lim\limits_{n\to\infty}\dfrac{1}{n^2}=0$（模板复走，注意这次反解要开方）。

**参考答案**：
1. 任给 $\varepsilon>0$。
2. 要使 $\left|\dfrac{1}{n^2}\right|=\dfrac1{n^2}<\varepsilon$，只需 $n^2>\dfrac1\varepsilon$，即 $n>\dfrac{1}{\sqrt\varepsilon}$（开方，$\varepsilon>0$ 保证合法）。
3. 取 $N=\left\lceil\dfrac{1}{\sqrt\varepsilon}\right\rceil$。
4. 当 $n>N$ 时 $\dfrac1{n^2}<\varepsilon$。由定义，$\lim\dfrac1{n^2}=0$。$\blacksquare$

**验算方法**：抽查一轮——$\varepsilon=10^{-4}$ 时 $N=100$，核对 $n=101$：$1/101^2\approx9.8\times10^{-5}<10^{-4}$ ✓。

**A2** 用定义证明 $\lim\limits_{n\to\infty}\dfrac{n+3}{2n+1}=\dfrac12$。

**参考答案**：
先化简距离（主流形态：第一步先化简）：
$$\left|\dfrac{n+3}{2n+1}-\dfrac12\right|=\left|\dfrac{2(n+3)-(2n+1)}{2(2n+1)}\right|=\dfrac{5}{4n+2}<\dfrac{5}{4n}\quad(\text{放缩：分母变小}).$$
1. 任给 $\varepsilon>0$。
2. 要使 $\dfrac{5}{4n}<\varepsilon$，只需 $n>\dfrac{5}{4\varepsilon}$。
3. 取 $N=\left\lceil\dfrac{5}{4\varepsilon}\right\rceil$。
4. $n>N$ 时 $\left|\dfrac{n+3}{2n+1}-\dfrac12\right|<\dfrac5{4n}<\varepsilon$。由定义，极限为 $\dfrac12$。$\blacksquare$

（若不放缩、直接解 $\dfrac5{4n+2}<\varepsilon$ 得 $N=\left\lceil\dfrac{5-2\varepsilon}{4\varepsilon}\right\rceil$ 也对——$N$ 不唯一，两条路都合法。）

**A3** 判断下列说法对错，对的说一句理由，错的指出病灶（对照哪条"罪"或哪个部件）：

(1) "$\tfrac1n$ 越来越接近 $-1$（距离 $1+\tfrac1n$ 一直变小），所以 $\lim\tfrac1n=-1$。"
(2) "收敛数列一定是单调地靠近极限的。"
(3) "$\lim a_n=A$ 的意思是：数列可以一直算下去，最终某一项会等于 $A$。"

**参考答案**：
(1) 错。**罪一**：没定量——"距离在变小"（降到 $1$ 就停）不是"距离趋于零"；$\left|\tfrac1n-(-1)\right|=1+\tfrac1n\to1\ne0$，而 $\left|\tfrac1n-0\right|=\tfrac1n\to0$，极限是 $0$（且由唯一性，不可能是别的数）。
(2) 错。**罪二**：过程成见——第五节例 3 的摆动数列收敛但不单调（$1>0<\tfrac12>0<\tfrac13$，一直跳）。收敛只看尾部进带，不看姿势。
(3) 错。**罪三**：终点幻觉——极限是走势的性质不是"到达某项"；$\tfrac1n\to0$ 而 $\tfrac1n$ 对任何 $n$ 都不等于 $0$。极限为 $A$ **允许**某些项等于 $A$（常数列全是 $A$），但**从不要求**。

**A4** 判断对错并给理由或反例：(1) 收敛 ⇒ 有界；(2) 有界 ⇒ 收敛；(3) 发散 ⇒ 无界；(4) 无界 ⇒ 发散。

**参考答案**：
(1) 对（7.2 定理：$\varepsilon=1$ 得尾部界，前有限项取 $\max$）。
(2) 错（反例：$(-1)^n$ 有界、发散——7.3 两武器）。
(3) 错（同上反例：$(-1)^n$ 发散但有界）。
(4) 对（**(1) 的逆否命题**：无界 ⇒ 不收敛 ⇒ 发散——"有界是入场券"的判卷实用版：**查无界可一票否决收敛**，查有界一票通不过）。

### B. 提高（证明与构造）

**B1** 用定义证明 $\lim\limits_{n\to\infty}\dfrac{\sin n}{n}=0$（$\sin$ 是高中知识；$|\sin n|\le1$ 直接用）。

**参考答案**：
距离放缩（有界量 $\times$ 趋零量）：
$$\left|\dfrac{\sin n}{n}-0\right|=\dfrac{|\sin n|}{n}\le\dfrac1n.$$
1. 任给 $\varepsilon>0$。
2. 要使 $\dfrac1n<\varepsilon$，只需 $n>\dfrac1\varepsilon$。
3. 取 $N=\left\lceil\dfrac1\varepsilon\right\rceil$。
4. $n>N$ 时 $\left|\dfrac{\sin n}n\right|\le\dfrac1n<\varepsilon$。$\blacksquare$

（注意答案**没有**用"夹逼定理"这个名字——它属于第 05 讲；本答案用的是它的手艺前身：**给距离找一条趋于零的上界**。名字后到，手艺先行。）

**B2** 证明数列 $a_n=(-1)^n\cdot\dfrac{n}{n+1}$ 发散。

**参考答案**：
用**子列武器**（7.3 武器二）：奇子列 $a_{2k-1}=-\dfrac{2k-1}{2k}\to-1$，偶子列 $a_{2k}=\dfrac{2k}{2k+1}\to1$。两个子列极限不同，若原列收敛则任何子列应同限（子列定理），矛盾——发散。
（也可用**定义否定式**（武器一）：对候选 $A$，距 $1$ 与距 $-1$ 的两个量在 $n$ 奇偶时分别趋于 $0$ 与 $2$，取 $\varepsilon_0=1$，任何 $N$ 后的偶项距 $-1$ 已超 $1$、奇项距 $1$ 已超 $1$，漏网之鱼总在——写法同 7.3，注意要对**一切**候选 $A$ 说话，子列法天然回避了这个麻烦：两子列极限是 $1$ 和 $-1$，靶心不可能同时是两个数——**唯一性**替你排除了其余候选。两种武器都能收工，子列法书写更省。）

**B3** 设 $a_n\to A$。数列 $\{b_n\}$ 满足：$n>5$ 时 $b_n=a_n$（前 5 项随便乱写）。证明 $b_n\to A$。

**参考答案**：
1. 任给 $\varepsilon>0$。
2. 因 $a_n\to A$：$\exists N_0$：$n>N_0$ 时 $|a_n-A|<\varepsilon$。
3. 取 $N=\max(N_0,\ 5)$。
4. $n>N$ 时：$n>5$ 故 $b_n=a_n$；$n>N_0$ 故 $|b_n-A|=|a_n-A|<\varepsilon$。$\blacksquare$

（这就是 4.5 第 4 条"前有限项无关"的正式写法：**$\max$ 把"两个各自的要求"焊成一条公共起跑线**——有限项取 $\max$ 工具的又一变奏。）

### C. 综合（难题档，允许卡）

**C1** 令 $a_n=(-1)^n$，$b_n=(-1)^{n+1}$。证明：两个数列都发散，但 $a_n+b_n$ 收敛（并求其极限）。然后说明这件事为什么不是"极限可以随便拆开加"的证据。

**参考答案**：
**都发散**：$a_n$ 即 7.3 的标准反例（两子列极限 $1\ne-1$）。$b_n=(-1)^{n+1}$ 是 $a_n$ 的反号版（奇项 $1$、偶项 $-1$），同样两子列异限，发散。
**和收敛**：$a_n+b_n=(-1)^n+(-1)^{n+1}=(-1)^n(1+(-1))\equiv0$——常数列（例 4），收敛于 $0$。
**为什么不是拆加的证据**：正确的加法规则（第 04 讲正式立）形如"$\lim a_n$ 与 $\lim b_n$ **都存在** ⇒ $\lim(a_n+b_n)=\lim a_n+\lim b_n$"——它是**单向的充分条件**，不是"和收敛 ⇔ 各自收敛"。本题正是反向的活体反例：**和收敛，加数不收敛**。"前提存在"保护的是**正向使用**（已知两极限存在时放心拆），从不承诺"拆不了就不存在"。把"$\lim(a+b)$ 存在"倒推出"$\lim a$、$\lim b$ 存在"，是把充分条件误读成充要——第 04 讲开讲第一件事就是把这个边界画清。

**C2** 把第六节的证明完整独立地写一遍并补一个具体核对：证明 $0.999\ldots=1$，要求 (1) 从等比求和出发推导 $s_n=1-10^{-n}$；(2) 用 $\varepsilon$-$N$ 模板证明 $s_n\to1$，$N$ 必须显式给出；(3) 取 $\varepsilon=10^{-6}$，算出 $N$，并验证 $n=N+1$ 这一项确实满足距离条件。

**参考答案**：
(1) $s_n=\dfrac9{10}+\dfrac9{10^2}+\cdots+\dfrac9{10^n}$ 是首项 $\dfrac9{10}$、公比 $q=\dfrac1{10}$ 的等比数列前 $n$ 项和：
$$s_n=\frac{\tfrac9{10}\left(1-\left(\tfrac1{10}\right)^n\right)}{1-\tfrac1{10}}=\frac{9(1-10^{-n})}{9}=1-10^{-n}.$$
(2) 距离 $|s_n-1|=10^{-n}$。
1. 任给 $\varepsilon>0$。
2. 要使 $10^{-n}<\varepsilon$，两边取常用对数（$\log_{10}$ 单调增，不等号方向不变）：$-n<\log_{10}\varepsilon$，即 $n>-\log_{10}\varepsilon=\log_{10}\dfrac1\varepsilon$。
3. 取 $N=\left\lceil\log_{10}\dfrac1\varepsilon\right\rceil$。
4. $n>N$ 时 $|s_n-1|=10^{-n}<\varepsilon$，由定义 $s_n\to1$，即 $0.999\ldots=1$。$\blacksquare$
(3) $\varepsilon=10^{-6}$：$\log_{10}\dfrac1{10^{-6}}=6$，$N=\lceil6\rceil=6$（恰为整数，向上取整没有加量）。验证 $n=7$：$|s_7-1|=10^{-7}=0.0000001<10^{-6}$ ✓（第 7 个 9 写完，离 $1$ 只剩千万分之一）。
（顺带核对边界：$n=6$ 时 $|s_6-1|=10^{-6}$，**等于** $\varepsilon$ 而非小于——所以 $N$ 取 $6$ 恰好卡在"从 $n=7$ 起生效"，多取 $N=7$ 更宽裕。$N$ 的贴边与宽裕，都合法。）

### D. 代码（可跑验证）

**D1** 复刻并扩展实验 2：对摆动数列 $a_n$（奇 $2/(n+1)$、偶 $0$），给定 $\varepsilon=10^{-3}$，用 $N=\lceil2/\varepsilon\rceil$，扫描 $n\in(N,\ N+5000]$ 核对全部 $|a_n|<\varepsilon$，打印最大偏离；再对 $(-1)^n$ 取 $\varepsilon_0=0.9$，对 $N=1,10,100,1000$ 各找出一个具体漏网项（要求 $n>N$ 且距候选 $A=1$ 不小于 $\varepsilon_0$）并打印。

**参考答案**：

```python
import math
import numpy as np

# 摆动数列: n 奇 -> 2/(n+1), n 偶 -> 0
def swing(n):
    return 2.0 / (n + 1) if n % 2 == 1 else 0.0

eps = 1e-3
N = math.ceil(2.0 / eps)
ns = np.arange(N + 1, N + 5001)
vals = np.array([swing(int(n)) for n in ns])
worst = np.max(np.abs(vals))
print(f"eps = {eps:g}, N = {N}, scan {len(ns)} terms, max |a_n| = {worst:.3e}")
assert worst < eps
print("[OK] 摆动数列尾部全体进带")

# (-1)^n: 对每个 N 找一个漏网项 (距候选 A=1 不小于 eps0)
eps0 = 0.9
a = lambda n: 1.0 if n % 2 == 0 else -1.0
for N2 in [1, 10, 100, 1000]:
    n = N2 + 1 if (N2 + 1) % 2 == 1 else N2 + 2   # 找一个奇数项(值为 -1)
    print(f"N = {N2:4d}: 漏网项 n = {n}, a_n = {a(n):.0f}, |a_n - 1| = {abs(a(n) - 1):.0f} >= {eps0}")
    assert abs(a(n) - 1.0) >= eps0
print("[OK] 对任何测试的 N 都存在漏网项: (-1)^n 发散的机器版判负")
```
