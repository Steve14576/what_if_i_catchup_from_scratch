## 一、开场：三道"定义级"题

**题 1**：抛物线 $y=x^2$ 下、$[0,1]$ 上的"面积"——"分割近似求和取极限"你听过。**追问**：这里的"取极限"到底是让**什么**趋于零？（$n\to\infty$？还是别的？——两个答案有区别吗？）

**题 2**：$\displaystyle\int_0^1x^2\,dx$ 里那个 $dx$——12 讲说它"和微分同户口"、19 讲说"22 讲细讲"。**它在这里到底是什么？**

**题 3**：$\displaystyle\int_{-1}^{1}x\,dx$ 等于多少？（"面积"？——算完你会发现**它等于 0**。）

**答案预告**：

1. 让**分割的最粗段长** $\lambda\to0$——**不是**简单的 $n\to\infty$："段数无限多"与"每段无限短"在**不均匀分割**时不是一回事（第二节给反例，实验 4 给数值活体）。
2. 在黎曼和里，$dx$ 是 **$\Delta x$ 的极限化身**（分割宽度的无穷小版）——它和 12 讲的微分（"线性标尺"）的关系本讲第五节结清（"三级身份"户口本）。
3. $\int_{-1}^1x\,dx=0$——因为面积是**有向**的：$x>0$ 的上方"正面积"与 $x<0$ 的下方"负面积"**精确抵消**（对称的函数）。"面积"这个词要加定语的场合来了（第三节）。

## 二、黎曼和与定积分定义

### 2.1 四部曲

设 $f$ 在 $[a,b]$ 上有界。**①分割**：插入分点 $a=x_0<x_1<\cdots<x_n=b$，记 $\Delta x_i=x_i-x_{i-1}$（第 $i$ 段长）、$\lambda=\max\limits_i\Delta x_i$（**最粗段**）。**②近似**：第 $i$ 段上任取 $\xi_i\in[x_{i-1},x_i]$，用矩形 $f(\xi_i)\Delta x_i$ 近似那一片。**③求和**：$S=\sum\limits_{i=1}^n f(\xi_i)\Delta x_i$（**黎曼和**）。**④取极限**：令 $\lambda\to0$。

### 2.2 定义

> **定义（定积分）**：若当 $\lambda\to0$ 时黎曼和 $S$ 的极限**存在**，且**与分割方式、取点方式都无关**，则称 $f$ 在 $[a,b]$ 上**黎曼可积**，该极限记作
> $$\int_a^bf(x)\,dx:=\lim_{\lambda\to0}\sum_{i=1}^n f(\xi_i)\Delta x_i,$$
> 称**定积分**（一个**数**）。

**逐部件读**：$\int_a^b$ 是"从 $a$ 到 $b$ 累加"的记号；$f(x)$ 是被积函数；$dx$ 的角色第五节结清；这个**数**是"和式的极限"——**与 19 讲的"不定积分"（函数族）是两个对象**（画像定制：它们长得像、名字像，**只有 23 讲的 N-L 公式把它们焊起来**）。

### 2.3 $\lambda\to0$ 与 $n\to\infty$ 的差别（疑问 1、4——本讲核心知识）

**先把蕴含关系钉死**：

- $\lambda\to0\Rightarrow n\to\infty$：每段长都小于 $\lambda$ ⇒ 段数 $n\ge\frac{b-a}{\lambda}\to\infty$ ✓（**单向成立**）；
- $n\to\infty\not\Rightarrow\lambda\to0$：**反例**（不均匀分割）：把 $[0,1]$ 先分成两半 $[0,\frac12],[\frac12,1]$，然后**只把 $[0,\frac12]$ 无限细分**、$[\frac12,1]$ 永远不细——段数 $n\to\infty$，而**第一段始终长 $\frac12$**：$\lambda\equiv\frac12$ **不趋零**。

**这个反例的杀伤力（为什么非 $\lambda\to0$ 不可）**：在这种"一边无限细、一边永远粗"的分割下，黎曼和会收敛到**别的值**——对 $f(x)=x$、取每段左端点作 $\xi_i$：几何级数衰减的分割（$0,\frac12,\frac34,\dots$）下和 $\to\frac13$，而真值 $\int_0^1x\,dx=\frac12$（实验 4 的完整数值活体）。**"段数多"可以掩盖"某一段永远粗"——极限就变了**。所以：

> **"无限细"的精确含义是 $\lambda\to0$（每段都短），不是 $n\to\infty$（段数多）。**

（教材里"$\Delta x\to0$""无限细分"等说法，从现在起统一翻译成 $\lambda\to0$。）

### 2.4 取点任意性（疑问 2）

定义里"**与取点方式无关**"是**可积性的一部分**——不是"运气"：对可积函数，任取 $\xi_i$ 极限都相同。**用一个例子把三种取法摆开**（$\int_0^1x\,dx$，等分 $\Delta x=\frac1n$）：

- **左端点** $\xi_i=\frac{i-1}n$：$S_L=\sum_{i=1}^n\frac{i-1}n\cdot\frac1n=\frac{n(n-1)}{2n^2}\to\frac12$；
- **右端点** $\xi_i=\frac in$：$S_R=\sum_{i=1}^n\frac in\cdot\frac1n=\frac{n(n+1)}{2n^2}\to\frac12$；
- **中点** $\xi_i=\frac{2i-1}{2n}$：$S_M=\sum_{i=1}^n\frac{2i-1}{2n}\cdot\frac1n=\frac{n^2}{2n^2}\to\frac12$（用了 $\sum_{i=1}^n(2i-1)=n^2$——奇数和公式）。

**三者同趋 $\frac12$**——"任意"的地位就是这么落实的（实验 2 的数值表）。

### 2.5 从定义直立算两例（"定义级"计算）

**例 1（已会）**：$\int_0^1x\,dx=\frac12$（上一小节三取点已算）。

**例 2（平方和登场）**：$\int_0^1x^2\,dx$：等分、右端点：

$$S=\sum_{i=1}^n\left(\frac in\right)^2\frac1n=\frac{1}{n^3}\sum_{i=1}^ni^2=\frac{n(n+1)(2n+1)}{6n^3}\ \xrightarrow{n\to\infty}\ \frac13.$$

（**平方和公式** $\sum i^2=\frac{n(n+1)(2n+1)}6$——高中资产，本讲现场点名使用；等分时 $n\to\infty$ 与 $\lambda\to0$ 等价，可以放心用 $n\to\infty$ 算。）⇒ $\int_0^1x^2dx=\frac13$ ✓。

**一句实话**（23 讲的动员）：从定义**能**算的只有"$x^k$ + 简单区间"这类"公式友好"的函数——**绝大多数积分的定义级计算都是灾难**——这就是 N-L 公式存在的全部理由（下一讲："用导数机器批量处理面积"）。

## 三、有向面积与基本性质

### 3.1 有向面积（疑问 3）

**几何读法**：$f\ge0$ 时 $\int_a^b f$ = 曲边梯形面积；**$f$ 取负的那部分贡献负的**——整体是**代数（有向）面积**：

$$\int_a^bf(x)\,dx=(\text{曲线上方的面积})-(\text{曲线下方的面积}).$$

**两个立威例**：

- $\int_{-1}^1x\,dx=0$（奇函数对称——上下抵消——实验 3 数值）；
- 若问"**几何面积**"（老师强调"面积"而非"积分"时）：$\int_{-1}^1|x|dx=1$（翻上去——有向=几何的修正版）。

### 3.2 基本性质（定义直推——快表）

| 性质 | 内容 | 推导要点 |
|---|---|---|
| 线性 | $\int(\alpha f+\beta g)=\alpha\int f+\beta\int g$ | 和式线性后取极限 |
| 区间可加 | $\int_a^bf=\int_a^cf+\int_c^bf$ | 把 $c$ 加进分割点（**$c$ 在 $[a,b]$ 外也成立**——靠下方约定） |
| 保号 | $f\ge0\Rightarrow\int_a^bf\ge0$ | 和式每项非负 |
| 上下界 | $m(b-a)\le\int_a^bf\le M(b-a)$（$m,M$ 为上下界） | 逐项夹 |
| 约定 | $\int_a^a f=0$；$\int_a^bf=-\int_b^af$ | "有向"的第二层：**区间也有方向** |

（**"有向"的双层含义**：面积可负（$f$ 的符号）+ 方向可反（上下限交换）——两条约定都让"区间可加"在各种位置通用。）

## 四、可积性：深度表与两个反例

### 4.1 深度表（疑问 5 的答案——"学多深"一次说清）

| 结论 | 要求层次 | 依据/说明 |
|---|---|---|
| **闭区间连续 ⇒ 可积** | 知道结论 + **骨架** | 骨架：连续 ⇒ **一致连续**（08 讲 Cantor 定理）⇒ 分割足够细（$\lambda<\delta$）时**每段振幅** $\omega_i<\varepsilon$ ⇒ "上和与下和之差" $<\varepsilon(b-a)$ 任意小 ⇒ 可积（完整的达布准则属数学分析） |
| **有界 + 有限个间断点 ⇒ 可积** | 知道 | 直觉：坏点只剩有限个，其矩形贡献 $\le2M\cdot(\text{坏点邻域总长})$，随 $\lambda\to0$ 压掉；严格版本属数学分析 |
| 无界 ⇒ **不可积** | 会用（反例） | 无界段的矩形可任意大——和式极限不存在 |
| **Dirichlet 函数不可积** | 会用（反例） | 见 4.2——"取点任意性"的反面教材 |
| 黎曼可积的充要条件（达布准则）、测度零 | **知道有这回事** | 数学分析内容（本课程不展开） |

### 4.2 两个反例

**反例 1（无界）**：$f(x)=\frac1x$（$x\ne0$）、$f(0)=0$ 在 $[0,1]$ 上：含 $0$ 的段上矩形可任意大（取 $\xi_i$ 靠近 $0$）——不同取点给不同和 ⇒ 不可积。

**反例 2（Dirichlet——"取点任意性"的死刑演示）**：

$$D(x)=\begin{cases}1,&x\ \text{为有理数}\\0,&x\ \text{为无理数}\end{cases}$$

在 $[0,1]$ 上：**每段都既含有理点又含无理点**（实数稠密性——01 讲资产）：

- 全取有理点：$S=\sum 1\cdot\Delta x_i=1$（任何分割都是 1！）；
- 全取无理点：$S=0$。

**两个"取法极限"决战**（1 vs 0）——极限与取点有关 ⇒ **不可积** ✓。（它同时说明：可积性定义里"与取点无关"这半句**不是冗余的礼节**。）

## 五、$\int$ 里的 $dx$ 是什么（12/19 讲欠条——正式结清）

### 5.1 三级身份户口本

| 讲次 | 身份 | 内容 |
|---|---|---|
| **12 讲** | **微分** | $dx:=\Delta x$（自变量的微分——"线性标尺"）；$dy=f'dx$ |
| **19 讲** | **记号的一部分** | $\int f(x)dx$ 是整体记号；$dx$"宣告积分变量"（当时按整体记忆） |
| **22 讲（本讲）** | **分割宽度的极限化身** | 黎曼和里 $dx$ 就是 $\Delta x$ 在 $\lambda\to0$ 下的化身：$\int_a^bf\,dx=\lim\sum f(\xi_i)\,\Delta x_i$——**"$f$ 乘上一段无穷小的宽度，累加"** |

**三级的统一读法**（一句话）：**$dx$ 永远是"与 $x$ 方向配套的微小宽度"**——微分里是"标尺刻度"、不定积分里是"待打包的刻度"（19 讲读微分表：$dx$ 被换成 $d(g(x))$——换元时"刻度跟着换"）、定积分里是"极限里的分割宽度"。**同一个角色，三种舞台。**

### 5.2 与微分的关系（"同户口"的兑现——两处实用）

1. **换元的合法性**（20 讲已用、这里说透）：$\int f(g(x))g'(t)dt=\int f(g)\frac{dg}{dt}dt=\int f(g)dg$——**"$g'(t)dt$ 打包成 $dg$"就是微分形式不变性**（12 讲）在积分里的运行——$dx$ 与 $dg$ 是同一户口的两张脸；
2. **定积分的换元预告**（26 讲）：定积分换元时"上下限跟着换"（$x$ 的刻度换成 $t$ 的刻度）——机理同款（刻度变换），26 讲细办。

（**理解深度**：三级身份**要能复述**；$dx$ 的"无穷小宽度"是**非严格的说法**——严格版就是黎曼和定义本身，本讲不引入"无穷小量"这种旧概念。）

## 六、与级数的关系（疑问 6——合法跳过）

$\lim\limits_{\lambda\to0}\sum$ 是"无穷多项相加"吗——**和级数不是一回事**（初学最容易的联想，先掐掉）：

- **级数**（高数下）：**可数无穷项**求和 $a_1+a_2+\cdots$（固定顺序、逐项相加的部分和的极限）；
- **本讲的 $\sum$**：**项数 $n$ 随 $\lambda$ 变动**——"无穷多项"是"越分越多"，而且**值必须与分法无关**（级数只对一种固定的项序负责）。

**真实的关系**（挂名即可）：等分且被积函数"逐段同形"时，黎曼和会与某个级数的部分和长得像——**"积分与级数通婚"的桥属高数下**（Fourier 级数、级数收敛的积分判别法都在桥上）。**本课程只用"黎曼和极限"这一条定义路径**——现在只需记住：**两者长得像，身份不同**（$n$ 是否随 $\lambda$ 动、值是否与分法无关——这两条是照妖镜）。

### 实验 1：$\int_0^1x^2dx$ 的右端点和收敛表

$n=10,100,1000,10^4$：打印黎曼和与 $\frac13$ 的差（观察 $O(1/n)$ 收速）。

（实测，全脚本 0.00 秒跑完，可复跑）：

```
  n =     10: S = 0.38500000, 与 1/3 的差 = +5.17e-02 (理论 ~1/(2n) 级)
  n =    100: S = 0.33835000, 与 1/3 的差 = +5.02e-03 (理论 ~1/(2n) 级)
  n =   1000: S = 0.33383350, 与 1/3 的差 = +5.00e-04 (理论 ~1/(2n) 级)
  n =  10000: S = 0.33338334, 与 1/3 的差 = +5.00e-05 (理论 ~1/(2n) 级)
```

**结论（实测坐实）**：和单调下降趋 $\frac13$，误差逐行恰好是 $\frac1{2n}$ 的结构（$5.17\times10^{-2}\to5.00\times10^{-5}$）——收敛但**不快**（"定义级计算的灾难"的量化预告）。

### 实验 2：三种取点的同趋（$\int_0^1x\,dx$）

$n=10,100,1000$：左端点/右端点/中点的三列和——全部趋 $\frac12$。

（实测）：

```
  n =    10: 左 = 0.45000000, 右 = 0.55000000, 中 = 0.50000000
  n =   100: 左 = 0.49500000, 右 = 0.50500000, 中 = 0.50000000
  n =  1000: 左 = 0.49950000, 右 = 0.50050000, 中 = 0.50000000
```

**结论（实测坐实）**：三列夹向 $\frac12$（左低右高、中点在中间且恒精确）——取点任意性的数值现场。

### 实验 3：有向抵消（$\int_{-1}^1x\,dx$）

$n=10,100,1000$：黎曼和恒 $\to0$（正负面积精确抵消）。

（实测）：

```
  n =    10: 右端点和 = 0.20000000, 中点和 = 0.00000000
  n =   100: 右端点和 = 0.02000000, 中点和 = -0.00000000
  n =  1000: 右端点和 = 0.00200000, 中点和 = 0.00000000
```

**结论（实测坐实）**：右端点和趋 0（$\frac2n$ 级）；中点和恒 0（对称性）——有向面积的实弹。

### 实验 4：不均匀分割反例（$n\to\infty$ 而 $\lambda\not\to0$，和 $\to\frac13\ne\frac12$）

对 $f=x$、$[0,1]$：分割点 $0,\frac12,\frac34,\frac78,\ldots$（段长几何衰减）+ 收尾；取左端点作 $\xi_i$：打印 $n=$ 段数与 $\lambda$（恒 $\frac12$）与和（趋 $\frac13$）。

（实测）：

## 本讲小结

- **定积分=黎曼和的极限**（一个数）：四部曲（分割→取点近似→求和→$\lambda\to0$）；**"无限细"$=\lambda\to0$**（每段都短），**不是** $n\to\infty$（段数多）——**单向蕴含 + 不均匀反例**（"一边无限细一边永远粗"：$n\to\infty$ 而和 $\to$ 错值 $\frac13$）。

### A. 基础（定义与计算）

**A1** 从定义算 $\int_0^bc\,dx$（$c$ 常数）与 $\int_0^bx\,dx$（等分、右端点）。

**参考答案**：
$\int_0^bc\,dx=\lim\sum c\cdot\frac bn=c\cdot b=cb$（和 $=c\cdot\frac bn\cdot n=cb$——常数和式直接精确）。
$\int_0^bx\,dx$：$S=\sum\frac{bi}n\cdot\frac bn=\frac{b^2}{n^2}\cdot\frac{n(n+1)}2\to\frac{b^2}2$。

**A2** 从定义算 $\int_0^1x^3dx$（提示：立方和 $\sum i^3=\left(\frac{n(n+1)}2\right)^2$）。

**参考答案**：
$S=\sum\left(\frac in\right)^3\frac1n=\frac{1}{n^4}\cdot\frac{n^2(n+1)^2}4=\frac{(n+1)^2}{4n^2}\to\frac14$。

**A3** 有向面积：(1) $\int_{-2}^2x^3dx$；(2) $\int_0^1(1-2x)dx$。

**参考答案**：
(1) $x^3$ 是奇函数、区间对称 ⇒ 正负**精确抵消** ⇒ $=0$（也可与 A2 的 $\int_0^1x^3$ 类比放大：$\int_{-2}^2=\int_0^2-\int_0^2=0$）。
(2) $1-2x$ 在 $[0,\frac12]$ 正、$[\frac12,1]$ 负，两块面积相等（对称）⇒ $=0$。

**A4** 判断：(1) "无限细分"就是 $n\to\infty$ 吗？(2) 取点任意性是定义的一部分吗？(3) 有界函数一定可积吗？(4) $\int_a^bf$ 一定是面积吗？

**参考答案**：
(1) **不是**——是 $\lambda\to0$（不均匀分割反例）。
(2) **是**（可积性=极限存在且与取点/分法无关）。
(3) **不一定**（Dirichlet 函数有界不可积）。
(4) **不一定**——是**有向（代数）面积**，可为负、可为零。

### B. 提高（性质与反例）

**B1** 用定义证明线性性质：$\int_a^b(\alpha f+\beta g)=\alpha\int_a^bf+\beta\int_a^bg$（假定两者可积）。

**参考答案**：
任意分割与取点：$\sum(\alpha f+\beta g)(\xi_i)\Delta x_i=\alpha\sum f(\xi_i)\Delta x_i+\beta\sum g(\xi_i)\Delta x_i$（**和式的线性**——逐项展开）。令 $\lambda\to0$：左端趋 $\int(\alpha f+\beta g)$（定义），右端两项分别趋 $\alpha\int f$ 与 $\beta\int g$（**极限的线性**——04 讲）⇒ 两边相等。$\blacksquare$

**B2** 复述"不均匀分割反例"：构造、$\lambda$ 的行为、和的极限值（$\frac13$）与真值（$\frac12$）为何不同（机制说明即可）。

**参考答案**：
**构造**：分割点 $0,\frac12,\frac34,\frac78,\dots,1-2^{-k},\dots$（把左半部分无限细分、右半部分只留粗段），取左端点作 $\xi_i$。
**$\lambda$**：最粗段始终是 $[0,\frac12]$ ⇒ $\lambda\equiv\frac12$ 不趋 0（尽管 $n\to\infty$）。
**和**：几何级数求和 $\to\frac13$（各项 $(1-2^{-j})2^{-(j+1)}$ 的累加）——**为什么错**：粗段的矩形贡献是"以左端点为准的一次估计"，$\lambda\not\to0$ 时这个"系统性偏小"永不被修正，累加成一个**错值**。**结论**：极限的唯一正确驱动量是 $\lambda\to0$。

**B3** Dirichlet 函数为什么不可积？把"取点任意性失败"的机制写清。

**参考答案**：
$D$ 在任意小段内都取到 1（有理点）与 0（无理点）（**稠密性**——01 讲）。对任一分割：全取有理点：$S=\sum1\cdot\Delta x_i=1$；全取无理点：$S=0$。**极限值随取点而变**（1 或 0）⇒ 不满足定义中"与取点方式无关" ⇒ **不可积**。$\blacksquare$

### C. 综合（难题档，允许卡）

**C1** 从定义算 $\int_0^bx^2dx$（一般右端点 $b$——把正文的 $b=1$ 推成一般区间）。

**参考答案**：
$S=\sum\left(\frac{bi}n\right)^2\frac bn=\frac{b^3}{n^3}\cdot\frac{n(n+1)(2n+1)}6\to\frac{b^3}3$（用了 $\frac{(n+1)(2n+1)}{6n^2}\to\frac13$）⇒ **$\int_0^bx^2dx=\frac{b^3}3$**。$\blacksquare$
（**预告 23 讲**：N-L 公式下这题一行：$\frac{x^3}3\big|_0^b=\frac{b^3}3$——"定义级 20 行 vs 公式级 1 行"的对照，就是下一讲的存在意义。）

**C2** 双反例辨析：(a) 自造一例"$n\to\infty$ 但 $\lambda\not\to0$"（与正文反例不同构造）；(b) 说明为什么"有界 + **无限个**间断点"未必可积（Dirichlet 属于此类），而"有界 + **有限个**间断点"却可积（机制）。

**参考答案**：
(a) 例：第 $k$ 步把 $[0,\frac12]$ 等分 $k$ 段、$[\frac12,1]$ 不动：$n=k+1\to\infty$ 而 $\lambda=\frac12$ 恒成立 ✓（任何"某固定段永不细分"的构造都行）。
(b) **有限个间断点**：把每个间断点用小邻域盖住，总长度 $\le\varepsilon$，其矩形贡献 $\le2M\varepsilon$（有界性）随分割极限归零；其余区间上函数连续（可积）⇒ 整体可积。**无限个间断点**：没有"有限个邻域"可盖——如 Dirichlet 的间断点是**全部实数**，任何分割的每段都"坏透"，取点分歧无处躲 ⇒ 不可积。$\blacksquare$

### D. 代码（可跑验证）

**D1** 复刻并扩展实验 1、2、4：(a) $\int_0^1x^2dx$ 右端点和在 $n=100,10^4$ 的值（断言接近 $\frac13$、相对差 $<10^{-3}$）；(b) 三取点在 $n=1000$ 的值（断言三者互差 $<10^{-3}$）；(c) 不均匀反例（断言 $\lambda$ 恒 $\frac12$ 且和接近 $\frac13$ 且与 $\frac12$ 相差 $>0.1$）。

**参考答案**：

```python
import numpy as np

print("(a) int_0^1 x^2 dx, 右端点和")
for n in [100, 10000]:
    i = np.arange(1, n + 1)
    S = np.sum((i / n) ** 2) / n
    print(f"  n = {n}: S = {S:.8f}, 与 1/3 的差 = {S - 1/3:+.2e} (<= 1/n = {1.0/n:.0e})")
    assert abs(S - 1 / 3) < 1.0 / n   # 断言按行绑定收敛率: 误差 ~ 1/(2n)

print("(b) int_0^1 x dx, 三种取点 (n=1000)")
n = 1000
i = np.arange(1, n + 1)
SL = np.sum((i - 1) / n) / n
SR = np.sum(i / n) / n
SM = np.sum((2 * i - 1) / (2 * n)) / n
print(f"  左 {SL:.8f}, 右 {SR:.8f}, 中 {SM:.8f}")
assert max(SL, SR, SM) - min(SL, SR, SM) < 1e-3

print("(c) 不均匀分割反例 (f = x, 左端点)")
S, lam = 0.0, 0.5
for k in range(1, 40):
    x_left = 1 - 2.0 ** (-k)
    dx = 2.0 ** (-(k + 1))
    S += x_left * dx
    if k < 5:
        print(f"  k = {k}: 累计和 = {S:.6f} (lambda 恒 = 0.5)")
print(f"  极限和 ~ {S:.6f}, 真值 1/2 之差 > 0.1: {abs(S - 0.5) > 0.1}")
assert abs(S - 1 / 3) < 1e-9 and abs(S - 0.5) > 0.1
print("[OK] 收敛/取点/反例三组核实通过")
```
