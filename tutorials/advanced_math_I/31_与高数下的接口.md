## 一、开场：收官三问

**问 1**：上册学完了——**下册（高数下）是"另一门课"吗**？

**问 2**：级数（$\sum a_n$）——它和 22 讲的黎曼和、极限是什么关系？

**问 3**："学完就还"是常态——**怎么复习才不白学**？

**答案预告**：

1. **不是**：下册 = 上册的**三种升维**——**加自变量**（一元函数 → 多元函数：偏导、重积分）、**加项数**（有限和 → 无穷和：级数）、**加结构**（方程与向量语言化：动力系统、矩阵解法）。本讲第三节的对照表逐条标坐标。
2. **地基完全相同**：级数的收敛 = **部分和数列的极限**（02 讲的 ε-N **原封不动**）；级数是"离散版的积分"——与黎曼和是"反方向的亲兄弟"（第四节讲清"像"与"不像"）。
3. 用**三层资产分级**（第五节）：**地基**（不能松）／**主力工具**（要常练）／**定理武器**（要能默写）——每一层给复习动作；照单执行即可。

## 三、一元 → 多元：对照表（接口预览）

> **纪律声明**：本节每个名词只给"**是什么（一句话）+ 对应本课程哪一讲 + 现在只需知道这么多**"——**不深挖**。它们是你的"坐标"，不是这一讲的任务。

### 3.1 导数 → 偏导数、全微分、方向导数、梯度

| 上册（讲次） | 下册形态 | 一句话是什么 | 现在只需知道 |
|---|---|---|---|
| 导数（09） | **偏导数** $\partial f/\partial x$ | 有多个自变量时，**按住其他变量当常数**、只对其中一个求导——**就是上册的导数换个场景** | 记号 $\partial$；会读"偏" |
| 微分（12） | **全微分** $df=f_xdx+f_ydy$ | "线性主部"在多变量下的推广（12 讲的账本换成多栏） | 知道 $df$ 是各偏导乘各自微分的和 |
| 方向导数 | 沿**任一方向**的变化率 | "朝某个方向走，函数变化多快" | 知道有这回事 |
| **梯度**（向量） | $\nabla f=(f_x,f_y)$ | 把所有偏导打包成的**向量**——指向"最陡上升方向" | **这是线代与微积分的第一个正式接口**：梯度是向量、方向导数 = 梯度·方向单位向量（内积——线代 13 讲） |

**一句话接口（疑问 5 的第一半）**：**多元的"导数"不再是一个数，而是一组数（向量/矩阵）**——向量的语言由线代提供（本仓库的线代教程第一章就位；"梯度是向量"从这里开始）。

### 3.2 定积分 → 重积分（兑现 27 讲的承诺）

| 上册（讲次） | 下册形态 | 一句话是什么 | 现在只需知道 |
|---|---|---|---|
| 定积分（22） | **二重积分** $\iint_D f\,dA$ | 在**平面区域** $D$ 上累加（不只是 $x$ 轴上的区间） | **它的"语言"你已经在 27 讲立过**：$dA$=面元、"$\int_\Omega(\cdots)dA$"=区域累加——**27 讲当时说过"这是高数下的内容，31 讲接口会提"，就是这里**：下册把它正式化（$\iint$ 记号、富比尼定理＝"先条内后条间"的正式版） |
| 元素法（26） | **照搬到多维** | 面积→体积、弧长→曲面面积、功→更复杂的物理量——**一台引擎、继续通用** | 26 讲的"局部误差 $o$"判据在多维逐字成立 |
| 二阶矩（27） | **转动惯量的体版本** | 27 讲的 $I=\int y^2dA$ 升为 $\iiint y^2\,dV$ | 知道"矩语言"在多维继续用 |

### 3.3 微分方程 → 偏微分方程与动力系统（疑问 4）

| 上册（讲次） | 下册/后续形态 | 一句话是什么 | 现在只需知道 |
|---|---|---|---|
| 一阶/二阶方程（28–30） | **偏微分方程（PDE）** | 未知函数含**多个自变量**的方程（波动、热传导、拉普拉斯——三个经典名字） | 知道有这回事、它们就是"物理三大方程" |
| 特征方程（29） | **矩阵解法与稳定性** | 方程组 $\mathbf x'=A\mathbf x$：解的形状由**矩阵 $A$ 的特征值**决定（29 讲特征方程的矩阵版） | **线代接口第二接口**：特征值 ↔ 常系数方程 |
| 欧拉法（28） | **数值解家族** | 欧拉法是一切数值解法的祖型（实际用 Runge–Kutta 等更精的版本） | 28 讲实验的那个小循环就是它的最小形态 |

### 3.4 其他移植（一句清点）

- **中值定理**（13–14）：多元版存在（沿路径的版本）——知道有这回事；
- **泰勒**（15）：多元版用**二次型**表达（$\frac12\mathbf h^T H\mathbf h$——海森矩阵）——**线代接口第三接口**；
- **极值**（16）：多元极值的二阶判据 = 海森矩阵的正定性（16 讲判据的矩阵版）；**约束极值** = 拉格朗日乘数法（挂名）；
- **曲线**：上册的"曲线"（11 讲参数方程）→ 下册的**向量值函数与空间曲线**（向量语言全套接管）。

## 四、级数：把"有限"推向"无限"（疑问 2）

### 4.1 级数是什么

> **级数** $\sum_{n=1}^\infty a_n$：把无穷多个数**依次相加**——"加出来的结果"定义为**部分和数列** $S_N=a_1+\cdots+a_N$ 的极限（有极限称**收敛**，极限值记作级数的和）。

**与上册的关系（两句）**：
- **"收敛"的判定标准 = 02 讲的 ε-N**（部分和 $S_N$ 是数列！）——**级数的地基就是你已经练过的 ε-N**，没有任何新语言；
- **像不像黎曼和**：**像**（都是"有限和 → 取极限"），**但方向不同**——黎曼和是"**同一定积分的近似**，$n$ 越大越准"；级数是"**把无穷多项真的加起来**，先问它到底收不收敛"。更深一层的对照：$\sum$ 与 $\int$、差分与微分、求和与积分——**级数是"离散版的积分"**（一个值得记一辈子的对偶）。

### 4.2 两个代表作（实验 1 会把它们跑成表）

- **收敛的代表**：$\sum\frac1{n^2}=1+\frac14+\frac19+\cdots=\frac{\pi^2}6$（欧拉的著名结果——**收敛**；部分和以 $O(1/N)$ 的速度爬向 $\frac{\pi^2}6$——**慢收敛**，与 22 讲"矩形法 O(1/N)"是同一条消息）；
- **发散的代表**：$\sum\frac1n$（调和级数）——**发散**（部分和以 $\ln N$ 的速度缓慢增长——"每加一项虽小但永不停"）。

### 4.3 幂级数与泰勒（15 讲欠的完全形态）

15 讲的泰勒多项式走到"无限项"就是**泰勒级数**："15 讲的余项 $R_n\to0$ 吗"这个悬问，正是"泰勒级数收敛到 $f$ 吗"——**泰勒公式的完全形态在下册**（知道有这回事；本课程 15 讲给的"有限版"永远是考试主力）。

### 4.4 傅里叶级数（挂名）

用 $\sin/\cos$ 的无穷组合"拼"出函数（信号处理的数学心脏）——**知道有这回事**。

> **本节唯一要带走**：**级数不需要学新的"极限语言"——它就是 02 讲 ε-N 的应用题**。

## 六、收官实验：三个回环（`scripts/lec31-01_verify_interfaces.py`）

**为什么做这三个**：它们分别**回望**本课程的三块地基——02 讲的 ε-N、15 讲的泰勒、积分的收敛观——**用机器再跑一遍**，作为收官仪式。

### 实验 1：级数的收敛肖像（回望 02/22）

\sum\frac1{n^2}\to\frac{\pi^2}6\approx1.6449$（部分和，$N=10^2,10^3,10^4,10^5$）；对照 $\sum\frac1n$ 的部分和（$N=10^2,10^3,10^4$——**只缓慢增长、不停**）。

（实测，全脚本 0.11 秒跑完，可复跑）：

```
  sum 1/n^2, N =    100: S = 1.6349839002, pi^2/6 - S = 9.95e-03
  sum 1/n^2, N =   1000: S = 1.6439345667, pi^2/6 - S = 1.00e-03
  sum 1/n^2, N =  10000: S = 1.6448340718, pi^2/6 - S = 1.00e-04
  sum 1/n^2, N = 100000: S = 1.6449240669, pi^2/6 - S = 1.00e-05
  sum 1/n,   N =    100: S = 5.187378 (log 增长, 发散)
  sum 1/n,   N =   1000: S = 7.485471 (log 增长, 发散)
  sum 1/n,   N =  10000: S = 9.787606 (log 增长, 发散)
```

**结论（实测坐实）**：$1/n^2$ 的误差列 $9.95\times10^{-3}\to10^{-3}\to10^{-4}\to10^{-5}$——**每档 $N$ 缩 10 倍、误差恰缩 10 倍**（$O(1/N)$ 逐位）；$1/n$ 列 $5.19\to7.49\to9.79$——**每档 $N$ 增 10 倍、和也只增 $\ln10\approx2.303$**（实测差 2.298/2.302——"永不停但每步都在变慢"的数值肖像）。

### 实验 2：泰勒级数部分和（回望 15）

$\sin x$ 在 $x=1$ 处的泰勒部分和（阶数 $1,3,5,7,9,11$）与 $\sin 1$ 的误差表。

（实测）：

```
  order 1: S = 1.000000000000, err = 1.59e-01
  order 3: S = 0.833333333333, err = 8.14e-03
  order 5: S = 0.841666666667, err = 1.96e-04
  order 7: S = 0.841468253968, err = 2.73e-06
  order 9: S = 0.841471009700, err = 2.49e-08
  order 11: S = 0.841470984648, err = 1.60e-10
```

**结论（实测坐实）**：误差每两阶降约 1.5–2 个数量级；**关键账**：9 阶误差 $2.49\times10^{-8}\approx$ 下一项 $\frac1{11!}=2.505\times10^{-8}$、11 阶误差 $1.60\times10^{-10}\approx\frac1{13!}=1.605\times10^{-10}$——**误差被下一项接管**（15 讲"余项主项"的完全呼应；**一条诚实的修正**：预写本节时预判"9 阶达机器精度"——实测 9 阶只到 $10^{-8}$ 级，加两阶（11 阶）到 $10^{-10}$ 级；数字与下一项对仗得更漂亮）。

### 实验 3：ε-N 的机器仪式（回望 02）

对 $a_n=\frac1n$："是否存在 $N$ 使 $n>N$ 时 $|a_n|<\varepsilon$"——机器**找出最小 $N$**：$\varepsilon=10^{-2},10^{-3},10^{-6}$ 分别给出 $N=101,1001,10^6+1$。

（实测）：

```
  eps = 1e-02: N = 101 (= floor(1/eps)+1 = 101)
  eps = 1e-03: N = 1001 (= floor(1/eps)+1 = 1001)
  eps = 1e-06: N = 1000001 (= floor(1/eps)+1 = 1000001)
```

**结论（实测坐实）**：$N=\lfloor1/\varepsilon\rfloor+1$ 逐位——**注意这个"$+1$"的来历**：$n=100$ 时 $1/100$ 恰好**等于** $10^{-2}$，而判据是**严格小于**（不满足）——**"$<$"与"$\le$"在整除点上的差别**（与 16 讲"等号四格"、22 讲"$\lambda$ 与 $\max$"的边界纪律同族）；02 讲"对手出 $\varepsilon$ 我出 $N$"的对抗游戏，机械执行版。

### D. 代码（可跑验证）

**D1** 复刻实验 1 与 2：(a) $\sum_{n=1}^N1/n^2$ 在 $N=10^4,10^5$ 与 $\pi^2/6$ 的差（断言 $<10^{-4}$ 与 $<10^{-5}$）；(b) $\sin 1$ 的泰勒部分和到 9 阶，断言与 $\sin 1$ 差 $<10^{-9}$。

**参考答案**：

```python
import math

import numpy as np

print("(a) partial sums of 1/n^2 vs pi^2/6")
target = np.pi ** 2 / 6
for N in [10**4, 10**5]:
    S = np.sum(1.0 / np.arange(1, N + 1) ** 2)
    print(f"  N = {N}: S = {S:.10f}, 差 = {target - S:.2e}")
S4 = np.sum(1.0 / np.arange(1, 10**4 + 1) ** 2)
S5 = np.sum(1.0 / np.arange(1, 10**5 + 1) ** 2)
assert target - S4 < 1e-4 and target - S5 < 1e-5

print("(b) Taylor partial sums of sin at x=1")
x = 1.0
s = 0.0
term = x
for k in range(1, 12, 2):   # 阶数 1..11 的项
    s = s + term
    print(f"  order {k}: S = {s:.10f}, err = {abs(s - math.sin(x)):.2e}")
    term = -term * x * x / ((k + 1) * (k + 2))
assert abs(s - math.sin(x)) < 1e-9
print("[OK] 级数收敛与泰勒部分和全部核实")
```
