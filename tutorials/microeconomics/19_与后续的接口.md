## 引子：把工具箱倒出来清点

学完十八讲，你的工具箱大概是这样的状态：**单件都见过，但有点散**——这很正常，因为知识本来就是"按讲次装货"的，而要"按问题取货"，需要一张**地图**。

这张图要回答两类问题（也正是一直悬着的两个）：

- **横向**：这些东西是怎么**咬合**起来的？（价格怎么定 → 定出来的结果好不好 → 不好的话管不管 → 分配又怎样——§1 的四层）
- **纵向**：每一个概念**往上往下**接什么？（就业率接宏观、税负分析接财政、现值接金融——§2、§3）

先给一条穿线用的口诀（它会在 §1 反复出现）：**"谁在选、选什么、约束是什么、边际怎么平"**——十八讲的每一站，都是这句话的一次具体演出。

## 1. 全景地图：十八讲拼成的一台机器

### 1.1 四层结构：从个体到市场的四次放大

把十八讲按"放大倍数"排成四层（每层标出讲次与它回答的问题）：

```
第 0 层  语言与世界观          01–02
   十大原理 / 权衡·机会成本·边际·激励 / 比较优势与贸易
   回答：经济学用什么语言说话？

第 1 层  个体怎么选             11–12、17
   企业：生产函数 MP、成本七件套、MR = MC、停产与退出
   消费者：预算线、无差异曲线、MRS = 价格比、两效应
   回答：一个买者 / 一个卖者，在约束下怎么算最优？

第 2 层  市场怎么定             03–04、12–15
   供求三步法、弹性；四谱系（竞争/垄断/垄断竞争/寡头）；
   要素市场（VMPL、工资、地租、现值）
   回答：许多个体凑在一起，价格与数量落在哪？

第 3 层  结果好不好、要不要管   05–10、16、18
   CS/PS/TS 账本、价格管制、税与 DWL、国际贸易、外部性、
   公共物品与税制、不平等与贫困、三前沿（信息/政治/行为）
   回答：均衡的结果算不算"好"？政策动了哪条曲线、代价落在谁头上？
```

一个记忆锚点：**第 1 层是"个体边际算最优"，第 2 层是"个体相加成市场"，第 3 层是"市场结果上账本"**——做题时先问自己"这题在哪一层"，工具立刻浮现。

### 1.2 三条暗线：贯穿十八讲的"三股绳"

复习时最怕"一章一章顺背"；改按三条暗线**串珠**，效率翻倍：

**暗线一·边际思维（"边上那一个"家族）**：

| 站点 | 内容 | 讲次 |
|---|---|---|
| 出生地 | "理性人考虑边际量"（十大原理之三） | 01 |
| 生产 | 边际产量 MP 递减、MC 曲线 | 11 |
| 决策 | **MR = MC**（竞争版 P = MC；停产看 minAVC） | 12 |
| 垄断 | MR < P 的价格效应；MR = a − 2bQ | 13 |
| 博弈 | 古诺的"最佳反应"（对方的量已定，我的边际怎么算） | 14 |
| 要素 | **VMPL = MP × P**；雇工规则 VMPL ≥ W | 15 |
| 消费者 | **MUx/Px = MUy/Py**（最后一块钱原则） | 17 |

一句话总纲：**"让每一个边际的收益向成本看齐"**——从第 01 讲到第 17 讲，这句话换了七身衣服。

**暗线二·均衡思维（"没人愿意单方面再动"家族）**：

- 供求均衡（03）：价格动到不剩过剩/短缺；
- 竞争长期均衡（12）：进出挤到零经济利润；
- 纳什均衡（14）：没人愿单方面改策略（古诺 (30,30) 是它的算术版）；
- 劳动市场均衡（15）：W 与 L 在供需交点被"碰"出来；
- 消费最优（17）：相切——再动任何一步都变差。

一句话总纲：**"均衡 = 各方都懒得再动的位置"**（它可以是好均衡，也可能是坏均衡——囚徒困境的 60/60 提醒过我们）。

**暗线三·效率与平等（"账本与政策"家族）**：

- 账本诞生（06）：CS/PS/TS，总剩余最大化；
- 扭曲的度量（07–09）：DWL = "被吓退的交易"；关税、外部性同款账；
- 政策的两轴（10、16）：效率轴（蛋糕大小）与公平轴（蛋糕切法）永远分开说；
- 前沿的补丁（18）：信息、政治、行为——都是"在真实条件下重算账本"。

一句话总纲：**"先算总账变大还是变小，再谈谁多谁少"**——辨析题的分全在这条线上。

## 2. 宏观接口：新闻词里的微观影子

### 2.1 微观与宏观的关系（一段说清）

> **宏观经济学研究经济"总水平"**——总产出、总物价、总就业；**微观经济学研究个体**。两者不是两栋楼，是**同一栋楼的不同楼层**：宏观的对象（GDP、物价、失业）本就是千千万万个微观决策**加总**出来的。

一个诚实的补充（预置给宏观课）：加总**偶尔会出"合成谬误"**——一个人看戏站起来能看得更清楚，所有人站起来谁也没更清楚；"对个体的好建议"未必"对总体成立"。这是宏观需要独立工具的原因，也是它与微观接壤的地方。

### 2.2 新闻词 → 微观影子（对照表）

| 新闻词 | 一句话是什么 | 它的微观影子（讲次） |
|---|---|---|
| **GDP** | 一国一年生产的全部最终产品与服务的市场价值 | "市场价值怎么加总"与循环流量（01）；"生产与成本"（11） |
| **通胀** | 物价**总水平**持续上涨 | 单个市场的供需波动（03）；"印钞太多→通胀"（01 第十原理） |
| **失业** | 想工作而没工作 | 劳动市场的超额供给（15）；最低工资的效应（05） |
| **利率** | 资金的价格 | 现值与贴现（15 的 R/r 就是它的第一课）；资本需求（15） |
| **财政政策** | 政府的收与支 | 税负归宿与 DWL（05、07）；税制两轴与公共物品（10） |
| **贸易差额** | 出口与进口的差 | 国际贸易三级账与关税四区（08） |
| **经济周期** | 总产出的波动 | 供需冲击（03）在加总层的放大（宏观课的主场） |

读这张表的方式：**宏观课的每个大词，你手里都已经有它的微观零件**——宏观卷要教你的是"零件加总后的新规律"。

### 2.3 读报告、做判断的"四把刀"（链条第 4 问正式作答）

拿到一条财经新闻或一份行业报告，按顺序问四刀：

1. **三步法刀**（03）：**什么变了 → 哪条曲线动了 → 新均衡落在哪**？（"xx 政策出台"= 在移动哪条线？）
2. **账本刀**（06）：**谁受益、谁受损**？（CS/PS 各动了几格？）
3. **激励刀**（01/12/15）：**规则或价格变了，边际上的行为会怎么调整**？（人会往哪边挪？）
4. **两轴刀**（06/10/16）：**这是效率问题（蛋糕大小）还是分配问题（切法）**？（别混着吵。）

**做商业判断**的对应工具箱（一句族）：定价与竞争策略（12–14）、成本与规模（11）、进入/退出与长期均衡（12）、信息设计与信任机制（18）、政策环境预判（05–09 的框架）。

最后一段诚实提醒（第 18 讲"场域折扣"的延伸）：**模型是基准，现实有摩擦**——报告里的数字是"倾向性结论的素材"，不是"扳机"；把四把刀当思考的骨架，别当算命的水晶球。

## 综合演练（横贯全课程，5 题）

> 这是整套课程的"总检验"：每题都要动用多讲工具。答案在题后——**每题都是"温馨提示"级的完整推导，请先自己走一遍**。

**Q1. 政策全链·一次征税的完整旅程**：某市场：需求 $P = 100 - Q$、供给 $P = 20 + Q$；政府每单位征税 t = 10。

(1) 征税前均衡；
(2) 税后：买方价、卖方价、成交量；
(3) 税收收入、DWL；
(4) 归宿：买、卖双方各承担多少？（两线斜率对称说明什么）

**参考答案**：
(1) $100 - Q = 20 + Q \Rightarrow Q = 40$、$P = 60$。
(2) 税楔：$100 - Q = (20 + Q) + 10 \Rightarrow Q = 35$；买价 $P_b = 100-35 = 65$、卖价 $P_s = 20+35 = 55$（价差 10 ✓）。
(3) 收入 = $10 \times 35 = 350$；DWL = ½×10×5 = 25（Q 从 40 缩到 35）。
(4) 买方多付 65−60 = 5、卖方少收 60−55 = 5——**对半**；因为两条线的"陡度"（弹性）对称：**归宿跟着弹性走，谁的线更陡谁担得多**（05/07 的规矩）。

**Q2. 结构全链·同一行业四种命运**：某行业：需求 $P = 80 - Q$、$MC = 20$（常数，无固定成本）。

(1) 若是完全竞争：产量与价格？
(2) 若一家垄断：两步口诀求产量价格；算 DWL；
(3) 若是两家古诺：求各家产量、总产量与价格、各家的利润；
(4) 用一句话把三种结果的"谱系位置"排出来。

**参考答案**：
(1) $P = MC$：$80 - Q = 20 \Rightarrow Q = 60$、$P = 20$。
(2) $MR = 80 - 2Q = 20 \Rightarrow Q = 30$；$P = 80-30 = 50$；DWL = ½×(60−30)×(50−20) = **450**。
(3) 反应函数：$q_1 = (80 - 20 - q_2)/2 = (60 - q_2)/2$；对称解 $q_1 = q_2 = 20$；$Q = 40$、$P = 40$；每家利润 = $(40-20)\times 20 = 400$。
(4) 产量 60 > 40 > 30、价格 20 < 40 < 50——**竞争 > 古诺 > 垄断**，古诺居中（14 讲的三方对照同款结论）。

**Q3. 要素与分配·旅游小镇的十五年**：某小镇因旅游走红。

(1) 用要素市场的工具解释："民宿管家"的工资与从业人数会怎么变？（要出现 VMPL）；
(2) 十五年后：一条街上的民宿老板收入差出几十倍、基尼上升。请给两条"零件"解释 + 一条"不能只看基尼"的理由；
(3) 镇里想给低收入从业者"每月补贴 500、每赚 1 元补贴减 0.5"——隐含边际税率多少？对他"多接活"的激励有何含义？

**参考答案**：
(1) 游客增多 → 民宿服务的价值上升 → 劳动需求（VMPL 曲线）**右移** → 均衡上**工资与就业同升**（15 讲"苹果涨价"同款传动）。
(2) 零件解释（任两条）：人力资本差异（会运营者 vs 普通管家——16 讲零件一）；超级明星现象（"网红民宿"赢家通吃——零件五）；补偿性差别也可（旺季熬夜/投资风险）。不能只看基尼的理由：**得快照×流动性一起看**（16 讲陷阱四：今天的底层会不会换人），外加实物转移不计等口径问题。
(3) 隐含边际税率 = 1 − 0.5 = **50%**；含义：**每多赚 1 元、兜里只多 5 毛**——"补贴退坡"会削弱"多接活"的激励（底线与激励的两难，16 讲的旋钮）。

**Q4. 消费者与福利·同一件事的两种讲法**：某商品降价（15 → 10 元），某消费者多买了。

(1) 用 17 讲的语言解释"为什么多买"（出两个效应的名字）；
(2) 用 06 讲的语言解释"他因此更爽了"（出术语）；
(3) 用一句话说清两种讲法的连接点。

**参考答案**：
(1) **替代效应**（相对变便宜，用奶茶替代其他）+ **收入效应**（实际购买力上升）；两条腿加起来 = 多买（+6 杯的分解账就是模板）。
(2) 价格下降 → **消费者剩余增加**：需求曲线下方、价格上方的"三角形/梯形"变大了。
(3) 连接点：**需求曲线本身就是"每个价格下的最优购买量"**（17 讲推出来的）——所以 17 讲的"行为变化"与 06 讲的"剩余变化"是同一件事的两个镜头（行为 vs 福利货币化）。

**Q5. 前沿综合·一个平台的三个麻烦**：某二手交易平台遇到三件事：

(a) 用户抱怨"好货越来越难卖、骗子货越来越多"；
(b) 商户们集体抗议费率新规，平台让大家投票选方案 A/B/C，结果"谁都能赢谁都能输"；
(c) 平台上线"划线原价 + 倒计时折扣"后，转化率大涨。

请对每件事：(1) 点名对应的前沿机制；(2) 给一句"诊断"；(3) 给一句"药方或提醒"（至少用到一次第 14 讲或第 15–16 讲的旧工具）。

**参考答案**：
(a) **信息不对称／柠檬市场**：买家只按平均质量出价、好货退出——螺旋正在发生。药方：建评价与信用体系（**重复博弈的工程化**——14 讲工具）或平台质保（信号：成本好坏有别）。
(b) **康多塞循环**：三方案两两对决可能成环、"先投哪场"决定赢家——"多数意志"并未唯一存在。提醒：固定议程与规则（或改用针对单一维度的方案）比"多轮投票"更稳；注意议程问题本身也是一种"操纵"。
(c) **锚定 + 损失厌恶（含现时偏好）**："原价"是无关参照锚、"倒计时"把"不买"框成持续损失——偏差被系统性利用。提醒：这在合规与伦理上处于灰色地带（第 18 讲政策接口的"消费者保护"正为此存在）；对消费者则是"识别套路"的练习。
