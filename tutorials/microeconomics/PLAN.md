## 一、目标与读者画像

### 课程目标（学完能做什么，行为化）
- 能从零把一套正经的微观经济学原理考核（大学期末 / AP 同类水准）做下来：概念选择题、计算题（均衡、弹性、成本、利润、福利、税收、博弈）、画图分析题（曲线移动、剩余区域、无谓损失）、简答题（机制解释、政策评估）。
- 对每个核心模型说清"它是什么 + 它在解释哪一类现象 + 它的前提与边界 + 什么时候调用它"，而不是背结论。
- 能用 Python 把模型跑成具体数字：均衡求解、弹性、剩余与无谓损失、成本曲线、利润最大化、垄断定价、古诺均衡、效用最大化和替代-收入效应、基尼系数、柠檬市场——每个实测数字都能在 `scripts/` 复跑。
- 能读懂财经新闻与政策讨论里的经济学论证：识别激励、得失方、效率与公平的权衡，识别常见话术错误。

### 读者是哪一种（决策记录，2026-10-01 对齐拍板）
**完全零基础重学**：
- 没系统学过经济学；有生活常识与朴素直觉（"价格涨了买得少"这类），但不知道"经济学怎么作为一个体系思考"。
- 这类读者**不知道自己不知道什么**——没写出来的东西他问不出来，只能靠作者地毯式覆盖兜底。原则 10（地毯式覆盖优先于组织优雅）是第一纪律。
- 数学：有高中代数底子；微积分**不假设熟稔但可调用**（用户拍板"不刻意躲着高数"）——写作判据是**"怎么理解深且不绕就怎么讲"**：能用一行导数说清的，不用三段文字绕；图形直觉更直接的（供需移动、福利区域），不硬算。涉及微积分处就地给最小说明或"微积分视角"小框。

### 数学深度（决策记录 · 已拍板：混合）
- 正文主体按原理课风格：图形 + 直觉 + 说人话，关键处（边际分析、MR=MC、MRS=价格比、无谓损失几何、最优化的拉格朗日视角）附**"微积分视角"小框**，一步到位不绕路。
- 考试式答题仍可只靠图形与代数；微积分框是"把话说透"的补充，不是答题门槛。
- 反例纪律：**不许"刻意躲着高数然后更绕"**（例如用大段文字绕"边际=导数"），也不搞全篇微积分化。

### 例子风格（决策记录）
- **直觉 / 手算例题 / Python 数值实验 三者并重**，与概率统计课程一致；经济学的手算例题=考试风格题（均衡、弹性、成本表、福利区域）。

### 数值实验方向（初拟，写作时细化并实测）
- **01**：边际决策数值化（给定边际收益/边际成本表找最优决策，对比"平均思维"的错误）；PPF 数值表与机会成本
- **02**：比较优势与贸易收益（两人两品机会成本、专业化前后消费对比、贸易价格区间扫描）
- **03**：线性供需求解均衡 + 需求/供给移动的比较静态（对照表）
- **04**：中点法弹性计算、点弹性沿直线扫描、总收入随价格变化（验证"弹性>1 降价增收"）
- **05**：价格上限/下限的短缺过剩计算；税收楔子求解与税负分担（不同弹性对比）
- **06**：CS/PS 积分计算；扫描不同产量验证"均衡=总剩余最大"
- **07**：不同税率下无谓损失计算表（验证平方律量级）；税收收入-税率曲线（拉弗）
- **08**：出口国/进口国福利分解；关税各区域数值计算（含两块无谓损失）
- **09**：负外部性：市场均衡 vs 社会最优 + 庇古税计算；正外部性补贴对称案例
- **10**：公地悲剧（过度放牧：私人最优 vs 社会最优数值求解）；搭便车支付矩阵枚举；税制算术（平均/边际税率）
- **11**：成本表计算（TC/ATC/AVC/MC）；扫描验证 MC 过 ATC 最低点；规模经济区间判定
- **12**：MC=P 求最优产量、利润曲线扫描验证、停产条件、长期均衡 P=min ATC
- **13**：线性需求下 MR 数值验证（差分 vs 解析）；垄断 vs 竞争的 DWL 计算；价格歧视福利对比
- **14**：古诺反应函数迭代收敛表（与合谋对照）；囚徒困境支付矩阵枚举纳什均衡
- **15**：VMPL 计算与劳动需求曲线；均衡工资求解；产品价格冲击下的需求移动
- **16**：洛伦兹曲线与基尼系数计算（两个收入分布对比）；工资差别的简单算术（人力资本/明星效应）
- **17**：Cobb-Douglas 效用最大化（数值验证 MRS=价格比）；替代效应/收入效应数值分解
- **18**：柠檬市场迭代崩溃模拟；中位投票人定理数值演示（理想点分布→政策收敛）

### 3.2 关键机制"完整形态六问"决定登记

> 六问：① 标准形态+每部分自由度 ② 嵌套/组合 ③ 被控/外部打断 ④ 重复与共存 ⑤ 规范：好习惯/坏习惯 ⑥ 相邻边界与对比。只登记容易漏、且需要当场拍板处理方式的机制。

- **供需模型（03）**：① 标准图：向下需求 + 向上供给 + 交点；每段自由度：函数形式任意、可线性可曲线；② 可组合：任何市场都能套，但每次要检查前提；04/05/07/08 全搭建在它上面；③ 被谁控制：外生冲击移动曲线、均衡点自动调整，无人"定"价；④ 重复与共存：供需可独立移动、同时移动；⑤ 规范：画图纪律（轴、标注、实/虚线）、三步法纪律；⑥ 边界：价格粘性、非完全竞争、信息不对称时结论打折（09/13/18 回收）。
- **税收分析链条（05 → 07 的分工）**：05 讲"税收如何改变均衡、谁承担"（楔子、归宿）；07 讲"税收的福利代价"（无谓损失、拉弗）。**两讲间必须显式接力**，不得互相重复或互挖坑：05 结尾留钩子，07 开头回收。
- **成本曲线关系（11）**：① 七条成本概念各司其职（FC/VC/TC/AFC/AVC/ATC/MC）；② MC 与 AVC/ATC 的交点关系是"平均与边际"的一般规律（12/13/15 复用）；③ 由生产函数推导而非背诵；④ 短期 U 形 vs 长期包络；⑤ 规范：先表格后曲线；⑥ 边界：规模经济与边际递减是两回事（短期 vs 长期）。
- **MR=MC 规则（12 与 13 的共性）**：一般规则其实不止竞争企业用——12 讲在"MR=P"特例下引入，13 讲推广到"MR<P"的一般情形。**必须让读者看到这是同一条规则**（12 讲明确提出"这是一条通用规则，后面会推广"），防止把 MR=MC 当成垄断专属。
- **博弈论基本框架（14）**：① 要素：参与者、策略、支付；② 支付矩阵写法与读法；③ 纳什均衡 = "给定别人不动，我没动力单方面改策略"；④ 与囚徒困境的关系（纳什均衡 ≠ 集体最优）；⑤ 规范：先找"最优反应"再找交点；⑥ 边界：一次博弈 vs 重复博弈（合作可能性）、与市场结构的映射（古诺/合谋）。
- **无差异曲线（17）**：① 标准形态：向下倾斜、凸向原点、不相交、越远越高四性质；② 与预算线组合定最优（相切）；③ MRS = 斜率 = 意愿交换比；④ 与需求曲线的联系（替代/收入效应分解）；⑤ 规范：先画预算线再叠偏好；⑥ 边界：与"等产量线"同构（不写生产理论，但可提一句）。
- **"模型与假设"总纪律（01 立，全课程回收）**：经济模型是"简化地图"；每个模型学完后必须回答"它假设了什么、什么时候会不好用"。01 讲立此纪律，后续每讲在小结处回收（03 的 ceteris paribus、11 的递减性假设、14 的理性人假设、17/18 的理性质疑）。

- 到 15：以上 + 生产要素与派生需求、VMPL（MP×P）与雇工规则（边际非总量防错）、劳动需求三移位、劳动供给（闲暇机会成本/替代与收入效应/可能后弯）、劳动均衡 (60,5) 与产品价格传动（涨价→工资就业同升）、土地（供给固定→地租由需求定；纯地租税不扭曲）、资本（租金 vs 买价、现值 R/r、利率反向）、几何级数闭式。
- 到 16：以上 + 工资差别五零件（人力资本/补偿性差别/能力努力运气/信号/超级明星；效率工资）、歧视经济学（取证纪律、三位置、竞争清洗机制的两方向实验、存续三抓手）、洛伦兹曲线与基尼系数（面积比、手算梯形法 0.312/0.444）、四个度量陷阱（实物转移/生命周期/暂时收入/流动性）、贫困率口径、三工具代价表、负所得税退坡旋钮（隐含税率 50%/30%）、三种立场与两本账。
- 到 17：以上 + 预算约束（斜率=价格比、平移与旋转）、效用（序数）与无差异曲线四性质、MRS（=MUx/MUy，递减）、相切最优（MRS=价格比 ⟺ MUx/Px=MUy/Py 等边际）、拉格朗日视角（λ 含义）、两效应数值分解（补偿预算线；+6=+2.7+3.3）、方向表（正常/劣等/吉芬）、需求曲线向下的终极解释、劳动供给后弯正式作答（Cobb-Douglas 恒 8 小时）、理性假设裂缝表（通 18）。
- 到 18：以上 + 信息不对称与柠檬市场（迭代崩溃实验 10→5→3→2→1）、逆向选择 vs 道德风险（前/后定位）、信号与筛选（成本差原则）、制度解药族（认证/声誉/法律）、康多塞循环（对决 2:1×3 与议程操纵）、中位投票人定理（单峰偏好；三回合趋同 51-50/40-61/51-50）与两推论、政治场里的经济人、行为经济学三偏差（锚定 10/65→25%/45%；损失厌恶 λ≈2.25、丢 100≈得 506、前景理论价值函数；过度自信/现时偏好/禀赋效应）、政策三件套（默认/助推/保护）、行为效应的场域折扣。
- （后续每讲交付时顺延，格式同上。）

## 四、每讲认知思维链条（学习者第一人称 · 五段骨架，写法见 wiicufs/reference.md）

> 每条五段：**我带着什么来 / 第一反应 / 我会依次卡住的疑问（4–8 个，`[→]` 标计划中的答题位置，交付该讲时校正为真实小节）/ 学完后 / 钩子**。
> 硬约束：第一人称；疑问按遇到顺序排列；四类必含——**元问题迷失**、**旧直觉冲突**、**边界**、**防错**。

- **01 经济学十大原理与经济学思维**
  - 我带着什么来：没系统学过经济学；在我印象里"经济学"=研究钱、炒股、财经新闻里通胀失业那些大事；"供求关系""看不见的手"这些词听过但说不清。
  - 第一反应：十大原理听起来像一堆口号——"人面临取舍"这种也要学？是不是把常识说得复杂点就叫科学？
  - 我会依次卡住：
    - "（元问题）经济学到底研究什么？我该用什么眼光看世界？" [→§1 稀缺：研究选择的学问]
    - "取舍我懂，但机会成本凭什么算上我没做的事？账不是只算花的钱吗？" [→§2 机会成本]
    - "（旧直觉冲突）'理性人'是说人只认钱吗？那感情、慈善算什么？" [→§3 理性人]
    - "'边际'是什么意思？为什么说它是经济学里最重要的词？我按平均算为什么错？" [→§4 边际决策（水与钻石之谜）]
    - "（防错）政策为什么老有意外后果？激励还能反着来？" [→§5 激励]
    - "模型这么简化（假设、曲线），凭什么有用？假设不是在撒谎吗？" [→§6 模型与假设的作用]
    - "（边界）'看不见的手'是不是说市场永远对、政府别管？" [→§6 市场与政府（细讲在 06/09/10）]
    - "（防错）'两个东西一起涨，所以一个导致另一个'——这话能信吗？" [→§7 因果 vs 相关]
  - 学完后：经济学=研究稀缺条件下如何选择的社会科学；一套固定动作：识别取舍、算机会成本、想边际、看激励；模型是地图不是照片。
  - 钩子：十大原理里有一条"贸易能使人人受益"，听着最可疑——买卖明明有输有赢——去 02 算账。

- **02 相互依存与贸易的好处**
  - 我带着什么来：会算简单百分比；听过"专业分工效率高"的说法；心里觉得贸易有赢家就必有输家。
  - 第一反应：两国贸易离我很远，而且"双方都赚"听着像鸡汤——总有一方在占便宜吧？
  - 我会依次卡住：
    - "（元问题）凭什么说贸易不是零和？不就是一个人赚另一个人的钱吗？" [→§5.3 折算检验（区间机制在 §6.1）]
    - "绝对优势好懂——谁效率高谁赢；'比较优势'长什么样？" [→§2 绝对 vs 比较优势]
    - "'机会成本更低'怎么用来判定比较优势？具体怎么算？" [→§3 判定三步]
    - "（边界）如果我样样都比对方强，还有必要贸易吗？" [→§4 强者的困惑（边界情形在 §4.3）]
    - "贸易价格为什么有个区间？实际价格谁说了算？" [→§6 价格谈判桌（谁说了算 → §6.3 预告第 03 讲）]
    - "（防错）'进口挤压国货=吃亏'，这个直觉错在哪？" [→§7.2 破误与 §7.3 边界]
  - 学完后：贸易的基础是比较优势（机会成本更低者专业化）；专业化+交换让双方消费超过自产自销；价格落在双方机会成本之间、实际值由供求决定。
  - 钩子：价格区间具体落在哪，是千万人买卖碰出来的——市场里价格怎么冒出来？去 03。

- **03 供给与需求的市场力量**
  - 我带着什么来：会画坐标里的直线；生活里见过"涨价了少买点"。
  - 第一反应：供求谁不知道？涨价因为东西少、买的人多——这讲大概是归纳补全，应该不难。
  - 我会依次卡住：
    - "（元问题）价格到底是谁定的？小摊、奶茶店、机票，谁说了算？" [→§4 均衡（§4.4 结清）]
    - "需求曲线凭什么向下弯？'越便宜越想买'也算科学？" [→§2.1 需求定理]
    - "（防错）'需求量变化'和'需求变化'为什么非要分开？我老觉得是一回事。" [→§2.4 沿曲线 vs 移动]
    - "什么让曲线动？收入、替代品、预期……怎么记不乱？" [→§2.5 与 §3.3 清单]
    - "（旧直觉冲突）价格涨了到底算需求增加还是供给减少？我怎么判断？" [→§5 三步法与 §5.5 反推表]
    - "均衡凭什么稳定？没人指挥为什么不会一直偏？" [→§4.2–4.3 自我修正]
    - "（边界）这套模型什么时候不好用？" [→§6 纪律与边界]
  - 学完后：价格是买卖双方在市场上"碰"出来的，不是谁定的数；分析任何冲击都用三步法：动哪条线→往哪动→新旧均衡对比。
  - 钩子：光知道"涨价买少点"不够——买少多少？1% 还是 50%？这才是决策与政策的钥匙，去 04。

- **04 弹性及其应用**
  - 我带着什么来：会算百分比；知道"刚需"这个词；"弹性"在物理里见过（弹簧）。
  - 第一反应：弹性大概就是"敏感程度"——软概念，方向感不清。
  - 我会依次卡住：
    - "（元问题）弹性到底在度量什么？为什么不直接看曲线陡不陡？" [→§1.3 单位陷阱与斜率]
    - "中点法是什么？为什么不用普通百分比？" [→§2.2 中点法]
    - "弹性可以大于 1？'富有弹性'是说东西好？" [→§3 五档]
    - "（防错）降价一定多赚吗？总收入凭什么会降？" [→§4 总收入（§4.3 规则表）]
    - "（边界）同一条直线需求曲线上，弹性会变？" [→§4.5 沿直线走位]
    - "弹性大小由什么决定？我只能背吗？" [→§6 四大决定因素]
    - "丰收悖论：多收了三五斗反而变穷，真的假的？" [→§7.1 丰收悖论]
  - 学完后：弹性=数量对价格的百分比反应；它决定涨价/降价的收入效应；由替代品、必需程度、市场宽度、时间四因素决定。
  - 钩子：有了弹性，第一次能量化评估政府"管价格"的政策——05。

- **05 供给、需求与政府政策**
  - 我带着什么来：知道政府会限价（房租管制、票价）也会收税（工资条上扣过）。
  - 第一反应：限价保护老百姓、收税是"商家交的"——这有什么难的？
  - 我会依次卡住：
    - "（元问题）价格上限为什么反而让想保护的人吃亏？" [→§1.2 后果链]
    - "租金管制短期还凑合，长期为什么灾难？" [→§2 租金管制深挖]
    - "（旧直觉冲突）最低工资不是让工人赚更多吗？为什么会有人失业？" [→§3.3（§3.4 实证边界）]
    - "对买者征税和对卖者征税，结果居然一样？凭什么？" [→§4.3 等价性]
    - "（防错）法律写着'商家缴纳'，为什么最后是我掏的钱？" [→§5.1–5.2 名义与机制]
    - "（边界）什么情况下商家真的扛下更多税？" [→§5.2–5.3 弹性规则与实验]
  - 学完后：管价格=用行政命令代替市场出清，数量必然错配（短缺/过剩）；税收落在谁的账上由相对弹性决定，法律名义不重要。
  - 钩子：政策到底"亏"多少，现在只能看图说话；要精确算账得有"福利"这把尺子——06。

- **06 消费者、生产者与市场效率**
  - 我带着什么来：知道"买卖双赢"的说法；会算简单面积。
  - 第一反应：市场效率大概就是"均衡最好"——教科书又要讲"看不见的手"了。
  - 我会依次卡住：
    - "（元问题）怎么给'市场结果好不好'定一把能算的尺子？" [→§1.2–1.3 CS 与面积]
    - "支付意愿怎么变成曲线下的面积？" [→§1.3 面积=积分]
    - "（旧直觉冲突）生产者剩余是卖家的利润吗？" [→§2.3 两个辨析]
    - "为什么均衡数量恰好让总剩余最大？多产或少产会怎样？" [→§3.2 两侧论证]
    - "（边界）'效率'等于'对大家好'吗？穷人富人的剩余能直接相加吗？" [→§4.1–4.2（加总前提在 §4.2）]
    - "（防错）什么时候这套效率论证会失效？" [→§4.3 失灵概览]
  - 学完后：CS+PS=总剩余是评估市场的通用账本；均衡=总剩余最大；但效率 ≠ 公平，还有三种失灵情形要盯。
  - 钩子：拿账本去量税收——07。

- **07 赋税的代价**
  - 我带着什么来：会算三角形面积；"无谓损失"没听过，但"税收有代价"听过。
  - 第一反应：税收的代价不就是收走的那些钱吗？政府拿去修路盖学校，不算损失吧？
  - 我会依次卡住：
    - "（元问题）税收'从左手到右手'，凭什么说还额外亏一块？" [→§1.1 转移与蒸发]
    - "两块三角形是什么？怎么看出来的？" [→§1.2 公式 + §2 图]
    - "为什么弹性越大损失越大？" [→§3.1 弹性对照]
    - "税率翻倍、损失四倍——真的假的？" [→§3.2 平方律]
    - "（边界）税率越高，收的税一定越多吗？" [→§4 拉弗曲线]
    - "（防错）无谓损失那块钱到底去哪了、被谁拿走了？" [→§1.1 三个“不是”]
  - 学完后：DWL=被税收吓退的交易本可产生的剩余，谁也没拿到；它随税率的平方量级增长；收入-税率曲线是山峰形。
  - 钩子：拿这杆秤去国际贸易上量关税——08。

- **08 国际贸易**
  - 我带着什么来：知道进出口、关税、贸易战这些词；心里觉得进口多=吃亏。
  - 第一反应：贸易谁赢谁输是"国家大事"，新闻里各说各话，感觉水很深。
  - 我会依次卡住：
    - "（元问题）一个国家什么时候是出口国、什么时候是进口国？" [→§1.2 判定规则]
    - "为什么贸易让总数变好、但一定有人受损？" [→§2.1–2.3（三级账与三句话）]
    - "关税的福利怎么分解？跟 07 的无谓损失什么关系？" [→§3.2 四区账 + §3.4 扫描]
    - "（旧直觉冲突）'保护就业'的说法哪里对哪里错？" [→§4 论点 1（就业）]
    - "（防错）贸易赤字=吃亏吗？" [→§5.1 赤字误区]
    - "（边界）什么情况下'保护'能说得通？" [→§4 论点点评 + 作业 Q8 框架]
  - 学完后：世界价格低于国内均衡=进口国、反之出口国；自由贸易净收益为正但赢家输家分明；关税=给消费者上税+两块无谓损失。
  - 钩子：这一切的前提是"市场自己算得对账"——可污染这类事，市场自己算不对——09。

- **09 外部性**
  - 我带着什么来：关心过污染、环保话题；听过"不能全怪工厂，是市场的问题"这类说法。
  - 第一反应：外部性大概就是"副作用"——烟头乱扔算不算？听起来挺生活化的。
  - 我会依次卡住：
    - "（元问题）市场为什么解决不了污染？它的账哪里算错了？" [→§1.2 两本社会账]
    - "社会最优产量怎么求出来？" [→§2.1 数字账]
    - "庇古税凭什么刚好等于外部成本？" [→§3.1 税率=边际外部成本]
    - "（边界）科斯定理说私下谈就行——那还要政府干嘛？" [→§4.2–4.3（谈判区间与交易成本）]
    - "税和可交易许可证，哪个工具好？" [→§5.1–5.2 工具对照]
    - "（防错）既然正外部性有好处，为什么市场给得不够？" [→§3.2 补贴]
  - 学完后：外部性=交易之外的第三方被波及且没进价格；纠正=把外部成本/收益"塞进"私人账本（税、补贴、许可证、协商）。
  - 钩子：还有一类东西"谁都能用、没人愿意出钱"——公共品与公地——10。

- **10 公共物品、公共资源与税制设计**
  - 我带着什么来：听过"搭便车""公地悲剧"两个词，但说不清具体指什么。
  - 第一反应：公共的东西大家用就会坏、免费的东西没人珍惜——这是常识吧？还要理论？
  - 我会依次卡住：
    - "（元问题）怎么给物品分类？哪些该市场给、哪些该政府给？" [→§1.1 四格棋盘]
    - "搭便车为什么导致公共品供给不足？" [→§2.2 三人路灯]

- **11 生产成本**
