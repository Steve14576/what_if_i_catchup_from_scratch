## 二、公式

| 公式 | 符号各指什么 | 适用条件 | 出处讲次 |
|---|---|---|---|
| 机会成本 = 被放弃的次优选项的价值 | ——（定义式，非计算式） | 一切决策情境；只取"次优"一项，不叠加所有放弃项 | 第 01 讲 |
| $N(q) = R(q) - C(q)$ | $N$ 净收益；$R$ 总收益；$C$ 总成本；$q$ 数量 | 单变量决策问题 | 第 01 讲 |
| 离散决策规则：做到 $MB \ge MC$ 的最后一个单位为止 | $MB$ 边际收益；$MC$ 边际成本（每单位） | 行动按单位离散可分的场景 | 第 01 讲 |
| 连续决策规则：最优点满足 $MB = MC$（即 $N'(q) = 0$） | $N'(q)$ 净收益对 $q$ 的导数 | 行动量连续可调的场景（需二阶条件判极大，见第三部分） | 第 01 讲 |
| PPF 上：$\lvert \Delta y / \Delta x \rvert$ = $x$ 的机会成本 | $x,y$ 两种产品的产量；$\Delta y / \Delta x$ 为两点间斜率 | 两产品、资源给定 | 第 01 讲 |
| 产品 X 的机会成本（以 Y 计）= Y 的全产能 ÷ X 的全产能 | “全产能”= 全部资源只做该产品时的产量 | 两人两品、线性产能（机会成本恒定）场景 | 第 02 讲 |
| 比较优势判定：同产品机会成本更低者有比较优势；两产品下必然“一人一边”（$a<b \iff 1/a>1/b$） | $a,b$ 分别为两人做同一产品的机会成本 | 两种产品、两人 | 第 02 讲 |
| 贸易价格区间：卖方机会成本 < $p$ < 买方机会成本 | $p$ = 以 Y 计价的 X 的价格 | 双方自愿成交的前提区间 | 第 02 讲 |
| 产能占用率 $= x/X + y/Y$；大于 1 即“自力不可达”（消费点走出 PPF） | $x,y$ 为消费量；$X,Y$ 为两种产品各自的全天产能 | 线性 PPF | 第 02 讲 |
| 需求函数 $Q_d = a - bP$；供给函数 $Q_s = c + dP$（$b>0$，$d>0$） | $a$ 为价格为零时的需求量；$c$ 为截距；$b,d$ 决定斜率 | 线性供需的简化形式 | 第 03 讲 |
| 均衡求解：令 $Q_d = Q_s$ 解出 $P^*$，回代得 $Q^*$ | $P^*$ 均衡价格；$Q^*$ 均衡数量 | 供需函数可解时（线性情形必然可解） | 第 03 讲 |
| 缺口 $= Q_s - Q_d$：大于 0 为过剩、小于 0 为短缺、等于 0 为均衡 | —— | 判断价格调整方向 | 第 03 讲 |

### 1. 导数与"边际量"（用得最多的一件外置工具）

**课内用在哪**：第 01 讲 §3.2 "微积分视角"小框；后续第 11–13、17 讲会反复以"导数 / 边际"两种语言互译。

**是什么（最小版）**：导数描述"变化率"——自变量增加一点点，因变量增加多少。比如总收益 $R(q)$ 对产量 $q$ 的导数 $R'(q)$，读作"产量每多一点，收益增加多少"，这正是"边际收益"的定义。所以：

> **边际量 = 导数**：把"多做一单位多赚/多花多少"写成数学，就是"总函数对数量的导数"。离散场合它是差分（$R(q+1)-R(q)$），连续场合它是导数——同一件事的两种版式。

**为什么"最优在导数为 0"（证一遍）**：设净收益 $N(q)$ 在 $q^*$ 处达到最大。看两侧扰动：

- 若 $N'(q^*) > 0$：$q$ 稍微**增大**还能让 $N$ 更高——$q^*$ 不可能是最大点；
- 若 $N'(q^*) < 0$：$q$ 稍微**减小**能让 $N$ 更高——同样矛盾。

两个方向都被排除，所以（在最大值位于内部时）只能 $N'(q^*) = 0$。这就是"一阶条件"$MB = MC$ 的来历：$N = R - C$，$N' = R' - C' = 0$ 即 $MB = MC$。

**注意（二阶条件，此处点到为止）**：$N'=0$ 只说明"平坦"，平坦处可能是峰顶（最大）也可能是谷底（最小）。判据是再求一次导：$N''(q^*)<0$ 为峰（最大）。本课程大多数图里用"边际曲线从上方穿过"直观代替这一步；真正用到时（第 11、13 讲）会就地说明。
