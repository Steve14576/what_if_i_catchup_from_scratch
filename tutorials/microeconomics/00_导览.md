# 微观经济学——导览

> 这是一套**面向完全没系统学过经济学的人**的教程。目标不是"知道几个经济学名词"，而是：学完你能单纯凭借它，把一套正经的微观经济学原理考核做下来，并且真的理解每个模型在解释什么、它的前提和边界在哪、什么时候该调用它。

## 这门课是什么

微观经济学是"研究稀缺条件下人们如何选择"的科学。它看起来分支很多，其实主线只有一条链子——**选择怎么发生 → 价格怎么形成 → 结果好不好 → 政府怎么介入 → 卖方怎么决策 → 人与分配**：

- **选择**：资源不够就要取舍；取舍要算账（机会成本）；账要算在"下一边际"上；激励一变，行为就变。
- **价格**：千万人的买卖在市场上"碰"出价格——供给、需求、弹性、均衡。
- **评价**：拿"消费者剩余 + 生产者剩余"这本总账去算，市场多数时候很有效，但它有边界，也有三种失灵。
- **政策**：价格管制、税收、补贴、许可证——每一样都用前面的账本算清赢家与输家。
- **企业**：成本怎么算、产量怎么定；完全竞争、垄断、寡头三种牌局怎么打，同一条规则（边际收益 = 边际成本）怎么变脸。
- **分配与个体**：工资怎么定、收入为什么不均、消费者怎么选择、信息与心理如何让人偏离"理性人"。

这套课从零开始，每一步都配三样东西：**直觉**（它在解释哪一类现象）、**能笔算的例题**（考试风格：概念辨析、计算、画图、简答）、**能跑的 Python 数值实验**（把模型结论坐实成具体数字，全部可在 `scripts/` 复跑）。关键图形都会配图（`figures/`），且每张图旁都有文字描述兜底。

## 前置

- 高中代数：会算百分比、解简单方程、看坐标图即可。
- 微积分：**不需要预先掌握**。用到导数、最优化、积分的地方会就地给最小说明或"微积分视角"小框；所有这类工具另在 `AA_一览.md` 的"外置前置知识工具库"统一汇总（按应用角度讲/证一遍，随时可查）。
- Python：不需要预先会。需要跑实验时讲义当场给出可直接运行的代码，环境用 `uv`（不熟也没关系，照着复制即可；跑不动也可以只看脚本里的输出表格）。
- 英语：术语会配中英对照（方便你读英文材料或对照考试），但正文不依赖英语。

## 学完你能做什么

- [ ] 把一条政策新闻拆成"取舍、激励、赢家输家、效率与公平"的结构，分清实证与规范。
- [ ] 由供需表求均衡、用三步法推演外生冲击；算弹性并预测价格变化对总收入的影响。
- [ ] 算价格管制造成的短缺与过剩、税收楔子与税负归宿；算无谓损失并说出"平方律"。
- [ ] 算消费者剩余 / 生产者剩余 / 总剩余，评估一项政策的效率得失。
- [ ] 判定一国是出口国还是进口国，分解自由贸易与关税的赢家、输家与净福利。
- [ ] 求外部性的社会最优产量与庇古税；给物品分类（排他性 × 竞用性）、算公地的过度使用。
- [ ] 由生产函数算出整套成本曲线；算竞争企业的最优产量、利润、停产与长期均衡。
- [ ] 由需求曲线推边际收益，算垄断定价与无谓损失；解古诺均衡与囚徒困境的纳什均衡。
- [ ] 算劳动边际产量价值与均衡工资、洛伦兹曲线与基尼系数；解效用最大化并分解替代与收入效应。
- [ ] 用 Python 复跑全课程的数值实验，并说清每个模型的前提与边界。

## 讲次大纲

|---|---|---|
| 01 | 经济学十大原理与经济学思维 | 稀缺—取舍—机会成本—边际—激励；模型是简化地图不是照片；分清实证与规范 |
| 02 | 相互依存与贸易的好处 | 比较优势（机会成本更小）是贸易的基础；专业化让双方消费都超出自家产能；价格落在双方机会成本之间 |
| 03 | 供给与需求的市场力量 | 价格是买卖双方"碰"出来的，不是谁定的；三步法分析一切冲击 |

| 05 | 供给、需求与政府政策 | 价格管制 = 行政命令代替市场出清，必然错配；税落在谁账上由相对弹性决定 |
| 06 | 消费者、生产者与市场效率 | 剩余账本：均衡恰是总剩余最大点；效率 ≠ 公平 |

| 08 | 国际贸易 | 世界价格定角色（出口国/进口国）；自由贸易净收益为正但赢家输家分明；关税 = 两块无谓损失 |
| 09 | 外部性 | 外部性 = 没进价格的第三方影响；纠正 = 把外部成本/收益塞回当事人账本 |
| 10 | 公共物品、公共资源与税制设计 | 物品四分类、搭便车、公地悲剧；税制用"效率 + 公平"两轴评价 |
| 11 | 生产成本 | 成本 = 放弃的价值；从生产函数推出整套成本曲线；边际穿过平均最低点是必然 |
| 12 | 竞争市场上的企业 | P = MC 生产、跌破 AVC 停产、长期零利润；"MR = MC"是通用规则 |

| 14 | 垄断竞争与寡头 | 差异化市场的过剩产能均衡；支付矩阵与纳什均衡；囚徒困境是结构问题 |

## 每讲怎么用（固定循环）

1. 开头看**本讲目标**和**脉络图**，知道这讲要带你做出什么、途经哪几站。
2. 每讲先给一个能立即上手的"**成品**"（算清一件事、回答一个问题），再在卡壳处拆零件——概念永远在你需要它的那一刻出场。
3. 每个概念注意标注的**理解角度与深度**：是"要会推导/手算"、"要知道有这回事 + 去哪找它"、还是"建立直觉即可"。
4. 数值实验的每个实测数字都能在 `scripts/` 找到脚本复跑（文件名形如 `lecNN-01_verify_xxx.py`）；关键图形在 `figures/`，每张图旁有文字描述。
5. 结尾**掌握度自测**全打勾 → 做**作业**（基础 / 提高 / 综合三档）→ 达标。

## 达标判据

- **一讲达标** = 该讲"掌握度自测"全部能打勾，且作业能独立做出来（参考答案就在每题下方，先独立做再对照，不是抄）。
- **一门达标** = "学完你能做什么"清单全部打勾。
- **应试达标** = 拿一份真实的经济学原理试卷，能在限时内做下来，并说清每个答案用的是哪个模型、前提是什么。
