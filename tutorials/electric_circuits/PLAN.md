## 一、目标与读者画像

### 课程目标（学完能做什么，行为化）
- 能从零把国内工科《电路》课程水准的考试做下来：直流电阻电路分析（等效、节点法/回路法、定理、运放电路）、动态电路时域分析（一阶三要素、二阶三种阻尼）、正弦稳态分析（相量法、阻抗、功率、三相）、耦合电感与变压器、频率响应与谐振、非正弦周期电路、拉普拉斯复频域、二端口网络的典型题目。
- 对每个核心方法说清"它是什么 + 它在解决哪一类电路 + 前提与边界 + 什么时候调用它"，而不是背公式套题型。
- 能用 Python 把电路结论跑成具体数字：线性方程组数值求解（节点法/回路法）、微分方程数值积分（暂态）与解析解对照、符号推导（复阻抗、传递函数、拉普拉斯——sympy）、相量与功率数值验算、矩阵组装与状态方程积分——每个实测数字都能在 `scripts/` 复跑，并且每个数值结论都回代 KCL/KVL 或元件方程验算。
- 能把典型电路画成 IEC 风格原理图（SchemDraw）、把响应与曲线画成图形（matplotlib）——本课程是仓库内第一门使用 SchemDraw 的课程，图形方案已探针验证。

### 读者是哪一种（决策记录，2026-10-03 对齐拍板）
**完全零基础重学**（用户自述：当年课程上得很快且很乱，只记得上到二端口网络，对课程细节无系统概念）：
- 假想读者没系统学过电路分析；有高中物理残存的朴素直觉（"电压 = 电流 × 电阻"、串并联、"电容通交流阻直流"这类口头禅），但不知道电路分析作为一个体系是怎么运转的。
- 这类读者**不知道自己不知道什么**——没写出来的东西他问不出来，只能靠作者地毯式覆盖兜底。原则 10（地毯式覆盖优先于组织优雅）是第一纪律。
- 数学工具：微积分（导数、一/二阶微分方程）与复数运算**可用**，但不假设熟练——凡是本课要用到的地方，就地给最小说明（复数运算在 13 讲集中复习一遍；拉普拉斯变换在 21 讲以"够用的工具"自足处理，不假设先修信号与系统）。

### 数学深度（决策记录）
- 正文按电路课正统风格：列方程、解方程、看响应，代数与微积分自然使用，不躲也不炫。
- "换武器"的节点（相量法、拉普拉斯）要专门花笔墨讲透"为什么换、换了之后什么变简单"——这是全课程理解的关节处。
- 微积分与复数是工具不是教学对象：需要处就地给最小说明，不把电路课写成数学课。

### 例子风格（决策记录）
- **直觉 / 手算例题 / Python 数值实验 三者并重**；手算例题=考试风格题（求等效电阻、列节点方程、三要素、相量、二端口参数）。
- 电路数值验证的天然形态是"**求解 + 回代验算**"：任何数值结论都要代回 KCL/KVL/元件方程复核；符号推导（sympy）与数值结果互相对照。
- 图形方案（2026-10-03 探针拍板）：电路原理图用 **SchemDraw**（IEC 风格矩形电阻，`elm.style(elm.STYLE_IEC)`），响应曲线用 **matplotlib**；两者均 SVG + PNG 双格式存 `figures/`，文字转路径保渲染兼容；绘图脚本一律 `Drawing(show=False)` + `matplotlib.use('Agg')` 无头化（防弹窗阻塞，探针事故记录见 `_probe_circuit/`）。

### 3.2 关键机制"完整形态六问"决定登记

> 六问：① 标准形态+每部分自由度 ② 嵌套/组合 ③ 被控/外部打断 ④ 重复与共存 ⑤ 规范：好习惯/坏习惯 ⑥ 相邻边界与对比。只登记容易漏、且需要当场拍板处理方式的机制。

- **参考方向（01）**：① 标准=先设定再求解，电压电流各自独立设定；② 元件级与系统级都要设、可逐支路设；③ 求解得负值只说明实际方向相反，不必回头改图；④ 同一电路任选方向、结果一致（差一个符号）；⑤ 规范=全程一套方向不改动、方程与图严格对应；⑥ 与"真实方向"的边界：参考方向是记账约定不是物理主张。
- **KCL/KVL（02）**：① 标准形式；② 推广形态（广义结点、广义回路/路径）必须在正文出现；③ 与电荷守恒/能量守恒的关系要讲清；④ 独立方程计数（n-1、b-n+1）在 04 讲回收；⑤ 规范=先标方向再列方程、写方程带符号；⑥ 适用边界=集总参数电路。
- **受控源（02）**：① 四类标准形与控制系数；② 控制量可以在任意支路（跨电路"喂"回来）；③ 不能独立提供能量，是"有源器件的模型"；④ 与独立源混合出现时的方程处理；⑤ 规范=当未知量联立、不单独"等效掉"（除非控制量在端口）；⑥ 边界：独立源与受控源在等效中的待遇不同（03/04/05 反复用）。
- **等效（03）**：① "对外等效"的严格含义（端口伏安关系相同）；② 链式组合（等效后再等效）；③ 含受控源时输入电阻的求法差异；④ "等效≠相同"（内部损耗/电流不同）；⑤ 规范=先声明"对哪两个端子"；⑥ 边界：非线性、受控源特殊情形。
- **结点法（05）**：① 标准形 Y_n·U_n = I_s 与观察法；② 修正情形（无伴电压源/受控源）清单；③ 参考结点选择自由；④ 与 A·Y·A^T 的同一性（25 回收）；⑤ 规范="自导纳正、互导纳负"的观察写法；⑥ 与回路法对偶边界。
- **换路定则（10）**：① 标准用法 u_C(0+)=u_C(0-)、i_L(0+)=i_L(0-)；② 多个储能元件同时换路；③ 理想化下的"强迫突变"反例（冲激）要标注；④ 与终值 f(∞) 的配套（三要素）；⑤ 规范=先算 0- 状态、再画 0+ 电路；⑥ 边界：理想化元件假设的局限。
- **相量（13）**：① 与瞬时量的对应关系（振幅/有效值口径二选一后全程统一）；② 相量运算与叠加；③ 只对同频正弦有效（不同频不能相量相加）；④ 相量图组合；⑤ 规范=口径统一、微分算子写清；⑥ 与拉氏变换的边界（21/22 回收：相量是 s=jω 的特例）。
- **磁路（17）**：① 标准量对（F/Φ/R_m）与对偶表；② 组合=串并联磁路、铁心+气隙串联；③ 被控/打断=非线性 B-H：按平均 μ 或查曲线，当场声明口径；④ 与 09 的 $\psi = Li$ 互证（$L = N^2/R_m$）；⑤ 规范=先画磁路等效图、单位统一（A、A/m、Wb、H）；⑥ 边界=忽略漏磁/边缘效应，与电机学衔接。
- **耦合电感（18）**：① 标准量对（ψ 磁链方程 / M 互感 / k 耦合系数；两电流都从名端流入为正号口径）；② 组合=多线圈、去耦等效（串联、T 型三端）把互感拆成普通电感网络，再与结点法/网孔法组合；③ 被控/打断=符号由同名端与电流方向共同决定（五步流程）；④ 与 09/17 互证（$M = N_1N_2/R_m$、全耦合 $k=1$）；⑤ 规范=先标同名端、统一参考方向再列方程、负电感是等效参数不当物理元件；⑥ 边界=理想变压器三极限（全耦合/无损耗/大电感），普通变压器三本账（漏磁/损耗/励磁电流）。
- **频率响应（19）**：① 标准形态=网络函数 $H(\mathrm{j}\omega) = \dot Y/\dot X$（输出口决定哪个网络函数；幅频+相频两件套）；② 组合=扫频/曲线族（多 Q 对比）、与滤波家族相认（低通/高通/带通/带阻=图形分类）；③ 被控/打断=拓扑决定口径（串联 vs 并联谐振的"谁最大谁最小"完全不同）；④ 与 14 讲互证（阻抗是一类网络函数）；⑤ 规范=先判拓扑再套 Q 公式、过压/过流上限用 Q 估、半功率口径 $1/\sqrt{2}$；⑥ 边界=基本 R∥L∥C 模型（实际线圈自阻按等效模型走）；Bode 认识层（-3dB、-20dB/dec）。
- **非正弦周期（20）**：① 标准量对（傅里叶系数 $a_0/a_n/b_n$、各次谐波相量组）；② 组合=对称性判定省项、截断项数按量级选；③ 被控/打断=不同频率不能相量相加（必须各自回时域）；④ 与 06 叠加/13 相量互证（线性前提下的逐次独立）；⑤ 规范=先判对称再积分、逐次用相量法、平方和汇总（$U=\sqrt{U_0^2+\sum U_n^2}$、$P=U_0I_0+\sum U_nI_n\cos\varphi_n$）；⑥ 边界=周期前提（非周期→21/22 拉普拉斯）、线性前提（非线性产生新频率）。
- **复频域（21）**：① 标准量对（$F(s) = \int_{0^-}^\infty f e^{-st}dt$；变换对最小表；微分性质 $sF(s)-f(0^-)$）；② 组合=s 域模型与旧方法全面复用（KCL/KVL/结点法/戴维南在 s 域照用）；③ 被控/打断=初值经附加源自导入场（$0^-$ 下限的机制）；④ 与 13 讲互证（$s=\mathrm{j}\omega$ 退化为相量法）；⑤ 规范=初值只取 $u_C(0^-)/i_L(0^-)$、方向以回路/分压关系交叉核对、假分式先长除；⑥ 边界=线性时不变、单边因果、有理分式可拆；极点位置—响应形态为 22 讲钩子。
- **极零点与稳定（22）**：① 标准量对（$H(s) = N(s)/D(s)$（零初值）、极点、零点、$h(t)$）；② 组合=极零点是固有属性、与输入解耦（$Y = HX$）；③ 被控/打断=$s=\mathrm{j}\omega$ 切片回 19 讲频响；几何读法（近极点峰/近零点谷）；④ 与 12/19/21 讲互证（极点=特征根=分母根；$\omega_0$=极点模、$\omega_d$=虚部）；⑤ 规范=先写 $H(s)$ 再求根判三态、无源恒稳定快速自查；⑥ 边界=稳定性只看极点、劳斯判据属后续课程（认识层）。
- **二端口参数（23/24）**：① 四套参数的标准矩阵与定义式；② 互易/对称参数的特殊关系（少几个独立参数）；③ 参数存在的条件（Y 病态时用 Z…）；④ 参数换算与选用；⑤ 规范=计算（测量）口径与假设（一端开路/短路）写清；⑥ 与一端口等效的边界。
- **叠加/替代（06）**：① 标准操作四步与置零规则表；② 与回路/结点法的组合（子电路任选方法）；③ "单独作用"是数学部件而非物理场景；④ 功率等乘积量一律不叠（当场识别）；⑤ 规范=标方向、代数和带符号、置零时串/并联元件原地保留、受控源保留；⑥ 边界：线性 vs 非线性（叠加失效/替代仍可用）、替代 vs 等效（依赖解 vs 不依赖）。
- **戴维南/诺顿（07）**：① 三件套标准求法与口诀（无源看进去/有源喂回去/顺除互验）；② 与回路法/结点法、等效变换的组合（胶囊后任意方法求解）；③ "对外等效、内部不保"的宣读义务；④ 受控源单口的统一求法（置零后外施/端口关系读斜率）；⑤ 规范=三招互验（不一致即查错报警）、匹配与效率分开记账；⑥ 边界：网络须线性且自足（控制量在网络内部）、负载任意（含非线性）。
- **运放（08）**：① 理想模型三件套（A→∞/输入电阻→∞/输出电阻→0）与有限模型的对照账（误差随 A 收缩）；② 组合=级联与反馈网络（虚短虚断 + 结点法的四步模板）；③ 被控/打断=饱和顶轨则虚短失效；④ 五类电路共存对照表（跟随/反相/同相/加法/减法）；⑤ 规范=先看回接端判负反馈、虚地不是真接地、减法器必验匹配；⑥ 边界=负反馈 + 未饱和 + 非高频三条件。
- **电容/电感（09）**：① 标准符号与关联方向下的伏安关系（微分/积分双形式）；② 组合=串并联"反着来"与对偶置换；③ 被控/打断=冲激式突变仅在理想化病态场景；④ 记忆属性=积分需初值（状态量身份，10 讲回收）；⑤ 规范=换路只保 u_C、i_L；口诀按"稳态"口径使用；⑥ 边界=线性时不变 + 理想元件假设。

> 每条五段：**我带着什么来 / 第一反应 / 我会依次卡住的疑问（4–8 个，`[→]` 标计划中的答题位置，交付该讲时校正为真实小节）/ 学完后 / 钩子**。
> 硬约束：第一人称；疑问按遇到顺序排列；四类必含——**元问题迷失**、**旧直觉冲突**、**边界**、**防错**；两类问题按要求自然出现——"不知道自己不知道"型（如 01 讲"这门课到底在学什么"）与"想当然归纳"型（如 02 讲"是不是所有元件都能套 $V=IR$"），后续各讲继续自然出现、不机械凑数。

- **01 电路模型与基本变量**
  - 我带着什么来：高中物理的 $V=IR$、串并联；在我印象里"电路"就是电池点亮小灯泡，电流从正极流出来、被灯泡"用掉"。
  - 第一反应：这不都是初中知识吗？参考方向、集总参数这些词，听着像把简单的事故意搞复杂。
  - 我会依次卡住：
    - "（元问题·不知道自己该问什么）这门课到底在学什么？和我高中见过的电路有什么本质不同？" [→ §1 从真实器件到电路模型]
    - "（旧直觉冲突）电流真的会被元件'消耗'吗？灯泡后面出来的电流是不是变少了？" [→ §2.3 电流守恒：灯泡"用掉"的到底是什么]
    - "参考方向是什么？为什么先'假设'？我假设反了岂不是全错？" [→ §2.2 参考方向、§3.2 参考极性]
    - "电压和'电位差'是一回事吗？说'某点的电压'严谨吗？" [→ §3.3 电位与参考点]
    - "功率的正负号到底在说什么？怎么判断谁吸收、谁发出？" [→ §4.1–§4.2 $p=ui$ 与关联参考方向]
    - "（防错）$P=UI$ 好像哪里都能套——哪里会翻车？" [→ §4.2 判定表、§4.3 引子对账]
    - "（边界）真实电池凭什么画成'理想源+电阻'？这种简化什么时候不成立？" [→ §1.2 三处替换、§1.3 模型契约]
  - 学完后：电路分析 = 在理想化模型上算电压、电流、功率；一切从"先设参考方向、再按约定记账"开始；电流不消耗，能量才被消耗。
  - 钩子：现在手里只有"量"，还没有"元件"和"定律"——去 02。

- **02 电路元件与基尔霍夫定律**
  - 我带着什么来：认识电阻、电池；没听过"受控源"；觉得 KCL、KVL 是"废话常识"。
  - 第一反应：元件 + 两条定律，听起来全是老熟人，应该很快翻过去。
  - 我会依次卡住：
    - "（元问题）KCL、KVL 凭什么成立？它们和电荷守恒、能量守恒是什么关系？" [→ §3.2/§3.3 电荷账与能量账]
    - "（想当然归纳）是不是所有元件都能用一个 $V=IR$ 式子算到底？将来的电容电感也算吗？" [→ §1.4 欧姆定律的边界]
    - "受控源是什么东西？画着电源符号却不是电源，为什么要发明它？" [→ §2.4 受控源]
    - "受控源的四类缩写（VCVS 那一串）怎么记？'控制量在别的支路'什么意思？" [→ §2.4 四类别表]
    - "（防错）受控源和控制量互相缠住，方程会不会列混？" [→ §4.3 含受控源的单回路]
    - "两大定律齐了，是不是所有电路都能解了？我该怎么动第一步？" [→ §3.4 两本账、§4.1 心智模型]
    - "（边界）KCL/KVL 在什么情况下会失效？" [→ §3.5 集总参数前提]
  - 学完后：任何电路 = 元件约束（伏安关系）+ 拓扑约束（KCL/KVL）两本账；受控源是有源器件的伏笔。
  - 钩子：元件一多方程就多——有没有"先化简"和"机械列方程"两条路？先化简：03。

- **03 等效变换**
  - 我带着什么来：会串并联公式；以为"等效"就是"两个电路完全一样"。
  - 第一反应：等效变换大概是考试里"把电阻并一并"的化简技巧，属于硬算之前的热身。
  - 我会依次卡住：
    - "（元问题）'等效'到底是对谁等效？我能说这两个电路'完全一样'吗？" [→ §1.1 对外等效的定义]
    - "Y-Δ 变换的公式那么怪，它是怎么被想出来的？我什么时候该想起它？" [→ §3.2 公式与检验 / §3.3 桥式全解]
    - "电压源串电阻 和 电流源并电阻 居然能互换？凭什么是同一件事？" [→ §2.1–§2.2 两模型与实测]
    - "（防错）两个理想电压源能直接并联吗？两个理想电流源能串联吗？直觉靠得住吗？" [→ §2.4 禁区]
    - "（边界）电路里含受控源时，还能'想并就并'吗？'输入电阻'又是什么？" [→ §4 含受控源的单口]
    - "等效变换这么顺手，为什么后面还要发明结点法、回路法？" [→ §5 等效的射程]
  - 学完后：等效 = 对外端口行为相同；它把电路往"好解"的方向变形，但只管外观、不管内脏。
  - 钩子：变形是手工艺术；先给一套"机械列方程"的流程——回路法，去 04。

- **04 支路电流法与回路电流法**
  - 我带着什么来：会解二元一次方程组；会单回路。
  - 第一反应：解电路 = 列方程解方程？那这是数学课还是电路课？
  - 我会依次卡住：
    - "（元问题）面对一张电路图，我到底该列几个方程？怎么下手？" [→ §1 计数与阶梯]
    - "支路电流法为什么方程特别多？KCL 只要 $n-1$ 个？多列的行不行？" [→ §1.2–§1.3 计数 / §2.2 全解]
    - "（旧直觉冲突）回路电流是'绕着圈流的假电流'——假的东西凭什么能算出真答案？" [→ §3.1 三条事实]
    - "（防错）独立回路怎么选？选错、选重了会怎样？" [→ §3.2 独立回路判定]
    - "方程里冒出电流源、受控源，回路法还照样转吗？" [→ §4 特殊支路处理]
    - "（边界）回路法和后面的结点法，考试该用哪个？" [→ §5 方法选择]
  - 学完后：支路法是直接法、回路法是减元法；"独立方程数"背后是电路的图结构在说话。
  - 钩子：还有一种方法比回路法更受工程师欢迎——去 05。

- **05 结点电压法**
  - 我带着什么来：会回路法；觉得"两套方法差不多够了"。
  - 第一反应：又一种方法？它凭什么"最常用"？我记两套都嫌多。
  - 我会依次卡住：
    - "（元问题）结点方程的'标准形'为什么长成'自导纳×本站电压 − 互导纳×邻站电压'这副模样？" [→ §2.2 标准形与观察法]
    - "这套方程为什么对计算机特别友好、成了各种软件的地基？" [→ §2.4]
    - "（防错）电路里有'无伴电压源'这种钉子户怎么办？" [→ §3.2 无伴电压源两招]
    - "参考结点随便选吗？换一个参考点结果会不会变？" [→ §1.3 参考结点]
    - "（想当然归纳）'自导纳、互导纳矩阵'——这不就是矩阵方程的雏形吗？" [→ §4 矩阵视角与 25 讲钩子]
    - "（边界）含受控源会让标准形哪里变形？" [→ §3.3 含受控源三步]
  - 学完后：结点法 = 以结点电压为未知量、凭观察写方程；它是后面矩阵化、程序化的地基。
  - 钩子：方程会列了，但很多时候只关心"某个元件上的响应"——有没有少算一点的捷径？去 06。

- **06 电路定理 I：叠加与替代**
  - 我带着什么来：会完整解一个电路。
  - 第一反应："定理"两个字听着就要背；为什么不老老实实解一遍完事？
  - 我会依次卡住：
    - "（元问题）什么时候用定理、什么时候硬解？分界线在哪？" [→ §1 定理的动机]
    - "叠加定理凭什么成立？'每个源单独作用'具体怎么操作？不用的源画成什么样？" [→ §2 叠加定理]
    - "（防错）功率为什么不能叠加？这条最容易被坑，怎么一眼识破？" [→ §2.4]
    - "替代定理到底在替代什么？它和'等效'是一回事吗？" [→ §3 替代定理]
    - "（边界）非线性电路还能用这些定理吗？" [→ §4 适用条件汇总]
  - 学完后：叠加 = 线性性的直接推论；替代 = 换个角度描述同一个解。定理是"省力工具包"，不是新知识。
  - 钩子：最有名的一块招牌还没出场——去 07。

- **07 电路定理 II：戴维南、诺顿与最大功率**
  - 我带着什么来：听过"戴维南等效"这个词（不记得在哪听过）。
  - 第一反应：又一个等效？和 03 讲的等效变换什么关系？会不会是重复？
  - 我会依次卡住：
    - "（元问题）'任何线性含源二端网络'都能浓缩成'一个源+一个电阻'？凭什么这么强？" [→ §1 戴维南定理]
    - "等效电阻三种求法（化简、外施激励、开路短路）分别什么时候用？" [→ §2 等效电阻]
    - "（防错）开路电压法和短路电流法打架了怎么办？" [→ §2.4 受控源的情形]
    - "最大功率传输：负载多大时功率最大？为什么'匹配'时效率并不高？" [→ §4 最大功率]
    - "特勒根定理、互易定理要不要深学？" [→ §5 认识层]
    - "（边界）戴维南等效是'对外等效'——那我能不能用它算原电路内部的事？" [→ §1.4 等效的边界]
  - 学完后：戴维南 = 线性网络的"浓缩胶囊"，一步把复杂变简单；最大功率与效率是两本不同的账。
  - 钩子：电路里加一个"特别的有源器件"——运放马上登场：08。

- **08 含运算放大器的电阻电路**

  - 我会依次卡住：

- **09 电容与电感**
  - 我带着什么来：高中摸过电容；电感陌生；记得"电容通交流阻直流"这句口诀。
  - 第一反应：$C=Q/U$、线圈 = 电感——感觉这是背公式的元件课。
  - 我会依次卡住：
    - "（元问题）为什么需要'记忆元件'？它们和电阻本质差在哪？" [→ §1 电容]
    - "电容电流为什么正比于电压的'变化率'？'电压不能突变'是谁规定的？" [→ §1.3 伏安关系]

    - "（想当然归纳·旧直觉）'电容通交流阻直流'——这话到底什么条件下对？" [→ §5 一句口诀的正确打开方式]
    - "（防错）'电压不能突变'严谨吗？有没有例外？" [→ §4 连续性的条件]

  - 学完后：C/L 是记忆元件，电路方程从此变成微分方程；它们的连续性行为是换路定则的根基。
  - 钩子：一个储能元件 + 电阻 = 最简单的时间演化电路——去 10。

  - 第一反应：解电路变成解微分方程了，是不是套数学流程就行？
  - 我会依次卡住：

### 写作红线（血泪，逐讲交付前必查）
- **每个基础对象/机制，正文必须给全四样**：① 它到底是什么 + 有几种视角/心智模型（分别何时用、哪副焊成直觉）；② 该用什么**态度/理解深度**对待（要会推导？要会手算？知道有这回事？）；③ **怎么记**（口诀/图像/流程）；④ **怎么算不出错** + 常见误用。
- **不空降**：术语、缩写、记号、中英对照首次出现要么当场定义，要么一句话说清"干啥的 + 现在只需知道这么多 + 第 N 讲细讲"；符号口径（$u$、$i$、$\varphi$、$\omega$、$\mathrm{j}$ 等）全书统一。
- **就近自足（2026-10-03 用户原则）**：能当场说清的简单概念不写"见前文/见后文"，当场说清；跨讲引用只给真正需要跨讲架桥的内容（重要的二级结论、需跨讲才能理解的思维框架）；前后呼应保留方向感，但不退化为"对账式"指路，以内容本身为中心。
- **标准流程固化红线（工科模式，2026-10-03 用户强调）**：每个定律/方法/公式第一次出现，必须给出可直接照做的"**标准列法（模板）**"：① **标准形式**（模板方程 + 符号口径的唯一固定规矩）；② **操作步骤**（编号、机械可执行，禁止"重新理解整图再凭感觉抓公式"式叙述）；③ **照模板填数的示范**（用本讲例题）；④ **怎么用**一句（与联立求解、验算的衔接）。同一符号规矩全课程统一（已定：KCL 流出为正；KVL 沿走向"降正升负"；功率一律以"吸收"口径读数）。新方法（等效变换、结点法、回路法、各类定理……）一律先立模板、再展开。
