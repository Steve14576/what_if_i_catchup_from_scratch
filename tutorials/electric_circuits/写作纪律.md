## 三、根因（为什么"顺"出 402 次）

1. **结构需求真实**：电路学充满"守恒 + 分配"结构（KCL/KVL、功率平衡、能量守恒、安匝平衡），每讲都要为"结算"找动词——"账"系词最好用，于是被反复调用；
2. **比喻通胀**：一个喻体用顺后，后续同类结构全部回指它，不留神就成为套话；
3. **收尾句式密集**：课程模板（每节"下一站"、每讲小结/实测合集/自测/态度表）制造大量"结算位"，账系词是那些位置最顺手的填充；
4. **工作流词源污染（疑似）**：维护层一直在写"台账同步"（PLAN 行话），可能溢出到正文。

## 四、写作纪律（自 20 讲起强制，交付前核验）

### 红线
1. **禁止概念之外的修辞喻体**：不新增"账/武器/宪法/金律/面孔/舞台/镜子/门票/护照/体检/剧本/手术"类喻体词。允许的例外：**该比喻有实质解释功能，且全文出现 ≤2 次**（低频点缀，首用时可自带解释）。
2. **禁用自造动词"核账"**。结算/自检用语按语境轮换平实词：**独立核对 / 双路互证 / 验算 / 残差检查 / 对上 / 吻合**（"对账"限量，全文 ≤3 次）。
3. **结算句式用事实语言**：不写"三笔账/两本账/一笔悬着的账"，写"三个结论 / 两个代价 / 一个待解释的现象"；不写"总账/账本/记账"，写"总结 / 全套数字 / 约定"。
4. **半术语"档案"不再扩容**：既有"元件档案"可沿用（≤5 次/讲），但**不得再创造"X 档案"新命名**；新表述优先用"伏安特性 / 特性表"。

### 判定标准（一句话）
> **把这个词换成一个平实词，意思有没有损失？没有损失就替换。**

- "账" ≤ 3 次（且均为必要表达，"核账" = 0）；
- 喻体族（武器/面孔/宪法/金律/镜子/舞台/坑/地基…）每词 ≤ 2 次；
