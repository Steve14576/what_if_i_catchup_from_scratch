# 电路学——导览

> 这是一套**面向完全没系统学过电路分析的人**的教程。目标不是"认得几个电路符号"，而是：学完你能单纯凭借它，把国内工科《电路》课程水准的考核做下来，并且真的理解每个方法在解决哪一类电路、它的前提和边界在哪、什么时候该调用它。

## 这门课是什么

电路学（国内工科常直接叫"电路"，内容即"电路分析基础"）研究的是：把真实的电气器件换成**电路模型**之后，如何用一套系统的方法算出各处的电压、电流、功率。它看起来章法繁多，其实主线只有一条——**"解电路"的武器不断升级**：

- **建模**（01–02）：先把真实器件换成电路模型，立好全课程第一套规矩：参考方向、电流、电压、功率，以及两条支配全图的定律（KCL、KVL）。
- **解电阻电路**（03–08）：纯代数武器时代——等效变换、回路电流法、结点电压法、四大定理、运放电路。这是所有后续分析的底座。
- **动态电路**（09–12）：电容与电感登场，电路有了"记忆"，方程从代数升级为微分方程；一阶三要素法、二阶三种阻尼。
- **正弦稳态**（13–19）：第一次"换武器"——相量法把微积分变回代数；阻抗、功率、三相、互感、频率响应一路展开。
- **收束与进阶**（20–26）：非正弦周期（傅里叶+谐波法）、拉普拉斯复频域（第二次换武器）、二端口网络（黑箱视角），外加一讲进阶（矩阵形式与状态方程）与接口讲。

这套课从零开始，每一步都配四样东西：**固化的标准做法**（每个定律/方法都给出可照抄的模板：标准形式、符号规矩、操作步骤、填数示范——列方程与套公式不靠"感觉"）、**直觉**（它在解决哪一类电路问题）、**能笔算的例题**（考试风格：概念辨析、计算、脚本题）、**能跑的 Python 数值实验**（把结论坐实成具体数字，全部可在 `scripts/` 复跑；每个数值结论都回代 KCL/KVL 或元件方程验算）。关键图形都会配图（`figures/`）：电路原理图（IEC 风格）与曲线图，且每张图旁都有文字描述兜底。

## 前置

- 高中物理的电路常识：听过欧姆定律、串并联即可（本课程会把它们重新严谨化，旧的模糊印象不碍事）。
- 微积分：导数和一、二阶微分方程"见过"即可；用到的地方会就地给最小说明，或标注"现在只需知道这么多"。
- 复数：会基本运算更省力，不会也没关系——第 13 讲会集中复习一遍。
- 线性代数：会解多元一次方程组就够；矩阵语言在第 25 讲正式使用前会就近铺垫。
- Python：不需要预先会。需要跑实验时讲义当场给出可直接运行的代码，环境用 `uv`（不熟也没关系，照着复制即可；跑不动也可以只看脚本里的输出表格）。
- 英语：术语会配中英对照（方便你读英文材料或对照考试），但正文不依赖英语。

## 学完你能做什么

- [ ] 对任意直流电阻电路：化简、列方程（结点法/回路法），解出全部电压电流，并用 KCL/KVL 与功率平衡复核。
- [ ] 用叠加、戴维南、诺顿等定理"少算"地求解电路，并说清每个定理的适用条件。
- [ ] 求一阶电路的初始值、零输入/零状态/全响应（三要素法），与二阶电路的三种阻尼响应。
- [ ] 用相量法解正弦稳态：阻抗导纳、相量图、有功/无功/视在功率、功率因数与共轭匹配。
- [ ] 算对称三相电路的线量/相量与三相功率；用磁路欧姆定律算铁心磁路与铁心线圈；处理互感与理想变压器；求谐振频率与频响曲线。
- [ ] 用傅里叶分解+谐波法处理非正弦周期电路；用拉普拉斯运算法解含初值的电路；由极点零点判断稳定性。
- [ ] 求二端口网络的 Y/Z/T/H 参数，做等效电路与连接方式分析。
- [ ] （进阶）写出关联矩阵并验证 A·Y·A^T 就是结点导纳矩阵；列写状态方程。
- [ ] 用 Python 复跑全课程的数值实验，并说清每个方法的完整形态与边界。

## 每讲怎么用（固定循环）

1. 开头看**本讲目标**和**脉络图**，知道这讲要带你做出什么、途经哪几站。
2. 每讲先给一个能立即上手的"**成品**"（算清一件事、回答一场争论），再在卡壳处拆零件——概念永远在你需要它的那一刻出场。
3. 每个概念注意标注的**理解角度与深度**：是"要会推导/手算"、"要知道有这回事 + 去哪找它"、还是"建立直觉即可"。
4. 数值实验的每个实测数字都能在 `scripts/` 找到脚本复跑（文件名形如 `lecNN-01_verify_xxx.py`）；关键图形在 `figures/`，每张图旁有文字描述。
5. 结尾**掌握度自测**全打勾 → 做**作业**（基础 / 提高 / 综合三档）→ 达标。

## 达标判据

- **一讲达标** = 该讲"掌握度自测"全部能打勾，且作业能独立做出来（参考答案就在每题下方，先独立做再对照，不是抄）。
- **一门达标** = "学完你能做什么"清单全部打勾。
- **应试达标** = 拿一份《电路》课程的试卷，能在限时内做下来，并说清每个答案用的是哪个方法、前提是什么。
