## 一、概念与术语（中英对照）

| 概念（中文） | 英文/缩写 | 定义（说清"是什么"） | 首次出现 | 理解层次 |
|---|---|---|---|---|
| 电路模型 | circuit model | 用理想元件、理想导线与集总参数假设替代真实器件后得到的分析用图形：保留电气行为，舍弃无关的物理细节 | 第 01 讲 | 要能说清"模型 ≠ 实物" |
| 集总参数假设 | lumped-parameter assumption | 把元件的电气行为集中到端子上处理、导线只当连接（不当传输线）的假设；成立要求电路尺寸远小于信号波长 | 第 01 讲 | 知道适用条件与失效场景 |
| 理想导线 | ideal wire | 电阻为零、电压处处为零、只起连接作用的导线模型；必要时可"升级"为电阻元件 | 第 01 讲 | 识别 |
| 电流 | current | 电荷的定向移动；大小等于单位时间内通过某横截面的电荷量（$i = \mathrm{d}q/\mathrm{d}t$） | 第 01 讲 | 要能复述与辨析 |
| 参考方向 | reference direction | 分析前对每段电流先假设的方向（图上小箭头），是记账约定而非物理断言；结果符号用于读真实方向 | 第 01 讲 | 焊成直觉 |
| 直流 | direct current (DC) | 大小与方向都不随时间变化的电流 | 第 01 讲 | 识别 |
| 电压 | voltage | 电路中 a、b 两点间的电压，数值上等于把单位正电荷从 a 端移到 b 端所转移的能量（$U_{ab} = W_{ab}/q$） | 第 01 讲 | 要能复述 |
| 参考极性 | reference polarity | 分析前对电压先假设的"高端"（"+"/"-"标注或双下标），逻辑与参考方向同构 | 第 01 讲 | 焊成直觉 |
| 电位 | potential | 某点与参考点之间的电压（$V_a$）；换参考点时全体电位平移一个常数 | 第 01 讲 | 要会算、要会用 |
| 参考点 | reference point | 电路中被规定为零电位的基准点，惯例称"地"（ground） | 第 01 讲 | 识别 |
| 功率 | power | 能量转化的速率（$p = \mathrm{d}w/\mathrm{d}t$）；电路中由电压电流给出 $p = ui$；关联参考方向下算出的即"吸收功率" | 第 01 讲 | 要能推导 |
| 关联参考方向 | associated reference direction | 电流参考方向从电压参考"+"端流入元件；此约定下 $p = ui$ 直读吸收功率（正吸负发），非关联则 $p = -ui$ | 第 01 讲 | 焊成直觉 |
| 功率平衡 | power balance | 任何电路中全部元件发出功率之和等于吸收功率之和（能量守恒的电路形式）；全课程的验算尺 | 第 01 讲 | 焊成验算纪律 |
| 千瓦时 | kilowatt-hour (kWh) | 能量单位，$1\,\mathrm{kWh} = 3.6\times10^6\,\mathrm{J}$；日常计量用电的"度" | 第 01 讲 | 会换算 |
| 伏安关系 | volt-ampere relationship | 元件两端电压与流过电流之间的约束关系（每个元件的"电气性格"） | 第 01 讲（首提） | 知道有这回事；第 02 讲正式展开 |
| 基尔霍夫电流定律 | Kirchhoff's Current Law (KCL) | 流入任一结点的电流之和等于流出之和（任意"结点块"皆然）；电荷守恒的电路形式 | 第 01 讲（首提）、第 02 讲（正式） | 能复述、能写方程 |
| 欧姆定律 | Ohm's law | 线性电阻的伏安关系：关联参考方向下 $u = Ri$ | 第 02 讲 | 焊成直觉 |
| 线性电阻 | linear resistor | 伏安关系为过原点直线的电阻元件（$R$ 为常数） | 第 02 讲 | 识别 |
| 短路 | short circuit | 电阻为零的状态（$u \equiv 0$、$i$ 任意）；理想导线即 0 Ω 电阻 | 第 02 讲 | 认识 |
| 开路 | open circuit | 电流恒为零的状态（$i \equiv 0$、$u$ 任意）；0 A 电流源即开路 | 第 02 讲 | 认识 |
| 理想电压源 | ideal voltage source | 两端电压恒为给定值、与电流无关；电流由外电路决定 | 第 02 讲 | 要能复述 |
| 理想电流源 | ideal current source | 流过电流恒为给定值、与电压无关；电压由外电路决定 | 第 02 讲 | 要能复述 |
| 内阻 | internal resistance | 实际电源模型中串在理想电压源外侧的电阻，造成端电压随供流下垂 | 第 02 讲 | 会算、会解释 |
| 受控源 | controlled source | 电压或电流由电路中另一处的电压/电流控制的源（函数而非数据；四类，菱形记号） | 第 02 讲 | 能对表转换 |
| 支路 | branch | 两个连接点之间、一路串联无分岔的一段路；同一支路电流处处相等 | 第 02 讲 | 能认、能数 |
| 结点 | node | 支路与支路的交汇点；只连两条支路的连接点通常并入支路 | 第 02 讲 | 能认、能数 |
| 回路 | loop | 沿支路走一圈回到出发点的闭合路径 | 第 02 讲 | 能认、能数 |
| 广义结点 | generalized node | 把若干结点打包成的"超级结点"；进出整体的电流代数和为零 | 第 02 讲 | 认识 |
| 基尔霍夫电压定律 | Kirchhoff's Voltage Law (KVL) | 沿任一回路按任一绕行方向，各元件电压降的代数和为零（能量守恒的电路形式） | 第 02 讲 | 焊成肌肉记忆 |
| 单口网络 | one-port network | 只留两个端子对外连接的一块电路（亦称二端网络）；"等效"问题的最小对象 | 第 03 讲 | 识别 |
| 对外等效 | externally equivalent | 两个单口网络对同一对端子的伏安关系（$u$-$i$ 关系）完全相同；只约束端口，不承诺内部相同（内部电流/损耗可完全不同） | 第 03 讲 | 焊成直觉（先声明"对哪两个端子"） |
| 输入电阻 | input resistance | 不含独立源的单口从端口看进去的等效电阻 $R_{in} = u/i$（端口伏安为过原点直线时存在）；用外施激励法求 | 第 03 讲 | 会求 |
| Y-Δ 变换 | wye-delta transform | 三个端子上的两种电阻接法（星形/三角形）之间的对外等效互换；用于"非串非并"的桥式等结构 | 第 03 讲 | 能默写、会验 |
| 平衡电桥 | balanced bridge | 桥式电路中两臂电阻比例相等（桥端电位相等、中支路电流为零）的特殊状态；此时中支路可拿掉 | 第 03 讲 | 认识 + 会用边界 |
| 网孔 | mesh | 平面电路中"内部不再套着别的支路"的最小回路；平面电路的独立回路可取全部网孔 | 第 02 讲（提）、第 04 讲（正式） | 能认、能数 |
| 独立回路 | independent loop | 每新增一个回路至少含一条此前未用支路，如此选满 $b-n+1$ 个的一组回路；此组 KVL 方程互相独立 | 第 04 讲 | 会选、会判 |
| 支路电流法 | branch-current method | 以 $b$ 条支路电流为未知量，列 $n-1$ 条 KCL 与 $b-n+1$ 条 KVL（电压以元件档案替换）联立求解的方法 | 第 04 讲 | 能默写流程 |
| 回路电流法 | loop-current method（平面电路特称网孔电流法 mesh-current method） | 以 $b-n+1$ 个回路电流为未知量，对每个回路列 KVL；支路电流由回路电流线性组合还原的方法 | 第 04 讲 | 能默写、会解 |
| 回路电流 | loop current | 环行于某一回路的数学辅助电流（非真实支路电流）；支路电流 = 与之相关的回路电流的代数和 | 第 04 讲 | 能复述"假电流为什么合法" |
| 超网孔 | supermesh | 把含无伴电流源的两个网孔合并成的超级回路；对其列 KVL（绕开电流源）并补电流约束方程的处理手法 | 第 04 讲 | 会用 |
| 结点电压 | node voltage | 某结点相对参考结点的电压（即该结点电位）；支路电压 = 两端结点电压之差 | 第 05 讲 | 焊成直觉 |
| 超级结点 | supernode | 把含无伴电压源的两个结点合并成的组合结点；对其列 KCL（绕开源）并补电压约束方程的处理手法 | 第 05 讲 | 会用 |
| 观察法 | inspection method | 用"自导纳、互导纳、注入电流"三步直接写出结点方程（回路法标准方程同源）；矩阵对称可自检 | 第 05 讲 | 能默写、闭眼执行 |
| 叠加定理 | superposition theorem | 线性电路中任一响应 = 各独立源单独作用响应的代数和；置零时压源→短路、流源→开路，受控源保留 | 第 06 讲 | 能默写、会判用 |
| 替代定理 | substitution theorem | 已知支路（或单口）的 $u_k$ 或 $i_k$，可用同值电压源/电流源替换，其余各处解不变（解须唯一；对非线性亦成立） | 第 06 讲 | 能复述论证、会用 |
| 戴维南定理 | Thevenin's theorem | 线性含源二端网络对外等效为 $U_{oc}$ 串 $R_{eq}$；证明 = 替代（换口）+ 叠加（拆账）；对外等效、内部不保 | 第 07 讲 | 能复述、会用 |
| 诺顿定理 | Norton's theorem | 同一网络对外等效为 $I_{sc}$ 并 $R_{eq}$；与戴维南由电源互换互相转换（$U_{oc} = I_{sc}R_{eq}$） | 第 07 讲 | 能复述、会用 |
| 最大功率传输 | maximum power transfer | 匹配 $R_L = R_{eq}$ 时负载功率最大；功率账与效率账分开（匹配效率仅 50%） | 第 07 讲 | 能推导、会判断 |
| 运算放大器（理想模型） | ideal op-amp | 差动放大器理想化：$u_o = A(u_+-u_-)$，$A\to\infty$、输入电阻 $\to\infty$、输出电阻 $\to 0$；属受控源亲戚 | 第 08 讲 | 能复述、会用 |
| 虚短 | virtual short | 负反馈未饱和时 $u_+ \approx u_-$（残余 µV 级）；"虚"= 电位相等而不走电流 | 第 08 讲 | 能默写、知道签证条件 |
| 虚断 | virtual open | 理想运放输入端不取电流 $i_+ = i_- = 0$；外部电阻回路照常导通 | 第 08 讲 | 能默写 |
| 虚地 | virtual ground | 反相组态中 N 点电位为 0 但非真接地：电流不进口、由伺服维持 | 第 08 讲 | 能讲清两个区别 |
| 电容 | capacitance | $q = Cu$；伏安关系 $i = C\,du/dt$（积分形式需初值 → 记忆元件）；直流稳态断路 | 第 09 讲 | 能默写、会用 |
| 电感 | inductance | $\psi = Li$；$u = L\,di/dt$；直流稳态短路；与电容全对偶 | 第 09 讲 | 能默写、会用 |
| 对偶 | duality | 替换 $u \leftrightarrow i$、$C \leftrightarrow L$：两元件结论互为镜像；串并联规则交叉对应 | 第 09 讲 | 能默画对偶表 |
| 状态与状态量 | state / state variable | 状态 = 决定电路未来的最小信息集；一阶电路状态量 = $u_C$ 或 $i_L$（不能突变）；$i_C$、$u_L$ 及一切电阻量可跳变 | 第 10 讲 | 能一眼分类 |
| 换路定则 | switching rule | $u_C(0^+)=u_C(0^-)$、$i_L(0^+)=i_L(0^-)$（有限性前提）；操作="保两条命"；配套 $0^+$ 等效电路（C→电压源、L→电流源） | 第 10 讲 | 能默写、会四步流程 |
| 零输入响应 | zero-input response | 激励为零、仅由初始储能驱动的响应；$u_C = u_C(0^+)e^{-t/\tau}$（RL 对偶） | 第 10 讲 | 能推导、会计算 |
| 时间常数 | time constant | $\tau = RC$（电容）/ $L/R$（电感）；残值每 τ ×0.368、初始切线交横轴于 τ、快慢刻度；与初始值无关 | 第 10 讲 | 能读曲线、能算 |

## 二、公式

| 公式 | 符号各指什么 | 适用条件 | 出处讲次 |
|---|---|---|---|
| $i = \dfrac{\mathrm{d}q}{\mathrm{d}t}$ | $q$ 为电荷量（C），$i$ 为电流（A） | 电流的一般定义（对变化电流同样成立） | 第 01 讲 |
| $I = \dfrac{Q}{t}$ | $Q$ 为时间 $t$ 内通过横截面的电荷量 | 直流情形（大小方向不变）的简化式 | 第 01 讲 |
| $U_{ab} = \dfrac{W_{ab}}{q}$ | $W_{ab}$ 为电荷 $q$ 从 a 端到 b 端转移的能量（J） | 电压的一般定义 | 第 01 讲 |
| $U_{ab} = -U_{ba}$ | — | 恒成立（换边走能量反号） | 第 01 讲 |
| $U_{ab} = V_a - V_b$ | $V_a$、$V_b$ 为对**同一**参考点的电位 | 恒成立；电压与参考点选择无关 | 第 01 讲 |
| $p = ui$ | $u$、$i$ 为**同一元件**的端电压与电流 | 关联参考方向下，$p$ 即吸收功率（正吸负发）；非关联时用 $p = -ui$ | 第 01 讲 |
| $W = Pt$ | $P$ 为不随时间变化的功率 | 直流情形的能量账 | 第 01 讲 |
| $u = Ri$（关联参考方向下） | $R$ 为线性电阻的阻值（Ω） | 线性电阻；求电流时反解 $i = u/R$ | 第 02 讲 |
| $u = U_S$ | $U_S$ 为给定电压 | 理想电压源（电流由外电路定） | 第 02 讲 |
| $i = I_S$ | $I_S$ 为给定电流 | 理想电流源（电压由外电路定） | 第 02 讲 |
| $u = U_S - R_i\,i$ | $R_i$ 为内阻（Ω） | 实际电源的端电压档案（下垂） | 第 02 讲 |
| $u_2 = \mu u_1$；$i_2 = g u_1$；$u_2 = r i_1$；$i_2 = \beta i_1$ | 受控源四类：VCVS（$\mu$ 无量纲）、VCCS（$g$，A/V）、CCVS（$r$，Ω）、CCCS（$\beta$ 无量纲） | 受控源的档案（控制量 $u_1/i_1$ → 输出） | 第 02 讲 |
| $\sum (\pm i) = 0$（**模板**：流出取 +、流入取 −；等价 $\sum i_{\text{出}} = \sum i_{\text{入}}$） | 流出/流入同一结点的电流 | KCL：任一结点（含广义结点） | 第 02 讲 |
| $\sum (\pm u) = 0$（**模板**：沿绕行方向降取 +、升取 −；等价 $\sum u_{\text{降}} = \sum u_{\text{升}}$） | 沿所选绕行方向经过各元件的电压升降 | KVL：任一回路；路径版用于求两点电压 | 第 02 讲 |
| $R_{eq} = R_1 + R_2 + \cdots$ | $R_k$ 为串联各电阻 | 串联等效 | 第 03 讲 |
| $G_{eq} = \sum G_k$（即 $1/R$ 相加；两电阻"积除和" $R_1R_2/(R_1+R_2)$） | $G = 1/R$ 为导纳（S） | 并联等效 | 第 03 讲 |
| $u_k = U \cdot \dfrac{R_k}{R_{eq}}$ | $U$ 为**该串联段两端的总电压**；$R_k$ 为所求元件（分子放自己） | 串联分压公式（该段须确为串联） | 第 03 讲 |
| $i_k = I \cdot \dfrac{G_k}{G_{eq}}$（两电阻 $i_1 = I\,\dfrac{R_2}{R_1+R_2}$） | $I$ 为**该并联段收到的总电流**；"分流看对面" | 并联分流公式 | 第 03 讲 |
| $U_S = I_S R_s$ | $R_s$ 在两种模型中为同一只电阻；方向：电流源箭头指向原电压源"+"端 | 电源两模型互换 | 第 03 讲 |
| $R_1 = \dfrac{R_{12}R_{31}}{R_{12}+R_{23}+R_{31}}$（及对称轮换） | 星臂 = 夹该端的两条 Δ 边之积 ÷ 三边之和 | Δ→Y 变换 | 第 03 讲 |
| $R_{12} = \dfrac{R_1R_2+R_2R_3+R_3R_1}{R_3}$ | 两两积之和 ÷ 对面星臂；对称时 $R_\Delta = 3R_Y$ | Y→Δ 变换 | 第 03 讲 |
| $R_{in} = u/i$ | 不含独立源的单口；外施激励法：加测试源→解另一量→取比值 | 输入电阻 | 第 03 讲 |
| 独立方程计数：$n-1$（KCL）与 $b-n+1$（KVL） | $n$ 为结点数、$b$ 为支路数 | 连通电路；平面电路的独立回路可取全部网孔 | 第 04 讲 |
| $R_{kk} I_k - \sum\limits_{j\neq k} R_{kj} I_j = U_{Sk}$（观察法） | $R_{kk}$ 自阻（正）、$R_{kj}$ 互阻（全同向约定下取负）、$U_{Sk}$ 本回路电压源升压代数和 | 回路电流法标准方程（全部回路默认顺时针） | 第 04 讲 |
| $\mathbf{G}\,\mathbf{U} = \mathbf{I}_S$（观察法） | $G_{kk}$ 自导纳（正）、$G_{kj}$ 互导纳（负）、右端注入电流和（流入为正；有伴电压源折算 $g\,U_S$） | 结点电压法标准方程（参考结点取 0；矩阵对称） | 第 05 讲 |
| $x = \sum_k x_k$（各独立源单独作用之和） | 置零规则：电压源→短路、电流源→开路；受控源保留；仅线性量（功率不叠，交叉项被丢） | 叠加定理 | 第 06 讲 |
| $u = U_{oc} - R_{eq}\,i$；$U_{oc} = I_{sc}R_{eq}$ | 戴维南/诺顿胶囊一对；三件套互验式 $R_{eq} = U_{oc}/I_{sc}$ | 线性含源二端网络的对外伏安关系 | 第 07 讲 |
