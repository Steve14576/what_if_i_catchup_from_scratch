> 这是一套**面向完全没系统学过概率统计的人**的教程。目标不是"看懂几个分布"，而是：学完你能单纯凭借它，通过一份正经的期末/考研水准概率统计考核，并且真的理解每个概念在随机世界里描述什么、边界在哪。

## 这门课是什么

概率论与数理统计是"研究随机性"的数学，也是数据科学、机器学习、计量经济、实验设计、金融工程几乎所有定量领域的公共语言。它的主线其实只有一句话：**把"不确定的事"，变成可计算、可推断的东西。**

- 概率 = 给"所有可能结果"分配权重；
- 随机变量 = 给每个结果贴一个数，好让我们对它做运算；
- 期望 / 方差 = 用一两个数概括一个随机现象的"中心"和"波动"；
- 大数定律 / 中心极限定理 = 样本一多，就会稳定、就会趋近正态；
- 数理统计 = 反过来，从眼前的样本去推断看不见的总体。

这套课从零开始，每一步都配三样东西：**直觉**（这个量在描述随机现象的哪一面）、**能笔算的小例子**（掷骰子、抽牌、一小组数据，贴近答卷）、**能跑的 numpy/scipy 数值实验**（用蒙特卡洛模拟或精确计算把结论坐实成具体数字）。你不需要任何概率统计基础，连古典概型和排列组合都从头讲。

## 前置

- 高中数学：会算比例、会解简单方程、见过求和号 $\sum$ 即可。
- 微积分：**不需要任何微积分基础**。课程内含数学工具附录 `BB_数学工具.md`（承载换元积分、分部积分、高斯积分 $\int_{-\infty}^{\infty}e^{-x^2/2}\,dx=\sqrt{2\pi}$、Gamma 函数等）；用到时会在原地给**最小说明**，再指向附录查阅，不空降一个没见过的积分。
- 线性代数：**同样不需要**。概率统计主干几乎不用矩阵；个别地方（如第 22 讲回归的最小二乘）会用标量方式推导或就地补一句话，不假设你学过线代。
- Python：不需要预先会。需要跑模拟实验时，讲义会当场给出可直接运行的代码；环境用 `uv`（不熟也没关系，只跑不改的话，照着复制即可）。

## 学完你能做什么

- [ ] 把"掷两枚骰子""抽一张牌"写成样本空间与事件，用加法公式、古典概型、几何概型算概率。
- [ ] 用排列组合数清情况数，分清"该加还是该乘""有序还是无序""放回还是不放回"。
- [ ] 算条件概率，用全概率公式、贝叶斯公式由果推因，判定事件的互斥与独立（及两两独立 vs 相互独立）。
- [ ] 认全常见分布（0-1、二项、泊松、几何、超几何、均匀、指数、正态），写出分布律或密度并说出各自描述的场景。
- [ ] 求随机变量函数的分布（一维的 $g(X)$、二维的 $X+Y$、$\max/\min$），会定积分区域、会用雅可比。
- [ ] 算数学期望、方差、协方差与相关系数，用切比雪夫不等式框概率，用大数定律与中心极限定理做近似。
- [ ] 由样本算统计量，理解 $\chi^2/t/F$ 三大抽样分布，说清正态总体 $\bar X,S^2$ 的分布。
- [ ] 做点估计（矩估计、极大似然）与区间估计，判断估计量的无偏/有效/一致。
- [ ] 做假设检验：$z/t$ 检验、卡方检验（拟合优度 + 列联表）、单因素方差分析、一元线性回归。
- [ ] 用 numpy/scipy 把抽象概率跑成具体数字——模拟频率坐实概率、重复抽样坐实抽样分布、重复检验坐实两类错误与功效。

| # | 讲 | 一句话 |
|---|---|---|
| 01 | 随机现象、样本空间与概率公理 | 概率是"样本空间上满足三公理的一种权重分配"；事件就是结果的集合，古典/几何概型都是"数比例" |

| 03 | 条件概率、独立性、全概率与贝叶斯 | "已知 A 发生"=缩小样本空间；全概率是加权平均，贝叶斯是由果推因、把先验更新为后验 |
| 04 | 随机变量与分布函数 | 随机变量是把每个结果贴一个数的**函数**；分布函数一个语言统一离散与连续 |
| 05 | 常见离散分布 | 0-1/二项/泊松/几何/超几何：各自描述什么场景、参数啥意思，泊松是二项的稀有事件极限 |
| 06 | 连续型随机变量与概率密度 | 密度不是概率、单点概率为 0、密度可以大于 1；均匀、指数与无记忆性 |
| 07 | 正态分布 | 正态密度每个符号啥意思、$\frac1{\sqrt{2\pi}}$ 从哪来、为什么要标准化，$3\sigma$ 法则与它的中心地位 |
| 08 | 一维随机变量函数的分布 | 求 $g(X)$ 的分布：分布函数法（通法）与公式法（单调可导）；$Y=X^2$ 这类非单调为什么要合并两侧 |
| 09 | 二维随机变量：联合、边缘、条件与独立性 | 联合能推边缘、边缘推不出联合；边缘=积掉对方；二维独立性怎么判 |
| 10 | 二维随机变量函数的分布 | 和的卷积 $\int f_X(x)f_Y(z-x)\,dx$、$\max/\min$ 的分布、二维代换与雅可比、积分区域怎么定 |
| 11 | 数学期望 | 期望为何按概率加权；LOTUS 不必先求分布；线性性**无条件**成立，乘积拆分才要独立 |
| 12 | 方差、矩与切比雪夫不等式 | 方差为何用平方；简化公式 $\mathrm{Var}(X)=E(X^2)-(EX)^2$；切比雪夫凭什么只用两个数框概率 |
| 13 | 协方差与相关系数 | 协方差在度量共同波动；相关系数为何夹在 $[-1,1]$；不相关 ≠ 独立（二维正态例外） |
| 14 | 大数定律与中心极限定理 | 依概率收敛；大数定律与 CLT 的分工；标准差里的 $\sqrt n$ 从哪来；CLT 不要求 X 正态 |
| 15 | 数理统计基础与抽样分布 | 总体/样本/统计量/自由度各指什么；$\chi^2/t/F$ 怎么构造、凭什么重要；正态总体 $\bar X,S^2$ 的分布 |
| 16 | 点估计：矩估计与极大似然 | 估计量 vs 估计值；矩估计为何"样本矩=总体矩"，MLE 为何"最像产生这份数据的参数" |
| 17 | 估计量的评价 | 无偏、有效、一致、MSE 分解；$S^2$ 为何除以 $n-1$ 才无偏；"有偏但方差小"更好吗 |
| 18 | 区间估计 | "95% 置信"到底置信的是谁；枢轴量是什么；何时用 $z$、何时用 $t$ |
| 19 | 假设检验：原理与正态总体参数检验 | 原假设/备择怎么设；两类错误为何此消彼长；$\alpha$ 与 $p$ 值什么关系；显著 ≠ 重要 |
| 20 | 卡方检验：拟合优度与列联表独立性 | $\sum(O-E)^2/E$ 从哪来；自由度怎么算；期望频数太小怎么办；为什么只用右尾 |
| 21 | 单因素方差分析 | 比较均值为何叫"方差分析"；平方和为何能拆成组间+组内；F 为何是两均方差之比；前提假设 |

## 每讲怎么用（固定循环）

1. 开头看**本讲目标**和**脉络图**，知道这讲要带你做出什么、途经哪几站。
2. 跟着**直觉**走——先建立"这个量在描述随机现象的哪一面"的感觉，再看严格定义。
3. 每个概念注意标注的**理解角度与深度**：是"要会推导/手算"、"要知道有这回事 + 去哪找它"、还是"建立直觉即可"。别把该建直觉的东西当公式背，也别把该手算的偷懒跳过。
4. 数值实验的每个实测数字，都能在 `scripts/` 里找到对应脚本复跑（文件名形如 `lecNN-01_verify_xxx.py`）。
5. 结尾**掌握度自测**全打勾 → 做**作业**（基础/提高/综合三档）→ 达标。
