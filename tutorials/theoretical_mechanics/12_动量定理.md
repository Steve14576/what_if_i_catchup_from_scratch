# 第 12 讲：动量定理——力的时间累积

> 前置：第 10 讲（牛二与两类问题）+ 第 01/03 讲（受力图、系统的整体法）｜ 预计投入：3–4 小时
> 本讲回答什么问题：碰撞、爆炸、互推这类"力未知且剧烈变化"的过程，牛二逐帧算不动怎么办？为什么一堆物体组成的系统里，**内力再热闹也不改变总动量**？质心凭什么"只听外力的"？

> **本讲目标（学完你能）：**
>
> 1. 用**冲量-动量定理**算短时过程的平均力（击球、刹车、缓冲）；
> 2. 给一个质点系，能取对系统、只画外力、**逐分量判断动量守恒**，并用守恒（或质心运动定理）解出碰撞/爆炸/人-船类问题的速度与位移；
> 3. 说清质心是什么（含与重心的关系）、"空爆碎片质心照原抛物线走"的原因；知道火箭类变质量系统为什么不能乱套守恒。
>
> 目标达成 = 文末"掌握度自测"全打勾。

> **怎么学这一讲：** 先看三张开场卡片（击球的 7250 N、互推两人的速度反比、空爆碎片的抛物线质心）→ 动量与冲量（牛二的第二种记账）→ 质点系与"内力退场"→ 守恒条件与判别 → 质心与质心运动定理 → 火箭彩蛋 → 数值验证 → 作业。本讲数值结论有归档脚本可复跑（`scripts/lec12-01_verify_momentum.py`，见 §6）。

## 0. 开场：力算不动的题，换账本

棒球手击球：球（$m = 0.145$ kg）以 40 m/s 飞来、被击后以 60 m/s 反向飞回。球棒与球的接触力**变化剧烈、函数未知**（毫秒内从零冲到峰值再归零）——牛二的 $m\mathbf{a} = \sum\mathbf{F}$ 逐帧算不动。但换本账就能算：

| 场景                      | 牛二直接算？   | 换账本的结果                                                                                     |
| ------------------------- | -------------- | ------------------------------------------------------------------------------------------------ |
| **击球**（§1）     | 力未知且剧变   | 动量账：$\Delta p = 14.5$ kg·m/s → 2 ms 内**平均力 7250 N**（约 740 倍球重）           |
| **冰面互推**（§3） | 推力未知       | 守恒账：两人速度与质量**成反比**（$m_1 v_1 + m_2 v_2 = 0$）——推得多猛都这个比          |
| **炮弹空爆**（§4） | 爆炸力无从知晓 | 质心账：碎片**质心照原抛物线走**（爆炸内力不改变质心轨迹）——只需动量守恒就能解出每块速度 |

共同点：**过程力算不动，但"力对时间的累积"（冲量）与系统整体的动量账可以绕开力细节直接结算**。这就是本讲的账本。

## 1. 动量与冲量：牛二的第二种记账

### 1.1 动量

$$
\mathbf{p} = m\,\mathbf{v}\ (\text{单位 kg·m/s} = \text{N·s}，\ \textbf{矢量})
$$

质量 × 速度——"运动量"的度量：同样速度下卡车比自行车"运动得多"，同样动量下轻物快、重物慢。

### 1.2 牛二的改写与冲量

把 $m\mathbf{a} = \sum\mathbf{F}$ 写成 $\mathbf{a} = \mathrm{d}\mathbf{v}/\mathrm{d}t$、两边乘 $m$（质量不随时间变）：

$$
\boxed{\;\frac{\mathrm{d}\mathbf{p}}{\mathrm{d}t} = \sum\mathbf{F}\;}\qquad\text{（牛二的动量形式——牛顿原版写的就是它）}
$$

对时间积分（把"瞬时关系"攒成"过程账"）：

$$
\boxed{\;\mathbf{p}_2 - \mathbf{p}_1 = \int_{t_1}^{t_2}\sum\mathbf{F}\,\mathrm{d}t \;\equiv\; \mathbf{I}\;}\qquad\text{（动量定理：}\Delta\mathbf{p} = \mathbf{I}\text{——冲量）}
$$

**冲量** $\mathbf{I} = \int\mathbf{F}\,\mathrm{d}t$：力对时间的累积（矢量、N·s）——"力作用了一段时间"的总效果。粗细不变的近似账：$\mathbf{I} \approx \mathbf{F}_{avg}\,\Delta t$（**平均力**），这正是"力细节未知也能算"的机关：函数不知道，**积分值**可以被 $\Delta p$ 反过来钉死。

### 1.3 例 1：击球的平均力

球 $m = 0.145$ kg，以 40 m/s 飞向击球手、击后以 60 m/s 反向飞回，接触时间 2 ms。取"飞回方向"为正：

$$
\Delta p = m(v_2 - v_1) = 0.145\times(60 - (-40)) = 14.5\ \text{kg·m/s}
$$

$$
F_{avg} = \frac{\Delta p}{\Delta t} = \frac{14.5}{0.002} = 7250\ \text{N}
$$

真实接触力在 2 ms 内的峰值可能远超此值（波形不知道），但**时间平均**被 $\Delta p$ 唯一锁定——安全帽、缓冲气垫、汽车吸能区的设计全都吃这一行公式（延长 $\Delta t$、摊薄 $F_{avg}$）。**理解层次**：动量定理与平均力**要会用**；$\mathrm{d}\mathbf{p}/\mathrm{d}t$ 形式**要能推导**（两行）。

## 2. 质点系动量定理：内力自动退场

### 2.1 总动量与内力抵消（牛三的动力学兑现）

取 $n$ 个质点为**系统**（L03 的选取纪律原样适用）。每个质点受的力分两类：**外力**（系统外给的）与**内力**（系统内互相给的）。把每个质点的牛二加起来：

$$
\frac{\mathrm{d}}{\mathrm{d}t}\left(\sum_i m_i\mathbf{v}_i\right) = \sum\mathbf{F}^{外} + \sum\mathbf{F}^{内}
$$

关键一步（L10 §1.3 埋的钩子在此回收）：**内力成对出现**——$\mathbf{F}_{ij}$ 与 $\mathbf{F}_{ji}$ 等值反向（牛三），逐对相加**恒为零**：

$$
\sum\mathbf{F}^{内} = \mathbf{0}
$$

### 2.2 质点系动量定理

$$
\boxed{\;\frac{\mathrm{d}\mathbf{P}}{\mathrm{d}t} = \sum\mathbf{F}^{外}\;},\qquad \mathbf{P} = \sum_i m_i\mathbf{v}_i\ (\text{总动量})
$$

**系统总动量的变化只由外力决定**——内力再热闹（爆炸、互推、内部碰撞），总账不动。积分形式同样成立：$\mathbf{P}_2 - \mathbf{P}_1 = \mathbf{I}^{外}$（外冲量）。这就是"绕开内力细节"的理论根基——§6 实验 2 用数值把"内力刚度扫三个量级、加不加耗散，前后总动量纹丝不动"逐格坐实。

## 3. 动量守恒定律

### 3.1 守恒条件（逐分量判断）

由质点系动量定理直接读出：

$$
\boxed{\;\sum\mathbf{F}^{外} = \mathbf{0}\ (\text{矢量})\ \Longrightarrow\ \mathbf{P} = \text{常矢量}\;}
$$

三个使用要点：

1. **逐分量判**：外力在某方向的分量和为零，则**该方向**动量守恒（不必整个矢量守恒）——炮弹斜抛：水平无外力（水平守恒）、竖直有重力（竖直不守恒）；
2. **"合外力为零"≠"外力都为零"**：外力可以有、只要矢量和为零（一对平衡力抵消也算）；
3. **近似口径**（碰撞的工程用法）：碰撞内力 $\gg$ 外力、过程极短（毫秒级）——外力的冲量可忽略，**过程前后**近似守恒。严格条件仍是"合外力（冲量）为零"，近似口径要声明。

### 3.2 例 2：两车非弹性碰撞（合体）

小车 $m_1 = 1500$ kg 以 20 m/s 向东、卡车 $m_2 = 1000$ kg 以 15 m/s 向西（对头碰撞后**合体**滑动）。取向东为正。碰撞瞬间摩擦冲量可忽略（近似口径）：

$$
m_1 v_1 + m_2 v_2 = (m_1 + m_2)\,v\;\Rightarrow\; v = \frac{1500\times 20 - 1000\times 15}{2500} = \frac{15000}{2500} = 6\ \text{m/s}\ (\text{向东})
$$

注意：**动量守恒不要求能量守恒**——此碰撞大量动能被"耗散"掉（变成车体变形与热、不可回收），两本账必须分开记（能量账 L15 才立）。

### 3.3 例 3：跳船

人（60 kg）从静止的小船（120 kg）上以相对**岸** 3 m/s 水平跳离（水阻力不计）。取向跳离方向为正：

$$
0 = m_{人}v_{人} + m_{船}v_{船} \;\Rightarrow\; v_{船} = -\frac{60\times 3}{120} = -1.5\ \text{m/s}\ (\text{船后退})
$$

相对速度 = 3 + 1.5 = 4.5 m/s。**规律**：静止系统分裂，两部分速度与质量成反比（$v_{人}/|v_{船}| = m_{船}/m_{人}$）——冰面互推、发射后坐、原子核反冲，同一行公式的换装。

## 4. 质心与质心运动定理

### 4.1 质心：系统的"平均位置"

$$
\boxed{\;\mathbf{r}_C = \frac{\sum m_i\mathbf{r}_i}{M}\;},\qquad M = \sum m_i
$$

**质心**：按质量加权的平均位置——不一定是哪个质点的位置（哑铃的中点在空处）。对时间求导（$\dot{\mathbf{r}}_C = \frac{\sum m_i\mathbf{v}_i}{M}$）：

$$
\mathbf{P} = M\,\mathbf{v}_C
$$

——**总动量 = 总质量 × 质心速度**：一个系统在动量账本上等价于"全部质量堆在质心上的一个质点"。

**与重心的关系**：均匀重力场中（各点 $g$ 相同）重心 = 质心（把重心公式 $\sum W_i\mathbf{r}_i/\sum W_i$ 的 $W = mg$ 约掉即得）——L04 重心公式的动力学身份就此揭盅。离开均匀场（航天、大尺度）两者分离，**动力学里认质心**。

### 4.2 质心运动定理

把 $\mathbf{P} = M\mathbf{v}_C$ 代入质点系动量定理：

$$
\boxed{\;M\,\mathbf{a}_C = \sum\mathbf{F}^{外}\;}
$$

**内力再热闹，质心只听外力的**——系统整体的"平移账"等价于一个质点的牛二。三个立即推论：

- 合外力为零 → $\mathbf{v}_C$ 恒定（**质心运动守恒**；静止则质心位置钉死）；
- 空中物体（只受重力）→ $\mathbf{a}_C = \mathbf{g}$——**无论内部怎么炸**；
- 内力只能改变"内部怎么分"，动不了"整体去哪"。

### 4.3 例 4：炮弹空中爆炸（守恒解 + 质心复核，双视角闭环）

**题目**：炮弹 $m = 20$ kg 以 $v_0 = 100$ m/s、$45°$ 发射，在**最高点**爆炸为 $m_1 = 15$ kg 与 $m_2 = 5$ kg 两块，$m_1$ 恰好**竖直下落**（水平速度归零）。求 $m_2$ 的水平速度与两块落点（相对发射点）。

**守恒解**（爆炸内力 $\gg$ 重力、瞬间完成——水平方向外力为零、动量守恒）。最高点参数：$v_x = 100\cos 45° = 70.71$ m/s、$t_h = v_{y0}/g = 7.22$ s、$x_h = 70.71\times 7.22 = 510.2$ m、$h = (100\sin 45°)^2/2g = 255.1$ m：

$$
20\times 70.71 = 15\times 0 + 5\times v_2 \;\Rightarrow\; v_2 = 282.8\ \text{m/s}
$$

**两块落点**：从高 255.1 m 落地用时 $t_f = \sqrt{2h/g} = 7.22$ s（与上升时间相同——抛体对称）：

- $m_1$：水平速度零 → 落在最高点正下方，$x_1 = 510.2$ m；
- $m_2$：$x_2 = 510.2 + 282.8\times 7.215 = 2551.3$ m（中间量多留一位）。

**质心复核**（双视角闭环）：正常弹道射程 $= v_0^2\sin 90°/g = 1020.4$ m。爆炸不改变质心轨迹（$M\mathbf{a}_C = M\mathbf{g}$ 不变），两块落地时：

$$
x_C = \frac{15\times 510.2 + 5\times 2551.3}{20} = \frac{7653 + 12756.5}{20} = 1020.4\ \text{m}\ ✓
$$

与正常射程精确吻合——守恒解与质心账互相咬合。**这就是"侦察弹坑定位火炮"的原理**：不管炮弹怎么炸，弹坑的"质心"仍在原弹道上。

### 4.4 例 5：走船（质心位置不变 + 几何约束）

人（60 kg）在静止小船（120 kg）上相对**船**走了 5 m（船浮于静水、阻力不计）。求人与船各自相对**岸**的位移。

**质心账**：初始静止 + 水平无外力 → 质心位置**不动**：

$$
60\,x_{人} + 120\,x_{船} = 0
$$

**几何账**（相对位移）：

$$
x_{人} - x_{船} = 5\ (\text{人相对船走 5 m})
$$

联立：$x_{人} = 5\times\frac{120}{180} = 3.33$ m、$x_{船} = -1.67$ m（船退）。**位移同样反比于质量**（例 3 的速度反比在这里攒成了位移反比）——"你在船上走多远"和"船让你走了多远"是两笔账，岸上的观察者只认后者的合成。

**下一站**：动量是"力对时间的累积"账本。力还有另外两本账：对**轴**的累积（动量矩——转动版的动量，L13）和对**路程**的累积（功——能量账本，L15）。三本账各管一类守恒。

## 5. 彩蛋：火箭与变质量系统（为什么不能乱套守恒）

火箭烧掉燃料喷出燃气、自己越飞越轻——**系统的"名单"每一刻都在换人**（燃气离队）。动量守恒依然成立（无外力时），但必须对"**t 到 t+dt 的瞬时系统**"记账：t 时刻火箭（质量 $m$、速度 $v$）；dt 内喷出质量 $\mathrm{d}m$（相对火箭以速度 $u$ **向后**喷）、火箭增速 $\mathrm{d}v$。对"火箭 + 即将喷出的那团气"这个瞬时系统用守恒：

$$
m\,v = (m - \mathrm{d}m)(v + \mathrm{d}v) + \mathrm{d}m\,(v - u)
$$

展开、舍去二阶小量（$\mathrm{d}m\,\mathrm{d}v$）：

$$
m\,\mathrm{d}v = u\,\mathrm{d}m \;\Rightarrow\; \int\!\!\;\mathrm{d}v = u\int \frac{\mathrm{d}m}{m}
$$

$$
\boxed{\;\Delta v = u\,\ln\frac{m_0}{m_1}\;}\qquad\text{（齐奥尔科夫斯基公式）}
$$

**数字**：喷气速度 $u = 2000$ m/s、质量比 $m_0/m_1 = 4$（烧掉四分之三）→ $\Delta v = 2000\times\ln 4 = 2773$ m/s。质量比翻到 8 才再涨 1386 m/s——**对数增长**是火箭的宿命（多级火箭的存在理由）。

**初学者大坑**（为什么"乱套"错）：直接拿"初态火箭动量 = 末态火箭动量"对账——错在**喷出去的燃气带着动量离队了**，不在末态名单里。变质量的账必须逐时刻记（每 dt 重新圈系统）；数值上这正是 §6 实验 5 做的事（积分逐时刻的 $m\,\mathrm{d}v = u\,\mathrm{d}m$，与齐氏公式对账）。

## 8. 本讲小结（一页骨架）

- **动量与冲量**：$\mathbf{p} = m\mathbf{v}$（矢量）；牛二改写 $\mathrm{d}\mathbf{p}/\mathrm{d}t = \sum\mathbf{F}$；积分成过程账 $\Delta\mathbf{p} = \mathbf{I}$（冲量 = 力的时间累积；$\mathbf{F}_{avg} = \Delta p/\Delta t$ 钉死未知力的平均值）。
- **质点系**：总动量 $\mathbf{P} = \sum m_i\mathbf{v}_i$；**内力成对抵消**（牛三兑现）→ $\mathrm{d}\mathbf{P}/\mathrm{d}t = \sum\mathbf{F}^{外}$——内力再热闹、总账不动。
- **守恒**：$\sum\mathbf{F}^{外} = 0$（**逐分量判**）⇒ $\mathbf{P}$ 守恒；近似口径 = 内力 ≫ 外力 + 短时（碰撞）；分裂/合体/互推类速度与质量成反比。
- **质心**：$\mathbf{r}_C = \sum m_i\mathbf{r}_i/M$（加权平均、可在空处；均匀重力场中 = 重心）；$\mathbf{P} = M\mathbf{v}_C$；**质心运动定理 $M\mathbf{a}_C = \sum\mathbf{F}^{外}$**——空中系统 $\mathbf{a}_C = \mathbf{g}$ 无论内部怎么炸；走船类 = 质心不动 + 几何约束联立。
- **变质量（彩蛋）**：$\Delta v = u\ln(m_0/m_1)$；逐时刻圈系统，不能拿初末态直接对账。
- **下一站**：力对**轴**的累积（动量矩）——转动版动量定理，L13；力对**路程**的累积（功）——能量账本，L15。

## 10. 作业（先独立做，再看参考答案——答案只用本讲内容）

**题 1（判断，每小题答"对/错" + 一句理由）**
(a) 系统内力不改变系统的总动量。
(b) 系统动量守恒时，动能也一定守恒。
(c) 冲量是标量。
(d) 质心必定位于系统内某个质点所在处。
(e) 碰撞过程中若内力远大于外力且过程极短，可近似用动量守恒。

**参考答案：**
(a) **对**。内力成对出现、等值反向（牛三），逐对相加恒为零（§2.1）。
(b) **错**。非弹性碰撞动量守恒、动能大损——两本账泾渭分明（例 2/§6 Exp 2：动量不动、动能掉到 68%）。
(c) **错**。冲量 $\int\mathbf{F}\,\mathrm{d}t$ 是矢量（N·s）；一维问题里它的方向藏在符号中（§1.2）。
(d) **错**。质心是加权平均位置，可以在空处（哑铃中点、例 4 的弹坑"质心"）（§4.1）。
(e) **对**。近似守恒的工程口径——但要声明"近似"且只用于过程前后（§3.1）。

**题 2** 球 $m = 0.2$ kg 以 15 m/s 撞墙、以 10 m/s 反向弹回，接触 0.01 s。求球对墙的平均冲力。

**参考答案：**
取向墙为正：$\Delta p = m(v_2 - v_1) = 0.2\times(-10 - 15) = -5$ kg·m/s（方向离墙）。
墙给球的平均力 $F = \Delta p/\Delta t = -500$ N；**球对墙的冲力 +500 N**（牛三，指向墙）。

**题 3** 人 $m = 70$ kg 从静止的船（$M = 210$ kg）上以相对岸 2.5 m/s 跳离。求船速与人船相对速度。

**参考答案：**
$0 = 70\times 2.5 + 210\,v_{船} \Rightarrow v_{船} = -0.833$ m/s（后退）。
相对速度 $= 2.5 + 0.833 = 3.33$ m/s。

**题 4** 炮弹 $m = 30$ kg 以 200 m/s 水平飞行，空中爆炸成 20 kg 与 10 kg 两块，大块以 100 m/s 沿原方向继续飞。求小块速度。

**参考答案：**
水平动量守恒：$30\times 200 = 20\times 100 + 10\,v_2 \Rightarrow 6000 = 2000 + 10 v_2 \Rightarrow v_2 = 400$ m/s（原方向）。

**题 5** 人 $m = 50$ kg 在静止船（$M = 150$ kg）上相对船走 6 m（静水无阻力）。求人对岸与船对岸的位移。

**参考答案：**
质心不动：$50\,x + 150\,y = 0$；相对位移：$x - y = 6$。
联立：$x = 6\times\frac{150}{200} = 4.5$ m（人对岸）；$y = -1.5$ m（船退）。

**题 6** 光滑水平面上 $m_1 = 2$ kg 与 $m_2 = 6$ kg 之间夹一压缩弹簧，释放后 $m_1$ 获得 6 m/s。求 $m_2$ 速度与系统质心加速度；若地面摩擦系数 $f = 0.1$（两块都在滑动），质心加速度又是多少？

**参考答案：**
释放瞬间水平无外力：$0 = 2\times 6 + 6\,v_2 \Rightarrow v_2 = -2$ m/s。
光滑：质心加速度 $= 0$（合外力为零——弹簧内力不进质心账）。
有摩擦：合外力 $= -f(m_1+m_2)g$（与运动方向相反）$\Rightarrow a_C = -fg = -0.98$ m/s²——**内力（弹簧）仍然不进质心账**，摩擦外力独挑。

**题 7（代码题）** 两球（$m_1 = 2$、$m_2 = 4$ kg，$v_1 = 3$、$v_2 = 0$ m/s）以接触弹簧（$k$）模拟一维碰撞。数值积分碰撞全程，验证碰撞前后总动量相等；再把 $k$ 改大 100 倍重跑，观察总动量结论不变。参考骨架（补全后运行）：

```python
import numpy as np

m1, m2, v1, v2 = 2.0, 4.0, 3.0, 0.0
L = 1.0                        # natural length of contact spring

def collide(k):
    x1, x2, w1, w2 = 0.0, L, v1, v2     # positions and velocities
    dt, t_end = 1e-5, 1.0
    n = int(round(t_end / dt))
    for _ in range(n):
        dx = x2 - x1 - L                  # overlap (negative = compressed)
        if dx < 0:                        # contact force (internal pair)
            F = -k * dx                   # pushes them apart
        else:
            F = 0.0
        w1 -= F / m1 * dt                 # F on m1 is -F (opposite pair)
        w2 += F / m2 * dt
        x1 += w1 * dt
        x2 += w2 * dt
    return m1 * w1 + m2 * w2

P_before = m1 * v1 + m2 * v2
for k in (100.0, 10000.0):
    P_after = collide(k)
    print("k=%7.1f: P_before=%.6f, P_after=%.6f, diff=%.1e"
          % (k, P_before, P_after, abs(P_after - P_before)))
```

**参考答案：** 运行输出：`k=100.0: P_before=6.000000, P_after=6.000000, diff≈0`（数值积分精度内）与 `k=10000.0: P_before=6.000000, P_after=6.000000, diff≈0`——**刚度放大 100 倍、碰撞时间缩 10 倍、碰后速度分配完全不同（试打印 w1、w2 看），总动量纹丝不动**（对照 §6 实验 2：能量账才随 k 变）。要点：接触力 $\mathbf{F}$ 与 $-\mathbf{F}$ 这对**内力**在两个方程里同时出现、大小相等方向相反——"内力抵消"在代码里就是这两行的存在本身。
