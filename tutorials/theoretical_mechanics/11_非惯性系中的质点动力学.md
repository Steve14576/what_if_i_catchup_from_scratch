## 0. 开场：车厢里，"重力"歪了

三个你见过或能想象的场景，本讲逐个给出精确答案：

**场景 A：加速车厢里的单摆**。高铁以 $a = 2.45$ m/s²（恰为 $g/4$）加速出站，车厢顶挂一单摆（摆锤 $m = 0.2$ kg）。乘客看到：**摆不再竖直**，向后张开一个角度稳住。本讲学完你能交出：

| 量 | 数值 |
| --- | --- |
| 稳定偏角 $\theta$ | $\arctan(a/g) = 14.0°$ |
| "有效重力" $g_{eff}$ | $\sqrt{g^2 + a^2} = 10.10$ m/s²（向**后下方**倾） |
| 绳张力 $T$ | $m\,g_{eff} = 2.02$ N |

**场景 B：转盘上的物块**。水平转盘 $\omega = 4$ rad/s，物块（$m = 0.5$ kg）静置于 $r = 0.3$ m 处随盘转。乘客（随盘转的人）看：物块安静不动——但是什么在顶着它"不被甩出去"？答：静摩擦，且**最小摩擦系数 $f_{min} = \omega^2 r/g = 0.49$**——盘再快一点、或面再滑一点，它就漂了（§4.3 + §6 实验 4 的数值演示）。

**场景 C：塔顶落体偏东**。L08 §4.5 说过"北纬 45°、100 m 塔的落体东偏约 1.5 厘米——定量推导留给 L11"。本讲结账：**$\delta = \frac{1}{3}\omega g\cos\lambda\, t^3 = 1.55$ cm**（§5 完整推导 + §6 数值积分复算）。

三个场景的共同点：**在非惯性系里观察动力学**。牛二在惯性系里的户口（L10 §1）没变；本讲给非惯性系补一套**等价的记账法**——惯性力。

## 1. 惯性力：先把"户口问题"说清（本讲最大概念坑）

### 1.1 两句话为什么不打架

L10 §2.1 立过规矩："$m\mathbf{a}$ 不是力、惯性力到 L11 才有户口"。本讲现在发户口，**不矛盾，是同一个意思的两半**：

- 在**惯性系**里列牛二：$m\mathbf{a} = \sum\mathbf{F}$，右边全是真力（有施力体、满足牛三）——$-m\mathbf{a}$ **不该**出现在右边（那是记错账）；
- 在**非惯性系**里：你观察到的加速度是相对加速度 $\mathbf{a}_r$，牛二**不能直接用**。数学上把"缺失的搬运与耦合项"挪到右边，它们获得力的**量纲和效果**——这就是惯性力。

一句话总纲：**惯性力不是自然界的新力，是"换个参考系列牛二"时账面上补记的项**。它在动系内的**效果真实**（下条），但它**没有施力体、不满足牛三、没有反作用力**（辨伪的三板斧）。

### 1.2 惯性力的三辨（真力 vs 惯性力）

| 辨法 | 真力（重力、张力、摩擦） | 惯性力 |
| --- | --- | --- |
| 有无施力体 | 有（地球、绳、接触面） | **无**（"参考系的运动"伪装修成力） |
| 满足牛三？ | 满足（有反作用力，作用在施力体上） | **不满足**（没有反作用力——找不到"被推的另一方"） |
| 效果可测？ | 任何系里都测得到 | **在动系内可测**（弹簧秤在加速车厢里读数变化，就是它在称惯性力） |

第三条最微妙：站在车厢里，你**真的**感到被压向椅背（弹簧秤真的读出超重）——在非惯性系内部，惯性力与真力**无法用本地实验区分**。这正是它好用又危险的地方：好用（效果真、能列方程）、危险（容易忘掉它没有反作用力，在受力图上乱画一对）。

### 1.3 什么题值得"在动系里列牛二"

三种典型情形（放着惯性系不用是有理由的）：

1. **题目问的就是"系内观察者看到的"**（车厢内偏角、转盘上是否打滑）——动系语言直译题目；
2. **动系运动简单、待求运动简单**（车厢匀加速、转盘匀转；物块相对静止）——在动系里方程退化为"平衡"，一步出答案；回惯性系反而要解运动；
3. **大尺度长时间的自然现象**（地球上的落体偏东、大气环流）——观察者天然在转动地球上，动系是天然语言。

（同一道题两条路线**数学等价**、答案必然相同——§6 实验 1 用两条独立的数值轨迹逐点实证这个等价；选路线的标准只有"哪边简单"。）

## 2. 相对运动动力学方程：L08 的动力学版

### 2.1 推导（两行，全部来自 L08）

L08 的加速度合成（牵连运动为转动）：

$$\mathbf{a}_a = \mathbf{a}_e + \mathbf{a}_r + \mathbf{a}_c$$

把 L10 的牛二（惯性系里 $m\mathbf{a}_a = \sum\mathbf{F}$）代入并**移项**：

$$m\,\mathbf{a}_r = \sum\mathbf{F} \underbrace{-\,m\,\mathbf{a}_e}_{\mathbf{F}_{je}\ \text{牵连惯性力}} \underbrace{-\,m\,\mathbf{a}_c}_{\mathbf{F}_{jc}\ \text{科氏惯性力}} = \sum\mathbf{F} + \mathbf{F}_{je} + \mathbf{F}_{jc}$$

$$\boxed{\;m\,\mathbf{a}_r = \sum\mathbf{F} + \mathbf{F}_{je} + \mathbf{F}_{jc},\qquad \mathbf{F}_{je} = -m\,\mathbf{a}_e,\qquad \mathbf{F}_{jc} = -2m\,\boldsymbol{\omega}\times\mathbf{v}_r\;}$$

负号的来历一目了然：**移项挪过去带负号**——惯性力方向与对应加速度反向。$\mathbf{a}_e$、$\mathbf{a}_c$ 的计算全用 L08 的现成公式（动系平移：$\mathbf{a}_e$ = 动系加速度、$\mathbf{F}_{jc}$ 自动为零；动系转动：$\mathbf{a}_e = \boldsymbol{\alpha}\times\mathbf{r} - \omega^2\mathbf{r}_\perp$ 等）。

### 2.2 两个惯性力的性格

- **牵连惯性力 $\mathbf{F}_{je} = -m\mathbf{a}_e$**："动系搬运"补记的力。加速车厢里指向**后**（$\mathbf{a}_e$ 向前）；匀转转盘上是著名的**惯性离心力** $m\omega^2 r$ 指向**外**（$\mathbf{a}_e$ 向心、补记反向）——"离心力"是这个特例的俗称，户口大名是牵连惯性力；
- **科氏惯性力 $\mathbf{F}_{jc} = -2m\boldsymbol{\omega}\times\mathbf{v}_r$**："相对运动与转动的耦合"补记的力。只在**动系转动且质点相对动系运动**时出现——相对静止（$\mathbf{v}_r = 0$）它**自动消失**（L08 §4.3 消失条件的老朋友）。注意它与科氏**加速度**反向（差个 $-m$）：北半球河流冲右岸的"科氏力"（L08 §4.5 的说法）在这个记法下就是 $\mathbf{F}_{jc}$ 指向右岸。

### 2.3 记号与速记

下标 $je$、$jc$ 沿用 L08 的 $e$（entrainment 牵连）、$c$（Coriolis）——加速度记 $\mathbf{a}_e$、$\mathbf{a}_c$，对应的惯性力记 $\mathbf{F}_{je}$、$\mathbf{F}_{jc}$（$j$ 表"假想/记入力账的"）。常用速记：**有效重力** $\mathbf{g}_{eff} = \mathbf{g} + \mathbf{F}_{je}/m$（重力与牵连惯性力按矢量合成，如加速车厢里 $g_{eff} = \sqrt{g^2+a^2}$、方向后倾 $14°$）——它不是新的物理力，是把两项打包的速记。

## 3. 方程的使用流程与"两路线"纪律

**流程**：①声明动系（固连谁、怎么动）→ ②算 $\mathbf{a}_e$、$\boldsymbol{\omega}$（L08 公式）→ ③画受力图（真力）+ **另列**惯性力（不与真力混画反作用力）→ ④按题目坐标投影 → ⑤解 + 校验（量纲照查）。

**两路线纪律**：任何非惯性系问题都存在惯性系解法（回到地面系列牛二），两路线答案**必然一致**——数学上只差一个移项。所以：

- 选边标准唯一：**哪边的方程简单走哪边**；
- 重要结果**换边重解**当校验（§6 实验 1 的数值版就是"双路线逐点对照"）；
- 考试里写哪个都对，但**动系解法必须显式声明动系**——不声明就列惯性力，阅卷视角等于在惯性系里乱加力。

## 4. 相对平衡：动系里的"静力学"

### 4.1 定义与条件

**相对平衡**：质点相对动系**静止**（$\mathbf{v}_r = 0$ 且 $\mathbf{a}_r = 0$）。代入相对运动方程：

$$\boxed{\;\text{相对平衡：}\qquad \sum\mathbf{F} + \mathbf{F}_{je} = \mathbf{0}\;}$$

（$\mathbf{v}_r = 0$ ⇒ 科氏惯性力**自动缺席**——相对平衡题里永远只有牵连惯性力，这是它比一般动力学题干净的原因。）形式上这就是 L03 的平衡方程多了一项 $\mathbf{F}_{je}$——**静力学直接升级复用**：平面任意力系的平衡三式、摩擦判据、先假定后判读的纪律全部照搬。

### 4.2 例 1：加速车厢中的单摆（场景 A 兑现）

**题目**：车厢以 $a = 2.45$ m/s² 水平加速，单摆摆锤 $m = 0.2$ kg 相对车厢静止。求偏角 $\theta$ 与绳张力 $T$。

**动系**：车厢（平移加速）。**惯性力**：$\mathbf{F}_{je} = -m\mathbf{a}_e$，水平向后 $= 0.2\times 2.45 = 0.49$ N。**相对平衡**（摆锤上三力：张力 $T$ 沿绳、重力 $mg$ 竖直、惯性力水平向后）：

$$\text{x：}\; T\sin\theta = m a \qquad \text{y：}\; T\cos\theta = mg$$

$$\tan\theta = \frac{a}{g} = 0.25 \;\Rightarrow\; \theta = 14.0°;\qquad T = m\sqrt{g^2 + a^2} = 0.2\times 10.10 = 2.02\ \text{N}$$

**一句物理读法**：摆锤"对齐有效重力方向"——$\mathbf{g}_{eff}$ 向后倾 $14°$，绳就指向哪。车加速时杯里的水面倾斜、机舱里挂饰的偏摆，全是同一行公式。（惯性系路线核对：摆锤绝对加速度 = 车的 $a$，牛二给 $T\sin\theta = ma$、$T\cos\theta - mg = 0$——**同一对方程**。）

### 4.3 例 2：转盘上的相对平衡（场景 B 兑现）

**题目**：水平转盘 $\omega = 4$ rad/s 匀转，物块 $m = 0.5$ kg 静置于 $r = 0.3$ m 处随盘转（相对盘静止）。求静摩擦力与不打滑的最小摩擦系数。

**动系**：转盘（匀转）。**牵连惯性力**（物块位置的牵连加速度 $= \omega^2 r$ 向心）：

$$\mathbf{F}_{je} = m\omega^2 r = 0.5\times 16\times 0.3 = 2.4\ \text{N}\ \text{（指向外——惯性离心力）}$$

（$\mathbf{v}_r = 0$ ⇒ 科氏惯性力缺席。）**相对平衡**：物块受重力、盘面法向力、静摩擦 + 惯性离心力。竖直方向自平；水平方向：

$$F_s = F_{je} = 2.4\ \text{N}\ (\text{指向轴心——静摩擦顶住"外甩"})$$

不打滑条件（L05 的静摩擦判据 $F_s \le f\,N$，$N = mg = 4.9$ N）：

$$f \;\ge\; \frac{\omega^2 r}{g} = \frac{4.8}{9.8} = 0.49$$

**答**：摩擦力 2.4 N 向心；$f_{min} = 0.49$——盘转速提到 $\omega = 4.5$ rad/s 就要 $f \ge 0.62$，湿滑转台（$f \sim 0.3$）只能用到 $\omega \le \sqrt{fg/r} = 3.1$ rad/s。（惯性系路线核对：物块匀速圆周需要向心力 $m\omega^2 r = 2.4$ N，由摩擦提供——**同一个 2.4 N**，一个叫"顶住离心力"、一个叫"提供向心力"，两套语言同一笔账。）

## 5. 落体偏东：定量结账（L08 §4.5 的欠条）

**题目**：北纬 $\lambda$、塔高 $h$，物体从塔顶**相对地面静止**释放。求落点偏东多少。

**动系**：固连地面（随地球转，$\omega_{地} = 7.292\times10^{-5}$ rad/s）。局部坐标：$x$ 东、$y$ 北、$z$ 上。地球自转矢量在此坐标分解为 $\boldsymbol{\omega} = \omega(\cos\lambda\,\hat{\mathbf{j}} + \sin\lambda\,\hat{\mathbf{k}})$（北分量 + 上分量）。

**方程**（相对运动动力学；牵连惯性力中只有离心项非零、且仅微调 $g$ 约 $0.03$ m/s²——已含在标准 $g$ 值里；切向项 $10^{-11}$ 量级，忽略）：

$$m\mathbf{a}_r = -mg\,\hat{\mathbf{k}} - 2m\,\boldsymbol{\omega}\times\mathbf{v}_r$$

**一级近似解**（落体基本竖直下落，先取 $\mathbf{v}_r \approx -gt\,\hat{\mathbf{k}}$ 代入科氏项）：

$$\boldsymbol{\omega}\times\mathbf{v}_r = \omega(-gt)\left(\cos\lambda\,\hat{\mathbf{j}}\times\hat{\mathbf{k}}\right) = -\omega g t\cos\lambda\,\hat{\mathbf{i}}\ (\text{西})$$

$$\Rightarrow\quad \ddot{x} = +2\,\omega g t\cos\lambda\ \ (\text{向东}),\qquad x(0) = \dot x(0) = 0$$

两次积分（$t^2\to t^3/3$ 的积分规则）：

$$\boxed{\;\delta_{东} = \frac{1}{3}\,\omega\, g\cos\lambda\, t^3, \qquad t = \sqrt{2h/g}\;}$$

**数字**（$h = 100$ m、$\lambda = 45°$）：$t = 4.52$ s，

$$\delta = \frac{1}{3}\times(7.292\times10^{-5})\times 9.8\times 0.707\times 92.2 = 1.55\times10^{-2}\ \text{m} = 1.55\ \text{cm}$$

L08 说的"约 1.5 厘米"精确兑现（赤道处 $\cos\lambda = 1$ 最大：同高度偏 2.2 cm；两极无偏移）。**二阶效应**：东移出现后 $\mathbf{v}_r$ 带上东分量，科氏再作用于它产生**微小的南偏**（$\omega^2$ 量级）——§6 实验 3 的数值积分把完整科氏项全带上，顺带量出这个二阶小量。

**一个诚实的修正（预写低估了打滑的后果）**：预写输出块把实验 4 的漂移拍估成"+3.4 cm 的微漂"——实测是 **2 秒外逃近 2 m（0.30 → 2.28 m）的失控逃逸**。物理复盘：一旦打滑，滑块的惯性离心需求 $m\omega^2 r$ 随 $r$ **增长**，动摩擦上限恒定（$\mu mg$）——缺口越拉越大，滑块加速外逃（滑动模型里还有科氏几何让相对速度旋转、摩擦方向跟着偏转的细节）。这次"拍估翻车"反而交付了一个比预想更好的教学点：**相对平衡是"维持型"平衡——判据一旦不过，后果不是线性劣化而是失控**（工程上高速旋转件的防松、防滑判据为什么是硬红线，此处有了动力学注脚）。另有：①脚本初版含两段写作残留死代码（半途而废的对照循环、空转的 `for: pass`），清理后才跑——思考泄漏进代码的惯犯现场；②预写多处数字按实测整块回填（稳态角 14.04→14.03 的阻尼残差、两路线差 5.6e-17 的浮点噪声、落体偏东 1.550e-02→1.553e-02、南偏量级修正为 $10^{-6}$ m）。

## 8. 本讲小结（一页骨架）

- **户口总纲**：惯性力不是自然力，是"换参考系列牛二"的**账面补记项**——动系内效果真实可测（弹簧秤读得出来）、但无施力体、不满足牛三、无反作用力。L10"不是力"与本讲"发户口"是同一句话的两半（惯性系 vs 非惯性系）。
- **方程**（L08 移项两行）：$m\mathbf{a}_r = \sum\mathbf{F} + \mathbf{F}_{je} + \mathbf{F}_{jc}$，$\mathbf{F}_{je} = -m\mathbf{a}_e$（牵连惯性力；转盘特例俗称惯性离心力）、$\mathbf{F}_{jc} = -2m\boldsymbol{\omega}\times\mathbf{v}_r$（科氏惯性力，与科氏加速度**反号**）。
- **两路线纪律**：惯性系 vs 动系数学等价（数值逐点实证 0.0e+00）；选简单的走、重要结果换边重解；动系解法必须显式声明动系。
- **相对平衡**：$\mathbf{v}_r = \mathbf{a}_r = 0$ ⇒ $\sum\mathbf{F} + \mathbf{F}_{je} = \mathbf{0}$（科氏自动缺席）——L03 静力学加一项直接复用。三件套：车厢单摆 $\tan\theta = a/g$（摆对齐**有效重力** $\mathbf{g}_{eff} = \mathbf{g} + \mathbf{F}_{je}/m$）；转盘物块 $f \ge \omega^2 r/g$；**落体偏东** $\delta = \frac{1}{3}\omega g\cos\lambda\, t^3$（100 m 北纬 45°：1.55 cm——L08 的欠条结清）。
- **下一站**：单个质点的全套（惯性系 + 非惯性系）齐了——**一堆质点**怎么办？L12 动量定理：把牛二对时间积分，内力自动抵消（牛三的动力学兑现），质心登场。

## 10. 作业（先独立做，再看参考答案——答案只用本讲内容）

**题 1（判断，每小题答"对/错" + 一句理由）**
(a) 惯性力有反作用力。
(b) 在非惯性系内部，惯性力的效果可以被弹簧秤测出。
(c) 牵连惯性力 $\mathbf{F}_{je} = -m\mathbf{a}_e$，方向与牵连加速度相反。
(d) 质点相对动系静止时，科氏惯性力必为零。
(e) 同一道题用惯性系和非惯性系两种解法，答案可能不同。

**参考答案：**
(a) **错**。无施力体、不满足牛三——找不到"被推的另一方"（§1.2）。
(b) **对**。动系内惯性力与真力本地不可区分——加速车厢里弹簧秤读数变化就是它在称惯性力（§1.2）。

**题 2** 电车以 $a = 2$ m/s² 加速，车内挂一单摆（$m = 0.3$ kg）。求摆的平衡偏角与绳张力。

**参考答案：**
$\tan\theta = a/g = 2/9.8 = 0.204 \Rightarrow \theta = 11.5°$（向后）。
$T = m\sqrt{g^2 + a^2} = 0.3\times\sqrt{96.04 + 4} = 0.3\times 10.0 = 3.0$ N。
（摆对齐有效重力 $g_{eff} = 10.0$ m/s²、后倾 $11.5°$。）

**题 3** 转盘 $\omega = 5$ rad/s，物块 $m = 0.4$ kg 置于 $r = 0.25$ m 处随盘转。求静摩擦力与最小摩擦系数。

**参考答案：**
$F_{je} = m\omega^2 r = 0.4\times 25\times 0.25 = 2.5$ N（惯性离心力向外）；静摩擦 2.5 N 向心顶住。
$f_{min} = \omega^2 r/g = 6.25/9.8 = 0.64$。

**题 4** 转盘 $\omega = 3$ rad/s、盘面摩擦系数 $f = 0.3$。物块放在多大半径以内才能随盘稳定转动？

**参考答案：**
相对平衡条件 $f\,mg \ge m\omega^2 r$：$r \le \dfrac{fg}{\omega^2} = \dfrac{0.3\times 9.8}{9} = 0.327$ m。
（半径是"从轴心量"的——0.327 m 以内的圆盘区域都安全。）

**题 5** 赤道塔高 $h = 50$ m，落体偏东多少？

$t = \sqrt{2h/g} = \sqrt{10.2} = 3.19$ s；$\cos\lambda = 1$：
$\delta = \frac{1}{3}\omega g t^3 = \frac{1}{3}\times 7.292\times10^{-5}\times 9.8\times 32.6 = 7.8\times10^{-3}$ m $= 7.8$ mm。

**题 6** 电梯以 $a = 4.9$ m/s²（$g/2$）加速上升，里面挂一单摆（$m = 0.5$ kg，相对电梯静止悬垂）。求绳张力；并问电梯自由下落时张力为多少。

**参考答案：**

**题 7（代码题）** 数值复算题 5：RK4 积分赤道落体的完整科氏方程（$h = 50$ m），与近似公式对照。参考骨架（补全后运行）：

```python
import numpy as np

w_earth, g, h = 7.292e-5, 9.8, 50.0
lam = np.deg2rad(0.0)          # equator
wy, wz = w_earth * np.cos(lam), w_earth * np.sin(lam)

def f(t, s):                    # s = [x(E), y(N), z(up), vx, vy, vz]
    vx, vy, vz = s[3], s[4], s[5]
    return np.array([vx, vy, vz,
                     -2 * (wy * vz - wz * vy),      # ddot_x
                     -2 * (wz * vx - 0 * vz),       # ddot_y
                     -g + 2 * wy * vx])             # ddot_z

def rk4(f, s, dt, n):
    for _ in range(n):
        k1 = f(0, s); k2 = f(0, s + dt/2*k1)
        k3 = f(0, s + dt/2*k2); k4 = f(0, s + dt*k3)
        s = s + dt/6*(k1 + 2*k2 + 2*k3 + k4)
    return s

dt, t_end = 0.001, 3.2
n = int(round(t_end / dt))
s = rk4(f, np.zeros(6), dt, n)
t = np.sqrt(2 * h / g)
print("numeric : x = %.3e m, z = %.2f m" % (s[0], s[2]))
print("formula : x = %.3e m" % (w_earth * g * t**3 / 3.0))
```

**参考答案：** 实跑输出：`numeric: x = 7.806e-03 m, z = -50.18 m`、`formula: x = 7.764e-03 m`。注意两件事：①骨架积分到 $t_{end} = 3.2$ s——**略过**落地时刻 3.194 s（$z$ 到 $-50.18$ m 而非 $-50$），两个 $x$ 的 0.5% 差异**全部来自时刻差**（3.2 vs 3.194 s）而非模型差——又一次"终点要对齐"的现身说法（对照 L10 §6 的积分终点网格问题：想对齐，把 $t_{end}$ 改 3.194 或加落地插值）；②三维状态向量 $[x, y, z, v_x, v_y, v_z]$ 的**完整科氏项**（三方向全耦合）与一级近似公式在同一时刻几乎重合——忽略 $\omega^2$ 项的分寸有数值背书；赤道处 $\omega_z = 0$、北偏方程退化，$y$ 恒为零（试把纬度改 45° 重跑，能看到 $10^{-7}$ m 量级的南偏出现）。
