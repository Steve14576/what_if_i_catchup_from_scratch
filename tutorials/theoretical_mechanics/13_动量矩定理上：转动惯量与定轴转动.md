## 0. 开场：收臂变快之谜

花样滑冰员旋转中**把手臂收拢**，转速明显加快——手臂是自己的肌肉（**内力**）收回来的，L12 刚说过"内力不改变总动量"，那内力凭什么改变转速？还有更扎心的追问：能量也变多了（转得更快），能量从哪来？

本讲结束时你能交出这张账单（数字版 §3 现场推）：

| 量                               | 收臂前                | 收臂后                                      |
| -------------------------------- | --------------------- | ------------------------------------------- |
| 转动惯量$I$                    | 4 kg·m²（双臂展开） | 1.6 kg·m²（收拢贴身）                     |
| 角速度$\omega$                 | 2 rad/s               | **5 rad/s**（快 2.5 倍）              |
| **动量矩 $L = I\omega$** | 8 kg·m²/s           | **8 kg·m²/s（不变！）**             |
| 转动动能$\frac{1}{2}I\omega^2$ | 8 J                   | 20 J（**多出 12 J**——肌肉收臂做功） |

谜底预告：**守恒的是"动量矩"这个新账本，不是角速度**；转速是"动量矩 ÷ 转动惯量"，收臂让分母变小、商变大。而能量账（L15 正式开）不守恒——肌肉做了正功。一个动作、三本账、三种结论——这就是"三本账"地图的实战。

## 1. 动量矩：转动的"运动量"

### 1.1 为什么 $mv$ 不够

动量 $m\mathbf{v}$ 度量平移的"运动量"。但一个绕轴转的系统：每个质点都有 $m\mathbf{v}$、合起来总动量却可能是**零**（对过质心的轴，左右两半的速度恰好抵消）——"转得飞快、动量为零"，动量这本账对转动**失明**。转动需要自己的度量：**动量对轴的矩**。

### 1.2 定义（质点对轴）

$$
\boxed{\;L_z = m\,v\,r\;}\qquad\begin{aligned}&m\text{——质量}\\&v\text{——速度在垂直于轴的平面内的分量}\\&r\text{——质点到轴的垂直距离}\end{aligned}
$$

（对定轴转动的质点：$v = \omega r$，故 $L_z = m r^2\,\omega$；$L_z$ 是带符号的代数量，转向正方向取正。）结构与 L02 的力矩**完全平行**：

| 平移账                                 | 转动账                                        |
| -------------------------------------- | --------------------------------------------- |
| 力$\mathbf{F}$（因）                 | 力矩$M_z(\mathbf{F}) = \pm Fd$（因——L02） |
| 动量$\mathbf{p} = m\mathbf{v}$（果） | **动量矩 $L_z = mvr$**（果——本讲）  |

力矩改变动量矩（§2 的定理），就像力改变动量（L12 的定理）——**同一套因果，两副坐标**。

### 1.3 质点系与刚体

质点系对轴的总动量矩 $L_z = \sum_i m_i v_i r_i$。**刚体定轴转动**（每个质点同 $\omega$、各自的 $r_i$）：

$$
L_z = \sum m_i r_i^2\,\omega = \left(\sum m_i r_i^2\right)\omega\;\equiv\;J\,\omega
$$

$$
\boxed{\;L_z = J\,\omega\;}\qquad J = \sum m_i r_i^2\ (\text{或连续体 } J = \int r^2\,\mathrm{d}m)
$$

$J$ 就是**转动惯量**（§4 正式开箱）——它把"一整块刚体的转动"压缩成一个数，$L = J\omega$ 与 L12 的 $\mathbf{P} = M\mathbf{v}_C$ 遥相平行（转动账/平移账各一个"总运动量"公式）。

## 2. 动量矩定理（对固定轴）

### 2.1 质点版（两行推导）

把 L02 的力矩再算一遍，只是"被作用对象"从力换成动量随时间的变化：

$$
\frac{\mathrm{d}}{\mathrm{d}t}\left(m\,v\,r\right) = M_z\ (\text{外力对轴之矩的代数和})
$$

（严格推导走矢量叉乘 $m\mathbf{r}\times\mathbf{a} = \mathbf{r}\times\mathbf{F}$ 的 $z$ 分量——结论一致；平面情形用"对轴之矩"的代数记法最省事。）

### 2.2 质点系版与刚体版

对**质点系**：内力矩成对抵消（牛三给力矩版同样的待遇——两质点间的作用反作用力对任何轴的矩之和为零），只剩外力矩：

$$
\boxed{\;\frac{\mathrm{d}L_z}{\mathrm{d}t} = \sum M_z^{外}\;}\qquad\text{（对固定轴）}
$$

**刚体定轴转动特例**（$L_z = J\omega$，$J$ 恒定）：

$$
\boxed{\;J\,\alpha = \sum M_z^{外}\;}\qquad\text{（刚体定轴转动微分方程——}\S5\text{ 主武器）}
$$

与 $ma = \sum F$ 的**逐项平行**：

| 平移                    | 定轴转动                    |
| ----------------------- | --------------------------- |
| $ma = \sum F$         | $J\alpha = \sum M_z$      |
| 质量$m$（难推的程度） | 转动惯量$J$（难拧的程度） |
| 加速度$a$             | 角加速度$\alpha$          |
| 力$F$                 | 力矩$M_z$                 |
| $mv$ 动量             | $J\omega$ 动量矩          |

### 2.3 "固定轴"前提（L14 的钩子）

定理**只对固定轴（或过特殊点的轴）**成立——对"随便一根动轴"直接套会算错（动量矩的求导里会多出轴运动的耦合项）。对**质心轴**恰好也成立（这是幸运的特例，L14 讲平面运动时正式启用）；一般动轴的完整账本超出本课程范围。**纪律：写方程前先声明轴是固定的。**

## 3. 动量矩守恒

### 3.1 条件与读法

由定理直接读出：

$$
\boxed{\;\sum M_z^{外} = 0\ \Longrightarrow\ L_z = \text{常数}\;}
$$

注意"守恒的是 $L_z$"（$= J\omega$）——**不是** $\omega$：$J$ 变、$\omega$ 就反向变。这就是收臂之谜的钥匙。

### 3.2 例 1：收臂加速（开场账单现场推）

滑冰员初始 $I_1 = 4$ kg·m²、$\omega_1 = 2$ rad/s。收臂过程：**对竖直轴的外力矩为零**（重力过轴、冰面支承近似过轴）→ $L_z$ 守恒：

$$
I_1\omega_1 = I_2\omega_2 \;\Rightarrow\; \omega_2 = \frac{4\times 2}{1.6} = 5\ \text{rad/s}\ (2.5\ \text{倍})
$$

**三本账各说一句**：

- 动量矩账：$L = 8$ kg·m²/s 不变（守恒）；
- 动量账：内力不管多热闹、总动量照旧不动（L12）——但动量这本账对绕质心的转动**本来就失明**，这里它没发言权；
- 能量账：$\frac{1}{2}I_2\omega_2^2 - \frac{1}{2}I_1\omega_1^2 = 20 - 8 = 12$ J——**不守恒**，多出的能量是肌肉收臂克服"离心甩开"做的功（收臂要费劲，劲没白费）。

**有心力**一句带过（考试另一高频守恒源）：太阳对行星的引力永远指向日心（力过轴 ⇒ 矩为零）→ 行星轨道运动的动量矩守恒——开普勒第二定律（等面积律）的力学身份。

## 4. 转动惯量：转动的"质量"

### 4.1 定义与两个敏感

$$
J = \sum m_i r_i^2\quad(\text{连续体： }J = \int r^2\,\mathrm{d}m)
$$

**"质量 × 离轴距离的平方"**——两个敏感：

1. **对轴的位置敏感**：同一根杆，绕端点 $ml^2/3$、绕中点 $ml^2/12$——差 4 倍；
2. **对质量分布敏感**：同样 $m$、同样外径，质量全摊在外缘（薄环 $mR^2$）是质量均匀摊开（圆盘 $\frac{1}{2}mR^2$）的 **2 倍**——"远处的质量算平方倍"。飞轮把质量集中在轮缘、直升机尾桨要轻而靠外缘配重，都是吃这条。

（量纲：kg·m²。**注意**：$J$ 不是"惯量"本身——空间刚体对不同轴有不同 $J$，说 $J$ 必须同时说轴。）

### 4.2 常见形体表（考试查表基准）

| 均质形体                  | 轴的位置                   | $J$                              |
| ------------------------- | -------------------------- | ---------------------------------- |
| 细杆$m, l$              | 过中点、垂直杆             | $\dfrac{1}{12}ml^2$              |
| 细杆$m, l$              | 过端点、垂直杆             | $\dfrac{1}{3}ml^2$               |
| 薄圆盘$m, R$            | 过中心、垂直盘面（对称轴） | $\dfrac{1}{2}mR^2$               |
| 均质圆柱$m, R$          | 对称轴                     | $\dfrac{1}{2}mR^2$               |
| 薄壁圆环$m, R$          | 对称轴                     | $mR^2$                           |
| 厚壁圆筒$m, R_外, R_内$ | 对称轴                     | $\dfrac{1}{2}m(R_外^2 + R_内^2)$ |
| 均质球$m, R$            | 任一直径                   | $\dfrac{2}{5}mR^2$               |

（表的用法纪律：**先核对轴**再抄数——考试错误一半出在"盘的 $\frac{1}{2}mR^2$ 用在了绕直径轴上"这类张冠李戴。）

### 4.3 平行轴定理

$$
\boxed{\;J_{z'} = J_{C} + m\,d^2\;}\qquad\begin{aligned}&J_C\text{——过\textbf{质心}、与 }z'\text{ 平行的轴的转动惯量}\\&d\text{——两轴间距}\end{aligned}
$$

**推导**（一行，离散版）：设 $z'$ 轴相对过质心的 $C$ 轴平移 $\mathbf{d}$，每个质点 $\mathbf{r}_i' = \mathbf{r}_i + \mathbf{d}$：

$$
J_{z'} = \sum m_i|\mathbf{r}_i'|^2 = \sum m_i r_i^2 + 2\,\mathbf{d}\cdot\underbrace{\sum m_i\mathbf{r}_i}_{=M\mathbf{r}_{C,\text{相对}C\text{轴}}\,=\,0} + d^2\sum m_i = J_C + md^2
$$

中间项为零**正因为 $C$ 轴过质心**——这就是定理的**使用边界**：**两根轴中必须有一根过质心**。两根都不过质心的平行轴之间不能直接用（要分两步走）。

**例 2**：均质杆 $m = 10$ kg、$l = 1.2$ m，转轴垂直于杆、距杆端 0.3 m（杆上）。轴偏离中点 $d = 0.3$ m：

$$
J = \frac{ml^2}{12} + md^2 = \frac{10\times 1.44}{12} + 10\times 0.09 = 1.2 + 0.9 = 2.1\ \text{kg·m}^2
$$

（验算习惯：直接积分 $\int_0^{0.9}\frac{m}{l}(x+0.3)^2\mathrm{d}x$？不必——平行轴就是替你积分的。数值验证在 §6 实验 2。）

### 4.4 组合法与负质量法

- **组合法**：复杂形体拆成表内形体，$J$ 相加（同轴）。带轮 = 轮盘 + 轮毂 + 轮辐，各查各的表再加；
- **负质量法**：**挖孔**的形体 = 完整形体 −"孔"（质量、转动惯量都取负）。条件：**同材料、等厚度**（孔的质量按面积比例折算）。

（挖孔实操：孔若不在轴上，"孔的 $J$"自己要用平行轴（$J_{孔} = J_{孔质心} + m_{孔}d_{孔}^2$）——漏平移项是负质量法的高发错误。）

### 4.5 回转半径

$$
J = m\,\rho^2 \;\Rightarrow\; \rho = \sqrt{J/m}
$$

**回转半径** $\rho$："把这块质量摊成一个**薄环**、使 $J$ 不变"的等效半径——一个把任意形体的 $J$ 折算成直觉量的标签（如某飞轮 $J = 8$ kg·m²、$m = 50$ kg → $\rho = 0.4$ m："等效于半径 0.4 m 的薄环"）。

## 5. 刚体定轴转动微分方程：$J\alpha = \sum M_z$

### 5.1 方程与解题流程

$J\alpha = \sum M_z^{外}$（§2.2 的刚体版）。解题流程与 L10 的五步同构，只换账本：

$$
\text{①取对象（绕哪根定轴转）} \to \text{②画外力矩（不过轴的力才有力矩——力矩版的"矩心红利"）} \to \text{③算 } J \to \text{④列 } J\alpha = \sum M_z \to \text{⑤解（}\alpha\text{ 常量走匀变速三式）}
$$

**矩心红利再现**（L03 的老朋友）：轴承反力**过轴**（力过轴矩为零）——它被方程自动消掉。定轴问题里未知的轴承反力**不进 $J\alpha$ 方程**（要它得另走 L12 质心运动定理，§5.4）。

### 5.2 例 3：绞盘下放重物（组合系统的整体账）

**题目**：矿井绞盘 $J = 2$ kg·m²、半径 $r = 0.5$ m，缠绕钢绳下放重物 $m = 40$ kg；制动闸对绞盘施加恒定制动矩 $M_b = 148$ N·m。从静止开始，求角加速度、3 s 末的角速度与重物速度、下放深度。

**整体动量矩账**（对绞盘轴；重物挂在绳上，把"绞盘 + 重物"取为一个系统）：系统对轴的动量矩 = 绞盘 $J\omega$ + 重物 $mvr$（$v = \omega r$）：

$$
L = J\omega + m r^2\,\omega = (J + mr^2)\,\omega
$$

外力矩（对轴）：重物重力给 $mgr$（驱动）、制动力矩 $-M_b$（轴承反力与钢绳拉力——绳张力是**内力**、轴承反力**过轴**，都不出力矩）。动量矩定理（对固定轴）：

$$
(J + mr^2)\,\alpha = mgr - M_b = 40\times 9.8\times 0.5 - 148 = 196 - 148 = 48
$$

$$
\alpha = \frac{48}{2 + 40\times 0.25} = \frac{48}{12} = 4\ \text{rad/s}^2,\qquad a = \alpha r = 2\ \text{m/s}^2
$$

3 s 末：$\omega = \alpha t = 12$ rad/s、$v = 6$ m/s、下放深度 $= \frac{1}{2}at^2 = 9$ m。

**结构读法**：$(J + mr^2)$ 是"组合系统对轴的等效转动惯量"——重物被折算成 $mr^2$ 的转动惯量（挂在半径 $r$ 上的"转动质量"）。**对比另一条路**：分开列（绞盘 $J\alpha = M_{绳}r - M_b$、重物 $ma = mg - M_{绳}$、约束 $a = \alpha r$）三式联立消绳张力——结果相同、路更绕。整体账是"先消内力"的转动版（L12 §2 的精神平移到转动账）。

### 5.3 例 4：飞轮的指数制动（变力矩）

**题目**：飞轮 $J = 2$ kg·m² 以 $\omega_0 = 20$ rad/s 转，制动矩与转速成正比 $M_b = c\,\omega$（$c = 0.5$ N·m·s）。求 $\omega(t)$ 与 4 s 内转过的圈数。

**方程**（只有制动力矩）：

$$
J\,\frac{\mathrm{d}\omega}{\mathrm{d}t} = -c\,\omega \;\Rightarrow\; \omega = \omega_0\,e^{-ct/J}
$$

（分离变量——L06/L10 的老朋友；特征时间 $\tau = J/c = 4$ s，"转速的指数衰减"。）4 s 时 $\omega = 20e^{-1} = 7.36$ rad/s；转角 $\theta = \omega_0\tau\,(1 - e^{-t/\tau}) = 80\times(1-e^{-1}) = 50.6$ rad $= 8.0$ 圈。**对照**：恒定制动矩 $M_b = c\omega_0 = 10$ N·m 会 4 s 停死（$\alpha = -5$）——比例制动"先猛后柔"，物理直觉来自"转得快时摩擦发热大、力矩也大"。

### 5.4 轴承反力需求：偏心转子的 20 倍账

$J\alpha = \sum M_z$ 里轴承反力**被消掉了**——但这不代表它小。求它要换 L12 的账本：**质心运动定理**。

**例 5（量级警示）**：圆盘 $m = 10$ kg、质心偏离转轴 $e = 2$ mm、转速 $n = 3000$ r/min（$\omega = 314.2$ rad/s）。质心做半径 $e$ 的匀速圆周 → $a_C = e\omega^2$：

$$
F_{轴承} = m\,e\,\omega^2 = 10\times 0.002\times 314.2^2 = 1974\ \text{N}
$$

自重才 $98$ N——**动反力是自重的 20 倍**，方向随转动**旋转**（每转一圈方向转一圈，轴承高频交变载荷——疲劳之源）。这就是"转子必须做**动平衡**"（把偏心质量配平掉的工艺）的力学根据：2 mm 的加工误差在高速下放大成 2 kN 的交变力。**定轴转动问题的完整解 = $J\alpha$ 方程（给角加速度）+ 质心运动定理（给轴承反力）两本账一起走。**

**一个诚实的修正（球的数值积分权重 bug）**：实验 1 首跑球的 $J$ 给 0.2667（应为 0.32）——不是精度问题，是**物理模型错**：切片法把球的质量沿 $z$ **均匀分**（每片 $m/2000$），算出来的其实是"边缘加厚的串珠串"而不是均匀球。均匀球的边缘片薄、质量应按**面积（$r^2$）加权**——修正权重后误差骤降到 $4\times10^{-8}$。教训：**离散化一个连续体时，"每个网格块分多少质量"本身就是物理建模**——分错了，收敛得再好也是在逼近一个错的形体。（预写输出块的 err 值也按实测整块回填——杆/盘/环的实际网格误差比预写小几个量级。）

三个读点：① 四个查表公式被网格数值积分**逐个坐实**（杆 $10^{-7}$、盘 $10^{-8}$、环 $10^{-6}$、球 $10^{-8}$）——表不是背的、是可复算的；② 平行轴定理在 500 组随机质点系上**恒等到浮点噪声**（$10^{-15}$）——一行推导的普适性；③ 收臂模拟：$L$ 全程守恒、$\omega$ 从 2 到 5、动能恰增 12 J——开场账单的每一格都有数背书。

## 8. 本讲小结（一页骨架）

- **动量矩**：$L_z = mvr$（质点对固定轴）、$L = J\omega$（刚体）——转动的运动量（动量对转动失明，$L$ 补位）。与力矩 $M_z$ 因果配对。
- **动量矩定理**（对**固定轴**）：$\mathrm{d}L_z/\mathrm{d}t = \sum M_z^{外}$（内力矩成对抵消）；刚体定轴：$J\alpha = \sum M_z$——与 $ma = \sum F$ 逐项平行（$m\leftrightarrow J$、$F\leftrightarrow M$、$v\leftrightarrow\omega$）。
- **守恒**：$\sum M_z^{外} = 0 \Rightarrow L_z$ 恒——收臂 $I\downarrow\ \omega\uparrow$（守恒的是 $L$ 不是 $\omega$；能量增 = 肌肉做功）；有心力（引力）轨道守恒 → 开普勒第二定律。
- **转动惯量**：$J = \sum mr^2 = \int r^2\mathrm{d}m$（kg·m²）——对轴位置与质量分布双敏感；查表（杆/盘/环/筒/球）+ **平行轴** $J_{z'} = J_C + md^2$（一根必须过质心）+ 组合/负质量 + 回转半径 $\rho = \sqrt{J/m}$（等效薄环）。
- **定轴转动解题**：$J\alpha = \sum M_z$（矩心红利：轴承反力过轴自动消）+ 匀变速三式（$\alpha$ 常量）；组合系统 $(J + mr^2)\alpha$ 整体账；变矩分离变量（指数制动）。
- **轴承反力**：另开 L12 质心运动定理的账；偏心 $me\omega^2$ 高速放大 20 倍且方向交变——**动平衡**的力学根据。
- **下一站**：对固定轴的账本立好了——L14 把动量矩定理开到**质心轴**（相对质心的动量矩定理），配上质心运动定理，得到刚体**平面运动微分方程**（三个方程：$x$、$y$、$\varphi$）——动力学篇的合体大招。

## 10. 作业（先独立做，再看参考答案——答案只用本讲内容）

**题 1（判断，每小题答"对/错" + 一句理由）**
(a) 动量矩是标量。
(b) 同一刚体对不同轴的转动惯量可以不同。
(c) 花样滑冰收臂转速变快，说明动量矩不守恒。
(d) 平行轴定理适用于任意两根相互平行的轴。
(e) 刚体定轴转动微分方程对任何位置的轴都成立。

**参考答案：**
(a) **错**。对轴的动量矩是带符号的代数量（转向藏在符号里）——不是无方向的标量（§1.2）。
(b) **对**。$J$ 是"刚体+轴"的配对属性（§4.1）。
(c) **错**。守恒的是 $L = I\omega$；$I$ 变小 $\omega$ 变大正是守恒的表现（§3.2）。
(d) **错**。必须有一根过质心（§4.3 推导的中间项）。
(e) **错**。只对**固定轴**（质心轴是特例，L14）（§2.3）。

**题 2** 均质细杆 $m = 12$ kg、$l = 2$ m。求绕端点与绕中点的转动惯量，并用平行轴定理互验。

**参考答案：**
绕中点：$J_C = \frac{ml^2}{12} = \frac{12\times 4}{12} = 4$ kg·m²；绕端点：$J = \frac{ml^2}{3} = 16$ kg·m²。
平行轴互验：$J_C + md^2 = 4 + 12\times 1^2 = 16$ ✓（$d = l/2 = 1$ m）。

**题 3** 均质圆盘 $m = 20$ kg、$R = 0.4$ m，中心挖去直径 $0.2$ m 的圆孔（同材料等厚）。求剩余部分绕对称轴的 $J$。

**参考答案：**
孔质量按面积比：$m_{孔} = 20\times\frac{0.1^2}{0.4^2} = 1.25$ kg。
负质量法（孔与盘同心、平移项为零）：

$$
J = \frac{1}{2}mR^2 - \frac{1}{2}m_{孔}r^2 = \frac{1}{2}\times 20\times 0.16 - \frac{1}{2}\times 1.25\times 0.01 = 1.6 - 0.00625 = 1.594\ \text{kg·m}^2
$$

**题 4** 转台上的表演者 $I_1 = 6$ kg·m²、$\omega_1 = 1.5$ rad/s（无外矩）。收臂后 $I_2 = 2$ kg·m²。求 $\omega_2$ 与动能增量，并说明能量来源。

**参考答案：**
$\omega_2 = I_1\omega_1/I_2 = 6\times 1.5/2 = 4.5$ rad/s。
$\Delta E = \frac{1}{2}I_2\omega_2^2 - \frac{1}{2}I_1\omega_1^2 = 20.25 - 6.75 = 13.5$ J——收臂做功（克服离心趋势）。

**题 5** 绞盘 $J = 1.5$ kg·m²、$r = 0.3$ m，下放 $m = 30$ kg 重物，制动矩 $M_b = 70$ N·m。求角加速度与重物加速度；从静止 2 s 后重物速度。

$(J + mr^2)\alpha = mgr - M_b = 88.2 - 70 = 18.2$：
$\alpha = 18.2/(1.5 + 30\times 0.09) = 18.2/4.2 = 4.33$ rad/s²；$a = \alpha r = 1.30$ m/s²。
2 s 末 $v = 2.60$ m/s。

**题 6** 飞轮 $J = 4$ kg·m² 受恒定驱动力矩 $M = 60$ N·m，从静止启动。求 2 s 末角速度与转过的圈数。

**题 7（代码题）** 随机生成 200 个质点（质量与位置随机），验证平行轴定理：先算质心与过质心轴的 $J_C$，再对一根平移 $\mathbf{d} = (0.3, 0.2)$ 的平行轴算 $J'$，对照 $J_C + md^2$。参考骨架（补全后运行）：

```python
import numpy as np

rng = np.random.default_rng(7)
m = rng.uniform(0.1, 2.0, 200)
xy = rng.uniform(-1.0, 1.0, (200, 2))

rC = (m[:, None] * xy).sum(axis=0) / m.sum()     # center of mass
rel = xy - rC                                    # positions relative to C
J_C = (m * (rel ** 2).sum(axis=1)).sum()         # about axis through C (z-dir)

d = np.array([0.3, 0.2])
rel2 = xy - (rC + d)                             # about shifted parallel axis
J_p = (m * (rel2 ** 2).sum(axis=1)).sum()

print("J_C = %.6f, J' = %.6f" % (J_C, J_p))
print("J_C + m d^2 = %.6f" % (J_C + m.sum() * (d ** 2).sum()))
print("diff = %.2e" % abs(J_p - J_C - m.sum() * (d ** 2).sum()))
```

**参考答案：** 运行输出（数值随机、结构恒等）：`diff = 0.00e+00` 或 $10^{-16}$ 量级——**逐点严格成立**。要点：代码里 `rel`（相对质心）与 `rel2`（相对平移轴）**逐点相差同一个 $\mathbf{d}$**——把每点的 $|\mathbf{r}+\mathbf{d}|^2$ 展开成 $r^2 + 2\mathbf{r}\cdot\mathbf{d} + d^2$ 后，交叉项 $\sum m\mathbf{r}$ **正因为参考点是质心而精确为零**——平行轴定理的推导（§4.3）在代码里逐质点重演；把 `rC` 换成任意非质心点重跑，`diff` 立刻变大——"一根必须过质心"的边界亲手可见。
