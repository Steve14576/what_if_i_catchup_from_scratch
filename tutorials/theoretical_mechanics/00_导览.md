# 理论力学：从零到拉格朗日

> 这是一套写给"没系统学过理论力学、但有真实考试要打"的工科机械学生的完整讲义。
> 从画第一张受力图，一直走到用拉格朗日方程建模、算出共振曲线。

## 这门课是干什么的

理论力学回答三类问题：

1. **东西为什么不动**——静力学。结构与机构上的力怎么传、怎么算，约束给了什么反力。
2. **东西怎么动**——运动学。位置、速度、加速度怎么描述，"又转又平"的刚体速度怎么分布。
3. **东西为什么这么动**——动力学。牛顿定律与三大定理（动量、动量矩、动能），再加两件趁手兵器：达朗贝尔原理（把动力学问题伪装成平衡问题）和拉格朗日方程（不画受力图的万能建模法）。最后落到振动——工程里最常见的运动形态。

对机械专业，这门课是机构原理、机械设计、机械振动的地基：机构运动分析立在刚体平面运动上，机构受力分析立在达朗贝尔与虚功原理上。

## 前置要求

- **高中物理**：力的基本概念、牛顿定律的定性认识。这是 L01 的起点。
- **微积分与线性代数**：学过但不扎实完全可以——本讲义的策略是**用到现场补**：求导（L06 用到，现场讲怎么用）、叉乘（L07 用到，现场讲几何意义）、微分方程（L10 用到，分离变量法现场教）、矩阵特征值（L21 用到，只用到"算 2×2 特征值"这一步，现场给）。**不需要**先去补一轮数学再回来。
- 不需要任何理论力学基础。

## 怎么学这套讲义

每讲固定循环：**先看成品（这一讲结束时你能做出什么）→ 拆解（缺什么补什么）→ 例题里练 → 掌握度自测 → 作业**。

- 自测全打勾才算讲过，别只"看懂了"——受力分析这类技能，看懂和会画隔着一条鸿沟，作业就是桥。
- 每讲预计投入 2–4 小时（正文 + 作业），动力学后半场（L13–L16）和 L19 会更重。
- 数值实验不用会编程也能跟：脚本都能直接跑，看懂 print 出来的对照结论就算过；会 Python 更好，改改参数自己玩。

## 学完能做什么（全课程达标判据）

- 拿到静力学题（含摩擦、桁架、物体系）：能独立取分离体、列平衡方程、解出全部未知量，并判断静定/静不定；
- 拿到运动学题（含合成运动、平面运动）：能选对方法（基点/瞬心/合成运动），解出指定点的速度与加速度；
- 拿到动力学题（含刚体平面运动、碰撞）：能判断用哪个定理、能联立求解，能判断哪些量守恒；
- 拿到理想约束下的机构或质点系：能用达朗贝尔原理或虚位移原理处理，能用拉格朗日方程从零建模；
- 拿到一个弹簧-质量系统：能算固有频率、能画出幅频曲线、能说清共振条件和对策；
- **只靠这套讲义，应对工科理论力学期末考试。**

## 考试前怎么用这份讲义

1. 按讲过一遍各讲的"掌握度自测"，打不了勾的讲回正文补；
2. 重做每讲作业里当时做错或没做的题（答案平铺在题下，先独立做再对照）；
3. 翻 `AA_一览.md` 过一遍概念与公式字典，重点过"适用条件"列——考试丢分大半丢在用错条件，不是算错数；
4. L16（三大定理选型）和 L22（收口一页图）是考前速览的入口。
