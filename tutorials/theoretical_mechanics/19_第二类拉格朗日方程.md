## 0. 开场：双摆的两种命运

**双摆**：摆 1（$m_1$、$l_1$）挂在顶点，摆 2（$m_2$、$l_2$）挂在摆 1 的锤上。自由度 2（L18 §5.1——$\theta_1$、$\theta_2$）。

**牛顿法**（L10–L14 的老路）：对两个质点各画受力图——摆 1 受重力 + **两根绳的张力**（$T_1$、$T_2$——未知！）、摆 2 受重力 + 张力 $T_2'$。列 4 个直角坐标方程（每质点 2 个）、含 2 个未知张力；再写摆长约束消坐标——**消元量：两组三角函数**，方程长得狰狞。

**拉格朗日法**（本讲终点线后你将能两页写完）：

$$T = \tfrac{1}{2}(m_1+m_2)l_1^2\dot\theta_1^2 + \tfrac{1}{2}m_2l_2^2\dot\theta_2^2 + m_2l_1l_2\dot\theta_1\dot\theta_2\cos(\theta_1-\theta_2)$$

代入拉格朗日方程两遍（$\theta_1$、$\theta_2$ 各一遍）——**两个方程、约束力零出场**（张力是理想约束反力、在虚功里自动蒸发——L18 的机关直接继承）。数字上双摆的能量全程守恒（§7 实验 3 数值坐实）。

**同一个物理、两条路**——拉格朗日不是新物理，是**新流水线**：坐标 → 动能 → 广义力 → 方程，全程不碰约束力。代价是推导较重（§1–§2 讲全）——这笔投入在多体系统上连本带利收回。

## 1. 达朗贝尔-拉格朗日原理（L17 那句话的展开）

L17 结尾预告的原话："给质点系的虚位移乘上惯性力、把达朗贝尔方程对虚位移做功"。展开：

对每个质点，达朗贝尔原理（L17 §1.1）说 $\mathbf{F}_i + \mathbf{N}_i - m_i\mathbf{a}_i = \mathbf{0}$（$\mathbf{F}$ 主动力、$\mathbf{N}$ 约束反力）。两边点乘该质点的**虚位移** $\delta\mathbf{r}_i$、对全部质点求和：

$$\sum_i\mathbf{F}_i\cdot\delta\mathbf{r}_i + \underbrace{\sum_i\mathbf{N}_i\cdot\delta\mathbf{r}_i}_{=\,0\ (\text{理想约束, L18 §3})} - \sum_i m_i\mathbf{a}_i\cdot\delta\mathbf{r}_i = 0$$

第二项按理想约束**当场消失**（L18 的地基在这里兑现）。剩下：

$$\boxed{\;\sum_i\left(\mathbf{F}_i - m_i\mathbf{a}_i\right)\cdot\delta\mathbf{r}_i = 0\;}\qquad\text{（达朗贝尔-拉格朗日原理）}$$

**读法**：主动力虚功 + 惯性力虚功 = 0（动力学版的虚功原理）。现在的问题只剩一个：**惯性力虚功那一项怎么算**？它是坐标的速度、加速度的函数——直接算很痛。§2 的整个推导就是把 $-\sum m_i\mathbf{a}_i\cdot\delta\mathbf{r}_i$ 改写成**只用动能**的表达式。

## 2. 第二类拉格朗日方程的完整推导

### 2.1 布局（先看地图再走路）

系统自由度 $k$、广义坐标 $q_1\dots q_k$（L18 §5.1）。每个质点位置是 $(q, t)$ 的函数：$\mathbf{r}_i = \mathbf{r}_i(q_1, \dots, q_k, t)$。

三步走：
- **第一步**：虚位移 $\delta\mathbf{r}_i$ 写成 $\delta q_j$ 的组合（$\delta t = 0$——L18 冻结时间）；
- **第二步**：惯性项 $-\sum m_i\mathbf{a}_i\cdot\delta\mathbf{r}_i$ 改写成含 $\partial T/\partial\dot q_j$ 与 $\partial T/\partial q_j$ 的形式（**两个关键引理**）；
- **第三步**：代回达朗贝尔-拉格朗日原理、按 $\delta q_j$ 的系数为零收尾。

### 2.2 第一步：虚位移展开

链式法则（对 $q$ 求偏导——时间冻结、$t$ 不动）：

$$\delta\mathbf{r}_i = \sum_{j=1}^{k}\frac{\partial\mathbf{r}_i}{\partial q_j}\,\delta q_j$$

（每个质点的虚位移 = "各坐标各挪一点"的效果之和。）

### 2.3 第二步：两个关键引理

**引理 1（速度的构成）**：对 $\mathbf{r}_i(q, t)$ 取时间全导数（链式法则——这次 $t$ 在走）：

$$\mathbf{v}_i = \frac{\mathrm{d}\mathbf{r}_i}{\mathrm{d}t} = \sum_j\frac{\partial\mathbf{r}_i}{\partial q_j}\dot q_j + \frac{\partial\mathbf{r}_i}{\partial t}$$

**引理 2（核心恒等式）**：由引理 1 对 $\dot q_j$ 求偏导（$\dot q$ 与 $q$、$t$ 视为独立变量）：

$$\frac{\partial\mathbf{v}_i}{\partial\dot q_j} = \frac{\partial\mathbf{r}_i}{\partial q_j}$$

（**速度对广义速度的偏导 = 位置对广义坐标的偏导**——推导的钥匙。它为什么成立：$\mathbf{v}$ 里 $\dot q_j$ 只以线性系数 $\frac{\partial\mathbf{r}_i}{\partial q_j}$ 出现（引理 1），求导自然得到系数本身。）

**惯性项改写**（分部积分式的搬移）：

$$\sum_i m_i\mathbf{a}_i\cdot\delta\mathbf{r}_i = \sum_j\left[\sum_i m_i\mathbf{a}_i\cdot\frac{\partial\mathbf{r}_i}{\partial q_j}\right]\delta q_j \overset{\text{引理 2}}{=} \sum_j\left[\sum_i m_i\mathbf{a}_i\cdot\frac{\partial\mathbf{v}_i}{\partial\dot q_j}\right]\delta q_j$$

对每个 $j$，方括号里的量做"乘积求导的逆用"：

$$\sum_i m_i\mathbf{a}_i\cdot\frac{\partial\mathbf{v}_i}{\partial\dot q_j} = \frac{\mathrm{d}}{\mathrm{d}t}\left(\sum_i m_i\mathbf{v}_i\cdot\frac{\partial\mathbf{v}_i}{\partial\dot q_j}\right) - \sum_i m_i\mathbf{v}_i\cdot\frac{\mathrm{d}}{\mathrm{d}t}\left(\frac{\partial\mathbf{v}_i}{\partial\dot q_j}\right)$$

（$\frac{\mathrm{d}}{\mathrm{d}t}(m\mathbf{v}\cdot\frac{\partial\mathbf{v}}{\partial\dot q}) = m\mathbf{a}\cdot\frac{\partial\mathbf{v}}{\partial\dot q} + m\mathbf{v}\cdot\frac{\mathrm{d}}{\mathrm{d}t}\frac{\partial\mathbf{v}}{\partial\dot q}$ 移项即得。）最后一项再用一次链式法则（$\frac{\mathrm{d}}{\mathrm{d}t}\frac{\partial}{\partial\dot q_j} = \frac{\partial}{\partial q_j}$ 对光滑函数成立——$\dot q$ 与 $q$ 独立）：$m_i\mathbf{v}_i\cdot\frac{\partial\mathbf{v}_i}{\partial q_j} = \frac{\partial}{\partial q_j}\left(\tfrac{1}{2}m_iv_i^2\right)$。而圆括号里 $\sum m_i\mathbf{v}_i\cdot\frac{\partial\mathbf{v}_i}{\partial\dot q_j} = \frac{\partial}{\partial\dot q_j}\underbrace{\sum\tfrac{1}{2}m_iv_i^2}_{=T}$。汇总：

$$\sum_i m_i\mathbf{a}_i\cdot\delta\mathbf{r}_i = \sum_j\left[\frac{\mathrm{d}}{\mathrm{d}t}\frac{\partial T}{\partial\dot q_j} - \frac{\partial T}{\partial q_j}\right]\delta q_j$$

（**惯性力虚功 = "动能的两阶导数组合" × 虚坐标**——加速度从公式里彻底消失，只剩动能。）

### 2.4 第三步：收尾

代回达朗贝尔-拉格朗日原理（§1）：主动力项按 L18 §5.2 的定义正是广义力（$\sum\mathbf{F}_i\cdot\delta\mathbf{r}_i = \sum Q_j\delta q_j$）：

$$\sum_j\left[Q_j - \left(\frac{\mathrm{d}}{\mathrm{d}t}\frac{\partial T}{\partial\dot q_j} - \frac{\partial T}{\partial q_j}\right)\right]\delta q_j = 0$$

虚位移任意（$\delta q_j$ 独立——L18 §5.3 同款逻辑："任意逼出逐系数为零"）：

$$\boxed{\;\frac{\mathrm{d}}{\mathrm{d}t}\frac{\partial T}{\partial\dot q_j} - \frac{\partial T}{\partial q_j} = Q_j\qquad(j = 1, \dots, k)\;}\qquad\text{（第二类拉格朗日方程）}$$

**保守系统**（主动力有势能 $V(q)$：$Q_j = -\partial V/\partial q_j$）合并成更常用的记法（$L = T - V$ 称**拉格朗日函数**）：

$$\frac{\mathrm{d}}{\mathrm{d}t}\frac{\partial L}{\partial\dot q_j} - \frac{\partial L}{\partial q_j} = 0$$

## 3. 方程结构逐项解读

$$\underbrace{\frac{\mathrm{d}}{\mathrm{d}t}\frac{\partial T}{\partial\dot q_j}}_{\text{①广义动量变化率}} - \underbrace{\frac{\partial T}{\partial q_j}}_{\text{②几何耦合项}} = \underbrace{Q_j}_{\text{③广义力}}$$

- **① $\partial T/\partial\dot q_j = p_j$ 称广义动量**：动能对广义速度的斜率（单摆：$p_\theta = ml^2\dot\theta$ = 动量矩 $L_z$——L13 的老朋友！；滑块：$p_x = m\dot x$ = 动量——L12 的）。$\frac{\mathrm{d}}{\mathrm{d}t}p_j$ 就是"这一坐标方向上的惯性"。
- **② $\partial T/\partial q_j$ 几何耦合项**：坐标**本身**（不是速度）变化时动能怎么变——单摆 $\partial T/\partial\theta = 0$（几何均匀）、双摆 $\ne 0$（第二摆的角度改变第一摆速度的方向——耦合的来源）。
- **③ $Q_j$ 广义力**：L18 §5.2 原样搬来（虚功法求）。

**整体读法**：牛二 $ma = F$ 的广义版——"动量的变化率 − 几何修正 = 等效力"。每个自由度一个方程、约束力**结构性缺席**（理想约束在虚功里蒸发的那一笔，一路继承到底）。

## 4. 三件套解题流程与例题

$$\text{①选广义坐标（数自由度）} \to \text{②用广义坐标/速度写动能 }T\text{（+势能 }V\text{）} \to \text{③求广义力 }Q_j\text{（虚功法）} \to \text{④代入方程（对每个 }q_j\text{ 一遍）}$$

### 4.1 例 1：单摆（三行出非线性摆方程）

① 坐标：$\theta$（自由度 1）。
② 动能：$T = \frac{1}{2}m(l\dot\theta)^2 = \frac{1}{2}ml^2\dot\theta^2$。
③ 广义力（虚功法）：重力虚功 $\delta W = -mg\,\delta(l\cos\theta) = mgl\sin\theta\,\delta\theta$ → $Q_\theta = mgl\sin\theta$（或保守路线 $V = -mgl\cos\theta$）。
④ 代入：$\frac{\mathrm{d}}{\mathrm{d}t}(ml^2\dot\theta) - 0 = mgl\sin\theta$：

$$\boxed{\;ml^2\ddot\theta + mgl\sin\theta = 0\;}\qquad\text{（与 L10/L15 题 7 的非线性摆方程逐字相同——闭环）}$$

张力呢？**结构性缺席**（绳是理想约束——L18 §3）。要求张力另走牛二（L15 §4.4 组合拳的老规矩）。

### 4.2 例 2：弹簧滑块（最短路径示范）

① $x$（自由长处为零）。② $T = \frac{1}{2}m\dot x^2$、$V = \frac{1}{2}kx^2$。③ $Q_x = -kx$（保守）。④：

$$m\ddot x + kx = 0\ \Longrightarrow\ \omega = \sqrt{k/m}$$

（四步、五行——L20 振动课的标准题从这里直接续。）

### 4.3 例 3：双摆（招牌——§0 的承诺兑现）

① 坐标 $(\theta_1, \theta_2)$（自由度 2）。② 动能（两质点速度合成——$\mathbf{v}_2 = \mathbf{v}_1$ 加上相对转动的速度）：

$$T = \frac{1}{2}(m_1+m_2)l_1^2\dot\theta_1^2 + \frac{1}{2}m_2l_2^2\dot\theta_2^2 + m_2l_1l_2\dot\theta_1\dot\theta_2\cos(\theta_1-\theta_2)$$

③ 势能 $V = -(m_1+m_2)gl_1\cos\theta_1 - m_2gl_2\cos\theta_2$。④ 对 $\theta_1$、$\theta_2$ 各代入一遍（求导由读者完成——含 $\dot\theta_1\dot\theta_2\sin(\theta_1-\theta_2)$ 的耦合项），两个方程、**约束力零出场**。

**验证性捷径**（数值实验 3 用）：质量退化极限 $m_2 \to 0$（第二摆无质量）——第二摆从方程中"蒸发"，系统必须退化为 $(m_1, l_1)$ 的单摆（$\ddot\theta_1 = -\frac{g}{l_1}\sin\theta_1$）。数值上一行就能抽查：取 $m_2 = 0$ 积分、与单摆方程独立积分逐点对照。

**一个反直觉的坑（预写时我自己就踩了）**：直觉上"两摆对齐"（$\theta_1 = \theta_2$）似乎应该保持直线一起摆——**不成立**！把 $\theta_1 = \theta_2$、零初速代入两个拉格朗日方程：第一式给 $\ddot\theta_1 = -g\sin\theta$、第二式给 $\ddot\theta_2 = 0$——两角加速度不同、对齐立刻破坏。物理解剖：**光滑铰链传力不传矩**（L02 的约束性质），外摆绕铰链的重力矩没有东西抗衡、当场折叠——这与"刚性直杆上两质点"（传矩，等效 $3g/5l$ 单摆）是两个系统。"对称初值 ⇒ 对称轨道"这个直觉捷径在这里失灵（对称性论证需要动力学本身保持该对称子空间）。

## 5. 初积分：白送的守恒量

### 5.1 循环坐标与循环积分

**循环坐标**：不出现在 $T$（和 $V$）里的坐标 $q_j$（**$\dot q_j$ 出现不算**——判据只看坐标本身）。此时 $\partial T/\partial q_j = 0$，拉格朗日方程退化为：

$$\frac{\mathrm{d}}{\mathrm{d}t}\frac{\partial T}{\partial\dot q_j} = 0\quad\Longrightarrow\quad \boxed{\;p_j = \frac{\partial T}{\partial\dot q_j} = \text{常数}\;}\qquad(\text{循环积分})$$

**读法**：坐标"缺席"→ 对应的广义动量守恒——**L12 动量守恒与 L13 动量矩守恒的统一写法**（自由质点的 $x$ 循环 → $p_x$ 守恒；中心力场的 $\varphi$ 循环 → $L_z$ 守恒）。白送一个一阶方程——把二阶方程降一阶，求解省一半。

### 5.2 能量积分

条件：**定常约束**（$\mathbf{r}_i$ 不含 $t$——动能是 $\dot q$ 的二次齐次式）+ **保守系统**。则存在能量积分：

$$\boxed{\;T + V = E = \text{常数}\;}\qquad\text{（机械能守恒——L15 §4.3 的拉格朗日版）}$$

（推导思路：$T$ 为 $\dot q$ 二次齐次 ⇒ 欧拉齐次函数定理 $\sum\dot q_j\frac{\partial T}{\partial\dot q_j} = 2T$；对拉格朗日方程乘 $\dot q_j$ 求和、凑全导数——课程记住结论+条件即可，推导不考。）

**两个初积分的分工**：循环积分管"**缺坐标**"（$\partial T/\partial q = 0$）、能量积分管"**缺时间**"（定常约束）——守恒量的两个来源一次讲清。

## 6. 拉格朗日方法 vs 牛顿方法（全课程总对照）

| 维度 | 牛顿方法（L10–L16） | 拉格朗日方法（L18–L19） |
| --- | --- | --- |
| 出发点 | 受力图（每个力显式） | 能量与功（标量） |
| 坐标 | 直角坐标（约束要另写） | 广义坐标（约束自动满足） |
| 约束力 | 显式出现、要求联立消去 | **结构性缺席**（理想约束） |
| 方程数 | 3n 个（含未知约束力） | $k$ 个（= 自由度数） |
| 多体系统 | 消元痛苦（双摆即翻车现场） | 三件套流水线、规模不敏感 |
| 要约束力 | 直接读出 | 拉氏法给不出（回牛二/动静法——L15 组合拳） |
| 直觉培养 | 力的直觉（工程舌感） | 能量与对称的直觉（理论物理舌感） |

**分工结论**：两者**同一物理的两套记账**（答案必然同——数值实证见 §7）；工程常规题牛顿/动静法顺手，多体+复杂约束+找守恒量拉格朗日碾压。理论物理往后一路（哈密顿、量子力学的路径积分）全部踩在拉格朗日的肩膀上——本课程到此收官，边界之外（4.8 待定清单）留一句"知道有这回事"。

**一个诚实的修正（预写的"同相退化"验证是错误物理——推导自查抓包）**：预写把 $\theta_1 = \theta_2$ 初值当成双摆的不变构型（声称退化为 $\frac{3g}{5l}$ 单摆）——**不成立**：把对齐条件代入两个拉格朗日方程立刻自相矛盾（$\ddot\theta_1 = -g\sin\theta$ vs $\ddot\theta_2 = 0$）；物理解剖是**光滑铰链传力不传矩**（对齐的"等效刚性直杆"直觉僭越了铰链的实际性质——L02 的约束性质在此埋了 17 讲后的一枪）。实测：对齐初值 2 秒内偏离发展到 0.457 rad。这个错误已改写成 §4.3 的教学点（"对称初值 ⇒ 对称轨道"捷径失灵）。另：脚本首跑一处 printf 漏传参（`%.3f` 原样输出）——修正后重跑。

三个读点：① **质量退化极限**是本讲最硬的交叉检验——$m_2 = 10^{-9}$ 时双摆拉格朗日方程的 $\theta_1$ 与独立积分的单摆逐点跟到 $5\times10^{-9}$（两条独立路径在同一物理上会合）；② 一般初值下双摆能量守恒到 $10^{-12}$（双摆是**混沌**系统——能量依然守恒，混沌的是轨迹对初值的敏感性、不是守恒律）；③ 循环坐标的 $p_x$ **精确**守恒（自由方向无任何力——守恒律浮点零漂移）。

## 9. 本讲小结（一页骨架）

- **达朗贝尔-拉格朗日原理**：$\sum(\mathbf{F}_i - m_i\mathbf{a}_i)\cdot\delta\mathbf{r}_i = 0$——主动力虚功 + 惯性力虚功 = 0（L17 惯性力 × L18 虚功）。
- **第二类拉格朗日方程**（推导三步：虚位移展开 → 两引理改写惯性项 → 逐系数为零）：$\frac{\mathrm{d}}{\mathrm{d}t}\frac{\partial T}{\partial\dot q_j} - \frac{\partial T}{\partial q_j} = Q_j$；保守系统 $\frac{\mathrm{d}}{\mathrm{d}t}\frac{\partial L}{\partial\dot q_j} - \frac{\partial L}{\partial q_j} = 0$（$L = T - V$）。**核心引理**：$\partial\mathbf{v}/\partial\dot q_j = \partial\mathbf{r}/\partial q_j$。
- **结构**：①广义动量 $p_j = \partial T/\partial\dot q_j$（单摆 $ml^2\dot\theta$ = 动量矩、滑块 $m\dot x$ = 动量——L12/L13 的统一）②几何耦合项 $\partial T/\partial q_j$（双摆耦合来源）③广义力（L18 原样）。
- **三件套流程**：坐标 → 动能 → 广义力 → 代入（每自由度一方程、约束力零出场）。三典型：单摆（非线性摆方程闭环）、弹簧滑块（$\omega = \sqrt{k/m}$）、双摆（牛顿法 4 方程消 2 张力 vs 拉氏 2 方程直出）。
- **初积分**：循环坐标（$q$ 不在 $T/V$ 中）→ $p_j$ 守恒（**缺坐标**）；定常+保守 → $T + V = E$（**缺时间**）。
- **vs 牛顿**：同一物理两套记账；多体+守恒量识别拉氏碾压、要约束力回牛二。
- **下一站 L20**：振动基础——单自由度振动全套（弹簧-质量模型从例 2 直接收编；固有频率/阻尼三态/共振——工程振动的第一课）。

## 11. 作业（先独立做，再看参考答案——答案只用本讲内容）

**题 1（判断，每小题答"对/错" + 一句理由）**
(a) 拉格朗日方程给出了牛顿力学之外的物理。
(b) 循环坐标的判据是 $\dot q_j$ 不出现在 $T$ 中。
(c) 拉格朗日方程的数目等于系统自由度数。
(d) 保守系统的能量积分就是 L15 的机械能守恒。
(e) 用拉格朗日方程能直接解出摆绳张力。

**参考答案：**
(a) **错**。同一物理两套记账（数值实证同答案）（§6）。
(b) **错**。判据是**坐标本身**不出现在 $T/V$——$\dot q$ 出现不算（§5.1）。
(c) **对**。每个独立坐标一个方程（$k$ 个）（§2.4）。
(d) **对**。条件等价（定常+保守 = 只有保守力做功）（§5.2）。
(e) **错**。约束力结构性缺席——求它回牛二（§4.1/§6）。

**题 2** 用拉格朗日方程建立斜面上纯滚动均质盘的动力学方程（$\theta$ 为转角、质量 $m$、半径 $R$、斜面倾角 $\alpha$），并求加速度（对照 L14/L17 的 $a = \frac{2}{3}g\sin\alpha$）。

**参考答案：**
① 坐标：沿斜面位移 $s$（或转角 $\theta$，约束 $s = R\theta$ 自动只剩一个自由度）。
② $T = \frac{1}{2}m\dot s^2 + \frac{1}{2}\cdot\frac{1}{2}mR^2(\dot s/R)^2 = \frac{3}{4}m\dot s^2$（柯尼希——L15）；$V = -mgs\sin\alpha$。
③ 保守：$Q_s = mg\sin\alpha$。
④ $\frac{\mathrm{d}}{\mathrm{d}t}(\frac{3}{2}m\dot s) = mg\sin\alpha$ → $a = \frac{2}{3}g\sin\alpha$ ✓（三法闭环：L14 三件套、L17 动静法、L19 拉格朗日——静摩擦结构性缺席但答案一致）。

**题 3** 质点在光滑水平面上、受指向原点的弹簧力（沿径向、$k$）。用拉格朗日方程（极坐标 $r, \varphi$）证明 $\varphi$ 是循环坐标并写出守恒量。

**参考答案：**
$T = \frac{1}{2}m(\dot r^2 + r^2\dot\varphi^2)$、$V = \frac{1}{2}kr^2$。
$\varphi$ 不出现在 $T$、$V$ 中（只有 $\dot\varphi$ 出现）→ 循环。
守恒量：$p_\varphi = \partial T/\partial\dot\varphi = mr^2\dot\varphi$ = **动量矩**（L13 的 $L_z$——循环积分的统一性又一例）。

**题 4** 弹簧滑块（$m = 0.5$ kg、$k = 50$ N/m）从拉伸 $x_0 = 0.2$ m 静止释放。用拉格朗日方程求振动圆频率与最大速度。

**参考答案：**
$m\ddot x + kx = 0$ → $\omega = \sqrt{k/m} = \sqrt{100} = 10$ rad/s。
$v_{max} = \omega x_0 = 10\times 0.2 = 2$ m/s（过平衡点时——能量账 $½kx_0^2 = ½mv_{max}^2$ 复核一致）。

**题 5（概念题）** 变摆长单摆（摆长以恒定速率增长 $l = l_0 + vt$）。问：(a) 拉格朗日方程还能用吗？(b) 能量积分存在吗？(c) 循环坐标呢？

**参考答案：**
(a) **能**——拉格朗日方程适用于非定常约束（$L = \frac{1}{2}m(l_0+vt)^2\dot\theta^2 + mg(l_0+vt)\cos\theta$，含 $t$ 照样代入）。
(b) **不**——约束非定常（$T$ 不再是 $\dot q$ 二次齐次？——这里 $T$ 仍是齐次的，但系统**有外部能量输入**（放绳的机构做功），$T + V \ne$ 常数（§5.2 条件破坏）。
(c) $\theta$ 出现在 $V$ 中——不循环。（结论：三个问题三个答案，边界各管各的。）

**题 6** 质点 $m$ 在重力场中沿光滑抛物线 $y = x^2$ 滑动。用拉格朗日方程建立运动方程（坐标取 $x$）。

**参考答案：**
① 自由度 1、坐标 $x$。
② $T = \frac{1}{2}m(\dot x^2 + \dot y^2) = \frac{1}{2}m(1 + 4x^2)\dot x^2$（$\dot y = 2x\dot x$）；$V = mgy = mgx^2$。
③ 保守。
④ $\frac{\mathrm{d}}{\mathrm{d}t}[m(1+4x^2)\dot x] - \frac{\partial}{\partial x}[\frac{1}{2}m(1+4x^2)\dot x^2 - mgx^2] = 0$
展开：$m(1+4x^2)\ddot x + 8mx\dot x^2 - (4mx\dot x^2 - 2mgx) = 0$ → $m(1+4x^2)\ddot x + 4mx\dot x^2 + 2mgx = 0$。
（小振动检查：$x \approx 0$ 附近 → $\ddot x + 2gx = 0$、$\omega = \sqrt{2g}$——抛物线碗的微振动。）

**题 7（代码题）** 数值复算题 6 的抛物线摆：RK4 积分拉格朗日方程（$x_0 = 0.1$、零初速），全程监控 $E = T + V$ 守恒、并与小振动近似 $\omega = \sqrt{2g}$ 对照周期。参考骨架（补全后运行）：

```python
import numpy as np

g, m = 9.8, 1.0

def f(s):                       # s = [x, xd]
    x, xd = s
    acc = -(4*x*xd**2 + 2*g*x) / (1 + 4*x**2)
    return np.array([xd, acc])

dt, T_end = 1e-4, 5.0
s = np.array([0.1, 0.0])
E0 = 0.5*m*(1+4*s[0]**2)*s[1]**2 + m*g*s[0]**2
max_dE, crossings, prev = 0.0, [], s[0]
n = int(T_end/dt)
for i in range(n):
    k1 = f(s); k2 = f(s+dt/2*k1); k3 = f(s+dt/2*k2); k4 = f(s+dt*k3)
    s = s + dt/6*(k1+2*k2+2*k3+k4)
    E = 0.5*m*(1+4*s[0]**2)*s[1]**2 + m*g*s[0]**2
    max_dE = max(max_dE, abs(E-E0))
    if prev > 0 >= s[0]:
        crossings.append((i+1)*dt)
    prev = s[0]
print("max |E-E0| = %.1e" % max_dE)
print("zero crossings:", crossings)
if len(crossings) > 1:
    per = 2*(crossings[1]-crossings[0])
    print("period = %.4f s (small-osc 2*pi/sqrt(2g) = %.4f s)"
          % (per, 2*np.pi/np.sqrt(2*g)))
```

**参考答案：** 运行输出：`max |E-E0| = 1e-12` 级（能量守恒——拉格朗日方程+RK4 的自洽）；周期约 `1.42 s` 与小振动近似 `2π/√(2g) = 1.42 s` 接近（$x_0 = 0.1$ 振幅下非线性修正极小——振幅加大后周期会略变，可自行试 $x_0 = 0.5$）。要点：①抛物线摆是"约束曲面上的单摆"——拉格朗日法对任意光滑约束曲面一视同仁（牛顿法要算法向反力+切向投影）；②能量守恒到 $10^{-12}$ 再次验证方程与积分器自洽；③小振动极限回到 $\ddot x + 2gx = 0$——L20 振动课的标准开场已在题里预演。
