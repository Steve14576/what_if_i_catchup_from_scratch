## 0. 开场：加一个 z 轴，炸出多少新账

先给你一个心理准备：平面那套**思路**几乎全部存活——简化还是"搬+合成"、平衡还是"主矢主矩为零"、静定还是"未知量 vs 独立方程"。真正冒出来的是这些新账：

2. **力矩升级成矢量**：平面里矩是带正负号的数（只有"逆/顺"两个转向）；空间里转动的方向可以是任何轴——力矩变成一个**既有大小又有方向的矢量**，"对点之矩"和"对轴之矩"两个概念要分清楚（§2，**叉乘**这个数学工具在此现场补）；
3. **简化结果多一种形态**：力螺旋——一个力和一个**与它共线**的力偶死锁在一起，再也合不动了（§4，L02 钩子兑现）；
4. **平衡方程从 3 个变 6 个**；空间约束（球铰、止推轴承）的未知量清单要重新数（§5）；
5. **重心**：空间里"各部分重力合力的作用点"，组合形体要按账本算（§6）。

## 1. 力在空间中的投影：一次与二次

### 1.1 一次投影：方向余弦直接分解

力 $\mathbf{F}$ 与三根坐标轴的夹角 $\alpha, \beta, \gamma$ 已知时，三个分量直接写：

$$F_x = F\cos\alpha, \qquad F_y = F\cos\beta, \qquad F_z = F\cos\gamma$$

三个角不是独立的——它们满足**方向余弦恒等式** $\cos^2\alpha + \cos^2\beta + \cos^2\gamma = 1$（一个方向只有两个自由度，第三个角被前两个锁定）。这叫**一次投影法**（直接投影法）：适合题目把力的方位角都给你摆好的情况。

### 1.2 二次投影：工程图纸的标准给法

工程里更常见的给法是：力 $\mathbf{F}$ 与某根轴（设为 $z$）的夹角 $\varphi$ 已知，但它在 $xy$ 平面内的方位角 $\theta$（从某基准方向量）另给。这时一次分解搞不定，要**分两步**：

$$\text{第一步：} F_z = F\cos\varphi, \qquad F_{xy} = F\sin\varphi \ (\text{力在 } xy \text{ 面上的投影})$$
$$\text{第二步：} F_x = F\sin\varphi\cos\theta, \qquad F_y = F\sin\varphi\sin\theta$$

这叫**二次投影法**（间接投影法）——先斜着投到面上，再在面内投到轴上。为什么它是工程标准：图纸的尺寸标注方式（高度角+平面方位角）天然对应这套分解——斜撑杆、皮带张力的空间方位，几乎总是这么给的。

**自检方式**：分解完用方向余弦恒等式验一遍（$F_x^2+F_y^2+F_z^2 = F^2$），三个分量平方和等于原力平方——一次免费的校验器。

**理解层次：要会用**（两种投影法都是纯算术，练几道就稳）。

## 2. 力对轴之矩：空间力矩的记账方式

### 2.1 从平面矩到轴矩：一次自然的升级

回忆平面：力对点 $O$ 之矩是个**带符号的数**（逆时针正）——为什么平面里能这么懒？因为平面里所有转动都绕**垂直于纸面**的轴发生，"绕哪根轴"没有悬念，只剩"逆还是顺"两个方向，一个正负号就够记账。

空间里转动轴可以是任何方向：同一个力，绕 $x$ 轴转的效果、绕 $y$ 轴的效果、绕一根斜轴的效果，各不相同——**一个正负号不够记账了，得给每根轴各记一笔账**。

**力对轴之矩**的定义（挑一根轴 $z$ 来说，任选垂直于它的平面，比如 $xy$ 面）：

1. 把力 $\mathbf{F}$ **投影到垂直于轴的平面**上（得 $\mathbf{F}_{xy}$，若力平行于轴，投影为零）；
2. 把力的作用点也**投影到该平面**上；
3. 在这个平面里按**平面力矩**算：$M_z = \pm F_{xy} \cdot h$（$h$ 为投影点 $O$ 到投影力线的垂距），逆着**从轴正向看去**的转向为正。

直觉版：**力平行于轴或与轴相交，对这根轴的矩必为零**——平行（推不动转）与相交（力臂为零）都对转动无贡献。这个"平行或相交 → 零"是空间力矩的第一快速判据（对应平面里的"力线过矩心矩为零"）。

### 2.2 数学工具现场补：叉乘（第一次也是本课程最重要的一次登场）

要给空间力矩一个**坐标算式**，需要一件新工具——**矢量的叉乘**（乘出来还是一个矢量的那种乘法）。本课程到 L07（角速度）还会反复用它，这里一次补齐。

**定义**：两个矢量 $\mathbf{a} \times \mathbf{b}$ 的结果是一个**新矢量**：

- **大小**：$|\mathbf{a}\times\mathbf{b}| = ab\sin\theta$（$\theta$ 为两矢量夹角）——恰等于 $\mathbf{a}, \mathbf{b}$ 张成的**平行四边形面积**；
- **方向**：垂直于 $\mathbf{a}, \mathbf{b}$ 所在平面，指向由**右手定则**定——右手四指从 $\mathbf{a}$ 转向 $\mathbf{b}$（转不超过 180° 的那个方向），拇指即指向。

**坐标算式**（行不行验一下：$\mathbf{i}\times\mathbf{j}=\mathbf{k}$）：

$$\mathbf{a}\times\mathbf{b} = \begin{vmatrix} \mathbf{i} & \mathbf{j} & \mathbf{k} \\ a_x & a_y & a_z \\ b_x & b_y & b_z \end{vmatrix} = (a_y b_z - a_z b_y,\; a_z b_x - a_x b_z,\; a_x b_y - a_y b_x)$$

（按行列式第一行展开；记不住就展开成三个"交叉相减"。）

**四条性质**（后面全要用）：

1. **反交换**：$\mathbf{a}\times\mathbf{b} = -\mathbf{b}\times\mathbf{a}$（次序换，方向反）；
2. **自身为零**：$\mathbf{a}\times\mathbf{a} = \mathbf{0}$（$\sin 0 = 0$）；
3. **对加法分配**：$\mathbf{a}\times(\mathbf{b}+\mathbf{c}) = \mathbf{a}\times\mathbf{b} + \mathbf{a}\times\mathbf{c}$（这条让"逐力取矩再相加"合法）；
4. **平行则零**：$\mathbf{a} \parallel \mathbf{b} \Rightarrow \mathbf{a}\times\mathbf{b} = \mathbf{0}$。

**理解层次：叉乘的坐标算式与右手定则要会用**——它从本讲起是常驻工具，值得花 15 分钟用两三个具体矢量手算一遍找手感（如 $\mathbf{a}=(1,0,0)$, $\mathbf{b}=(0,1,0)$，结果是 $(0,0,1)$）。

### 2.3 力对点之矩（矢量版）与力对轴之矩的关系

**力对点之矩**（空间版定义）：

$$\mathbf{M}_O(\mathbf{F}) = \mathbf{r} \times \mathbf{F}$$

（$\mathbf{r}$ 为从 $O$ 指向力作用点的位置矢量。）它是一个矢量：大小 = $\mathbf{r}, \mathbf{F}$ 张成平行四边形的面积 = $Fh$（$h$ 就是力臂），方向 = 转动轴方向（右手定则：四指沿力推物体绕 $O$ 转的方向，拇指即矩矢量方向）。平面里那个"带符号的数"，就是这个矢量**在 z 轴上的分量**——正负号约定（逆时针正）恰是"z 正向看去逆时针 = 矩矢量沿 +z"。旧知识完整地被新框架**收编**，没有推翻。

**对轴之矩 = 对点之矩在轴上的投影**（关键关系，一步到位的算法）：设轴 $l$ 过点 $O$、单位方向矢量 $\mathbf{u}$，则

$$\boxed{\;M_l(\mathbf{F}) = \mathbf{M}_O(\mathbf{F})\cdot\mathbf{u} = (\mathbf{r}\times\mathbf{F})\cdot \mathbf{u}\;}$$

（$\mathbf{r}$ 为轴上任一点指向作用点的矢量；可以证明换轴上别的点结果不变——这正是"矩与矩心无关"的矢量版本。）于是空间力矩的**实战算法**：不用真的做投影图，坐标给出 $\mathbf{r}$ 和 $\mathbf{F}$ → 叉乘一次 → 想对哪根轴取矩就点乘哪个单位矢量。三行算式替代一整套几何作图。数值上它和 §2.1 的"投影到平面算法"结果完全一致（§7 实验 1 用随机数据验证这一点）。

### 例 1：力对三根坐标轴的矩

**题目**：$F = 90$ N，方向沿 $(1, 2, 2)$（与三轴的方向余弦为 $\frac13, \frac23, \frac23$），作用点 $A(2, 3, 4)$ m。求它对 $x$、$y$、$z$ 三轴之矩。

**解**：分量 $F_x = 90 \times \frac{1}{3} = 30$，$F_y = 60$，$F_z = 60$ N，即 $\mathbf{F} = (30, 60, 60)$ N；$\mathbf{r} = (2, 3, 4)$ m。

$$\mathbf{M}_O = \mathbf{r}\times\mathbf{F} = (3\times 60 - 4\times 60,\;\; 4\times 30 - 2\times 60,\;\; 2\times 60 - 3\times 30) = (-60,\; 0,\; 30)\ \text{N·m}$$

对三轴之矩 = 三个分量：$M_x = -60$ N·m、$M_y = 0$、$M_z = +30$ N·m。

**$M_y = 0$ 的物理含义值得看一眼**（快速判据"平行或相交 → 零"的演练）：力线是过 $A$、方向 $(1,2,2)$ 的直线。取参数 $t$：$(2+t,\; 3+2t,\; 4+2t)$。令 $x = 0, z = 0$：$t = -2$ 时 $x = 0$、$z = 4 - 4 = 0$ 同时成立，且 $y = 3 - 4 = -1$——**力线恰好穿过 $y$ 轴上的点 $(0, -1, 0)$**。力与 $y$ 轴相交 → 对 $y$ 轴矩为零 ✓。叉乘算出来的零从来不是巧合，背后必有几何原因——养成"看见零矩就找几何解释"的习惯，检查错误极其好用。

## 3. 空间力偶：矩矢登场

平面里力偶的"身份证"是带符号的力偶矩 $M = \pm Fd$。空间里力偶可以在**任何平面**内作用，光有大小和转向不够，还要说清**作用面的方向**——于是力偶的身份证升级为**力偶矩矢量** $\mathbf{M}$：

- **大小**：$Fd$（力 × 力偶臂，不变）；
- **方向**：垂直于力偶作用面，指向由右手定则定（四指沿力偶的转向卷，拇指即指向）。

空间力偶的等效条件相应升级：**两个力偶等效 ⇔ 力偶矩矢量相等**（大小相等且方向相同）。平面里的三性质（可移转、可改装、矩与矩心无关）在空间全部继承且升级为三维版：力偶可以在**平行平面**之间搬移（只要矩矢不变）。空间力偶系合成 = 矩矢量的矢量和（不再只是代数和）：

$$\mathbf{M} = \sum_i \mathbf{M}_i$$

**理解层次：矩矢的方向判别（右手定则）要会用**；等效条件要能陈述。

## 4. 空间力系的简化：主矢、主矩与力螺旋

### 4.1 流程：与平面完全同构，只是记账升级

向简化中心 $O$ 简化（力线平移定理在空间原样成立——刚体上平移力附加力偶，附加力偶矩矢 = $\mathbf{M}_O(\mathbf{F})$）：

$$\text{主矢 } \mathbf{F}_R' = \sum \mathbf{F}_i \ (3 \text{ 个分量}), \qquad \text{主矩 } \mathbf{M}_O = \sum \mathbf{M}_O(\mathbf{F}_i) = \sum \mathbf{r}_i \times \mathbf{F}_i \ (\text{矢量})$$

主矢照旧与简化中心无关；主矩照旧随中心变，换心公式的空间版：

$$\mathbf{M}_{O'} = \mathbf{M}_O + \mathbf{M}_{O'}(\mathbf{F}_R') = \mathbf{M}_O + (\mathbf{r}_O - \mathbf{r}_{O'})\times\mathbf{F}_R'$$

（推导与平面版一字不差：把"主矢@O+主矩"再向 $O'$ 简化一次。§7 实验 2 随机验证。）

### 4.2 最终形态讨论：力螺旋的诞生

平面里讨论表只有四行（合力过 O/合力不过 O/合力偶/平衡），因为主矩**永远垂直**于平面（矩矢方向只能垂直纸面），与主矢（在面内）**恒垂直**——总能"挪一步"消掉。空间里主矩方向任意，于是**多出一行**。按主矩在主矢方向上的**平行分量** $M_\parallel = \mathbf{M}_O\cdot\hat{\mathbf{F}}_R'$（$\hat{\mathbf{F}}$ 为主矢方向单位矢量）分类：

| 条件 | 最终形态 | 说明 |
| --- | --- | --- |
| $\mathbf{F}_R' \neq 0$，$\mathbf{M}_O \perp \mathbf{F}_R'$（即 $M_\parallel = 0$） | **合力**（作用线可求） | 垂直分量可被"挪一步"消掉（平移主矢 $d = M_\perp/F_R'$） |
| $\mathbf{F}_R' \neq 0$，$M_\parallel \neq 0$ | **力螺旋** | 平行分量怎么挪都消不掉——见下 |
| $\mathbf{F}_R' = 0$，$\mathbf{M}_O \neq 0$ | 合力偶 | $\mathbf{M}_O$ 本身 |
| $\mathbf{F}_R' = 0$，$\mathbf{M}_O = 0$ | 平衡 | |

**力螺旋（L02 钩子兑现）**：一个力 + 一个**与它共线**的力偶锁死在一起。为什么平行分量消不掉？——**平移一个力只能产生与力垂直的力偶**（$\mathbf{r}\times\mathbf{F}$ 永远垂直于 $\mathbf{F}$），所以无论把主矢挪到哪里，附加力偶永远垂直于主矢、永远碰不到平行分量半根毫毛。$M_\parallel$ 是"挪不走的转动零头"，与主矢锁死成螺旋——像拧螺丝：边前进（力）边拧转（共线力偶）。**中心轴**：消掉垂直分量后主矢所在的那条直线。工程实例：钻头打孔、螺旋桨、斜齿轮啮合力。

**二次简化流程**（把任意空间力系化到最简）：① 向 O 简化得 $(\mathbf{F}_R', \mathbf{M}_O)$；② 分解 $\mathbf{M}_O = M_\parallel \hat{\mathbf{F}} + \mathbf{M}_\perp$；③ 把主矢从 O 平移到 $\mathbf{r}^* = \dfrac{\mathbf{F}_R'\times\mathbf{M}_\perp}{|\mathbf{F}_R'|^2}$ 处（这步平移恰好附加 $-\mathbf{M}_\perp$ 的力偶，垂直分量清零）；④ 剩下"主矢 + 共线的 $M_\parallel$"——力螺旋的标准形态（或 $M_\parallel = 0$ 时就是合力）。公式 $\mathbf{r}^*$ 不用背，**理解"垂直可消、平行锁死"这个分类逻辑**才是考点。

**理解层次：讨论表要会用**（给数字能判形态）；力螺旋"要建立直觉"（拧螺丝的图像）；$\mathbf{r}^*$ 公式"知道有这回事"（可推导，不必背）。

### 例 2：空间简化与形态判定

**题目**：$\mathbf{F}_1 = (40, 0, 0)$ N 作用于 $(0, 4, 0)$；$\mathbf{F}_2 = (0, 30, 0)$ N 作用于 $(3, 0, 0)$；另有主动力偶 $\mathbf{M}_c = (0, 0, 20)$ N·m。向原点 O 简化并判断最终形态。

**解**：

- 主矢：$\mathbf{F}_R' = (40, 30, 0)$ N，$|\mathbf{F}_R'| = 50$ N；
- 主矩（力偶直接进主矩）：$\mathbf{M}_O = \mathbf{r}_1\times\mathbf{F}_1 + \mathbf{r}_2\times\mathbf{F}_2 + \mathbf{M}_c$：
  $\mathbf{r}_1\times\mathbf{F}_1 = (0,4,0)\times(40,0,0) = (0\cdot0-0\cdot0,\; 0\cdot40-0\cdot0,\; 0\cdot0-4\cdot40) = (0, 0, -160)$；
  $\mathbf{r}_2\times\mathbf{F}_2 = (3,0,0)\times(0,30,0) = (0\cdot0-0\cdot30,\; 0\cdot0-3\cdot0,\; 3\cdot30-0\cdot0) = (0, 0, +90)$；
  $\mathbf{M}_O = (0, 0, -160+90+20) = (0, 0, -50)$ N·m；
- 形态判定：$M_\parallel = \mathbf{M}_O\cdot\hat{\mathbf{F}}_R' = (0,0,-50)\cdot\frac{(40,30,0)}{50} = 0$——**主矩垂直于主矢** → 可合成**合力**；
- 合力线：找点 $\mathbf{P}$ 使主矩换心后为零，即 $\mathbf{P}\times\mathbf{F}_R' = \mathbf{M}_O = (0,0,-50)$。设 $\mathbf{P}=(a,b,c)$：$\mathbf{P}\times\mathbf{F}_R' = (-30c,\; 40c,\; 30a-40b)$。解 $-30c = 0 \Rightarrow c = 0$；$30a - 40b = -50 \Rightarrow 3a - 4b = -5$。合力线 = $\{z = 0,\ 3x - 4y = -5\}$（方向沿主矢），O 到它的距离 $d = |\mathbf{M}_O|/|\mathbf{F}_R'| = 50/50 = 1$ m。

**答**：主矢 $(40, 30, 0)$ N，主矩 $(0, 0, -50)$ N·m；最终为合力，作用线在 $z=0$ 平面、方程 $3x-4y=-5$，距 O 为 1 m。

（顺带一个反向确认：如果本题的主矩里再混进一个沿 $\mathbf{F}_R'$ 方向的分量，比如把主动力偶改成 $(24, 18, 20)$ N·m——其中 $(24,18)$ 恰与主矢 $(40,30)$ 同向——那么 $M_\parallel = \frac{(24,18,20)\cdot(40,30,0)}{50} = \frac{960+540}{50} = 30 \neq 0$，垂直分量照旧可消，剩下的就是"50 N 的力 + 30 N·m 的共线力偶"——**力螺旋**。同一个框架，一行判据分流两种命运。）

## 5. 空间约束与空间平衡方程

### 5.1 六个平衡方程

平衡判据"主矢为零 + 主矩为零"翻译到空间，每个矢量给三个分量方程：

$$\boxed{\;\sum F_x = \sum F_y = \sum F_z = 0, \qquad \sum M_x = \sum M_y = \sum M_z = 0\;}$$

（三个投影 + 三个对轴之矩。）**6 个独立方程，最多解 6 个未知量**。矩轴依然任选（不必是坐标轴——挑过未知力或平行于未知力的轴，那些未知力不出场，L03 的矩心技巧全面继承）。退化情形：空间汇交力系 3 个方程、空间平行力系 3 个方程。

### 5.2 空间约束清单（L01 预告的兑现）

| 约束类型 | 长什么样 | 没收什么 | 反力 | 未知量数 |
| --- | --- | --- | --- | --- |
| 球形铰支座 | 球窝扣住球头（汽车换挡杆的底座） | 三维任意方向移动（放行绕三轴转动） | 三个分量 $F_x, F_y, F_z$ | 3 |
| 向心轴承（径向滑动轴承） | 轴穿在光滑轴承孔里 | 垂直轴线平面内的两向移动（放行轴向窜动与转动） | 垂直轴平面内两分量 | 2 |
| 止推轴承 | 向心轴承+轴肩（同时挡住轴向窜动） | 三向移动 | 两径向分量+一轴向分量 | 3 |
| 空间固定端 | 杆端浇死在基础里 | 移动+转动全没收 | 三力分量 + 三力偶矩分量 | 6 |

> 口径声明（如实说）：**止推轴承**的未知量计数，个别教材计 4–5 个（把限制某些转动的约束力偶也算进去）。本讲义按主流的"3 个力分量"口径走；考试以你们课程的口径为准——判断静定前先对一下你们教材的表。这是本课程唯一一处"教材间有分歧"的记账，值得知道。

### 5.3 空间受力图的画法习惯

空间受力图直接画立体图容易乱。工程惯例：**把三个坐标面的投影图分开画**（xy 视图、yz 视图、zx 视图），每个力按它的分量出现在对应视图里；或对简单系统用一张立体图但每个力标注分量。列方程时全部走解析式（坐标+叉乘），不做图上量角。

### 例 3：传动轴的空间平衡（本讲的标准考题形态）

**题目**：水平传动轴沿 $x$ 轴：A 端 $(0,0,0)$ 为止推轴承，B 端 $(5,0,0)$ 为向心轴承（只约束 $y, z$ 向）。C 处 $(2,0,0)$ 装有齿轮，受啮合力 $\mathbf{F} = (0,\ 100,\ -200)$ N（$y$ 向为径向分量、$z$ 向为切向分量，齿轮细节不影响本题）。轴自重不计。求 A、B 轴承反力。

**解**（先数账：未知量 $A_x, A_y, A_z, B_y, B_z$ 共 **5** 个；方程 6 个——待会儿看"多出的方程"去哪了）：

- $\sum F_x = 0$：$A_x + 0 + 0 = 0 \Rightarrow A_x = 0$（无轴向载荷，止推的轴向分量空转）；
- $\sum M_y = 0$（绕 $y$ 轴，$M_y = zF_x - xF_z$）：B 处 $-5B_z$；F 处 $-2\times(-200) = +400$；$\Rightarrow -5B_z + 400 = 0 \Rightarrow B_z = 80$ N；
- $\sum M_z = 0$（$M_z = xF_y - yF_x$）：B 处 $5B_y$；F 处 $2\times 100 = 200$；$\Rightarrow 5B_y + 200 = 0 \Rightarrow B_y = -40$ N；
- $\sum F_y = 0$：$A_y + B_y + 100 = 0 \Rightarrow A_y = -60$ N；
- $\sum F_z = 0$：$A_z + B_z - 200 = 0 \Rightarrow A_z = 120$ N；
- $\sum M_x = 0$：绕 $x$ 轴——所有力都过 $x$ 轴（作用点在轴上）→ 各力矩全为零，**方程自动满足**。

**答**：$\mathbf{F}_A = (0,\ -60,\ 120)$ N，$\mathbf{F}_B = (B_y, B_z) = (-40,\ 80)$ N。

**注意那个"多出的方程"**：6 列 5 解，第 6 个（$\sum M_x$）自动满足——**独立方程其实是 5 个**（L03 §1.4 的概念在空间的再现：外载分布让一个方程退化）。这不是巧合，是这类"轴上受力"题的结构性特征：载荷全过轴线时，绕轴的矩方程恒为零。有些题会故意在轴上**加一个绕轴的主动力偶**（如输入扭矩），那时 $\sum M_x$ 变成真方程、解出新的未知（如皮带预张力）——形态不变，账目长一格。

## 6. 重心：空间分布力系的合账

### 6.1 重心是什么

把物体切成无数微元，每个微元受重力 $d\mathbf{W}$（竖直向下）——这是一族**平行分布力**（都竖直向下、大小按质量分布）。它们有一个合力 $\mathbf{W} = \sum d\mathbf{W} = Mg$，合力的**作用点**就是**重心**——无论物体怎么摆放，重力合力总过这个点（换个摆放方向，各微元重力随之转，但合力作用点跟着转，相对物体的位置不变）。

"重力都从重心出"是**记账便利**：画受力图时重力画成一个作用于重心的合力（L01 §5.2 一直在这么干），现在你知道这个点的法定来历了——它是分布力系的**合力作用点**，坐标由合力矩定理定：

$$x_C = \frac{\sum_i W_i x_i}{\sum_i W_i}, \qquad y_C = \frac{\sum_i W_i y_i}{\sum_i W_i}, \qquad z_C = \frac{\sum_i W_i z_i}{\sum_i W_i}$$

（$W_i$、$x_i$：各分块的重量与分块重心的坐标——**分块法**。连续体是它的积分极限，考试以分块为主。）

### 6.2 三个容易混的词：重心、形心、质心

- **重心**：重力合力作用点（依赖"有重力"这件事）；
- **形心**：纯几何形状的中心（面积/体积的"平均位置"），跟质量、重力都无关；
- **质心**：质量分布的平均位置（$\sum m_i \mathbf{r}_i / \sum m_i$），不需要重力场。

对**匀质物体**（密度处处相同）：重量分布 ∝ 体积分布 → **重心 = 形心**；且在任何引力场下 **质心 = 重心**（均匀重力场中）。地面上的匀质构件，三个词指同一个点——所以教材常混着用。分清楚的场景：**非匀质**物体（配重块）重心≠形心；无重力环境（空间站）谈质心不谈重心。质心这个概念在动力学（L12 质心运动定理）才是主角，现在先立好户口。

### 6.3 组合形体解题流程（含负面积法）

匀质等厚平板/柱体的重心坐标 = **面积/体积的加权平均**，流程：

1. **拆块**：切成矩形、圆、三角形等基本块（形心查表可得）；
2. **挖孔/切口**：当作"负面积/负体积"的块，权重取负；
3. **对称性先扫**：有对称轴的块，形心必在对称轴上（先降坐标数）；
4. 套公式求和。

### 例 4：挖孔矩形板的重心

**题目**：匀质等厚矩形板 $60 \times 40$ cm，右下角挖去 $20\times 20$ cm 的方孔（孔的边界为 $x\in[40,60]$、$y\in[0,20]$，坐标原点在板的左下角）。求重心。

**解**（负面积法，等厚匀质 → 用面积代替重量做权重）：

| 块 | 面积（cm²） | 形心 (cm) |
| --- | --- | --- |
| 整板 | $60\times 40 = 2400$ | $(30,\ 20)$ |
| 方孔（负） | $-20\times 20 = -400$ | $(50,\ 10)$ |

$$x_C = \frac{2400\times 30 - 400\times 50}{2400 - 400} = \frac{72000 - 20000}{2000} = 26 \text{ cm}, \qquad y_C = \frac{2400\times 20 - 400\times 10}{2000} = \frac{48000-4000}{2000} = 22 \text{ cm}$$

**答**：重心 $(26,\ 22)$ cm——从几何中心 $(30, 20)$ 向挖孔的对侧偏移（重量少了右下方一块，重心向左上方退），方向对、量级合理（§7 实验 4 用数值积分复核这个数）。

### 6.4 实验法（L01 预告兑现）

形状不规则、不好拆块时，两种实验定重心：

- **悬挂法**：任意一点悬挂，静止时重心必在悬线延长线上（二力平衡公理！挂点给拉力、重力过重心，两者共线）——换两个点各挂一次，两条悬线的交点即重心。
- **称重法**：物体一头支在秤上、另一头支在刀口上，水平平衡时由力矩方程算重心位置（对称地进行两次可定三维位置）。

注意悬挂法的理论依据正是 L01 的二力平衡——老朋友在新战场露脸。

## 9. 本讲小结（一页骨架）

- **投影**：一次（方向余弦，满足 $\cos^2\alpha+\cos^2\beta+\cos^2\gamma=1$）；二次（$\varphi$ 到面+面内 $\theta$：$F_z = F\cos\varphi$，$F_x = F\sin\varphi\cos\theta$，$F_y = F\sin\varphi\sin\theta$）。验算：分量平方和=原力平方。
- **叉乘**：$|\mathbf{a}\times\mathbf{b}| = ab\sin\theta$、方向右手定则；坐标式三个"交叉相减"；反交换、分配、平行为零。
- **力矩**：对点之矩 $\mathbf{M}_O = \mathbf{r}\times\mathbf{F}$（矢量）；对轴之矩 $M_l = (\mathbf{r}\times\mathbf{F})\cdot\hat{\mathbf{u}}$（对点之矩的投影）；快速判据：力平行于轴或交轴 → 零。
- **空间力偶**：身份证升级为矩矢量（大小 $Fd$、右手定则方向）；合成=矩矢量和。
- **简化**：主矢（3 分量，与中心无关）+主矩（矢量，随中心变，换心公式照搬）。**形态判据一句话：主矩的平行分量 $M_\parallel$ 决定命运——为零合成合力，非零锁成力螺旋**（平移只能产生垂直力偶，动不了平行分量）。
- **空间平衡**：6 方程（3 投影+3 矩）；约束：球铰 3、向心轴承 2、止推 3（口径声明过）、空间固定端 6。轴类题的结构特征：过轴之力绕轴矩恒零。
- **重心**：平行分布力系的合力作用点；分块法+负面积/负体积法；匀质体重心=形心=质心；悬挂法=二力平衡公理的现场应用。
- **下一讲**：静力学最后一块版图——摩擦：摩擦角与自锁、翻倒 vs 滑动、考虑摩擦的平衡问题。

## 11. 作业（先独立做，再看参考答案——答案只用本讲内容）

**题 1（判断，每小题答"对/错"+一句理由）**
(a) 空间汇交力系有 6 个独立平衡方程。
(b) 力对某轴之矩为零，则该力一定与该轴相交。
(c) 主矢不为零、主矩也不为零的空间力系，一定能简化为一个合力。
(d) 匀质物体的重心一定也是它的形心。
(e) 用悬挂法找重心，挂两个不同点得到两条悬线，其交点即重心。

**参考答案：**
(a) **错**。汇交点取矩恒为零，独立方程只剩 3 个（三投影）。
(b) **错**。还可能**平行**于轴（两路"零矩"通道：相交或平行，§2.1）。
(c) **错**。$M_\parallel \neq 0$ 时是力螺旋，永不合成为一个力（例 2 的反向确认）。
(d) **对**。匀质 → 重量分布 ∝ 体积分布 → 重心=形心（§6.2；非匀质才分开）。
(e) **对**。每次悬挂悬线必过重心（二力平衡共线），两条线交点唯一定位（§6.4）。

**题 2（二次投影）**力 $F = 200$ N：与 $z$ 轴夹角 $\varphi = 30°$，其水平投影与 $x$ 轴夹角 $\theta = 45°$。写出三个分量并验算。

**参考答案：**
$F_z = 200\cos 30° = 173.2$ N；$F_{xy} = 200\sin 30° = 100$ N；$F_x = 100\cos 45° = 70.7$ N；$F_y = 70.7$ N。
验算：$70.7^2 + 70.7^2 + 173.2^2 = 5000 + 5000 + 30000 = 40000 = 200^2$ ✓。

**题 3（力对轴之矩）**力 $\mathbf{F} = (0,\ 36,\ 48)$ N（大小 60 N，沿 $(0,3,4)$ 方向）作用于点 $(1,\ 2,\ 3)$ m。求对三根坐标轴之矩，并检查是否有零分量、为什么。

**参考答案：**
$\mathbf{M}_O = \mathbf{r}\times\mathbf{F} = (2\times48 - 3\times36,\;\; 3\times0 - 1\times48,\;\; 1\times36 - 2\times0) = (-12,\ -48,\ +36)$ N·m。
即 $M_x = -12$、$M_y = -48$、$M_z = +36$ N·m。无零分量：力既不平行于任何坐标轴（分量 0, 36, 48 都不为零方向），力线也不穿过任何坐标轴（可验证：力线 $(1, 2+3t, 3+4t)$ 要 $y=z=0$ 需 $t$ 同时满足 $2+3t=0$（$t=-2/3$）与 $3+4t=0$（$t=-3/4$）——不同解，不交 $x$ 轴；其余两轴同理）。

**题 4（空间简化与形态）**$\mathbf{F}_1 = (20, 0, 0)$ N 作用于 $(0, 3, 0)$；$\mathbf{F}_2 = (0, 0, 40)$ N 作用于 $(2, 0, 0)$；主动力偶 $\mathbf{M}_c = (0, 24, 0)$ N·m。向 O 简化，判形态，若有合力求作用线。

**参考答案：**
主矢 $\mathbf{F}_R' = (20, 0, 40)$ N（$|\mathbf{F}_R'| = \sqrt{2000} \approx 44.7$ N）。
$\mathbf{r}_1\times\mathbf{F}_1 = (0,3,0)\times(20,0,0) = (0, 0, -60)$；$\mathbf{r}_2\times\mathbf{F}_2 = (2,0,0)\times(0,0,40) = (0, -80, 0)$；$\mathbf{M}_O = (0, 0, -60) + (0, -80, 0) + (0, 24, 0) = (0, -56, 0)$ N·m。
$M_\parallel = (0,-56,0)\cdot\frac{(20,0,40)}{\sqrt{2000}} = 0$ → 垂直 → **合力**。
合力线：$\mathbf{P}\times\mathbf{F}_R' = \mathbf{M}_O$：$\mathbf{P}=(a,b,c)$，$\mathbf{P}\times(20,0,40) = (40b,\; 20c-40a,\; -20b)$，等于 $(0,-56,0)$：$b = 0$、$20c - 40a = -56 \Rightarrow c = 2a - 2.8$。合力线：$y = 0$ 平面内直线 $z = 2x - 2.8$（方向沿 $\mathbf{F}_R'$）；O 到线距离 $d = 56/\sqrt{2000} \approx 1.25$ m。

**题 5（空间平衡，传动轴变体）**传动轴沿 $z$ 轴：A 端 $(0,0,0)$ 止推轴承（三分量），B 端 $(0,0,4)$ 向心轴承（$B_x, B_y$ 两分量）。C 处 $(0,0,1.5)$ 受力 $\mathbf{F} = (300,\ -200,\ 0)$ N。求 A、B 反力，并指出哪个方程自动满足。

**参考答案：**
- $\sum F_z$：$A_z = 0$（无 z 向载荷）；
- $\sum M_x$（$M_x = yF_z - zF_y$）：F 处 $-1.5\times(-200) = +300$；B 处 $-4B_y$；$\Rightarrow -4B_y + 300 = 0 \Rightarrow B_y = 75$ N；
- $\sum M_y$（$M_y = zF_x - xF_z$）：F 处 $1.5\times 300 = 450$；B 处 $4B_x$；$\Rightarrow 4B_x + 450 = 0 \Rightarrow B_x = -112.5$ N；
- $\sum F_x$：$A_x + B_x + 300 = 0 \Rightarrow A_x = -187.5$ N；$\sum F_y$：$A_y + 75 - 200 = 0 \Rightarrow A_y = 125$ N；
- **自动满足的是 $\sum M_z$**：所有力都过 $z$ 轴（作用点在轴上）——绕轴矩恒零。
**答**：$\mathbf{F}_A = (-187.5,\ 125,\ 0)$ N；$\mathbf{F}_B = (-112.5,\ 75)$ N。（验算：C 点把跨度 4 m 分成 1.5 与 2.5，反力按 $2.5:1.5$ 分担——$A_y = 125 = 200\times 2.5/4$、$B_y = 75 = 200\times 1.5/4$ ✓，简支梁反力分配的直觉在空间照样灵。）

**题 6（重心，分块法）**匀质等厚 L 形板：横条 $0\le x\le 40,\ 0\le y\le 10$ cm；竖条 $0\le x\le 10,\ 10\le y\le 50$ cm。求重心。

**参考答案：**
横条：面积 400，形心 $(20, 5)$；竖条：面积 400，形心 $(5, 30)$。
$x_C = \frac{400\times20 + 400\times5}{800} = 12.5$ cm；$y_C = \frac{400\times5 + 400\times30}{800} = 17.5$ cm。
**答**：重心 $(12.5,\ 17.5)$ cm。对称性检查：两块面积相等，重心是两个形心的中点 $((20+5)/2, (5+30)/2) = (12.5, 17.5)$ ✓——面积相等时"加权平均退化为中点"，一行免费验算。

**题 7（重心，负面积）**匀质圆盘半径 $R = 20$ cm，挖去半径 $r = 5$ cm 的圆孔，孔心在盘心右侧 $8$ cm（沿 $x$ 轴）。求重心位置，并回答：重心在孔的一侧还是对侧？为什么？

**参考答案：**
$x_C = \frac{\pi R^2 \cdot 0 - \pi r^2 \cdot 8}{\pi R^2 - \pi r^2} = \frac{-25\pi\times 8}{375\pi} = -\frac{200}{375} = -0.533$ cm；$y_C = 0$（对称）。
**答**：重心 $(-0.533,\ 0)$ cm——在孔的**对侧**（左侧）。直觉：挖孔=拿走右边的重量，剩余重量的"平均位置"向左退。偏移量很小（不到 1 cm）：因为挖掉的面积只占总面积 $\frac{25}{400}\approx 6\%$，且偏心只有 8 cm——权重小，撬不动大盘。
