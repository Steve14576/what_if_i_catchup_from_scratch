## 1. 课程目标

写一套 22 讲的理论力学教程，让一个没系统学过理论力学的工科机械学生：
1. 从零学懂：静力学 → 运动学 → 动力学 → 分析力学基础 → 振动基础，完整走通工科理论力学主线；
2. 能打真实考试：考点地毯式覆盖、题型齐全、作业可自验证，能只靠这份讲义应对期末；
3. 可当手册查：AA_一览提供严谨字典，各讲末尾有小结骨架；
4. 数值坐实：关键结论配可跑的 Python 验证脚本，抽象概念用数值实验落地。

## 2. 读者画像（P11）

- 类型：完全踏入陌生领域的工科学生——"不知道自己不知道什么"型，不是手册型也不是旧语言迁移型；
- 背景：机械专业，正在并行学习《机构原理》（理论力学是其先修）；
- 数学：微积分、线性代数学过但不扎实，仅能通过考试；偏应用取向；用法是"用到现场补"，不接受长篇数学前奏，但该讲透的（如转动惯量、叉乘的几何意义）必须讲透；
- 动机：有真实期末考试，学懂优先、考试兜底；
- 期待：说人话、不空降、例子具体、每讲有作业、能自验证。
