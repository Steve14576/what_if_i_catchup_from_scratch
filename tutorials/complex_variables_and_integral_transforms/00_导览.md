# 复变函数与积分变换——从复平面到 $s$ 域 · 导览

> 这是一套面向**电类本科生**的《复变函数与积分变换》教程。它假设你学过高数、学过线性代数、在电路课上见过 $j\omega$，但没有假设你喜欢这门课。
>
> 目标很具体：学完你能独立做完一份正经的期末试卷，并且能把复变、傅里叶、拉普拉斯这三套语言，对应到电路、信号与系统、自动控制里真实出现的地方。

## 这门课是什么

这门课由两半组成，中间用"解析函数"这根轴串起来。

**前半是复变函数**：把数从实数轴搬到复平面，研究复平面上的函数。核心线索只有一条：

> 复数 → 复变函数 → 可导（柯西-黎曼条件） → 解析 → 积分（柯西定理） → 级数（泰勒、洛朗） → 奇点 → 留数 → 实积分。

**后半是积分变换**：把时间信号搬到频率域或复频率域，让微分方程变成代数方程。核心线索是：

> 周期信号 → 傅里叶级数 → 非周期信号 → 傅里叶变换 → 频域分析 → 拉普拉斯变换 → $s$ 域分析 → 电路暂态与传递函数 → （选讲）Z 变换 → 离散系统。

两半不是拼在一起的。复变里的"解析"保证了傅里叶变换、拉普拉斯变换的性质；留数则直接给出拉普拉斯逆变换的一种算法。学完后你会看到，它们本来就是一套工具的不同侧面。

## 这门课为谁写（对号入座）

假想读者长这样（对上几条算几条）：

- 大二，电类或自动化、通信、电子相关专业；
- 高数（上）（下）学过，会算积分、会解二阶常系数微分方程，但**级数部分学得最虚**；
- 高中复数只会四则运算，**没把复数当成平面上的点用过**；
- 电路课见过相量、$j\omega$、阻抗，知道"用复数算交流很方便"，但**不知道 $j$ 和 $i$ 是同一个东西，也不知道相量法为什么合法**；
- 对这门课的第一印象是"公式很多、听说很难、不知道学了干什么"；
- **高数里的级数与常微分方程学得虚、忘得差不多**，看到比值判别法和特征根公式只剩模糊印象；
- 做题习惯是套公式，**不习惯检查定理条件**。

这套讲义按这个画像设防：

- 每个概念先给**复平面上的图像**，再给代数式；
- 每个工具至少给一个**电路或信号里的用法**，不让你把它当纯数学供着；
- 每个定理写全**条件**，并配"条件不满足会怎样"；
- 第 09 讲从级数收敛重新讲起，**不假设你真的会**；
- 第 04 讲把多值性讲透，**不让它含糊过去**。

## 前置

- 高等数学：极限、导数、一元与多元积分。**级数与常微分方程不要求记得**——第 09 讲从实数项级数的收敛定义重建，第 24 讲从一阶线性方程重建。
- 线性代数：矩阵与行列式（第 26、27 讲会用到一点）。
- 电路：相量法与阻抗（不熟也没关系，第 01 讲会把 $j$ 与 $i$ 统一，第 26 讲会重新讲一遍）。
- Python：不需要预先会。数值实验给出可直接复制的代码，用 `uv` 跑，照抄即可。

- [ ] 参数化计算复积分，会用柯西定理、复合闭路定理、柯西积分公式、高阶导数公式，并说清条件。
- [ ] 在指定圆域展开泰勒级数，在指定圆环域展开洛朗级数。
- [ ] 判断三类孤立奇点，计算留数，用留数定理算三类实积分。
- [ ] 求分式线性映射与常见初等映射，把上半平面、单位圆、角形域互相映射。

- [ ] 求拉普拉斯变换与逆变换，解常系数线性微分方程的初值问题。

## 每讲怎么用

1. 开头看**本讲解决什么**和前置，知道这一讲要做出什么。
2. 概念按**几何图像 → 定义 → 手算例题 → 数值实验**的顺序走。
3. 遇到定理，先看**条件清单**，再看结论；条件不满足的反例会在正文里给出。
4. 数值实验的每个数字，都能在 `scripts/` 找到脚本复跑。
5. 结尾做**作业**（基础 / 提高 / 综合三档），参考答案在每题下方平铺。先独立做，再对照。

## 三档深度与卡住协议

这门课公式多，最容易犯的错是**在不需要死磕的地方死磕**。每个概念会标三档：

- **要能推导 / 手算**：柯西-黎曼条件、柯西积分公式、留数计算、傅里叶与拉普拉斯性质表。这些要亲手写到不看书。
- **要知道有这回事 + 什么时候找它**：黎曼面、最大模原理、约当引理的证明、广义函数严格理论。知道名字和用途即可，别陷进去。
- **要建立直觉**：复平面图像、映射的几何效果、频谱的物理含义。它们是路标，不是证明。

**卡住协议**：

1. 一个定义读三遍不懂，先去做这一节的具体例题或数值实验（数字比符号友好）。
2. 还卡，标记后跳小节；很多卡点会在下一节的应用里自己解开。
3. 还卡，把问题记下来去问，或写进你自己的追问卡片。
4. 禁止对着一句话空想三十分钟以上。复变函数第一次读不懂是正常的：柯西-黎曼条件从提出到被理解，历史上也花了不少年。
