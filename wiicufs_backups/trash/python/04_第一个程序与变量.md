# 第 04 讲 第一个程序与变量：名字、对象、类型

> 这是 Python 主线的第一讲。从这一讲起，你写的是真正会算东西的程序，不再只是打印一句话。本讲只用到三样东西：`print`、`input`、变量（变量就是给一个值起的名字）。但会顺手拆开三件几乎所有初学者都会撞上的事：`input` 拿到的为什么不能直接加、`b = a` 之后改 `b` 为什么 `a` 也变、`0.1 + 0.2` 为什么不等于 `0.3`。

## 这一讲解决什么

先看两个要写的小程序。

**程序一：算 BMI。** 输入体重（公斤）和身高（米），输出 BMI 和等级。公式是体重除以身高的平方。

**程序二：算找零。** 一件商品 23.5 元，付 50 元，应该找多少。

写这两个程序，技术上只需要：让程序读入两个数、做一次除法、把结果打印出来。但你会依次撞上三堵墙：

- `input()` 读回来的"12"看起来是数字，加 1 却报错；
- 你把 `a` 赋给 `b`，改了 `b`，`a` 也跟着变；
- 用小数（浮点数，第 6 节讲它为什么会出错）算钱，`0.1 + 0.2` 的结果是 `0.30000000000000004`。

这三堵墙的根都在同一件事上：**Python 里的变量不是装东西的盒子，而是贴在对象（内存里的一块数据）上的名字**。把这一点想通，后面几讲会少很多莫名其妙的错误。

## 1. 先把一个脚本跑起来

### 1.1 三行脚本

打开记事本（或任何编辑器），输入：

```python
print("hello")
print(1 + 1)
print("1 + 1 =", 1 + 1)
```

另存为 `hello.py`，**保存类型选"所有文件"**，编码选 UTF-8（第 01 讲 3.2 节讲过为什么）。然后在这个文件所在的文件夹里打开黑窗口，敲：

```text
> python hello.py
hello
2
1 + 1 = 2
```

三行输出分别来自三条语句。`print` 的作用是"把括号里的东西显示出来"，它是你后面调试程序时最常用的工具。

### 1.2 怎么跑，以及跑不起来怎么办

上面那条命令 `python hello.py` 由两部分组成：`python` 是命令（叫醒 Python），`hello.py` 是参数（交给它读的文件）。

如果敲完出现：

```text
'python' 不是内部或外部命令，也不是可运行的程序或批处理文件。
```

说明这台机器没装 Python，或者装了但系统找不到。第 02 讲有完整的安装与 PATH 处理；如果你已经装好，只是换个文件夹就报错，先看第 01 讲 5.3 节（当前目录不对）。

如果出现：

```text
  File "hello.py", line 2
    print(1 + 1
              ^
SyntaxError: '(' was never closed
```

那就是代码写错了（`SyntaxError` 是"语法错误"的报错名），报错会指出行号（这里是第 2 行）和位置（`^` 指着缺右括号的地方）。先改这一行，再跑。

### 1.3 改一行再跑

把第一行改成 `print("你好")`，保存，再跑一次。输出变成"你好"。

这一步值得单独做，因为它确立一个循环：**改文件 → 保存 → 跑 → 看输出**。后面所有调试都是这个循环。最常见的"改了没生效"，几乎都是**没保存**，或者跑的是另一个目录里的同名文件。

## 2. input：程序第一次跟人说话

### 2.1 input 读回来的永远是文字

`print` 是程序往外说，`input` 是程序往里听：

```python
name = input("你叫什么？")
print("你好，" + name)
```

`input("你叫什么？")` 做两件事：先把提示语打出来，然后停在那一行，等你敲内容并回车。你敲的东西被读成一个**字符串**（一串文字，第 05 讲展开）——不管看起来像不像数字。

这一点必须当场确认，因为它是最容易踩的坑：

```python
x = input("输入一个数：")
print(type(x))
```

（`type()` 问"这个值是什么类型"；`str` 是字符串的类型名。）

你输入 `12`，打印出来是 `<class 'str'>`（`class` 就是"类型"，读作"str 类型"）。也就是说，`x` 是文字 `"12"`，不是数字 12。所以：

```text
>>> "12" + 1
TypeError: can only concatenate str (not "int") to str
```

（`>>>` 是交互式解释器的提示符，第 01 讲 5.5 节见过；这里只是表示"在解释器里敲这一行会得到这个结果"，不用抄进 `.py` 文件。）

### 2.2 要算数，就转换

想把它当数字用，得**显式转换**：

```python
x = float(input("输入一个数："))
print(x + 1)
```

`float(...)` 的意思是"把括号里的文字按小数解释"。整数用 `int(...)`。转换失败会报 `ValueError`，比如输入了空行或者 `abc`：

```text
ValueError: could not convert string to float: 'abc'
```

所以一个更稳的写法是：先读成文字，再尝试转换，转换失败就提示重来。第 11 讲会讲怎么捕获这个错误；现在先知道它会发生。

### 2.3 一个完整的 BMI 脚本

```python
weight = float(input("体重(kg)："))
height = float(input("身高(m)："))
bmi = weight / height ** 2
print("BMI =", round(bmi, 1))
```

跑起来是这样（`>` 后面是你输入的内容）：

```text
> python bmi.py
体重(kg)：> 70
身高(m)：> 1.75
BMI = 22.9
```

逐行看：

- `weight = float(input(...))`：先执行右边的 `input`，拿到文字；`float` 把它变成小数；`=` 把这个值贴上名字 `weight`。
- `height ** 2` 是"height 的平方"；`**` 是幂运算符。
- `weight / height ** 2` 先算幂，再算除法。
- `round(bmi, 1)` 把 `bmi` 保留一位小数。

`round` 的行为和你想的可能不一样（第 6.3 节会讲），但先跑通。

第二个脚本：找零。商品 23.5 元，付 50 元：

```python
price = float(input("商品价格："))
paid = float(input("付款："))
change = paid - price
print("找零", round(change, 2))
```

```text
> python change.py
商品价格：> 23.5
付款：> 50
找零 26.5
```

这个脚本现在能用，但它埋了一个雷：金额用 `float` 存，遇到 `0.1 + 0.2` 这类运算会冒出不精确的尾数（第 6.4 节实测）。现在先跑通，第 6.4 节给正确做法。

## 3. 变量是标签，不是盒子

### 3.1 赋值做了什么

`a = 1` 这一行，右边先算出一个值（整数 1；`=` 右边的整段东西叫**表达式**），然后 `=` 做的是：**把名字 `a` 贴到这个值上**。

```text
a = 1

  a ──▶ ┌─────┐
        │  1  │
        └─────┘
```

再执行 `a = 2`，不是"把盒子里的 1 换成 2"，而是"把 `a` 这张标签撕下来，贴到另一个对象 2 上"。原来的 1 还在，只是没有名字指着它了。

这个区别在数字上看不出来，换成列表就现形了。

### 3.2 两个名字可以贴在同一个对象上

```python
a = [1, 2]
b = a
b.append(3)
print(a)      # [1, 2, 3]
print(a is b) # True
```

（`[1, 2]` 这种方括号写的东西叫**列表**，能装一串值，第 06 讲细讲；`a is b` 问"是不是同一个对象"，第 4 节细讲。）

`b = a` 没有复制列表。它只是把 `b` 这张标签也贴到**同一个列表对象**上：

```text
a ──┐
    ▼
  ┌──────────┐
  │ [1, 2]   │   ← 只有一个列表，两个名字
  └──────────┘
    ▲
b ──┘
```

`b.append(3)` 改的是那个对象本身（`append` 是列表的一个**方法**——挂在对象上的函数；函数是"一段有名字、能被反复调用的代码"，第 09 讲细讲）。所以通过 `a` 看，它也变成 `[1, 2, 3]` 了。

### 3.3 为什么 `a = a + [3]` 和 `a += [3]` 不一样

同样是"加一个元素"，两种写法结果一样，过程不同。实测：

```text
after x = x + [3]: id changed = True   x = [1, 3]
after y += [3]   : id changed = False  y = [1, 3]
```

- `x = x + [3]`：先造出一个**新列表**，再把 `x` 改贴到新列表上。所以 `id` 变了。
- `y += [3]`：列表的 `+=` 是**原地修改**，往原来的列表尾部追加。所以 `id` 没变。

`id` 是对象在本次运行中的编号（下一节细讲）。这里只需要记住：**`+` 新建，`+=` 原地**。字符串的 `+=` 又不一样（字符串不可变，只能新建），第 7 节会说。

### 3.4 变量名的规矩

- 只能由字母、数字、下划线组成，不能以数字开头：`score1` 可以，`1score` 不行。
- 区分大小写：`Score` 和 `score` 是两个名字。
- 不能用 Python 的关键字：`if`、`for`、`class`、`def` 这些。
- **不要用内置名字当变量名**：`list`、`str`、`int`、`sum`、`max`。你写 `list = [1]` 之后，`list(...)` 这个内置功能就被你覆盖了，后面会报"`list` object is not callable"。

命名习惯用 `snake_case`：`user_name`、`total_score`，全小写、下划线分隔。第 16 讲会讲完整的风格约定。

## 4. 每个值都是对象：id、类型、值

### 4.1 问三个问题

Python 里每个值都是一个**对象**。对任何对象，你都能问三个问题：

| 问题 | 怎么问 | 例子 |
|---|---|---|
| 是同一个对象吗 | `a is b` | `a is b` → `False` |
| 是什么类型 | `type(a)` | `<class 'int'>` |
| 值相等吗 | `a == b` | `1 == 1.0` → `True` |

`id(a)` 给出对象在本次运行中的编号。同一对象编号相同，不同对象编号不同（数字本身是哪个不重要，不要拿它当地址用）。

### 4.2 `is` 和 `==` 各用在哪

- `==` 问"值相等吗"，日常比较都用它。
- `is` 问"是不是同一个对象"，**只建议用在 `None`、`True`、`False` 上**。

```python
x = None
if x is None:      # 对
    ...
if x == None:      # 能跑，但不推荐
    ...
```

为什么 `is` 只用于这三个？因为它们各自只有一个对象，`is` 不会骗你。而数字和字符串的"是不是同一个对象"取决于 Python 的内部优化，不可依赖——下面就是例子。

### 4.3 为什么 256 是同一个、257 不是

实测：

```text
256: p is q = True   p == q = True
257: r is s = False  r == s = True
```

同样的写法：`p = 256; q = int("256")`，`p is q` 为 `True`；换成 257 就变成 `False`。

原因是 Python 预先造好了一份 $-5$ 到 $256$ 的小整数对象，用到时直接复用。257 不在这个范围，`int("257")` 每次造一个新对象。

这件事的结论不是"记住 256"，而是：**`is` 的结果依赖实现细节，比较数值永远用 `==`**。

## 5. 五种基本类型与两条线

### 5.1 int、float、bool、None、str

| 类型 | 表示什么 | 例子 | 要留意的 |
|---|---|---|---|
| `int` | 整数，位数不限 | `42`、`-7`、`2**100` | 没有溢出 |
| `float` | 小数（双精度） | `3.5`、`0.1` | 有精度误差 |
| `bool` | 真 / 假 | `True`、`False` | 是 `int` 的子类：`True == 1` |
| `NoneType` | "没有值" | `None` | 只有一个对象 |
| `str` | 文本 | `"hello"` | 第 05 讲展开 |

`bool` 是 `int` 的子类（子类就是"一种特殊的"：布尔值是一种特殊的整数），所以 `True + True` 等于 `2`，`isinstance(True, int)`（问"True 是不是 int 类型"）是 `True`。这不是设计缺陷，是故意的：布尔值可以直接参与计数。

### 5.2 动态类型：名字可以改贴

同一个名字，先贴整数、再贴字符串，完全合法：

```python
v = 1
v = "one"
```

Python 不要求你声明类型，因为**类型属于对象，不属于名字**。`v` 只是一个标签，它贴到谁身上，`type(v)` 就是谁的类型。

### 5.3 强类型：不隐式瞎转

"不用声明类型"经常被误解成"随便写"。实际上 Python 在运算上很严格：

```text
1 + "1"  -> TypeError
1 + 1.0  -> 2.0
```

`1 + "1"` 不会自动把 `"1"` 变成 1，直接报错。而 `int + float` 可以，因为数值类型之间有明确的提升规则（整数自动变小数），这不算"瞎转"。

所以两条线要一起记：**名字可以随便改贴（动态），但运算要求类型相容（强类型）**。

### 5.4 None 和"假值"

`None` 表示"没有值"，它只等于自己：

```text
None is None: True    None == False: False
bool(None): False  bool(0): False  bool(''): False  bool([]): False
```

`None`、`0`、`""`、`[]`、`{}`、`False` 在 `if` 里都算假，但它们不是一回事：`None` 是"没有"，`0` 是"数量为零"，`""` 是"空文本"。判断"有没有给值"用 `is None`，判断"数量是不是零"用 `== 0`，别混。

## 6. 数字的完整形态

### 6.1 `/` 永远出小数，`//` 向下取整

```text
7 / 2   = 3.5
-7 // 2 = -4
```

- `/` 是普通除法，**结果永远是 `float`**，哪怕整除：`4 / 2` 是 `2.0`，不是 `2`。
- `//` 是整除，但它不是"去掉小数部分"，是**向下取整**（朝负无穷方向）。所以 `-7 // 2` 是 `-4`，不是 `-3`。

### 6.2 `%` 与 `//` 是一对

```text
-7 // 2 = -4    -7 % 2 = 1
check: -7 == (-7 // 2) * 2 + (-7 % 2)  ->  True
```

`%` 是取余数。Python 保证这条恒等式对任何整数都成立：

$$a = (a \mathbin{//} b) \times b + (a \bmod b)$$

所以 `%` 的结果符号跟着**除数**走：`-7 % 2` 是 1，`7 % -2` 是 -1。C 语言里 `%` 跟着被除数走，这是两门语言容易混的地方。

### 6.3 round 不是四舍五入

```text
round(2.5) = 2    round(3.5) = 4    round(0.5) = 0
```

`round` 用的是"四舍六入五成双"（银行家舍入）：恰好 .5 时，向偶数那边靠。所以 `round(2.5)` 是 2，`round(3.5)` 是 4。要真正的"四舍五入"，得自己写判断，或者用 `Decimal` 的舍入模式。

### 6.4 浮点误差与金额

```text
0.1 + 0.2 = 0.30000000000000004    == 0.3: False    isclose: True
```

`float` 用二进制存小数，0.1 和 0.2 都不能被精确表示，相加后的误差就露出来了。两条结论：

- **不要用 `==` 比较两个浮点数**。要判断"差不多相等"，用 `math.isclose(a, b)`（`math` 是 Python 自带的标准库，`isclose` 是里面判断"两个浮点是否足够接近"的函数）。
- **金额不要用 `float`**。用整数"分"（23.5 元记成 2350 分），或者用 `decimal.Decimal`（`Decimal` 是一个能把十进制小数精确存下来的类型）。它怎么用，本讲不展开，知道它存在即可。

### 6.5 整数没有上限

```text
2**100 的位数 = 31
2**1000 的位数 = 302
```

Python 的 `int` 是任意精度的，位数只受内存限制，不会像 C 的 `int` 那样溢出回绕。代价是大数运算更慢、更占内存。

## 7. 可变与不可变

### 7.1 一张清单

| 不可变（改了等于新建） | 可变（可以原地改） |
|---|---|
| `int`、`float`、`bool`、`None`、`str`、`tuple`、`frozenset` | `list`、`dict`（字典）、`set`（集合）、你自己写的类的实例 |

（`dict` / `set` 第 07 讲展开；`frozenset` 是"不可变的集合"，认识层即可。）

实测两种"改"的差别：

```text
str += 后 id changed = True   | text = ab
list append 后 id changed = False | lst = [1, 2]
```

字符串 `+=` 之后 `id` 变了——它不是原地追加，而是造了一个新字符串；列表 `append` 之后 `id` 没变——它真的在原地改。

### 7.2 三条推论

从"可变 / 不可变"这一条，能推出后面三讲要反复用的结论：

1. **可变对象当函数参数传进去，函数里改了，外面也会变**（函数第 09 讲细讲；现在只需知道函数能接收外面的值）。
2. **可变对象不能当函数的默认值**，否则会在多次调用之间累积（第 09 讲）。
3. **可变对象不能当字典的键**（第 07 讲）。

现在不用记细节，只要记住这张清单：判断"会不会互相影响"之前，先问"这个对象可变吗"。

### 7.3 tuple 里放 list，tuple 也"变了"

```python
t = (1, [2, 3])
t[1].append(4)
print(t)     # (1, [2, 3, 4])
```

（`(1, [2, 3])` 这种圆括号写的东西叫**元组**，第 06 讲细讲。）

`tuple` 不可变，指的是"不能换掉它里面的元素引用"：`t[0] = 9` 会报 `TypeError`。但如果某个元素本身是列表，你改那个列表的内容，`tuple` 看上去就变了。**不可变是浅的**。

## 8. 注释与 docstring

### 8.1 注释：写给人看的

```python
# 体重用公斤，身高用米；单位混了结果会差很多
bmi = weight / height ** 2
```

`#` 后面的内容 Python 不执行。注释应该解释"为什么"，不是复述代码——`i += 1  # i 加 1` 这种注释没有信息。

### 8.2 docstring：写给用这个函数的人看的

函数（第 09 讲细讲；`def` 是"定义函数"的写法）的第一行如果是三引号字符串，它就成为这个函数的**文档字符串**（docstring），会被存进 `__doc__`：

```python
def bmi(weight, height):
    """返回 BMI：体重(kg) / 身高(m) 的平方。"""
    return weight / (height ** 2)
```

实测取出来：

```text
bmi.__doc__ = '返回 BMI：体重(kg) / 身高(m) 的平方。'
bmi(70, 1.75) = 22.9
```

`help(bmi)`（`help()` 是 Python 自带的查帮助函数）打印的就是这段文字；`return` 后面的东西叫**返回值**，第 09 讲细讲。注释解释"这一步为什么这样做"，docstring 说明"这个函数是什么、怎么用"。

## 小结

- `print` 往外写，`input` 往里读；`input` 读回来的永远是 `str`，要算数必须 `int()` / `float()` 转换。
- 变量是贴在对象上的名字；`b = a` 不复制，只是多贴一张标签。
- `+` 新建对象，`+=` 对列表是原地改；字符串的 `+=` 是新建。
- `==` 比值，`is` 比"是不是同一个对象"；`is` 只用于 `None` / `True` / `False`。
- Python 动态（名字可改贴）且强类型（运算不隐式转换）。
- `/` 出小数，`//` 向下取整，`%` 与 `//` 配套；`round` 是银行家舍入。
- 浮点有误差：比较用 `math.isclose`，金额用整数分或 `Decimal`。
- 判断"会不会互相影响"之前，先问"这个对象可变吗"。

**Q1.** 下面两行输出看起来一样，但值不一样。写出它们各自的类型，并说明为什么 `print` 看不出来区别。

```python
print(12)
print("12")
```

**参考答案：**
`12` 是 `int`，`"12"` 是 `str`。`print` 的作用是"把对象转成适合显示的文本"，两种类型显示出来都是 `12`，所以看不出区别。用 `type(12)` 和 `type("12")` 能看到 `<class 'int'>` 与 `<class 'str'>`。

**Q2.** 你写 `x = input("输入一个数：")`，然后 `x + 1` 报 `TypeError`。解释原因，并写出两种修法。

**参考答案：**
`input` 读回来的永远是字符串，`"12" + 1` 是"文本加整数"，Python 不做隐式转换，所以报 `TypeError: can only concatenate str (not "int") to str`。修法：① 读入时就转换 `x = int(input(...))`（小数用 `float`）；② 读入后转换 `x = int(x)` 再运算。

**Q3.** `a = [1, 2]`、`b = a`、`b.append(3)` 之后，`a` 是什么？画出名字与对象的关系，并解释为什么。

**参考答案：**
`a` 是 `[1, 2, 3]`。`b = a` 没有复制列表，只是把 `b` 也贴到同一个列表对象上；`append` 改的是那个对象本身，所以通过 `a` 看也变了。关系是：两个名字、一个列表对象。

**Q4.** `x = x + [3]` 与 `x += [3]` 对列表的结果一样，过程有什么不同？用 `id` 怎么验证？

**参考答案：**
`+` 造一个新列表再把 `x` 改贴过去，`id` 会变；`+=` 调用列表的原地追加，`id` 不变。验证：在操作前后各打印一次 `id(x)`，前者两次不同，后者相同。

**Q5.** 判断并说明理由：`256 is 256` 是 `True`，`257 is 257` 可能是 `False`。这说明比较数值应该用哪个运算符？

**参考答案：**
Python 预先缓存了 $-5$ 到 $256$ 的小整数对象，所以这个范围内的同值整数常常是同一个对象；257 不在范围内，可能每次新建。这说明 `is` 的结果依赖实现细节，比较数值应该用 `==`，`is` 只用于 `None` / `True` / `False`。

**Q6.** 写出下面每个表达式的结果或错误类型：① `7 / 2`；② `7 // 2`；③ `-7 // 2`；④ `-7 % 2`；⑤ `1 + "1"`；⑥ `True + True`。

**参考答案：**
① `3.5`（`/` 永远出 float）；② `3`；③ `-4`（向下取整，不是截断）；④ `1`（`%` 与 `//` 配套，符号跟除数）；⑤ `TypeError`（强类型，不隐式转换）；⑥ `2`（`bool` 是 `int` 的子类）。

**Q7.** 用 `round` 处理 2.5、3.5、0.5，结果分别是什么？如果你要实现"真正的四舍五入"，能直接用 `round` 吗？

**参考答案：**
分别是 `2`、`4`、`0`。`round` 是"四舍六入五成双"（银行家舍入），恰好 .5 时向偶数靠，所以不能直接当四舍五入用。要严格四舍五入，需要自己判断小数部分，或用 `Decimal` 指定舍入模式。

**Q8.** 你写了一个算钱的程序，`0.1 + 0.2 == 0.3` 是 `False`。给出两种正确的处理方式，并说明各自适合什么场景。

**参考答案：**
① 用整数"分"表示金额（23.5 元记成 2350 分），所有运算在整数上做，最后再除以 100 显示；适合加减乘除都简单的账目。② 用 `decimal.Decimal`，它能精确表示十进制小数；适合需要精确小数位与舍入规则的场景。两种都比 `float` 适合金额。比较浮点是否"差不多相等"用 `math.isclose`。

**Q9.** `t = (1, [2, 3])` 之后执行 `t[1].append(4)`，会不会报错？`t` 变成什么？这说明 `tuple` 的"不可变"是什么意思？

**参考答案：**
不会报错。`t` 变成 `(1, [2, 3, 4])`。`tuple` 不可变指的是"不能替换它里面的元素引用"（`t[0] = 9` 会 `TypeError`），但它不阻止你修改元素指向的可变对象。所以"不可变"是浅的。

**Q10.** 注释和 docstring 各写给谁看？各举一个应该写和不该写的例子。

**参考答案：**
注释写给读代码的人，解释"为什么这样做"，例如"# 体重用公斤，身高用米，单位混了结果差很多"；不该写"# i 加 1"这种复述代码的。docstring 写给"要调用这个函数的人"，说明它是什么、参数和返回值，例如函数的 `"""返回 BMI：体重(kg) / 身高(m) 的平方。"""`；不该拿它当"临时注释掉的一段代码"。
