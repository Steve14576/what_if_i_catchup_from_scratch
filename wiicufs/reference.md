# WIICUFS 1.4.5：具体参考与示范

> 本文件展示 v1.4.5 的规则落在正文、PLAN、验证和回查时是什么样。SKILL.md 负责讲清原则；这里负责给可辨认的正反例。

## 1. 直接说清，比“生活化”更像人话

### 反面：万能词没有信息

```markdown
还有一笔旧账没算。
同名端是下一节的整个舞台。
去耦等效是解决互感方程的大杀器。
理想变压器为什么能变阻抗？这是它的魔法。
```

这些句子的问题不是口语，而是指向不稳定：旧账可能是初始值、旧结果或漏洞；舞台可能是变量、问题或应用；大杀器可能是任意方法；魔法没有说明机制。读者只能回翻上下文猜。

### 正面：对象、条件、关系、结果

```markdown
还需要解释一个现象：谐振时，电容两端电压为什么会高于电源电压？
本节先确定同名端如何决定互感项的正负号。
去耦等效把含互感项的方程改写为普通电感网络，之后可直接列结点方程。
由 U1/U2=N1/N2、I1/I2=N2/N1，可得 Zin=(N1/N2)^2 ZL。
```

后一组并不冷，也不需要读者解码。它直接告诉读者当前对象、下一步动作和因果关系。

### 类比何时可留

```markdown
# 不够：
不同频率的正弦像不同筛子，各筛各的。

# 可以：
不同频率的正弦在一个周期内的乘积积分为零，称为正交。
因此把函数乘上 sin(nωt) 再积分时，其他频率项全部消失，
可以单独求第 n 次的系数。这个结论只用于周期积分和线性汇总。
```

这里即使保留“筛子”的直觉，也必须给出映射、结果和边界；通常直接写后一段就够。

## 2. 自然段落不是没有结构

下面是一种自然推进：

```markdown
### 为什么相变时温度不变仍然吸热？

相变期间，温度不变只说明分子平均动能没有继续增加，
不说明内能不变。液体变成蒸气时，分子间距离增加，
需要克服分子间作用力，因此势能增加。

能量关系是：
$$Q=\Delta U+P\Delta V$$

其中大部分热量对应 $\Delta U$，小部分对应膨胀做功。
所以“温度不变”不能推出“没有吸热”。
```

它有结构：问题 → 误解 → 机制 → 公式 → 结论。但它不需要先画阅读路线，也不需要在结尾广播“下一站”。

## 3. PLAN 防漏，但不进入正文

### PLAN 中可以这样写

```markdown
- 相变：定义、五阶段、显热/潜热、温度不变但内能改变、T-v 与 P-v 图、边界：理想气体关系不适用于两相区。
- 读者可能误判：T 不变，所以 ΔU=0。正文应在潜热段直接纠正。
- 这讲不展开分子势能的统计力学来源；理由：只需用能量关系做工程计算。
```

### 正文不应这样写

```markdown
现在要完成 PLAN 里的边界项，并回应链条上的防错问题。
```

PLAN 是作者的工作台。读者只应看到当场需要的内容：

```markdown
注意：ΔU=cvΔT 只适用于理想气体单相区。相变时液气共存，
温度不变但分子间势能仍会改变。
```

## 4. 脉络图、任务、自测：按需，不是仪式

### 值得加脉络图的情形

一讲同时处理三个分支，例如“先求状态 → 选择查表路径 → 做能量方程 → 核查单位”。读者确实会在路径选择处迷失，可放一张简短路线图。

### 不值得加脉络图的情形

一讲只解释一个线性因果链，例如“为什么电容电压连续”。直接从 $i=C\,du/dt$、有限电流、积分关系讲到结论，读者不会因为没有树状图而迷路。

### 值得加自测的情形

多个相近公式容易混淆时，用三五项动作型自测：例如“我能区分饱和液体、气液混合物和过热蒸气”。

### 不值得加自测的情形

小结已经用例题、公式与边界自然收束时，再加十个复选框只会重复。

## 5. 不空降的最小形态

### 反面

```markdown
相变时查饱和表，利用 x 求 h。
```

读者不知道“饱和表、x、h”是什么，也不知道为何要查。

### 正面

```markdown
气液混合物的温度和压力不再足以确定状态，还需要知道其中蒸气占多少。
这个比例叫干度 $x$：单位质量混合物中蒸气的质量占比，范围是 0 到 1。
查饱和表得到饱和液体焓 $h_f$ 和饱和蒸气焓 $h_g$ 后，混合物焓为
$$h=h_f+x(h_g-h_f)。$$
```

定义、为什么需要、符号、范围、公式都在读者第一次遇到处。

## 6. 验证脚本的最小形态

```python
# 规模纪律：方波的前若干傅里叶项，目标 < 2 秒。
import numpy as np

A = 10.0
for n_max in [1, 3, 9, 99]:
    u_rms = np.sqrt(sum((4 * A / (n * np.pi)) ** 2 / 2
                        for n in range(1, n_max + 1, 2)))
    print(f"n={n_max}: partial RMS={u_rms:.4f}; expect -> {A}")
```

它不是为了炫代码：输出明确说明正在测什么、预期是什么、为何这个数据能支撑讲义结论。脚本应归档，讲义中的数值能追溯回来。

## 7. 预写偏差要诚实留下

```markdown
> 一个修正：原先以为“保留更多傅里叶项会消除跳变处过冲”。
> 实测中，过冲高度没有消失，只是集中到更窄的时间区间。
> 这是 Gibbs 现象。增加项数能改善整体逼近，但不能让跳变点局部一致收敛。
```

需要同时有：原预想、实际现象、原因。不要把改过后的结论伪装成一开始就知道。

## 8. 作业不按档位凑数

```markdown
**Q.** 一个方波的基波有效值为 9 V，三次谐波有效值为 3 V，
其余项忽略。求总有效值。

**参考答案：**
$$U=\sqrt{9^2+3^2}=\sqrt{90}=9.49\ \mathrm{V}。$$

验算：不同频率正弦正交，所以用平方和而不是 $9+3$。
```

题目有一个明确练习目标就够。若内容自然需要综合题，再加；不为“基础/提高/综合”标签生成空题。

## 10. 完整形态检查在 PLAN 中怎样工作

“完整覆盖”不是让正文回答一个六问清单，而是防止作者只写“主线刚好够跑”的部分。

### 作者 PLAN 的记录

```markdown
- 电容电压连续性：
  - 标准关系：i=C du/dt；有限电流时 u 连续。
  - 组合：多个电容、串并联留到后讲；本讲给最小说明。
  - 外部打断：理想冲激电流可使 u 突变，标为例外。
  - 重复/共存：初值由换路前状态决定。
  - 规范：先判 0-，再写 0+；不把“电容开路”误用于瞬间。
  - 相邻边界：直流稳态开路，不等于任意时刻无电流。
  - 决定：连续性、初值、稳态/瞬态边界进本讲；串并联留给元件章。
```

### 读者正文可能只需要这样写

```markdown
换路瞬间，若电容电压突然改变，就意味着 du/dt 无穷大。
由 i=C du/dt 可知这需要无穷大的电流。普通电路没有这种电流，
所以 uC(0+)=uC(0-)。

注意：这不是“电容永远开路”。电容只在直流稳态中不再有电流；
换路后它仍可能充电或放电。
```

后台检查很完整，正文却只写当前读者必须知道的关系、条件和常见误用。

## 11. 认知思维链：预测卡点，不替正文写剧本

### 被退回的 PLAN 写法

```markdown
来：会解方程组。
疑问：矩阵乘法为什么行乘列？
学完：矩阵乘法是变换复合。
```

问题：没有第一人称旧直觉；只有一道笼统问题；没有边界、防错和问题顺序；无法据此检查正文是否真的回答了读者。

### 可用的 PLAN 写法

```markdown
- 我带着什么来：会解小方程组；我以为矩阵只是把数字排成方格。
- 第一反应：矩阵乘法大概和数字乘法一样，我会默认 AB=BA。
- 我会依次卡住：
  - 矩阵到底是什么，为什么不是普通数表？[→ 矩阵的作用]
  - 加法逐元素，乘法为什么不逐元素？[→ 行乘列与复合]
  - 结果尺寸怎么判断，避免把行列乘反？[→ 尺寸规则]
  - AB 能交换吗？[→ 不交换的例子]
  - AB=AC 时能约掉 A 吗？[→ 零因子与消去陷阱]
  - 除了“数表”还能怎样理解矩阵？[→ 向量与变换]
- 学完后：矩阵是线性变换的表示；行乘列使乘法对应复合，顺序不能乱。
- 还悬着的钩子：哪些变换能撤销？去逆矩阵。
```

它不要求正文按六个问号逐问排演。它要求作者在读者会卡住的位置，给出系统解释；交付前能逐条核对是否漏答。

## 12. 问答段装新知识的事故

线性代数教程曾把下列内容首讲塞进“想当然三连击”：

- $(AB)^{-1}=B^{-1}A^{-1}$；
- $A^{-k}$ 的含义；
- 矩阵没有普通除法。

这种写法看似有互动，实际是让读者从答疑里捡结论：

```markdown
# 错误
想当然三连击：$(AB)^{-1}$ 是不是 $A^{-1}B^{-1}$？
```

正确次序应是：正文先给定理、条件、推导或数值例子；定理后才可就地写：

```markdown
如果你想当然认为顺序无所谓，试一下 A、B 都可逆但 AB≠BA 的例子。
反序不是记号游戏：要让 (AB)(B^{-1}A^{-1})=I，B 必须先和 B^{-1} 相邻。
```

末尾若还需要问答索引，首句写“本节零新知识，只对答案”，每条对应一个正文小节。

## 13. 任务、脉络图、导航的选择示范

### 适合任务牵引

C++ 温度装置可以连续做：开机自检 → 存读数 → 超温报警。每一讲增加一个可观察功能，读者确实需要知道当前功能属于整条装置的哪里；此时任务成品和简短路线图有用。

### 不适合硬套任务

“傅里叶级数为什么能分离不同频率”是一个线性的数学因果链。强行编“频率侦探任务”会增加人物、场景和动机，却不帮助读者理解正交积分。直接讲现象、正交性、系数公式和方波例子更好。

### 导航应当解决具体迷失

```markdown
# 有价值：读者需要在两个方法间选路
已知压力和温度：先判断是否落在饱和区；若在两相区，查饱和表并用干度；
若在过热区，改查过热蒸气表。

# 无价值：只重复作者正在继续
下一站：现在我们继续理解这个概念。
```

## 14. 一个完整验证脚本的形态

```python
# 规模纪律：小规模演示，目标 < 8 秒。
import time
import numpy as np

T0 = time.perf_counter()
np.random.seed(42)
N = 50
x = np.random.uniform(-3, 3, N)
y = 2.0 * x + 3.0 + np.random.normal(0, 0.5, N)

print("=== EXP1: gradient descent — loss decreases ===")
w, b, lr = 0.0, 0.0, 0.05
losses = []
for epoch in range(100):
    y_pred = w * x + b
    loss = np.mean((y_pred - y) ** 2)
    losses.append(loss)
    w -= lr * 2 / N * np.sum((y_pred - y) * x)
    b -= lr * 2 / N * np.sum(y_pred - y)

print(f"learned w={w:.4f}, b={b:.4f}")
print(f"loss: epoch 0={losses[0]:.4f}, epoch 99={losses[-1]:.4f}")
print("expect: loss decreases and parameters approach the source values")
print(f"runtime={time.perf_counter() - T0:.2f}s")
```

脚本同时给出规模、数据、预期、实测和结论。讲义引用其中数字时，读者可定位脚本复跑。

## 15. 预写偏差怎样诚实写进讲义

### 例：偏差—方差的预想被实测打破

预写：“9 次多项式偏差低、方差高。”

实测：

```text
degree=9: bias^2=6.3720, variance=390.5019
```

可写成：

```markdown
> 一个诚实记录：这次 9 次模型的 bias^2 也高（6.37），
> 不是常见图里的“低偏差”。样本数接近参数数目，拟合数值不稳定，
> 部分采样的预测剧烈偏离，连平均预测也偏了。
> 但最明显的仍是方差 390 的爆炸：它说明模型对训练样本极敏感。
```

三件事必须都在：原预想、实际数据、根因。不要偷偷把结论换掉。


## 18. 什么不是 WIICUFS

- 不是用任务、人物或故事替代技术解释；
- 不是把作者 PLAN 输出给读者；
- 不是为了自然而少讲必要条件、边界和验证；
- 不是学术论文、随意博客、API 文档或视频脚本的通用替代品；
- 不绑定具体项目，可用于数学、物理、工程和编程。
