# 课件扒取：把 PPT / PDF 课件变成可信文字稿

把一堆课件（`.ppt` / `.pptx` / `.pdf`）变成**逐页、保真、可引用**的 Markdown 文字稿。**只还原、不加工**——不做讲解、不做融合（那是下游"写教程"的事）。这份文字稿是下游写作的原料。

**一份源文件 = 一讲。** 讲次边界等于源文件边界，不按学时数拆（文件名叫"05－06学时"，只要是一个文件就是一讲）。

## 什么时候用

用户显式点名时使用，例如：要把课件转成文字稿、扒 PPT、把讲义整理成 md、还原课件里的公式或图。

## 开工前先向用户声明：格式难度与最优入口

三种源文件的提取难度差别很大，**动手前先向用户讲清楚**，并主动建议最省事的路径：

| 源格式 | 提取难度 | 说明 |
|---|---|---|
| **PDF** | 最省事（首选） | 文本层完整、编码无歧义；公式会碎成碎片，但反正都要靠渲染图重打，不算额外负担 |
| **PPTX** | 中等 | 走 python-pptx，且**必须递归组合形状**，否则静默漏字；公式是 OLE 对象、无文本 |
| **PPT（旧二进制）** | 最麻烦 | OLE record 手工解析，编码不可靠、易乱码，母版噪音多 |

**因此，主动鼓励用户：如果手里是 `.ppt` / `.pptx`，先用 PowerPoint / WPS / LibreOffice「另存为 / 导出为 PDF」再交给我们。** 这是全流程最省事、最稳的入口，一下绕开旧 `.ppt` 解析与 PPTX 组内漏字两类坑。

**两个边界（别把 PDF 说成万能）**：

- 导出时要用「另存为 PDF」这类**保留文本层**的方式；若把文字栅格化成图，该页会退化成“纯图页”，所以拿到 PDF 后**仍要探测文本层是否为空**。
- PDF **不消除**“公式要渲染重打、图要归档”这两步——那是所有格式共有的工作；PDF 只是不额外增加风险。

## 交付三件套

一讲同时给出三样：

1. `文字稿.md` —— 按 `## 第 N 页` 分节；含 LaTeX 公式 + 相对路径图片引用 + 头部来源说明。
2. `<讲次>-images/` —— 归档的关键图，命名 `p页码_中文描述.png`。
3. `<讲次>-render/` —— 全页渲染兜底目录，每页一张 PNG（命名 `<源文件名>_pNN.png`）。

## 核心原则（违反即返工）

1. **只还原不加工**：按页序原样落，不融合、不跳重点、不打乱顺序、不替老师改写；中英混排原样保留。
2. **讲次边界 = 源文件边界**：一份课件一讲，不拆分、不合并。
3. **判据优先，别凭印象**：每个判断都落成一句**可判定判据**，再用脚本或计数核对。凭"我感觉"必翻车。
4. **整页渲染永远兜底**：先保证每一页都有一张渲染图可查，最坏情况下也不丢内容。
5. **先探测、后假设（对抗"格式地狱"）**：课件版式五花八门，任何"这里一定是 X 格式 / 一定有 Y"的假设都可能错。动手前先核实源文件真实结构；每种通路都留兜底；判据写成与版式无关的。
6. **先做一份完整样本，再批量推广**：先用一讲跑通整条通路并验收，再套同一口径到其余讲次。
7. **中文脚本与中文路径格外小心**：这是最高频的坑，见下"高频坑"。

## 流程（六步）

1. **逐页文本提取** → 原始稿。PDF 走 PyMuPDF；无 PDF 的 PPTX 走 python-pptx（**必须递归组合形状**，否则静默漏字）。公式在此步是坏的（OLE 对象 / 文本层碎字符），留给第 3 步。
2. **全页渲染** → `<讲次>-render/`。每页一张 `dpi=200` 起的 PNG，既用于读图，也作兜底。
3. **公式视觉还原**：**读渲染图**（唯一权威来源），把占位符替换成干净 LaTeX。定界符：行内 `$...$`、块级 `$$...$$`（不用 `\(...\)` / `\[...\]`）。
4. **图片归档**：选图源 + 判范围（详见下）。
5. **嵌入成品**：在每页 `## 第 N 页` 后插入 `![P<页> 描述](<讲次>-images/....png)` + 一行 `（图中：…）` 说明；补头部来源说明。同一讲次只保留成品一份。
6. **交付前校验**：页数对齐、公式计数、图片路径可解析、占位符清零、纯图页有标注。

各步的完整做法、代码片段、边界情况 → 见 [reference.md](reference.md)。

## 图片归档：三条图源通路（第 4 步的核心）

1. **从源文件提取"插入的位图"**（旧 `.ppt` 的 `Pictures` 流按魔数切片）→ 干净原图。
2. **渲染整页** → 任何页可取，但带页面背景。
3. **决定性判据**：图上带**教学标注**（箭头、分段名、公式注记）时，一律用整页渲染图——干净原图会丢标注，而标注才是教学主体。

**"去掉标注后这张图还完整吗？"** 不完整 → 用整页渲染。

## 关键判据速查

| 要判什么 | 判据 |
|---|---|
| 一讲的范围 | = 一份源文件的全部页；不按学时拆 |
| 某讲做没做完 | 数文字稿里 `$$` 块与图片引用计数，分「达标 / 只有公式 / 纯文本」三档 |
| 哪些页是纯图页 | 该页可提取文本 < 50 字 |
| 某张图能不能干净抠出 | 先核实源文件有没有 `Pictures` 流；有则魔数切片，无则渲染 |
| 用原图还是用渲染图 | "去掉标注后还完整吗？"不完整 → 渲染图 |
| 这张图要不要归档 | "不看这张图会漏信息吗？"会 → 归档 |
| 公式对不对 | 以渲染图为准，逐页读图还原，最后查占位符清零 |

## 高频坑（详情见 reference.md 的"工具坑全表"）

- **PowerShell 跑含中文的 .ps1**：无 BOM 的 UTF-8 会被按 ANSI 读 → 乱码。改用 `$c = Get-Content -LiteralPath "x.ps1" -Raw -Encoding UTF8; Invoke-Expression $c`。
- **命令行向 python 传中文路径**：常乱码。命令行保持纯 ASCII，中文路径硬编码进脚本源码。
- **Python 打印中文到 Windows 控制台**：`UnicodeEncodeError`。开头 `sys.stdout.reconfigure(encoding='utf-8', errors='replace')`。
- **禁用 markitdown**（PDF/Word/PPT 输出稀碎）、**禁用 pandoc 做 md→tex**。
- **脚本内置路径易过期**：目录会重组，跑前先列目录核实。
- **改文件前必读当前版本**：不要信任会话里的旧快照。
